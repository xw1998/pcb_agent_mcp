# 07 · 布线几何与铺铜规则（拐角、线宽梯度、铺铜、缝合、禁布区）

> 这一篇是补漏：01–06 讲的是**先规划后动手**与**布哪条线**，完全没有回答
> 「线怎么拐弯」「铜怎么铺」「铺完的铜什么时候会骗你」。于是板上出现 123 个 90° 直角、
> 只有一片没有重铺的 GND、零个电源区、零个缝合孔——连通性检查全绿，板子不能用。
> 本篇每一条都带**判定工具**与**来源**，能判真伪，不是审美偏好。

## 1. 45° 与圆弧：先搞清楚收益在哪，再说能不能不遵守

**必须分两件事讲，混在一起就是忽悠。**

| 说法 | 成立吗 | 依据 |
|---|---|---|
| 直角走线会让高速信号「反射、插损变差很多」 | **不成立（低速/普通数字网）** | 实测 10 GHz 下 90° 与 45° 插损差 **0.15–0.28 dB**，与板材批次波动同量级 |
| 直角在铜箔拐角产生应力集中，热循环下有开裂风险 | **成立** | 微切片显示 45° 比 90° 的拐角塑性变形低约 **37%**，CTE 失配处是裂纹起点 |
| **锐角（<90°）是工艺缺陷** | **成立，必须避免** | 内角形成蚀刻液滞留的微区（俗称「酸角」），过蚀/残留药水，是良率问题不是审美问题 |
| 拐角用圆弧或 45° 折线是行业推荐 | 成立 | IPC-2221B 对拐角的要求；IPC-2221 推荐 135° 钝角或圆弧 |

**结论（可执行）**：
- 锐角：**禁止**。`board_45_corners` 的 `acute_corners` 必须是 0，出现即返工，不可用「反正连通了」放过。
- 90° 直角：**不致命，但不要画**。理由是铜箔应力与全板一致性，不是「信号会坏」。说「直角毁信号」是错的，会被懂行的人当场否掉。
- 圆弧：差分对、晶振、射频、大电流拐弯优先。低速普通信号用 45° 折线即可。

## 2. 拐角的两个尺寸（能算的数，不要凭手感）

- **45° 切角长度 L ≤ 0.4W**（W = 线宽）。切太长等于把一段直干线提前斜掉，转弯点漂移。
- **圆弧半径 R ≥ 0.5W**，且弧长足够让线宽过渡完整；R 太小等于没倒角还多了个制造难点。
- 差分对内两根线的切角必须**同形同位**，否则对内长度失配。

**对应工具**：`board_45_corners(action="audit")` 给出 `segments / off45_segments / off45_worst_deg /
corner_kinds{right, miter45, straight, other} / acute_corners / junctions`。
`action="chamfer"` 做**保持拓扑**的对称斜切（顶点替换为沿两腿各退 `cut` 的两点 + 一条对角）。
它不是布线器：不改走线方向、不新增层、不碰焊盘。

`chamfer` 的五种诚实拒绝，看到就要当结论读，不要绕过：
`vertex_on_pad` / `vertex_on_via`（在焊盘或过孔上切角 = 把铜拔掉，断路）、
`leg_too_short` / `leg_reserved`（腿不够长，或同一段两端各切一刀会互穿）、
`would_collide`（切出来的对角会撞到相邻网络，附 `with` / `with_net` / `gap_mm`）。

**一条实测结论**：231 段曼哈顿走线里 123 个直角，只有 81 个能切。
能切的比例就是「靠后处理能救回到什么程度」的上限——**45° 必须在布线的当下就走出来**，
不能布完再倒角。倒角是验收工具，不是补救工具。

## 3. 线宽梯度（按电流算，不按习惯抄）

| 网络 | 宽度 | 依据 |
|---|---|---|
| 普通信号 | 0.15–0.25 mm | 工艺下限 + 余量 |
| 电源（< 1 A） | 0.4–0.5 mm，或改铺铜 | 1 oz 铜、10 °C 温升，0.5 mm ≈ 1 A 量级 |
| 大电流 / LDO 进线 / VBUS | 铺铜或 ≥ 0.5 mm 短直 | 同上 |
| 差分对 | 按目标阻抗算，两根**等宽** | 等宽是等阻抗的前提 |

**同一条网从头到尾不要换宽度**：换宽处是阻抗台阶 + 蚀刻不均。必须换时用一段锥形过渡。
**给电源网留铺铜，不要用一根细线串完所有去耦**——这是「电源也不铺铜」挨骂的根因。

## 4. 铺铜（这是最容易骗人的一块）

### 4.1 `filled_polygon` 是**快照**，不是「活着的铜」

KiCad（以及所有 EDA）把铺铜结果**烘成多边形顶点**存进文件。这个快照只对「填的那一刻板上的铜」
成立。你在填之后画的任何一根线、任何一个过孔，**都没有从这个多边形里被挖掉**。

后果不是「看起来有点脏」，而是：

- DRC 把每一根新线都判成 **「走线 → 填充区，要求 0.25 mm，实际 0.0000 mm」**；
- 于是一次真实只新增 3 条违规的编辑，闸门报 **169–178 条新违规**并回滚；
- 反过来，如果你习惯性 `allow_new_violations=true` 硬写，就会把**真的短路的板子**当通过。

**实测（F412 核心板，231 段走线，两片 GND 区，填充比最后一轮布线早一代）**：

| 检查方式 | violations | clearance | 说明 |
|---|---|---|---|
| 不重铺 | **502** | 324 | 450 条是快照造成的幻觉 |
| 重铺后（scratch 副本，内存里填） | **52** | **0** | 同样的字节，才是真答案 |

⇒ **不重铺的 DRC 不是「更严格」，是「错的」。** 它会把真违规淹在噪声里，
让你永远分不清「板子坏了」和「铺铜过期了」。

**对应工具**：
- `board_drc(refill_zones=true)`（默认 true）：`kicad-cli --refill-zones` 在 scratch 副本里重铺后判定，**不写你的文件**。
- `board_fill_zones`：真正把重铺结果写盘（`--save-board` 等价的 pcbnew ZONE_FILLER 移植）。
- `board_apply` 的 DRC 闸门：两侧都带 `refill=True`。**重铺只会去掉幻觉，不会藏住真违规**——
  两根线太近，重铺后还是太近。

### 4.2 铺铜的工程参数

| 参数 | 建议 | 为什么 |
|---|---|---|
| 每个电源网各一片区 | 有 3V3 就铺 3V3，别只有 GND | 「电源不铺铜」= 电流全挤在细线上 |
| `clearance` | 0.25 mm（跟工艺一致） | 比设计间距小会让 DRC 与填充打架 |
| 热焊盘（thermal）辐条 | 4 条，宽 ≥ 0.4 mm | 太少/太窄 → `starved_thermal`，焊盘带不起来 |
| 孤岛（island） | 默认删除 | 留着就是天线 / 蚀刻不均 / `isolated_copper` |
| 优先级 | 电源区高于地、小面积高于大面积 | 低优先级区会让路 |
| 同名网多片区的连接 | 必须有缝合孔连通 | 否则「地平面」其实是一堆孤岛 |

### 4.3 铺完必须复查的三件事

1. `board_drc(refill_zones=true)` 里 `starved_thermal` / `isolated_copper` 为 0；
2. 两面 GND 之间的**缝合过孔**足够（见 §5）；
3. 铺铜**没有**把该留的禁布区吃掉（见 §6）。

## 5. 地平面与缝合过孔

- 双层板的最佳配置：**一面完整地平面（不被走线切）+ 另一面走线**。地平面被切开，回流就得绕，
  绕的那一圈就是环路面积 = EMI 与串扰。
- 两面都是地时，**缝合孔把两面缝成一片**：间距经验值 ≤ λ/20（低速板按 2–5 mm 网格足够），
  关键处（晶振四周、接口进线、板边一圈）加密。
- 信号换层时，**必须**在换层过孔旁就近放一个地过孔（回流路径跟着换）。
  只换信号不换回流 = 回流被迫绕一大圈。
- 缝合孔只放在「两面都已经是地铜」的位置。工具（`board_stitch` / `return_path`）会报告它
  因为那一侧没铜而跳过了哪些点——**跳过就是跳过，不是成功**。

## 6. 禁布区（keepout）：不是装饰，是几何约束

必须留、且必须能说出「留多大」的四处：

| 位置 | 为什么 | 留什么 |
|---|---|---|
| 晶振（Y1）四周 | 负载电容与走线寄生会让频偏；噪声会灌进时钟 | 器件下方不铺铜（或接地但不走线）、四周禁其他网络走线、外圈加缝合孔 |
| USB / 差分对进线 | 共模与阻抗 | 进线短、直、等长，参考面连续，不跨分割 |
| 按键 / 复位 | 机械行程与手感 | 按键下方与周边禁器件，禁走线（按压形变会磨阻焊） |
| 安装孔 / 排针 | 装配与螺柱 | 孔位一圈禁铜（螺柱会短路铺铜），排针内侧禁区 |

判定方式：`board_zones` / `keepout` 能不能读出这些区域；读不出来就是没做。

## 7. 泪滴（teardrop）

焊盘与走线连接处加泪滴，减少钻孔偏移/热应力下的断线。低速板可选，但**过孔密集区与细线拐角**建议加。
不加不会 DRC 报错——所以它属于「不做也没人拦你，但拆机就断」的那一类。

## 8. 验收清单（每条都能在一个数上判真伪）

| 项 | 通过标准 | 读数来源 |
|---|---|---|
| 锐角 | `acute_corners == 0` | `board_45_corners` |
| 直角 | `corner_kinds.right` 尽量为 0；不为 0 要能解释（例如焊盘处不可避免） | `board_45_corners` |
| 切角尺寸 | `L ≤ 0.4W`、`R ≥ 0.5W` | 尺寸可在 `chamfer` 的 `cut_mm_range` 上核 |
| 间距/边距 | DRC `clearance`/`copper_edge_clearance` 为 0 | `board_drc(refill_zones=true)` |
| 铺铜 | 每个电源网都有区；无 `starved_thermal`/`isolated_copper` | `board_drc` + `board_zones` |
| 缝合 | 两面地之间的过孔数 > 0，且换层处就近有地孔 | `board_stitch` / `return_path` |
| 回流 | 没有信号跨分割 | `board_cross_split` |
| 禁布区 | 晶振/USB/按键/安装孔四处都能读出禁区 | `board_zones` |
