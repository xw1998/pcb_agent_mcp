# 03 地与电源：铺铜不是「最后补一块绿」

## 两层板的标准答案

Sierra Circuits 对两层堆叠给的方案：**信号与电源走一层，另一层专做完整地平面**；
若两层都必须走线，地平面就会被切碎 → 必须**两面都铺地、用过孔缝合**维持连续性。

所以两层板的地策略是：
1. B.Cu 尽量整片地（能不走线就不走）。
2. F.Cu 也铺地，但给信号与电源让路。
3. 两面用缝合孔连成**同一个地**。
4. **不切地**（不 split）。模拟/数字靠分组摆放与走线隔离，不靠把地割成两块。

## 缝合孔：间距和位置

- 间距 **λ/20 ~ λ/10**（λ 为关心频段的最高频率波长）；实践值：高速数字 2.5–5 mm，
  一般混合信号 5–12.7 mm。**只能更密，不能更稀。**
- 位置：铺铜边缘、每个 GND 焊盘附近、每个信号换层点的两侧、连接器接地脚旁、
  敏感器件四周、长条铺铜的中段。
- 缝合孔要按**网格**摆，不要扎堆：扎堆会形成大量重叠反焊盘，反而在参考面上挖出大洞。

## 铺铜的六条细则（Sierra 的 ground plane 建议 + 两层板实务）

1. 铺铜与高速走线之间留 **1.5–2 倍线宽**，太近会改变阻抗、太远是浪费。
2. 不许有**孤岛**：没连到主地的碎铜要么删、要么打缝合孔接上。孤岛是天线。
3. 长条形、尖锐形状的碎铜（尤其是一头悬空的细条）必须处理——它就是辐射体。
4. 铺铜不是自动「填满就行」：**填完之后要验**，孔/焊盘/挖空把铜切碎了，等于没铺。
5. 散热片/大焊盘的地连接：手焊要热焊盘（thermal relief，辐条），大电流/散热要直连；
   这两种连接在回流上是两回事，别一把梭。
6. 电源铺铜与地铺铜之间要留够间距（按电压选行，见 `01`），不要贴在一起。

## 电源

- 线宽按电流与允许温升算（IPC-2221 图表拟合：`I = k·ΔT^0.44·A^0.725`，k=0.048 外层 /
  0.024 内层；仓库 `calc/current.py` 已实现，工具 `width_for_current` / `current_capacity`）。
  **必须显式指定标准**：`ipc2221` 与 `ipc2152` 同一个问题能差 3 倍以上，替调用方选就是错答案。
- 大电流不要单过孔：多个过孔并联，且过孔载流按镀层厚度算（`via_current_allowed`）。
- 功率回路（输入电容—开关/LDO—地）面积最小化：它决定辐射与纹波。
- 压降：长距离细线会掉压，用 `ir_drop_chain` / `board_ir_drop` 算，别用「大概够」。
- 电源入口要有：保护（保险/二极管）→ 大容量储能（1–10 µF）→ 每脚 100 nF。

## 验收用的读数（不要靠眼睛）

| 想确认的事 | 用什么 |
|---|---|
| 铺铜真的填出来了吗、填了多少面积 | `board_zones`（有 outline 无 filled_polygon 是「没铺」不是「铺了」） |
| 每个 GND 焊盘都吃到铜了吗 | `board_fill_zones`（让 KiCad 自己的 filler 铺）+ `board_pour_connectivity`（注意：中心点在多边形内 = **非权威**） |
| 铺铜把网络连起来了吗 | `board_drc` 的 unconnected（权威），不信自算 |
| 压降够不够 | `board_ir_drop`、`ir_drop_chain` |
| 参考面有没有被切开、信号有没有跨 | `board_cross_split`（没有平面层时它**拒答**，因为「没找到分割」会让坏板变绿） |
| 环路面积 | `board_loop_area`（没有层叠时拒答，因为猜介质厚度就是猜 EMC） |

**这一节的纪律**：铺铜相关的「差不多」「看起来连上了」全部不算数。中心点在内 ≠ 电气连通；
没有填充多边形 ≠ 有铜。所有结论必须落在工具读数或 DRC 上。
