# 04 接口专项规则：晶振 / USB / QSPI / LDO / 去耦

每条都写「为什么」，因为只记结论的人在板子尺寸变了之后就会做错。

## 晶振（ST AN2867 与 ST 社区文的布局部分）

ST 的原文态度很直接：**器件选得再好，布局不合只会剩一半价值**。

必须做到：
1. **两个负载电容 CL1 = CL2**，值由 `CL = Cs + CL1·CL2/(CL1+CL2)` 反解；
   `Cs = CIO + CPCB ≈ 3 pF`（ST 的经验值，数据手册常给 CIO = 5 pF 作最坏情况）。
   算出来不是标准值就取最近的标准值——偏离越多，频率偏得越多（pullability）。
2. **晶体紧贴 OSC_IN/OSC_OUT**，两条线的长度尽量短、尽量等长，中间不许走别的信号。
3. **槽形地屏蔽（trough）**：晶体与它的两个负载电容**各自**有一块独立的地「底板」，
   与其它地之间留一条可见的分隔线；再在装配层沿晶体与电容外围做一圈**地护墙**，
   墙上打**多个过孔**接到那块底板。
4. 那块底板**单独接到最近的 VSS 引脚**（可以与其他 VSS 分开）。
5. 晶振下方与四周不放任何其它网络；不在晶体区域换层；不走差分。

反面教材：晶体摆在芯片另一侧、两根长线并行走过一堆 GPIO、地只靠整板铺铜——
板上能跑，但温度/电压边角会起振失败，而 DRC 全绿。

相关：起振裕度 `gm ≥ 5·Gmcrit`（`Gmcrit = 4·ESR·(2πF)²·(C0+CL)²` 形式，具体按 AN2867 的
产品表取 `gm`），不满足就换晶体或降频率——这一步在选型阶段做，不在布局阶段补救。

## USB（全速 FS，12 Mbps）

- D+/D− **必须当差分对**：同层、并行、等长、等间距、尽量不换层；换层时两条一起换，
  过孔数量相同、位置对称（Sierra 的差分对规则）。
- 差分阻抗惯例 **90 Ω ±10%**（FS 对阻抗不敏感，但按惯例做不会错；用 `diff_impedance` /
  `diff_width` 算，需要层叠与介质厚度，两层板要显式给）。
- **不许有 stub**：分叉、测试点、上拉抽头都会变成反射源。需要上拉就串成菊花链。
- ESD 保护器件**靠近连接器**、在串联电阻**之前**；串联电阻靠近 MCU。
- VBUS 要有去耦（典型 4.7 µF + 100 nF），VBUS 走线要比信号宽。
- USB 线不要从晶振/开关电源下方穿过。
- 屏蔽壳（连接器 SH 脚）要多点接到地平面上。

> 说明：ST 的 AN4879《Introduction to USB hardware and PCB guidelines using STM32 MCUs》
> 是这一节的权威出处（检索时见到 V13.0，2026-10-30 版），**本次只核到条目未读正文**，
> 所以上面只写通行做法；要写进报告的数值，必须回到 AN4879 正文核对。

## QSPI / SPI NOR Flash

- **CLK 最短、最直**，优先于其它四根；CLK 两侧尽量有地（铺铜或地线），不跨分割。
- IO0–IO3、CS 在 SPI 模式下时序宽松，**不要求等长**；但 QSPI 高时钟（数十 MHz 以上）时
  按同一组处理：同层、参考面连续、避免并行走太长。
- Flash 的 VCC 脚旁**一颗 100 nF 紧贴**（引脚—电容—地回路最小），另在电源入口放 1 µF。
- CS 上拉（防止上电误进入某模式）按芯片手册接，别自创。
- Flash 放在 MCU 同侧、靠近对应引脚组；不要为了「板子平衡」把它放到远侧。

## LDO（SOT-223 / SOT-23 类）

- 输入电容紧贴 IN 与 GND，输出电容紧贴 OUT 与 GND；两者都要**低 ESR 且靠近**。
- 散热片（tab）铺铜面积最大化，必要时打过孔到地铜散热（`thermal_via_array`）。
- 反馈从输出电容接点取（固定输出版本内部已接，只需保证输出电容位置对）。
- LDO 的 GND 是噪声敏感点：不要让它成为别的高频回流路径的一部分。
- 输入—输出—地的铜**不要贴在一起**（按电压选间距行），功率回路面积最小。

## 去耦（通用）

- **每个 VDD 引脚一颗 100 nF**，位置优先于数量。
- 板级储能（1–10 µF）放在电源入口。
- 判据用 `decoupling_check`：需要电流、频段、纹波三个参数，缺一个它给
  `INDETERMINATE`——这是对的，别逼它猜。
- VCAP/内核稳压脚（STM32 的 VCAP1/VCAP2）按数据手册接电容，**不要接电源**。
- BOOT0/NRST 这类配置脚要有确定的默认电平（下拉/上拉），不许悬空。

## 一份可以照抄的「每引脚检查单」

对每个电源/地/晶振/复位引脚问四句：
1. 它旁边有电容吗？距离多少 mm？
2. 它到地的回路能画出来吗？画不出来的地方就是问题。
3. 它换层了吗？换层点旁边有地过孔吗？
4. 它下面（或旁边）有参考铜吗？被切开了吗？
