# 手工 PCB 布局布线方法论

## 这条技能是为了修什么

有过多轮教训：一块 F412 两层核心板，被画成 4 层、双面贴片、没有铺铜、用了自动布线，
最后 12 组网络布不通、走廊被自己堵死。事后复盘，**没有一条错误是「布线技巧不够」，
全部是顺序错**：先布线后规划、先连上后想回流。所以本技能的骨架是**顺序**，不是技巧。

三条硬规矩，任何情况下不例外：

1. **不许自动布局、不许自动布线。** 工具优化的是「连上」，不是环路面积、回流路径、
   工艺余量、可维修性。它们会先占掉中间的黄金通道，再用一条绕板三圈的线把网连上——几何全绿，
   板子是废的。
2. **先规划后动手。** 每一层要跑哪些网、跨几个方向、留几条车道，必须在放第一个器件之后、
   布第一根线之前算完。
3. **「连上了」不是验收项。** 验收项是：回流路径连续、电源有铜、缝合够密、间距过工艺、
   关键信号短且直。连通性只是入场券。

## 第 0 步：把约束写成能判定的数（不做这步，后面全是返工）

把用户嘴里的要求翻译成一张表，**每一项都要能在一个数上判真伪**。缺项就去问，不要替他假设。

| 约束 | 必须落成的数 | 反例（真事） |
|---|---|---|
| 层数 | 铜层数 = 2 | 「低成本双层板」被画成 4 层 |
| 贴装面 | 元件只在 F.Cu，B.Cu 只有铜（不许放件） | 要求单面贴片，结果两面都有件 |
| 板框 | 外形尺寸 + 定位孔 | 板框与机壳对不上 |
| 最小线宽/间距 | 工艺下限，例如 0.15 / 0.15 mm | 按 0.20 画，打样厂能做但没必要 |
| 电源电流 | 每条电源网的 A 与允许温升 → 线宽/铺铜 | 5 V 进 500 mA 用 0.25 mm 单线 |
| 接口与速率 | USB FS 12 Mbps / QSPI 时钟 Hz / 晶振 MHz | 「有 USB 就行」 |
| 关键器件 | 型号 + 封装 + 引脚定义（不许猜） | F401RGT6 不存在、F401 没有 QUADSPI |
| 装配/维修 | 排针间距、按键可达、测试点位置 | 排针把调试口挡死 |

判定通过的标准：**表里每一行都能被 `board_summary` / `dfm_check` / `board_view` 读出来或算出来**。
读不出来的约束，等于没提。

### 0b. 用户说「好看」时，先翻译成数（这一步以前是缺的）

专业工程师说一块板「好看 / 很难看」，说的从来不是审美，是下面这几件可以数出来的事。
**不要照着参考图临摹像素，要把参考图里成立的不变量抽出来**——照抄形状换一块板就崩，
抽出的不变量换一块板照样成立。

| 用户的话 | 真正在说的是 | 工具能判的数 |
|---|---|---|
| 直角走线像狗屎 | 线段只许 0°/45°/90°，不许随手斜 | `board_geometry_check` → `right_angle_corner_count`、`acute_corner_count`（锐角必须 0） |
| 线挤在一起 | 相邻两条线的中心距是常数 | 同函数 `closest_pair.centre_to_centre`；0.5 间距扇出恒为 0.3536 |
| 走线乱七八糟打结 | 有交叉、有来回 | `board_fanout_order_check` 的 `inversions` 与 `simulated_crossings` 都必须是 0 |
| 元件乱放 / 打架 | 器件外框不重叠、留装配间隙 | `board_footprint_extents` 的 **真实 courtyard**（不是 pads 盒加个余量） |
| 挤 / 空得离谱 | 这块区域还有没有合法落点 | `board_pad_obstacle_map` → `free_fraction`、`probes[].pad_fits` |
| 怎么回事，连规则都不看 | 项目里写了什么限制、我画的贴不贴边 | `board_constraints_report` → `limits`、`hugging`、`contradictions` |

**顺序是固定的**：先 `board_constraints_report` 读限制（不许凭记忆），再 `board_pad_obstacle_map`
问哪块地能用，再 `board_footprint_extents` 摆，摆完 `board_geometry_check` 判线，
扇出前 `board_fanout_order_check` 判「这组配对能不能零交叉」。**一个数不合格就不要往下画。**

## 七步流程（每一步有出口条件，不满足不许进下一步）

### 1. 定层叠与铺铜策略
两层板的标准答案（Sierra Circuits 对两层堆叠的建议）：
- **B.Cu = 完整地平面**（尽量不被信号切碎）；F.Cu = 信号 + 电源。
- 两层都要有地铺铜，**用过孔缝合**把两面连成同一个地。
- 不许把地平面分区（split）；模拟/数字靠**分组摆放**隔离，不靠切地。

出口条件：写死「哪层是地、哪层是信号+电源、缝合孔间距目标值」。

### 2. 摆放（floorplan），按这个顺序，不许跳
1. **机械固定的东西**：连接器、排针、按键、指示灯、安装孔——位置由外壳决定，不由布线决定。
2. **主控**：放在几何中心附近，让各方向引脚到各自目标的距离都不极端。
3. **电源链**：输入 → 保护 → LDO/DCDC → 输出滤波 → 负载，**一条直线摆完**，中间不插别的。
4. **晶振**：紧贴 OSC_IN/OSC_OUT，越短越好；周围留空地给地护墙。
5. **存储器（QSPI 等）**：靠近对应引脚组。
6. **去耦电容**：每个电源脚一颗，紧贴引脚 + 地。
7. **其余慢速器件**：LED、电阻、测试点。

出口条件：**每个功能块之间的通道宽度能算出来**（见第 3 步），且每个器件的「引脚朝向」
明显指向它的对端。摆放阶段就要看得出信号流向，看不出就是没摆完。

### 3. 通道/走廊规划（这一步决定板子能不能布通）
- 数一遍：**每个方向上要跨多少条网**（A→B 方向、C→D 方向分开数）。
- 每条网占一条车道，车道宽 = 线宽 + 2×间距；n 条网需要 `n·w + (n+1)·c`。
- 每个方向至少留 **1 条余量车道**。没有余量的板子，改一个网络就得拆一片。
- **不许出现把板子切成两半的墙**：电源干线、总线、屏蔽墙都可能成为 L 形/环形死墙，
  它一旦闭合，另一侧的网络就只能绕板边。发现墙，先改墙（换层、走边、加缺口），别改线。

出口条件：一张手画的「车道表」——每个方向、每条车道归哪个网、余量几条。

**这一步先用 `board_cut_capacity` 算一遍，别靠数。** 给一条线（点 + 走向）它会报：
这条线切线方向上有几个自由通道、每个多宽、能过几条 `track_mm` 的线，以及**有几个网
必须跨过这条线**（两侧都有焊盘的网）。「必须过的网数 > 所有层通道总数」就是**画不通的
必要条件**，画第一根线之前就能知道，不必等布线器失败。

- 反面教训：我把「12 个网在 B.Cu 上穿过排针行」解释成「通道不够」，实测是 361 条通道
  对 5 个必须过的网，差两个数量级 —— 真堵点在焊盘逃逸宽度（`board_routability` 的
  `width_scan_mm`：LQFP 扇出只能出 0.3）。**别把「撞到焊盘」当成「线上没位置」。**

### 4. 电源与地先布（不是最后补）
- 电源：宽线或铺铜；大电流走铺铜 + 多个过孔并联（单过孔接大电流是错的）。
- **线宽是量出来的，不是猜的**：动手前先 `board_trunk_plan`（`net` 必填）问
  「这一网的焊盘簇之间能走多宽、卡在哪一格」。真板实测 `+3V3`：0.4 mm 主干在
  12/13 条簇间通道上有层能走，但最薄一处 F.Cu 只有 0.164（该改走 B.Cu），
  还有一条 18.19 mm 的走廊双层封死（实况是 509 段信号线 + 30 焊盘 + 15 过孔，
  该动布局）。**「先猜 0.5 被 DRC 打回、再猜 0.3」是拿两次构建换一个本来可以量出的数。**
  读法只有一条要注意：粗栅格会把宽度读窄（最坏 `≈0.7·grid`），`no_path` 与很窄的
  宽度都要降 `grid_mm` 复核；它给的宽度是「能走」，不是「已经走了」。
- 地：B.Cu 整板铺铜 + 缝合孔；F.Cu 的地铺铜在边缘、每个 GND 焊盘附近、每个换层信号旁缝合。
- 铺铜与信号线之间留 **1.5~2 倍线宽**（Sierra）；缝合间距 **λ/20 ~ λ/10**，
  一般数字板实测取 2.5–5 mm，模拟/混合 5–12.7 mm，**不许更稀**。
- 孤岛（没连到主地的碎铜）必须删掉或补缝合孔，否则它是天线。
- 「这一块铜是一块铜吗」用 `board_pour_fragments` 数，不要看渲染图：它按
  `filled_polygon` 报碎块数、每块面积/包围盒、相邻最近距离。未灌铜的 zone 报
  `pour_not_filled`（未知），不是 0 块。

出口条件：两面铺铜都在、都连到同一个地、缝合孔数量与间距可数。

### 5. 关键信号先布，慢速信号最后
顺序：时钟/差分（USB、QSPI CLK）→ 敏感模拟（VREF、ADC 输入）→ 复位 → 其余 GPIO → LED/测试点。
理由：关键信号对长度、参考面、绕行最敏感，一旦被慢速线占掉通道就无解。

### 6. 每布完一组就量一次，不要一口气布完再查
量什么：这组网的 DRC 间距、是否压到别的焊盘、过孔是否落在焊盘里、
连通判定的口径（中心点在不在焊盘多边形内）。**在错的几何上继续加线，只会把错误固化。**

换层之前先用 `board_via_sites` 问「这附近有没有合法孔、余量多少」，不要凭眼睛挑：
给 `x/y + radius_mm` 或 `region`，它会报每个合法点的 `room_mm`（最紧那条约束的余量）
和 `limited_by`（板边 / 哪条走线 / 哪个焊盘 / 钻孔间距）。`net` 要给对 —— 该网自己的
铜不吃余量，孔就长在自己的线上。

- 反面教训：缝合那轮 16 个接地孤岛只有 4 块放得下 0.45 的孔，其中 2 块放进了
  PD13/PD14 的走线，靠重建板子读 DRC 才发现。一个孔一盏茶，重建一次半小时。
- 铺铜**默认不算障碍**（灌铜会绕开新孔重切），但 `inside_pours` 会告诉你这个孔会咬掉
  哪块平面；要严格口径用 `pours_block=true`。

### 7. 验收（DRC 全绿只是第一项）
按这个顺序过：
1. **权威 DRC**（KiCad 自己的引擎）零 violation、零 unconnected。
2. **回流**：每条高速信号下面都有连续参考铜；跨了分割就补缝合孔/缝合电容。
3. **电源**：压降（IR drop）与线宽在允许温升内；地铺铜把每个 GND 焊盘都吃到。
4. **工艺**：最小线宽/间距/环宽/孔到孔 ≥ 打样厂能力（拿能力表去核，不凭印象）。
5. **可修性**：调试口可达、测试点可探、去耦电容可换。
6. **焊盘角上的泪滴先问余量，再决定加不加**：`board_teardrop_room` 只量不画，
   逐角报「以离开焊盘处**焊盘自身弦宽**为底的包络还能长多长」（`room_mm`，负=已经放不下）
   与「最长能到多少」（`max_length_mm`）。本板实测 238 个角里只有 4 个不行
   （最紧 `R19.1 -0.100`），**先看这 4 个再决定要不要全板加**：
   ① `pad_width_mm` 是弦宽，不是焊盘外接尺寸——0.3×1.6 的焊盘 45° 引出读到 0.3，
   按对角线算会读成 1.6，整排排针会被误判 blocked；
   ② `room` 为负读成「放不下这么多」，不是「距离」；
   ③ 引起阻塞的多数是邻居焊盘（本板 193 pad / 32 via / 13 track），不是板边。
   **不要自造一个「应该多长」**：KiCad 的 curve / 长度比是程序设置，编一个所需长度就是猜。
7. **人眼**：把版图渲出来看一遍——大面积空白、长距离无意义绕行、平行的长距离双面走线，
   这三样一出现，说明规划错了。

## 布线之前必读的六条（本篇是硬约束，不是风格建议）

1. **45° 是布线当下就要走出来的，不是布完再倒角。** 实测：231 段曼哈顿走线里 123 个直角，
   只有 81 个能被机械倒角救回（其余顶点在焊盘/过孔上、或切角会撞邻线）。倒角是**验收**工具。
2. **锐角（<90°）一律禁止**——它是蚀刻酸角，是良率缺陷。直角不致命但别画（收益在铜箔应力与一致性，
   不要说成「信号会坏」）。**具体口径与来源见 07 篇第 1 节。**
2b. **「有没有直角」必须拆成三个数报**，合成一个是假结论（工具：`board_angle_audit`）：
   ① **段走向** `other`（不是 H/V/45 的段）——**只有这一项是 45° 规则的违规**；
   ② **顶点角**：135 = 正确倒角、90 = 直角、<90 = 锐角；
   ③ **T 型**（端点落在另一同网段内部）= **分支不是拐弯**，90° T 是电源干线的正常做法，
   45° 分支反而造锐楔。实测：本板 `other` = 0/377（0.0%），参考板 0.4%；
   90° 顶点从 3+13 个降到 1+10 个，剩下的全在过孔/焊盘上或紧邻异网铜（倒角会撞）。
   **见 `references/08` 第 9 节。**
2c. **倒角只留「DRC 0 error」的。** 逐处单独改 + 单独跑 `kicad-cli pcb drc`，通过了才留。
   `d` 从 0.35 试到 0.15（本板 5/7 在 d=0.20 通过）。方向算错（把「回缩」写成「外延」）会
   静默生出 45° 小尾巴，**必须看锐角数有没有变多**——本板反向对照：改对前锐角 1+2 → 3+5，改对后仍 1+2。
3. **`filled_polygon` 是快照。** 任一时刻你新画的线都没有被挖出铺铜，于是 DRC 会报
   「走线→填充区 实际 0.0000 mm」，一次真实 3 条违规的编辑会被报成 169~178 条。
   **判 DRC 前必须重铺**（`board_drc` 的 `refill_zones` 默认开），不重铺的 DRC 不是更严格，是错的。
4. **元件本体可以压线，焊盘不行。** KiCad 不查「走线从元件体下面过」，板厂也不管，
   每块密板都这么做。把外框当障碍，8.5 mm 走廊里扫过 18 条线就会被判成「放不下」，
   于是器件四处乱飞——这是上几版最难看的原因之一。`board_pad_obstacle_map` 的障碍物
   只有焊盘/线/过孔，**故意不算本体**。
5. **不许用「焊盘盒 + 余量」近似 courtyard。** 实测差 0.4~1.9 mm/边，按它摆会真重叠。
   用 `board_footprint_extents` 的 `courtyard`（读文件里的 `F.CrtYd` 图元）。它报 `missing_courtyard`
   时说明该封装没画外框，**那是不确定，不是零**——按丝印盒再自己留余量，并在交付里说明。
6. **铺了两面地不等于有地平面**——两面只有通过过孔才成为一片。布完用
   `board_stitch_vias(action="audit")` 读：`existing_stitch_vias` 与「网格无孔点」都该是 0，
   换层信号过孔旁边的回流地孔也该有。用 `action="place"` 出孔位（只加孔，不动线）。
   孔只能落在**该网 `filled_polygon` 内且每一层都有**的位置——不靠「外框里就算」。
7. **铺铜的「边框」你可以写，「填充」只能交给 EDA 官方。** 两个 EDA 里铺铜都是两个对象：
   边界（谁、哪层、什么网、内缩多少）+ 填充结果（真正的铜、避让、孤岛）。
   - KiCad：边框用 `board_add_zone` 之类写 `zone`，填充用 `board_fill_zones`（内部是官方
     `ZONE_FILLER`）；`filled_polygon` 只是填充结果的快照。
   - 立创 EDA：边框用 `lceda_pour(action="create")`，填充**没有 API 入口**——98 个命名空间逐个试过、
     键鼠注入在本机也无效，唯一有效的是编辑器里 `Shift+B`（重建全部铺铜）。所以 `lceda_pour` 只建/删/读，
     读的时候用 `action="check"` 看路径数与面积。
   - **禁止自己算带状矩形、一条条画 fill 图元来「铺铜」**：实测这样铺出来的板 DRC 报 302 条
     Clearance 违规（焊盘/走线避让全靠手算），比不铺更糟。
   - 新画的线是在填充**之后**加的，`pourFills` 里没有它 ⇒ 同网铜虽不触发 clearance，
     但要让铜皮真正合并、并用于最终 Gerber，**必须再按一次 `Shift+B` 再 `check`**。

## 布完之后必须跑的三件事（2026-11 新增，缺一件就等于没验收）

1. **`board_net_report`** —— 逐网 `detour_ratio = 实铺长 / 焊盘中心 MST`。
   本板实测 +3V3 = 2.81、XTAL_IN = 2.58（参考板同网 1.01）。它只回答「先看哪条」，
   **不是判据**：分母看不见避障，多分支网天然高。ratio ≥ 1.8 的网必须配 `board_render` 看图。
2. **`board_render`** —— 把一层铜栅格成 PNG，人眼/视觉模型直接看。
   之前所有「这走线逆天」的争论都是靠文字描述的，这就是那块缺失的能力。
   **不许只看数不看图**，也不许只看图不看数。
3. **`board_pour_audit`** —— 逐 zone 逐填充岛：面积、本网焊盘数、**本网过孔数**、死铜判定。
   死铜 = 既无本网焊盘也无本网过孔。**只数焊盘会造假缺陷**：本板 GND B.Cu 14 个岛里
   12 个没有焊盘、却有 1~70 个缝合孔，按焊盘口算会误报 10 个死铜，真死铜是 0。

### 两条新增硬约束

8. **删「高 ratio 的绕行回路」之前，必须先证它可删。** 本板 +3V3 有一条沿板顶边横穿 38 mm
   的回路，ratio 2.81，看着最像「逆天走线」。删掉后 **+3V3 直接断成 2 个连通分量**
   （DRC unconnected 2→3），0.25 mm 栅格 A*（F 单层 / B 单层 / 双层允许 ≤2 孔）三种配置
   对两段缺口全部 `no_path`。它是布局没留通道的必然产物。
   **顺序**：删之前跑连通分量检查（union-find 含 T 接）→ 再跑 A* 找替代 → 都过了才许删；
   否则正确表述是「根因在布局，改线改不动」。
9. **2 层板默认不铺电源铜。** 本板实测：+3V3 在 B.Cu 整板铺拿到 1109.9 mm²，
   代价是地平面碎成 **181 个岛（1197→592 mm²）**，并新增 4 条 `starved_thermal`、
   3 条 unconnected、11 个悬空孔；铺在 F.Cu 则 +3V3 自己碎成 11 岛、地碎成 114 岛。
   同尺寸参考板 4 个铺铜全是 GND/AGND，**零电源铜**，电源靠 0.50/0.60 主干。
   正解 = 双面地铜 + 加粗主干 + 缝合孔（本板 GND F 1732.6 / GND B 1635.2 mm²，857 个缝合孔）。
   要铺电源铜的前置是「先证明有一块真空闲区且该网焊盘集中在里面」，铺完 `board_pour_audit` 验收。
10. **电源铜要铺成「形状」，不是往板上丢矩形块；更不能把地平面铺碎。**
   参考板（立创梁山派·天空星，39.8×64.6 双层）的 4 个 `POUR` 解出来是
   `GND/顶层(USB 区)`、`AGND/底层`、`GND/顶层`、`GND/底层` —— **一条电源铺铜都没有**；
   走线 81% 在顶层（1463/337），底层就是地平面，电源靠 0.30/0.50/0.60 mm 三种线宽，
   GND 过孔 573 个（占 83%）、其中 235 个是按 ~1 mm 网格铺的 SUTURE 孔。
   ⇒ **双层板的「好电源铺铜」= 两面地平面 + 宽电源线 + 只在真需要处留电源铜**，
   而且那块电源铜的轮廓必须**跟着它要供的铜走**：

   - **轮廓是画出来的折带/阶梯多边形，不是矩形。** 转角 45°（凸角与凹角都切），
     窄齿端 45° 收口，宽度沿电流路径变化；一条电源轨就是一条沿轨敷设的铜带 +
     在真正有焊盘要接的地方伸出的短齿。
   - **不要把矩形块压在焊盘列上。** 本板第一版把 +3V3 铺成 `(2.9,-58.6)-(6.7,-11.0)`
     的竖矩形，整条 J2A 排针列（x=3.0，不同网络）都落进这块铜里，KiCad 的
     `starved_thermal` 立刻报 `J2A.1(GND) 花焊盘只有 1 根辐条`。改成 x 4.30..6.40
     的铜带、只在下口伸一只 `(2.55,-12.45)-(4.90,-10.65)` 的短齿去接 `J2A.19`，
     error 归零，且 GND B.Cu 岛数从 30 降回 16。
   - **矩形块会切碎地平面，多边形不会（同样面积下更少）。** 实测三版：
     `v66`（整面电源矩形）GND B **123 岛**、`v84`（矩形块）**30 岛**、
     `v87`（折带多边形）**16 岛** = 与不铺电源时完全一致。
     所以判据必须同时是 **GND 岛数 + 死铜 + DRC error**，只报「电源面积变大」是假绿。
   - 本板定稿 `v87_shaped`：+3V3 B.Cu **176.6 mm²/2 岛**（沿 x≈5.0 供电轨的折带 +
     R3/R1-C6/C9-R6-C3/R2/C2/U2 六处短齿；被 PC1/PC2/XTAL 三条线切断成两段是真实
     拓扑，两段都有焊盘，`pour_geometry_clean` 判不是死铜）、VBUS B.Cu **52.7 mm²/2 岛**
     （阶梯带：左端窄口接 U2.3，主体接 U4.5 与 J1 四只 A/B 脚，右臂收窄到 J2B.19）、
     GND F 1726.6/4 岛、GND B 1464.0/**16 岛**、死铜 0、DRC **0 error / 44 warning / unconn 2**。
   - **能力口径**：`+3V3` 铜里 199.7 mm² 是走线本身（10 段 1.5 mm、20+ 段 ≥1.0 mm），
     所以电源能力不靠铺铜补，铺铜只是把已在走的那条路加宽。
   - **工具口径**：轮廓由人画，铜由官方引擎浇。`board_add_zone` 只做三件事——
     校验（网络必须真存在、≥3 点、不重复点、面积>0）、写轮廓、调 KiCad `ZONE_FILLER`
     并回 KiCad 自己的 DRC 判词；它不圆角、不简化、不"优化"你给的形状，
     因为没人画过的形状没人能评审。改旧 zone 的轮廓则是原地重写它的 `(polygon)` 节点
     （`Outline().RemoveAllContours(); o.NewOutline(); o.Append(x,y)...`），
     **`board.Remove(zone)` 会段错误，禁止用删除+重建来改形状**。
   手法细节见 `references/08` 第 8c 节。
11. **KiCad 10 的 python API：`PCB_VIA.GetWidth()` 必须传层。**
   `via.GetWidth()` 会触发 `pcb_track.cpp(387)` 的 `wxAssert`（弹「wxWidgets Debug Alert，
   是否停止程序」），看上去像板文件坏了，**其实文件没事**——点「否/取消」继续即可，
   随后把脚本改成 `GetWidth(pcbnew.F_Cu)`。`PCB_TRACK.GetWidth()` 无此问题，
   只在外层已经过滤 `isinstance(t, PCB_VIA)` 的脚本里才安全。

## 扇出算术（LQFP 0.5 mm 间距必用）

相邻两个焊盘之间能过几条线，只取决于三个数：

```
焊盘边到边间隙 g = pitch − pad_width
能容纳 n 条线  ⇔  g ≥ n·w + (n+1)·c        (w=线宽, c=线到铜间距)
```

实例（pitch 0.5 / pad 0.3 / w 0.15 / c 0.15）：`g = 0.2`；n=0 需 0.15、n=1 需 0.45
⇒ **一条都过不去**。所以 0.5 mm 间距的 LQFP 只能**沿焊盘法向直出**，
同列相邻焊盘之间不许平行走线；要换层就在焊盘外侧放盘（过孔**不能压在焊盘里**）。

### 能不能零交叉，完全由**两端网络的排列顺序**决定（与怎么画无关）

两条相邻 45° 平行线的垂距恒为 `d/√2`。间距 0.5 ⇒ 中心距 **0.3536**，线宽 0.15 ⇒
边距 0.2036，刚好越过 0.2 间距（余量 3.6 µm，是精确算术不是估的）。所以：

- **配对里出现一个倒序（inversion），就一定有一个交叉**，换什么画法都一样；
- **倒序数为 0 时零交叉一定存在**——按「法向外伸 d → 一段 45° → 水平进焊盘」直接画完。

上板前先跑 `board_fanout_order_check`：`verdict=zero_crossing_exists` 才能开始画；
`crossing_forced` 说明该改的是**排针的网络顺序**或**器件的朝向**，不是布线。
（实测：排针右列第 7~16 位原本反单调，翻转 10 个焊盘后逆序 45→0。）
LQFP 的焊盘是**一圈**，用 `side_a=left|right|top|bottom` 只取一条边；
GND/+3V3/VBUS 用 `mapping` 排除掉（它们走另一层）。

## 什么时候该重画，而不是继续修

出现下面任一条，**停下来重摆**，不要在错的骨架上继续接线：
- 有一个方向上要跨的网数 > 该方向可用车道数（墙已经形成）。
- 关键信号的最短路径被一个可以移动的器件挡住（挪器件比绕线便宜 10 倍）。
- 电源链不是一条直线，或者地平面被切成了碎片。
- 已经出现「为了连通而绕板三圈」的线。

判据：**改摆放的代价 < 改布线的代价 × 3** 时才重摆；否则继续修。代价用「要动的器件数」
与「要拆的线段数」估，不用感觉。

## 参考板实测规律（同尺寸官方板到底打了什么）

`references/08-reference-board-metrics.md` 是一个 40×66 双层官方开发板（立创梁山派）的
逐项实测：1800 条走线 / **686 个过孔其中 573 个是 GND** / **763 个泪滴** / 75% 走线用 0.152 mm /
81% 走顶层 / 角度只有 H·V·45° / 全板只有一种过孔尺寸（0.30 孔 0.51 盘）/
缝合孔按 **1 mm 网格**铺（31 mil、39 mil 两档间距最常见）。

四条可直接落地的规则：

1. **缝合孔按 1 mm 网格铺满**，不是"每个孤岛补一个"。同尺寸板 573 个 GND 孔是常态。
2. **全板只用一种过孔尺寸**；尺寸混用是最容易被一眼看出的业余特征。
3. **泪滴用 KiCad 官方标志位**（`SetTeardropsEnabled(True)`），不要自己画锥形铜。
4. **线宽分级** 0.15 信号 / 0.30 电源支路 / 0.50~0.60 主干；电源全程 0.15 是明显缺陷。
   加宽必须逐条过 DRC，撞了就单条退回，别整批放弃。
