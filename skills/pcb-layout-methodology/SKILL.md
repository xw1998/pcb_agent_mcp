# 手工 PCB 布局布线方法论

## 这条技能是为了修什么

有过多轮教训：一块 F412 两层核心板，被画成 4 层、双面贴片、没有铺铜、用了自动布线，
最后 12 组网络布不通、走廊被自己堵死。事后复盘，**没有一条错误是「布线技巧不够」，
全部是顺序错**：先布线后规划、先连上后想回流。所以本技能的骨架是**顺序**，不是技巧。

三条硬规矩，任何情况下不例外：

1. **不许自动布局、不许自动布线。** 工具优化的是「连上」，不是环路面积、回流路径、
   工艺余量、可维修性。它们会先占掉中间的黄金通道，再用一条绕板三圈的线把网连上——几何全绿，
   板子是废的。
2. **先规划后动手。** 每一层要跑哪些网、跨几个方向、留几条车道，必须在放第一个器件之后、
   布第一根线之前算完。
3. **「连上了」不是验收项。** 验收项是：回流路径连续、电源有铜、缝合够密、间距过工艺、
   关键信号短且直。连通性只是入场券。

## 第 0 步：把约束写成能判定的数（不做这步，后面全是返工）

把用户嘴里的要求翻译成一张表，**每一项都要能在一个数上判真伪**。缺项就去问，不要替他假设。

| 约束 | 必须落成的数 | 反例（真事） |
|---|---|---|
| 层数 | 铜层数 = 2 | 「低成本双层板」被画成 4 层 |
| 贴装面 | 元件只在 F.Cu，B.Cu 只有铜（不许放件） | 要求单面贴片，结果两面都有件 |
| 板框 | 外形尺寸 + 定位孔 | 板框与机壳对不上 |
| 最小线宽/间距 | 工艺下限，例如 0.15 / 0.15 mm | 按 0.20 画，打样厂能做但没必要 |
| 电源电流 | 每条电源网的 A 与允许温升 → 线宽/铺铜 | 5 V 进 500 mA 用 0.25 mm 单线 |
| 接口与速率 | USB FS 12 Mbps / QSPI 时钟 Hz / 晶振 MHz | 「有 USB 就行」 |
| 关键器件 | 型号 + 封装 + 引脚定义（不许猜） | F401RGT6 不存在、F401 没有 QUADSPI |
| 装配/维修 | 排针间距、按键可达、测试点位置 | 排针把调试口挡死 |

判定通过的标准：**表里每一行都能被 `board_summary` / `dfm_check` / `board_view` 读出来或算出来**。
读不出来的约束，等于没提。

## 七步流程（每一步有出口条件，不满足不许进下一步）

### 1. 定层叠与铺铜策略
两层板的标准答案（Sierra Circuits 对两层堆叠的建议）：
- **B.Cu = 完整地平面**（尽量不被信号切碎）；F.Cu = 信号 + 电源。
- 两层都要有地铺铜，**用过孔缝合**把两面连成同一个地。
- 不许把地平面分区（split）；模拟/数字靠**分组摆放**隔离，不靠切地。

出口条件：写死「哪层是地、哪层是信号+电源、缝合孔间距目标值」。

### 2. 摆放（floorplan），按这个顺序，不许跳
1. **机械固定的东西**：连接器、排针、按键、指示灯、安装孔——位置由外壳决定，不由布线决定。
2. **主控**：放在几何中心附近，让各方向引脚到各自目标的距离都不极端。
3. **电源链**：输入 → 保护 → LDO/DCDC → 输出滤波 → 负载，**一条直线摆完**，中间不插别的。
4. **晶振**：紧贴 OSC_IN/OSC_OUT，越短越好；周围留空地给地护墙。
5. **存储器（QSPI 等）**：靠近对应引脚组。
6. **去耦电容**：每个电源脚一颗，紧贴引脚 + 地。
7. **其余慢速器件**：LED、电阻、测试点。

出口条件：**每个功能块之间的通道宽度能算出来**（见第 3 步），且每个器件的「引脚朝向」
明显指向它的对端。摆放阶段就要看得出信号流向，看不出就是没摆完。

### 3. 通道/走廊规划（这一步决定板子能不能布通）
- 数一遍：**每个方向上要跨多少条网**（A→B 方向、C→D 方向分开数）。
- 每条网占一条车道，车道宽 = 线宽 + 2×间距；n 条网需要 `n·w + (n+1)·c`。
- 每个方向至少留 **1 条余量车道**。没有余量的板子，改一个网络就得拆一片。
- **不许出现把板子切成两半的墙**：电源干线、总线、屏蔽墙都可能成为 L 形/环形死墙，
  它一旦闭合，另一侧的网络就只能绕板边。发现墙，先改墙（换层、走边、加缺口），别改线。

出口条件：一张手画的「车道表」——每个方向、每条车道归哪个网、余量几条。

### 4. 电源与地先布（不是最后补）
- 电源：宽线或铺铜；大电流走铺铜 + 多个过孔并联（单过孔接大电流是错的）。
- 地：B.Cu 整板铺铜 + 缝合孔；F.Cu 的地铺铜在边缘、每个 GND 焊盘附近、每个换层信号旁缝合。
- 铺铜与信号线之间留 **1.5~2 倍线宽**（Sierra）；缝合间距 **λ/20 ~ λ/10**，
  一般数字板实测取 2.5–5 mm，模拟/混合 5–12.7 mm，**不许更稀**。
- 孤岛（没连到主地的碎铜）必须删掉或补缝合孔，否则它是天线。

出口条件：两面铺铜都在、都连到同一个地、缝合孔数量与间距可数。

### 5. 关键信号先布，慢速信号最后
顺序：时钟/差分（USB、QSPI CLK）→ 敏感模拟（VREF、ADC 输入）→ 复位 → 其余 GPIO → LED/测试点。
理由：关键信号对长度、参考面、绕行最敏感，一旦被慢速线占掉通道就无解。

### 6. 每布完一组就量一次，不要一口气布完再查
量什么：这组网的 DRC 间距、是否压到别的焊盘、过孔是否落在焊盘里、
连通判定的口径（中心点在不在焊盘多边形内）。**在错的几何上继续加线，只会把错误固化。**

### 7. 验收（DRC 全绿只是第一项）
按这个顺序过：
1. **权威 DRC**（KiCad 自己的引擎）零 violation、零 unconnected。
2. **回流**：每条高速信号下面都有连续参考铜；跨了分割就补缝合孔/缝合电容。
3. **电源**：压降（IR drop）与线宽在允许温升内；地铺铜把每个 GND 焊盘都吃到。
4. **工艺**：最小线宽/间距/环宽/孔到孔 ≥ 打样厂能力（拿能力表去核，不凭印象）。
5. **可修性**：调试口可达、测试点可探、去耦电容可换。
6. **人眼**：把版图渲出来看一遍——大面积空白、长距离无意义绕行、平行的长距离双面走线，
   这三样一出现，说明规划错了。

## 布线之前必读的三条（本篇是硬约束，不是风格建议）

1. **45° 是布线当下就要走出来的，不是布完再倒角。** 实测：231 段曼哈顿走线里 123 个直角，
   只有 81 个能被机械倒角救回（其余顶点在焊盘/过孔上、或切角会撞邻线）。倒角是**验收**工具。
2. **锐角（<90°）一律禁止**——它是蚀刻酸角，是良率缺陷。直角不致命但别画（收益在铜箔应力与一致性，
   不要说成「信号会坏」）。**具体口径与来源见 07 篇第 1 节。**
3. **`filled_polygon` 是快照。** 任一时刻你新画的线都没有被挖出铺铜，于是 DRC 会报
   「走线→填充区 实际 0.0000 mm」，一次真实 3 条违规的编辑会被报成 169~178 条。
   **判 DRC 前必须重铺**（`board_drc` 的 `refill_zones` 默认开），不重铺的 DRC 不是更严格，是错的。

## 扇出算术（LQFP 0.5 mm 间距必用）

相邻两个焊盘之间能过几条线，只取决于三个数：

```
焊盘边到边间隙 g = pitch − pad_width
能容纳 n 条线  ⇔  g ≥ n·w + (n+1)·c        (w=线宽, c=线到铜间距)
```

实例（pitch 0.5 / pad 0.3 / w 0.15 / c 0.15）：`g = 0.2`；n=0 需 0.15、n=1 需 0.45
⇒ **一条都过不去**。所以 0.5 mm 间距的 LQFP 只能**沿焊盘法向直出**，
同列相邻焊盘之间不许平行走线；要换层就在焊盘外侧放盘（过孔**不能压在焊盘里**）。

## 什么时候该重画，而不是继续修

出现下面任一条，**停下来重摆**，不要在错的骨架上继续接线：
- 有一个方向上要跨的网数 > 该方向可用车道数（墙已经形成）。
- 关键信号的最短路径被一个可以移动的器件挡住（挪器件比绕线便宜 10 倍）。
- 电源链不是一条直线，或者地平面被切成了碎片。
- 已经出现「为了连通而绕板三圈」的线。

判据：**改摆放的代价 < 改布线的代价 × 3** 时才重摆；否则继续修。代价用「要动的器件数」
与「要拆的线段数」估，不用感觉。
