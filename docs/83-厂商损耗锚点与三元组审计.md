# 厂商印刷的损耗锚点：两个厂商都不印 Steinmetz 三元组

日期：2026-11-02　工具：`magnetics_core_loss_audit`（**新增，工具数 178 → 179**）
数据：`data/material_loss_anchors.json`（9 个牌号、17 个印刷点、3 个来源）

## 1. 结论先行

`82` 篇之后，诚实清单里挂着这一句：

> No material-level Steinmetz triple (k/alpha/beta) is stored, and the nine ferrite
> materials have no vendor fit here at all: their loss away from a measured point
> still needs exponents from you.

这一篇没有把这句话删掉，而是把它改写成它真正的原因。**实测（2026-11-02）两个厂商
都不印三元组**：

| 来源 | 文件 | 页数 | 损耗是怎么印的 |
| --- | --- | --- | --- |
| Ferroxcube 数据手册 | `FXC_HB2013.pdf`（10,439,076 B） | 1108 | 每个牌号的规格页印 **2–3 个 PV 点**，带 `≤` 或 `≈`；其余全是曲线 |
| Ferroxcube 3C96/3C98 宣传册 | `3C96_3C98_web_MAR_2022.pdf`（784,415 B） | 8 | 同上，裸数字 |
| TDK SIFERRIT **N87** 材料单 | `528882`（June 2025） | 12 | **一个数都不印**，损耗只画三族曲线 |

所以这一篇做的是两件能做的事，而不是一件不能做的事：

1. **把厂商印的点入库** —— 17 个点，每个带印刷页号、原文、以及它印的时候是界限
   还是典型值；
2. **给「你手上那个三元组」做审计** —— 在每一个厂商印过的点上算一遍，报偏差、
   报是否满足印刷上界、报是否落在 10 % 报告带内。

**明确不做的**：从这些点里反解三元组。3C90 同一列里印着两个 `≤` 和一个 `≈`，
解出来的三元组将同时要求「低于两个上界」和「等于那个典型值」——那是算术穿着厂商
的衣服。所以 `solved_here` 恒为 `false`，理由跟着答案走。

## 2. 页号与取数方法（逐页实测）

**Ferroxcube HB2013：printed = pdf**（84/84、88/88、90/90、92/92、96/96 逐页核过）。
`metadata` 里标题仍写着 *Data Handbook 2009*，而每页页脚写 `2013 Jul 31`——
**登记为异常，不改**（写进 `sources[0].anomaly`）。

**Ferroxcube 2022 宣传册：没有恒定偏移**（pdf 4 印 "3"、pdf 6 印 "5"）。两个页号
都记：`pdf_page: 6` / `printed_page: "5"`。

**取数必须双读。** 手册的文本流会把 PV 行和旁边那张图的轴标签（`10`、`1`、`102`）
混成一行，所以每一行都用 `page.get_text("words")` 按 `round(y0/4)` 分行、按列 x
（条件列 / 数值列 / 右侧图轴标签列）重新读一次，两次读到的结果比对。3C90 与 3C96
两行另外与 2022 宣传册交叉核过。

**一个必须带上的判定**：3B7 的规格页上**没有 PV 行**（只有 `tanδ/µi` 和 DF），正则会
把它误读成 `25 / 100 / 0.25 / ≤ / 5` 这样的假点。所以先判 `text.find("PV") < 0`
即返回空，并在数据里记 `points: []` + 原因。N27 同样：页上那个 920 kW/m³ 没有工况，
已在 `magnetic_materials.json` 里记成 `pv_quoted_unconditioned_kw_m3`。

`qualifier` 四分类分开存，因为**它们不是同一种数**：

- `at_most`（2 个）/ `max`（1 个）——**上界**，任何更小的值都满足它；
- `approx`（11 个）/ `plain`（3 个）——**典型值**，两个方向都可比。

3C90 一列里混着两类，这就是「不能拟合」的直接理由，也是审计里
`satisfies_the_printed_bound` 与 `within_10_percent` 必须**分开报**的原因。

单位：`1 kW/m³ == 1 mW/cm³`，所以这些数直接喂 `khz_mt` 约定，不需要换算。

## 4. 三条交叉校验 + 一条位移检查

```
3C96 印了两次（相隔九年）：2013 手册 [40, 300, 250] == 2022 宣传册 [40, 300, 250]
宣传册正文 250 mW/cm³ @ 100 kHz/200 mT == 表里 250 kW/m³ @ 同一工况
   （1 kW/m³ == 1 mW/cm³）
```

第三条是**位移检查**，不是拟合：把每个牌号的印数按固定 f 求比值得到 β、按固定 B
求比值得到 α，看它们落在 MnZn 功率铁氧体公开的范围内没有（列错位的表会立刻炸）：

| 牌号 | β | α |
| --- | --- | --- |
| 3C90 | 2.49 | 1.21 |
| 3C93 | 2.81 | 500 kHz 那一行按规律断开（拟合窗口到此为止，本该断） |

**不存任何指数**：这只是「列没有错位」的证据，不是拟合结果。

## 5. 审计工具怎么判

参数：`magnetics_core_loss_audit(material, k, alpha, beta, units="khz_mt",
temperature_c=None)`。`units` 是核心问题的一部分（同一个 k 换一种约定差约 10⁶）：

```
si         f[Hz]  B[T]   k[W/m^3 per Hz^a T^b]
khz_mt     f[kHz] B[mT]  k[mW/cm^3 per kHz^a mT^b]   ← 厂商风格，默认
khz_gauss  f[kHz] B[G]   k[mW/cm^3 per kHz^a G^b]
khz_t      f[kHz] B[T]   k[mW/cm^3 per kHz^a T^b]
```

逐点输出：`temp_c / f_khz / b_mt / printed_pv_kw_m3 / qualifier / printed_as /
computed_pv_kw_m3 / deviation_pct / within_10_percent /
satisfies_the_printed_bound`。

- 上界点（`at_most` / `max`）：`satisfies_the_printed_bound` 是 true/false；
  算出来低于上界就是**满足**，即使差 39 % —— 但会给一句 note 说明「上界排除不了
  更小的值，所以这一点既没否证也没确认你的三元组」。
- 典型值点：`satisfies_the_printed_bound` 恒为 `null`；跑出 10 % 带外就是 miss。

判词三档：

```
consistent_with_every_printed_point      每个点要么满足上界、要么在 10 % 带内
does_not_match_every_printed_point       没违反上界，但有典型值点跑出带外
violates_a_printed_upper_bound           算出来高于某个印刷上界 —— 这是矛盾，不是容差问题
```

**10 % 是报告层带宽，不是及格线**：原始 `deviation_pct` 一律透出，调用方自己选阈值。

一个实例（k = 5e-7, α = 1.6, β = 2.5，`khz_mt`）：

```
3C90  p.84
  25 kHz / 200 mT   印刷 ≤ 80     算出  48.78   −39.02 %   上界满足   带外
 100 kHz / 100 mT   印刷 ≤ 80     算出  79.24    −0.94 %   上界满足   带内
 100 kHz / 200 mT   印刷 ~ 450    算出 448.28    −0.38 %   典型值     带内
  → consistent_with_every_printed_point（3 点里只有 2 点在带内）

N87   100 kHz / 200 mT 印刷 Max. 375  算出 448.28  +19.54 %  上界违反
  → violates_a_printed_upper_bound
```

同一个三元组在一个牌号上成立、在另一个牌号上自相矛盾 —— 这就是这个工具要说的话，
也是为什么它不取平均、不挑一个牌号代表全体。

## 7. 负控制（这条判据能失败）

四种**篡改过的表副本**（写到 `_scratch/anchor_bad_*.json`，不入库），加载器必须拒绝
而不是照算：

1. `schema` 改成 `v2`；
2. 某个 `pv_kw_m3` 改成负数；
3. `qualifier` 拼成 `at-most`（不在四分类里）；
4. 某个 `source` 指向 `sources` 里没有的 id；
5. 删掉五个牌号的点（17 → 6 个点）触发「截断」检测；
6. 把一个有 3 个点的牌号写进 `materials_without_points`；
7. 删掉某个点的 `printed_as`。

另外还有一条**行为层**负控制：同一个三元组在 3C90 上判 consistent、在 N87 上判
`violates_a_printed_upper_bound` —— 说明判词不是「一律放行」。
