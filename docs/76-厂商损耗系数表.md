# 厂商自己印的那条损耗式子 —— 粉末芯的 `PL = a·Bpk^b·f^c`

日期：2026-11-01　工具：`magnetics_material_core_loss(...)`（新，第 175 个）

`magnetics_core_loss` 一直要求**调用方给出** `k / alpha / beta`。这是刻意的：仓库里没有任何
material-level 的 SI 三元组，因为**厂商不那样出版**。粉末芯（Kool Mµ / MPP / High Flux）印的是

```
PL = a · Bpk^b · f^c        PL 单位 mW/cm3，Bpk 用 TESLA，f 用 kHz
```

而且**同一材料不同磁导率、不同形状各有一行系数**。所以"Kool Mu 的损耗"不是一个数：
任何单值回答都会错一个调用方看不见的量级。

这一篇把厂商印的这 61 行系数入到表里（带印刷页码），并新增一个**按名字查**的工具来算它。
查不到、或问题没问到能唯一确定一行时，工具**报错并列出候选行**，绝不替你挑一个磁导率。

既有 `magnetics_core_loss` / `select_core` / `magnetics_winding_ac` 的行为**一位不变**
（自检 `1876` 号显式对照 SI 三元组仍是 `130000 W/m³`）。

---

## 1 判据

| # | 要守住的事 | 能被什么违反 |
|---|---|---|
| 1 | 系数必须来自**厂商一手 PDF**，转录带**印刷页码**，可逐行回查 | 从 CSDN/博客里抄一个「MnZn k=3.5e-6 α=1.7 β=2.7」|
| 2 | 读数必须被厂商**自己的算例**钉住（11.0 / 168 / 466 mW/cm³）| 只看公式对不对、不看数对不对 |
| 3 | 必须钉死**哪个指数是频率**：`c` 是频率、`b` 是磁通 | 两个指数写反 —— 数依然"像样"，只是错了 |
| 4 | `Bpk` 必须是**半摆幅**（振幅），与其他 Steinmetz 入口同口径 | 把峰峰值喂进去 ⇒ 差 `2^b ≈ 4 倍` |
| 5 | 单位换算必须是**算术**（`k_SI = a·10^(3−3c)`），不是手算常数 | 手算错一位，或误用 mT 约定（差 `1000^b ≈ 1e6`）|
| 6 | 问题**欠定就拒绝**，并交出候选行 | 随便挑一行（两个磁导率两页之隔，差可能超过答案本身的精度）|
| 7 | 频率分裂的边界**不插值、不猜**：恰好 100 kHz 判无解 | 用 `<100` 或 `>100` 任一侧回答边界点 |
| 8 | 拟合的**有效域**要说出来（5 kHz–2 MHz、≤0.5 T），超界只警告但标明是外推 | 把曲线拟合说成保证值，或超出域外静默给数 |
| 9 | 旧工具的答案一位不动 | 顺手把 `steinmetz` 槽位改写成厂商拟合 |

第 2、3、4 条互相咬合：任一条写错，三个算例里至少一个会偏出去，而偏的方向各不相同 ——
这正是把它们三个一起做锚的原因。

## 2 厂商方程与口径（原文）

来源：Magnetics 官方粉末芯目录（210 页 PDF）
`https://www.mag-inc.com/Media/Magnetics/File-Library/Product%20Literature/Powder%20Core%20Literature/Magnetics-Powder-Core-Catalog.pdf`
本机副本 `_scratch/mag_powder_catalog.pdf`（12,415,449 字节，与 `Content-Length` 一致）。

**PDF 第 25 页（印刷第 23 页）原文**：

```
PL = a * Bpk^b * f^c
Units typically used are (mW/cm3) for PL; Tesla (T) for Bpk; and (kHz) for f.
Bpk = (B_acmax - B_acmin)/2
```

三件事同时被这段定死：**PL 是体积功率密度**、**B 是特斯拉**、**Bpk 是半摆幅**。
第三条和本仓库其他入口的 `b_peak_t`（"the AC flux amplitude, i.e. half the
peak-to-peak swing"）是同一个量，所以两个工具可以直接对比。

系数表分别在印刷 **p.109**（环 toroids，PDF 111）、**p.110**（E/U/EER 与 EQ/LP，PDF 112）、
**p.111**（Blocks / Round Blocks / Cylinders，PDF 113）三页。

## 3 三个算例：把读数钉死

印刷第 23 页紧挨着公式给了三个已算好的点：Kool Mµ 60µ 环，100 kHz，`a=44.30, b=1.988, c=1.541`。

| Bpk | 目录印刷 PL | 本实现 | 相对差 |
|---|---|---|---|
| 0.014 T | 11.0 mW/cm³ | 11.0384 | +0.35 % |
| 0.055 T | 168 mW/cm³ | 167.589 | −0.24 % |
| 0.092 T | 466 mW/cm³ | 466.030 | +0.01 % |

三个点误差都在目录 **3 位有效数字的舍入**以内，且**方向不一致**（一大一小一大）——
如果是指数写反或单位错了，三个点会朝同一个方向偏出几十个百分点。
`tests/test_material_loss_fit.py` 把这三行做成第一个测试（±0.5 %）。

## 4 陷阱：`c` 才是频率

按写法直觉，`a·B^b·f^c` 里 `b` 像是频率（`b` 在 `f` 前面的写法里常见）、`c` 像是磁通。
**反了**。厂商目录里 `b` 是磁通指数、`c` 是频率指数，转成 Steinmetz 三元组是

```
(k, alpha, beta) = (a 换算成 SI, c, b)
```

自证（测试里独立量一次，不看代码）：

- 频率 ×10 ⟹ 损耗 × `10^1.541 = 34.7`（若写反会是 `10^1.988 = 97.3`，差 **2.8 倍**）
- 磁通 ×2 ⟹ 损耗 × `2^1.988 = 3.97`（若写反会是 `2^1.541 = 2.91`，差 36 %）

两条同时成立，才有可能是什么都对了。

## 6 欠定就拒绝：六条拒绝臂 + 一条边界

工具的问法是"哪一行"，所以每一层过滤都是一次问：

| 情形 | 结果 |
|---|---|
| 材料根本没有厂商拟合（N87 / 3C90 / 3C96 …）| `FIT_NOT_RESOLVED`，说明该材料只能走 `magnetics_core_loss` 自己给三元组 |
| 材料名不在表里 | `NOT_FOUND`，hint 列出**有拟合**的三个材料 |
| 没点名磁导率 | `FIT_NOT_RESOLVED` + `rows_available` 全表（Kool Mu 环就是 12 行）|
| 形状该线没印 | `FIT_NOT_RESOLVED`，说明"prints no EQ/LP fit"并列出它印了哪些形状 |
| 形状名不是四种之一 | `FIT_NOT_RESOLVED`，列出合法形状 |
| 磁导率不在该行覆盖 | `FIT_NOT_RESOLVED`，列出该形状/变体实际覆盖的磁导率 |
| 变体该线没有 | `FIT_NOT_RESOLVED`，列出该材料印了哪些变体 |
| **恰好 100 kHz 的 Ultra 行** | `FIT_NOT_RESOLVED`，说明两侧都不声明边界、请用一侧内部的频率 |

最后一条值得单说：Kool Mµ Ultra 的环在 100 kHz **分裂成两行**（`<100 kHz` 与 `>100 kHz`），
系数相差 6~7 倍（`79.79` vs `11.83`）。`>=`/`<=` 任一写法都会**静默**把边界归给一侧，
而边界恰好是最常见的工作点（100 kHz 是开关电源的默认频率）。所以这里选的是**报错**，
并告诉调用方"用一个在一侧内部的频率表达你的意思"。`99 kHz` 与 `101 kHz` 都正常解析。

## 7 单位换算：`khz_t` 这一行是怎么来的

`core_loss_steinmetz` 原来有三个单位约定（`si` / `cgs` / `khz_mt`）。厂商用
**mW/cm³ + T + kHz**，其中**特斯拉**是新的：已有的 `khz_mt` 是毫特斯拉，差 `1000^b ≈ 1e6`。
所以新增第四个约定 `khz_t`，并在代码里**算**出等价 SI 系数，而不是手写一个常数：

```
P[mW/cm3] = a · B[T]^b · f[kHz]^c
  换算成 P[W/m3] = k_SI · B[T]^alpha · f[Hz]^beta
  ⟹ 1 mW/cm3 = 1e3 W/m3，f[kHz]^c = (f[Hz]/1e3)^c = f[Hz]^c · 1e-3c
  ⟹ k_SI = a · 1e3 · 1e(-3c) = a · 10^(3 − 3c)
  ⟹ alpha = c，beta = b
```

对 `a=44.30, c=1.541`：`k_SI = 44.30 · 10^(3 − 4.623) = 1.0553675249259014`。
测试里两条路径互相验证（`khz_t` 直接算 与 `si` 用换算后的三元组算），并断言两者**逐位相同**
（`11038.403394 W/m³`）。

## 8 适用范围：曲线拟合，不是保证

- 拟合是从目录 **p.99–108 的损耗曲线**上做出来的。读那些图的坐标轴得到
  **5 kHz … 2 MHz**、纵轴到 **0.5 T**。
- 出界**只警告不拒绝**：低频大摆幅是真实工况，拒绝等于不回答。警告文本明确写
  "outside the 5-2000 kHz span … so it is extrapolation"。
- `>0.5 T` 的警告还多说一句：粉末芯在那个点也**接近自己的饱和**，而这条拟合**没有饱和项**。
- 每次调用都往 `not_modelled` 追加一条"拟合自身有效域"，防止调用方把 `ok` 读成"保证"。
- 表里还写死了 `fit_is_a_curve_fit_not_a_limit`（原文摘录厂商自己的措辞），
  `value` 里每次都会带出来。

## 9 这一轮**没做**的（说清楚，不假装）

| 缺口 | 为什么现在不做 |
|---|---|
| **XFlux / Edge** 两个粉末材料 | 系数在同一 PDF 里齐全（环 / E-U-EER / EQ-LP / 块 五组），但材料本身（Bsat / Tc / 密度）不在表里 ⇒ 只入系数会出现"能算损耗、查不到材料"的半个材料。0.0.75 候选：材料与系数一起入 |
| **九个铁氧体没有厂商拟合** | TDK/Ferroxcube 出版的是 material-level 三元组（且带温度/频率条件），与粉末芯的 per-permeability 拟合不是同一种对象。**不许凭记忆填**，故留作拒绝臂 |
| **material-level SI 三元组仍然是 `null`** | 这是刻意的：该槽位语义是 material-level SI 三元组，粉末厂商不那样出版。`steinmetz_note` 已改写说明"null 是刻意的"并指向 `loss_fit` |
| **`select_core` 还是选不了磁环** | 表里 16 个核全是铁氧体（RM/EE/ETD 之类）。粉末芯的几何（OD/ID/HT、Ae/le/Ve、AL）尚未录入 ⇒ 有了损耗系数却还不能选型。0.0.75 候选，且这是当前**最大**的磁材缺口 |
| 温度 / 直流偏置对系数的影响 | 拟合本身不含这两项，`not_modelled` 每次都写 |
