# 47 · 把铜算进板子温度场：铺铜/平面作为面内散热通道

0.0.43 之前 `board_electrothermal` 的精度说明里有一句实话：**散热介质是调用者给的
层压板 k，不是真实的铺铜与平面**。这句话的代价很具体——一块在发热走线下面铺了地的
板子，会读到比实际更高的温度，而"读到更高"恰好是最容易被当成"保守所以安全"的那种错。

这一版把铜补进去。补法是**面内片电导**（sheet conductance），不是 3-D、不是各向异性
张量，也不是去解固体导热。

## 47.1 为什么是「片电导」

这个 2-D 求解器解的是

```
k*t*lap(T) - 2*h*(T - Tamb) + q(T) = 0
```

其中 `k*t` 是**面内片电导**（W/K），`2*h` 是上下两个面对空气的对流。也就是说，这个
模型里的铜只有一条途径能起作用：**把热量在面内铺开，再让它从两个表面散掉**。

所以正确的混入方式就是把铜并到面内片电导上：

```
S[i][j] = k_lam*t_board + Σ_pours( frac[i][j] * t_cu * N ) * k_cu
```

- `frac[i][j]` 是这块矩形与这个网格单元的**精确面积重叠比例**；
- `t_cu`、`N` 是每层铜厚与层数，`k_cu` 默认 400 W/(m·K)（可改，是参数不是常数）；
- 单位对得上：W/(m·K) × m = W/K，与 `k*t` 同量纲。

**竖着的那条路没有被加厚**，因为它本来就在 `h` 里——两块表面各自对空气散热。这一点
写进了每次答案的 `copper_spreading.assumption`，因为它是这个近似的边界所在：铜不会
让热量更容易离开板子，只让它先铺开再离开。

## 47.2 面积重叠必须是精确的

一处一眼看不出的坑：如果按"单元中心落在矩形内"来标记，**铺铜边正好落在单元中间**时，
答案取决于网格从哪里起算。2 mm 网格下把矩形边缘放在 x = 1 mm，它要么整格算铜、要么
整格算没有，两种都不对。

所以 `_rect_cover` 算的是精确重叠：

```
ox = min(xhi, (i+1)*cw) - max(xlo, i*cw)     # 长度重叠
frac = (ox/cw) * (oy/ch)                     # 面积重叠比例
```

实测（100×80 板，2 mm 网格，35 µm 铜）：x ∈ [0, 1] 这半格的 `k_eff` 最大值为
**4.675 = 0.3 + 0.5×8.75**，逐位等于手算；板面积平均 **0.3875**，也等于
`(0.3×1999 + 4.675×40)/2000`。这不是"差不多"，是算术。

## 47.3 面上用调和平均，不是算术平均

两个相邻单元之间那道面，导热要串过两个半格。材料不连续时标准答案是**调和平均**：

```
G_face = 2*S_a*S_b/(S_a + S_b) * (面宽/格距)
```

S 均匀时它退化成 `S*dy/dx`，也就是原来那套均匀 k 的算子——这就是为什么"整板满铺"
必须等于"把等效 k 直接当参数传进去"。实测两者 `t_max` 在 6 位小数上完全一致：

| 算法 | t_max |
|---|---|
| 整板 35 µm 铺铜（`k_eff = 9.05`） | 27.395644 ℃ |
| 同一次求解，直接传 `k_w_mk = 9.05` | 27.395644 ℃ |

这条等价关系同时是一个**能在测试里失败的对照**：调和平均若写成算术平均，两者就不再
相等（算术平均在 S 跳变处会把面电导抬得比真实高）。

## 47.4 铜要在"热的地方"，这才是负控制

只证明"加了铜以后峰值下降"是不成立的——任何一个往对角线上加数的改动都会让温度下降。
真正的判据是**同一块铜，换个位置就不该起作用**。

实测（100×80×1.6，k=0.3，h=10，走线 y=40、3 mm 宽、35 µm、4 A、2 mm 网格）：

| 铜在哪 | t_max | 相对裸板 |
|---|---|---|
| 没有铜 | 36.082953 ℃ | — |
| 整板满铺 35 µm | 27.395644 ℃ | −8.687 K（−24.1%） |
| 100×10 条带压在走线上（y 35..45） | 29.357 ℃ | −6.726 K |
| **同一块 100×10 条带，挪到 y 0..10** | 36.080894 ℃ | **−0.002 K** |

后两行的面积与铜厚完全相同，唯一区别是位置。第三行降 6.7 K，第四行降 0.002 K——这就是
"铜只有在热的地方才帮忙"的可测版本，也是这一版唯一值得信的物理判据。

`tests/test_electrothermal_pours.py` 里 `test_the_same_strip_far_from_the_trace_barely_moves_the_peak`
钉的就是这一条（阈值 0.1 K），`test_the_two_strips_are_the_same_board_area` 保证两行的
`area_fraction_of_board` 相等，否则这个对照是假的。

## 47.5 三条零变化的保证

1. **不给 `copper_pours` 时逐位不变**：`copper_pours` 为 `None` 走原来那条
   `_sor_plate`，`_sor_plate_map` 是独立函数，不在内循环里做 `isinstance` 判断。
   既有 75 例电热/腔体测试全部原样通过。
2. **0 µm 铜 = 没加铜**：`t_max/t_min/t_avg/delta_t_max_k` 逐位相同，且
   `copper_spreading.modelled` 仍为 true、`k_eff` 三个读数都等于 `k_lam`。
3. **`not_computed` 换句而不是删句**：有铺铜时第一条从"只沿你给的层压板 k 扩散"换成
   "铜被涂抹成每格一个面内片电导"，两条都是限制，没有一条被悄悄删掉。

## 47.6 拒绝的那几种

| 输入 | 返回 | 为什么不能近似 |
|---|---|---|
| 矩形跑出板子 | `ARG_RANGE` | 裁掉就是替用户改设计 |
| `thickness_um < 0` | `ARG_RANGE` | 负厚度没有物理含义（0 是允许的：必须零变化） |
| 缺 `thickness_um` 等 | `ARG_INVALID`（点名缺哪个键） | 猜一个 35 µm 正是本模块一直在拒绝的事 |
| 面积为 0 | `ARG_RANGE` | 一条线不是铺铜 |
| `k_copper_w_mk <= 0` | `ARG_RANGE` | — |
| `copper_pours` 不是列表 / 元素不是对象 | `ARG_INVALID` | — |
| `layers = 0` | `ARG_RANGE` | — |

## 47.7 还不知道的（每次都写在答案里）

- 单元内部的铜形状、铜与层压板的界面热阻、**热过孔**；
- **你没有列进来的铜**（这一版不会自己去开 `.kicad_pcb` 读 zone）；
- 涂抹是面内的，竖向路径仍在 `h` 里；
- 3-D、辐射、元件热质量与接触热阻、AC 损耗（趋肤/邻近）——与 0.0.42 相同。

一句话：这一版让"平面在发热点下面"这件事第一次能算进来，并且用"同面积换位置就失效"
把它钉住了；它仍然不是 3-D 热仿真。
