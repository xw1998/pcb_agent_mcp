# 粉末芯的第二、第三种材料 —— XFlux / Edge，以及两条 High DC Bias 各自的独立印行

日期：2026-11-01　工具：`magnetics_material_core_loss(...)`（**不新增工具**，仍是第 175 个）

`76` 篇收尾时把话说死了：「XFlux / Edge 系数同 PDF 齐全但材料本身未入表」。
这一篇把那句话兑现：**两种材料的 32 行系数、材料常数、密度基准全部入表**，
并把上一轮**漏掉的一半**补上 —— XFlux 与 Edge 各有两条 **High DC Bias** 产品线，
它们的系数不是 base 行的插值，而是**印在另外两页**上的独立拟合。

这一点不是排版细节。如果只存 base 行，调用方问「High DC Bias XFlux 60µ 在 100 kHz、0.1 T 的损耗」
会得到一个**看着像答案的错答案**：实测 base 给 `1315.52 mW/cm³`，
High DC Bias 的真值是 `1512.30 mW/cm³`（**高 15.0 %**），Edge 那一条差得更多（`373.79` 对 `500.25`，**高 33.8 %**）。

既有行为一位不变：工具数仍是 **175**，`loss_fit` 从 61 行扩到 **93 行**、材料从 12 个扩到 **14 个**，
`magnetics_core_loss` / `select_core` / `magnetics_winding_fringing` 的所有读数逐位不变
（自检 `1876` 号仍在对照 SI 三元组 = `130000 W/m³`）。

**两个不同页面对同一条曲线的两次陈述**。用前者算出来的数去对后者，错了就一定是转录错，
而不是"公式没对上" —— 因为公式本身在 `76` 篇里已经被三个算例钉死了。

### 2.3 High DC Bias 的两个页面（印刷 p.12 / PDF 14、印刷 p.14 / PDF 16）

上一轮只读了 p.109–111 的三张形状表，**整页漏掉了这两页**。它们各自印一组 `Perm a b c`：

- **High DC Bias XFlux**（印刷 p.12）：26µ `443.53 / 2.015 / 1.312`；40µ `442.15 / 2.015 / 1.283`；60µ `447.34 / 2.015 / 1.272`
- **High DC Bias Edge**（印刷 p.14）：26µ `83.23 / 2.106 / 1.520`；60µ `82.64 / 2.106 / 1.444`

和 base 行比：`b` 一样（XFlux 2.015、Edge 2.263 对 2.106 变了），`a` 与 `c` 都不一样 ——
**这是另一条曲线，不是同一个曲线换个常数**。所以它只能作为 `variant = "High DC Bias"` 的独立行存在。

这两页上还有 DC 磁化曲线拟合 `B = x(a + bH + cH²)/(1 + dH + eH²)` 的 a,b,c,d,e,x
（XFlux 26/40/60µ、Edge 26/60µ 各一组）。**本轮不入库**，理由见 §8。

## 3 交叉核对：厂商自己印的第二个数字

条件统一：60µ 环、`Bpk = 0.1 T`（= 1000 G 的**半摆幅**）、磁导率 60。

| 材料 | 频率 | 拟合算出 | p.10 印刷 | 比值 |
|---|---|---|---|---|
| XFlux | 50 kHz | **574.999** | **575** | **1.0000** |
| Edge | 50 kHz | 149.611 | 150 | 0.9974 |
| XFlux Ultra | 50 kHz | 424.341 | 450 | 0.9430 |
| XFlux | 100 kHz | 1315.518 | 1280 | 1.0277 |
| Edge | 100 kHz | 373.788 | 375 | 0.9968 |
| XFlux Ultra | 100 kHz | 999.512 | 1035 | 0.9657 |

读法：

1. **XFlux 的 575.00 对 575 不是运气，是三个数同时对了才可能出现的巧合** ——
   `a` 错一点、`b` 错一点、或者把 1000 G 当成峰峰值，`574.999` 都不会出现。
   它一次性证明了：转录对、`c` 是频率指数、`Bpk` 是半摆幅。
2. **100 kHz 那一列 XFlux 高 2.8 %** —— 汇总表印三位有效数字，且厂商那两列本身是分档读的。
   这是**厂商两张表之间的舍入差**，不是我们的错，如实记录（`docs`/测试都写明）。
3. **XFlux Ultra 差 5.70 % / 3.41 %** —— 这条**没有**得到解释。
   Ultra 的 26µ/60µ 行用的是另一套拟合（`c = 1.236`，base 是 `1.194`），两行都偏低；
   能确定的只有方向（Ultra 损耗本来就更低，450 对 575）与量级，差的那 5.7 % 没有第二份印刷值可对。
   测试里给它 `0.06` 的门槛并**显式写明这不是容差而是这个差距本身**，没有把它揉成"通过了"。
4. **半摆幅的负控制**：把 1000 G 当峰峰值（`Bpk = 0.05 T`）时 XFlux 给 `142.26 mW/cm³`，
   是印刷值的 **0.247 倍** —— 差约 4 倍，不可能被读成"差不多"。
   这条负控制是 `test_reading_1000_gauss_as_peak_to_peak_is_refused_by_the_numbers`。

## 4 一个看起来像笔误、复核后不是的数字

Edge 的 toroid 行在 p.109 上是：

```
75µ        121.47 / 2.263 / 1.403
90µ,125µ   481.77 / 2.263 / 1.139
```

`a` 从 `121.47` 跳到 `481.77`（**3.97 倍**），`c` 从 `1.403` 掉到 `1.139`——
在一张别的行都只变几十的列里，这很像是把 `481.77` 抽成了别人的数。

复核做法：**把 PDF 第 109 页渲染成图，按图像读一遍，再按文本层读一遍**，两边都是 `481.77`。
所以：

- 值**原样保留**（`a = 481.77`、`c = 1.139`）；
- 测试 `TheEdgeRowThatLooksLikeATypo` 断言它就是 `481.77` 且比 75µ 的 `a` 大 3.5 倍以上 ——
  这条测试存在的意义是**挡住下一个人"顺手修正"它**；
- 文档这里写明"复核过、不是笔画误、厂商原样如此"，理由写在注释里。

顺带一条：High DC Bias Edge（p.14）的 `a` 只有 `83.23 / 82.64`，
和 base 的 `207.90 / 156.18` 反向（更低），说明 High DC Bias 是**另一条工艺线**而不是 base 的偏移量。

## 6 密度：一个基准 + 一组因子，不是十四个数

`material_core_loss` 不碰密度；密度是给质量/热容估算用的。厂商的写法是
「**60µ 的密度** + 其他磁导率的近似因子」，所以表里也只这样存：

- 材料级 `density_kg_m3` = **60µ 基准值**（XFlux 6900、Edge 7800、Kool Mµ 5800、MPP 7800、High Flux 7600）
- 顶层 `density_vs_permeability_60u.factors` = §2.1 那 11 个因子
- `permeabilities_without_a_printed_factor = [200, 300, 550]` + `note_on_the_gap`
  说明这三个厂商只给磁导率、不给因子，**我们不算**
- `is_approximate: true`：这些因子本身就是"approximate"

为什么不把 14 个磁导率都写一遍？因为那等于**替厂商做的乘法**，而且其中三个厂商明确没给输入。
一个商业软件在这里要的是"能不能引用"，不是"看起来齐"。

**XFlux Ultra 的密度是 7.1 而不是 6.9**（p.16 单印一行），`density_note` 里写明了：
不要把 XFlux 的密度套到 Ultra 件上。

## 7 一处显式修正：MPP 密度 8700 → 7800

表里原来 MPP 的 `density_kg_m3 = 8700`，字段自己的注释就承认是「secondary transcription …
the weakest number in this file」。而一手目录 p.16 印的是 **7.8 g/cm³**。

第一反应是怀疑抽取错位 —— **因为同一张表里 Edge 也印 7.8**。所以把 p.16 渲染成图逐行读：
MPP 7.8、Edge 7.8、High Flux 7.6，**两行真的是同一个数**，不是错位。

于是按"修正 + 登记"而不是"悄悄换掉"：

- `density_kg_m3 = 7800`（压制后含粘结剂的**芯体**密度，估质量用的就是它）
- `density_alloy_kg_m3 = 8700`（**合金**密度，另一个物理量，旧值改名保留）
- `density_note` 以 **`CHANGED in 0.0.75, and not silently`** 开头，写明两个量不同、
  写明"同表 Edge 也印 7.8，看起来像抽取错但不是"
- 测试 `test_the_mpp_density_correction_is_registered_not_smuggled` 断言这三件事都在

这是本篇唯一一处**改变既有答案**的地方，所以它出现的三个位置（JSON 注释、本篇、CHANGELOG）
都要留痕。

## 8 这一轮**没做**的（说清楚，不假装）

| 没做 | 为什么现在不做 |
|---|---|
| **粉末芯几何入 `cores`** | 磁环的 OD/ID/HT、Ae/le/Ve/AL、质量在 part-number 索引页与各材料几何表里，量很大且要逐族核对。**这是当前最大的缺口**：16 个核全是铁氧体，`select_core` 选不了磁环 |
| **DC 磁化曲线** `B = x(a+bH+cH²)/(1+dH+eH²)` | p.12/p.14 上确实印了 5 组（XFlux 26/40/60µ、Edge 26/60µ），但它是 **B-H 曲线**，语义与"损耗"完全不同，`what_this_is_not` 现在明说 "Not a B-H curve"。塞进同一个工具会把两个量混成一个答案 ⇒ 留给独立一轮（新工具或新参数 + 新判据） |
| **XFlux Ultra / High DC Bias 各自的饱和磁密** | p.10 只给到 XFlux/XFlux Ultra 共用 1.6 T 一行、p.12 只说 High DC Bias "same high saturation as standard XFlux"；没有单独的印刷值就不另立字段 |
| **Bsat 的温度** | p.10 那一列没印温度，所以 `bsat_mt_25c` 里的 `25c` 是**本表的约定**，`bsat_note` 明写了这一点，不许读成厂商声明 |
| **XFlux Ultra 5.7 % 差的原因** | 只能确认方向（Ultra 更低损耗）与量级；没有第二份印刷值可对 ⇒ 登记为未解释，不猜 |
| **九个铁氧体**（N87 / 3C90 / 3C96 …）仍拒绝 | 它们没有厂商印的 `(a, b, c)` 形状表，只有 k/α/β 或曲线图；`FIT_NOT_RESOLVED` 仍是对的答案 |
