# 圆不是方的：圆导体（实心线与圆管）的趋肤，和一个会骗人的闭式解

日期：2026-11-01　工具：`ac_round_conductor(...)`（`calc/roundwire.py` 新增，纯 stdlib）；
`via_resistance` 新增 `plating_outside`（默认关，答案逐位不变）

上一篇（`69`）把薄板解决了，用的是一条只在厚度方向扩散的 1-D 解。它明写着一条边界：
**"过孔场：孔壁的电流分布是另一个问题"**。

这一篇解的正是那个问题。而且它不是"把薄板套到圆上"就能完事 —— 一个 0.15 mm 钻孔、
25 µm 镀铜的过孔，在 1 GHz：

```
δ                = 2.0897 µm
x_out = a2/δ     = 47.85          （壁厚 25 µm = 11.96 个 δ）
R_ac / R_dc      = 10.5781
R_dc             = 1.2543 Ω/m     （按环形截面算，不是按外圆算）
R_ac             = 13.2684 Ω/m
```

**10.58 倍。** 一块走 1 GHz 的数字板，孔壁的损耗不是 DC 那个数的一倍多，是一个数量级。

而这篇更想让人记住的是第二件事：**圆管有一个教科书闭式解，它在 `x ≳ 15` 之后会安静地
返回实心线的答案**。`x = 40, a1/a2 = 0.9` 时它答 `20.2523`，真值是 `3.8501` ——
差 **5.26 倍**，不报错、不警告、量级看起来完全合理。本轮一开始就是从这里翻车的。

---

## 1 判据

**一个解要在三个极限上成立、被两个完全独立的数值解复现、并且对"用错几何"这件事有可见的后果。**

| 判据 | 期望 | 打错哪里会让它失败 |
|---|---|---|
| `x→0`（实心） | `R/Rdc → 1 + x⁴/48`，`X/Rdc → x²/4` | 小 x 展开的系数 —— **薄板是 `1 + 4x⁴/45`，两者不能混** |
| `x→0`（薄壁管） | `R/Rdc → 1`，`X/Rdc → ω L`，`L → μ/(8π)` 的环形修正 | 环形截面的面积/磁链归一化 |
| `x→∞` | `R/Rdc → x/2 + 1/4 + 3/(32x)`，`X/Rdc → x/2 − 3/(32x)` | 渐近分支、`√f` 的系数、45° 相位 |
| 两个独立解 | Riccati 走针 vs 复有限差分 vs mpmath 高精度 | 任何一处公式抄错 |
| DC 自证 | `η = j x²(ρ²−rᵢ²)/ρ` ⇒ `Z/Rdc ≡ 1`（精确） | 归一化分母用错（用外圆而不是环形） |
| 用错几何的代价 | 环形 vs 外圆差 **18 %**（0.3 mm 孔 + 25 µm） | 两种孔径约定被静默统一 |

最后一条是本轮**唯一新增的一类判据**：一个数量对不对，取决于你把"直径"当成什么。
这件事在商业软件里是要出图纸纠纷的，所以它必须在信封里被写出来（§9）。

## 2 模型：柱坐标，孔是一个 Neumann 面

良导体内的电场满足（`e^{+jωt}`，柱对称，只依赖 `r`）：

```
E'' + E'/r + k² E = 0,        k² = −j ω μ σ,   k = (1 − j)/δ
```

两个边界条件，一个定尺度：

| 边界 | 物理 | 数学 |
|---|---|---|
| `r = a1`（孔壁） | 孔里没有净电流 ⇒ 孔内 `H_φ(a1) = 0` | `E'(a1) = 0` |
| `r = 0`（实心） | 轴上正则 | `E'(0) = 0` |
| `r = a2` | 定尺度 | `E(a2) = 1` |

**这一条是本轮最容易搞错的地方：孔不是对称面。** 一个圆管不是"实心线的一半"，
也不能用 `faces="two"` 的薄板去套 —— 薄板的对称面是 `H=0`，而孔壁的 `H=0`
是**另一个几何上的面**，它的面积、曲率、磁链全部不同。实测：一片 25 µm 铜按薄板
单面算 vs 按圆管算，除掉中径几何因子 `(a1+a2)/(2a2) = 0.833` 之后 `R` 仍差 1.41 %
（`x_rel_error` 1.5e-4），残余是圆管独有的 `O(1/x)` 表面项 —— 它不是错误，
是"薄板和曲面本来就不共享那一项"。

阻抗：

```
Z = jωμ · E(a2) / (2π a2 · E'(a2))        每米
R_dc = ρ / (π (a2² − a1²))                环形截面，不是外圆
```

`R_dc` 用环形截面是**判据**而不是选择：`Z/R_dc` 在 `x→0` 必须恰好是 1，
只有按环形截面归一才成立。如果按外圆归一，薄壁镀铜的答案会偏大 `(a2²/(a2²−a1²))` 倍 ——
0.3 mm 孔 + 25 µm 镀层是 **1.18 倍**，一个"看起来只是保守一点"的错答案。

## 3 答案通路：不走闭式，走 Bessel 方程的对数导数

圆管有闭式解（见 §4，它是错的）。本工具真正的答案通路是**对数导数的推进**：

```
η(ρ) = d lnE / dρ,           ρ = r/a2,     A = (k a2)² = −2j x²

dη/dρ = A − η² − η/ρ                        （Bessel 方程的对数导数形式）
η(a1/a2) = 0                                 （孔壁：E' = 0）
Z/R_dc = j x² (1 − (a1/a2)²) / η(1)
```

实心线取 `ρ0 = 1e-6`、`η = j x² ρ0`（轴上正则的级数首项），同一套代码。

**这是一条 Riccati 方程**，它把"两个 Bessel 函数相减"这个病根整个绕开了：
没有任何两个 O(1) 的数相减，所以不存在相消。实测 `x = 40, a1/a2 = 0.9`
走针给 `3.850095923252`，`riccati_convergence_rel = 1.8e-10`。

**步数按壁厚算，不按外径**：

```
n = max(200, 16·(x_out − x_in) + 200)       Richardson: z₂ + (z₂ − z₁)/15
```

这一条是过孔能不能用的关键。via@1 GHz 的 `x_out = 47.85` 而 `x_in = 35.89`，
按壁厚只要 **528** 步；按外径要 766 步，而一个 5 mm 的铜柱在 1 GHz（`x ≈ 1196`）
按外径要近 2 万步。实心线同理：`diameter_mm = 1 @ 1 MHz` 是 `x = 7.57`、642 步，
而 `x = 1e5` 的实心线用走针要 160 万步 —— **所以实心线不走走针，走闭式**：

```
Z/R_dc = (k a2 / 2) · J0(k a2) / J1(k a2)       （实心，稳定，就是答案）
```

这个闭式没有相消问题（`J0/J1` 在复平面上不接近相消），实测对 Riccati 走针
在 `x = 400` 相符到 5e-15，对渐近式在 `x = 1e6` 相符到 6e-11。

**所以本工具是两条通路**：实心 → 闭式（答案），圆管 → Riccati 走针（答案，
闭式只在 `x_out ≤ 10` 作复核）。分岔点在 `hollow`，信封里 `model` 字段明写了走的是哪条。

## 4 那个会骗人的闭式：`c = −J1(ka1)/Y1(ka1)`

圆管的教科书解是

```
E(r) = J0(kr) + c·Y0(kr),      c = −J1(k a1)/Y1(k a1)     （由 E'(a1)=0 得）
Z/R_dc = (k a2/2)(1 − (a1/a2)²) (J0(ka2) + c Y0(ka2)) / (J1(ka2) + c Y1(ka1)·…)
```

数学上它是对的。数值上，**在 `x` 大到一定程度之后它就不是它了**：

| `x` | `a1/a2` | 闭式给的 `Z/Rdc` | 走针给的（真值） | 差 |
|---|---|---|---|---|
| 5 | 0.5 | (2.0579, 1.8858) | 同 | 1e-10 |
| 10 | 0.9 | (1.0812, 0.6172) | 同 | 1e-10 |
| **40** | **0.9** | **(20.2523, 19.9976)** | **(3.8501, 3.7967)** | **5.26 倍** |
| 71 | 0.845 | 见 §5 的 dps 表 | (10.2240, 10.1517) | 视精度 |

`x = 40, a1/a2 = 0.9` 那一行值得盯一眼：`20.2523` **就是同 `x` 的实心线答案**
（`_solid_ratio(40) = (20.252342746369110, 19.997596696158611)`，逐位相同）。
机制是 `c → −i`：当 `|k a1|` 很大，`J1/Y1` 的比值趋于常数，于是 `E(r) = J0 + c Y0`
退化成一个纯实心的解，管子的信息被完全消掉了。

**这不是"精度不够"，是"换了一个物理问题还照样回答"。** 所以本工具把它降级为
`x_out ≤ 10` 的独立复核：`x_out > 10` 时 `closed_form_skipped` 里逐字写着
"at x=40, a1/a2=0.9 it returns the SOLID answer 20.2523 where the truth is 3.8501"，
而不是印一个看起来和走针吻合的数。

### 4.1 mpmath 也救不了它（这一条比上面更值得记）

闭式失效之后第一反应是"用高精度算"。实测（`x = 71, a1/a2 = 0.845`，
真值由走针与 80 dps 闭式、50 dps ODE 积分三方一致给出）：

| `mp.dps` | 闭式结果 | 相对误差 |
|---|---|---|
| 30 | `ZeroDivisionError` | — |
| 40 | `ZeroDivisionError` | — |
| 50 | `ZeroDivisionError` | — |
| **55** | **(10.223656803931606, 10.151851379981979)** | **2.422e-05** |
| 60 | (10.223983803730397, 10.151729519211120) | 1.363e-10 |
| 65 | (10.223983801769883, 10.151729519105713) | 4.711e-15 |
| 70 | (10.223983801769814, 10.151729519105718) | 1.744e-16 |

55 dps 那一行是本轮最贵的教训：**它不报错，它给一个错了 2.4e-5 的数**，

这条与 `69` 的 `s = 0.01` 相消是同一类事件，只是换了层：**读数层失败和被测对象失败

## 6 六条独立锚（不依赖任何 Bessel 函数）

这六条是"如果我 Bessel 全写错了，它们仍然会失败"的那种锚：

1. **实心 DC 级数**：`R/Rdc = 1 + x⁴/48`（实测 rel 1.4e-14），`X/Rdc = x²/4`。
   **薄板是 `1 + 4x⁴/45`** —— 两个系数不同，所以"把圆当成方"在这里立刻现形。
2. **DC 内电感**：`L_dc = μ/(8π) = 50.0 nH/m`，**与直径无关**。
   实测 `49.99999999893007`，rel **2.1e-11**。这条锚特别值钱，因为它不需要调用者
   给频率（工具内部用 `ω_x = 2x²/(a2² μ σ)` 自洽回代）。
3. **渐近**：`R = x/2 + 1/4 + 3/(32x)`、`X = x/2 − 3/(32x)`。
   实测 `x = 40` 时 `asymptote_r_rel_error = 4.96e-8`、45° 相位 1.2e-4。
   （注意 `X` 的常数项是 **0** 不是 `1/4` —— 写错这一项会让 45° 相位永远差一点点。）
4. **薄壁 → 薄板**：25 µm @ 1 GHz（11.96 个 δ）除中径因子后 `R` 差 1.41 %、
   `X` 差 1.5e-4；`x = 40`（壁厚 4 个 δ）时 `R` 差 1.26 %、`X` 差 1.2e-4。
   残余随壁厚/δ 缩小而消失 ⇒ 它确实是 `O(1/x)` 表面项，不是系数错。
5. **管 → 实心**：`a1 → 0` 时走针的答案必须等于实心答案乘面积因子
   `z_tube / (1 − (a1/a2)²) → z_solid`。比的是**物理阻抗**，不是 `Z/Rdc`
   —— 因为两者的 `R_dc` 定义不同，直接比比值会差一个面积因子。
6. **薄壁 → `R_dc`**：`wall/δ < 0.1` 时 `R/Rdc → 1`。
   实测 0.5 µm 镀层 @ 1 GHz：`1.00000000029`（0.3 mm 孔）、`1.0002898`（0.1 mm 孔）。
   这一条是"用趋肤深度算薄镀层会答非所问"的正面证据：`δ = 2.09 µm` 比镀层厚 4 倍，
   电流根本没被挤到表面，是**把能用的铜用满**。

## 7 径向剖面：一个看起来完全合理的错图

`profile` 报 9 个半径上的相对电流密度 `j_rel` 与相位。两条通路：

| 通路 | 何时用 | `x = 72` 时的表现 |
|---|---|---|
| `radial_profile`（走针，`ψ = lnE`） | **总是** | `j_rel: 4.85e-10 → 1.0` |
| `radial_profile_bessel`（闭式） | 只作 `x_out ≤ 5` 的复核 | **恒 1.0，相位恒 0** |

第二行是本轮最危险的形态：它不报错，它给一张**平直**的图。
`x = 72` 时真实电流在孔壁处衰减 9 个数量级，而闭式说"到处都是 1"。

所以 `profile` 默认走 `ψ = lnE`（走针顺带积出 `ψ`，代价是 0），
`j_rel = exp(Re ψ(r) − Re ψ(a2))`；节点间用 **Hermite 三次插值**
（`ψ' = η` 两端都已知，绝不线性插值 —— 那是 9 个点画一条指数曲线）。
`x_out > 5` 时信封里写 `profile_vs_closed_skipped`。

两条附带判据：`profile_monotone_outward`（`|J|` 必须从孔壁向外单调增）、
`profile_outer_is_max`。相位 `phase_lag_deg` 是**不折叠**的累积滞后，
一根几十个 δ 宽的线上能到 `−1278°`（via@1 GHz 到 **−685°**）；
`phase_deg` 则折到 `(−180, 180]`。两个都报，因为折过的那个会让人以为相位走得比物理快。

## 8 `regime`：四态，其中一态让"用趋肤深度"变成错答案

| `regime` | 判据 | 物理 |
|---|---|---|
| `dc` | `x_out ≤ _X_SERIES_SAFE` | `Z = R_dc` |
| **`wall-limited`** | 有孔 **且** `x_wall = x_out − x_in ≤ 1` | 电流用满整片壁，`R ≈ R_dc` |
| `transition` | 介于两者 | — |
| `skin-dominated` | `x_wall` 大 | 电流在 2δ 表面壳里 |

`wall-limited` 是本轮新增的一态，也是"专业软件该做的事"：薄镀层过孔在 1 GHz
**不是趋肤问题**，是"铜太薄"。这时候把孔挖大没有用，把镀层加厚才有用。
按 `δ` 反推"有效厚度"会给一个把电阻算大 4 倍的结果（0.5 µm vs 2.09 µm）。

## 9 两种孔径约定，差 18 %

同一个 `0.3 mm`，两张图纸说的可以不是一件事：

| 约定 | 铜在哪 | 成品孔 | 环形面积（0.3 mm + 25 µm） |
|---|---|---|---|
| **钻孔**（drill） | 在孔里侧 | `drill − 2·t` | 0.021598 mm² |
| **成品孔**（finished） | 在孔外侧 | `drill` | 0.025525 mm² |

差 **18 %**，直接进 `R`。

`via_resistance` 原本把 `drill_mm` 当钻孔（铜在里侧），但描述写的是
"finished hole diameter" —— **描述与代码不一致**。本轮的处置：

- `ac_round_conductor` 用**成品孔**（`OD = drill + 2·plating`），因为 `H_φ(a1)=0`
  的正确语义就是这个面，而且制造图纸通常给的是成品孔径；
- `via_resistance` 加 `plating_outside=False`（**默认，读数逐位不变**；`basis`/`extra`
  逐字不变，只在 `assumptions` 里**追加**一条 `hole_convention` 说清默认读的是哪种图纸），
  置 `True` 时切到与 `ac_round_conductor` 一致的约定，并跳过"镀层堵死孔"的检查；
- 两个工具的信封都写明自己用的是哪种（`assumptions["glossary"]` /
  `assumptions["hole_convention"]` + `extra["hole_convention"]`，后者只在 `True` 时出现）。

**不静默统一**，因为两种约定都是行业里真实存在的图纸语言；默认值不动，是因为
已经发出去的读数不能因为一次描述修正而变。

## 11 明说的边界（`limits` / `assumptions`）

1. **无邻近效应**：只解孤立导体。真实过孔阵列里相邻孔的场会互相挤压，
   单个孔的 `R` 会更大或多一点（取决于相位），本工具不预报这一项。
2. **无 pad / antipad**：只在 `a1..a2` 之间解场，焊盘、反焊盘、平面开口都不在模型里
   —— 它们对过孔的 `L` 影响远大于对 `R` 的影响，但这里一个都不报。
3. **无端部扩散**：两端当成无限长圆柱，孔口边缘的电流挤入不算。
4. **单频点**：不算扫频、不算脉冲响应。
5. **无温升**：`temp_c` 只改 ρ，不自洽求解热。要自热请把 `R` 喂给
   `electrothermal_conductor`。
6. **`μ_r` 只有一个**：不区分内外层（有磁性镀层的情形不支持）。
7. **粗糙度只作乘子**：复用 `calc/roughness.py`，默认关。深趋肤（`δ < 3 µm`）时
   不给 `Rq` 会明确 warning：那是**下界**。

`limits.not_modelled` 里一条不落，因为"过孔 = 一根小圆柱"这个近似在某些结构上
（比如背钻、盘中孔、密集过孔墙）会明显偏低，而偏低不会自己报警。

## 12 口径与成本

- **默认关时读数逐位不变**：`via_resistance` 不传 `plating_outside` 时，读数与 0.0.66
  **逐位相同**，`basis` 与 `extra` 逐字不变；`assumptions` 里**追加**一条 `hole_convention`
  （默认读的是「钻孔、铜在里侧」）—— 这是「加字段」而不是「改语义」。
  自检里直接断言两种约定的面积（`0.021598` / `0.025525`）而不动默认分支。
- **工具数棘轮 171 → 172**。新工具而不是开关：圆导体的输入表是
  `diameter | (drill, plating)` + `wall_um`，与薄板的 `thickness/faces` 不是同一张表，
  而且答案通路（Riccati vs 半角恒等式）完全不同。
- **成本**（本机实测，20 次平均）：

  | 场景 | `x_out` | 步数 | FD | 单次 |
  |---|---|---|---|---|
  | via 0.15 mm @ 1 GHz | 47.9 | 782 | 1148 | **68.3 ms** |
  | 1 mm 线 @ 1 MHz | 7.6 | 642 | 801 | **14.8 ms** |
  | 2 mm 孔/200 µm @ 10 MHz | 57.4 | 706 | 1378 | **78.0 ms** |
  | 5 mm 铜柱 @ 1 GHz | 1196 | — | skipped | **100 ms** |

  **归因（`cProfile`，5 次调用累计 0.334 s）**：`_bisect` 三次里程碑频率搜索
  占 **0.285 s（85 %）**，`fd_annulus` 0.023 s（7 %），答案走针 `_eta_walk`
  两次（含 Richardson）约 0.002 s/次（3 %）。所以关掉 FD（`fd_verify=false`）
  **省不下多少**（实测 63.8 → 59.9 ms，且本机计时噪声可达 ±30 %，见下），
  真正的开销是那 3 × ~37 次走针的二分。

  里程碑搜索二分的是**壁厚 `s = x_out − x_in`（≤ 5）而不是频率**：`R/Rdc` 只
  通过 `s` 依赖几何，频率用 `f = (s/span)² · 1/(μ₀μ_rσπa2²)` 换算回去。
  直接对 `f` 二分会把 `x` 推到 1e6，而走针步数正比于 `x_wall` —— 那是 1 ms
  和一次超时之间的差别。

  （计时噪声：同一台机器上重复测同一组用例，`fd_verify` 开/关的次序反过来会有
  20 ms 级的漂移，所以本表只报到 0.1 ms 的一位，归因以 `cProfile` 的累计时间为准。）
- `profile_samples` 默认 9，下限 `>= 2`，工具描述与模块报错文案现在一致（本轮顺手修掉
  了描述里写 `>= 3` 的错）。2 个采样点是合法的，但它对一条指数曲线几乎什么也没说。

## 13 结论

**圆导体是可以算准的，闭式解是不能再用了，而"把圆当成方"在 1 GHz 的过孔上错一个数量级。**

三句要一起说：

- 算准了 —— 八个 mpmath 锚（80–900 dps，两个独立积分方式）、六条不依赖 Bessel 的锚、
  两条独立数值解，全部对上；
- 闭式解不能用了 —— `x ≳ 15` 之后它返回实心线的答案（`x=40` 差 5.26 倍），
  而且它同时把 `profile` 变成一条平直的 1.0；
- 错一个数量级 —— 0.15 mm / 25 µm 的过孔在 1 GHz 是 `10.58 × R_dc`，
  按 DC 算就是低了一个数量级，而 `10.58` 这个数还要再乘上"18 % 的孔径约定"
  才落得进真实图纸。

**这篇唯一想让人记住的，是那个安静的错答案**：`20.2523` vs `3.8501`，
以及 55 dps 给出的 `2.4e-5`。两者都不报错 —— 所以判据必须能失败，而不是必须通过。
