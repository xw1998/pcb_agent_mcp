# 阶段 4b —— band 可以「预留波场」：只改价钱、不改合法性，以及它在这块板上买不到齿

`188 §4` 把 lane 内等长的死路算清了一半：走廊横截面实测相邻网中心距 **0.25–0.30 mm**，而放一个**可读**齿（`ARC_H_LEGIBLE_MM = 0.15`，1.5 倍线宽）需要中心距 ≥ **0.475 mm**，于是 `too_shallow` 的算术来源就在那里。`188 §5` 留的下一句是：*这一步是布局账*——band 生成时就该把「要打蛇形的那几条网」周围的空气预留出来，改 `net_priority` 的 escape 顺序也一样。

本文把「预留」做成 **band 的一个键**（`reserve_nets` / `reserve_mm` / `reserve_price`），然后在真板上量它到底买到了多少空气。结论先说：**机制成立、可读性买不到**，而且原因不是参数没调对，是焊盘间距在场、铜在场之后才想起要空气。

本轮不升版本、不进 CHANGELOG（沿用 181–192 的先例）；工具数不变（262），因为这是 `route.router.plan` 的一个键，不是新工具。

## §1 结论先行

**新能力**（`route/grid.py` + `route/router.py`，零新依赖）：

| 位置 | 内容 |
|---|---|
| `grid.astar(..., reserve=None, reserve_price=1.0)` | `reserve` 是 `{layer: bytearray(nx*ny)}`；命中格 `step_cost *= reserve_price`，命中的 via 再加 `VIA_COST*(price-1)`。**与 `guide` 完全同型：只改代价，绝不改合法性** —— 栅格说不能走的格子，价钱再高也还是不能走 |
| `bundle_bands[k].reserve_nets` | 必须是**本 band 的成员**（不满足 ⇒ `ARG_INVALID`）。预留是「这一组对自己共享空间的主张」，不是全局 keepout |
| `bundle_bands[k].reserve_mm` | 环宽，`(0, 4]`。缺失 ⇒ 拒绝（「没有宽度的环不是预留」）；> 4 ⇒ 拒绝（「那不是蛇形的空气，是第二条走廊」） |
| `bundle_bands[k].reserve_price` | `(1, 20]`。1.0 ⇒ 拒绝（等于没预留）；> 20 ⇒ 拒绝（「价钱从引导搜索变成决定搜索」） |
| 顺序 | `_band_key` 的第二键改成 `0 if net in reserving else 1` —— **预留网先路由**。否则环是从空气里画出来的，报告却报成功 |
| 报表 | `stats["bundle_bands"][i]["reserve"] = {nets, mm, price, ring_cells, gap_mm}`，`gap_mm[net] = {gap_mm, nearest}` 是**腰部净空**（同层、跳过该网自身焊盘 1.0 mm 内、0.1 mm 采样点对段距离） |

**真板读数**（`D:/tmp/_s1d.esc2.kicad_pcb`，12 网 = LANE0 九条 + `/DDR_DQS0P/N` + `/DDR_CLKP`，两端钉 `In2.Cu`/`B.Cu`，pitch 0.05、track 0.1、via 0.2/0.1、clearance 0.105、`new_copper_layers=["In2.Cu","B.Cu"]`）：

| 组 | 通了 | ops | elapsed | lane0 spread | 预留网的腰部净空 |
|---|---|---|---|---|---|
| 189 基线复跑（无 band） | 12/12 | 94 | 87.2 s | — | 0.300 mm（`/DDR_DQ1`） |
| band，**无** reserve | 12/12 | 116 | 33.6 s | **7.737** | 0.250 mm（`/DDR_DQ1`→`/DDR_DQ0`） |
| 预留 4 网，mm 0.5 / price **4** | **10/12** | 101 | 132.6 s | 5.420 | 0.0000 / 0.0354 / 0.0118 |
| 预留 4 网，mm 0.5 / price 2 | 12/12 | 118 | 42.3 s | **6.539** | 0.2873 / 0.2475 / 0.2500 / 0.2500 |
| 预留仅 `/DDR_DQ1`，mm 0.5 / price 3 | 12/12 | 136 | 22.7 s | **10.048** | 0.300 mm（→`/DDR_DQS0N`） |
| 预留仅 `/DDR_DQ1`，mm **1.2** / price 2 | 12/12 | 129 | 24.2 s | **8.444** | 0.250 mm（→`/DDR_DQ0`） |

四条读法，一条一条写死：

1. **环确实买到了空气，但只有 +0.05 mm**：最好的一格 0.300（仅 DQ1、环 0.5 mm、price 3），基线 0.250。可读齿要 0.475 ⇒ **差 0.175 mm，不是调参数能补的距离**。
2. **加宽环没用**：0.5 → 1.2 mm 环（`ring_cells` 5710 → 16558，3 倍）净空从 0.300 **掉回** 0.250，spread 从 10.048 变 8.444。环越宽，邻居被迫绕得越远，最后从别的方位贴回来——腰部的「最近者」从 `/DDR_DQS0N` 换成了 `/DDR_DQ0`。
3. **价钱开过头会真的把网搞挂**：4 网 × price 4 ⇒ `/DDR_DQ5`、`/DDR_DQ1` 两条 `search_budget`，10/12。这是价钱的正确失败模式（拒网而不是违规），但它同时说明**预留不是免费的**：环越值钱，被挤出去的那几条网越可能找不到路。
4. **spread 与净空不同向**：无 reserve 时 spread 7.737 最「整齐」，仅 DQ1 预留时 10.048 最不整齐 —— 为了让一条网有腰部空间，其余八条被拉长了 2.3 mm 的跨度。**这两件事不能同时当验收量**，报表里必须并排出现。

## §2 机制：为什么是价钱而不是墙

这条界线是本仓库反复被纠正出来的。`guide` 当初就是这么定的：band 只是让走廊成为「最便宜的地方」，一个被栅格判为 blocked 的格子，`guide` 再甜也进不去。`reserve` 抄同一套：

- 命中格：`step_cost = step_cost * reserve_price`；命中格的 via：`vtoll += VIA_COST * (reserve_price - 1.0)`。除此之外 A* 一行没动（`g` / `h` / `TURN_COST` / `pen` / `toll` 的算式不变）。
- 之所以敢这么写，是因为 reserve 的**唯一目的**是「让别人现在绕一下」，而绕一下的代价必须是**有限**的。价钱一旦变成墙，就会出现「环画好了但整组布不通」，那是比「没有空气」更坏的答案。
- 反向失败对照把它固定住了：`reserve_price=18` 在三网小例上仍然 3/3 通、`rejected_ops == 0`（§4）。

**预留网必须优先路由**，是同一个哲学的第二次落点。第一次跑的时候（`_rsv2.py` 第一版）把预留网混在 band 里按长度排，结果是：环从「还没画的铜」上什么也没画出来，`ring_cells` 报 0，而 `plan` 报全部成功 —— 正是这个仓库到处在拒的**静默空转**。修法是把预留网提到 band 内的第一顺位（`_band_key` 的第二键），并在 `tests/test_route_reserve.py` 里断言 `order[0] == "/BUS_C"`。

第三个落点是**报表量选在腰部**。焊盘中心距由布局定死（0.25–0.30），量它永远得同一个数；能放齿的地方在走廊中段，所以 `gap_mm` 跳过该网自身焊盘 1.0 mm 内的采样点。这一条顺手修掉两个自己的 bug：

- 最初按段端点判「要不要跳过」，而一段 4 mm 的直线**两个端点都在焊盘上** ⇒ 整段被跳掉，`gap_mm` 为空（`key_perr`：`/BUS_C` 只有一条直线段，测试当场红）；
- 最初跨层量距离 ⇒ 两层铜合法交叉报 **0.00 mm**，把「穿过」读成「贴着」。改成 `flats` 的键是 `(net, layer)`，比较前 `if l != l_here: continue`。

## §3 真板读数为什么是这个数

三条互不替代的证据，都在板上：

1. **`ring_cells` 与净空不同步**：0.5 mm 环 5710 格买到 +0.05 mm；1.2 mm 环 16558 格买到 0。环是「面积」，净空是「最近者」，两者只在环宽刚好越过半个走廊间距时才相关。
2. **净空的 `nearest` 会换人**：仅 DQ1/price 3 时报 `/DDR_DQS0N`，仅 DQ1/环 1.2/price 2 时报 `/DDR_DQ0`。说明这个数不是「DQ1 与某个固定邻居的距离」，而是「走廊里此刻谁离它最近」——所以它只能在**整组布完之后**量，布的过程中量没有意义。
3. **`ops` 与 `elapsed` 的账**：同一块板 94 op / 87.2 s（189 基线，无 band）→ 116 op / 33.6 s（band 无 reserve）→ 136 op / 22.7 s（预留仅 DQ1）。band 让搜索变快（走廊变便宜，A* 少绕），reserve 让它再快一点（别人主动避开），**但净空没变**。

也就是说：**这块板的 `too_shallow` 是布局给的，不是路由给的。** 要让 §188 那五条网（`DQ1` 差 1.96、`DQ12` 差 1.96、`DQ13` 差 1.81、`DQ10` 差 1.75）活过来，出路只有两条，两条都在 band 之外：

- **band 生成期就要预留**：现在的 `_paint_ring` 是在**已 emit 的铜**上画环，也就是「先有走线再画环」。真正的预留应该发生在 **band 决定走廊几何的那一刻**（骨架 + radius），那时还没有对抗几何。
- **改 escape 顺序**（`net_priority`）：焊盘出线顺序决定谁占走廊中间，中间那条才有两侧空气。

这两条都不是本轮能顺手改的：前者要重写 `_band_key`/`_skeleton` 的时序，后者要先把 `net_priority` 在真板上量一遍它的实际影响（现在只知道它改变路由顺序，不知道改变多少净空）。

## §4 四条反向失败对照

「宁可报错不给错答案」的落法是：每条新判据都有一个**把它改坏就必红**的对照（`tests/test_route_reserve.py`，8 例全过；`ReserveBase.three_wire_bus()` 是三网 0.7 mm 密排的小板）。

| 判据 | 正例 | 反例 |
|---|---|---|
| **环必须真的买到空气** | 三网密排（焊盘中心距 0.7 mm）+ 预留 `/BUS_C`（mm 1.0 / price 4）⇒ `/BUS_C` 腰部净空 **1.100 mm**（`nearest /BUS_B`）、`ring_cells 5389`。断言 `gap_mm ≥ 0.9` | 不去预留 ⇒ 三网各 **24.000 mm**；预留档 `/BUS_B` 被绕成 **24.566 mm**（+0.566），说明环不是白画的、代价落在邻居身上 |
| **价钱不能变成墙** | price 18 ⇒ 仍 3/3 routed、`rejected_ops == 0` | 若把 `reserve` 写进 `grid._map`（改合法性而非代价）⇒ 正例 3/3 变成 2/3 或 0/3，且失败理由会变成 `no_path`（找不到路）而不是「绕远了」 |
| **预留网必须先路由** | `order[0] == "/BUS_C"` | 把 `_band_key` 改回 `(bi, w[0])`（只按长度）⇒ `_paint_ring` 拿到空集合、`ring_cells == 0`，而 `plan` 仍然报全部成功 —— 这就是要拦的静默空转 |
| **参数异常一律拒绝** | 5 例：`reserve_nets` 里有不在 band 的网名 / 有 `reserve_nets` 缺 `reserve_mm` / `reserve_mm = 9.0` / `reserve_price = 1.0` / `price = 50.0` ⇒ 全部 `ARG_INVALID`，且文案点名是第几个 band、叫什么都写出来 | 若把校验改成「越界就截断到合法值」⇒ 5 例由红转绿，同时 `reserve_price=1.0` 会变成一个**看起来成功但等于没预留**的配置，也就是本项目最不能接受的那类答案 |

定向回归：`test_route_reserve + test_route_bundle + test_route_new_copper` = **19 passed**（10.6 s）。

## §5 零影响验证：189 的基线逐字节没变

加 `reserve` / `reserve_price` 两个默认参数之后，用 `_v2e.py`（189 的 12 网脚本）在同一块板上复跑：

```
12/12, ops 94, sweeps 2, rips 3
```

与 `D:/tmp/_v2e_newcu_raster.json` **逐字节相同**（含每一段的起止坐标）。默认参数路径上 A* 多了一次 `if rmap is not None` 判断，代价不可测，行为一模一样。

这条验证不是走形式：`astar` 是整条路由链唯一的搜索内核，`pen` / `guide` / `toll` 三处代价叠加已经很难读，再加一个乘性因子最怕的就是「顺手改了别的分支」。

## §6 复现

探针脚本（**不在仓库里、不进 git**，都在 `D:/tmp/`）：

```bash
# 12 网口径，band 可开可不开；第五/六个参数是预留的网名与 bind 的端点网名
MSYS2_ARG_CONV_EXCL='*' D:/KiCad/10.0/bin/python.exe D:/tmp/_rsv2.py \
    D:/tmp/_rsv2_one12.json reserve 1.2 2.0 /DDR_DQ1 /DDR_DQ1
```

`MSYS2_ARG_CONV_EXCL='*'` 不是装饰：Git Bash 的 MSYS 路径转换会把 `/DDR_DQ1` 改写成 `C:/Users/.../PortableGit/DDR_DQ1`，参数**静默丢失**，脚本照常跑完、报 12/12，只是 band 少了那条网。第一次踩到的就是这个（`BIND` 匹配不上，预留网一个都没进 band）。

任意一份 ops json 的腰部净空可以单独复算：

```bash
D:/KiCad/10.0/bin/python.exe D:/tmp/_rsv_gap.py D:/tmp/_rsv2_one12.json
```

## §7 这一轮没有做的

1. **`bundle_bands` / `net_priority` / `terminal_override` 没有进 `board_route` 的 schema** —— 本轮真板读数直接调 `route.router.plan`（`_rsv2.py`），工具层仍是旧参数面。要开这个口子得同时定三个参数的语义与默认值，属独立一批，不在本轮夹带。
2. **band 生成期预留**（§3 第一条出路）：`_paint_ring` 现在画在已 emit 的铜上，正确时机是走廊几何被决定时。
3. **`net_priority` 的实测**（§3 第二条出路）：只知它改变顺序，不知它改变多少净空。
4. **0.2 mm 余量**（`ruleset.precondition.CLEARANCE_FLOOR_MM`）仍是**需要用户定**的事，工具不自己放宽 —— 但它与本文直接相关：`188 §4` 的 2×2 矩阵里，floor 0.2 → 0.1 让短网可加数从 5 掉到 2/4，也就是说**余量本身就是可读齿的一个大买家**。
5. `hole_in_pad` 9 / 旧 `via_in_pad` 9 / `copper_under_magnetics` 1 / 5 处半路由 / 旧锐角 / `track_dangling` 25 全在阶段 2/3 的欠账清单里，本轮不碰。
