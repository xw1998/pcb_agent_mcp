# 182 · RK3506 分阶段重做 —— 阶段 1b「电源布局专项」

承接 `docs/181`。阶段 1 交完布局图后用户的意见只有一句：**「电源布局不太行」**。
本阶段只做一件事：把四路 buck 的电源元件按 buck 布局规则重排到「四路同构」，
并把被新焊盘压住的旧铜清干净。**不做布线、不做自动布局/自动布线**（沿用项目红线）。

## 1. 判据：buck 布局七项间距

不看「看起来齐不齐」，看七个有物理含义的中心距（越大越差，只有 `Cin→VIN`、`SW→L`、
`BS→cap`、`FB→div` 是「够近」，`L→Cout`、`Cin→GND`、`SW→cap` 是「能短则短」）：

| 项 | 含义 | 为什么要近 |
|---|---|---|
| Cin→VIN | 输入电容到 IC 的 VIN 脚 | 输入环流面积决定输入纹波与 EMI |
| Cin→GND | 输入电容地端到 IC 的 GND 脚 | 输入环流的回程 |
| SW→L | SW 脚到电感 | SW 是最强 dv/dt 节点，越长辐射越大 |
| BS→cap | BS 自举脚到自举电容 | 高 dv/dt 小环 |
| SW→cap | SW 节点到自举电容另一端 | 同上，跨 IC 体是一处固有折衷 |
| L→Cout | 电感输出到输出电容 | 输出纹波环 |
| FB→div | FB 脚到分压中点 | FB 是高阻节点，越短抗噪越好 |

全部用**焊盘中心距**实测（同一把尺子，改前改后同口径）。

## 2. 重排了什么

四路 buck（U4 / U5 / U6 / U7）改成**同一套单元模板**，以 IC 中心 `(cx,cy)` 为基准：

| 件 | 位置 | 说明 |
|---|---|---|
| L（电感） | `(cx+0.15, cy−4.05)`，rot 0 | 与 SW 脚同侧，铜间隙 0.985 mm |
| Cout | `(cx+3.16, cy−4.05)`，rot 90 | 在电感输出外侧 |
| Cin | `(cx−2.41, cy+0.48)`，rot 90 | 贴 VIN 脚 |
| BS 帽 | `(cx+2.41, cy−0.48)`，rot 90 | BS 端 1.21 mm |
| 分压上电阻 | `(cx+0.75, cy+2.55)`，rot 0 | rail 侧 |
| 分压下电阻 | `(cx+2.65, cy+2.55)`，rot 0 | GND 侧，与上电阻 P2↔P1 间距 0.94 |
| IC 中心 | U4 (31.40,31.40) / U5 (39.00,31.40) / U6 (31.40,14.20) / U7 (8.20,**8.60**) | U7 本轮下移 2.2 mm 与其余三路对齐 |

共 **31 个器件落盘**（24 个首轮 + U7 单元的 U7/L4/C7/C8/C12/R7/R8）。

U7 下移的原因写在明处：U7 原本电感在 `cy+4.05`（SW 侧相反，铜间隙 2.885），
与另外三路不是同一套几何；下移 2.2 mm 后四路读数完全一致，代价是 U7 单元旧铜要在
阶段 3 重布。

| U4 | 1.54 | 3.74 | 3.10 | 1.21 | 3.73 | 1.73 | 1.60 |
| U5 | 1.54 | 3.74 | 3.10 | 1.21 | 3.73 | 1.73 | 1.60 |

## 4. 一处如实登记的折衷

BS 帽放在 IC 右侧后，它的 SW 端要跨 IC 体下方回到 SW 节点，`SW→cap` 只能到 3.73 mm。
这是 TSOT-23-6「BS 与 SW 分处两侧」的固有折衷：把 BS 帽挪到 SW 侧可以让这项变短，
但 `BS→cap` 会立刻变长（BS 是高 dv/dt 小环，先保它）。数字留在表里，不粉饰。

## 5. 铜怎么处理的（没有自动布线）

新焊盘压在别人家的走线上，是重排必然产生的事。做法是**按区域清铜**，不是推倒重灌：

1. 对 31 个器件**新的 courtyard 外扩 0.35 mm** 的区域，删除其中**所有网络**的 `F.Cu`
   轨道与过孔（第一版只删「器件自己的网」，结果 28 处 `shorting_items`——移位的焊盘
   压在 `/SDMMC_CMD`、`/RMII0_*`、`/ACODEC_INP`、`/USB0_DN`、`/MIPI_DSI_*` 上）。
2. 剩下的悬空桩用「先量 DRC 再删、删完核对未连数不涨」的方式逐条回收：
   `tools/prune_dangling.py`（整批）→ 逐条贪心（`unconnected` 一涨就放回）→
   按 uuid 直接删。收敛到「每删一条，链子下一段又变成新的悬空头」，剩下的都是
   **一端还挂在器件上、另一端被切断**的半个路由——这些不能删，只能等阶段 3 接通。
3. 两条干道单独处理：
   - `+5V_IN` 在 In3 的 0.8 mm 边缘总线（J1 侧 x=43.93）保留全段；试着裁短 1.6 mm
     反而让 In3 上一块 `+5V_IN` 铺铜变成孤岛（`isolated_copper` +1），已回填并复核。
   - `+3V3` 的 In4 干道原来断在 (10.2, 1.5)，本轮加一颗通孔 + 两段 F.Cu（45°）接到
     L4 的 `+3V3` 焊盘 (9.7, 4.55)，J1 的四个 `+3V3` 脚因此不再悬空。
4. 铺铜一律由 KiCad 官方 `ZONE_FILLER` 灌注（`tools/board_loop.py` 的 `refill()`），
   本阶段没有一行自写灌注代码。

## 7. 还没做的（不藏在正文里）

- **电源区没有走线**（第 6 节数字），阶段 3 按「同构单元模板」重布：Cin→VIN 短粗、
  SW→L 最短、L→Cout、FB 分压取样线走 rail 平面、GND 就近下缝合孔。
- **5 处 dead_end 是半个路由**（一端接器件、一端被切断），只有接通才能消掉，删不得。
- `+1V35_DDR` 在 In3 的孤岛铺铜要等 DDR 缝合孔（阶段 2）。
- 旧的 `hole_in_pad` / `copper_under_magnetics` 与 `via_in_pad 18` 属阶段 3 清单。
