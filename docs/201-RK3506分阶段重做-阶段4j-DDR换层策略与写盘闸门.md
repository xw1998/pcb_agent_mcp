# 阶段 4j —— 「建议 DDR 不要瞎换层」：把建议落成写盘闸门

用户一句话：**「建议 ddr 不要瞎换层」**。

上一轮（`docs/200`）已经能回答「这次换层合不合法」，但它是**仪器**——只报告，不拦人。用户说的「建议」在一句「WL 叫我全做了听不懂？」之后不含任何许可余地：这是一个规则，规则必须让 MCP 在写盘那一刻**拒绝**，否则它只是一个可以被忽略的报告。

所以本轮做的不是又一版读数，而是把同一条判定接到写盘通道上，并且**一个判定只写一份实现**（`_judge_via`），让报告与闸门不可能各说各话。

## §1 结论先行

1. **规则有两个表达，都必须能说**：①「这条总线的每次换层都得有回流路」（按缺陷判，`reference_changes_net` / `no_reference` / `dangling_escape` 三类不可由孔救）；②「这条总线最多换 N 次层」（按次数判，`too_many_layer_changes`）。真实项目里两条都有人写，只用缺陷数表达不出第二条——一条全部合法的总线，换 40 次层，缺陷数仍是 0。
2. **闸门只判「新增」，不判总量**。本板 DDR 现在就有 **97 处**违例；如果闸门按总量判，这张板从此**一个字都改不了**——规则会被关掉，这是最坏的结果。判定口径是 `(net, verdict)` 多重集差分：`after` 里有、`before` 里没有的才算新增。老缺陷照旧报告（`after.violations` 仍写着 97），**通过 ≠ 干净**。
3. **两道闸，一道便宜一道权威**：`board_propose` 就在计划上预判（改主意的成本最低的地方，返回 `precheck.layer_policy` 并写进 `blocking`），`board_apply` 再对着**磁盘上的 checkpoint** 复判（规则集与叠层要重新读，不能信内存）。拦截时按既有四道闸的约定**回滚到 checkpoint 字节**。
4. **override 是显式的新开关 `allow_layer_changes`，不是 `allow_new_violations`**：语义不同（后者是 DRC 新增违例的通行证），而且 `allow_new_violations` 蒙过新违规是仓库红线。用 override 写成功之后，`gates.layer_policy.ok` **仍然是 `False`**——放行不是洗白。
5. **默认关＝零变化**：不传 `precheck_layer_policy` 时 `gates` 里没有 `layer_policy` 这个键，行为与上一版逐字节一致（`_layer_policy_gate` 只在 spec 存在时被调用）。
6. **口径修正（本轮实测才暴露）**：`nets` 是**子串匹配**，`DDR` 会命中 `+1V35_DDR` 这条电源网。被 pour 的网默认排除并列入 `excluded_as_poured`——理由不是「名字像电源」，而是**它的孔是平面缝合**：电流本来就在一整块导体里，「换层之后还有没有参考」对它是另一个问题。`include_poured=true` 可以要回旧的全板口径，正好用来把自己的读数与 `audit_reference` 对账。

## §2 判据（写在返回值的 `meaning` 里，不靠人猜）

| verdict | 含义 | 一颗孔能救吗 |
|---|---|---|
| `shared_reference` | 两侧看到同一块平面，回流不离开那层 | 不需要，也不欠 |
| `stitched` | 同网不同层，`reach_mm` 内已有缝合孔 | 已经有 |
| `stitch_needed` | 同网不同层，还没孔 | **能**（记作 `owed_vias`，**不算**违例） |
| `reference_changes_net` | 两侧参考面**不同网** | **不能**（往两块不同铜上打孔没有意义） |
| `no_reference` | 至少一侧 `depth` 层内没有铺铜 | **不能** |
| `dangling_escape` | 这个孔只连一层（悬空短桩） | **不能** |
| `too_many_layer_changes` | 该网换层次数超过 `max_changes` | **不能**（要改布线） |

「孔真正连了哪几层」按**走线到孔心 ≤ 0.02 mm** 判，不看钻孔跨度：本板 425 个孔全是 F→B 通孔，看跨度会把每颗都读成六层连通。

`stitch_needed` 故意**不是**违例：它欠一颗孔，一颗孔就能修好。把它算成违例，这条策略就会禁掉一件它自己说「可以修」的事。

## §3 两个读数并列，不互相替代

| 口径 | 粒度 | 会在哪里骗人 |
|---|---|---|
| `audit_reference(board)` | 逐孔 | 一张按网看的报告里，一条网有一个 `no_reference` 就整个网定罪，看不出这条网另外 20 颗孔是干净的 |
| `layer_changes(board, nets=…)` | 逐网聚合（也保留逐孔明细） | 整板合并成一个数时，一条网变好、另一条变坏，总数不变 |

`layer_changes` 的 `_judge_via` 与 `audit_reference` 是**同一份判据**（本轮把这个内联块抽成函数），所以「报告说无解，闸门说没事」这种双绿在结构上不可能出现。等价性用 `include_poured=true` 实测验回：HEAD（`5bb24b7`）的 `audit_reference` 在交付板上读 `no_reference 253 / dangling_escape 123`，新版 `layer_changes(include_poured=True)` 读 `376 = 253 + 123`、164 网，**逐项一致**。

## §7 坑

1. **`checkpoint["body"]` 是路径字符串，不是 bytes**（`save_checkpoint` 把内容写到文件、meta 里存路径）。第一版 `_layer_policy_gate` 直接 `.decode()`，异常被吞成「这不是 KiCad 板」⇒ `ok: None` ⇒ **apply 写出去了却没被拦**（`file unchanged: False`）。读数是对的、闸门是通的、结论是错的——只有真跑一遍价签能发现。修法：`str` 就当路径 `open(...,'rb')` 读。
2. **子串匹配会连带电源网**：`DDR` ⊂ `+1V35_DDR`。默认排除 pour 网 + 点名 `excluded_as_poured`；有人在 `schema` 与返回里都能看见这件事，不必读源码。
3. **`unmatched_patterns` 的键总是在**（`pats` 非空时写，哪怕是 `[]`）：比「有没有这个键」更稳的断言是 `== []`。
4. 只跑定向回归（`test_return_path` 89–140 s／例均含真板解析）：`test_return_path` 36 passed、`test_route + test_stitch + test_return_vias + test_route_via_gate + test_calc + test_tools` 182 passed、`test_edit` 39 passed。

## §8 未做（照实写）

1. **闸门不修板**：本板 DDR 的 97 处违例（82 悬空短桩 + 14 参考换网 + 1 无参考面）一条没动。要真干净只有两条路——改叠层（B.Cu 下面补一片连续面）或改布线（DDR 不落 B.Cu），都是设计决定，不是工具能替人拍的。
2. **没把 `layer_changes` 接成布线前的强制前置**：`route/` 至今不查 `calc/rules.py` 的 `layout.reference_plane_continuous` / `layer_changes_without_return_via`。本轮只做到「写盘时拦住」，做到「布线时就不许产生」还要动路由通道，单独立项（与 `docs/200` §8 同一条欠账）。
3. `examples/rk3506_som/rk3506_som.kicad_pcb` 不替换。
4. `max_changes` 只有按网的上限，没有「只许换一次层到指定层」这类结构化表达（例如「DDR 只许在 F.Cu/In2.Cu 之间来回」）。真要用得加 `allowed_layers`，本轮没有需求证据，不加。
5. 阶段 4 其余欠账不变：`+5V_IN` 只有 23.65 mm²、`+0V9_*` 无 zone、In4 当第二信号层用、`hole_in_pad`(9)、旧 `via_in_pad`(9)、`copper_under_magnetics`(1)、5 处半路由、旧锐角、`track_dangling`(25)。
