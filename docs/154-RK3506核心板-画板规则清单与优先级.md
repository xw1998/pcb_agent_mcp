# 154 RK3506 核心板 · 画板规则清单与优先级（0.1.17）

这一版回答一个问题：**这套 MCP 到底学了哪些画板规则，每条怎么量、在本板上读到什么数**。
规则不是一句口号，是一条能跑的判据：有来源、有量法、有限值、有级别（P0…P4），并且每条都被
反向对照打过一遍（判 pass 的规则要能判 fail，判 fail 的规则要能在别的板上判 pass）。

本轮还补上了上一版的缺口：**磁器件（电感/磁珠）与晶振本体下方禁走线**，这不是风格问题，
是 EMC 与涡流问题。补完之后量到本板的真实数字，并做了两条独立否证（§5）。结论不好听，
但它是量出来的：**这块板子的磁器件摆在通道正上方，改摆位与改布线两条路都不通**——
问题出在「摆位时没人检查本体禁布区有没有和布线通道打架」这一步，MCP 缺的正是这道闸门。

## 1 优先级为什么是五级

| 级别 | 含义 | 未过时的后果 |
|---|---|---|
| **P0** | 制不出来 / 制出来是短路或断板 | 板厂直接退回，其它一切免谈 |
| **P1** | 能制，但功能不可靠（连通、参考平面、去耦、回流、磁器件禁布） | 上电可能不工作，或工作到某个频点/温度就抖 |
| **P2** | 能工作，但余量与可维护性差（器件间距、热焊盘、深层禁布、测试点） | 良率与返修成本，量产阶段暴露 |
| **P3** | 工艺与信号完整性偏好（45°、差分、缝合孔、阻抗） | 一致性差，认证难过 |
| **P4** | 外观与丝印（丝印高宽、晶振包地） | 可读性 |

优先级不是排序用的标签，是**判停顺序**：`audit()` 的 `first_action` 永远取最低级别里
第一条非 pass 的检查，P0 没清完不许谈 P1。本板现在的 `first_action` 是
`PCB.EDGE.ROUTED`（走线到板边 0.0 mm，限值 0.2 mm）。

## 3 本轮新增的四条判据（这就是「电感下面不能走线」的代码形态）

| 判据 | 级别 | fact | 量法 |
|---|---|---|---|
| `layout.magnetic_keepout` | **P1** | `trace_under_magnetic` | 走线**轴线**进入磁器件焊盘外接矩形（本体近似），层 = 器件自身所在层或紧邻它的那一层 |
| `layout.magnetic_via_keepout` | **P1** | `via_under_magnetic` | 过孔中心落在同一矩形内且不是该器件自己的网 |
| `layout.magnetic_keepout_deep` | P2 | `trace_under_magnetic_deep` | 同几何，但层比「紧邻层」更深（隔着至少一层实心平面） |
| `layout.magnetic_keepout_graze` | P3 | `trace_under_magnetic_graze` | 铜的**边缘**碰到矩形但轴线没进（擦角，见 §4） |

「磁器件」的识别是三重判定，不是只看位号：位号前缀 `L` / `FB`（且不是连接器）、
库名或值里出现 `inductor / ferrite / bead / choke`、值里出现 `4.3uH / 600R` 这类数字+单位。
本板命中 6 个：L1/L2/L3/L4（CKCS4020 屏蔽电感）+ FB1/FB2（0603 磁珠）。晶振同规格另算
（`trace_under_crystal` / `_inner`），Y1 24 MHz。

**为什么分三层而不是一个数**：把它量成单个布尔值，本板是 `True`，背后是 17 段 + 3 孔 +
139 段三层东西。P1 只该报「真能改、改了真影响功能」的那一层；把 139 段深层铜塞进 P1，
报出来的数字没人能改，规则就退化成噪声。

## 4 两个口径陷阱（都是本轮踩出来的）

**（1）焊盘外接矩形的四个角是空的。** 两焊盘器件的铜是个「日」字少一横，但外接矩形是满的
矩形，四角没有任何铜。于是抗 45° 斜线从角上擦过去时，用「轴线 + 半个线宽」去判会命中，
而实际离最近的真铜还有 0.1 mm。本轮先按「半个线宽」判，得到 17 段；改成「**轴线**进矩形」
再判，其中 9 段其实是擦角。这 9 段没有被丢掉，而是单列成 P3 的 advisory——**报错要报得准，
不能把噪声混进 P1 里让整条规则失信**。

**（2）`pcbnew.PCB_VIA.GetWidth()` 必须传层。** 不传层参数时 KiCad 只在 debug 构建里断言，
release 里不报错、直接返回一个不可预期值；脚本表现为「卡死 60 s 不返回」，日志里只有
`assert "false" failed in GetWidth(): PCB_VIA::GetWidth called without a layer argument`。
量过孔直径一律写 `v.GetWidth(pcbnew.F_Cu)`。

## 5 这块板到底能不能改（两条独立否证）

### 5.1 摆位：全板没有一块空地能放下一个 4.6×3.9 的本体

按 0.25 mm 栅格把板上所有非 GND、非器件自有网的铜（走线 + 过孔 + 焊盘）栅格化到四个信号层，
再滑窗找「一个本体矩形（4.6×3.9 + 0.3 余量）在四层全都干净」的位置：

| 器件 | 本体尺寸 | 全板可行位置 |
|---|---|---|
| L1 / L2 / L3 / L4 | 4.6 × 3.9 | **0** |
| FB1 / FB2 | 2.65 × 1.15 | 382 / 368，但**最近的一个也在 5.1 mm 外** |
| Y1 | 3.8 × 3.1 | **0** |

四层各自的占用率 49%–61%（F.Cu 16469 / In2 17237 / In4 16223 / B.Cu 19923，栅格 181×181），
四层并集几乎全覆盖：最优窗口里还要撞 12 个格子。磁珠挪 5 mm 外等于把它滤的回路拉长 5 mm，
电学上比违规更糟，所以不挪。

### 5.2 布线：网级重布 7/9 被拒，且与禁布无关

撕掉 10 个违规网（226 段 + 27 孔）后，用同一套迷宫搜索重布，跑两遍做对照：

| 网 | 带本体禁布 | 不带禁布 |
|---|---|---|
| /SDMMC_D2 | OK（14 段 / 2 孔） | OK（14 段 / 2 孔） |
| /RMII0_MDC | OK（30 段 / 3 孔） | OK（30 段 / 3 孔） |
| /RESET_N / SPI0_CSN0 / SDMMC_D3 / RMII0_TXD1 / ACODEC_INP / RMII0_CLK / SDMMC_CMD | **REFUSED** | **REFUSED** |

两列**逐网相同**，包括那两个 OK 的段数。这组对照证明：拒绝不是禁布造成的，是本板逃逸口袋
早在 0.1.13 就量出来不存在（400/204216 可达格）。禁布加进去，只是把「本来就找不到路」变成
「找到了也不许走」。因此重布的候选方案不能上板（会把 7 个网变成死网，unconnected 8→远大于 8），
`_v18` 保持交付。

### 5.3 结论：这是**摆位缺陷**，不是布线缺陷

磁器件本体正压在 SDMMC / RMII / ACODEC 的通道上，F.Cu 有 8 处真穿越（SDMMC_CMD 2.39 mm、
SDMMC_D2 3.61/0.67 mm、SDMMC_D3 3.81 mm、RESET_N 0.99 mm 等），另外 3 个过孔也落在 L1 本体里。
要根治只有两条：**把 L1/L3 从通道上挪走**（无地可挪，§5.1）或 **把 U2 DDR 转 90° 让通道整体
改道**（docs/153 §8 量过：旋转后离散度 14.79→7.28、交叉 480→103，是唯一还有余量的方向）。
本版不改板，把读数如实记账，P1 两条判据在交付板上是 **fail**，不隐藏。

## 6 所以 MCP 缺什么

缺的不是规则文本，缺的是**在摆位那一刻问一句「本体禁布区有没有和布线通道打架」**：

1. 布线器原先不知道磁器件本体是障碍物 → 现在知道了（`_mazeH.py` 的 `KEEPOUT` 注入，
   用不可能与任何网同名的 net 名注入矩形，绕过 `it['net'] == net` 的自网豁免）。
2. 判据原先没有 fact → 现在有（四个 fact，三层分级）。
3. 还缺的一道闸门：**摆位完成、布线开始之前，先做可行性判定**——把每个本体矩形扣掉后，
   通道两端的网是否仍有连通路径。这道闸门在摆位阶段并不存在，所以磁器件才落在
   DDR/SDMMC 通道正上方。它属于摆位层，不属于布线层，本轮只把它的输入（本体矩形 + 四层占用）
   备齐，闸门本身留作下一版。

## 7 可复用口径

1. 判据要分级：一个布尔值背后如果同时藏着「真能改的 8 段」和「改不了的 139 段」，规则必然
   被当成噪声忽略。分级 = 把「能改」和「知道但改不了」分开报。
2. 量禁布区分两问：**轴线进没进**（走线过本体）与**边缘碰没碰**（擦角）。前者是功能问题，
   后者是几何必然（外接矩形四角是空的），必须分列。
3. 改板之前先量「有没有地方可挪」，不要先算「挪了要重布几条」：空地数为 0 时后者是白算。
4. 对照臂要「同一份输入、只差一个变量」：重布两次只差 `KEEPOUT` 有无，结果逐网相同，才能
   把「拒绝」归因到密度而不是归因到新加的禁布。
