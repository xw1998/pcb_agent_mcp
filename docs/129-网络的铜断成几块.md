# 网络的铜断成几块、最近两块差多远

`board_net_gaps` 回答一个 DRC 只给总数的问题：「这一网的铜断成几块，最近的
两块差多远、在哪一段」。

## 1. 为什么需要它

真板（`examples/sky_star/sky_star_routed.kicad_pcb`）的权威 DRC 说：

```
unconnected_total = 115
```

到此为止。它数的是 ratsnest 边，不会说 `+3V3` 一个人占 38 条、不会说这 38 条
落在 39 块铜上、也不会说最近的两块只差 0.05 mm 以及量它的是哪两段。想把这个数
变成「先连哪两块」，缺的就是一次按网的铜的几何盘点。

同一块板上，DRC 的 115 条按网分开是这样（`board_drc` 的 `unconnected` 里，
按条目描述里的网名归并，跨网的两条各算半条）：

| 网 | 条数 |
|---|---|
| `+3V3` | 38 |
| `GND` | 15 |
| `AGND` | 9 |
| `$1I8749/$2N1188` | 6 |
| `$1I8749/VDDA` | 5 |

`+3V3` 一个网就占了三分之一，而它在这块板上**没有一根走线**——全是 14 块铺铜
碎片和 7 个焊盘。这就是为什么工具必须把铺铜算进「这一网的铜」：`_items` 只给
焊盘/走线/过孔，铺过铜的板子上最大的那块铜正好不在里面。

## 2. 算法

六步，全部只读：

1. **收集**：`_net_copper` 取 `_items(board)` 里该网的全部条目，再把该网每个
   zone 的每个 `filled_polygon` 作为一条 `kind="zone"` 的条目加进来，`ref` 写成
   `zone6.piece5` 这样可命名的形式（zone 序号 + 片段序号）。
2. **降成段**：走线是**一条**段 + 半宽；多边形是它的**边** + 零半宽。这样距离是
   精确的：圆头走线就是「到中心线距离 ≤ w/2 的点集」，所以两条走线相碰等价于
   中心线距离 ≤ 两个半宽之和；走线碰到多边形等价于中心线离边界 ≤ w/2 或某个端点
   在多边形内。两条多边形边界之间的距离就是段-段最小，用格子把它变成本地运算，
   而不是拿 20 168 个顶点的铺铜去和 3 000 条走线做 O(N·M)。
3. **并查集**：两段落在同一格（各自按半宽膨胀过的包围盒）且共享至少一层铜、
   且段距 ≤ 半宽和 + 1e-6，就并。**同网铜全部参战**——这正是与其它工具相反的
   地方：`board_teardrop_room` 要把同网铜排除（泪滴就长在自己的铜上），这里必须
   包含（同一网的铜就是同一个导体的候选）。
4. **包含**：多边形内部不会有边界相交（过孔压在铺铜里、焊盘被 solid 连接的
   铺铜整块盖住），所以每个段的端点还要对**包围盒覆盖它的那些多边形**做一次
   点在多边形内。为了不做 20 168 顶点 × 全部端点的乘法，多边形按 y 分带建索引
   （`_poly_bands`）：射线法本来只测跨过查询点 y 的那些边，分带之后结果与全扫
   逐位相同，代价与顶点数无关。
5. **组间距**：两块之间的最小距离从**小的那块**往外找，只走到 `gap_limit_mm`；
   找到就报精确最小值与那对段，找不到就诚实地说「不在这个半径内」。
6. **产出**：每块的焊盘数/位号/走线/过孔/铺铜片段数/包围盒，以及按 `gap_mm`
   升序的相邻对（含 `on` 层、两侧的 `ref` 与线段坐标）。

## 3. 真板读数

`+3V3`（`limit` 够大时全量）：

| 项 | 值 |
|---|---|
| 块数 | **39** |
| `edges_needed` | **38** |
| 相邻对总数（`gap_limit_mm=5`） | 61 |
| 最近 | **0.05 mm**（`SW2.1` ↔ `zone8.piece0`） |
| ≤ 0.2 mm 的对 | 2 |
| ≤ 0.5 mm 的对 | 3 |
| 5 mm 内没有邻居的块 | 8（`2/3/16/25/26/27/35/37`） |
| 单焊盘块 | 37 / 39 |
| 耗时 | **0.55 s** |

39 块里 38 块是「1 个焊盘 + 1 块铺铜碎片」，剩下那一块是 7 个焊盘 + 1 块铺铜。
换句话说 `+3V3` 的 38 条 unconnected 不是「一条主干没走完」，而是**每一个去耦
电容的 +3V3 脚各自守着一块孤岛**——这决定了下一步该做的不是补一根长线，而是
先让这些孤岛各自连到主干（或者干脆别铺这种碎铜）。

全板（不给 `net`）：**104 条 `edges_needed`、120 个网、33 块铺铜片段计入**，
总耗时 **1.65 s**。

`GND`：5 块、4 条、最近 0.06 mm。

## 4. 与 DRC 的对照——以及那一处不等

`edges_needed = 块数 − 1` 应当等于该网的 DRC unconnected 条数。实测：

| 网 | 本工具 | DRC | |
|---|---|---|---|
| `+3V3` | 38 | 38 | ✓ |
| `AGND` | 9 | 9 | ✓ |
| `$1I8749/$2N1188` | 6 | 6 | ✓ |
| `$1I8749/VDDA` | 5 | 5 | ✓ |
| `$1I8749/$2N1197` | 2 | 2 | ✓ |
| `$1N4415` | 2 | 2 | ✓ |
| **`GND`** | **4** | **15** | ✗ |

GND 那 11 条差额有明确机制：这块板 F.Cu 的 GND 铺铜碎成 15 块，每块都压着
1 个 GND 焊盘（`C14.1` 到 `C23.2`、`D2.2`…`D8.2`、`X1.2`），而主铺铜
（`zone6.piece5`，20 168 个顶点、1857.6 mm²）也压着其中若干焊盘。**一个焊盘同时
被主铺铜和碎岛的热焊盘辐条咬住，在我这里是「通过焊盘连成一个导体」，在 KiCad 的
连通性引擎里不算。** 我按几何读，KiCad 按它自己的连通图读，两边都自洽。

因此口径写死：**过不过板子听 `board_drc`；这个工具回答的是「在哪、差多远」。**
这条不进判词，只进 `assumptions.cross_check`，把那六个网的相等与 GND 的不等
一起印在读数里——把「不一致」藏起来比读错更糟。

## 5. 四处设计上的取舍

1. **铺铜默认算铜（`pours_connect=true`）**。这与其他四个板级工具相反——它们默认
   铺铜不挡（灌铜会绕开新增铜重切）。理由不同：那里问的是「加铜会不会违规」，
   这里问的是「现有的铜算不算这个网的一部分」。`pours_connect=false` 问的是另一句
   话：「如果把这些铺铜去掉，这个网还剩几块」。
2. **铺铜只在有 filled_polygon 时算铜**。`add_zone` 只写外框，KiCad 要跑一次
   填充才有 `filled_polygon`。没填的 zone 一个铜都不贡献，此时该网会被**少算**，
   这一点写进 `precision` 而不是偷偷拿外框顶上（`board_pour_connectivity` 才会
   退回外框，并在字段里说明）。
3. **空隙量在段上，不编一个「最近点」**。`a.seg`/`b.seg` 是最近的那一对**线段**；
   两个斜段之间的最近点对要另写一个求解器，而线段的坐标已经足够让人看到位置。
   字段名与 `precision` 都写明是段。
4. **超过 `gap_limit_mm` 只计数不测量**。`pairs_beyond_limit` 给出上限一侧的数量，
   `pieces_with_no_neighbour_within_limit` 点名那些孤立的块。不为了「都量出来」
   去把全板两两块互算（`+3V3` 的 39 块就是 741 对）。

## 6. 没有做的事

- **不连线、不换层、不挪件**。它给的是两块的间距与位置，接不接、从哪层接、
  接多宽，都还是人的决定；这也是这个仓库对自动布线的禁令的延续。
- **不判死铜**。哪块铜该删去问 `board_pour_audit`（它按本网焊盘与过孔数判），
  这里只报块。
- **不跟 KiCad 的连通图对齐**（见 §4）。要对齐就得把热焊盘辐条、岛删除模式、
  `connect_pads` 三种模式全套模拟一遍，那是另一个量级的活，而 DRC 已经把答案给了。
- **不数丝印/阻焊/禁布**。它们是层，不是铜。

## 7. 判据与对照

`tests/test_net_gaps.py` 16 条，每条主判都有「只改一件事、答案必须翻」的对照：

| 说法 | 对照 |
|---|---|
| 两个同网焊盘是两块、间距 = 金属到金属 | 加一根走线 → 1 块 0 个间距 |
| 走线差 0.15 mm 不到焊盘就不算连 | 再多 0.2 mm（铜压到焊盘上）→ 1 块 |
| 两块铜靠过孔连成一块（双面网） | 少一个过孔 → 2 块，B.Cu 那半挂着 |
| 焊盘整块在自己的铺铜里也是同一个导体 | 焊盘改别的网 → 两个网各 1 块、互不吞并 |
| `pours_connect=false` 不算铺铜 | 同一块板 `pours_counted_as_copper` 从 1 变 0 |
| 超过 `gap_limit_mm` 只计数 | 同一块板把 `gap_limit_mm` 放宽 → 量出来 19.0 mm |
| 不给 `net` 时按断得多排序 | 三焊盘的网排在两焊盘的网前面 |
| 写盘为零 | 文件 sha256 前后相同 |
