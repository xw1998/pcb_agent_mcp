# 熔断沿长度的一维梯度

> 0.0.59。`fusing_current` 回答「一段等宽铜在 t 秒内熔断要多少电流」，并且把空间
> 整个删掉了 —— 它的 `assumptions.spatial` 原文是 `one temperature for the whole trace
> cross-section and length`。真实板子上会熔断的位置恰恰**不是等宽**的：保险丝颈、过孔
> 扇出瓶颈、进焊盘前收窄的那一段。同一套物理，第二条曲线：`fusing_current_taper`。
> 本文记录它的离散、三个算术锚点、一条 8.5 K 之外的旧纪律（数值先量后写）、以及
> **两个方向相反的误差**为什么必须同时写进信封。

## 62.1 为什么不能给 `fusing_current` 加一个 `width_mm` 列表

锥形几何用单一宽度表达不了，这不是参数名问题：

* 温度沿长度有剖面，熔点在**某一段**某一点，答案是一个**位置**而不只是一个时间；
* 两侧的铜既是热源（同样的电流密度，更大的截面积 ⇒ 更小的 I²R 密度，但总量更大）
  又是散热器（轴向导热），`fusing_current` 里那项被**明确删掉**的东西（"adiabatic"）
  在这里必须拿回来，否则「颈比臂先熔」这句话只能靠猜；
* 「熔在哪」这个输出是新的一维信息，塞进旧工具的输出结构里会让旧字段的含义漂移。

所以：新工具、新工具数（164 → **165**），`fusing_current` 一行未改。

## 62.2 模型与离散

节点 = 每个轴向段的中心，段内等温（横截面一个温度，长度方向集总到一个点）：

```
C_i dT_i/dt = I² R_i(T_i) + Σ_j G_ij (T_j - T_i)   (+ G_end (T_end - T_i))

C_i   = ρ_m·c_p·A_i·L_i                        J/K
R_i   = ρ(T_i)·L_i / A_i                       Ω
G_ij  = 1 / ( L_i/(2·k·A_i) + L_j/(2·k·A_j) )    W/K   （两个半段串联）
ρ(T)  = ρ20·(1 + α·(T - 20))                   α = 1/254（铜的 234 定律）
```

`ends_c` 给了就两端固定在那个温度，`G_end = 2kA/L`（半个段到端子的铜）；不给就是绝热端
（**热出不去**，稳态对任何正电流都不存在，这一点在输出里明说而不是给个假阈值）。

ρ 对 T 是**线性**的，所以源项是 `a_i + b_i T`：

```
a_i = I²·L_i/A_i·ρ20·(1 - α·20)     b_i = I²·L_i/A_i·ρ20·α
```

整个系统因此保持三对角，后向 Euler + Thomas **每步精确解** —— 没有迭代、没有收敛判据、
没有"改动量小于 tol 就算收敛"这种可以被刚性耦合骗过的东西（`61` 里那条 8.5 K 的静默错答案
就是被它骗出来的，这里的结构从根上不给它机会）。

熔断判定：某节点在本步跨越 `melt_c` 时按温度在步内**线性插值**给出 `t_melt` 与位置；
两个熔断时间（真实那个与对照那个）都只精确到 `dt_s`，输出里如实写 `time_resolution_s`。

## 62.3 均匀段是算术锚点：三个口径一起对

等宽 + 绝热端 ⇒ 所有邻居相同 ⇒ **每一对传导项精确抵消**，系统退化成集总绝热 ODE：

```
t = ρ_m·c_p·A² / (I²·ρ20·α) · ln( (1+α(Tm-20)) / (1+α(Ta-20)) )
```

于是有三条互相独立的检查（`tests/test_fusing_taper.py` 41 例里的前 5 条）：

| 口径 | 结果 |
|---|---|
| 对解析绝热式（`I = 20.21 A`，2 mm × 35 µm，Ta=25） | 0.993269 s，**−0.0614 %**（dt = 1.5/2000） |
| 对 Onderdonk 闭式（同一电流 ⇒ 1.000000 s） | **−0.6731 %** |
| 分段数 1 / 2 / 5 / 10 / 40 | 全部 **0.993269**，差 < 1e-9 |
| 均匀段的剖面 | 温度**极差 0.0**（不是"很小"，是精确 0） |
| 均匀段的 `conduction_delay_pct` | **0.0**（精确，不是"接近 0"） |

最后两行是负控制：如果"传导延后"是个常数、或者被塞了个 3 % 的修正，这两条会立刻红。

## 62.4 那 0.31 % 残差是什么，为什么不去拟合掉

解析式与 Onderdonk 之间的差**不在时间上，在电流上**：把它反解成电流，

```
I_解析(1 s) = 20.1481 A    Onderdonk(1 s) = 20.21 A   残差 = 0.306 %
```

原因是可以点名的一条算术：Onderdonk 的 **33** 把密度、比热、20 °C 电阻率折成了一个常数，
而本模型用的是今天的 ρ_m = 8960、c_p = 385、ρ20 = 1.72e-8。由它们推出来的等价值是
**33.21**，不是 33（`33·ln10 = 75.985` 对 `ρ_m c_p/(ρ20 α)·(1 cmil)² = 76.46`）。
时间对电流是平方反比，所以 0.31 % 的电流残差在时间上是 0.63 %。

**处理方式就是不去处理**：工具算自己的物理，不拟合 1928 年的常数，差距写进测试和本文。
如果以后有人动了 ρ_m / c_p / ρ20 里的任何一个，`test_agrees_with_onderdonk_and_the_residue_is_measured`
会指出是哪个数动了 —— 这比"调平到 1e-12"更能保住信息。

dt 收敛（一阶，误差从下方逼近解析值）：

| dt | t_melt | 对解析 |
|---|---|---|
| 1.5/200 | 0.987759 | −0.6158 % |
| 1.5/500 | 0.991436 | −0.2459 % |
| 1.5/1000 | 0.992659 | −0.1228 % |
| 1.5/2000 | 0.993269 | −0.0614 % |
| 1.5/4000 | 0.993575 | −0.0306 % |
| 1.5/8000 | 0.993727 | −0.0153 % |

## 62.5 颈部：熔在窄段，且比"同平均宽的均匀段"早一个数量级

几何：臂 20 mm × 2 mm，颈 2 mm（宽见下表），总长 42 mm，35 µm，30 A，窗 1 s。

| 颈宽 | t_melt | 熔点 | 对照（传导关） | `conduction_delay_pct` |
|---|---|---|---|---|
| 2.00 mm（= 臂宽） | 0.450642 | 21.0 mm | 0.450642 | **0.000 %**（精确） |
| 1.00 mm | 0.234030 | 21.0 mm | 0.112355 | **+108.295 %** |
| 0.50 mm | 0.039764 | 21.0 mm | 0.027780 | **+43.137 %** |
| 0.25 mm | 0.007593 | 21.0 mm | 0.006627 | **+14.584 %** |

同电流、同长度、宽取**平均**（1.9286 mm）的均匀段：**0.419000 s** —— 颈那段早了 **10.5 倍**。
这就是"给一个宽度"永远说不出来的东西。

`conduction_delay_pct` **不是单调的**（108 % → 43 % → 15 %）：颈越窄熔得越快，留给两侧铜
把热搬回来的时间越少。这个不单调是真实现象，不是噪声，本文登记它以阻止后来者"修平"它。

## 62.6 传导的收益是量出来的，不是断言的

`adiabatic_control` 是真的再跑一遍（`k_thermal_w_mk = 0`、端绝热），不是解析估计：

* 先看 `test_switching_conduction_off_reproduces_the_control_arm`：把 `k_thermal_w_mk` 设 0 的
  正跑，与信封里那个对照臂**逐位相同**（6 位小数）。这证明对照臂真的没有传导，不是少算了一点。
* 均匀段 ⇒ 延后 **精确 0**（邻居相同，传导项抵消），见 §62.3。
* 两端固定（`ends_c=25`）⇒ 100 mm 均匀段 20.21 A 的熔断时间 0.993269 → **1.007784 s**，
  延后 +1.461 %。**这个数小得反常但正确**：0.1 m 长、2 mm 宽、35 µm 厚的铜，沿长度的
  导热只有 `2kA/L ≈ 5.6e-4 W/K`，热根本来不及走到端子。

## 62.7 反解：同一条曲线反着读

给 `t_melt_s` 反解电流，做法是**对电流二分**（对数刻度），下界取**最窄段的绝热电流**
（`_taper_adiabatic_current`）——传导只会把热从颈部搬走，所以真实电流一定在它上面，这个
下界不是调出来的，是推出来的：

| 目标 | 反解电流 | 绝热下界 | 下界/解 |
|---|---|---|---|
| 0.02 s | 39.085049 A | 35.617071 | 0.911 |
| 0.05 s | 27.861327 A | 22.526214 | 0.809 |
| 0.10 s | 23.093069 A | 15.928438 | 0.690 |
| 0.30 s | 19.168011 A | 9.196288 | 0.480 |

来回一次（反解 → 正跑）的相对偏差 **−6.5e-4 / −4.6e-4 / −2.0e-4 / −2.2e-4**，量级就是 dt。
越往上界越紧（颈越窄、越快熔，铜越没时间帮忙），所以"下界/解"这一列随目标变短而趋 1 ——
它自己的形状就是一条可校验的物理读数。

## 62.8 `ends_c`：稳态阈值只在两端有温度时存在

100 mm × 2 mm × 35 µm，两端 25 °C：

* 稳态阈值 **3.049725 A**（把这个电流代回稳态线性系统，峰值 = **1083.0017 °C**，1 K 内命中）；
* 同一个几何的 1 s 熔断电流是 20.21 A ⇒ 阈值只有它的 **15 %**；
* 不给 `ends_c` ⇒ `steady_threshold_a = null`，理由写死：「绝热端没有任何东西把热搬走，
  稳态对任何正电流都不存在」（这是回答，不是缺失）。

这个阈值低得让人不舒服，但它是正确的物理：一块 0.1 m 长的薄铜只有自己的两端当散热器，
`2kA/L = 5.6e-4 W/K` 是个极差的散热器。真实板子侧向散热（对流、板、平面、焊料）比它强
几个量级 —— 这也正是 §62.10 里"删掉侧向散热"这条误差必须写在精度栏里的原因。

## 62.9 不熔就是不给数

`current_a = 2 A, t_end_s = 1 s`：

* `melted: false`
* `value: null`、`unit: "s"`、`t_melt_s: null`、`melt_at_mm: null`
* `peak_c: 29.1838`、`margin_to_melt_k: 1053.82`

**不给**「请输入更大电流」以外的任何数字，也**不**把窗前那点温升当成熔断时间。5 A / 10 s
同理（471.2996 °C，余量 611.70 K）。这条就是「宁可报错不给错答案」在"没熔"这种**非错误**
结果上的版本：它不是错误，所以仍然是 `status: ok`，但答案里没有一个时间。

## 62.10 边界：两个方向相反的误差

| 删掉的东西 | 误差方向 | 什么几何下赢 |
|---|---|---|
| 侧向散热（对流、板、平面、焊料）—— 只有轴向传导 | 电流**偏低**（真实能熔更多） | 宽而短的颈（侧向面积大） |
| 段内等温（无横向梯度）—— 窄颈边缘真实更热 | 电流**偏高** | 细颈、大宽厚比 |
| 潜热不算（熔点是"到点"，不是"化完"） | 电流**偏高** | 长脉冲 |
| 恒定电流波形（等 RMS 的脉冲不等价） | —— | 短脉冲 |

所以 `precision` 字段里写的是 **OPPOSITE**（两个方向相反），并且明说"哪个赢取决于宽厚比，
不给一个统一的符号"。这是本工具与 `fusing_current`（四个误差全朝一个方向）在措辞上必须
分开的地方。

还没做的（写进 `not_implemented_yet`）：侧向散热（这个模型**没有 h 这个参数**）、横向梯度、
潜热、skin effect 短脉冲、电迁移、开断后的电弧/等离子体。

## 62.11 拒绝清单（17 条，全部带 `reason_code`）

`segments` 空 / 非 list / 元素不是对象 / 缺 `length_mm` 或 `width_mm`（`ARG_INVALID`）；
`length_mm ≤ 0`、`width_mm ≤ 0`、厚度 ≤ 0、`alpha_per_k ≤ 0`、`k_thermal_w_mk < 0`、
`t_end_s ≤ 0`、`dt_s ≤ 0`、步数超 `max_steps`、`t_ambient_c ≤ -234`、`melt_c ≤ t_ambient_c`、
`ends_c ≥ melt_c`（`ARG_RANGE`）；`ends_c` 非数值（`ARG_INVALID`）；
`current_a` 与 `t_melt_s` **同时给**或**都不给**（`ARG_REQUIRED`）。

其中 `alpha_per_k ≤ 0` 的理由是结构性的而不是保守：没有电阻率上升就没有失控，这个模型
就没有可解的熔断判据，所以拒绝而不是"当成 alpha=0 继续算"。
