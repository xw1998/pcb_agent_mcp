# 负载跳变要的是曲线：时域 droop 与 |Z(f)| 是两个问题

日期：2026-11-01　工具：`pdn_step_response(...)`（`calc/power.py` 新增，纯 stdlib）

`pdn_impedance` 回答的是「有没有难看的频点」。而 datasheet 上那行 load transient
要的是另一件事：**负载跳了，轨掉多深、什么时候掉、多久回来**。

这两件事**不可互换**，而且不可互换的方式很具体：一条在带内 |Z| 很平的轨，遇到
一个阶跃照样会先掉 `I*ESR`——那是电阻，不是电抗，频域里它就是一条水平的 |Z|，
看不出「难看」。反过来，|Z| 在某个频点有个尖峰，如果负载从不到那个速度，那个尖峰
一辈子不会出现在曲线上。

所以这是一个**新工具，不是给 `pdn_impedance` 加一个开关**：时域要 `rise_ns`、要
调节器模型、要返回波形，与频域的输入表不是同一张。工具数棘轮 169 → **170**
（`tests/test_vibration_mass_copper.py` 里就地写了理由）。

---

## 1 判据

**在同一张网络上做时域积分，答案必须落在四个有闭式解的锚上，而且两条内建恒等式
必须闭合。**

1. **一阶网络**：两端由两个不同的电阻决定（`R_series` 与 `R_series‖ESR`），
   中间是指数为 1 的衰减（§3.1）；
2. **DC 尾**：`-I_final*(R_series+plane_r)`——任何漂移的积分器或写错符号的伴随
   模型都会在这里露出来（§3.2）；
3. **纯电容是斜坡**：后向欧拉对纯电容**精确**，所以这条能分辨「方法误差」和
   「实现错」（§3.3）；
4. **LC 环的周期是 `2π√(LC)`**：ESR 是唯一阻尼，所以这条同时检验 L 与 C 的量纲
   和符号（§3.4）；
5. **换一个求解器**：同一网络丢给 ngspice，逐点对表（§4）。

第 5 条是这轮唯一**不是自己验自己**的证据。前四条都在同一个伴随模型里，
如果那个模型的符号整体写反，四条锚可能一起「通过」。

---

## 2 模型

### 2.1 拓扑（固定，1 或 2 个未知节点）

```
ref --[R_series, L_series]--+--[plane R, plane L]--+-- die   <-- 负载（电流沉）
                             |                     |
                         bulk caps              die caps
```

- `caps` 每项 `{c_farad, esr_ohm, esl_h, count, at:"die"|"bulk"}`；同参数并联按
  `C*n / ESR/n / ESL/n` 合并成一组再建支路（`count` 与「把同一条列 n 遍」逐位相同，
  §5）。
- 调节器是 **Thevenin**（`r_series_ohm` + 可选 `vr_series_h`）。
- 负载是**电流沉**：`I(t) = preload_a + step_a*min(t/rise, 1)`。

**平面永远在路径上。** 没有 `at="bulk"` 的电容时没有第二个节点可放它，但负载电流
照样要穿过它，所以它被**并进调节器支路**（串联求和，拓扑等价）。这条是本轮修掉的
一个真缺陷（§6.1）：修之前 `plane_r_ohm=0.002` 在单节点情形下被**静默忽略**，
同一块板报 −10.00 mV 而真值是 −30.00 mV。

### 2.2 伴随（companion）模型

每条支路是串联 R-L-C，方向 `a→b`，电流 `i`：

```
g     = 1/(R + L/h + h/C)        # 无 C 时去掉 h/C
i_n   = g*(v_a - v_b) + i_src
i_src = (L/h)*g*i_prev - g*u_prev
u_n   = u_prev + (h/C)*i_n
```

KCL 装配：`a` 存在则 `G[a][a] += g`；`b` 存在则 `G[b][b] += g`、`G[a][b] -= g`、
`G[b][a] -= g`；`j[a] -= i_src`、`j[b] += i_src`；负载 `j[die] -= i_load`。
**地面用 `None` 表示，不进系统**——这是「ref」那一端，它不是一个需要解的电压。

### 2.3 后向欧拉，不是梯形法

BE 是 L-stable，但它**耗散**：振铃会比物理更快衰减。这是**单向、可量化的**偏差
（Q 是下界），而梯形法要额外维护 `di/dt` 的历史、符号风险大得多。

所以 `refine=True` 会把整段在 `h/2` 上重跑一遍，报 `h_refine_peak_delta_pct`：
**峰值是不是网格的产物，变成了一个读数**，超过 5% 就挂 warning 直说峰值不是测量。

### 2.4 自适应网格

`h_first = min(各支路自然周期, 各 rc)/40`，每步 ×1.02，封顶
`h_last = t_stop/samples`。理由是一条硬数字：`100 µF + 25 ns` 的自然步长铺满
10 ms 要 **400000** 步，而自适应网格在同一个窗口只走 **1444** 步（§8）。
1 nH 的 ESL 振铃与 1 ms 的 bulk 恢复必须在同一张网格上分辨，均匀网格只能二选一。

### 2.5 为什么**没有**单独的 slew 旋钮

串联电感本身就是 `dI/dt = Δv/L` 的物理限流。再加一个「VRM 电流斜率」参数，就是把
同一个数写两遍，而且两遍会互相矛盾。`rise_ns` 描述的是**负载**的边沿，那是外生量。

### 2.6 初值 = `preload_a` 的 DC 解

电容开路（`i=0`、`u` 取所在母线电压），电感支路电流 `= preload`，
`v0[die] = -preload*r_path`、`v0[bulk] = -preload*r_series`。

这条决定了 `v_initial_v` 的**语义**：它是**台阶前**的状态，不是 `t=0+`。单调 droop
的 `t_peak_s` 也就是窗口末端（最小值在那里）。两件事都写进 `precision`，因为
「`v_initial_v` 应该是 `-I(R‖ESR)`」是一个很容易犯、而且看起来很像对的误读。

## 3 四个闭式锚

### 3.1 一阶：`1 Ω` + `1 µF` 串 `10 mΩ`，`1 A`

```
r_par = R_s*ESR/(R_s+ESR) = 0.00990099
tau   = C*(R_s+ESR)       = 1.01e-06          <-- 不是 C*(R_s‖ESR)
v(t)  = -I*[R_s - (R_s - r_par)*e^{-t/tau}]
```

`R_s‖ESR` 只决定**起点**（`t=0+` 电容经自己的 ESR 短路），速度由真正给电容充电的
那个回路决定，也就是串联和 `C(R_s+ESR)`。

| t | 实测 | 闭式 | 差 |
|---|---|---|---|
| 101 ns（0.1τ） | −0.104065555 | −0.104121368 | 0.054 % |
| 1.01 µs（1τ） | −0.634964039 | −0.635762929 | 0.126 % |
| 5.05 µs（5τ） | −0.993247827 | −0.993328765 | 0.008 % |
| 20 µs | −0.999999997 | −1.0 | 3e-9 |

`dc_check_rel = 2.6e-9`、`charge_balance_rel = 2.8e-14`、
`settle_time_s = 4.65109e-06`、`steps = 4104`、`h_first = 0.25 ns`。

**这条锚在本轮抓到的不是代码错，是测试错**：我最初把 `tau` 写成 `C(R_s‖ESR)`，
于是断言在 1 µs 期望 −0.6358 而实测 −0.6313 —— 差 0.7 %，看起来像后向欧拉的一阶
误差，其实是闭式错了 10 倍。教训写在 `tests/test_pdn_step.py` 里：
**闭式和实现同时可疑时，先算一遍解析解的两个端点**（`t=0` → `-I·r_par`、
`t→∞` → `-I·R_s`），两端都对而中间差 10 倍，错的只能是时间常数。

### 3.2 DC 尾：`100 µF / 10 mΩ / 20 mΩ` 稳压器，`2 A`

| 量 | 值 |
|---|---|
| `v_final_v` | −0.039999954（`-I*R = -0.04`） |
| `dc_check_rel` | 1.16199e-06 |
| `charge_balance_rel` | 7.62331e-15 |
| `settle_time_s` | 1.26657e-05（窗口 40 µs） |
| `steps` | 1203 |
| `vrm_di_dt_a_per_us` | 27.1074 |

**电荷恒等式**：`Σ(-C·Δu)` 对上 `∫(I_load - i_vrm)dt`。这条只有在两个前提下才闭合：

1. 电容**电压下降是放出电荷**，状态项是 `-C·Δu`（写成 `+C·Δu` 给 1.99，看起来像
   漏了一半电荷）；
2. 求和**必须用右端点**——BE 的状态更新本身就是右端点。用梯形法只能闭合到
   **0.7 %**，那 0.7 % 全是「方法不同」的假象，会让这条闸门失去分辨力。

改对之后闭合到 **7.6e-15**，也就是双精度噪声。

### 3.3 纯电容是斜坡：`1 µF / 50 mΩ`，`1 A` / `50 ns` 边沿，窗口 1 µs

`v(t) = ESR*I(t) + q(t)/C`，`q = ∫I`。窗口内一共 1 µs，远不到稳态。

| t | 实测 | 闭式 |
|---|---|---|
| 25 ns | −0.031458331 | −0.03125 |
| 50 ns（边沿结束） | −0.075416661 | −0.075 |
| 100 ns | −0.125416654 | −0.125 |
| 1000 ns | −1.025416090 | −1.025 |

后向欧拉对纯电容**精确**（斜坡对 BE 是精确解），所以这里 0.04 %～0.7 % 的偏离全部
来自「右端点求和在一个凸斜坡上略高」，不是积分格式的阶数问题。

这一格的 `dc_check_rel = 0.999999`、`tail_settled = False` 是**正确读数**：
`r_series = 1 MΩ` 时 DC 答案本身是 −1e6 V，窗口 1 µs 当然没到。
`dc_check_rel` 不是「错」，它是「离 DC 多远」。

### 3.4 LC 环：`1 µF` / `0 ESR` / `50 mΩ` + `10 nH` 稳压器电感

```
T = 2π√(LC) = 628.32 ns
```

| 量 | 实测 |
|---|---|
| 过 `v_final` 的零点 | 77.06 / 403.63 / 730.18 / 1056.67 ns |
| 由 3 个半周期反推的周期 | 653.07 ns（vs 628.32，+3.94 %） |
| 峰值 | −0.110376434 @ 212.5 ns |
| `v_final_v` | −0.050006599 |
| `undershoot_v` | **0.060376434**（> `\|v_final\|`） |
| `h_refine_peak_delta_pct` | 0.0538 |

`undershoot > |v_final|` 是这条锚的重点：`ζ = (R/2)√(C/L) = 0.25`，首摆会**冲过**
DC 答案再回来。一个只会「单调掉到底」的模型会在这里给 `undershoot = 0`，
而它是 0.0604 V。

周期偏高 3.9 % 的原因是过零点的判读——`rise_ns = 50` 的负载边沿把第一个半周期
拉长了（边沿本身就是 50 ns，占了 1/4 周期的 1/3）。这条用「3 个半周期」而不是
「相邻两个过零点」就是为了把这个偏差摊薄。

三副 deck 在 `docs/samples/pdn_step/`（可以直接 `ngspice -b` 跑，说明在

**一阶**（§3.1 同一网络）：

| t | 本工具 | ngspice | 相对 |
|---|---|---|---|
| 1 ns | −0.010880673 | −0.010880297 | 0.0035 % |
| 100 ns | −0.103179482 | −0.103233044 | 0.052 % |
| 1.01 µs | −0.634964039 | −0.635762950 | 0.126 % |
| 20 µs | −0.999999997 | −1.000000000 | <0.0001 % |

**LC 环**（§3.4）：峰值 −0.110376 vs −0.111801（低 1.27 %）、尾部 −0.050007 vs
−0.049999。

**bulk 在板子另一端**（§5 的 `at="bulk"` 那格）：峰值 −0.052937 vs −0.053159
（低 0.42 %）、尾部两边都是 −0.030000。

峰值**一律偏低**，方向与 §2.3 说的一致（后向欧拉的数值阻尼）。

三副 deck 都是线性的（无半导体、无温漂、无容值随偏压变化）。

## 5 负控制（23 条，每条都能失败）

`tests/test_pdn_step.py`：

| 若这项失败说明什么 | 判据 |
|---|---|
| 时间常数写错 | 一阶三点对上闭式（`C(R_s+ESR)`），且 1τ 处已走完 62–65 % 的缺口 |
| 积分器漂了 / 伴随符号错 | DC 尾落在 `-I_final*(R_s+plane_r)`，`dc_check_rel < 1e-4` |
| 某条支路没进节点方程 | 电荷恒等式 `<1e-9`（实测 7.6e-15） |
| 理想阶跃进电感被给了个数 | 有 L 无 `rise_ns` ⇒ `ARG_REQUIRED` 且 message 含 `rise_ns`；同一网络给 `rise_ns` 就有答案 |
| 慢边沿没有更浅 | `rise 2000 ns` 的峰值与 `vrm_di_dt` 都小于 `rise 100 ns` |
| L 或 C 的量纲/符号错 | LC 环 3 个半周期对上 `2π√(LC)`（5 %） |
| 振铃被抹成单调 droop | `undershoot_v > \|v_final_v\|` |
| 平面在单节点情形被丢掉 | 无 plane 给 −10.00 mV、2 mΩ plane 给 −30.00 mV，且两者 `nodes` 相同 |
| 摆位被算进 DC 尾（错的方向） | `at="die"` 与 `at="bulk"` 的 `v_final` 都是 −30.00 mV |
| 摆位没被算进峰值 | bulk 峰值 > die 峰值 × 1.4（实测 1.63×） |
| `count` 不是并联 | `count=3` 与列三遍 `peak/v_final` 差 <1e-15 |
| 负阶跃方向反了 | `preload 2 A / step −2 A`：`v_initial = −0.04`、`v_final → 0`、轨**上升** |
| 0 V 尾巴让 settle 退化 | 同上，`0 < settle < t_stop`（终值 0 V 时相对带宽必须是死数） |
| 无电容 / 零阶跃 / 零容值 / 未知 `at` | 各自 `ARG_REQUIRED` / `ARG_INVALID`，message 点名（`"middle"` 出现） |
| 电压源直连被当成测量 | `r_series = vr_series_h = plane_r = plane_l = 0` ⇒ `ARG_INVALID`，message 含 `ideal source` |
| bulk 电容但没有路径 | `at="bulk"` + `plane_r = plane_l = 0` ⇒ `ARG_INVALID` |
| 标量越界被静默钳位 | `samples=10 / settle_band_pct=0 / rise_ns=-1 / t_stop_ns=-1 / r_series_ohm=-1` 全部报错，`reason_code ∈ {ARG_RANGE, ARG_INVALID}` |
| 步数预算被静默放过 | `samples=500000` ⇒ `TOO_LARGE`（不是偷偷粗化网格） |
| 工具没注册或参数没透传 | `TOOLS["pdn_step_response"]` 存在、12+1 个属性、`required == ["caps"]` |
| 读数不在信封里 | `unit == "V"`、`model == STEP_MODEL`、`basis` 含 `backward Euler` |
| 边界没写出来 | `not_computed` 里必须有 `"regulator LOOP"` |
| 波形长度或终点不对 | `t_s[0] == 0`、`len(t_s) == len(v_rail_v)`、`t_s[-1] ≈ t_stop` |

## 6 本轮修掉的真缺陷

### 6.1 平面在单节点情形被静默忽略（**改变答案**）

`at` 默认是 `"die"`。全部电容都在 die 时只有一个未知节点，`plane_r_ohm` /
`plane_l_h` 原本只加在「bulk → die」那条支路上——于是**整对参数被丢掉，一个 warning
都没有**。同一块 2 mΩ 板，工具报 −10.00 mV，真值 −30.00 mV。

修法不是加警告，是**把平面并进调节器支路**（串联求和，拓扑等价）。修之后：

| | 峰值 | DC 尾 | 节点 |
|---|---|---|---|
| `at="die"` | −0.032524503 | −0.030000 | 1 |
| `at="bulk"` | −0.052936594 | −0.030000 | 2 |

这张表比修之前**更强**，因为它说清了时域到底买到了什么：**摆位进的不是 DC 尾**
（DC 时电容开路，电流横竖要过那块板），**而是峰值**。频域工具只能看到 |Z| 的一处
凸起，看不出「同一个 DC 答案，峰值差 1.63 倍」。

### 6.2 理想阶跃进电感（**拒绝，不给数**）

`V = L·dI/dt` 在理想阶跃下由时间步决定。实测：`h = 0.25 ns`、`20 A` ⇒ 16 V，
`h_refine_peak_delta_pct = 100 %`——一个只在网格上存在的答案。现在有电感（任何
`esl_h` / `vr_series_h` / `plane_l_h`）而没有 `rise_ns`，直接 `ARG_REQUIRED`，
message 里把这个式子写出来。

### 6.3 0 V 尾巴让 `settle_time_s` 退化

载荷释放（`step` 为负）时终值是 0 V，`tol = band/100*|dc_expected|` = 0，永不触发。
改成 `scale = max(|dc_expected|, |peak - v_initial|)`：尺子跟着这条曲线自己的尺寸走。

### 6.4 `5%%` 直接印在 `precision` 里

那句是普通字符串拼接，不是 `%` 格式化，所以 `%%` 没有被还原成 `%`。用户看到的是
`above 5%% the peak is not a measurement`。已改。

## 7 本轮**没有**证明什么

1. **调节器的控制律不在里面。** VRM 是 Thevenin：没有环路带宽、没有相位裕度、
   没有限流、没有多轨之间的 droop 分摊。所以「这条轨在这里通过」不代表它在
   真实环路上不会因为环路自己引起的振荡而挂掉。这句话写在 `not_computed` 第一条。
2. **板是一到两个集中节点，不是分布平面。** 平面内的扩展是 `board_ir_drop` /
   `pdn_plane_impedance` 的事，这里只把它们合成一个 R + L。
3. **die/封装电感与片上电容没有。**
4. **电容的 DC bias / 温度 / 老化降额没有。** 给的 `c_farad` 就当它在工作点上。
   实际陶瓷电容在标称电压下可能只剩一半——**这个降额要用户自己先算**。
5. **只有单台阶**（可带边沿）。任何其他波形都在范围外。
6. **后向欧拉的阻尼让 Q 是下界。** 振铃衰减比物理快，所以「我这里不振铃」不等于
   「板上不振铃」。`h_refine_peak_delta_pct` 只界定**峰值**，不界定衰减率。
7. **交叉验证只覆盖线性网络。** 三副 deck 都没有半导体。
8. **`t_stop` 不够长时 `tail_settled = False` 是一个正确读数，不是错误。**
   斜坡锚的 `dc_check_rel = 0.999999` 就是这种情形。

| bulk 摆位（40 µs 窗） | 2 | 1254 | 5 ns | 33.1 ns | 24 ms |
| 1 nH ESL + 1 mF bulk（200 µs 窗） | 2 | 1436 | 0.588 ns | 166.7 ns | 32 ms |
| 同 100 µF 拉到 10 ms 窗 | 1 | **1444** | 25 ns | 8.33 µs | 12 ms |
| `samples=200000` | 1 | ~2e5 | 25 ns | 50 ps | 0.93 s |
| `samples=500000` | — | — | — | — | `TOO_LARGE`，0.10 s 拒绝 |

最后两行说明 `TOO_LARGE` 的守卫是**活的**：它经 `samples`（也就是网格尾部的密度）
可达，不是一段永远不会触发的死代码。10 ms 那行是自适应网格的理由本身——
均匀 `25 ns` 铺满 10 ms 要 400000 步，自适应网格 1444 步。

## 9 定稿口径

- `unit = "V"`，`model = "pdn_step_backward_euler"`；
- `v_initial_v` 是**台阶前**的 preload DC 点；单调 droop 的 `t_peak_s` 是窗口末端；
- `probes` 是**未抽稀**的网格上线性插值出来的（返回的 `t_s`/`v_rail_v` 为了读数抽过稀，
  拿它插值会差在振铃上）；
- 峰值一律报 `h_refine_peak_delta_pct`，超过 5 % 挂 `warning` 说峰值不是测量；
- 平面参数**永远生效**（单节点时并入调节器支路），不会被静默忽略。
