# 气隙之外那一圈 —— Dowell 看不见的铜损

日期：2026-11-01　工具：`magnetics_fringing_loss(...)`（新，第 174 个）

`winding_ac_resistance` 里的 Dowell 公式假设绕组周围是一维的、**平行于箔面**的磁场。带气隙的电感里
这个假设不成立：磁通从气隙边缘**鼓出来**，穿过绕组时方向是**横的**，箔片在它面前像一块被穿过的板。
这一项在 gapped inductor 里经常是**最大的一项**，而 Dowell 的公式里根本没有它的位置——
`winding_ac_resistance` 的 `not_modelled` 第一句就写着"no gap/fringing field"。

这一篇把那一项算出来，并且把它的**每一个假设都写成能失败的检查**。

不给新工具时，旧答案一位不动：`magnetics_winding_ac` 在 4 层 / 0.05 mm / 100 kHz 上仍然是
`fr = 1.00575 = 1.00029 + 0.00546`（自检 `1869` 号显式对照）。

## 1 判据

| # | 要守住的事 | 能被什么违反 |
|---|---|---|
| 1 | 场必须是**真解**，不能是"某个形状的拟合"：用 Biot–Savart 独立求积与 `∇·B = 0`、`∇×H = 0` 双查 | 直接写一个指数衰减因子 `exp(-2z/g)` 之类的"看起来像"的式子 |
| 2 | 极面磁荷密度 `q` 不能假设「隙内均匀」：轴向积分要有**闭式**并与求积对上 | 拿 `B = μ0·NI/g` 当唯一的场，于是 `pole_concentration ≡ 1` |
| 3 | 箔片厚度方向必须是**精确**涡流解，不是薄板近似 | 用 `σω²μ0²t²/12` 一路乘下去（1 mm / 100 kHz 时高估 **18 倍**）|
| 4 | 薄板近似的极限必须**精确**落回教科书式（`D→0` 时 `g(D)=1`）| 两个解各自写一遍、只验一个方向（本轮就是这么发现 2 倍差的）|
| 5 | 口径必须是 **rms**，且写死（`H_peak = √2·H_rms`）| 一半用峰值场、一半用 rms 场 ⇒ 差 2 倍，且看起来"系数错了" |
| 6 | 没建模的三件事必须**量化**地写出来（径向分量在这里是轴向的 **0.32**）| `not_modelled` 里含糊一句"忽略了高阶项" |
| 7 | 圆线**拒绝**，但要交出可组合的原料（`field_weight_a2_m` + `probe_radii_mm`）| 拿箔片公式回答圆线的损耗（静默给错答案）|
| 8 | 旧工具的输出**一位不变** | 顺手把 `winding_ac_resistance` 也改成"含边缘场" |

第 3、4、5 条是这一轮的锚：它们互相咬合，任一条写错都会让数字差 2 倍或 18 倍，而两种错看起来都像"系数问题"。

## 2 模型：两条反向的带电条带

气隙两侧的极面在 2-D 截面里是两段长为 `2a = leg_width` 的**线**，间距 `g`。磁标势问题里，
均匀磁化的极面等价于面上的一层**磁荷**（面密度 `q`，单位 A/m），两条带子的符号相反。
于是场就是两条带电条带的 2-D 库仑场：

```
极面：|x| ≤ a，位于 z = ±g/2，密度 ±q

H_z(x, z) =  q/(2π) · [ atan((x+a)/(z−g/2)) − atan((x−a)/(z−g/2))
                      − atan((x+a)/(z+g/2)) + atan((x−a)/(z+g/2)) ]

H_x(x, z) =  q/(4π) · [ ln(((x+a)²+(z−g/2)²)/((x−a)²+(z−g/2)²))
                      − ln(((x+a)²+(z+g/2)²)/((x−a)²+(z+g/2)²)) ]
```

**必须用 `math.atan`，不能用 `atan2`。** 两个 `atan` 的差是"一个条带的两端"的**有向张角**，
`atan2` 会把每个 `atan` 折进 `(−π, π]` 再做差，在 `|x| > a` 的区域直接翻号。这一条有测试守着
（`test_edge_value_is_half_the_density` 与 `test_far_field_falls_as_inverse_square`）。

`z = ±g/2` 上 `c = 0`：`H_x` 的 `ln` 会撞 `log(0)`，库内把 `c²` 兜到 `1e-36`、`ln` 的辐角兜到 `1e-300`；
`H_z` 的 `atan` 兜 `1e-18`。角点 `(±a, ±g/2)` 因此是**有限**的（测试 `test_radial_field_is_finite_on_the_pole_edge`）。

### `q` 不是猜的：轴向积分有闭式

`q` 由「总 MMF 落在气隙里」定：`∫_{-∞}^{∞} H_z(x, z) dz` 沿一条竖线穿过气隙，必须等于 `NI`。
这个积分有闭式（自行推导，见 §3 第 5 条的自证）：

```
∫ H_z dz = (a·log1p((g/a)²) + 2g·atan(a/g)) / π  ≡  G(a, g)

q = NI / G(a, g) ，     gap_mmf_fraction = G·q/(NI) 之外的份额落在极面外
```

`baseline`（`a = 5 mm`、`g = 1 mm`）：`G = 9.3676e-4 m`，`q = 106751.4 A/m`，
 **`gap_mmf_fraction = 0.936756`** —— 也就是说 6.3 % 的 MMF 落在极面高度之外（`|x| > a` 的区域），
 这就是"边缘"的物理来源。`pole_concentration = q / (NI/g) = 1.067514`：极面中部的场比
 「隙内均匀」的 `μ0NI/g` 高 6.75 %。

### 两个对称性把积分砍一半

实测（不是假设）：`H_z` 关于 `z` **偶**，`H_x` 关于 `z` **奇**，且 `H_x(x, 0) ≡ 0`（测试断言精确 0）。
所以沿厚度 `∫_{-h/2}^{h/2}` 只算半区再乘 2。

## 3 五条自证（互相独立，任一条失败都会暴露）

1. **Biot–Savart 独立求积**：把两条带电条带离散成 4000 段线电荷，直接按 `dH = q dl × r̂ / (2π|r|²)` 求和，
   与 `_fringe_hz` / `_fringe_hx` 相对差 **< 3e-5**（离散误差，收敛阶验证过）。
2. **`∇·B = 0` 与 `∇×H = 0`**：在 `x ± 0.1 mm`、`z ± 0.1 mm` 的四点上做中心差分，
   `∂H_z/∂z + ∂H_x/∂x` 与 `∂H_z/∂x − ∂H_x/∂z` 都 **< 1e-5**（相对 `q/a` 归一）。场是势场，不是拼出来的。
3. **边缘值 → `q/2`**：`x = ±a` 处 `H_z → q/2`（半无限面），且从 `x = 0` 往边缘走 `H_z` **单调上升**；
   逼近边缘时误差按网格**二次**收敛。
4. **远场 `1/z²`**：`z ≫ a` 时把 `H_z(z)` 与 `C/z²` 拟合，斜率落在 `±0.06` 内——两条反向条带在远处是一个**偶极**，
   这是"两条带子"与"一条带子"能分开的判据（单条带是 `1/z`）。
5. **闭式 vs 求积**：`G(a, g)` 与对 `H_z` 的梯形求积相对差 **2.6e-5**（求积在 `z = ±g/2` 处有 `q` 的跳变，
   误差就是这个跳变，加细网格按一阶收敛）。另一个方向的探针：`g/a → 0` 时 `G → q·g` **精确**成立
   （`log1p((g/a)²) → 0`、`2g·atan(a/g) → πg`），这是把闭式钉死的极限。测试里 `assertAlmostEqual` 到 `places=2`。

**库内用闭式，不用求积**：求积只能到 2.6e-5，闭式没有离散误差。求积降级为测试里的独立对照——
「两条独立路径互证」比「一条路径加细网格」便宜且更强。

## 4 精确的板因子：薄板式在 1 mm 上错 18 倍

箔片（厚度 `t`、平行于箔面的横向场 `H`）里的涡流损耗。薄板近似（`t ≪ δ`）是

```
P_thin = (σω²μ0²t²/12) · H_rms² · V        （教科书式）
```

`t` 与 `δ` 可比时这个式子不能用。精确解（自行推导，用复积分独立验证）给出同一个因子乘上一个 `g(D)`：

```
D = t/δ,   δ = √(2ρ/(ωμ0))

g(D) = 3·(sinh D − sin D) / [ D³ · (sinh²(D/2) + cos²(D/2)) ]

g(D) → 1 − D⁴·(1/24 − 1/840)      D < 1e-2 时走这条级数（两个 O(D) 立方会相消）
```

- **对独立复积分**（`E = A·sinh(kx)`、`A = −jωμ0/(k·cosh(kt/2))`、4001 点数值积分）：相对差 **2e-7**。
- **`D → 0` 极限**：`g(1e-6) = 1 − 4e-26` ⇒ 薄板式是**精确式的极限**，不是另一条公式。
  这条极限是发现旧 2 倍差的工具（见下）。
- `t = 1 mm`、`100 kHz`：`D = 4.785`、`g = 0.0556` ⇒ **薄板式高估 17.99 倍**。

### 那个 2 倍是 rms/峰值口径，不是系数

薄板式里的 `H_rms² = H_peak²/2`。第一版把闭式与复积分都按 `H_peak = 1` 归一，薄板式按 `H_rms`，
于是"精确/薄板 = 0.5"——差正好 2 倍，看起来像系数写错。**定死口径为 rms**（`factor_rms = 2 × factor_peak`）后
`exact_rms / thin_rms → 1.0000`（`1e-7`）。连带修正：那个 36 倍是峰值/rms 混算的产物，
**真实高估是 18 倍**，工具描述里写的是 18x。

`baseline`（`t = 0.05 mm`）：`δ = 208.97 µm`、`D = 0.23927`、`g = 0.999867` —— 薄板式在这个厚度上误差 0.013 %，
`thin_sheet_over_exact = 1.000133`（薄板式略低）。所以**薄箔上两者等价，厚箔上必须用精确式**：

| `t` (mm) | `D` | `g(D)` | 薄板式/精确式 | 总铜损 (W) |
|---|---|---|---|---|
| 0.05 | 0.23927 | 0.999867 | 1.000133 | 0.0653932 |
| 0.1 | 0.47853 | 0.997882 | 1.002122 | 0.437969 |
| 0.2 | 0.95706 | 0.967171 | 1.033943 | 2.59072 |
| 1.0 | 4.78532 | 0.055591 | 17.988531 | 6.49721 |

（总铜损涨得比 `t²` 快，因为厚度同时增加铜的体积与 `D`——`t` 翻倍损耗涨 6.7 倍，不是 4 倍。）

## 5 损耗积分与数值

对每个箔壳（第 `i` 层，半径 `r_i = standoff + (i − 1/2)·t`，周长 `2·((leg_w + 2r) + (leg_depth + 2r))`）：

```
weight_i = ∫_{-h/2}^{h/2} H_z(x = r_i, z)² dz            [A²/m]
P_i      = thin_factor · g(D) · t · perim_i · weight_i
thin_factor = (2πf)²·μ0²·t²/(12ρ)
```

`weight` 用 `z` 网格（`z` 跨度 `min(h/2, 6g)` 内 **400** 点等距 + 再往外 **600** 点按几何增长到 `h/2`）做梯形：
场在 `z` 上有 `1/z⁴` 的尾巴（`H_x` 偶、`H_z` 奇），均匀网格会把远场权重严重高估。
80/120 与 640/960 两档的 `weight` 相对差 **3.5e-4**（二阶收敛，库内用 400/600）。

**模型解读**：分层是**同轴箔壳**，一壳 = 一匝 ⇒ `MMF = layers × I_rms`。
箔平面含径向与周向，`H_z` 垂直于箔面但驱动的是**闭合的周向电流**——这是经典叠片/环涡流问题，
厚度方向的屏蔽就是 §4 的 slab 因子。`H_x` 驱动的是**跨层闭合**的环流，尺寸依赖，未建模（§6）。

### 与 Dowell 的邻近项比：6.2 倍

同一绕组用 `magnetics_winding_ac`（4 层、0.05 mm 箔、100 kHz、25 A）：
`F_R = 1.00575`，其中邻近项 `F_R − 1 = 0.00546`，即

```
P_prox = I²·R_dc·(F_R − 1) = 625 × 2.9239e-3 × 0.00546 = 0.0105 W
P_fringe / P_prox = 6.23
```

**这不是「多了几个百分点」，是另一个场高 6 倍。** 65 mW 的绝对值不大，但它有两个性质让它在设计里
很讨厌：① 它**不随箔变薄而线性下降**（薄箔上 `g(D)→1`，`thin_factor ∝ t²` 走到头之后这一项就只随
`t` 变，比 Dowell 的邻近项衰减得慢）；② 它只由**几何**（隙宽、腿宽、箔离隙的距离）决定，绕线方式
改不了。所以它是设计做完才被发现的那一类损耗。

## 6 没建模的八件事（写出来，不是暗示）

返回值里 `not_modelled` 有 **8 条**，其中第一条带实测比例：

1. **径向（面内）分量**：它驱动的电流回路**跨层闭合**，因子取决于叠层几何而不是箔厚。
   在极面上方一个隙宽处它是轴向分量的 **0.32**——「不小，而且在这个数字里完全不存在」。
   这个 0.32 是算出来的（`radial_over_axial_at_0p2g`），不是估的。
2. **腿的 3-D 端部**：模型是 2-D（沿 `leg_depth` 无限），所以绕组两端看到的是一个"永不结束"的面
   ——在那里**高估**。要算端部得换 3-D 或半解析，成本不是一个数量级。
3. **功率相加、无交叉项**：Dowell 自身场的邻近损耗与这一项按功率相加。真实合损耗**不是**精确的和。
   （这一条是本轮新工具与 `winding_ac_resistance` 的接口契约：两个数各自可信，相加只是近似。）
4. **圆线**：横向场里圆柱的涡流因子要 Kelvin 函数（`ber`/`bei`），纯 stdlib 自证成本高。
   **所以拒绝箔片公式回答圆线**，但交出原料：`field_weight_a2_m` 与 `probe_radii_mm`，
   让你自己乘上你的线因子。这不是空手拒绝。
5. **极面是理想磁导体**：没有磁通"跑进"磁芯，也没有饱和收缩边缘场。**饱和的隙鼓得更多，不是更少**。
6. **绕组自身场在隙内的贡献**：绕组不共心或磁芯不对称时，它会改变隙看到的 MMF。
7. **非正弦**：按谐波自己叠加，`field_weight ∝ I_k²`。
8. **层间绝缘厚于 `insulation_mm` 时**：假设的是笔直径向叠层（无螺旋、无跨层）。

## 7 拒绝臂

| 输入 | `reason_code` | 消息要点 |
|---|---|---|
| `freq_hz ≤ 0`、`gap_mm ≤ 0`、`leg_width_mm ≤ 0`、`leg_depth_mm ≤ 0`、`thickness_mm ≤ 0`、`winding_height_mm ≤ 0` | `ARG_RANGE` | 各自点名 |
| `standoff_mm < 0`、`insulation_mm < 0` | `ARG_RANGE` | `must be >= 0` |
| `layers < 1` 或 `> 200` | `ARG_RANGE` | `layers` 上限是"这不是一台变压器"的护栏 |
| `current_rms_a` 与 `ampere_turns` **都给**或**都不给** | `ARG_MISSING` | `exactly one`（不给就不知道 MMF，两个都给就不知道信谁）|
| `resistivity_ohm_m` 与 `temperature_c` **同给** | `ARG_INVALID` | `not both`（温度只是 ρ 的一种给法）|
| `probe_radii_mm` 含负数 | `ARG_RANGE` | 半径 |
| `probe_radii_mm` 不是可迭代 | `ARG_INVALID` | `must be a list of radii in mm` |
| 任一非数值 | `ARG_INVALID` | 点名参数 |

**`warnings`（不是拒绝）唯一的触发条件**：`gap_mm > leg_width_mm / 2`。文案：

> `gap_mm=8 exceeds half the leg width: the two pole faces are then not facing each other over most of their area and the 2-D strip model's premise (a thin gap) is gone`

这时仍给数字——因为模型**还算得出**，只是前提没了。拒绝和警告的分界是"算术能不能算"，
不是"结果好不好看"。

---

## 8 边界

- **均匀 MMF、同轴壳**：`layers` 同时是壳数与匝数。不做"壳数 ≠ 匝数"的自由度（那样 DC 电阻与 MMF 会自相矛盾）；
  按实测 MMF 缩放请走 `ampere_turns`。
- **单频正弦**：宽频要走 `sim` 或自己按谐波叠加。
- **2-D**：沿 `leg_depth` 无限。
- **极面理想磁导体**：没有 `μr`、没有饱和。
- **一个气隙**：多隙（分布气隙）要按每个隙单独算，功率相加（并按 `insulation` 与 `standoff` 定位）。
- **没有 E 型芯的中柱/边柱区分**：模型只认"两条面对面、宽 `leg_width`、相距 `g`"的几何。E 芯的边柱与中柱
  都近似成这一对；两个边柱同时存在时，MMF 的分配由磁路决定，不是本工具能反推的。

---

## 9 成本

纯闭式，无迭代、无线性代数。一次调用是 `layers × 1000` 次 `atan`/`log` 加一次场强采样（`probe_radii_mm` 每点 1900 次）。
`python -m unittest tests.test_fringing_loss` 的 35 例总耗时 **0.4 s**；`--selftest` 全量 262 例约 100 s，
其中新增的 5 条占总时长的不到 1 %。

## 10 结论

1. **气隙边缘场不是 Dowell 的邻近项**：同一绕组上它是后者（`I²R(F_R−1) = 0.0105 W`）的 **6.2 倍**，
   而 Dowell 的公式里没有它的位置。`winding_ac_resistance` 的 `not_modelled` 第一句话就是这个缺口。
2. **`q` 不能假设均匀**：轴向积分的闭式给出 `gap_mmf_fraction = 0.936756` 与 `pole_concentration = 1.067514`，
   即 6.3 % 的 MMF 与 6.75 % 的场强是"边缘"带来的。假设均匀会系统性低估。
3. **薄板近似在厚箔上错 18 倍**：`t = 1 mm`、`100 kHz` 时 `g(D) = 0.0556`。
   而那个"2 倍差"是 **rms/峰值口径**问题，不是系数——`g(D→0) → 1` 精确成立，这条极限把口径钉死。
4. **箔离气隙的距离是唯一有效的设计旋钮**：`0 → 2 mm` 掉到 9.1 %；隙宽、腿宽、频率都是"你改不了多少"的。
5. **高度几乎无关**（6 → 40 mm 差 2.02 %）：`1/z⁴` 的尾巴，物理结论而不是数值巧合。
6. **圆线明说拒绝并给原料**：`field_weight_a2_m` + `probe_radii_mm`，`not_modelled` 点名怎么用。
7. **旧答案一位不动**：`magnetics_winding_ac` 的同参数读数仍是 `fr 1.00575 = 1.00029 + 0.00546`（自检 `1869`）。

### 与文献

方向来自 Roshen 的两篇（*IEEE Trans. Magn.* **43**(8) 2007, 3387–3394，DOI `10.1109/TMAG.2007.898908`；
**44**(10) 2008, 2396–2401，DOI `10.1109/TMAG.2008.2002302`）与 Stadler/Huber/Stolzke/Gulden 2014
（Xplore 文档号 `6748958`）。**这三篇的正文这一轮取不到**，所以这里**不声称"照抄文献公式"**：
2-D 磁荷模型、`G(a, g)` 的闭式、`g(D)` 的闭式都是按上面五条自证自行推导与验证的。
拿到正文后要做的第一件事是核对**归一化口径**（峰值 vs rms、单面 vs 双面），而不是改数字——
因为 §4 那条 `D→0` 极限会立刻告诉你口径对不对。
