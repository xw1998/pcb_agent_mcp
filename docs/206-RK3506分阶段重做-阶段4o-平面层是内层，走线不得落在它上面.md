# 阶段 4o —— 平面层是内层，走线不得落在它上面

`docs/205 §7` 留下一条欠账：路由器**自己**把 `In1.Cu` 叫平面层，却又允许走线走上去。这一阶段把它结清，同时拆掉这条路径上两个错答案——一个是把「外层铺铜」也当平面（`examples/sky_star` 整块板因此不可路由），另一个是把「过孔」也当切面（任何内层布线都会被永久拒绝）。

**交付板 `examples/rk3506_som/rk3506_som.kicad_pcb` 逐字节未动**，也没有新增工具（仍 265），版本不动（阶段文档按先例不升版本、不进 CHANGELOG）。

## §1 结论先行

1. **平面 = 有电源样铺铜 + 该层是内层**。两个条件缺一不可，且只在两处实现：`route/router.py::_inner_layer`（路由器分层）与 `edit/planes.py::inner_layers`（写盘闸门测量）。外层铺铜是 ground fill——每个设计都在切它、官方 `ZONE_FILLER` 会围着新铜重新灌、它不是任何东西的参考面（外层信号的回流在内层平面）。**两层板根本没有参考面**，这是诚实答案，不是测量失败。
2. **旧口径的实测后果是「把板子弄坏」而不是「更安全」**：`examples/sky_star`（2 层，GND 在 B.Cu、+3V3/+5V 在 F.Cu）整批报 `every copper layer on this board is a plane` ⇒ router 完全不能用；`tests/data/sample.kicad_pcb` 被降级成单层板（routing 只有 `['F.Cu']`、B.Cu 变成 `{B.Cu: GND 100%}`），只到 B.Cu 的网没有起点。
3. **默认不再切平面**：`plan()` 的 `walk_layers` 由新函数 `_walk_layers(routing, new_layers)` 决定，`None`（默认）= **ROUTING 层**，不再等于「栅格里的每一层」。栅格必须留着平面层（via 仍要避让它不许用的铜），所以「栅格每一层」当默认值就是在允许切平面。
4. **真板读数（同一对 DDR 网）**：新默认 **78.1 s / 0 op / `rejected: []`**，`/DDR_A11 failed search_budget`、`/DDR_A8 failed no_path`；旧默认 **371.388 s / 19 op**，其中 `In1.Cu` 上 9 段。**两条网接上**和**GND 面被挖掉 36.1 mm²** 是同一批铜。
5. **过孔不是切面**：through via 没有 `layers` 键、贯穿整个叠层，落在平面上得到的是 antipad 小圆洞，板上有几千个；把它算成切面会让所有内层布线（默认都是全贯穿孔）永远被拒。via 现在报 `via: true` / `plane: false`，只报不拦。
6. **一个网既沿平面走 track 又打 via 时，按最坏的铜定级**（`plane = OR`、`via = AND`、`at` 取 track 的点）。我第一版按 `(net, layer, pour_net)` 先到先得，结果 via 在 op 序列里排在 track 前面，把 9 段 In1 track 全丢了 ⇒ 闸门只剩「4 条 antipad」，险些放过真切割。修后 `plane_hits = 2`。
7. **只报不拦的三类**：via（antipad）、外层铺铜（ground fill）、覆盖不到板面一半的铺铜（本板 In3 的 17% 分割电源面——「能不能跨它」是设计问题，几何答不了）。
8. **测试**：`test_plane_pours.py` **21 passed（7.585 s）**、`test_edit*` **39 passed（35.160 s）**、`test_route*` **129 passed（107.122 s）**、`test_rule_projection*` **17 passed**、`test_length_corridor*` **10 passed**、`test_blockers*` **23 passed**。

## §2 平面判据：为什么必须加「内层」

旧判据只有一条：铺铜外框覆盖 ≥ `PLANE_SHARE`（默认 0.5）就降级成平面。它在 6 层 RJ3506 上读起来是对的（In1 的 GND 95.51%），但它是**按面积猜**的，一旦碰到外层铺铜就出事。

真板审计（`_w1_layers.py` 扫全仓 `*.kicad_pcb`，旧口径）：

| 板 | 旧口径读数 | 后果 |
| --- | --- | --- |
| `examples/sky_star/*` | `every copper layer on this board is a plane`（2 层，GND 在 B.Cu、+3V3/+5V 在 F.Cu） | routing 为空 ⇒ **整块板不可路由** |
| `tests/data/sample.kicad_pcb` | routing `['F.Cu']`，B.Cu 降级为 `{B.Cu: GND 100%}` | **单层板**，只到 B.Cu 的网无起点 |
| `examples/rk3506_som/*` | In1 `In1.Cu` / In3 `In3.Cu` | 正确（本来就只有内层有电源样铺铜） |

新判据（两处同源）：

- `router._inner_layer(layer, copper)`：`0 < i < len(copper) - 1`，栈序里既不是最外也不是最外；
- `edit/planes.inner_layers(board)`：有栈就 `order[1:-1]`；没有栈就按 KiCad 命名 `^In\d+\.Cu$` 认；只有 `F.Cu/B.Cu` 的板返回空集（**没有参考面**）。

修后：`sky_star` 回到 `routing == ["F.Cu","B.Cu"]`、`planes == {}`；`sample` 同；`rk3506` 仍 `planes == ["In1.Cu","In3.Cu"]`、`routing == ["F.Cu","In2.Cu","In4.Cu","B.Cu"]`。这三条都进了 `tests/test_plane_pours.py::PlanesAreInnerLayers`（4 例，含 `_walk_layers` 的 3 条断言）。

`edit/planes.pours()` 每条铺铜多一个 `reference` 字段（内层名排序列表），`crossings()` 的 `hit` 与 `report["planes"]` 都带它；外层铺铜因此可被下游读成「报了但不是参考面」，而不是靠文案猜。

## §3 默认不再切平面

`plan()` 里的 `walk_layers` 决定搜索**允许落到哪一层的新铜**。旧实现有三处调用点直接传 `new_layers`（`None` 的语义是「栅格里的每一层」），而栅格是 `grid_layers = routing + planes` ——为了 via 的物理检查必须把平面层留在栅格里。于是默认值等于「允许把新铜放到平面上」。

新实现：

```python
def _walk_layers(routing, new_layers=None):
    return list(new_layers) if new_layers is not None else list(routing)
```

`plan()` 里 `walk = _walk_layers(routing, new_layers)`，三处调用点（现 1482 / 1496 / 1741 行）由 `walk_layers=new_layers` 改为 `walk_layers=walk`。**显式出口不动**：`new_copper_layers` 仍只接受 routing 层；「故意切内层平面」的能力留在写盘闸门的 `allow_plane_crossing`（`docs/201` 同构：放行不是洗白）。

真板读数（同一对 `/DDR_A8`、`/DDR_A11`，pitch 0.1 / clearance 0.1 / track 0.1）：

| 口径 | elapsed | ops | 结果 | 出处 |
| --- | --- | --- | --- | --- |
| 旧默认 | 371.388 s | **19**（F.Cu 3+3、**In1.Cu 4+5**、via 4） | 两网 routed（穿过 In1 GND） | `_r1_plan.json` |
| 新默认 | **78.1 s** | **0** | A11 `failed search_budget`、A8 `failed no_path`，`rejected []` | `_r12_default.json` |
| 显式信号层（`_r8`） | 124.049 s | 0 | 同上 | `_r8_ddr.json` |

新默认比显式信号层快（78.1 s vs 124.049 s）是因为它不再为平面层做无用搜索：A11 在预算内就没找到路，A8 直接判无路。**这不是「损失了 2 条连接」而是「不再偷 GND」**——按 `docs/205` 的同一笔账，那 9 段 In1 铜对应铺铜账单 −36.9551 mm²（GND −36.0753，1809.1031→1773.0278）。

## §4 过孔不是切面，以及我那次被去重抢先的错

### §4a 判据

`_points_of()` 现在返回 5 元组 `(x, y, layer, net, kind)`，`kind ∈ {"track","via"}`：

- `add_track` → `"track"`，沿 `layer` 取 5 个采样点；
- `add_via` → `"via"`，有 `layers` 才按 `span` 铺，**没有 `layers`（全贯穿孔）按调用方给的全部铺铜层铺**。

`hit["plane"] = _plane(p, layer) and kind != "via"`：track 沿平面跑才是切；via 的桶贯穿每层、平面被钻 antipad、电流绕着走，是板子的常态。闸门文案因此拆成三组：`vias`（"N via(s) whose barrel passes through it - an antipad is not a cut"）、`outer`（"…outer-layer pour(s), which are ground fill and not reference planes"）、`small`（"…under half the board"），合成一句 `copper lands on %d pour(s) that are not reference planes: %s`。

### §4b 真板读数（`_r9_gate_real.json`）

把 `_r1` 那 19 op 重新 `board_propose`：

- `verdict = refused_at_plane_pour_intact`，`precheck.plane_pours.planes = [{layer: "In1.Cu", net: "/GND", area_mm2: 1933.989, share: 0.9551, reference: ["In1.Cu"]}]`；
- `crossings` 4 条 = **2 条 `plane: true`**（A8/A11 的 **track** 落 In1，`reference` 非空）+ **2 条 `via: true / plane: false`**（落 In3 的 0.1741 小面）；
- `plane_hits = 2`。

### §4c 我第一版的错（必须留档）

第一版 `_points_of` 里 via 无 `layers` 时回退到「所有铺铜层」，去重是 `seen` 集合先到先得——而 **via 在 op 序列里排在 track 前面**，于是 key 被 via 的 `plane=False` 抢走，**9 段 In1 track 全丢失**。读数变成「override row ok=True，只有 4 条 via 命中」：数字齐全、闸门通、结论错——险过。

修法两件：

1. via 单独 `kind` 分级，不再参与「平面命中」；
2. 去重改为合并：`plane = OR`、`via = AND`、`at` 优先 track 的点（`if prev["via"] and not hit["via"]: prev["at"] = hit["at"]`）。理由是一个网在同一坐标既走 track 又打 via 时，钢绞的是 track，报出来的点也必须是 track 那个。

锁死：`tests/test_plane_pours.py::ATrackAndItsViaAreOneCrossing`（1 例：同点 via + track ⇒ 1 条、`via False`、`plane True`、`at == [5.0, 5.0]`）与 `AViaIsNotACut`（3 例：through via 报 `via True / plane False / reference ["In1.Cu"]`；同板 track 仍 `plane True`；闸门 `ok=True` 且 `why` 含 `antipad`）。

## §6 为什么不是「在两种默认之间折中」

- **「栅格每一层」不能当默认**：栅格必须含平面层（via 的物理检查），把它当「可落铜层」是把物理检查的需要误读成布线许可。这不是权衡，是纠正错答案。
- **但平面判据必须先改成内层**：否则「收默认」会先砸坏两层板——`sky_star` 从可路由变不可路由、`sample` 从两层变一层。顺序反了，修一处坏一处。本轮先有正确判据（§2），再收默认（§3），两步的真板读数都是先量后写。
- **via 必须排除在外**：内层布线默认全是全贯穿孔，把 antipad 算成切面等于禁用内层布线。`ruleset/measure.py::_reference_plane` 早就按「窄缝不算 split」放过同类东西，口径一致。
- **按最坏铜定级**：一个网同时有 track 和 via 时，报 via 就是报了个无害的东西（§4c 的实测）。

## §7 没做什么

- **不替换交付板**：`examples/rk3506_som/rk3506_som.kicad_pcb` 字节未动。DDR 要不要换层、要不要接受切平面是设计决定。
- **不改 `new_copper_layers` 的显式出口**：故意切内层平面的能力保留在写盘闸门 `allow_plane_crossing`。
- **不留 `sleep`、不写新判定**：本轮只做「同一句判据在两处落地 + 一个默认值纠正 + 一组反向对照」。
- **`layer_changes_without_return_via` 仍未在布线前前置检查**（`docs/200 §8` / `docs/201` 同一条欠账，与本轮无关）。
- 六网灌铜、`+1V35_DDR` 面未覆盖 U6、`boot_sw` 朝向、`hole_in_pad`/`via_in_pad`/`copper_under_magnetics`、`track_dangling`、DDR 悬空短桩、旧锐角、0.2 mm 余量重谈等欠账原样，见 `docs/205 §9`。
