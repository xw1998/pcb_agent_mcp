# 141 — 通孔化、`set_pad_drill`，与排针块里那条 0.29 mm 的缝

> 立创天空星开发板（`examples/sky_star/sky_star_routed.kicad_pcb`）第一次做**真通孔**。
> 版本 `0.0.150`。本文记三件：新 op、通孔化暴露出的几何、以及一件**没修完**的事——
> 排针块里 65 条 DRC 违规的根因是「三网争两条缝」，逐网贪心已被六次只读实测证伪。
> **这一件没做完，不许读成做完了。**

## 1. `set_pad_drill`：一个 op 补上 120 个孔

原先 458 个焊盘全是 SMD 口径（`smd`、无 `drill`），所以整块板只有过孔有孔，
排针、按键、晶振、连接器的脚都是"贴"在铜上的——DRC 不报，是因为它没东西可报。

新增 `set_pad_drill`（`edit/ops.py`，**OPS 45 个**）：

| 参数 | 含义 |
|---|---|
| `footprint` / `pad`（或 `pad_uuid`） | 定位到一个 pad |
| `drill` | 钻孔直径，mm，> 0 |
| `type` | `thru_hole`（默认）/ `np_thru_hole` |
| `plating` | `plated`（默认）/ `non_plated`，写 `(options ...)` |

写出来的 pad 保留原 `at`/`size`/`layers`/`net`，只把 `smd` 换成 `thru_hole`（或
`np_thru_hole`）并加 `(drill …)`。落板实测：**88 个 `thru_hole` + 32 个 `np_thru_hole`
= 120 个钻孔**（含 8 个定位孔/安装孔走 np）。

测试 `tests/test_ops_edit.py` +196 行，钉住四条：SMD→THT 保留其余字段、np 不写 net、
drill ≤ 0 报错、缺 pad 报错。

## 2. 通孔化当场暴露的第一件事：行高不够

焊盘一旦有孔，**同层的钻头净空变成真实约束**（之前只在过孔上生效）。于是原先"从内列 pad
正上方横穿"的十几条 B.Cu 走线，全部变成短路——

- 排针 P2：40 脚，内列 `x=165.43`（奇 1..39）、外列 `x=167.97`（偶 2..40），
  行 `y=80.87+(n−1)·2.54`，pad 1.8 / drill 1.1 / pitch 2.54，**全部 THT**。
- 一条 0.15 线要穿过 pad 行，中心离 pad 中心必须 ≥ 1.125（0.9 铜 + 0.075 半线 + 0.15 净空）。
  行距 2.54 ⇒ **缝的有效宽度只有 0.29 mm**（缝中心 ±0.145）。

这就是后面所有麻烦的出处：**每条缝只能过 1 条线**，没有第二条的位置。
可用缝中心（y）：79.60、82.14、84.68、87.22、89.76、92.30、94.84、97.38、99.92…110.08、112.62…

## 3. 五条可复用的走廊事实（都是量出来的）

改这个块之前先量清楚哪些方向是空的，比事后 DRC 试错便宜得多：

1. **列间通道** `x ∈ [166.33, 167.07]`（中心 166.70）在**全部 y 上自由**——两列 pad 之间的
   那条竖缝，是这块区域唯一的纵向高速公路。
2. **东侧走廊** `x ≥ 169.095` 自由（实测 `x 169.1..170.0`、`y 90.4..112.0` 无铜）。
3. **F.Cu 在 `x 159..164, y 83..93` 被四根竖线封死**：`_SPI_CS` x=160.23、
   `_SPI_MISO` x=161.5、`_SPI_MOSI` x=163.405、`$1N1206` x=164.12。
   ⇒ **换层救不了东西向交叉**（这正是最初"排针不是多层"的直觉，但方向得反过来：
   不是没做多层，是 F 面这块本来就满）。
4. **`x > 164.2` 的 `y 82..92` 区间几乎全空**（只有 `$1N1206` 与上面那几根竖线）——
   但**再往北 `y≈79.6` 不是空的**：那里压着 U4 / RN3 / R21 的元件焊盘。
5. 45° 斜腿穿 pad 列**必然侵占 pad 中心净空**（实测最近 0.73 < 1.125），所以换列只能
   在 `x ≤ 164.3` 或 `x ≥ 169.0` 做。

## 4. 这一轮真修掉的：DRC 279 → 188

| 阶段 | 总违规 | 分型 |
|---|---|---|
| 通孔化后（未修） | 279 | lib 96 + silk 27 + mask 71 + shorting 55 + hole_to_hole 12 + clearance 10 |
| gapfix 18 op | 216 | mask 53 + shorting 39 + hole_to_hole 6 + hole_clearance 1 |
| batch1 三组 | 215 | mask 48 + shorting 34 + hole_clearance 1 |
| `_rowup.py` 30 op | 203 | mask 42 + shorting 28 + hole_clearance 1 |
| `_rowy2.py` 36 op | 192 | mask 36 + shorting 21 + via_dangling 1 + track_dangling 1 |
| `_pc7fix.py` 2 op | 190 | mask 36 + shorting 22 |
| PC0 6 op | 189 | mask 35 + shorting 21 + track_dangling 1 |
| 删 PC0 悬空段 | **188** | lib 96 + silk 27 + **shorting 21 + clearance 9 + mask 35** |

基线 123 条（`lib_footprint_issues` 96 + `silk_over_copper 27`）是板子自带、不动。
`solder_mask_bridge` 35 条全是短路的副产物（走线穿 THT pad 开窗），修短路同时消。
**剩余真违规 65 条**（shorting 21 + clearance 9 + mask 35）。

按焊盘聚合（`_drcgrp.py` 读 `drc9.json`，比按网归因准）：
pad 10 / 7 各 9~13 条，pad 8 / 1 / 4 / 2 / 3 各 4~9 条，pad 5/6/9/22 各 2~3 条，
pad 12/14/16/18/20/24 各 1 条（`mask` 单条），pad 29 1 条，加 **P1 pad 10（`$1N4905`）1 条**。

## 5. 没修完的那件事：三网争两缝，且中间横着一堵 11.6 mm 的墙

剩余 65 条全部落在 P2 排针块，结构上是**一个 1:1 互锁**，不是七个独立的坏点：

**墙**：`$1N4752` 自己的 pad-8 逃生线，B.Cu `y=88.49`，`x 152.6 → 166.75`（**11.6 mm**）。
它横穿 pad 7 的中心（这本身就是违规来源之一），同时把整块区域**一分为二**：

- 往南要过 `y=88.49`：`x > 166.75` 被 pad 铜带 + 1.125 净空封死；
  `x < 152.6` 被 `$1N4919` 的 `y=82.5`、`_SDIO_CLK` 的 `y=87.523`、PE 系列竖段封死。
- 往北要过它：同样无处。

**争用**：`$1N4752` / `$1N4863` / `$1N9171` 三网同时需要穿 `87.22` 与 `89.76` 两条缝，
而每条缝只容 1 条线（第 2 节）。

- `$1N9171`：唯一可行路线是东侧走廊 `x=169.30` 一路南下（全绿，最小余量 +0.295），
  最后必须从 `89.76` 缝往西切进来接 B1.1（中心 `155.9, 90.0`，rad 1.70，在墙南侧）。
- `$1N4863`：想把 `y=90.0` 的墙挪到 `89.76` —— 与上面那条**同一格**，二选一。
- `$1N4849`：需要同层横穿，与另两网的竖穿互斥。

**两条被证伪的候选方案**（`_n2fix.py` 只读测量，未写入板子）：

```
$1N4891  F.Cu 北绕 y=79.60
  (164.160,79.600)->(158.200,79.600)   pad -0.044 U4.2
  (158.200,82.300)->(158.425,82.525)   pad -0.173 RN3.2  cop +0.005
  (158.425,82.525)->(158.425,89.000)   pad -0.183 R21.1  cop -0.150 _SDIO_CLK
  WORST -0.183 R21.1
$1N9171  东侧走廊 x=169.30 + 89.76 缝
  (167.970,111.350)->(169.300,110.020) pad +0.821 P2.24
  (169.300,110.020)->(169.300,90.550)  pad +0.355 P2.10
  (169.300,90.550)->(168.510,89.760)   pad +0.305 P2.10
  (168.510,89.760)->(164.400,89.760)   cop -0.150 $1N4863
  (164.040,89.400)->(157.300,89.400)   pad +0.686 P2.7   cop +0.450
  WORST -0.150 $1N4863
```

两条各只差**一处**：前者撞元件焊盘（"排针上方是空的"这个假设不成立），
后者撞 `$1N4863` 的 `y=90.0`。这不是"再试一条就好"，因为它们抢的是同一格。

另两处更窄的死结：
- `$1N4905`（P1 pad 10）被 `$1N4919` 的圆角墙卡住，缺口 **0.238**，需要 **0.30**。
- `$1N4401` 的行缝 `115.16` 已被 PD6 的 `y=115.05` + 45° 肩占满，一缝塞两线
  ⇒ 最小余量 **+0.055**（正数，但 DRC 判不过）。

## 6. 下一个入口（就一个，且不许用搜索代替）

**一次协同重排** `$1N4752 / $1N4863 / $1N9171`（＋`$1N4849`），并把其中一个网的逃逸
via **迁出排针块**。这不能用"自写迷宫搜索/通用布线器"来做（既违反"不许自动布线"，
也违反"自写通用布线器同样违反本意"），只能逐条手工设计 + 只读测量 + DRC 验证。

前置工具缺口：现有 `_gapfix3.survey` 是**单网对既有铜**的测量，缺一个"多网同时 survey"
（一次算这四个网对新几何的两两余量）。做这件事之前先补这个只读工具。

DRC 是唯一仲裁——自算余量与 DRC 会不一致（本轮 `+0.295` 全绿而 DRC 仍报的那两条
就是口径差异，不是算错）。
