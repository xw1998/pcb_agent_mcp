# 粉末磁环：几何、AL 与九列材料码 —— 让 `select_core` 第一次能选一颗环

日期：2026-11-01　工具：`magnetics_data(kind="powder_cores" | "powder_parts")` + `magnetics_select_core(include_powder_cores=)`（**不新增工具**，仍是第 175 个）

`77` 篇的 §8 把话说死了：「粉末芯几何、DC 磁化曲线都没入表，见 §8」。
其中第一条就是这一篇：**43 个印刷尺寸、500 个磁导率行、1923 个可买料号**全部入库，
并把 `select_core` 从「只能选铁氧体和块状芯」扩到「也能选磁环」。

这件事的意义不是多了一个数据文件，而是**一类问题的答案从 `NOT_FOUND` 变成了能算**：
100 µH / 5 A 在这张表里查不到任何一颗环之前，调用方只能自己翻 PDF 算匝数。
现在同一条请求给出 `0055141A2`、601 匝、63.996 mT 对 800 mT 的饱和、以及
**厂商自己印的** 60µ 环形拟合算出的 1.1 mW 损耗 —— 而气隙长度是 `null`，
因为粉末芯根本没有离散气隙（见 §6.3）。

既有行为一位不变：工具数仍是 **175**，`include_powder_cores` 默认 `False`，
默认路径的 16 行池与 `B66283G0000X187` 那一组读数逐位不动（§7）。

## 1 判据

| # | 要守住的事 | 能被什么违反 |
|---|---|---|
| 1 | 每一条几何、每一个 AL 都要回到**厂商一手 PDF 的某一印刷页**，页号写进数据 | 从分销商页面抄「OD 3.56 mm 的 MPP 有 60µ」|
| 2 | 列归属**不能靠词的先后**判断——厂商把空单元格整个不印 | 顺序解析在缺一格的地方把整行右移，材料码检查会当场抓到 |
| 3 | 转录必须被厂商**自己印的第二个数字**验过 | 用自己的公式算一遍对上了（错转录也自洽）|
| 4 | 几何三件套要**互相**核对：`Ve = Ae·Le`、`Le = 对数均值周长`、`Ae ≈ 矩形截面` | 只核一条，错的恰好是没核的那条 |
| 5 | 料号前缀里的**材料码**要与它所在列一致（1923 格逐格查）| 列位移、或者把 High Flux 的料号抄进 MPP 列 |
| 6 | 看起来像错的数（AL 18 对列中位 16、`CO58031A2` 里的字母 O）**渲染成图复核后原样保留**，并登记 | 顺手改成 16 / 改成 `C058031A2` —— 那是发明厂商数据 |
| 7 | 质量是**估计值**（`Ve × 密度 × 因子`），厂商没印因子的 200/300/550µ **拒绝而不插值** | 给 300µ 算一个「差不多」的数 |
| 8 | 没有离散气隙就**不编一个气隙长度**，没有平均匝长就**不算铜损** | 拿 `π(OD+ID)/2` 当 MLT 算铜损 |
| 9 | 默认关时，池、行数、每个候选的每个字段逐位不变 | 粉末表渗进默认路径 |
| 10 | 没做的部分写清楚（§8）| 把「有 1923 个料号」说成「能设计磁环了」|

## 2 厂商原文（印刷页 → PDF 页）

一手来源只有一份，且**只有这一份**带完整九列网格：

```
vendor : Magnetics, a Division of Spang & Company
doc    : Powder Core Catalog
url    : https://www.mag-inc.com/Media/Magnetics/File-Library/Product%20Literature/
         Powder%20Core%20Literature/Magnetics-Powder-Core-Catalog.pdf
bytes  : 12,415,449
pages  : 210（PDF），本轮用到 PDF 156–198 = 印刷 155–197
```

**印刷页 = PDF 页 − 1**，这一整段没有例外，数据文件里每个 size 块都同时存
`printed_page` 与 `pdf_page`，测试断言 `pdf_page == printed_page + 1` 在 43 个块上成立。

### 2.1 为什么必须按坐标取列

这张表**对空单元格根本不印**：一颗环的 MPP 列没有 26µ，那个位置就是空白，
`get_text("words")` 里**没有词**。所以「第几个词属于第几列」这种顺序解析
一旦遇到空单元格，整行就往左错位一格 —— 而错位后每行仍然「看起来有九个值」。

做法是取每页表头 `Part Number` 的 y（记 `yP`），在 `y ∈ [yP−6, yP+40]`
的窄带里找文本属于 `("Kool","XFlux","Edge","High","MPP")` 的词，按 x 排序。
排序后的序列必须**恰好**是

```
["Kool","Kool","Kool","Kool","XFlux","XFlux","Edge","High","MPP"]
```

（九个列头里有四个都以 `Kool` 开头，所以序列本身就是一个断言），且相邻中心距
落在 `(10, 80) pt` 内；列边界取相邻中心的中点。
**任何一项不满足就中止入库**，不做「差不多对」的容错。

数据行取 `y > yP + 36`。这个 36 是量出来的，不是留白：印刷 p.172 的首行
`y = yP + 39.8`，用 `+40` 会把它整行漏掉，而它的 AL 是 `9.9`（非整数），
一旦漏掉，这一页的 AL/µ 会整体偏移。

## 3 六条自校验（每条都能翻脸）

### 3.1 `Ve = Ae × Le`

43 个尺寸逐个算 `Ve/(Ae·Le)`：

| 门槛 | 通过 | 唯一例外 |
|---|---|---|
| `|r−1| ≤ 0.007` | **41/43** | p178 = 1.0152（1.5 %）、p193 = 0.9348 |
| `|r−1| ≤ 0.02` | **42/43** | p193 |

**摘要里那句「42/43 落 1.000±0.007」是不成立的**：0.007 门槛下有两例。
两个门槛都写进测试与文档，测试按 0.02 断言唯一例外，注释里保留两例的区别。

### 3.2 `Le` 与对数均值周长

球形/环形磁路的平均路径长度，与 `π(OD−ID)/ln(OD/ID)` 比：**43/43 误差 < 1 %**，
最差 0.97 %（p178）。这一条独立于 §3.1，所以 p178 的小偏差是**舍入**，
而 p193 的 0.9348 不是。

### 3.3 `Ae` 与矩形截面

`HT·(OD−ID)/2` 是环截面的外接矩形。实测比值 **0.9034 – 0.9972**（43/43 落在
`(0.85, 1.0)` 内），符合「有效面积略小于矩形」的物理预期。
于是 p193 的自相矛盾可以定位：**Ae 与 Le 各自都对，错的是印的 Ve**。

### 3.4 料号里的材料码 vs 它所在的列

料号结构印在 p.17：`GradingCode(2) + MaterialCode(2) + CatalogNumber(3) + CoreFinish(2)`。
材料码九取值：`77` Kool Mµ、`79` Kool Mµ MAX、`76` Kool Mµ Hƒ、`70` Kool Mµ Ultra、
`78` XFlux、`74` XFlux Ultra、`59` Edge、`58` High Flux、`55` MPP。

1923 个格子里 **1921 个一致**，2 个例外是厂商自己印错（§4 的 1、2 条）。
这一条是 §3.1–§3.3 都看不见的：几何自洽与列位移**完全无关**。

### 3.5 `AL/µ` 在同一页同一列里是常数

`AL = µ0·µi·Ae/Le`，几何固定时 `AL/µ` 是常数。**必须按 (页, 列) 分组取中位** ——
跨页跨列算全局中位会误报 **1637 处**（不同尺寸的 Ae/Le 差几个量级）。
分组后偏离 > 12 % 的只有 **3 处**，且全是印刷 p.158 的 `perm=40 / AL=18`
（该列中位 16）。

三处是同一行的三列（Kool Mµ / High Flux / MPP），渲染成图确认**印刷就是 18**，
于是原样保留并在测试里点名。

### 3.6 每列的磁导率都落在 p.10 印的范围里

p.10「Available Permeabilities」给了每列的最小/最大磁导率，九列逐个包含检查通过：

| 列 | 印的范围 | | 列 | 印的范围 |
|---|---|---|---|---|
| Kool Mµ | 14–125 | | XFlux Ultra | 26–60 |
| Kool Mµ MAX | 14–90 | | Edge | 14–125 |
| Kool Mµ Hƒ | 26–60 | | High Flux | 14–160 |
| Kool Mµ Ultra | 26–60 | | MPP | 14–550 |
| XFlux | 19–125 | | | |

## 5 另外两张表：材料对比（p.10）与材料特性（p.16）

### 5.1 p.10 —— 九列材料的可比参数

每列 11 个字段，其中三个是本轮真正用到的：

| 列 | 合金 | 磁导率范围 | Bsat (T) | 60µ 损耗 @50 kHz/1000 G | 60µ 损耗 @100 kHz/1000 G |
|---|---|---|---|---|---|
| Kool Mµ | FeSiAl | 14–125 | 1.0 | 215 | 550 |
| Kool Mµ MAX | FeSiAl | 14–90 | 1.0 | 210 | 550 |
| Kool Mµ Hƒ | FeSiAl | 26–60 | 1.0 | 120 | 325 |
| Kool Mµ Ultra | FeSiAl | 26–60 | 1.0 | 100 | 160 |
| XFlux | FeSi | 19–125 | 1.6 | 575 | 1280 |
| XFlux Ultra | FeSi | 26–60 | 1.6 | 450 | 1035 |
| Edge | FeNi | 14–125 | 1.5 | 150 | 375 |
| High Flux | FeNi | 14–160 | 1.5 | 250 | 625 |
| **MPP** | FeNiMo | 14–550 | **0.8** | 165 | 450 |

**MPP 的 0.8 T 是九列里最低的** —— 这一点直接决定选型：同样 5 A、同样匝数，
MPP 的可用磁通余量只有 XFlux 的一半。

`magnetics_data(kind="powder_cores")` 把这张表整块回读（`material_comparison_printed_page_10`），
不转述、不换算。

### 5.2 p.16 —— 密度、居里点、热膨胀、密度因子

`density_60u_g_cm3`（9 列）：5.8 / 6.5 / 6.0 / 6.0 / 6.9 / 7.1 / 7.8 / 7.6 / 7.8。
原文注明这是**磁芯 bulk 密度**（含粘结剂），不是合金密度。

`permeability_density_factors_60u` 11 项：14µ 0.85、19µ 0.89、26µ 0.91、40µ 0.96、
60µ 1.00、75µ 1.02、90µ 1.03、125µ 1.05、147µ 1.06、160µ 1.07、173µ 1.08。

**200µ / 300µ / 550µ 没有因子**（11 项对 14 个磁导率），所以这三个磁导率的
`mass_g` 是 `None`，`mass_basis` 写「refused rather than interpolated」。
质量公式本身是 `Ve(mm³) × 1e-3 × density_60u × factor`，且 p.16 原文把标称重量
推给单页数据表（“See individual data sheets for nominal core weights”），
所以每个 `mass_g` 都带 `mass_basis = "…estimate…"`。

### 5.3 料号结构与 AL 公差（p.17 / p.18）

`C055206A2` = `C0`（分级）+ `55`（MPP）+ `206`（目录号）+ `A2`（涂层耐压）。

AL 公差**由前缀与 OD 推**，不再逐行存：

| 前缀 | OD | 公差 |
|---|---|---|
| `C0` | > 4.65 mm | ±2 % |
| `C0` | ≤ 4.65 mm | ±5 % |
| `00` | 任意 | ±8 %（单值带）|

行级 `al_tolerance_pct` 在生成时被**刻意删掉**，只留规则 —— 一份数据只存一处。
注意 §3.4 的第 3 条异常（`CO58031A2`）会让 `part[:2]` 变成 `CO`，
`_powder_tolerance` 里 `.upper().replace("O","0")` 把它归一到 `C0`，所以这一格仍按 2 %/5 % 判，
而料号字符串本身**原样保留字母 O**。

## 6 接进 `select_core` 之后的行为

### 6.1 池与开关

```python
magnetics_select_core(inductance_h=100e-6, i_peak_a=5.0,
                      include_powder_cores=True,         # 默认 False
                      material="MPP", permeability=60,
                      freq_hz=100e3, b_ac_t=0.05, limit=1)
```

`core_pool` 报 `{parts, solid_cores, table, retrieved, permeability_filter, note}`。
`parts` 是**这次调用实际考虑的**粉末件数（narrow 之后），不是整表 1923 ——
MPP/60µ 是 **41** 件（该列该磁导率在 43 个尺寸里实际印了 41 格）。

`permeability` 单独给（不带开关）是 `ARG_INVALID`，不是静默忽略：
块状芯的 AL 由料号固定，这个参数对它没有意义。

### 6.2 一条被修掉的错答案

最初把 `permeability` 直接传给展开函数，于是 `material="MPP", permeability=55`
（该列**没有** 55µ）返回的是

```
NOT_FOUND  no core in the table uses material MPP
```

**这是错答案**：MPP 明明在表里。根因是「池被 55µ 过滤空了」被误读成「材料不存在」。
现在先按材料展开、过了材料/形状两道存在性检查之后再按磁导率收窄，报

```
NOT_FOUND  no powder core is printed with permeability 55
           permeabilities_printed: [14, 19, 26, 40, 60, 75, 90, 125, 147, 160, 173, 200, 300, 550]
```

`magnetic_data(kind="powder_parts", material="MPP", permeability=55)` 同样补上了
`permeabilities_printed`。这条属于「宁可报错不给错答案」里最难发现的一类：
**状态码是对的、文案是错的**。

### 6.3 饱和：一个列级数值，且明写「厂商没印温度」

粉末芯的 Bsat 只有 p.10 的**列级单值**，那一页**不印温度**。
用材料的温度路径（`_bsat_at(mat, 100.0)`）会把所有粉末环判成 `saturation_unknown`，
用 25 ℃ 冒充则是编数据。折中是：

* `b_limit_t = 0.8 × bsat_typical_t`（列值），
* 候选行里 `b_limit_temperature` 全文写出「not printed by the vendor - one typical
  value per column, not a 25 C or a 100 C number」，
* 饱和裁定文案也带上「no temperature printed for it」。

同时把材料表里缺的两个 `bsat_mt_25c` 补上：**MPP 800 mT、High Flux 1500 mT**，
两条 `bsat_note` 以 `CHANGED in 0.0.76, and not silently:` 开头，写明出自 p.10、
并说明该页不印温度、「25c」是本表约定、0.8 T 是九列最低。
`git diff --stat` 对 `data/magnetic_materials.json` 只有 **4 行**变动。

### 6.4 损耗：走厂商自己的环形拟合，不新造系数

`_core_loss_for` 新增一支：核带 `loss_fit_lookup` 就用
`_resolve_loss_fit(material, µ, "toroid", variant, f)` 命中那一行，再乘 `Ve`：

```
0055141A2 @100 kHz / 0.05 T
  fit    toroid 60u (a=72.15, b=2.103, c=1.449; mW/cm³, T, kHz)
  P_v    → × Ve 10.5 mm³ → 1.1 mW
  basis  "vendor printed fit toroid 60u (a=72.15, b=2.103, c=1.449; mW/cm3, T, kHz) x Ve"
```

三角形磁通（`flux_waveform="triangle"`, `duty=0.4`）走同一条 iGSE 路径，
`core_loss_basis` 多带一句 `iGSE shape ratio 0.93514`：正弦 1.1 mW → 三角 1.029 mW
（同一 `Ve`、同一工况），比率与 α=1.449 的三角/正弦比同量级。

`P_v_mw_cm3` 是 6 位有效数字、公开答案 4 位小数，所以测试按 `places=4` 比，
不再用比值比到 1e-6（那会拿舍入误差当失败）。

### 6.5 三处「不编」

| 项 | 行为 |
|---|---|
| 气隙长度 | `gap_mm = None` + `gap_because` 说明粉末芯的气隙分布在整块体积里、AL 不能靠切气隙修 |
| 平均匝长 / 铜损 | 目录不印 MLT ⇒ `winding.p_copper_w = None`、`missing` 含 `p_copper_w`、`missing_wire` 写「no mean turn length」，**不拿 `π(OD+ID)/2` 顶替** |
| 标称重量 | `mass_g` 是估计值，`mass_basis` 每行都说明 |

`not_modelled` 在粉末路径上追加 4 条：DC 偏置下的 AL 跌落、环无铜损、无离散气隙
（所以 `magnetics_fringing_loss` 不适用）、质量是估计值。

## 7 零变化，以及怎么证明

`include_powder_cores=False`（默认）走的是和 0.0.75 完全相同的路径。证明方式不是「看起来没变」，
而是把 0.0.75 的 `calc/magnetics.py` 取出来做**逐位对照**：

```bash
git show b7dda3f:src/pcb_agent_mcp/calc/magnetics.py > _scratch/oldpkg/pcb_agent_mcp/calc/magnetics.py
```

7 组 `select_core` 参数（含 `material="3C90"`、`flux_waveform="triangle"`、`temperature_c=25`、
`limit=5`）与 3 种 `magnetic_data`（materials / cores / all）的
`json.dumps(..., sort_keys=True)` **全部 identical（7/7、3/3）**。
测试里也钉死了默认路径的两个数：`table_rows == 16`、`feasible_count == 9`、
首候选 `B66283G0000X187` 的 41 匝 / 0.310308 T / 0.312 T / 0.81913 mm。
另外断言默认返回里**没有** `core_pool` 键、候选里**没有** `permeability` 字段 ——
谁把粉末表漏进默认路径，这两条会亮。
