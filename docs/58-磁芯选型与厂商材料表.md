# 58 · 磁芯选型：一张真厂商表，和每一个没填的数

0.0.54 的工具表里 `magnetics_inductor` 的描述结尾是这么一句：

> ... and, only if you supply a saturation current, whether that part is enough;
> no core selection and no material table lives here

这句话诚实，但它描述的缺口比读起来大：**没有材料表**意味着 `magnetics_inductor`
只能回答"你的绕组要扛多少安匝、峰值磁密多高"，回答不了"哪个买得到的磁芯装得下这个
电感、要多少匝、要不要开气隙、会不会饱和、窗口塞不塞得进"。0.0.55 补上这一段。

补的方式不是"算一个最佳答案"，而是**先要一张带来源的表**，再对每个候选部件逐条点名
它为什么行、为什么不行。一句话结论：

> **表里每一个数都能点开来源；每一个取不到的数都是 `null` 并写明缺什么；
> 饱和只在厂商公布过的那个温度上判、中间温度不插值；损耗是一个实测点、不是一条曲线。**

## 58.1 表的来源：能核的写，核不到的写 `null`

`data/magnetic_materials.json`（12 种材料、16 个磁芯，`verified: true`，
`retrieved: 2026-10-31`）每行都带 `source` 数组。两个对照说明纪律：

| 字段 | N87 | N27 |
| --- | --- | --- |
| `mu_i` | 2200（注：标称值，25 ℃） | 2000（同） |
| `bsat_mt_100c` | **390**（厂商页面明写 100 ℃） | **410**（E 42/21/15 的 N27 页明写） |
| `bsat_mt_25c` | `null` + "厂商没在这个页上给 25 ℃ 值，所以留空而不是回忆一个" | `null`（同） |
| 损耗参考点 | `pv_ref = 375 kW/m³ @ 200 mT / 100 kHz / 100 ℃` | **`pv_ref = null`**，只有 `pv_quoted_unconditioned_kw_m3 = 920` + 说明"页面给了 920 但可达的那段没写工况，所以只当引文、不当参考点" |
| `steinmetz` | `null` | `null` |

**N27 那一行是这个仓库里最值钱的一格**：920 kW/m³ 这个数字是对的，但少了
(B, f, T) 三件套它就不是一个可以拿来算的数——同样的 920 kW/m³ 在 200 mT/100 kHz
和在 100 mT/300 kHz 下对应完全不同的材料。所以它被降级成一个"引文"字段，
`schema` 里根本没有让它参与任何计算的路。宁可少一个数，也不让一个没有工况的
损耗密度混进答案。

其余取不到的字段，一律 `null` + 说明（28 行里没有一行是空的 `source`；16 个磁芯里只有 `B67410A0105X087` 几何全空——厂商页面只给了 390 g 质量）。`what_this_is_not` 里把四条边界写死：

1. **不是 Steinmetz 拟合**。TDK / Ferroxcube 的 `Cm/x/y` 在材料 PDF 里，
   2026-10-31 用 `web` 抓 `product.tdk.com` / `ferroxcube.com` 全部失败（JS 渲染），
   所以 `steinmetz` 一个都没填；`select_core` 只在**调用方自己给两个指数**时
   才把实测点外推。
2. **不是热模型**。一个部件的 `Rth` 都没找到 ⇒ 只报瓦，不报温升。
3. **不是 B-H 曲线**。`bsat` 是一个点（好一点是两个温度的两个点），点之间的形状、
   AL 的直流偏置跌落、AL 的温度系数全都没有。
4. **不是全型号**。只收录厂商页面真的写全了几何的行；缺的行是"缺"，不是"填一个典型值"。

材料侧还有三条容易踩的：3C90 只有 **25 ℃ 的 470 mT**（100 ℃ 没有）；Kool Mµ 的
Bsat 是 **1050 mT**（粉芯，不是铁氧体，μ 随牌号 14–125）；MPP 的 `tc_min_c = 460`
来自二手分销页，`density` 也是——来源标了二手，读数照用但可追。

## 58.2 匝数是两条约束里大的那个

给定 (L, Ipk)，匝数不是"算一个"，是两个下界取大：

    N_al = sqrt(L / AL)                 电感量要求
    N_b  = L · Ipk / (B_lim · A)        磁密上限要求
    N    = max(ceil(N_al), ceil(N_b), 1)

`A` 用 **`Amin`**（厂商给了就用），不是 `Ae`——中心柱比外腿窄的磁芯里，通量峰在窄柱上。

同一次调用里两个下界都报出来，因为它们回答两个不同的问题。ELP 18/4/10（N87）在
100 µH / 3 A / 0.3 T 下：`turns_from_al = 6.201737`、`turns_from_flux = 25.445293`
⇒ **N = 26**、`b_peak = 0.2936 T`。这里磁通约束是真正的约束：AL 只要求 7 匝，
但 7 匝会把峰值推到 1.09 T，早就没磁芯了。

**这解释了为什么"电感 ×1000"不是"匝数 ×31.6"**：小电感时 `N_al` 赢（匝数随 √L 走），
大电感时 `N_b` 赢（匝数随 L 线性走）。同一件 PQ 20/16（N87）：100 µH → **16 匝**，
100 mH → **15823 匝**，比值 989.4，几乎正好 1000。谁赢由 L 决定，不是常数。

## 58.3 饱和：只在厂商公布过的温度上判，不插值

`b_limit_t` 有两个来源，优先级固定：

1. 调用方给了 `b_max_t` ⇒ 就用它（"这是你定的，不是材料说的"，`b_limit_basis` 明说）。
2. 否则 `bsat_derate × Bsat(material, temperature_c)`，`bsat_derate` 默认
   **0.80**（设计余量，不是材料参数）。

`temperature_c` 只认表里有 Bsat 的那些温度（现在就是 **25 和 100 ℃**）。
中间温度**不做线性插值**——Bsat 在 Tc 之前不是线性的，插出来的数没有来源。
材料在该温度没有数据 ⇒ 这个部件进 `unjudged`：

```json
{"part": "PQ20/16-3C90", "reason": "saturation_unknown",
 "because": "3C90 has no published Bsat at 100 C in this table", "material": "3C90"}
```

实测最能说明问题的一对读数（100 µH / 3 A，只筛 3C90）：

- 25 ℃ ⇒ **6 个可行**；
- 100 ℃ ⇒ **0 个可行 + 6 个 `unjudged`**，且 `status` 仍是 `ok`。

这个决定改过一版。第一版是"材料缺 Bsat 就整次调用返回错误"——那样一个缺 100 ℃
数据的材料（3C90 就是）会把整个问题打死，哪怕问题本身是可答的。现在的形态是
**能判的照判，判不了的按名挂起**：`unjudged` 在顶层，`rejected` 里不混。

`bsat_derate` 是可调的：同一批部件 `derate=0.4` 与 `0.8`，前者匝数只增不减
（磁密上限收紧 ⇒ `N_b` 抬高），且 `derate=0.8` 时报出的 `b_limit_t` 逐位等于
`0.8 × 0.390`。

## 58.4 气隙：串联磁阻差，无边缘修正

    g = µ0 · A · N² / L − le / µi

也就是"要达到这个电感，磁路总磁阻需要多少；减去磁芯本身的磁阻，剩下的就是气隙"。
用了 `Amin`（同上）与 `mu_i`（标称值）。**没有边缘修正**——真实气隙的边缘场让有效
面积变大、所需机械气隙略小；`gap_basis` 把这句话原样输出，不假装有修正。

一个容易误判的情形：**已经开过气隙的部件**。PQ20/16-3C90-A250 的 `AL = 250 nH`
（气隙 295 µm、µe 120），算出来 `al_ratio = 1.0`、`gap_required = false`、
`gap_mm = null`。如果只看 `N = ceil(N_al)` 这一条，它会被误报成"需要再开气隙"。
所以加了 `GAP_NEEDED_BELOW = 0.90` 的容差带：`AL_required / AL_published < 0.90`
才说"需要加气隙"，同时输出 `al_ratio` 与 `l_at_n_ungapped_h` 让读者自己复核。

同一件 PQ 20/16 的三种情形（100 µH / 3 A / 0.3 T）：

| 部件 | N | b_peak | al_ratio | gap_mm |
| --- | --- | --- | --- | --- |
| PQ20/16-3C90 | 17 | 0.298597 | 0.106468 | 0.208453 |
| PQ20/16-3C90-A250 | 20 | 0.253807 | 1.0 | `null`（无需再加） |
| B65875B0000R087（N87） | 16 | 0.296677 | 0.126008 | 0.186405 |

## 58.5 损耗是"一个点"，不是一条曲线

表里每个磁芯最多带**一个**厂商实测点（`loss_ref`，带 `b_mt` / `f_khz` / `temp_c`）。
`select_core` 的取值路径是四级，逐级变严：

1. Steinmetz（表里恒 `null`，路径保留，将来谁真填了三元组就走这条）；
2. 厂商实测点，且**调用方的工况与它的工况逐项相等**（相对容差 1e-6）⇒ 原样复现；
3. 否则要求 `loss_exponents=(x, y)`，按 `P = P_ref · (f/f_ref)^x · (B/B_ref)^y` 外推；
4. 再否则 `core_loss_w = null` + "未知不是零"的说明（`core_loss_basis`）。

实测（U20/16/7-3C90 的实测点是 `1.9 W @ 200 mT / 25 kHz / 100 ℃`）：

| 调用 | `core_loss_w` |
| --- | --- |
| `freq_hz=25000, b_ac_t=0.2` | **1.9**（"the vendor's own measured point"） |
| `freq_hz=100000, b_ac_t=0.2` | `null`（"工况不是实测的那个；把单点搬离工况要 `loss_exponents`"） |
| 同上 + `loss_exponents=[1.6, 2.5]` | **17.460215** |

17.460215 就是 `1.9 × (100/25)^1.6 × (0.2/0.2)^2.5`——外推公式逐位可复核，
而 `x`/`y` 是**调用方的假设**，工具不替材料认领。

`b_ac_t` 的语义写死在参数说明里：**交流磁密幅值**（峰峰的一半），不是峰峰值。
单位滑一档，损耗差 2.5 个数量级。

## 58.6 绕组与窗口：只在该部件真有骨架数据时判

`i_rms_a` 一给就算绕组：

    Awire = Irms / J,   R_dc = ρ(T) · N · MLT / Awire,   P_cu = Irms² R_dc

ρ(T) 用铜的温度系数、MLT 用厂商的骨架平均匝长。窗口只有**真给了 `aw_mm2`**
的部件才判：`N · Awire / k_u ≤ Aw`。E 42/21/15（N87，来自 Ferroxcube CP-E42/21/15-1S
的骨架数据 `aw = 178 mm²`、`mlt = 93 mm`）在 2 A rms / 5 A·mm⁻² / k_u = 0.4 下：

| 量 | 读数 |
| --- | --- |
| `wire_area_mm2` | 0.4 |
| `copper_area_mm2` | 2.4 |
| `r_dc_ohm` | 0.031611 |
| `p_copper_w` | 0.126444 |
| 窗口需求 / 实际 | 6.0 / 178 mm² ⇒ `window_fits = true` |

其余部件 `window_fits = null` 并进 `window_image` 提示——"能选但没验窗口"比
"假装验过"诚实。要严格只留验过的，传 `require_window_fit = true`，它们会以
`window_unchecked` 出局。

绕组只算 **DC**：趋肤/邻近效应在 `magnetics_winding_ac` 里（Dowell 的 `F_R`），
两个工具不互相冒充。

## 58.7 拒答一律带名字

`verdict` 只有 `feasible`；出局的进 `rejected`，每个都带 `reason`，取值是封闭集：

| `reason` | 含义 |
| --- | --- |
| `saturates` | 算出的峰值超过 `b_limit_t`（附 `b_peak_t` 与 `bsat_t`） |
| `saturation_unknown` | 该温度上材料没有公布 Bsat ⇒ 进顶层 `unjudged` |
| `window_overflow` | `N·Awire/k_u > Aw` |
| `window_unchecked` | 只有 `require_window_fit=true` 时出现 |
| `no_geometry` | 表里几何为 `null`（如 QU 100/40/20 只有 390 g 质量） |
| `material_filter` / `shape_filter` | 被调用方的筛选条件排除（仍列出，不静默消失） |

材料名或形状认不出 ⇒ `NOT_FOUND`，并且把 `materials_in_table` / `shapes_in_table`
一起返回（"拼错了"和"表里没有"要能分开）。

排序：`feasible` 按 `ve_mm3` 升序（同尺寸里先给体积小的）。`limit` **只截返回的
列表，不改计数**——`feasible_count` 永远是全量。

`not_modelled` 固定输出一段：无 Rth ⇒ 不给温升；DC 偏置下的 AL 跌落、气隙边缘场、
绕组 AC 损耗、AL 容差、任何 Steinmetz 拟合都不算。

## 58.8 默认答案不变的自证

这一版对既有实现是**纯追加**：`git diff` 在 `magnetics.py` 里只删了 3 行 docstring
（`no core selection and no saturation curve from a real material` 那段改成
`select_core` 的边界说明），在 `tools.py` 里只删了 5 行工具描述文字。可执行代码
一行未删、一行未改。

- `magnetics_inductor` / `magnetics_core_loss` / `magnetics_dcm` /
  `magnetics_winding_ac` 的答案与 0.0.54 逐位相同（新参数全部有默认值，
  且旧函数签名未动）；
- 新增的 `magnetics_select_core` / `magnetics_data` 是**新工具**，不改任何旧读数；
- `TOOLS` 从 162 增到 164，既有工具名一个未变；
- 旧测试 2441 例照跑，新增 36 例只在新文件里；全量回归 **2477 例 / OK / 2031.147 s**。
  唯一跟着动的一条是**故意**的：`test_vibration_mass_copper` 里的工具数闸门 `162` → `164`
  ——那条测试就是为"工具数不能悄悄长"写的，加工具必须显式抬它一格（本轮它先失败了，
  抬完再跑干净；这正是闸门有牙的证据）。

## 58.9 边界（这一版仍不做的事）

- **无热**：没有 Rth，不报温升、不报"这个损耗下会不会过温"。
- **无 Steinmetz**：表里三系数全是 `null`；外推必须调用方给 `x, y`。
- **无 B-H 曲线**：Bsat 只有点（25 / 100 ℃ 两个温度），不插值、不给曲线形状。
- **无直流偏置 AL 跌落**：粉芯（Kool Mµ/MPP/High Flux）在大直流下 AL 掉得很厉害，
  这一版不建模——所以粉芯的匝数会**偏乐观**，这是已知方向的偏差。
- **无气隙边缘场修正**：`gap_mm` 是磁阻差，机械气隙要略小于它。
- **无 AL 容差区间**：`al_tolerance_pct` 在表里（有就抄），但选型不用它做最坏情况。
- **不是全型号**：16 个磁芯不是"能买到的磁芯"，是"厂商页面写全了几何的磁芯"。
- **窗口只有 1 个部件有骨架数据**：其余 `window_fits = null`。
- **绕组只有 DC**：AC 在另一个工具里。

## 58.10 判据与负控制一览

`tests/test_magnetic_select.py`（36 例，全 PASS）与 `server.py` 的 4 条 selftest
（193 → 197）一一对应，每条判据都配了一条能翻脸的控制：

| 判据 | 负控制 |
| --- | --- |
| 每行都有 `source` | 材料/磁芯计数与 `verified` 断言；缺字段必须 `null` 且带 `*_note` |
| 实测损耗点带工况 | N87 的 `pv_ref` 必须有 `(b_mt, f_khz, temp_c)`；N27 只有 920 这个裸数时 `pv_ref` 必须为 `null` |
| 表里没有 Steinmetz 三元组 | `test_no_steinmetz_triple_is_invented`：谁真填了，这条会主动失败，提醒重定外推路径 |
| `b_peak == L·Ipk/(N·A)`（A 用 Amin） | 用 `Ae` 重算会不等（RM10/I 的 89.1 vs 96.6） |
| 匝数是"够用的最少" | `test_where_flux_decides_the_answer_is_one_turn_short_of_failing`：少一匝必须越限（且只在磁通约束是活约束的部件上判） |
| 磁密上限收紧 ⇒ 匝数不减 | `b_max_t` 0.30 vs 0.15 逐部件比 |
| 电感 ×1000 ⇒ 匝数 ×~1000（磁通主导） | 比值必须落在 950–1050（单位滑档 mH/H 会露馅），且两种情况下 `b_peak` 都贴在上限 |
| 峰超材料 Bsat ⇒ 按名 `saturates` | 同一部件 `b_max_t=0.3` 仍 `ok`（不是"全都给拒了"） |
| 材料缺该温度 Bsat ⇒ `unjudged` | 3C90 25 ℃ 6 个可行 vs 100 ℃ 0 个可行 + 6 个挂起 |
| `derate` 只收紧不放松 | 0.4 的匝数 ≥ 0.8 的匝数；且 0.8 的 `b_limit_t == 0.8×0.390` |
| 无材料也能答（给了 `b_max_t`） | 60 ℃（表里没有的温度）仍 `ok` |
| 气隙 = 磁阻差 | 手算 `µ0·A·N²/L − le/µi` 复现 |
| 已带气隙的部件不加气隙 | A250 的 `al_ratio == 1.0`、`gap_mm is None` |
| 只有 Amin 更小时才用它 | `flux_area_mm2` 逐部件 ≤ `ae_mm2` |
| 实测点在同工况下逐位复现 | `100 kHz` 对 25 kHz 的部件必须 `null`——若忽略工况，这里仍会是 1.9 |
| 外推服从 `(f/f_ref)^x·(B/B_ref)^y` | 指数为负 ⇒ `ARG_RANGE` 拒答；50 kHz/0.1 T 带指数时逐位等于公式值 |
| 无实测点的部件说"未知"不说 0 | `core_loss_w` 是 `None` 且 `core_loss_basis` 含 "not zero"/"needs" |
| 排序按体积 | 相邻候选 `ve_mm3` 非降 |
| `limit` 只截列表不改计数 | `feasible_count` 与 `len(candidates)` 分离 |
| 无几何的部件按名拒，不静默丢 | QU 100/40/20 ⇒ `no_geometry` |
| 只有有骨架数据的部件才有窗口判 | 其余 `window_fits is None`；`require_window_fit=true` 时变成 `window_unchecked` |
| 铜损用骨架平均匝长 | `p_copper == Irms²·ρ(T)·N·mlt/Awire` 复现，且窗口需求 `== Awire·N/k_u` |
| 不给温升 | 输出里没有任何 `*_c` 的温升键（`test_no_temperature_rise_is_offered_at_all`） |
| 未知材料/形状 ⇒ `NOT_FOUND` + 清单 | 拼对的材料名 ⇒ `ok` |
| 未验证的表拒收 | `verified: false` 的临时表 ⇒ 具名错误；表文件缺失同理 |

**「宁可报错不给错答案」在这里的三处落地**：缺 Bsat 不插值、单点损耗不外推、
没骨架不算窗口。三处都能给出一个"看起来能用的数"，也都没给。

## 58.11 与 0.0.54 的关系

一句话：**0.0.54 让 SPICE 不再静默忽略卡片，0.0.55 让磁件不再假装有选型。**
两者是同一条纪律的两面——拒绝回答要带名字，能回答的要带来源。
