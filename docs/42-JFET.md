# 42. JFET `J`：平方律里没有那个 1/2

`0.0.35` 之后按名字拒绝的清单只剩 `J`、`A`。这一篇记 `J`（结型场效应管，level-1
Shichman-Hodges）进内置的过程——它**不像开关**那样只是换一条电导，也不像传输线那样能拆成一堆
线性元件：它需要一条新的器件方程。但它也不是 MOS 的复制粘贴：**同一份 `BETA` 与同一条
`Vgs-VTO`，JFET 读出来是 MOSFET 的两倍**，因为这条方程里没有那个 `1/2`。

这一篇的每个数字都是对着 `ngspice-47` 逐点量出来的，不是从教科书抄的：教科书同时写着
「`Id = (BETA/2)(Vgs-Vto)^2`」与「`Id = BETA(Vgs-Vto)^2`」两种形态，选错了答案差一倍，
而两种写法在页面上都长得像对的。

---

## 42.1 一张卡、三个端子

```
Jname nd ng ns model [AREA=<x>] [OFF]   ; drain / gate / source，没有 bulk 端
```

三个端子是 JFET 与 MOSFET 最硬的区别之一：`M` 卡是四端子（`nd ng ns nb`），因为 MOS 的衬底要
单独接；JFET 的沟道就是衬底，栅是一个**反偏的 PN 结**，所以只有三个。写四个端子在解析期就会被
按下来并提示 `three nodes (drain, gate, source)`，而不是悄悄把第四格当 `AREA=`。

尾部只接受两种东西：`AREA=<x>`（正数）与裸的 `OFF`（只作初始状态的种子，`OFF` 不改变工作点
答案——与 `41` 的 `S`/`W` 同一条口径）。其余一律点名拒绝。**`W=` 与 `L=` 在 `J` 卡上由 ngspice
自己拒绝**（`unknown parameter (w)`），所以这里直接说清「这是引擎的限制，不是本子集的遗漏」，
免得调用方以为是自己写错了。

## 42.2 平方律：不是 MOSFET 的公式

本实现拍下去的两条（`s = +1` 为 NJF，`s = -1` 为 PJF；`Vov = s·Vgs - VTO`）：

```
饱和  Vds >= Vov :  Id = BETA_eff * Vov^2        * (1 + LAMBDA*Vds)
线性  Vds <  Vov :  Id = BETA_eff * (2*Vov*Vds - Vds^2) * (1 + LAMBDA*Vds)
```

关键在**没有 `1/2`**。测试里把这一条写成反向断言：`BETA=1m`、`Vov=1` 时读数必须
`== 1.000 mA` 且 `assertNotAlmostEqual(0.5e-3)`——如果哪天有人「顺手」补上 `1/2`，这条会立刻
变红，而不是变成一个看起来更保守的曲线。MOS 卡（`M`）在同一个 `BETA` 下读的是 `0.5 mA`，两者
在同一个仓库里并存，正是最容易被抄错的地方。

`gm_s` 一律是 `dId/dVgs`，与 Jacobian 一样用**数值微分**算（`±1e-6 V` 中心差），所以不存在
第三条公式跟求解器吵架。两式求出来恰好长得像「分别对 `Vov` 与 `Vds` 求导」：

| 区域 | `Id` | `gm = dId/dVgs` |
|---|---|---|
| 饱和 | `BETA_eff·Vov²` | `2·BETA_eff·Vov` |
| 线性 | `BETA_eff·(2·Vov·Vds − Vds²)` | `2·BETA_eff·Vds`（`Vds` 不进导，故只剩这一项） |

`Vds=0.3 / Vov=1 / BETA=1m` 读 `0.51 mA`、`gm = 0.600 mA/V`；`Vds=5` 读 `1.000 mA`、
`gm = 2.000 mA/V`。这两组数同时钉住了「两式各自是什么」与「报告说的是哪一个区域」——不需要
额外的 `region_is_trusted` 之类字段来暗示。

`LAMBDA` 是沟道长度调制：`Vds=1.5` 与 `Vds=5.0` 在 `LAMBDA=0` 时读同一个数，`LAMBDA=0.02`
时 `5 V` 读 `1.1 mA`（`1.0·(1+0.02·5)`）。这一条也写进了测试。

极性是**镜像**而不是「取绝对值」：PJF 的 `Vd=-5 / Vg=+0.5 / VTO=-1` 给出 `id = -0.25 mA`、
`vds = +5`、`vgs = -0.5`、`vov = 0.5`、`gm = 1e-3`、`power = 1.25e-3`，与 NJF 的
`Vd=+5 / Vg=-0.5` 逐项镜像相等。写错符号在这里不会是「差一个负号」，而是整条曲线翻到不导通。

## 42.3 区域交界不需要平滑

两条式子在 `Vds = Vov` 处**精确相接**：代入 `Vds=Vov` 得线性式 `BETA(2Vov² − Vov²) = BETA·Vov²`，
与饱和式同一值。所以区域边界既不需要 `smooth` 项、也不需要在迭代里做过渡——这与 MOS 的
`Vdsat` 附近需要小心处理不同。测试里 `Vds = Vov = 1` 读 `1.000 mA` 且 `region == "saturation"`
（用 `>=` 判饱和）；两侧实测：`Vds=0.999` 读 `0.999999 mA`（`region=linear`、`gm=1.998 mA/V`），
`Vds=1.001` 读 `1.000 mA`（`region=saturation`、`gm=2.000 mA/V`）——值不断，斜率换了一条。

## 42.4 AREA：卡覆盖模型，不是相乘

`AREA` 是这张卡唯一的几何旋钮（没有 `W`/`L`，见 §42.1）。语义是：

```
BETA_eff = BETA * AREA
```

**卡上的 `AREA=` 覆盖（REPLACE）`.model` 里的 `AREA=`，不是相乘。** 实测：`.model ... AREA=2`
配 `J1 ... AREA=3`，读到 **3×** 而不是 6×。这一条在测试与 selftest 里都写成反向断言
（`assertNotAlmostEqual(6e-3)`），因为「相乘」是更容易想到的语义，而且它给出的答案**同样自洽**：
乘法只会让电流偏大两倍，而页面上没有任何东西会说「你多乘了一次」。

缺省 `AREA=1`，`AREA<=0` 拒绝（面积因子要缩放跨导，零或负没有物理意义）。

## 42.5 缺省值必须公示

`.model jm NJF()` 什么也不写时，本实现用的是 `ngspice` 的缺省（实测）：

```
VTO = -2.0 V    BETA = 1e-4 A/V²    LAMBDA = 0    AREA = 1
```

于是 `Vgs=0` 时 `Vov=2`、`Id = 1e-4·4 = 4e-4 A`。这个数看着很像一条真实的耗尽型管子，正因为
如此它必须**说出口**：`assumptions.defaulted_model_params` 会列出每个被缺省掉的参数
（`{"jm.vto": -2.0, "jm.beta": 1e-4, "jm.lambda": 0.0, "jm.area": 1.0}`），只指定一部分时只剩
缺省的那几个（例如给了 `VTO`/`BETA` 后只剩 `["jm.area","jm.lambda"]`）。

一条用缺省 `VTO=-2` 去对实际 `VTO=-1` 的管子，画出来的曲线是**平滑、单调、看起来完全合理**的，
只是整体平移了一倍——这类错误只有在参数被公示时才可能被发现。

## 42.6 栅结：不建模，但要说出越界了

真实的 JFET 栅是一个反偏 PN 结：正常工作时它不取电流（这是 JFET 的**定义性**特征），而正向
偏到 ~0.7 V 以上时它会导通、钳位、并毁掉管子的输入阻抗。

本子集**不 stamp 这个结**（栅极永远不取电流）。这在反偏与轻正偏下是**精确的**，越界之后是错的。
所以报告给 `gate_junction_forward_v`（栅相对沟道的最大正偏量），并在超过 **0.5 V** 时：

- 器件报告加 `outside_model`（说明「这个 deck 正偏了本模型没有的栅结」）；
- 同一条消息 append 到 `circ.disabled`，也就是信封的 `warnings`。

**正偏方向是实测的，不是从手册推的**（这一条很容易写反）：

| 类型 | 正偏量 | 实测证据 |
|---|---|---|
| NJF | `max(vg − vd, vg − vs)` | `Vg=-4`、源接地：栅流 3.14 A，栅结钳在 ~0.86 V（与 `IS=1e-14` 的二极管指数一致） |
| PJF | `max(vd − vg, vs − vg)` | 同上镜像：PJF 是栅**低于**沟道才正偏 |

`Vg=0.3`（`VTO=-1`、源接地）时 `fwd=0.3`、**没有** `outside_model`、`warnings == []`；`Vg=1.0`
时 `fwd=1.0` 且被标记。5 V 正偏在一只 36 mA 的器件上实测只偏 1 mA——也就是说这条边界不是
「一过 0.5 V 就天翻地覆」，而是**从这一侧开始答案不再属于这个模型**，界线画在能说清的地方。

0.5 V 这个数不是物理阈值（真结在 0.5~0.6 V 就开始明显导通），它是**报告口径**：在这个数量级
以下，栅流对工作点的影响小于本子集其他近似（无 `RD`/`RS`、单温度）的量级。写成常数而不是
「按 `IS` 算」，是因为本子集没有 `IS`，算出来的「结电压」只可能更假。

## 42.7 拒绝清单：每条都实测「不拒会错多少」

按名字拒绝的 15 个参数，理由不是「没实现」，而是**放行它会让答案错、且错得看不出来**：

| 参数 | 为什么拒 | 实测 |
|---|---|---|
| `RD` | 漏极串联电阻是**内部节点**（端子与沟道之间），会移工作点也移跨导 | `RD=100`、`Vd=0.2` 下电流变 **14%** |
| `RS` | 同上，源极侧 | `RS=100` 变 **16%** |
| `B` | level-1 的掺杂尾巴参数，**不是**这套平方律 | `B=2` 读 **1.5×**、`B=0.5` 读 **0.75×** |
| `IS` `PB` `MJ` `FC` | 全部是栅结二极管的参数，本子集没有栅结（见 §42.6） | 建模它会在正偏侧给出完全不同的解 |
| `CGS` `CGD` | AC 分析里本子集**没有器件电容**（只有 `C` 卡充电） | 放行会在每条 AC 曲线上静默丢掉这些电容 |
| `KF` `AF` | 噪声报告只有沟道热噪声，没有 `1/f` | 放行会给出「安静」的假答案 |
| `TCV` `BEX` | 本子集只在一个温度（27 °C）求解，不缩放 `VTO`/`BETA` | 放行等于假称有温度模型 |
| `BETA1` `LAMBDA1` | level-2 模型的参数，本子集只实现 level-1 | 放行会把两套方程混着用 |

三个例外按缺省值放行：`RD=0`、`RS=0`（零就是引擎自己的缺省：没有内部节点）、`B=1.0`（1.0 就是
引擎缺省：平方律本身）。这三条也测了——`RD=0 / RS=0 / B=1` 的 deck 必须正常出答案。

`BETA<=0`、`LAMBDA<0`、`AREA<=0` 另外拒绝：负的 `LAMBDA` 会让饱和电流随 `Vds` **下降**，
零/负 `BETA` 让器件完全不导通——两者都是「跑得动、但方程已经不是这条」。

## 42.8 三口径对账

| 口径 | 判据 | 数字 |
|---|---|---|
| 手算 | `Vds` 族 0.1 / 0.3 / 1.0 / 1.5 / 5 / 10 | 两式分段 + `Vds=Vov` 相接 + `λ` 斜率 |
| 偏置网络 | `Vdd=12 / Rd=4.7k / Vg=-0.4 / VTO=-1 / BETA=2m` | `Id = 0.72 mA`、`Vd = 8.616 V`、`power = 8.616·0.72 mA` |
| 源极退化 | `Vg=0 / VTO=-2 / BETA=1m / Rs=1k` | `Vs = 1 V`、`Vd = 7.3 V`、`Id = 1 mA`（二次方程另一根 4 mA 因 `Vov<0` 不成立） |
| 对 ngspice（DC） | `Vds` 族六个点逐节点 | 逐位 `< 1e-8`（`8.616` 这类值差 4e-8 = `gmin` 量级，故用 `delta=1e-6`） |
| 对 ngspice（AC） | 共源 `gm=4 mA/V`、`Rd=1k` | 增益复数差 `< 1e-6`（`4.0∠180°`，实部 `-4`） |
| 对 ngspice（瞬态） | `Rd=1k / C1=1u / PULSE(-2 0 …)` | 跳过 0.9~1.2 ms 台阶窗，尾段最差 < 12 V 的 **1%** |
| 噪声 | `4kT·(2/3)·|gm|`、`c["J1"]/c["Rd"] = (2/3)·gm·Rd` | 相对误差 `< 1e-9`；机制列表恰为 `["channel_thermal"]` |

瞬态尾段的 1% 与 `0.0.35` 开关边沿同源：本内置求解器是**固定步长**、引擎自适应细步，差异集中在
栅压跳变那一小段，不在方程的其余部分。AC 与 DC 是逐位对上的——这才是「平方律写对了」的证据。

噪声只给 `channel_thermal = 4kT·(2/3)·|gm|`（漏→源），**没有**栅结 shot noise、没有闪烁噪声：
前者的载体（栅结）不存在于本模型，后者被 `KF`/`AF` 拒绝。机制名固定为 `channel_thermal`，
`test_spice_jfet.py` 断言机制列表**恰好**是它——多出一个机制就意味着悄悄补了物理。
