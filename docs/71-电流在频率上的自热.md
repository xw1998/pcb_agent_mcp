# 电阻乘上电流乘上 Rth 就是温度 —— 只是这一次它不是一次乘法

日期：2026-11-01　工具：`ac_self_heating(...)`（`calc/acthermal.py` 新增，纯 stdlib）

前面三篇（`68` PDN 阶跃、`69` 薄板趋肤、`70` 圆导体趋肤）都在回答同一类问题：
**这根铜在频率上是多少欧姆**。`electrothermal_conductor` 早就在回答另一类问题：
**这根铜在 DC 下会热到多少度**。中间那一环一直是空的，而且 `calc_capabilities`
把它写在明面上：

> nothing here turns a loss into a temperature **at frequency**

`electrothermal` 自己的 `not_computed` 也说：

> P = I²·R is wrong for RF ... **nothing in THIS module changes**

这一篇填的就是这一环。它看起来像一次乘法（`P = I²·R`），实际上不是 ——
因为 **R 自己就是温度的函数**，而当电流被挤进一层壳里时，这个函数不是仿射的。

---

## 1 判据

一条判据如果不是能被违反的，它就不是判据。这一轮的五条：

| # | 要守住的事 | 能被什么违反 |
|---|---|---|
| 1 | 低频极限必须**等于** DC 解 | 任何 1000 倍量纲错、任何把 `R(元件温度)` 当 `R(20 ℃)` |
| 2 | `dT = I²·Rth·R(Ta+dT)` 是**定义**，不是近似 | 任何只做一次乘法的实现 |
| 3 | `dlnR/dlnrho ∈ {0.5, 1}` 是**测出来的**指数 | 任何硬编码 β、任何在薄壁下仍报 0.5 |
| 4 | 两种 runaway 是**两个不同的答案** | 合并成一句文案 |
| 5 | 熔点以上的根只能叫**排序**，不能叫读数 | 把 37326 ℃ 当温度报出来不带警告 |

第 4 条是这一轮最贵的一条，见 §4。

## 2 模型：一个求值入口，不是两套公式

```
ρ(T)   = ρ20 · (1 + α·(T − 20))          α = 0.00393 /K（线性，0…100 ℃）
R(T)   = 输入频率 f、输入 ρ(T) 的**那一个** AC 电阻（薄板 → calc/skin.py；
         实心/圆管 → calc/roundwire.py）
P(T)   = I² · R(T)
T      = Ta + P·Rth
```

求解的是

```
g(dT) = dT − I²·Rth·R(Ta + dT) = 0
```

关键实现约束：**R(T) 只有一处求值**。第一版里 `ac_self_heating` 内嵌了一份 `r_at()`
副本、圆导体分支还用 `globals()["_rho_ohm_mm"]` monkeypatch 进去，于是"求解用的 R"
和"测 β 用的 R"可以是两个不同的函数 —— 那种错不会报错，只会给出一个自洽但错数。
现在只有：

```python
def _one(geom, f, t_c, mur, rq_m, rho20=None, alpha=None):   # 唯一入口
def r_at(t_c): return _one(geom, f, t_c, mur, rq_m, rho20, alpha)
```

**为什么是二分而不是定点迭代**：`dT ← I²·Rth·R(Ta+dT)` 在这类问题里不是压缩映射
（这正是"跑飞"的定义）。定点迭代发散时，"没收敛"和"根本没有解"给出的是同一个现象，
分不开。二分的符号变化本身就是**存在性证明**：`g(0) < 0` 且 `g(hi) > 0` ⇒ 中间必有根。
所以不存在的稳态会以 `THERMAL_RUNAWAY` 返回，而不是返回一个跑飞的迭代值。

`R(T)` 在 `dT` 上是凹还是凸决定了根的个数 ≤ 1（`g` 的导数最多变号一次），
所以二分找的那个根就是唯一的那个根。

## 3 `dlnR/dlnrho` 是这一轮的枢纽

定义 `β ≡ dlnR/dlnρ`，**实测**（对 ρ 做中心差分，在解点算），不是假设：

- **趋肤主导**（`t ≫ δ`、电流只在表面一层）⇒ `R ≈ ρ/(w·δ) ∝ ρ/(√(ρ/f)) = √(ρ)` ⇒ **β = 1/2**
- **DC / 薄壁**（整块铜都载流，`t ≪ δ` 或壁厚 < δ）⇒ `R = ρL/A` ⇒ **β = 1**

`g(dT)` 的斜率是 `1 − I²·Rth·dR/dT`，而

```
dR/dT = R · α · β / (1 + α(T−20))
```

所以冷点增益（`gain_cold`）与 `β` 直接挂钩。**这一个数决定了"跑飞"是什么意思**：

| β | 冷点增益 ≥ 1 | 冷点增益 < 1 |
|---|---|---|
| **1**（DC / 薄壁） | 增益恒定 ≥ 1 ⇒ **任何温度都不是不动点**，抬上限也没用 | 代数根存在，位置随 1/(1−gain) 爆炸 |
| **1/2**（趋肤） | 电阻随温度涨得比 dT 慢 ⇒ **根必然存在**，只是很热 | 根存在，且不敏感 |

实测确认过：三个形状的 β 分别是 **1.0**（35 µm 铜 100 Hz）、**0.5000**（同铜 1 GHz）、
**0.999454**（0.3 mm 孔 + 0.5 µm 镀层 @ 1 GHz）、**0.952475**（0.5 mm 外径 + 50 µm 壁 @ 1 MHz）、
**0.50673**（0.5 mm 实心线 @ 100 MHz）。

## 4 两种 runaway，是两个答案

这是整轮里唯一一处"合并文案就等于骗人"的地方。

**（a）指数为 1，增益 ≥ 1 —— 代数死。**

0.1 mm 宽、35 µm 厚、20 mm 长、Rth = 20 K/W，12 A，100 Hz：

```
runaway_gain_cold        = 1.11502
dlnr_dlnrho_cold         = 1.0
unit_gain_current_a      = 11.3642
rth_for_root_at_melt     = 14.4088 K/W
→ THERMAL_RUNAWAY
message: no steady state at any temperature: g(dT) = dT - I^2*Rth*R(dT)
         is still negative at 1110 C (dT 1085 K), and with dlnR/dlnrho = 1.0000
         it stays negative for ever
```

抬搜索上限到 1e6 K 也没有根。它**真的**没有稳态，不是"太热了"。

**（b）指数为 1/2 —— 有解，只是没人造得出来。**

同一根铜，10 A，1 GHz：

```
dlnr_dlnrho_cold         = 0.5
runaway_gain_cold        = 6.42163
unit_gain_current_a      = 3.94618
root_beyond_melt_t_c     = 37325.8         （dT 37300.8 K）
rth_for_root_at_melt     = 2.8206 K/W
→ THERMAL_RUNAWAY
message: above the melting point: the self-consistent temperature would be
         37326 C (dT 37301 K), far past the 1085 C where ...
hint:    ... The 37326 C figure is extrapolated past melting: an ordering,
         not a reading
```

`37325.8 ℃` 这个数**只用来排序**（"比熔点高多少"），字段名与 hint 都写明
是外推。模型到熔点就失效了（线性 ρ 律、几何都失效），再往外给一个"温度"
就是在编。

### 4.1 这一轮修掉的一个真错答案

第一版的外推二分被一个条件包住：`if beta_cold < 0.999:`。逻辑是"指数为 1 时
代数上必无根，不用找"。**这个前提是错的**：指数为 1 只是让 `g` 变成一条直线
（斜率为 `1 − gain`），直线**照样可以穿过零**——只要冷点增益 < 1。

11 A 就是那个反例（同几何）：

```
runaway_gain_cold  = 0.93693   （< 1，11.3642 A 是单位增益电流）
dlnr_dlnrho_cold   = 1.0
→ 旧代码：no steady state at any temperature        ← 错答案
→ 现在：  root_beyond_melt_t_c = 3879.27（dT 3854.27 K），外推，给排序
```

"在 3879 ℃ 有一个自洽温度"和"任何温度都不自洽"是两个完全不同的陈述。
一处 `if` 就把它说反了。

**修法**：外推二分**无条件**执行；先找根，再按 β 选措辞；找不到才说
"no steady state anywhere"。这个顺序是唯一不可能说出那句错话的顺序。
自检里 12 A（无根）与 11 A（有根）成对出现，正是为了守住这一点：
一个笼统的答案不可能同时让这两条都过。

### 4.2 频率能不能把"无解"变成"有解"？

不能。**频率只增加电阻**（趋肤总是让 R 变大），所以高频永远更热。能变的只有
**失败形态**：DC 那种代数死（12 A）在高频会变成"根在 37 kK"。上面的 (a)/(b)
就是同一个电流档位、同一根铜、换频率得到的两种形态。

这一条是先量后写的：原本的猜想是"高频也许能把无解变成有解"，全扫
（w = 0.1 mm，I = 10/12/16 A，f = 1e2…1e10）之后被推翻，只保留了
"失败形态不同"这个真结论。

### 4.3 三个可执行的数

runaway 时给的三个数都是**设计能用**的，不是诊断：

- `unit_gain_current_a` —— 冷点增益到 1 的电流（`√((1+α(Ta−20))/(Rth·R_cold·α·β))`）
- `rth_for_root_at_melt_c_per_w` —— 把根压到熔点以下的 Rth 上限（`dt_melt/(I²·R(熔点))`）
- 以及 `rth` / `current` 里**该动哪一个**（hint 两个都给）

## 5 DC 对账，和那个 1.97 % 的负控制

`electrothermal_conductor` 是另一条通路、另一套代码、一个闭式解。指数为 1 时两者
**必须相等**。

100 Hz、35 µm、1 mm 宽、20 mm 长、3 A、Rth 20：

```
T        = 26.8208 ℃
dT       = 1.82079 K
R_cold   = 0.010045 Ω
R_hot    = 0.0101155 Ω
β        = 1.0
dc_linear_model_rel_diff = 3.042e-07
```

这个 `3.042e-07` 不是凑出来的 —— 它是两个独立实现用同一组输入算出的差。

**负控制**：`conductor_self_heating` 的参数是 **R at 20 ℃**，不是 R at 环境温度。
喂 `r_cold`（25 ℃ 的值）会差 `1 + α·5 = 1.0197`，即 **1.97 %**，远在 1e-6 带之外。
开发时正是这个 1.97 % 抓出了口径不一致；现在它被写成一条**必须失败**的测试
（`test_dc_limit_failure_it_catches` 断言 `rel ≈ 0.0197 ± 0.002`）。
一个"能通过"的对照不是对照。

## 6 三个形状的实测

35 µm 铜、1 mm 宽、20 mm 长、3 A、Rth 20 K/W：

| f | T (℃) | dT (K) | R_cold (Ω) | R_hot (Ω) | R/Rdc (cold) | β | gain | DC 模型差 |
|---|---|---|---|---|---|---|---|---|
| 100 Hz | 26.8208 | 1.82079 | 0.010045 | 0.0101155 | — | 1.0 | 0.00697 | **3.0e-7** |
| 1 GHz | 56.7733 | 31.7733 | 0.166611 | 0.176518 | 16.5865 | 0.5 | 0.0578 | **7.905 %** |

第二行的 `dc_linear_model_rel_diff = 0.07905` 是**报出来的差，不是误差棒**：

> β ≠ 1 时，DC 模型本身就是错的模型，不是"同一个模型多了点误差"。
> DC 说 1.58866 W，真值 1.58867 W？不——它说出来的温度是 56.77 ℃ 还是别的，
> 差别在于**它用了一个不随温度变化的电阻**。

同一个工具在 1 GHz 上比 DC 模型高 7.9 %，而这个差会随电流平方放大。

其它两个形状：

| 形状 | 条件 | T (℃) | β | 备注 |
|---|---|---|---|---|
| 实心线 0.5 mm | 1.6 mm, 2 A, Rth 100, 100 MHz | 26.0901 | 0.50673 | `x_out = 37.39`，`R/Rdc = 18.95` |
| 圆管 0.5/50 µm | 1.6 mm, 2 A, Rth 100, 1 MHz | 25.1632 | 0.952475 | `x_wall = 0.749`，`R/Rdc = 1.0246` |
| 过孔 0.3 mm+0.5 µm | 1.6 mm, 0.5 A, Rth 200, 1 GHz | 28.0147 | **0.999454** | `x_wall = 0.236` ⇒ `wall-limited` |

最后一行值得单说：**1 GHz 的过孔，指数是 DC 的 1**，因为 0.5 µm 的镀层只有
0.236 个趋肤深度厚，电流用光了所有铜。这就是"用趋肤深度"会答错的那个角落
—— 加厚镀层有用，加大钻孔没用。

## 7 两个面不是一个面的一半，而是"曲面看不见背面"

`faces="two"` 在趋肤主导下把电阻**恰好**减半：

```
one:  R_cold = 0.0833055 Ω   dT = 31.7733 K
two:  R_cold = 0.0833056 Ω   dT = 15.4346 K
```

这个"恰好"有原因：表面项看不见背面，所以两个面就是两个独立的表面。
它不是在整体电阻上乘 0.5 这么随意 —— 在 DC 下两个面就不是一半（整块铜都载流，
两面并联等于厚度翻倍，也是减半；但在**部分**趋肤的过渡区两者并不相同）。
这里断言的是趋肤极限。

## 8 粗糙度把 β 拉到 0.35，于是"期望值"必须闭嘴

1 µm Rq 的铜箔在 1 GHz 上（同几何、3 A）：

```
β（解点）    = 0.361116
β（冷点）    = 0.347433
T            = 62.563 ℃
dc 模型差    = 12.23 %
β_expectation = null
```

为什么置 null 而不是"判失败"：粗糙度因子 `K(δ)` 自己就随 ρ 变（δ ∝ √ρ），
所以 `R = ρ·K(δ(ρ))/A` 的指数既不是 1 也不是 1/2，**没有任何预言可以拿来比**。
这时候 `beta_expectation = null` + 一条 `beta_expectation_note`，
比"给一条注定不成立的判据再判它失败"诚实得多。

这与 `69`/`70` 里"粗糙度另开字段"不同：那里粗糙度是一个**可选的乘子**，
这里它已经折进答案，所以期望值必须承认自己不再适用。

## 9 近临界放大：0.67 % 变成 3 %

β = 1 且冷点增益接近 1 时，DC 模型的偏差会被 `1/(1 − gain)` 放大。

w = 0.1 mm、10 A、1 MHz：

```
β          = 0.9993
gain       = 0.774
R 的冷比值差 ≈ 0.67 %   （频率带来的，很轻微）
dc_linear_model_rel_diff = 0.0301   →  3.0 %
```

不是因为某个量算错了，而是因为**闭环**把开环的小差放大。这也是为什么
"频率很低所以用 DC 模型"这条经验在接近 runaway 的地方不再安全。

## 10 单调性（四条，都能被违反）

| 单调性 | 实测 |
|---|---|
| T 随 f 单调升 | 100 Hz → 26.82；1 MHz → 略高；1e8 → 更高；1 GHz → 56.77 |
| T 随 I 单调升 | 1 / 2 / 4 / 8 A 严格递增 |
| 电流为 0 ⇒ dT = 0 | `T = 25.0`，`dT = 0`，`iterations = 0` |
| α = 0 ⇒ 纯焦耳 | `dT = 9·20·0.00992013 = 1.78562` 精确，`β = 1.0`，`gain = 0`，`unit_gain_current = null` |

最后一条是**代数恒等式**：电阻不随温度变，回路就退化成一乘，没有根可解。
`unit_gain_current` 在这里是 null（不是 0，也不是 inf）—— 因为 `α = 0` 时
增益永远是 0，没有任何电流能到 1。

## 11 明说的边界

`limits.not_modelled` 里每条都是真的：

- **单导体、单频率**：不建模邻近走线的邻近效应，不建模与平面的回流耦合
- **线性 ρ(T) 用到 100 ℃ 以上**：真铜的 α 自己随 T 涨，所以热的答案是**乐观**的
- **不建模熔化、熔断、电迁移**：报温度，不报铜活不活得下来（脉冲熔断是 `fusing_current`）
- **熔点只用来画搜索的上界**：几何与 1-D 趋肤解在远早于熔点处就都不成立了
- **脉冲串**：真实谐波要逐次算，而大多数时候 DC 项支配发热

`assumptions` 里写死三条：

```
rth_source : "caller-supplied single lump, not derived here"
rho_law    : "linear in T, one alpha, no curve"
frequency  : "one frequency, one conductor (no proximity)"
```

**Rth 是这一份答案里唯一不是推出来的数。** 所以它是 required 参数，
没有默认值：给一个默认 Rth 等于在答案里塞一个凭空来的数。

## 12 三个"本来就该报错"的入口

这几处都是**静默给错答案**的入口，全部改成拒绝：

| 输入 | 后果（如果不拒绝） |
|---|---|
| 不给 `shape` | 同一"厚度"下薄板与圆线是两个不同问题，靠"传了哪个参数"推断会答错 |
| 不给 `rth_c_per_w` | 答案里多一个凭空来的数 |
| 镀层 `2p ≥ d`（单位串了） | 0.3 mm 孔 + 0.5 µm 镀层被读成"镀层把孔封死" |

第三条是真 bug：`2.0 * p >= d` 里 `p` 是 µm、`d` 是 mm，差 1000 倍。
同一类错还有一处更严重的：圆导体电阻写成 `rho·L_mm·1e3/area`，
多乘了 1000（`ρ` 的单位是 Ω·mm，不是 Ω·m），结果**所有小电流都"跑飞"**。
§5 的负控制就是为这一类错准备的。

## 13 口径与成本

- **默认关时体积与行为零变化**：新模块 + 一个新工具，没碰任何既有工具的输出。
  `electrothermal_conductor` 的读数逐位不变，只在 `not_computed` 的第 2 条
  **追加**一句指向 `ac_self_heating`。
- **工具数棘轮 172 → 173**。新工具而不是开关：输入表是
  `shape` + `frequency_hz` + `current_a` + `rth_c_per_w` + `length_mm`，
  输出是一**个温度**（解出来的），不是"某个量多一个频率维度"。
- **成本**：单次约 **2–5 ms**（`fd_verify` 默认开时两次 AC 求值 + 30~35 次二分求根；
  关掉 FD 只省约 4 ms，因为求根占大头）。本机计时噪声 ±30 %。
- 二分次数实测 30（100 Hz）到 34（1 GHz）—— 收敛准则是 `tol_c = 1e-9` K。

## 14 结论

**铜在频率上的自热是可以算准的，而"P = I²R"这一步在 GHz 上会少算 7.9 %，
在近临界处会少算 3 %（闭环放大），在 runaway 附近会把"有解"说成"无解"。**

四句要一起说：

- **算准了**：DC 极限与独立闭式解差 3.0e-7，指数实测复现 0.5 / 1 / 0.9995 / 0.9525 / 0.5067；
- **两种 runaway 分开说**：指数 1 的"任何温度都不自洽"与指数 1/2 的"根在 37 kK"是
  两个不同的判决，合并文案就是说谎；
- **一个 if 能说反话**：把外推二分包在 `β < 0.999` 下面，会让 11 A 那种
  "有根但很热"的案子报出"任何温度都不自洽"。修法是先找根、再选措辞；
- **熔点上没有读数，只有排序**：`37325.8 ℃` 是"比熔点高多少"的度量，
  不是什么材料的温度。

下一篇要做的，是把"一个导体"换成"一块板"：多个热源、共享的铜平面、
彼此之间的热阻网络 —— 那才是 PCB 上真正的问题，而这里只解了一根铜。
