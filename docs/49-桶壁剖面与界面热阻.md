# 49 · 「偏乐观」不再是一句警告：桶壁剖面与界面热阻

0.0.45 把过孔接进了板级 2-D 场，但它自己的答案里挂着一句实话：
`thermal_via_array` 的 `precision` 写着 **OPTIMISTIC**——墙是**一处镀层厚度**，
两端焊盘界面**根本不建模**。这一版把那句话换成两个能填的参数，并且都给出**能失败的
对照**，而不是「所以数字变大了」。

两个缺口的代数形态不同，这一点决定了做法：

| 缺口 | 形态 | 结果 |
|---|---|---|
| 中段镀层更薄 | 同一根桶壁沿长度**串联** | `R = Σ L_i/(k_cu·A_i)` |
| 两端界面（TIM/焊盘） | 整个场之后**再串**一层 | `R_if = n·t/(k·A)` |

串联是这里的关键词：薄的那一段不论多短都跑不掉，**不能被长度平均掉**。用「等效平均
厚度」去算，就会正好犯下 0.0.45 抱怨过的那个错。

## 49.1 桶壁剖面

```
A(t)      = π·((d/2)² − (d/2 − t)²)
R_seg     = L_i / (k_cu · A_i)
R_barrel  = Σ R_seg            （L_i 之和必须等于 length_mm）
```

`barrel_profile = [{length_mm, plating_um}, ...]`，从一端走到另一端。长度不闭合就
**拒绝**——不闭合意味着有一截铜是白送的，那正是偏乐观。

一段 1.6 mm、两端 25 µm、中段 15 µm（0.55 / 0.5 / 0.55）的墙：

| 段 | 长 (mm) | 镀层 (µm) | 环面积 (mm²) | R (K/W) | 占桶壁 |
|---|---|---|---|---|---|
| 0 | 0.55 | 25 | 0.0215984 | 66.142314 | 28.885 % |
| 1 | 0.50 | **15** | 0.0134303 | **96.699289** | **42.230 %** |
| 2 | 0.55 | 25 | 0.0215984 | 66.142314 | 28.885 % |
| 合计 | 1.6 | — | — | **228.983918** | 100 % |

- 31 % 的长度（中段）扛了 **42.2 %** 的阻力——这就是「平均 20 µm 左右」这个说法
  错在哪；
- 同几何的均匀 25 µm 是 **192.414004**，所以剖面让一根过孔的热阻涨
  **+19.0058 %**；
- `plating_equivalent_um` 报出「等效均匀镀层」= **20.6827 µm**（用等效面积反解，
  再回代能复原同一 R 到 5 位）——顺手就给了一个可读的标量；
- 一根 `1.6 mm @ 25 µm` 的单段剖面 == 均匀墙，**到第 9 位**（同一条物理的两条路径）。

`plating_um` 因此变成**可选**：给了剖面就没必要再给一个标称值。真给了，它只用来算
`plating_thinning_effect_pct`（「如果当初是均匀的呢」）；不给时，报告的
`barrel_area_mm2` 取**最薄那一段**，并在 `barrel_area_mm2_source` 里写明是哪一个。

## 49.2 界面层

```
R_iface = interfaces · thickness / (k · area)
```

`interface = {area_mm2, thickness_um, k_w_mk, interfaces?}`：

- 25 mm²、100 µm、k=3 W/(m·K)：`R = 100e-6/(3·25e-6) = 1.3333 K/W`；
- `interfaces = 2`（每端一片）就是 **2.6667**，逐位成倍；
- 它是**整个场之后**的一层，所以和阵列串联、**不除以根数**：`rth_array_total =
  rth_array_with_board + rth_interface`；9 根、1 mm 间距时界面占 **5.18 %**，
  双面时占 **11.44 %**；
- 这一层**故意不从表里取数**：TIM 的种类太多、压装条件比材料更影响结果，所以只吃
  `面积 / 厚度 / 导热率` 三个你给的数。voiding、泵出、安装压力都不建模，
  写进 `not_computed`。

## 49.3 剖面进板级 2-D 场

`board_electrothermal` 的 `thermal_vias` 每个数组也接受同一个 `barrel_profile`
（长度之和必须等于 `span_mm`）。电导就是串联和的倒数：

```
G = 1 / Σ L_i/(k_cu·A_i)
```

注意这里 `k_cu` 是 electrothermal 自己的 **400 W/(m·K)**（`thermal.py` 用 385），
所以同一根 1.0 mm@25 µm + 0.6 mm@10 µm 的墙在板级是 `R = 280.392 K/W`、
`G_one = 0.00356643 W/K`；100 根 `G_tot = 0.356643`（均匀 25 µm 时是 0.539961）。

20×20 mm、2 mm 网格、0.02 W 均匀：

| 墙 | G_tot (W/K) | t_max (℃) |
|---|---|---|
| 均匀 25 µm | 0.539961 | 25.037263 |
| 1.0@25 + 0.6@10 | 0.356643 | **25.055977** |

差 **+0.0187 K**。数不大，但这正是应该的样子：这个板上过孔的等效 h 已经被抬到几百，
散热通路的瓶颈不在桶壁。**这条数字的价值不是「更热了」，而是「同一个串联和真的进了
场，而不是只出现在报告里」**——所以判据写成「`G_one` 等于 `1/R_hand`」，而不是
「t_max 变大了」。

## 49.4 零变化（三条，逐条可测）

1. 不给 `barrel_profile`、不给 `interface` → `thermal_via_array` 走老公式，
   `rth_one_via_k_per_w = 192.414004399`，报告里**不出现**任何新键；
2. 板级不给 `barrel_profile` → 数组报告里**不出现** `barrel_profile_modelled`
   /`rth_per_via_k_per_w`/`plating_equivalent_um`，`t_max` 仍是 25.037263；
3. `not_computed` 与 `precision` **换句不删句**：只有真给了剖面/界面，才把
   「uniform plating / 两端焊盘未建模」换成「你给的剖面」/「你给的界面层」，
   否则仍是 0.0.45 的原句。

## 49.5 拒绝（不近似）

- 剖面长度之和 ≠ `length_mm`（板级：≠ `span_mm`）→ `ARG_RANGE`，消息里两个数都写出来；
- 某段 `plating_um ≥ 钻孔半径` → `ARG_RANGE`（那一段是实心铜，环形公式没有意义）；
- 某段 `length_mm` 或 `plating_um ≤ 0` → `ARG_RANGE`；
- 剖面不是列表 / 空列表 / 元素不是对象 / 段里缺 `length_mm` 或 `plating_um` →
  `ARG_INVALID`，点名第几段；
- `plating_um` 与 `barrel_profile` **都不给** → `ARG_INVALID`（「没有墙」）；
- 界面缺 `area_mm2`/`thickness_um`/`k_w_mk` → `ARG_INVALID`，并说明「这里没有 TIM 表」；
- 界面 `interfaces` 不是 1 或 2 的整数 → `ARG_RANGE`；不是对象 → `ARG_INVALID`；
- 任一界面尺寸 ≤ 0 → `ARG_RANGE`。

## 49.6 仍然不算

镀液/工艺模型（剖面是**你的数**，不是电镀槽的产物；IPC-4761 的孔型结构不做成表）、
两端焊盘与平面的铺开（spreading）、桶内吸锡、界面层的 voiding / 泵出 / 安装压力、
`k_cu` 随温度变化（就是一个数）、相邻过孔之间的相互作用、`rth_cs`（仍是你要给的输入）、
散热器选型（`thermal_heatsink` 只给**预算**，本服务故意不带散热器表）。

这一版之后，`thermal_via_array` 仍然是一个**一阶模型**——但它不再把已知的乐观项
当成不可说的警告，而是变成三个可以填的数。
