# 87 · 矩形热源的收缩（铺展）热阻

`not_implemented_yet` 里 `#16` / `#20` 两条从不同角度写着同一件事：**「pad/plane spreading 没做」**。
`thermal_stack` 明说"strictly 1-D, it cannot see spreading"，`thermal_plate` 更直接——它把厚度**集总**掉
（`k·t·∇²T − 2h(T−Tamb) + q = 0`），板子在厚度方向上恒温，所以一块板上放一个小焊盘，在那个模型里
**根本没有收缩阻力这回事**。缺的不是精度，是**这样一个物理量根本不在场**。

本篇补上它：`thermal_spreading`，一个纯解析、可手算、两个极限能对到 1e-15 解。

工具数 **179 → 180**，`dependencies = []` 仍成立（numpy/scipy 只在 `_scratch` 里做验算，不入库）；
`thermal_heatsink` 多一个可选入参 `rth_spread_k_per_w`，**不传则逐位不变**。

---

## 1. 模型

矩形板 `0≤x≤W`、`0≤y≤L`、`0≤z≤t`，各向同性 `k`，**四侧绝热**；`z=0` 上矩形 `[x0,x1]×[y0,y1]`
施加**均匀热流**、其余零流量；`z=t` 是**等温面**（板压在一块冷板上）或**对流面**（Robin，给定 `h`）。

分离变量（`cos(mπx/W)cos(nπy/L)`，四侧绝热 ⇒ 本征函数是余弦、不是正弦）：

```
R = 1/(k·A_s²·W·L) · Σ_{m,n} I_mn² · ε_m · ε_n · f(λ_mn)
I_mn = ∫_source cos(mπx/W)cos(nπy/L) dA        ε_0 = 1, ε_m = 2 (m ≥ 1)
λ_mn = π·sqrt((m/W)² + (n/L)²)
等温： f = tanh(λt)/λ
对流： E = e^(−2λt), g = h/(kλ)
       f = [ (1+E) + g(1−E) ] / [ (1−E) + g(1+E) ] / λ
```

回答的是**源面平均温度每瓦**——这是"收缩阻力"唯一有定义的读法（源面上温度并不均匀，
均匀热流 + 平均温度是一对共轭量，和均匀温度 + 总功率的差别就是下面第 6 节那条 8 %）。

对流分支写成 `E = exp(−2λt)` 而不是 `cosh/sinh`：厚板（`λt ≫ 1`）时 `cosh` 直接溢出，
而这个形式在 `λt→0` 和 `λt→∞` 两端都稳定。

代码在 `calc/thermal.py`：`_cos_integral()` / `_z12()` / `_spread_series()` / `spreading_resistance()`。

## 2. 两个精确极限——它们不是"容差"，是恒等式

级数有两个位置还能被手算钉死，而这两个位置恰好是最容易写错的两个：

| 极限 | 手算 | 实测 |
|---|---|---|
| 源 == 整板（只剩 `m=n=0` 项，`f=t`） | `R = t/(k·A_plate) = 0.05 K/W` | **`0.05`**，`spreading_excess` **`0.0`** |
| 源 == 整板 + 对流面 | `R = t/(k·A) + 1/(h·A) = 0.05 + 10.0` | **`10.05`**（`1e-9` 内） |

第二条在 0.0.85 的开发中**抓到过一个真 bug**：`m=n=0` 这一项原本写的是 `f = t`，对流时漏了 `k/h`。
一维解是 `T = q(t−z)/k + q/h`，`m=n=0` 的极限必须是 `t + k/h`。漏掉以后 `h=1000` 的 4×4 板给出
`0.5154`（横向铺展的残值），而正确答案是 `≈10.5`——**整项对流热阻凭空消失**，`status` 仍然是 `ok`。
"能对到 1e-15"的两个极限，就是这个 bug 能被发现的唯一原因：任何只在单一算例上对过的实现都会漏掉它。

## 3. 独立有限体积法——序列是极限，差距是离散误差

自证不能只靠"我算了两遍一样"。`_scratch` 里另写了一个**不分离变量**的三维有限体积解
（直接离散 `∇·(k∇T)=0`，10×10×1 mm、k=200、中心 4×4 源、等温远面，CG + Jacobi 预条件），
解析值 `0.236078530`：

| `nz`（厚度方向格数） | FVM (K/W) | 差 | 加半格面温修正后 |
|---|---|---|---|
| 8 | 0.206754 | 12.42 % | 4.15 % |
| 12 | 0.216500 | 8.29 % | 2.78 % |
| 24 | 0.226334 | 4.13 % | 1.37 % |
| 48 | 0.231294 | 2.03 % | 0.65 % |
| 96 | 0.233786 | 0.97 % | 0.28 % |

**每 halve 一次 `dz`，差距就 halve 一次**：一阶收敛 ⇒ 序列的极限就是解析值，差距是离散误差、
**不是缺项**（缺项不会这么收敛）。`nx` 扫描 40/80/160/240 给 `0.233291/0.231772/0.231294/0.231191`，
说明横向已饱和。这个探针是 numpy/scipy 的 `_scratch` 工作，**不入库**；入库的只有
"序列在声明截断处自身的值"和这张收敛表。

## 4. 冻结的读数（10×10×1 mm、k=200、等温远面、`terms=400`）

| 源 | R (K/W) | `psi = R·k·√A_s` | `spreading_excess` | `spreading_relief` |
|---|---|---|---|---|
| 中心 4×4（3–7 / 3–7） | `0.236078529798` | `0.188862824` | `0.186078529798` | `0.076421470202` |
| 中心 2×2（4–6 / 4–6） | `0.716124740033` | `0.286449896` | `0.666124740033` | `0.533875259967` |
| 角 3×5（0.5–3.5 / 0.5–5.5） | `0.253879439710` | `0.196654168` | `0.203879439710` | `0.045886877810` |
| 条 8×1（1–9 / 4.5–5.5） | `0.335405525827` | `0.189734017` | `0.285405525827` | `0.289594474173` |

默认 `terms=120` 的中心 4×4 = **`0.236046830818`**，`convergence_rel = 1.1e-4`（对同一条式子在
`terms=240` 的值）。也就是说默认截断的答案本身带 0.011 % 的口径，而这个数**每次都随答案一起报**，
不是"应该够准"的承诺。

结构检验（都在测试里，且是**精确**的）：`y` 镜像差 **`0.0`**；`x` 镜像差 **`0.0`**；`k` 加倍比值
**恰好 `2.0`**；角上 3×5 比中心 4×4 更便宜（`0.254` 对 `0.236`）——因为板边是绝热的，角上那块
四周有更多"同一块板"可以扩散进去。

## 5. 夹逼——两个 1-D 参照，恒成立

```
t/(k·A_plate)  ≤  R  ≤  t/(k·A_source)
  地板                 列上限
```

地板是 `m=n=0` 项（源铺满整面时的值），级数里其余项全为正 ⇒ 只能更高；上限是一块"只在源下面
成柱、完全不横向扩散"的板。`spreading_excess = R − 地板 ≥ 0`、`spreading_relief = 上限 − R ≥ 0`，
两个都报，`extra["brackets"]` 里写明恒成立和"一旦交叉就说明模型被问了它不描述的东西"。

构造性检查（自检 `852`）：偏离中心 1.5×3.5 mm 源、`terms=400` →
`0.05 ≤ 0.568797535268 ≤ 0.952380952381`（coverage 5.25 %）。

## 6. 口径与 `not_computed`

**均匀热流，不是等温焊盘。** 两者在半空间上是 8 % 的关系（经典结果），本模型取前者；
这是它比真焊盘**偏大**的那一块，写在 `precision` 里，不藏在假设里。

其它 `not_computed`（八条，逐条随答案给出）：等温源面、圆/环源、侧边对流或定温、
多层叠（铜箔 + FR4、基板下的 die）、穿板热过孔、两面接触热阻、`k` 随温度、
板面辐射。

**薄板极限的实测截断行为**（`R/col`，col = `t/(k·A_source)`，t→0 时理论到 1）：

| t (mm) | `terms=120` | `terms=400` |
|---|---|---|
| 1 | 0.572697948（conv 2.9e-04） | 0.572899792（2.6e-05） |
| 0.1 | 0.944566510（1.8e-03） | 0.946584510（1.6e-04） |
| 0.01 | 0.982412006（7.8e-03） | 0.992694476（1.4e-03） |
| 0.001 | 0.983182440（8.5e-03） | 0.994913976（2.5e-03） |

薄板收敛**明显更慢**（`t=1e-3` 时 120 项仍有 0.85 %），因为指示函数的余弦系数按 `1/m` 衰减，
有限截断总是少算尾部。所以这条极限的测试写成「`R/col` 随 `t` 减小**单调上升** + `t=1e-3,
terms=400` 时 `≥ 0.99`」——**不是**绕开问题，而是先量了收敛速度再据此写判据
（第一版写的 `0.02·t` 容差在 `t=1` 处要求 2 %，与实测 42.7 % 差得远，是被实测推翻的）。

对流面：`h = 1e9` 时 `0.236080537` 对上等温 `0.236046831`（差 3.4e-5），`h=10/100/1000` 时
`R − 1/(h·A_plate) = 0.5189/0.5186/0.5154`（`Bi→0` 的横向铺展极限）。
**注意 `1/(h·A_plate)` 只是近似**：热只从源附近出去，Robin 通量不是整板均匀的那种，
硬减它会在 `h=1e6` 处留下 `0.0217` 的残差——这是测试第一版踩的坑，现在的判据是
「`h` 越大 `R` 越小、且恒 `≥` 等温值、`h=1e9` 时与等温差 `< 1e-3`」。

## 7. 负控制——这条判据能失败

四条，都在 `TestTheChecksCanFail` 里，都是**故意写错的实现**：

| 错法 | 结果 |
|---|---|
| 漏掉 `ε_m` 正交因子（`m>0` 的模不乘 2） | 同一算例偏 **> 10 %**，被抓 |
| 同一个错法 vs **整板锚点** | 差 **0.0** —— 整板锚点对这一类错误**盲** |
| 整体系数乘错（尺度错） | 偏 **> 40 %**，被抓 |
| 朴素径向近似 `ln(b/a)/(2πkt)` 当矩形用 | 差 **> 30 %**，被抓 |

第二行是这一节的重点：**「能对到 1e-15 的极限」不等于"这个实现对"**。整板锚点只点亮 `m=n=0`
那一项，对正交因子、对系数、对所有 `m,n>0` 的项**完全看不见**。所以锚点和负控制是两类测试，
不能互相替代——蒙对一个极限，和模型是对的，是两件事。

## 8. 与 `thermal_plate` 的分工

| | `thermal_plate` | `thermal_spreading` |
|---|---|---|
| 厚度 | **集总**（`k·t·∇²T`） | **解析求解** |
| 侧边 | 对流/绝热可选 | 绝热 |
| 面 | 上下都可对流 | 一面源（均匀热流），一面等温**或**对流 |
| 能看见收缩阻力 | **不能**（板在厚度上恒温） | 这就是它的输出 |
| 规模 | 任意多个矩形热源、二维数值解 | 一个矩形源、解析 |

两者不是替代关系：`thermal_plate` 回答"板上温度分布长什么样"，`thermal_spreading` 回答
"这个小焊盘让热阻多了多少"。前者给不出后者，后者给不了前者。

`thermal_heatsink` 只**收**这个数、不**算**它（`rth_spread_k_per_w`，默认 0 ⇒ 逐位不变的旧答案）：
预算恒等式 `R_sa = (Tj−Ta)/P·margin − R_jc − R_cs − R_spread` 保持纯粹，
铺展用 `thermal_spreading` 算完再传进来。`thermal_stack` 的文案也一并改成指向本工具，
不再说"1-D，看不见铺展"就结束。
