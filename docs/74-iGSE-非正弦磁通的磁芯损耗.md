# 正弦不是唯一形状 —— 一个三角波不是一个正弦

日期：2026-11-01　工具：`magnetics_core_loss(...)` 新增 `waveform` / `duty` / `segments`；`magnetics_select_core(...)` 新增 `flux_waveform` / `duty`

Steinmetz 的 `P_v = k · f^α · B_peak^β` 是一条**正弦**的拟合曲线。它没有说自己只对正弦成立，
但它的三个常数是在正弦激励下测出来的，所以拿它去算三角波，答案不是"差一点"，是**错在一个未知的倍数上**。

而电感里的磁通**基本都不是正弦**：Buck 的电感电流是三角，反激是三角，PFC 的升压电感是
几十 kHz 的三角叠在 100 Hz 的绝对正弦上，LLC 是近似正弦但带死区。这一篇做的是把那条拟合
曲线换成**对你给的那条轨迹逐段积分**的 iGSE，并且——这是重点——把它**归一到你自己的 Steinmetz 三元组**上：
正弦输入必须还原出原公式，一位不差。

不给 `waveform` 时，答案与 `0.0.70` **逐字节相同**（360 组成功案例 + 12 组错误案例比对）。

---

## 1 判据

| # | 要守住的事 | 能被什么违反 |
|---|---|---|
| 1 | 不给 `waveform` 时，答案与 `0.0.70` **逐字节相同**（含 `not_modelled` 的次序与措辞） | 顺手把正弦路径也改成"走 iGSE、只是形状是正弦" |
| 2 | `k_i` 必须由**「正弦还原 Steinmetz」**推出，并用**对 B(t) 的独立数值积分**验证 | 从别处抄一个常数、或抄一个自己没验过的归一化 |
| 3 | `ΔB` 是**峰峰值**（max−min），不是幅值 | 写成幅值差 ⇒ 差 `2^(β−α)` 倍（本例 2.46 倍） |
| 4 | 三角闭式必须等于**对轨迹的数值积分** | 闭式与积分各写一遍、只验一处 |
| 5 | 形状比**只依赖 α 与形状**，与频率、幅值无关 | 把 `f`、`ΔB` 留在比率里 |
| 6 | 非正弦必须**同时打印正弦公式会说多少**、比率是多少、错在哪个方向 | 只给新数字，让用户拿旧数字对比时无从判断 |
| 7 | 只给 `duty` / `segments` 而不给对应的主参数，必须**拒绝** | 接受后按默认形状回答（靠遗漏说谎）|
| 8 | 说清楚**没有**什么：DC 偏置、窄脉冲高估、气隙边缘损耗、温度 | `not_modelled` 里含糊其辞 |

第 1、2 条是这一轮的锚，第 7 条是负控制。

## 2 模型

```
iGSE（Li / Abdallah / Sullivan 2001）：

    P_v = (1/T) · ∫₀ᵀ k_i · |dB/dt|^α · (ΔB_pp)^(β−α) dt

    I_α  = ∫₀^{2π} |cos θ|^α dθ = 2√π · Γ((α+1)/2) / Γ((α+2)/2)
    k_i  = k / [ (2π)^(α−1) · 2^(β−α) · I_α ]
```

**`k_i` 不是抄来的，是解出来的。** 要求"正弦必须还原 Steinmetz"：

```
dB/dt = 2π f B_p cos θ,      ΔB_pp = 2 B_p
(1/T)∫ k_i |dB/dt|^α ΔB_pp^(β−α) dt
  = k_i · (2π f B_p)^α · (2 B_p)^(β−α) · I_α/(2π)
  = k_i · (2π)^(α−1) · 2^(β−α) · I_α · f^α · B_p^β
≡ k · f^α · B_p^β
⇒ k_i = k / [ (2π)^(α−1) · 2^(β−α) · I_α ]                    （α = β 时也成立）
```

`I_α` 用 `lgamma` 算（`Γ` 在 α 大时会溢出双精度，`lgamma` 不会）：

| α | `I_α` |
|---|---|
| 0.7 | `4.425344538847297` |
| 1.0 | `4.0`（`|cos|` 的均值 × 2π，手推得出）|
| 1.4 | `3.582087499477732` |
| 2.7 | `2.7863280429779276` |

`k = 100`、`α = 1.4`、`β = 2.7` 时 `k_i = 5.4356673134947275`。

### 关于文献

定义来自 Li, Abdallah, Sullivan, *"Improved calculation of core loss with nonsinusoidal
waveforms"*, IEEE IAS 2001（Xplore 文档号 `955931`）。**文献正文这一轮取不到**（4 次检索 + 1 次抓取都没拿到公式页），
所以这里**不声称"照抄文献常数"**：`k_i` 按上面那条正弦一致性自行推导，再用两种独立办法验证：

1. `I_α` 的闭式对 `∫₀^{2π}|cos|^α dθ` 的 400001 点求积 —— 相对差 < `1e-8`（测试断言）。
2. 正弦时 iGSE 对 **B(t) 直接数值积分**（不是对闭式）与 Steinmetz 相对差 `5.7e-11`（断言 `1e-9`）。
   剩下的偏差只来自求积精度，不是公式。

如果哪天拿到正文，要做的第一件事是核对 `k_i` 的分母，而不是改数字——因为那条自证会立刻告诉你结果。

## 3 三角与分段折线

三角（上升占空比 `δ`，下降 `1−δ`），`|dB/dt|` 在两段上分别是 `ΔB/(δT)` 与 `ΔB/((1−δ)T)`：

```
P_v = k_i · ΔB_pp^β · f^α · [ δ^(1−α) + (1−δ)^(1−α) ]
```

任意轨迹走 `segments=[[dB_t, dt_fraction], …]`：每行是这一段磁通**变化量**（带符号）与它占**周期**的比例，
行必须时间上和为 1、磁通上和为 0（闭合一个周期）。工具对每行算 `dB_dt_t_s` 并原样回吐，
所以任何人可以拿这些数自己复算 `Σ k_i |dB/dt|^α ΔB_pp^(β−α) Δt`。

### 形状比

```
ratio = P(iGSE, 你的形状) / P(正弦, 同 f、同 ΔB_pp)
```

因为 `k_i` 里含 `k`，`ΔB_pp^(β−α)` 与 `|dB/dt|^α ∝ f^α` 两处 `f`、`ΔB` 都约掉，
**比率只依赖 α 与形状**。实测（`si`、`k=100`、`f=100 kHz`、`B_p=0.1 T`、`ΔB_pp=0.2 T`）：

| α | duty | `P_v` (W/m³) | `ratio_to_sine` | 正弦公式是 |
|---|---|---|---|---|
| 1.4 | 0.5 | `1859840.0` | `0.932129` | 高估 |
| 1.4 | 0.3 | `1953560.0` | `0.979098` | 高估 |
| 2.7 | 0.5 | `4203620000000.0` | `0.666230` | 高估 |
| 1.0 | 0.5 | `19952.62315` | `1.0` | 相等 |
| 0.7 | 0.5 | `653.053657` | `1.035020` | 低估 |

正弦本身：`P_v_w_m3 = 1995260.0`、`P_v_mw_cm3 = 1995.262315`
（真值 `1995262.31…`，输出按 6 位有效数字打印，所以断言容差不小于 `1e-5` 相对）。

**被改的只是损耗**：给三角时 `turns`、`b_peak_t`、`gap` 一律不动（见 §7），因为形状不影响 `L = AL·N²`
也不影响 `B = L·Ipk/(N·Ae)`。

### α = 1 那个"恰好 1.0"

α = 1 时 `|dB/dt|^1` 是线性的，iGSE 只看**平均** `|dB/dt|`，而三角与正弦的平均 `|dB/dt|` 都是 `4 B_p f`。
所以比率**精确**是 1（测试里断言 `delta=1e-12`）。这不是巧合，是这条实现有没有把 `f`、`ΔB` 留在比率里的探针。

### α ≠ 1 时方向由凸性决定

`x ↦ x^α` 在 α > 1 时凸、α < 1 时凹，而正弦的 `|dB/dt|` 在每半周期内**变速**、三角是**恒速**。
Jensen 不等式：凸 ⇒ 变速更贵 ⇒ 正弦公式（假设匀速的正弦）**高估**三角；凹 ⇒ 反过来，**低估**。
所以：

- α = 2.7（典型功率铁氧体）：三角被高估 33 %；
- α = 1.4（本例）：高估 6.8 %；
- α = 0.7（某些纳米晶/粉芯的拟合）：低估 3.5 %。

**"三角比正弦低"不是一句可以无条件说的话**，符号由 α 决定。

## 4 一个流传很广的错数：0.378

经常能看到"三角波损耗是正弦的 0.378 倍（α=1.4、β=2.7）"。这个数来自：

```
2^(β−α) = 2^1.3 = 2.4622        0.932129 / 2.4622 = 0.3786
```

也就是说它把 `ΔB` 当成了**幅值**（`B_p`）而不是 iGSE 里的**峰峰值**（`2 B_p`）。
算术没错，**读法错了**：同峰值幅值下三角/正弦是 `0.932129`，同峰峰值下也是 `0.932129`
（峰峰值 = 2×幅值，两边同时变），不存在 0.378。

这类错误在商业场景里代价很高：0.378 会让一个 10 W 的磁芯损耗被判成 3.8 W，
进而让温升、选型、效率预算全部偏乐观。所以这一篇把这个数写进文档、也写进自检。

## 5 分段折线：任意轨迹与它的量化误差

`waveform="piecewise"` 接 `segments=[[dB_t, dt_fraction], …]`。两个锚：

**① 分段三角 == 三角**：把 duty 0.5 的三角拆成两行 `[[0.2, 0.5], [-0.2, 0.5]]`，
`P_v` 与 `waveform="triangle"` **逐位相同**（断言 `delta=1e-12`）。这是"分段实现没有引入额外常数"的探针。

**② 8 段阶梯正弦 vs 正弦**：

| 形状 | `P_v` (W/m³) | `ratio_to_sine` |
|---|---|---|
| 正弦 | `1995260.0` | `1.0` |
| 8 段阶梯 | `1950490.0` | `0.977559` |
| 带 5 % 边沿的方波（±0.1 T）| `2033480.0` | `1.019154` |

阶梯偏低 **2.2 %**：8 段近似把它自己的离散化误差带了进来（α=2.7 时比值掉到 `0.927762`，
因为指数越大越挑速率尾部）。这条不是"精度声明"，是**提醒**：`segments` 的段数要跟 `α` 一起看，
`α` 越大越需要更细的分段。

方波**高于三角**（`2033480.0` vs `1859840.0`）：边沿越陡，`|dB/dt|` 的尾部越重，凸的 `α` 就越贵。
这条同时是"iGSE 真的在看形状而不是只看峰峰值"的负控制——三个形状的 `ΔB_pp` 都是 0.2 T。

## 6 三套单位约定仍然指向同一个物理量

`units` 三档（`si` / `khz_mt` / `khz_gauss`）对同一个三角给出的 `P_v` **九位小数相同**（断言 `1e-9`），
只有 `k` 的输入单位不同。这条在 `0.0.6x` 就已经量过，本轮新增的非正弦路径必须继承它——
否则"换个单位结论就变"这种错会在 iGSE 分支里重新长出来。

## 7 `select_core` 只缩放损耗，不动的那些数

`magnetics_select_core(..., flux_waveform="triangle", duty=0.5)`，L = 100 µH、Ipk = 3 A、
`b_ac_t = 0.1`、`loss_exponents = (1.3, 2.5)`、材料 N87：

| | `sine`（默认）| `triangle` |
|---|---|---|
| 首选件 | `B66283G0000X187` | 同 |
| `core_loss_w` | `0.106066` | `0.100831` |
| `turns` | 25 | 25 |
| `b_peak_t` | `0.305344` | `0.305344` |
| `gap_mm` | `0.297616` | `0.297616` |

比率 `0.9506439…`，正好等于 `_igse_shape_ratio(1.3, [(1,0.5),(-1,0.5)]) = 0.9506426081293552`
（`α` 取 `loss_exponents[0] = 1.3`）。**为什么用 x 当 α**：`core_loss_w` 本来就是按 `f^x · B^y`
从参考点缩放的，那个 `x` 就是 Steinmetz 的频率指数，与 iGSE 的 α 是同一个数。
这件事写在 `flux_waveform.shape_ratio_basis` 里，不靠读者猜。

`select_core` **只接受** `sine` 与 `triangle`。给 `piecewise` 会被拒：

> `select_core judges a SHAPE, not an arbitrary trajectory: use flux_waveform='triangle', or evaluate magnetics_core_loss with segments= yourself and scale the watts`

理由：`select_core` 要判的是"这部件的损耗在这条形状上够不够小"，任意轨迹是**一次具体计算**，
不是选型判据。让它接受 `segments` 等于把两个工具挤成一个。

**没有 `loss_exponents` 时**：`core_loss_w` 变 `null`，`core_loss_basis` 点名 `loss_exponents`，
但**选型本身照常回答**（`status` 仍是 `ok`，turns/饱和/气隙都在）。因为缺的只是那一个数，
不是半张表——拒绝整条会丢掉已经算出来的东西。

## 8 拒绝臂（九条）

| 输入 | `reason_code` | 消息要点 |
|---|---|---|
| `waveform="sawtooth"` | `ARG_INVALID` | `must be one of sine, triangle, piecewise` |
| `duty` 配 `waveform="sine"` | `ARG_INVALID` | `duty only applies to waveform='triangle'` |
| `segments` 配 `waveform="triangle"` / `"sine"` | `ARG_INVALID` | `segments only apply to waveform='piecewise'` |
| `duty = 0` 或 `≥ 1` | `ARG_RANGE` | `duty must be in (0, 1)` |
| `dt_fraction` 之和 ≠ 1 | `ARG_RANGE` | `the dt_fractions must sum to 1 (got 0.8)` |
| `dB_t` 之和 ≠ 0 | `ARG_RANGE` | `the trajectory does not close: the dB_t values sum to 0.1, not 0` |
| `piecewise` 只有 1 行 | `ARG_INVALID` | `needs segments=[[dB_t, dt_fraction], ...] with at least 2 rows` |
| `b_peak_t` 与 `segments` 的峰峰值矛盾 | `ARG_INVALID` | `b_peak_t (0.5) contradicts the segments, whose peak-to-peak swing is 0.2` |
| `α` 或 `β` ≤ 0 | `ARG_RANGE` | `must be > 0` |

最后三条是这一轮的负控制：**一个参数的形状信息与另一个参数矛盾时，不许挑一个信**。

`b_peak_t` 在 `piecewise` 下**可以省**（schema 的 `required` 里没有它），省了就从 `segments` 的峰峰值反推，
输出里仍然照常打印 `b_peak_t`/`b_peak_mt`。

## 9 边界（写出来的，不是暗示的）

- **没有 DC 偏置**：iGSE 只吃交流摆幅。同一摆幅叠 0.3 T 直流偏置，真实损耗更高（revised Steinmetz 才有偏置项）。
- **窄脉冲会高估**：`duty` 很小的三角，iGSE 已知偏高；修它要 GSE/WGSE 的周期平均斜率项。所以 `duty < 0.05` 只给方向，不给定量。
- **没有气隙边缘损耗**：`gap and fringing loss` 仍在 `not_modelled`。
- **没有温度依赖**：`k`、`α`、`β` 是常数，随温度变要你自己给另一个三元组。
- **只一个稳态周期**：不是暂态，不是几个周期叠加。
- **材料表里没有 Steinmetz 三元组**：`data/magnetic_materials.json` 的 11 个材料 `steinmetz` 全为 `null`，
  16 个磁芯里 7 个有 `loss_ref`（200 mT / 100 kHz / 100 °C 的整组瓦数）。所以 `_core_loss_for` 的
  **材料支路目前走不到**，实际路径是 `loss_ref + 调用者给的 exponents`。这是数据缺口，不是代码缺口，
  补的时候必须带厂商公布的拟合窗口与来源 URL，不许凭记忆填。

## 10 成本

纯算术，无迭代无场解：`I_α` 一次 `lgamma`，`k_i` 一次乘除，逐段一次幂。
`waveform="sine"` 走原来的闭式，**零新增开销**。34 例测试文件总耗时 **1.9 s**。

## 12 结论

1. **Steinmetz 是正弦的拟合**，拿它算三角波错在一个**随 α 变的倍数**上：α = 2.7 时高估 33 %，
   α = 0.7 时低估 3.5 %，α = 1 时精确相等。
2. **`k_i` 由"正弦必须还原 Steinmetz"解出**，并用对 `B(t)` 的独立数值积分验证到 `5.7e-11`；
   文献正文没取到，所以文档写"定义来自 Li 2001、归一化常数自行推导"，不写"照抄"。
3. **`ΔB` 是峰峰值**：那个流行的 `0.378` 是把峰峰值当幅值读出来的，正确值是 `0.932129`。
4. **形状比只依赖 α 与形状**：把 `f`、`ΔB` 留在比率里，`α = 1` 那条例检就会失败（它应为精确 1.0）。
5. **任意轨迹可积分**：分段三角与三角逐位相同，8 段阶梯低 2.2 %，带边沿方波高 9.3 %（对三角）。
6. **不给 `waveform` 就逐字节是 `0.0.70`**：360/360 成功案例 + 12/12 错误案例逐字节相同，
   包括 `not_modelled` 的次序与措辞。
