# 环型平均匝长与铜损：目录不印的那个数，凭什么能变成区间

日期：2026-11-01　工具：`magnetics_toroid_mlt`（**新增，工具数 176 → 177**）
＋ `magnetics_select_core(toroid_mlt="estimate")`（同一工具加参数）

`76`/`78` 篇的 `not_implemented_yet` 里一直挂着同一条，原话是：

> 环型的平均匝长（因此环型没有铜损估计）

这一篇把它做掉，但**不是**用一条公式把它做掉。做完之后的差别是：

```
T106-1（OD 26.92 / ID 14.48 / H 11.10）
  flat = 2H + (OD−ID)          = 34.64 mm        （磁芯截面按矩形读的周长）
  MLT  = flat × 1.2477…1.4605  = 43.22 … 50.59 mm（中位 47.32）
  厂商在同一个尺寸上印的 MLT    = 43.9 mm         ← 落在区间内，不落在中位上
  54 匝 φ1.0 mm 铜，100 °C     R_dc = 0.073719 Ω  （区间 0.067335 … 0.078821）
                               P_cu = 1.842964 W  （区间 1.683375 … 1.970525）
```

注意 43.9 距离中位 47.32 还有 7 % —— 这不是误差，这是**同一个磁芯配不同绕组**
的合法差别。正是这一点决定了这一篇只能给区间。

## 2 为什么是「实测比值带」而不是一条公式

磁芯截面的**矩形周长**（`flat = 2H + (OD−ID)`）是几何上唯一不需要任何假设的量，
但它比真实一匝短，因为线不贴着截面走：它绕在外侧多出来的地方，且圆角处的
路径比矩形短。两者之差不是常数，取决于线径和绕法。

三个候选闭式，全部拿这 13 个印刷点**量过残差**：

| 式子 | 残差（相对印刷值） | 结论 |
|---|---|---|
| `flat = 2H + (OD−ID)` | **−19.8 % … −31.5 %**（即印刷/flat = 1.248…1.461） | 明显偏短，只能当下界 |
| `2H + (OD+ID)/2` | −4.8 % … +7.5 % | 拟合出来的，没有厂商定义 |
| `2H + OD − 0.4·ID` | −5.0 % … +2.5 % | 同上 |

后两个是**拿这 13 个点自己拟合**的系数，误差好看是因为它就是拟合误差。把它们
当「公式」写进答案，等于把 13 个样本的拟合噪声伪装成厂商定义 —— 这与
「宁可报错不给错答案」直接冲突。所以采用的写法是：

```
MLT = flat × q,   q ∈ [1.247656, 1.460472]，中位 1.365936，n = 13
```

`q` 不是模型，是一条**实测区间的名字**；答案里同时给 `estimate_mm`（中位）与
`range_mm`，并在 `not_modelled` 里写明「松绕/多层在上界之外，紧单层靠近中位」。

## 4 两个几何关系：顺手当成自检

同一批 13 页上还印着 `le`、`Ae`、`Ve`，所以答案里给出的几何**可以当场对账**：

| 关系 | 印刷值残差（13 行） | 结论 |
|---|---|---|
| `le = π(OD+ID)/2` | **−0.61 % … +0.45 %** | 可以直接用（对数均值绕一周） |
| `Ae = H(OD−ID)/2` | **+4.41 % … +9.69 %**（**偏高**） | 印刷截面是圆角，矩形**过填**；只用来说明量级，不替换任何印值 |

这两条写进 `geometry.le_basis` / `geometry.ae_basis` 的原文里，所以读到 `Ae`
的人当场就知道它比厂商印的高 4–10 %，不会拿它去和印刷 `Ae` 比。

## 5 铜：`N`、层数、温度和窗口

```
N1     = floor(π(ID − d) / d)             单层最多匝数（铜只能绕着内孔排）
layers = ceil(N / N1)                     超过一层 ⇒ 后续层更长 ⇒ r_dc 是下界
A_cu   = π d²/4
ρ(T)   = 1.724e-8 · (1 + 0.00393·(T − 20))   Ω·m
R_dc   = ρ(T) · N · MLT / A_cu
P_cu   = I_rms² · R_dc
window = π(ID/2)² ;  needed = N·A_cu/ku
```

T106-1 + 54 匝 φ1.0 mm @100 °C：

```
A_cu = 0.785398 mm²      N1 = floor(π·13.48/1.0) = 42      layers = 2
R_dc = 2.266088e-8 · 54 · 47.31602e-3 / 0.785398e-6 = 0.073719 Ω
P_cu = 25 · 0.073719                                = 1.842964 W
window 164.674747 mm²，needed(ku=0.4) 106.028752 mm² ⇒ 放得下
ku = 0.05 时 needed 848.230016 mm² ⇒ 放不下，给 window_note 明说「这个绕组装不进这颗芯」
```

三件事必须同时成立才算给对答案：

1. `layers = 2 > 1` ⇒ 输出 `multilayer_note`（含 `biased LOW`），因为 band 是在
   **印着单绕组 MLT** 的页面上量的，多层必然更长。
2. 温度只以 `ρ(T)` 进，20 °C 是 0.056085 Ω，100 °C 是 0.073719 Ω，比值恰好
   `1 + 0.00393·80 = 1.3144`（不是另配一个系数）。
3. 窗口放不下时**不给"看起来还行"的数**：`window_fits:false` + `window_note`
   写出需要多少、有多少，并说明「这个电阻是那么多匝会测到的值，不是能绕出来的值」。

## 7 `select_core(toroid_mlt="estimate")`

| | `off`（默认） | `estimate` |
|---|---|---|
| 候选零件 | 同 | **同**（逐字节比过） |
| 匝数 | 同 | **同** |
| `winding.mlt_mm` | **不出现这个键** | 6.583811（对 `0077141A7`） |
| `winding.mlt_range_mm` | 不出现 | `[6.013704, 7.039475]` |
| `winding.mlt_is_estimate` | 不出现 | `true` |
| `winding.r_dc_ohm` / `p_copper_w` | `null` | 有值 |
| `winding.missing_wire` | 仍含 `no mean turn length` | 不适用 |
| 顶层 `toroid_mlt` 块 | **不出现** | `mode/how/ratio_band/rows_with_an_estimate/rows_without_one/why_only_toroids/not_a_printed_value/band_note` |

三条要点：

1. **`off` 与省略参数逐字节相同**（自检用 `json.dumps(sort_keys=True)` 直接比），
   因为 0.0.78 的答案不许被静默改动。
2. 只对**环型**给估计。固体芯（E 型等）的 MLT 是线圈骨架的印刷平均匝长，那是
   厂商自己印的数，`why_only_toroids` 里写着。
3. `rows_without_one` 是一个**列表**（不是计数），列出没有估计的行 —— 固体芯会
   出现在里面，而不是被悄悄跳过。

粉末芯表（`magnetics_data(kind="powder_parts")`）的每一行现在同时有：

```
mlt_mm            = null                    （目录确实不印，这一列保持空）
mlt_flat_rect_mm  = 2H + (OD−ID)            （几何）
mlt_estimate_mm   = flat × 1.365936          （中位）
mlt_range_mm      = [flat×1.247656, flat×1.460472]
mlt_note          = 仍以「the catalog prints no mean turn length」开头，并说明
                    mlt_estimate_mm 是几何 × 实测带，不是印值
```

`mlt_note` 保留原句是刻意的：0.0.76 的测试依赖这句话说明「这一列为什么空」。

## 8 未做（诚实清单）

| 没做 | 为什么不做 | 什么时候能补 |
|---|---|---|
| 包漆与加固层的厚度 | 它让真实 `N1` 比计算值略小、让真实 `r_dc` 略大 | 需要具体的线材规格（漆膜等级） |
| 多层长度增长模型 | 后续层更长，band 只覆盖单绕组 ⇒ 现状给下界并标记 | 需要绕法/张力数据，或厂商的分层匝长表 |
| 集肤与邻近效应 | 这一篇给的是**欧姆表值**；AC/DC 比在 `magnetics_winding_ac` | 已存在，不在这里重复 |
| 温升 | 这里不算铜或磁芯会到多少度，`temperature_c` 是**调用方给的** | 需要热阻/表面对流模型 |
| 绞线（litz）、铜箔、并绕 | 单根圆线的面积口径不适用 | 需要等效面积与填充系数模型 |
| 每条带之外的松绕/多层 | 上界之外没有数据，直接说在界外 | 需要更多印刷 MLT 样本 |
