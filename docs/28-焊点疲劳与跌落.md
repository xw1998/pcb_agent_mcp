# 28 界面可靠性：焊点热疲劳与跌落应变

> 这一篇回答两个问题：**温度循环下这个焊点能撑多少个循环**，以及
> **掉一下之后板子表面的应变是多少**。
>
> 它是 [19 机械振动](19-机械振动.md) 的延长线：19 解决「振多久会裂」用的是
> Steinberg 三带法（**相对位移**判据），这一篇解决的是另外两条物理路径——
> **热失配带来的剪切应变**和**冲击脉冲带来的板面应变**。三条路径不能互相替代：
> 20 g 随机振动通过的板子，照样可能被 100 K 温循或 1500 g 跌落打死。

代码：`src/pcb_agent_mcp/calc/reliability.py`（新增，730 行，纯 stdlib）
测试：`tests/test_reliability.py`（41 例）
工具：`solder_joint_fatigue` / `drop_board_strain` / `vibration_shock_spectrum`

---

## 28.1 一条贯穿全篇的规矩：阈值不许由本服务器发明

这两类问题的公开文献里塞满了「典型许用值」——许用应变 500 µε、许用循环 1000 次、
"typical" 疲劳延性 0.325。**这些东西没有一个属于本服务器**：

| 量 | 谁提供 | 不给会怎样 |
|---|---|---|
| `fatigue_ductility`（ε_f） | 本模块给一个**标明是拟合值**的默认 0.325 | 用了就在 `assumptions.ductility` 里点名，并说明 SAC305 的文献拟合散布在 0.2~0.35 |
| CTE（`alpha_*_ppm`） | 调用方给数，或用预设名 | 预设一律标注为 "typical in-plane CTE"，并写明 FR-4 各向异性、过 Tg 后从 16 跳到 ~60 ppm/K |
| `critical_strain_ue` | **只能调用方给**（来自器件与其鉴定报告） | 不给 ⇒ 只回来一个应变 + `judged: false`，**不出现 pass/fail** |
| `compliance_factor`（F） | 默认 1.0，改它就是改拟合 | `assumptions.strain` 写明「F 小于 1 是拟合，不是物理」 |
| Norris-Landzberg 的 m / n / Ea | 默认 1.75 / 1/3 / 0.141 eV（SnPb 组） | 三个都作为参数暴露，并在返回值里回显用了哪一组 |

这条规矩不是洁癖：焊点寿命对拟合常数的敏感度高得离谱，见 §28.3 的实测。

## 28.2 热疲劳：应变从几何来，寿命从应变来

### 剪切应变范围

```
Δγ = F · DNP · (α_c − α_b) · ΔT / h          （无量纲）
```

- `DNP`：从**中性点**到被判焊点的距离。面积阵列取对角线角点，
  给 `body_a_mm` / `body_b_mm` 时自动算 `hypot(a/2, b/2)` 并回报 `dnp_source`；
- `h`：焊点高度（standoff），也就是失配位移必须被吸收的那段间隙。
  **这是全模块最敏感的一个输入**：它是分母；
- 符号：`α_c − α_b` 的正负只决定哪一侧受压，应变范围是幅值，模块取 `abs()`。

### Engelmaier 应变-寿命（Coffin-Manson 的 Engelmaier 形式）

```
Nf = 0.5 · (Δγ / (2 ε_f))^(1/c)
c  = −0.442 − 6e-4 · T̄_sj + 1.74e-2 · ln(1 + 360 / t_D)
```

`T̄_sj` = 循环内焊点**平均**温度（℃），`t_D` = 半循环驻留时间（分钟）。

**方向性必须记清**（本模块第一版把这句写反了，是测试抓出来的）：
两项都让 `c` **更负**，而 `1/c` 是负的，所以

- 更热 → `c` 更负 → **Nf 更小**；
- 驻留更久 → `c` 更负 → **Nf 更小**。

也就是说 Engelmaier 认为**慢的、带驻留的、热的循环更伤**——因为时间够，焊料发生蠕变，
整个应变范围都被当成非弹性功花掉。物理上正确，直觉上容易写反。

### 实测（15×15 mm 器件、0.5 mm standoff、Δα=10 ppm/K、ΔT=100 K）

| 条件 | c | Nf |
|---|---|---|
| T̄=25 ℃ / 15 min | −0.4010 | 2544 |
| T̄=50 ℃ / 15 min | −0.4160 | 1870 |
| T̄=85 ℃ / 15 min | −0.4370 | 1259 |
| T̄=125 ℃ / 15 min | −0.4610 | 838 |
| T̄=50 ℃ / 1 min | −0.3695 | 5261 |
| T̄=50 ℃ / 15 min | −0.4160 | 1870 |
| T̄=50 ℃ / 60 min | −0.4381 | 1234 |
| T̄=50 ℃ / 240 min | −0.4561 | 908 |

Δγ = 0.0212132（= 10.6066 mm × 10e-6 × 100 / 0.5）。

### 拟合常数是这条链上最大的杠杆

同一个应变，只动 ε_f：

| ε_f | Nf |
|---|---|
| 0.200 | 582 |
| 0.325 | 1870 |
| 0.350 | 2235 |

**一个"文献范围"内的取值就能把答案差 3.8 倍。** 所以 ε_f 不是内部常数，
它是参数，并且用了哪个值必须写在信封里。任何拿这一个数当"设计裕度"的用法都是自欺。

### Miner 与多环境

每种循环环境各自算 Δγ、c、Nf，然后 `damage_i = n_i / Nf_i`，
`blocks_to_failure = 1 / Σdamage_i`。都给了 `blocks_per_year` 时再给一个
`years_to_failure`。**没有给循环数的环境不参与 Miner**，也不产生 verdict——
`damage_per_block` 与 `verdict` 都是 `None`，不是 0 也不是 pass。

### Norris-Landzberg：把试验寿命搬回使用条件

```
N ∝ f^n · ΔT^(−m) · exp(Ea / k T_max)        ⇒
AF = N_use / N_test
   = (ΔT_test/ΔT_use)^m · (f_use/f_test)^n · exp(Ea/k · (1/T_use − 1/T_test))
```

实测：试验 165 K / 2 cpd / T_max 125 ℃，使用 100 K / 1 cpd / T_max 55 ℃ ⇒
**AF = 4.58117**，试验条件 Nf = 197.97 次 ⇒ 折合使用条件 **906.95 次**。

两处必须说清、代码里也写死了：

1. 这里的 `frequency_cpd` 是**含驻留的循环频率**，和 Engelmaier `c` 里的 `t_D`
   是两个旋钮，**不可互换**。模块在 `norris_landzberg.c_dwell` 里明确写出：
   试验条件的 Nf 用的是 `T_max` 配**默认 15 min 驻留**算出来的 `c`，
   与试验真实驻留不是一回事；
2. 只有幂律本身被搬过去，没有做「使用条件下的完整再拟合」。

## 28.3 三处自检：不许和被测对象共用算式

`solder_joint_fatigue` 返回值里带 `self_check`：

| 检查 | 理论值 | 实测 |
|---|---|---|
| `c_at_zero_temp_infinite_dwell` | 0（即 c → −0.442） | 6.3e-12 |
| `nf_at_unit_strain_ratio` | 0.5（Δγ = 2ε_f 时） | 0.5 |
| `log_log_slope_minus_1_over_c` | 0（log-log 斜率就是 1/c） | 0.0 |
| `miner_single_condition_times_damage` | 0（damage × 1/damage − 1） | 0.0 |
| `self_check_af_identity` | 0（AF(x,x) = 1） | 0.0 |

但**自检和主算式同源**，它只能抓「公式写错」，抓不了「公式抄错」。所以
`tests/test_reliability.py` 另外造了两条**不共用代码**的第二解：

- **Nf 用二分法反解**：直接对 `ε_f·(2N)^c − Δγ/2 = 0` 做二分，
  完全不经过 `0.5·(Δγ/2ε_f)^(1/c)` 这个代数重排。四组 Δγ × 三组 c 全部对齐到 1e-6。
- **AF 用两条完整寿命相除**：按 `N = f^n·ΔT^(−m)·exp(Ea/kT)` 分别算出 test 和 use
  的绝对寿命（A 取 1），再相除，与模块给出的 AF 比值对齐到 1e-5。
  这一条同时验证了**三个符号都不反**——尤其是 `(f_use/f_test)^n` 那个方向：
  频率项很容易写反，写反了 AF 就从 4.58 变成 0.79。

## 28.4 跌落：三段已验证的求解器串起来，不重新推导

`drop_board_strain` 自己不写任何新物理，它只把 19 号文档里已经对过账的三段接起来：

```
第 1 段  vibration.plate_modes    → f1（板自己的第一阶模态）
第 2 段  vibration.shock_sdof     → 该模态在同一个脉冲下的峰值位移
第 3 段  vibration.plate_stress   → 该位移对应的板面应变
```

单模态这条假设是**明写**的：第一阶模态被当成一个同频同阻尼的单自由度振子，
所以它的峰值模态幅值就等于反节点处的峰值挠度。测试里**逐段复核**这条链：
先独立调 `plate_modes` 比频率，再独立调 `shock_sdof` 比位移，再独立调
`plate_stress` 比应变，三段都必须对上 1e-6。这样「串错了哪一段」会直接暴露成
三个不同的失败点，而不是一个笼统的错答案。

### 实测（100×80×1.6 mm FR-4，四角点支，Q=15，1500 g / 0.5 ms 半正弦）

| 量 | 值 |
|---|---|
| f1 | 223.662 Hz |
| 静位移（同样幅值持续加载） | 7.44848 mm |
| 峰值挠度 | 3.12767 mm（放大率 0.4199） |
| 峰值绝对加速度 | 631.268 g |
| 板面应变 | 2036.8 µε |

位移放大率**小于 1** 是对的：脉冲只有 0.5 ms，而 f1 = 224 Hz 的周期是 4.5 ms，
板子来不及跟着走完一个静位移。**"短脉冲 ⇒ 位移放大率小于 1"** 这条
是这一层最容易读反的地方（和振动里 DLF 总是 ≥ 1 的习惯相反，因为那边问的是
相对位移对**同幅值稳态**的比）。

### 为什么 verdict 必须由调用方给

`critical_strain_ue` 不给时，返回值里是 `judged: false`、`verdict: null`，
并在 `warnings` 里写：「一个焊点能活过多少应变属于器件和它的鉴定报告
（JESD22-B111 / B113 一类），本服务器没有这个数」。给了才出现
`verdict` / `strain_margin`。

### 焊点剪切应变（可选）

同时给 `dnp_mm` 和 `joint_height_mm` 时，额外回报

```
γ = ε_board · DNP / h
```

含义是「板在 DNP 这段距离上的伸长量全部由焊点剪切吸收」。假设也写死在返回值里：
**刚性器件、引线不柔顺**——对有翼形引线的封装，这个式子会**高估**，因为引线自己会弯。

## 28.5 冲击响应谱：先说清脉冲在每个频率上有多狠

`solder_joint_fatigue` 和 `drop_board_strain` 都需要一个脉冲，而脉冲"有多狠"
是频率相关的。`vibration_shock_spectrum` 扫一串单自由度振子，逐点报
峰值绝对加速度（ZPA）、伪速度（PV = 2πf·z）与峰值相对位移。

**默认 5 % 阻尼**——这是 SRS 的行业惯例，**是惯例不是你的板子的属性**，
所以 `damping.defaulted: true` + `convention` 一段话明示。

### 实测（1500 g / 0.5 ms 半正弦，5 % 阻尼，20 Hz ~ 5 kHz 对数扫 12 点）

| f (Hz) | ZPA (g) | PV (mm/s) |
|---|---|---|
| 20.0 | 55.9 | 4337.7 |
| 148.9 | 413.9 | 4315.6 |
| 1109.1 | 2295.6 | 3215.8 |
| **1832.2** | **2462.1** | 2092.1 |
| 5000.0 | 1567.4 | 489.4 |

- **峰值 ZPA = 2462.06 g，出现在 1832.23 Hz**，是输入峰值的 **1.641 倍**
  （半正弦的理论最大放大率约 1.73，5 % 阻尼下 1.64 正确）；
- 低频段 PV 平台 = 4337.7 mm/s。这个数的物理意义是**脉冲的速度变化量**
  ΔV = a₀·2t_d/π = 4682.3 mm/s。实测比它低 **7.4 %**，而
  `exp(−ζπ/2) = exp(−0.05·π/2) = 0.9250` ——**完全就是这个阻尼因子**。
  这条成了测试里的一条硬断言：`pv[0]/ΔV == exp(−ζπ/2)` 对到两位小数。

### 两条独立极限检查

| 检查 | 理论 | 实测 |
|---|---|---|
| 阶跃 + 近零阻尼（ζ=1e-9） | 每个频率都恰好 2 倍输入 | 59.9995 / 59.9999 / 60.0（输入 30 g） |
| 任意点不超过无阻尼上界 2×输入峰值 | 恒成立 | 全部通过 |

阶跃在任意频率都给出精确 2 倍，是位移解的解析结论（`2a/ω²` 对应 2a 的绝对加速度），
和频率无关——所以它是一个在**每一行**都能验的恒等式，而不只是一个数量级检查。
（ζ 恰好为 0 会被单自由度求解器拒绝：无阻尼不是阻尼比，是共振。）

## 28.6 明确不做的事

1. **不做蠕变-疲劳交互**，除了 Engelmaier 的 `c` 已经裹进去的那部分；
2. **不算 underfill、空洞、IMC 生长**——这三个在真实失效里权重不低；
3. **不算裂纹扩展阶段**：`Nf` 是"到出现可检裂纹"，不是"到断"；
4. **不算跌落方向性**：真实跌落有确定的方向，板子也有多阶模态参与；
5. **跌落链不算器件质量**：器件质量会把 f1 压下来、把响应抬上去，
   所以这里给出的响应是**偏乐观**的，信封里每次都写；
6. **不做多模态叠加**：单模态假设；
7. **不做热梯度**：认为焊点内部温度均匀，用平均温度；
8. **不产生任何许用值**。
