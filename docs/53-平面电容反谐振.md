# 53 · 平面-电容反谐振：把腔体写成 (N+1) 端口，然后降阶

`pdn_plane_impedance`（第 52 篇）只画平面自己。电容通常是平面-地之间**最主要的阻尼**，
所以那条曲线的峰会偏高、谷会偏深；更关键的是**两个峰之间那个谷**——电容转成感性、平面仍是
容性，二者在那里并联谐振，那个峰在 plane-only 曲线上根本不存在。

0.0.50 把这件事做成一个**新工具** `pdn_plane_with_caps`（第 162 个），不是给旧工具加参数：
旧工具的语义与答案必须逐位不变（§53.1）。

一句话结论：**这不是拟合，是线性网络的恒等变换**——腔体当成 (N+1) 端口 Z 矩阵，每颗电容是
一条 R-L-C 支路，然后做标准的端口降阶。它可被**另一条路径**（反正规化到导纳）交叉验证到
1e-6（§53.4）。

## 53.1 为什么是新工具，而不是给曲线工具加 `caps`

三条理由，每条都指向"不静默改变既有答案"：

* `pdn_plane_impedance` 的答案是**平面自己**的曲线，`plane_only_*` 这个语义要能用来做对照。
  给它加 `caps` 会让同一个工具在同一批参数下给出两种含义的 `value`；
* 每颗电容是**一个额外的端口**，需要它自己的焊盘（否则对角元发散，§52.2），这是新的必填量；
* 收敛行为不同：加载后的答案需要**更高的阶数**才收敛（§53.3 实测：0.5 mm 焊盘在默认带上
  中心位置 512、节点位置 1024，而 plane-only 只需 256）。

所以 plane-only 的默认 `max_order` 仍是 256，这个工具的默认是 1024，两者的差别是实测出来的，
不是拍出来的。

## 53.2 模型：腔体是 (N+1) 端口

端口 0 = 注入点，端口 1..N = 电容站点。任意两端口之间的转移阻抗就是第 52 篇那条级数，
但**每个端口带自己的孔径**：

    Z_ij = j·w·μ0·h · Σ_mn  P_i(m) P_j(m) Q_i(n) Q_j(n) / (k_mn² − κ²)
    P_i(m) = √c_m · S_x,i(m) · cos(mπ x_i/a)
    Q_i(n) = √c_n · S_y,i(n) · cos(nπ y_i/b)
    c_0 = 1，c_m = 2 (m>0)

对同一端口对，(P_i P_j)(Q_i Q_j) 精确重建第 52 篇的 `c_m c_n` 因子（`√c` 拆一半给每个端口），
所以两者是**同一个级数**，不是"另写一遍看着差不多"——`tests/test_plane_caps.py` 把矩阵的每个
元素与 `_plane_modal_z` 逐对拍到 1e-12，包括两端焊盘不同的情形。

每颗电容是一条串联支路，从上层板到下层板：

    Z_c = esr + j·w·esl + 1/(j·w·C)

端口降阶（这一步是**恒等式**，不是近似）：

    Z_in = Z00 − Z0c · (Zcc + diag(Z_c))⁻¹ · Zc0

`Zcc` 是电容端口之间的子矩阵（含各自的 `Z_ii`），`diag(Z_c)` 把支路串进去。

### 53.2.1 一个除法给所有 (i,j) 共用

朴素写法是 N(N+1)/2 次单对调用：15 个元素 × 0.04 s 已经 0.6 s，而每一次都要重算一遍模表。
矩阵法把 `1/(k_mn² − κ²)` 提到最内层循环外面，让所有 (i,j) 共用：

    inv = 1/(k_mn² − κ²);   M[i][j] += a_i·a_j·inv

实测：**15 个元素在 order 256 上 0.24 s，而单元素 0.04 s**——整张矩阵的代价不到"逐元素"
的 2.5 倍，且顺带白得 `Z00`（plane-only 对照，零额外成本）。另外把 `np_ = 1/2/3` 写死展开
（实测再快 2.5 倍：0.0768 s → 0.0303 s），`np_ ≥ 4` 走通用路径。

复杂度 `order²·Np²/2`，其中 `Np = 1 + 电容数`。默认带、1 颗电容、order 512：18.3 s；
节点位置 order 1024：70 s。

## 53.3 收敛门改成双条件（这一条同时动了 0.49）

0.49 的判据是「最后一次翻倍的相对变化 ≤ tolerance」。这一轮把它**测穿了**：单条件的门挡不住
一条"慢慢收敛"的尾项。两个今天量出来的例子：

**（a）单点查询根本没有被门检查（已修）**

`freqs_hz` 只给一个频点时，`probe_f`（门的探针频率集）是**空的**：没有模频落进带内，中段填充
`mid *= 1.7` 也退不出去。空集 ⇒ 循环体一次都不进 ⇒ 相对变化恒 0 ⇒ 门在第一个允许的阶
（64）就放行。实测该点 order 64 到 128 之间 |Z_in| 还差 **9.7 %**。修法不是加参数，是让
**调用者自己的频点当探针**（`probe_f` 为空时取 `{lo, hi}`）——那个频点正是答案所在。

**（b）增量不单调衰减时，单条件门会提前放行**

默认带、1 颗 100 nF/1 nH/0.01 Ω 电容（0.5 mm 焊盘、中心），加载曲线的逐次翻倍增量
（相对带内峰值）：

| 阶数 | 16 | 32 | 64 | 128 | 256 | 512 |
|---|---|---|---|---|---|---|
| 加载曲线 Δ/峰值 | 6.83 % | 11.61 % | 21.03 % | 22.31 % | **2.54 %** | **0.65 %** |
| plane-only Δ/峰值 | 6.29 % | 5.97 % | 5.01 % | 2.52 % | 0.203 % | 0.0498 % |

注意两个信号：**加载曲线在 128 阶的增量比 64 阶还大**（22.31 % > 21.03 %），而 256 阶
一下就掉到 2.54 %。一个 tolerance = 3 % 的单条件门会在 **256 阶**放行，而那时答案还差
0.65 % 的峰值（下一次翻倍还会动）——更糟的是它在 128→256 之间"看起来收敛了"。

所以门改成**双条件**：

    rc ≤ tolerance   且   len(increments) ≥ 3   且   rc ≤ 0.5 × prev_rc

即**增量自身必须减半**。同时门控两半答案：`Z_in` 与 `Z00` 各自按**自己的带内峰值**归一
（`loaded_change_rel_to_peak` / `plane_only_change_rel_to_peak` 都报出来），这样
`plane_only_*` 与 `pdn_plane_impedance` 的读数仍在同阶可比。

**对 0.49 默认答案的影响：零。** 默认带（50×50 mm、εr 4.4、t 1.6 mm、tanδ 0.02、端口
`[12.5,25]`、焊盘 0.5 mm）的扫描仍是

| 阶数 | 16 | 32 | 64 | 128 | 256 |
|---|---|---|---|---|---|
| Δ/峰值 | 6.29 % | 5.97 % | 5.01 % | 2.52 % | **0.203 %** |

128 阶的 2.52 % 大于 `0.5 × 5.01 % = 2.505 %`（差一点点被拒），于是仍在 **256 阶**接受，
读数逐位不变：`peak 92.4503 Ω @ 2.85841 GHz`、`dip 1.75989 Ω @ 1.55812 GHz`、106 个曲线点、
2.13 s。

**对 0.50 自己读数的影响：有，且已重算。** 同一颗电容的默认带调用在 256 阶被旧门接受过
（峰值 158.46 Ω），而那个数比收敛值低约 2.5 %（峰值附近的点在 400~440 MHz 一带对阶数特别
敏感）。收敛后（512 阶）是 **163.96 Ω @ 417.93 MHz**。凡是旧数字，一律作废。

## 53.4 三条独立真值（都不共用被检验的那段代码）

1. **零电容恒等**：`caps = []` 必须**逐位**等于 `pdn_plane_impedance`。实测两条曲线的 106 个
   频点、`freq_hz` 与 `z_ohm` 全等（双方都过 `_sig` 6 位），`peak` 都是 92.4503、order 都是
   256。这是"新工具没有偷偷改老答案"的运行时证据。
2. **开路恒等**：`c_farad = 1e-18`（远在双精度之外）必须等于 plane-only。实测 3 个曲线点
   相对差 **0.0**（6 位有效数字下完全相同），`peak_at_cavity_mode = True`。
3. **端口降阶的另算路径**：把 `Zcav` 求逆成 `Y`、在电容端口对角上加 `1/Z_c`、再求逆、取
   `[0][0]`——这是"加载支路"的另一种写法，不经过 `Z00 − Z0c(...)⁻¹Zc0`。实测在工具自己
   报的阶上相对差 **≤ 2e-6**（就是 `_sig` 的舍入），相位对上 3 位小数。

另外 `_csolve`（部分主元高斯消元）单独测：3×3 复系数解回代到 1e-12、对角为零但可换行的
矩阵不除零、真正奇异的矩阵返回 `None`（→ `NO_SOLUTION`，不是随便一个数）。

## 53.6 四条会失败的对照

1. **位置选择性（波腹 vs 节点）**：(0,2) 模 `f02 = 2.8584 GHz`，同一个电容、同样几何，
   只换位置。
   * 波腹 `(25,25)`：|Z| = **60.2092 Ω**，plane-only 同一行 **92.4504 Ω**，比值 0.651
     ⇒ 该模被阻尼；
   * 节点 `(25,12.5)`：|Z| = **92.4709 Ω**，比值 **1.0002** ⇒ **一点没阻尼**（0.02 %）。
   这条对照是会失败的：哪天耦合不再逐模（比如特征函数归一化写错一个因子），节点位置立刻
   跟着变。
2. **ESL 方向**：`w·esl = 1/(w·C)` ⇒ esl 越大反谐振越低。上表 4 nH→279 MHz、1 nH→440 MHz
   是两条互斥读数；把 `j·w·esl` 的符号写错，两者会互换。
3. **零电容恒等 / 开路恒等**：见 §53.4。它们是"没有引入额外物理"的运行时证明。
4. **无源性**：曲线上 `Re(Z_in)/|Z_in|` 的最坏值必须 ≥ 0。实测 `worst_re_over_abs_z = None`，
   即没有一个点越界；阈值 `-1e-9`，越界即 `INTERNAL_CHECK_FAILED`。这是**唯一**能抓住
   "`P_i` 多/少一个 √2"这类错误的全曲线判据。

## 53.7 三条读法（都会被读反）

1. **反谐振可以让加载曲线的峰高于 plane 峰**。中心那颗电容把 92.45 Ω 抬到 163.96 Ω
   （`peak_ratio_vs_plane = 1.773`）。所以只有一个"阻尼比"会被读成"电容让峰变高了"——
   工具报两个数：`peak_ratio_vs_plane`（加载峰相对 plane 峰）与
   `at_plane_peak_damping`（plane 自己那个模被压了多少，92.4589 / 163.96 与
   `at_plane_peak_z_ohm`）。两者**不是**一个量的倒数。
2. **`plane_only_*` 与 plane-only 工具同阶可比**，因为两半答案都被门控过（§53.3）。若只
   门控加载曲线，会出现"加载答案收敛了（被电容压平），plane-only 还在动"的假通过。
3. **`first_mode_q` 仍是上界**：`Q = 1/(1/Qc + 1/Qd)` 只看介质与铜，**没有任何东西跨接在
   两板之间**（除了你列的电容）。真实板子上还有封装、有源器件的并联支路，Q 只会更低。
4. 节点的情形要比中心**贵**：加载后的 |Z| 在那里是两个可比的数之差，截断误差被放大，
   实测 512 阶还动 2.1 %，要 1024。所以默认阶给到 1024——不给的话"电容放在模节点上"这个
   完全正常的问题会默认拒答。

## 53.8 拒答（每条都有测试）

| 情形 | 码 | 依据 |
|---|---|---|

| `caps[k]` 缺 `pad_mm` | `ARG_REQUIRED` | 电容站点的 `Z_ii` 同样发散 |
| `caps[k]` 缺 `c_farad` | `ARG_REQUIRED` | 没有它就没有支路 |
| 缺 `tan_delta` | `ARG_REQUIRED` | 无损时每个模峰无穷，电容在阻尼一个不存在的答案 |

| `at_mm` 在板外 / `pad_mm` 超过半板 | `ARG_RANGE` | 同 §52 的焊盘口径 |
| 超过 8 颗电容 | `ARG_RANGE` | 每颗是一个端口，矩阵按 `(N+1)²` 涨 |
| 容差没人能满足 / 阶数封顶仍在动 | `NOT_CONVERGED` | 报 `order_reached` 与整张 `order_scan` |
| 支路在某频点上正好短路到注入点 | `NO_SOLUTION` | `_csolve` 返回 `None`，提示给 esr 或挪位置 |
| 曲线出现 `Re(Z) < 0` | `INTERNAL_CHECK_FAILED` | 无源网络不可能，说明降阶或归一化错了 |
| 平面锚点（`f10/1000` 处 = 平板电容）偏 > 1 % | `INTERNAL_CHECK_FAILED` | 同 §52.6 |
| 低频锚点偏 > 0.5 %（**只在电容主导时判**） | `INTERNAL_CHECK_FAILED` | 见下 |

**低频锚点为什么有条件**：`f → 0` 时加载网络应等于 `j·ω·C_pp + Σ 1/Z_c`。但这不是精确极限：
端口之间有**铺展电感**，而 `Q = h/δs` 这个约定在 f→0 时把 (0,0) 也弄成了有损（物理上均匀场
H = 0 不损耗）。网格实测：电容比 |Z00| 小 10 倍时锚点成立到 **0.02 %**；电容与 |Z00| 同量级时
最大偏 **2.4 %**。所以门只在"电容主导"（`|Z_anchor| ≤ 0.1·|Z00|`）时生效，并把
`low_freq_anchor_applicable` / `low_freq_anchor_error_pct` 一起报出来——**不假装通过**。

## 53.9 与两个邻居的分工，以及自检

* `pdn_plane_modes`：单模峰值表，秒回，不需要焊盘。问"带内有哪些模"。
* `pdn_plane_impedance`：**平面自己**的曲线（含铜损），需要焊盘与阶数门。问"平面自己多高"。
* `pdn_plane_with_caps`：**加载后的曲线**，需要每颗电容的焊盘，阶数门更严。问"装了这批电容
  之后 |Z| 多少、反谐振在哪"。
* `decoupling_check` 仍是**集中 R-L-C**：它看不见腔体（除了 `plane_cap_farad`），也不该被
  当成这个工具的替代。这个工具反过来**不给结论**：反谐振算不算问题取决于负载电流的频谱，
  那个数不在这里（写进 `not_computed`）。

`not_computed`（5 条）点名：die/package 侧与过孔桶壁、你给的 esr/esl 之外的一切安装电感、
没列出的每一颗电容、分割平面/辐射 Q/开放边缘失谐、以及**任何判词**。

`--selftest` 新增 3 条（id 1601/1602/1603，总 **175** 条）：

* 零电容 = 平面曲线（1e-9 相对）；
* 波腹阻尼（< 0.8×plane）而节点不阻尼（|ratio−1| < 0.01），两处都用**同一行**的
  `plane_only_z_ohm` 比 —— 所以换了接受阶也不会假挂；
* ESL 1 nH / 4 nH 在 `[279, 440] MHz` 上反谐振位置互换（各 > 10 倍）。

`tests/test_plane_caps.py` 23 例：矩阵每元素对单对函数（1/2/3 端口 + **4 端口通用路径**）
1e-12、矩阵对称、`_csolve`（3×3 复解 / 换行 / 奇异→None）、**导纳路径独立重算降阶**、
零电容 = 平面工具、开路 = 平面工具、注入点短路埋掉腔体、波腹/节点位置对照、ESL 互换、
加载峰高于平面峰、`NOT_CONVERGED`（含"加载曲线不能跳过门"）、`order_scan` 两半都报、
缺参/越界/9 颗、工具面（注册 / `available` / `value == peak_z_ohm`）。
