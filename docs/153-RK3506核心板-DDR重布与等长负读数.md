# 153 RK3506 核心板 · DDR 重布与等长的负读数（0.1.16）

上一版（152 / 0.1.15）量出「蛇形能加的铜只有需求的 11%」，并把它归因到「走线成束并行、束外空地很多」。
本版去验证那条推论：**把束拆开、重布，能不能腾出蛇形空间**。答案是不能——而且量到了真正的根因：
**U1 的逃逸过孔已经互相封死**，别说蛇形，连新的一条线都逃不出来。

本轮零放宽：DRC 规则仍是工程模板里的官方值（`min_clearance 0.1`、`min_track_width 0.1`、
`min_via_diameter 0.2`、`min_via_annular_width 0.05`、`min_copper_edge_clearance 0.3`）。
「0.10 mm 净空」是规则本身，不是本轮降低了要求。

---

## 1 先量：组内的固有距离离散（直线，mm）

蛇形只能加铜，所以一个组的目标长度等于组内**最长**那条。因此「最短的那条要加多少」才是这组能不能救的量。

| 组 | 最短 | 最长 | 离散 = 最短那条至少要加 |
|---|---|---|---|
| DQS0P/DQS0N | 10.67 | 12.03 | 1.36 |
| DQS1P/DQS1N | 10.08 | 10.27 | 0.19 |
| CLKP/CLKN | 13.07 | 14.43 | 1.36 |
| lane0（DQ0-7+DM0） | 10.10 | 14.35 | 4.26 |
| lane1（DQ8-15+DM1） | 7.40 | 11.17 | 3.77 |
| addr/cmd 对 CLK | 13.07 | 22.31 | 9.24 |

离散来自摆位本身，不是布线质量：U1 的 50 个 DDR 焊盘挤在 11.8 × 2.7 mm 的一条带上，
U2 的 50 个信号球摊在 6.4 × 12.0 mm 的一片上。任你怎么画，两片之间的最近距离就差了这么多。

## 2 路线一：细步长 / 低净空阶梯 —— 全 REFUSED

| 步长 / 净空 | 结果 |
|---|---|
| 0.050 / 0.120 | 48 网里 OK 31、REFUSED 17 |
| 0.035 / 0.120 | 剩 17 网里 OK 10 |
| 0.035 / 0.100 | 剩 7 网 no-path |
| 0.030 / 0.100 | 剩 7 网 no-path（BUDGET 170–430 s/网，搜索框扩到全板） |

净空一路压到 0.10（官方规则值）仍然 no-path ⇒ 不是净空太严，是没地方。

## 3 路线二：撕掉 50 条整组重布 —— 换顺序也救不回

撕掉全部 1601 段/孔后重布（双端逃逸，见 §5）：

| 顺序 | 结果 |
|---|---|
| 按跨度**降序**（远端先布） | 23/50；近端 12 条全灭 |
| 按跨度**升序**（近端先布） | 38/50；远端 A13 / RESET / A9 / A11 全灭 |

降序时远端占满逃逸环、近端出不来；升序时反过来。**两端都只能容纳大约 40 条**，
比现状（48 条）更差 ⇒ 现有 48 条不是「随便布的」，它已经接近这布局的上限。

## 4 路线三：只撕 19 条过长网（>23 mm）重布 —— 第 2 条就无路

保留其余 31 条的铜，只重布 CSN / WEN / A3 / A0 / ZQ / BA0 / A9 / A13 / RESET / A5 / ODT / A7 /
A2 / RASN / A6 / DQ7 / DM0 / A12 / DQ5 共 19 条（842 段）：

- A13 OK，但用了 **71 段**——它是在残余缝隙里绕出来的，不是直路；
- A7、RESET 随即 REFUSED。

⇒ 走廊里剩下的自由度不足以让第 2 条远网通过。这 19 条现在的长度（最长 CSN 33.05 mm）
**不是布线器偷懒，是通道被 31 条占住后的唯一解**。

## 5 本轮新增的两条能力（工具侧的真收获）

**(a) `route_pair`：两端都是 SMD 焊盘时先各逃逸一个过孔再对布。**
旧 `route()` 要求「树里已有一个通孔端」才能开工，于是「pad ↔ pad」的网一律 no-path
——这就是为什么整组重布时 50 条**全部**瞬间 REFUSED（不是算不动，是一开始就没进去）。
补上之后单网立刻通：DQ13 7.40 直线 → 布出 7.98 mm，A13 22.31 → 24.14 mm（旧板 30.75）。
**顺带纠正一个旧结论**：以前把「重布后长度变长」读成布线质量问题，其实是旧路径是唯一解，
新路径才是最短解。长度离散的大头一直在**逃逸过孔的位置**，不在 A* 的搜索。

**(b) PROBE 探针：把「为什么没路」量成可达格数。**
以 USB1_DP 的逃逸过孔为起点做泛洪（搜索框 29.5 × 28.5 mm）：

| 层 | 可到达格 / 总格 |
|---|---|
| F.Cu | 162 / 204216 |
| In2.Cu | 17 / 204216 |
| In4.Cu | 82 / 204216 |
| B.Cu | 399 / 204216 |

四层全部在 400 格以内 ⇒ **过孔被邻网铜封在口袋里**。加预算、加细步长、放宽净空都不会有用。

## 6 蛇形在本板上的实际上限

在现状板上跑蛇形（振幅上限 1.2 mm、间隙 0.15 mm）：

| 网 | 需要加 | 实加到 |
|---|---|---|
| DQ1（lane0 最短） | 11.904 | 0.000 |
| DQ13（lane1 最短） | 10.148 | 0.000 |
| DQS0P（对内） | 1.604 | 0.000 |
| A6 | 8.532 | 1.415 ← 全板最大 |
| CASN | 12.775 | 0.986 |

最大一条只加到 1.42 mm。**在这块板上，蛇形不是「加不满」，是「加不进」。**

## 7 可交付 / 不可交付

可交付（`examples/rk3506_som/rk3506_som.kicad_pcb`，0.1.16）：

- DDR 48/50 连通（A8、A11 只剩桩），整板 `clearance` 违规 **0**、`shorting` **0**；
- DRC 合计 41：`via_dangling` 29、`lib_footprint_issues` 11、`zones_intersect` 1；
- `unconnected_items` **8**：USB1_DP / USB1_DN / SARADC_IN2 / SARADC_IN3 / ACODEC_INN 五条
  从 U1 引到 J1 的长线（逃逸口袋见 §5b），加 `/+1V35_DDR`、`/DDR_A11`、`/DDR_A8` 三条只有桩的网；
- 铺铜仍全部由 KiCad 官方 `ZONE_FILLER` 生成（GND 1802.0 / +1V35 283.6 / +3V3 141.9 + 11.5 / +5V_IN 23.5 mm²）。

不可交付：**6 组等长全部 fail**，偏差 1.604 / 1.952 / 0.940 / 11.904 / 10.148 / 32.084 mm。

### 7b 交付板为什么是这一块，不是「重新铺铜」那块

本版一度把「在 `_v18` 上再跑一次官方 `ZONE_FILLER`」的 `_final16` 当交付候选。上板 DRC 复核发现它更差：
`unconnected_items` 由 8 涨到 **12** —— 重铺给 `In3.Cu` 的 `+3V3` 多生成了一片填充区，
与原有那片判定为「同网同优先级的两片填充区不相连」，连带 3 条 `/+3V3` 走线与过孔脱开。
重铺不是免费的：`ZONE_FILLER` 只保证「按当前规则重新算」，不保证「结果与上一次的连通图等价」。
因此交付板取 `_v18`（0.1.15 的铺铜原样未动），并在上面只做了一件实质改动：
把 `C2` / `C5` 的 GND 焊盘接上（0.1.15 的 `unconnected_items` 是 10，本版 **8**）。

DDR 布线本身与 0.1.15 一致（逐网长度逐位相同）：本轮所有重布尝试都劣于现状，故原样保留。

## 8 结论与下一步（改布局，不是补线）

三件事合起来把「补线能救」这条路封死了：组内固有离散 4.26–9.24 mm、蛇形上限 1.42 mm、
逃逸区四层可达格 ≤400。**误差不在布线，在摆位。**

已量出两个可执行的方向：

| 方向 | 实测依据 |
|---|---|
| U2 旋转 90° | 全 50 网直线离散 14.79 → **7.28 mm**；按 U1 焊盘 x 排序的交叉数 480 → **103** |
| 走廊让出蛇形空间 | 不可行：U2 上方只剩 2.5 mm 到板边，腾不出 |

旋转 90° 把「12 mm 的纵向摊开」换成「横向摊开」，与 U1 那条 11.8 mm 宽的焊盘带对齐，
离散直接减半。这一步要重做 U2 全部 46 个电源球的过孔、并重布 50 条信号，属于下一版的活。

在这一步之前，本板如实记为：**连通性接近上限、净空干净、等长未达标且已证明不可达。**
