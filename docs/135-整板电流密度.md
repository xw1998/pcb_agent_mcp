# 135 · 整板电流密度：J，以及在哪儿

`134` 把热接到了板文件上。这一页接最后一块：**电流密度**。

`current_density_field` 从来是对的——它解 `div(sigma·grad V) = 0`，所以给的是 J **和
它在哪**；而其它一切（`trace_resistance`、`board_ir_drop` 的 `worst_current_density`）
都是 1-D 的 `J = I/(w·t)`，在直段上对，在板子真正失效的地方错：拐角、线宽台阶、过孔
颈部、**焊盘处的漏斗**。缺的从来不是求解器，是**区域和接触点从文件里来**。

---

## 1. 区域就是文件里的铜

一个网、一层：

| 组成 | 从哪来 |
|---|---|
| 走线 | `board_ir_drop(return_network=True)` 的同一张图，边上的 `x,y` 与 `width_mm` 作为圆头折线 |
| 焊盘 | 文件里的 `w/h` 作为矩形**并进区域** |
| 厚度 | 叠层该层的 `copper_um` |
| 接触 | 调用方指定的两个焊盘，半径 `0.4·min(w,h)` |

焊盘必须进区域：不进去的话走线在焊盘下面是断的——而"焊盘处的漏斗"正是要问的东西。
接触点必须由调用方指定：**哪两个焊盘之间**是设计问题，不是文件属性。

一个网打过孔就是**两个场**：合成一个 2-D 解等于解一块不存在的板。别的层、过孔、铺铜
都写进 `notes` 说"不在这个区域里"，不静默合并。

---

## 2. 两个数并排给，而不是挑一个

同一对焊盘上，`board_ir_drop` 的电阻与场解出的电阻一起报，附相对差。它们是**两个测量**：

- 1-D：每条边一个电阻，电流沿宽度均布，焊盘是一个点 ⇒ 看不见焊盘自己的铜，也看不见
  漏斗；
- 场：两个都看得见，但付网格的代价。

所以方向是有规律的：**峰值 J 更高**（接触处漏斗），**电阻往往更低**（焊盘铜把 1-D 收费
的那段路加宽了）。ecc83（C1.1→P3.1，0.1 A）：

| 量 | 场 | 1-D |
|---|---|---|
| R | 0.007034 Ω | 0.008472 Ω（−17%） |
| 峰值 J | 5.51 A/mm² | 3.57 A/mm² |

差得多就说明 1-D 那个数在接触处乐观——这正是把它并排给的原因。

---

## 3. 网格：一个低 25% 的数和一个断开的图

这是这一页最要紧的一段。按包围盒与 unknown 预算取步长时，1 mm 走线只有 7 格宽：

| 步长 | 结果 |
|---|---|
| 包围盒默认（≈0.14 mm） | R = 0.013451，解析 0.013989（−3.8%… 但见下） |
| 最窄宽/3（0.333 mm） | **0.010467，低 25.2%** |
| 0.12 mm | **`NOT_CONNECTED`：粗掩膜把细走线丢了** |
| 最窄宽/6 与 /12（1 mm 线） | 0.014016 / 0.013989，解析 0.013989 |
| 最窄宽/6 与 /12（0.5 mm 线） | 0.027915 / 0.027892，解析 0.027978 |

第三行是关键：粗掩膜丢细走线**不是一个"精度问题"**，solver 只能报断开，而更粗的步长
又"能算出数"。所以规则不是"挑一个好步长"，而是：

1. 默认步长 = **最窄铜宽 / 6**；
2. 必须在**细一倍**的网格上复核，`value.grid_convergence` 报两档电阻与相对变化；
3. 相对变化超过 3% 或细网格跑不动 ⇒ `is_grid_convergent: false`，并在 `notes` 写明
   "这个数只能当形状，不能当电阻"。

ecc83 两档差 **0.2%**（0.0070179 → 0.0070338），判 convergent。

---

## 4. 电阻不是 ρL/(w·t) 的 L

接触是**焊盘那么大的圆盘**（半径 0.8 mm），所以量的是 `30 − 2×0.8 = 28.4 mm`。按 30 mm
算会多出 5.7%，而那 5.7% 是"接触不是焊盘"造成的假差。折半宽度的对照也是同一件事：
0.027892 / 0.013989 = **1.99384**，不是 2.000——两块板的焊盘一样宽，窄线的分流少一点。

## 5. 拒答

| 情形 | 结果 |
|---|---|
| 缺 `net` / 缺任一接触焊盘 | `ARG_MISSING`（并列出该网的焊盘） |
| 两个焊盘是同一个 | `ARG_INVALID` |
| 焊盘不在这个网上 | `ARG_INVALID`（并列出该网的焊盘） |
| 这个网没有走线（只有铺铜） | `NOT_APPLICABLE` |
| 指定的层上没有该网的走线 | `NOT_APPLICABLE`（并说它有铜的层） |
| 焊盘在该层没有铜 | `NOT_CONNECTED` |
| 步长要的格数超过预算 | `MESH_TOO_FINE`（报窄宽、步长、面积、格数、需要的预算） |

最后一条是这一版加的第二道闸门：宁可说"这块网在 4 万未知量下分辨不出来"，也不交一张
断开的图。
