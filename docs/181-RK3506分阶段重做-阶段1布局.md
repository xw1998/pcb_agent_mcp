# 181 RK3506 分阶段重做 · 阶段 1：布局

用户要求：「你一步一步试试 RK3506，做一步给我看一下，比如布局结束了给我看下，ddr 画好了给我看下」。
本文件只记**布局这一步做了什么、量到了什么、还差什么**，不宣称整板可用。

工作副本：`examples/rk3506_som/_rl1.kicad_pcb`（`_` 前缀，不入库）。原始交付板 `rk3506_som.kicad_pcb` 不动。

## 1. 布局决策与证据

### 1.1 U1（RK3506J，BGA-333）不旋转

绕板中心四档旋转，测「空气线总量 / 跨边（网的一端正北一端不朝对方）的网数」：

| U1 rot | 空气线 mm | 错边网数 |
|---|---|---|
| **0** | 4121.21 | **43** |
| 90 | 4901.38 | 97 |
| 180 | 4902.72 | 77 |
| 270 | 4044.95 | 74 |

270° 只省 1.9% 空气线，错边从 43 涨到 74。错边的根因是**模块 140 个邮票半孔在球侧的分配**（球侧 W25/N67/E5，孔侧 W25/N29/E18/S25，对角上界 59/97 ⇒ 38 条必须绕行），属产品引脚定义，挪位置解决不了。⇒ 保持 0°。

### 1.2 U2（MT41K256M16，BGA-96）转 90°

绕自身中心四档：

| U2 rot | DDR 空气线 mm | 交叉序数（x 投影反序对/总对） |
|---|---|---|
| 0 | 737.00 | **479** / 1225 |
| **90** | **688.25** | **94** / 1225 |
| 180 | 690.87 | 453 |
| 270 | 765.58 | 1051 |

转 90° 后 U2 地址球的 x 区间 `[23.00, 27.00]` 与 U1 地址球 `[23.81, 27.18]` 几乎重合，DQS 组 x `[15.80,19.80]` 对 U1 `[16.50,19.88]` 对齐 ⇒ 总线天然成扇出，不是凑数。

### 1.3 四个被动件让位

U2 转 90° 后 courtyard 从竖长（9.5×14.5）变横长（14.5×9.5），压住 C13/R9/R10/C11（最差 gap −0.31 mm）。移到 U2 北侧一排：

- C13 → (20.7, 2.9, 0)
- R9 → (18.4, 2.9, 0)
- R10 → (16.2, 2.9, 0)
- C11 → (13.4, 16.6, 90)

其余 40 个器件坐标不动（`docs/173` 已测：搬周边功能簇只省 2.038 mm，0.1%）。

## 2. 铜的处理

布局一动，U2 焊盘所在层的铜就不可能还对：**只清被布局直接扰动的铜，不整板推倒**。

1. U2 触到的 58 个网里，有铜的 50 个（`/DDR_*`、`/+1V35_DDR` 等，−`/GND`）逐网 `delete_copper` tracks+vias；
2. U2 新 courtyard 内 F.Cu 的走线（焊盘在 F.Cu，BGA 体下方**内层走线是合法**的，第一次误把内层也清了，已修）；
3. U2 新 courtyard 内的 19 个外来过孔（11 个 `/GND`、RMII0_CLK、RMII1_MDC、BS_U6 等）——它们是旧的**盘中孔**，且其中 1 个 `/RMII1_MDC` 过孔离新焊盘 R2 只有 0.056 mm（间距违规）；
4. 被切断后已无铜可连的 3 个网（`/RMII0_CLK`、`/RMII1_MDC`、`/BS_U6`）整网拆除，留给重布；
5. `prune_dangling` 清掉 3 段 GND 短桩、2 个孤立过孔。

没有整板删铜，没有自造铺铜：4 个 zone 全部由 `pcbnew.ZONE_FILLER` 重新灌注。
