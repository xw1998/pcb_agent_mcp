
# 48 · 板级热的两条真缺口：辐射与热过孔

0.0.44 把铜补进了 2-D 场，但答案里还挂着两句实话：`not_computed` 第 1 条写着
「radiation (matters above ~60 C)」，第 2 条干脆只有三个字「thermal vias」。这一版把
这两条都做进模型，并且都用**能失败的对照**钉住，而不是「加了一个数所以更冷了」。

两条路在代数上是**同一个对象**：都是「每格一个到某个不参与求解的温度的线性电导」。

```
gadd[i][j]  (W/K)      —— 该格到这个外部节点的电导
gt[i][j]               —— 同一个电导已经乘过外部节点温度（W）
```

正因为同形，它们共用一个新的 SOR 内循环 `_sor_plate_add`，而原来的
`_sor_plate`（只层压板）和 `_sor_plate_map`（带铺铜）**一行未动**——两条老路径必须
逐位不变，2116 例回归与 0.0.43/0.0.44 的逐位等价断言都压在这上面。在旧循环里加
`if` 就是给所有老答案加税。

## 48.1 辐射：T⁴ 的精确改写，不是把小温差展开

发射率 ε 打开后，两个表面各自向外辐射：

```
q_rad = ε·σ·(T⁴ - Ta⁴)
```

直接把它塞进线性求解器会毁掉「稳态问题恰好线性」这个性质。但 T⁴ 的这一段有一个
**恒等式**（不是截断近似）：

```
ε·σ·(T⁴ - Ta⁴) = h_rad·(T - Ta),   h_rad = ε·σ·(T + Ta)·(T² + Ta²)   [开尔文]
```

右边对 T 是线性的，代价是 `h_rad` 自己依赖 T。所以做法是**外层不动点**：

1. `h_rad` 用上一轮迭代的温度场算（第一步用初值场）；
2. 整场重解（内层 SOR）；
3. 场移动量 < `tol_k` 就停，否则回到 1。

上限 80 次外层。**线性化一次**（把 ε 折进 h）就只是编了一个数；不动点收敛后的答案
才是 T⁴ 的解——而这一点是可以被检验的，见下面的等温极限。

`h_rad` 随温度单调上升（`at_t_ambient < at_t_max`），这条单调性在答案里两个都报出来，
它也是「为什么必须迭代」的直接证据。

每格的贡献是 `gadd += 2·A_cell·h_rad`、`gt += 2·A_cell·h_rad·Ta`（两个面）。

## 48.2 热过孔：一根环形截面的铜管，落在**一格**

每根过孔是一条到指定 sink 的铜管，电导是**环形截面**（不是钻孔面积）：

```
G = k_cu · π·((d/2)² - (d/2 - plating)²) / span
```

0.3 mm 钻孔、25 µm 镀层、1.6 mm 厚：环形面积 0.0215984 mm²，是钻孔面积的
**30.5556 %**——按钻孔面积算会把过孔的散热能力高估三倍多。

落点是**点载荷**：整根过孔的 G 落在「中心所在的那一格」。不做面积分摊，因为分摊会让
「一格 100 根」看起来像「四格各 25 根」，把点载荷抹成面载荷。代价是半格平移可能换格，
这是**如实报告的网格相关性**，`assumption` 里写明。

参数 `thermal_vias = [{x1_mm, y1_mm, x2_mm, y2_mm, pitch_mm, d_mm, plating_um,
span_mm?, sink_c?}]`；中心从 `(x1, y1)` 起按 `pitch` 铺满矩形。

- `span_mm` 缺省 = 板厚；
- `sink_c` 缺省 = 环温，并在 `sink_c_source` 里写 `"ambient"`；给了就是 `"caller"`。

**不与层压板竖向导热并联**：竖向那条路本来就被集总在 `h` 里（0.0.44 的 assumption 已
写死），再并一次 FR4 就是双计。

## 48.3 量出来的数字

几何：100×80×1.6 mm、k=0.3 W/(m·K)、h=10 W/(m²·K)、2 mm 网格（50×40）、
走线 y=40、x 10..90、3 mm 宽、35 µm、4 A。

### 辐射

| ε | t_max (℃) | 辐射占散热 |
|---|---|---|
| 不开 | 36.082953 | — |
| 0.05 | 35.870648 | 3.006 % |
| 0.2 | 35.291757 | 11.017 % |
| 0.5 | 34.338565 | 23.595 % |
| 0.9 | 33.360543 | 35.674 % |
| 1.0 | 33.153972 | 38.114 % |

- `h_rad`：ε=0.9 时 `at_t_ambient` 5.41027、`at_t_max` 5.64212 W/(m²·K)——
  和手算的 `ε·σ·(T+Ta)(T²+Ta²)` 在 5 位上相同，也和 `T=Ta` 时退化成 `4εσTa³`
  的 5.4103 相同；
- 外层迭代 4 次收敛；
- 能量残差 −2.0e-5 %，`power_out_convection + power_out_radiation == power_in`。

### 等温极限：这是「不动点而不是一次线性化」的检验

50×50 mm、2 W 均匀、h=10、ε=0.9、`q` 带温度系数（`1 + α(T−20)`，α 默认 0.00393）
有闭式根：

```
P·(1+α(T−20)) = 2hA(T−Ta) + 2εσA(T⁴−Ta⁴)   →  T = 52.8504556805 ℃
```

k 越大越接近等温：

| k (W/m·K) | tol_k | t_max (℃) | 与根差 | spread | 外层 |
|---|---|---|---|---|---|
| 100 | 1e-6 | 52.850398 | −5.8e-5 | 8e-6 | 6 |
| 1000 | 1e-7 | 52.850374 | −8.2e-5 | 1e-6 | 5 |

**坑（已记录，不改码）**：k=1000 用默认 `tol_k=1e-4` 时能量残差 0.624 %，会触发
`INTERNAL`「energy does not balance」。根因不是新功能错，而是 SOR 的 `dmax < tol`
收敛判据在强导热（迭代矩阵谱半径接近 1）下误差被放大——属既有判据松。写这个锚点必须
传更严的 `tol_k`。

### 热过孔

20×20 mm、2 mm 网格（10×10）、d=0.3、镀层 25 µm、span 1.6、每格 1 根、sink=环温、
均匀 0.02 W：

- **一根**的 `G = 0.005399612373357457 W/K`，与手算 `k_cu·π(r²−r_in²)/span` 逐位相同；
- 100 根共 `G_tot = 0.539961 W/K`；
- **等价性**：把 h 提到 `10 + G_tot/(2·A_cell·100) = 684.95125` 重跑，
  `t_max` 25.037265 对过孔场 25.037263，差 **2e-6 K**。这条等式就是「过孔真的接进了
  场，而不只是被报告出来」的证明；
- 报告的 `equivalent_h_w_m2k` = 674.952（= `G_tot/(2·A_cell·N)`）。

位置判据（100×80 板，287 根）：

| 过孔在哪 | t_max (℃) | 相对裸板 |
|---|---|---|
| 没有过孔 | 36.082953 | — |
| 压在走线上（y 34..46） | 25.431386 | **−10.652 K** |
| 同数量挪到 y 0..12 | 36.082764 | **−0.000189 K** |

负控制的方向是对的：同样的铜、同样的根数，不在热源下面就不帮忙。注意这个板上过孔的
`−10.65 K` 比铺铜的 `−6.7 K` 还大——因为这里 sink 是环温而 `h` 只有 10，等效 h 被抬到
了 600 多，本来就是这个模型允许的最强散热；它说明的是**机制接对了**，不是「过孔比平面
更好」。

- `sink_c = 0`：`t_min = 0.365545`、`t_max = 24.959461`、`status = ok`——低于环温是
  合法的（场被钉在更冷的节点上），不是 runaway。

## 48.4 两处闸门的修正，以及为什么它们不是「放宽」

### 4.1 物理性闸门从 1e-6 改成 `max(1e-6, 10·tol_k)`

原来的闸门是「任何格低于环温就是非物理」。加了过孔后实测出现过
`THERMAL_RUNAWAY: minimum temperature 25 C is below the ambient 25 C`——**这不是物理
问题**，是 SOR 停在 `tol_k=1e-4` 时残差本身就在 1e-5~1e-3 量级。闸门不能在自己的残差上
开火：真的非物理的场是差几度，不是差 1e-5。

### 4.2 闸门基准从「环温」改成「最冷的固定节点」

`sink_c` 比环温低时，场本来就会低于环温。一根通到 0 ℃ 冷板的过孔把格子拖到 0.37 ℃ 是
**正确的解**，用环温当基准会把它判成 runaway。所以 `floor_ref = min(ta, 所有 sink_c)`，
并在 `floor_why` 里写清是哪一个。

## 48.5 三条零变化

1. 不给 `emissivity`、不给 `thermal_vias` → `need_add = False`，走 0.0.44 的原路径，
   **逐位不变**；
2. `emissivity = 0.0` → `emis = None`，与「根本没传」逐位相同（`t_max`/`t_min`/
   `t_avg`/`delta_t_max_k` 全等），且 `radiation.modelled` 仍为 false；
3. `not_computed` **换句不删句**：第 1 条换成辐射的灰体局限、第 2 条换成过孔的单管局限；
   只有两者都开时，第 0 条的尾巴才不再补「thermal vias are not in it」。

## 48.6 拒绝（不近似）

- `emissivity` 不在 0..1 → `ARG_RANGE`（黑体 = 1，焊阻表面典型 0.8~0.9，但它不是常数）；
  非数字 → `ARG_INVALID`；
- 过孔：`plating_um ≥ 钻孔半径` → `ARG_RANGE`（镀层填满就没有环形截面可言）；
  `pitch_mm/d_mm/plating_um/span_mm ≤ 0` → `ARG_RANGE`；矩形出界 → `ARG_RANGE`；
  **没有一根中心落在板内** → `ARG_RANGE`（而不是给一个「0 根过孔」的成功答案）；
  缺键 → `ARG_INVALID` 点名缺哪个键；不是列表 / 元素不是对象 → `ARG_INVALID`；
  `sink_c` 不是数 → `ARG_INVALID`。

## 48.7 仍然不算

3-D、层内平面之间的内部辐射、随温度变化的发射率、元件热质量与元件-板接触热阻、
AC 损耗（趋肤/邻近）、`sim_spice` 里的器件自热、直接去读 `.kicad_pcb` 的走线与 zone。
过孔那侧还有：中段镀层减薄、两端焊盘/平面铺开、铜阻随温度变化（`k_cu` 就是一个数）、
相邻过孔之间的相互作用。

这一版让「板子往空气里辐射」和「过孔把热往下带走」第一次能算进来。它不是 3-D 热仿真。
