# 随机振动的模态叠加：Miles 只算了一个模，而现在把其余的都算上

`vibration_random_response` 一开始就是**单模态**的 Miles 公式：给一个 `f_n_hz`、一个 PSD、一个 Q，
回一个 `g_rms`。它的 docstring 一直写着「这是单模态估计，忽略其余模态，而第二个通常只差
1.5 倍」——这句话在 `not_implemented_yet` 里挂了二十多个版本。

这一篇把它补上：`modes=[...]` 进来，每个模带自己的**参与因子**与**观测点振型值**，位移按复数**相干
求和**、加速度按每个模自己的 `ω²z` 求和，交叉项不丢。同时补上算参与因子的那个数：
`vibration_plate_modes(participation=true)`。

**没有新增工具，工具数仍是 179**：新能力全部以可选参数进入两个既有工具，不给就逐位不变。

## 1. 结论先行

| 问题 | 答案 | 依据 |
| --- | --- | --- |
| 单模态到底错多少 | 两个模只差 5 %（100/105 Hz，Q=25）时，`g_rms` 高 43 %、位移高 61 %，而且**28.6 % 的位移方差来自交叉项**，单模公式里根本没有这一项 | §2 实测 |
| 为什么以前不能算 | 缺两样东西：每个模的**参与因子**（`Γ = ∫w dA / ∫w² dA`）与观测点的**振型值**。两者都要振型，而 `plate_modes` 之前只回频率 | §4 |
| 参与因子准不准 | 和两个解析锚点对上：SSSS 方板 (1,1) 的 `Γ = 16/π² = 1.621139`，本工具给 `1.62102`（**0.007 %**）；带偶数下标的模 `Γ` **恰为 0**（实测 −5.9e-13 量级，是求积残差） | §4 |
| 单模极限对不对 | 一个模 `Γ=1`、`w(p)=1`、平坦 PSD：`g_rms = 21.6982` 对 Miles 闭式 `21.708`（**0.05 %**），位移对 Miles **0.05 %** | §5 |
| 加速度怎么合 | 每个模 `g_i = ω_i²·z_i`，`g_rms = sqrt(Σ g_i²)`（模态叠加的标准做法）；位移则**相干求和**，所以两者不是同一个口径，两个数都报，并在有重叠时给出解说 | §3 |
| 为什么不用 `∫|ω²D|²` | 那个被积函数高频趋于常数，任何带宽积分都会被**非共振**项污染：两模 100/1000 Hz 时它给 82.3 g，正确值 65.71 g（25 % 高）；两模 100/1200 的旧版本更夸张到 66.9 g 对 28.0 g | §3 |
| 仍然不做 | 相位化的单一加速度谱（要每个模在观测点的**相位**，`plate_modes` 不携带）、非比例阻尼的耦合、点力/单点固定激振、应力谱 | §7 |

## 2. 为什么单模态不够：一个 5 % 的邻居

同一块板、同一个 PSD（0.1 g²/Hz）、同一个 Q=25（ζ=0.02）：

| 输入 | `g_rms` | 对 Miles | 位移 rms | 对 Miles 位移 | 相干份额 |
| --- | --- | --- | --- | --- | --- |
| 100 Hz 单模 | 19.8131 | 0.9998 | 0.492168 mm | 0.9998 | 0 |
| 100 + 105 Hz | **28.3684** | **1.432** | **0.795185 mm** | **1.615** | **28.6 %** |
| 100 + 1000 Hz | 65.7146 | 3.316 | 0.492586 mm | 1.001 | 0.00065 % |

三件事一起看：

1. **加速度近了就涨**：105 Hz 那个模把 `g_rms` 从 19.81 抬到 28.37，而它自己的 `g_rms_own` 只有
   ~19.8 —— 这就是「第二模只差 1.5 倍」那句话的代价。
2. **远隔才可加平方**：100 与 1000 Hz 时 `65.7146 = sqrt(19.8131² + 62.6545²)`，与独立求和一致，
   相干份额 0.00065 %（不是 0，因为 1000 Hz 的尾巴在 100 Hz 的峰上有极小的投影）。
3. **位移的交叉项是实的**：28.6 % 的位移方差来自 `2·Re(D₁D₂*)` 那部分。它是被**算进去**的
   （`displacement_rms_mm` 是相干的），同时单独作为一个数报出来 —— 报出来的数和算进去的东西是
   同一个，不是「描述了一件没人计算的事」。

## 3. 三个式子，三条积分

基座均匀加速度 `a(f)`，阻尼按经典（比例、粘性）处理。观测点 `p` 处的相对位移：

```
z_p(f) = -a(f) · Σ_i  w_i(p)·Γ_i / (ω_i² - ω² + 2j·ζ_i·ω·ω_i)
```

绝对加速度 = `a - ω²·z_p`，**每个频点都精确**（不是「取峰值的中间值」那种近似）。两条积分：

| 量 | 被积函数 | 为什么收敛 |
| --- | --- | --- |
| 位移（相干） | `W(f)·|Σ_i D_i|²` | `D_i ~ 1/ω²`，高频掉得快 |
| 每模自己的位移 | `W(f)·|D_k|²` | 同上，用来分账与算「只有最强模」 |
| 绝对加速度（板上传感器读数） | `W(f)·|1 - ω²Σ_i D_i|²` | 高频趋于 1，`a` 与 `ω²z` 相消 |

**不用的那一条**：`W(f)·|ω²Σ D_i|²`。它高频趋于 `c²`（常数），所以任何带宽积分都被非共振的
渐近项主导 —— 两模 100/1000 Hz 时给出 82.32 g，正确值 65.71 g，高 25 %。这条被写成了测试
（`test_the_asymptotic_acceleration_integrand_is_not_what_is_reported`）：那个错数每次都被算出来、
被断言「明显大于正确答案」，所以「为什么不用它」是可检验的，不是口味。

`g_rms` 的合成用的是每个模自己的 `g_i = ω_i²·z_i`：

```
g_rms = sqrt(Σ_i g_i²)
```

这不是偷懒，这是 Miles 自己那一步（模态响应在 `ω_i` 附近窄带，所以该模的加速度就是 `ω_i²` 乘它的
位移）用在每个模上。真正的**相干加速度**需要每个模在观测点的**相位**，`plate_modes` 只给幅值
（振型按峰值归一），所以那个数这里不给 —— 说清楚比给一个假装精确的数更重要。

网格：600 个粗点扫全带（`[0, 3f_max]`，PSD 给点时是 `[首点, max(末点, 3f_max)]`）＋ 每个峰
`±max(12ζ, 0.02)` 的 1200 点细带，合并排序后梯形积分。一个 Q=100 的峰用均匀网格要几十万点才
压得住，而交叉项也必须把峰压住。

## 4. 参与因子为什么是精确矩，而不是拟合权重

```
Γ_i = ∫ w_i dA / ∫ w_i² dA          （w_i 按峰值归一到 1）
```

两个积分都是 Ritz 基的**精确单项式矩**：`φ = X(xi)·Y(eta)` 可分离，`X = Σ_k Wx[k][i]·xi^k`，所以

```
∫ X dxi    = Σ_k Wx[k][i]/(k+1)
∫ X² dxi   = Σ_k Σ_k' Wx[k][i]·Wx[k'][i]/(k+k'+1)
```

没有求积、没有拟合、没有缓存。这带来两个**解析锚点**，也叫「本工具无论如何造不出来的数」：

| 锚点 | 解析值 | 本工具 |
| --- | --- | --- |
| SSSS 方板 (1,1) 的 `Γ` | `16/π² = 1.621139` | `1.62102`（0.007 %） |
| (1,2)、(2,1)、(2,2) 的 `Γ` | **恰 0**（沿该轴积分为 0，均匀基座加速度根本不激励它） | `-5.87e-13`、`-3.27e-13`、`3.8e-18` |
| (1,1) 的质量捕获率 | `(16/π²)²/4 = 0.656966` | `0.657023` |

第三行值得单独说：`Γ² · m_modal / M = (16/π²)² · (1/4)`，因为峰值归一下 (1,1) 的模态质量正好是
板重的四分之一（`100×100×1.6` FR-4：板 29.6 g，每模 `7.4011 g`）。实测 `effective_mass_sum_g =
19.4479 g = 29.6 × 0.657`。

捕获率随模数上升、且**恒 ≤ 1**（Bessel，因为 `Σ Γ_i²∫w_i² ≤ ∫1`）：

| n_modes | 捕获率 |
| --- | --- |
| 1 | 0.657023 |
| 2 | 0.657023（(1,2)/(2,1) 的 Γ=0，一点没加） |
| 4 | 0.657023（(2,2) 也是 0） |
| 9 | 0.819717 |

注意一个**不能误读**的地方：`modal_mass_sum_g` 在 n_modes=9 时会**超过板重**（55.0 g 对 29.6 g）。
这不是质量不守恒，而是振型按**峰值**归一 —— 幅值小的模被放大后 `∫w²` 变大。真正守恒的是捕获率
（`Σ Γ²∫w²`），上表就是它。

## 5. 实测读数（可复现的基准）

`psd = {"g2_per_hz": 0.1}`，模的参数按 `{freq_hz, participation, shape_at_point}` 给：

| 场景 | `g_rms` | Miles 闭式 | 比 | 位移 rms | 对 Miles 位移 | 绝对加速度 | 相干份额 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 100 Hz，Q=25 | 19.8131 | 19.8166 | 0.9998 | 0.492168 mm | 0.9998 | 22.2897 | 0 |
| 300 Hz，Q=10 | 21.6982 | 21.708 | 0.9995 | 0.0598884 mm | 0.9995 | 27.8465 | 0 |
| 1000 Hz，Q=25 | 62.6545 | 62.6657 | 0.9998 | 0.0155637 mm | 0.9998 | 70.4861 | 0 |
| 100 + 1000 Hz | 65.7146 | 19.8166 | 3.316 | 0.492586 mm | 1.001 | 82.321 | 0.00065 % |
| 100 + 105 Hz | 28.3684 | 19.8166 | 1.432 | 0.795185 mm | 1.615 | 36.9417 | 28.6 % |
| SSSS 100×100×1.6 的四个模，Q=25 | 73.8585 | 73.8565 | 1.000 | 0.065657 mm | 1.000 | 98.7721 | −3.8e-14 % |

最后一行是另一类锚点：一块真板的前四个模里只有 (1,1) 能被基座加速度激励，所以四模答案**必须**
等于单模答案（73.86 对 73.86），相干份额必须是 0（−3.8e-14 是浮点噪声）。这条测试
（`test_the_four_modal_answers_collapse_to_one_on_a_real_plate`）能抓住「把死模也算进去」的错误。

单模的 `g` 随 `√f` 增长：100 → 1000 Hz 时 19.81 → 62.65（`sqrt(10) = 3.16` 倍）。

## 6. Miles 就是这套的一个特例

Miles：`g_rms = sqrt(π/2 · f_n · Q · W)`。它是本工具在「一个模、`Γ·w(p) = 1`、平坦 PSD」下的
极限 —— 上表前三行就是这条极限的对账（误差 0.02~0.05 %，来自梯形积分而不是公式差异）。
所以两件事同时成立：

- 老答案没有被动过：不给 `modes` 时走的是原来那条代码路径，171 个既有振动测试逐位通过；
- 新答案是老答案的**推广**，不是另一套模型：`ratio_to_miles` 这个字段就是用来量「推广了多少」的
  （1.00 表示没推广，1.43 表示第二个模抬了 43 %）。

## 7. 仍然不做的，以及为什么

| 不做 | 为什么 |
| --- | --- |
| 相位化的**单一**加速度谱 | 需要每个模在观测点的相位；`plate_modes` 的振型按峰值归一到实数幅值，没有相位。给了会是伪造的精确 |
| 非比例阻尼（复模态）的耦合 | 现在按经典阻尼：每个模有自己的 `ζ_i`，但耦合项假设实模态。复模态要解非对称特征值问题，是另一个求解器 |
| 点力激振 / 单点固定激振 | 现口径是**均匀基座加速度**。点力要模态力 `∫w·F δ(p-p0)`，单点固定要另一组边界条件 |
| 应力谱 / 疲劳 | 位移与加速度有了，应力还是走 `steinberg_fatigue` 的单模 3σ 口径；多模应力谱（Dirlik 等）是独立一层 |
| 应变率、声致振、非线性 | 与 `plate_modes` 同一层边界，没变 |

这几条在 `calc_capabilities` 的 `not_implemented_yet` 第 21 条里逐条写着（本版把它的前半句
从「SINGLE-MODE」改成了「已支持模态叠加」，其余四条原样保留）。

## 8. 门与回归

- **默认关时逐位不变**：`participation` 不给，`plate_modes` 的值里没有 `participation` 键；`modes`
  不给，`miles_response` 走原路径。两条都有测试（`TestDefaultOffChangesNothing`）。
- **`--selftest`：305/305**（0.0.82 是 301）。新增四条：`Γ = 16/π²` 与 `Γ = 0`、捕获率
  `0.656966`、单模对 Miles 1 %、5 % 邻居改变答案且报出相干份额。
- **用例**：`tests/test_vibration_modal.py` 41 例；全量从 3304 涨到 3345。
- **工具数不动**：179（`available` 173）。`vibration_random_response` 的 `required` 从
  `["f_n_hz","psd"]` 改成 `["psd"]` —— 这不是放松判据，是纠正必填项的归属：`modes` 路径不需要
  `f_n_hz`，而两者都不给时函数内仍然 `ARG_INVALID`（有测试）。
- **两条口径写死在这里**，免得以后被当成 bug 改掉：
  1. `g_rms` 是**共振**口径（`Σ(ω_i²z_i)²`），与 Miles/Steinberg 可比；
     `g_rms_absolute_including_quasistatic` 才是板上传感器读数（含准静态段）。两个都报，不许只报一个。
  2. `mass_capture_fraction` 是**无量纲分数**（0.657），不是百分数；`coherent_displacement_variance_share_pct`
     才是百分数。
