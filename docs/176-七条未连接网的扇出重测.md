# 176 · 剩下 7 条未连接网：重新量一遍（`docs/168` 的可抄段已随删孔失效）

`docs/175` §4 把「7 条未连接网」留在欠账表里，理由写的是「属布局层」。这一份不是继续写理由，
而是**把它量成一组可核对的数**，顺便更正一处已经过期的记录：

> `docs/168` §2 说「`/USB1_DP` 已验可用的手绘段：`(41.70,33.058)→(41.70,21.30)→(44.00,19.00)→(45.00,19.00)`，
> 角度 90/135/0 全合法、最小余量 +0.450/+0.557/+0.525」。
>
> 那条线**起点是一个过孔**，而 `0.1.34` 把 24 个悬空过孔全删了（其中 11 个正好落在这 7 条网上）。
> 现在这 7 条网**一个铜点都没有**，那条线无处可接 ⇒ **该段作废，不能再当"可抄"引用**。
> 本轮先在 `docs/168` §3.2 就地加了一行更正。

## 1. 现状：7 条网全是「两个焊盘、零根铜线」

`pcbnew` 逐网列出 pads / vias / tracks（`/USB1_DP` 为例，其余六条同型）：

```
PAD J1.59  at (45.0000,-19.0000) size 0.850/0.850 layers=..._55555555_5555555f   (PTH)
PAD U1.B15 at (22.6861,-32.7770) size 0.250/0.250 layers=..._00000000_00002003   (F.Cu 单层)
UNCONN=7
```

| 网 | 焊盘 A | 焊盘 B |
|---|---|---|
| `/USB1_DP` | `J1.59` (45.000, 19.000) PTH | `U1.B15` (22.6861, 32.7770) |
| `/USB1_DN` | `J1.60` (45.000, 18.000) | `U1.A15` (22.6861, 33.3391) |
| `/SARADC_IN2` | `J1.65` (45.000, 13.000) | `U1.A21` (26.0579, 33.3391) |

所以这不再是一个"断开两根线"的问题，而是**每个 BGA 球的第一步扇出都没有**。

## 2. 球能不能出线：`board_blockers` 的八扇区读数

用仓库已有的 `board_blockers`（`route/blockers.py`，同一套 `Grid.seg_blockers` 精确段测），
对 U1 一侧的七个球各打一遍（`layer=F.Cu`，`clearance` 取板规 0.10）：

| 球 | 网 | 开着的扇区 | 挡它的东西（节选） |
|---|---|---|---|
| `U1.B15` | `/USB1_DP` | **SE** | E/N/W 是对面球自己的同族网（`/USB0_DN`、`/USB1_DN`、`/MIPI_DSI_CLKN` 的 pad 与 track）；SW/S 是两颗 `/GND` 过孔（short 0.0234 / 0.0367 mm） |
| `U1.A15` | `/USB1_DN` | **一个都没有** | NE/N/NW/W 全是 `/MIPI_DSI_CLKP` 的同一条 track；S 是 `U1.B15` 自己的 pad |
| `U1.A21` | `/SARADC_IN2` | **一个都没有** | N/NE 是 `/MIPI_DSI_CLKP`；W 是 `U1.A20`(`/SARADC_IN0`)；SW 是 `via@(25.777,33.058)` |
| `U1.B21` | `/SARADC_IN3` | **SW** | E/N/W 是邻居球与它们的 track；SE 是 `via@(26.339,32.496)` |
| `U1.B19` | `/ACODEC_INN` | **SW、SE** | NW 是 `via@(24.653,33.058)`；N 是 `U1.A19`(`/ACODEC_INP`) |
| `U1.W22` | `/DDR_A11` | **一个都没有** | 八个方向全是 DDR 邻居球的 pad + 它们的 0.10 track（每个方向至少两条） |
| `U1.Y21` | `/DDR_A8` | **SW、S、SE** | N 是 `U1.W21`(`/GND`)；W 是 `U1.Y20`(`/DDR_A6`) |

**三个球八面全堵**（`A15`、`A21`、`W22`）。这不是"再挪几个 0.05 mm 台阶"的事：0.25 mm 球 +
0.10 mm 规则下，一条 track 要从球心出去，两侧各要 0.05+0.10 = 0.15，而 0.5 mm 球距只给
`0.5 − 0.25 = 0.25` 的缝 ⇒ 1:1 的球阵里**每个球只能从缝里斜穿**，只要隔壁那条缝已经被同族网占了，
这个球就出不来。

## 3. 出线长度与"过孔能放哪"

两个数都是本轮量出来的（`copper_geo.dist_item`，8 方向 × 0.02 mm 步进；过孔条件
= 孔体 0.10 半径 + 0.10 净空 ⇒ 距外来铜 ≥ 0.20，且钻孔离自己的球 ≥ 0.275（0.125 球半径 +
0.05 钻孔半径 + 0.10 钻孔到焊盘间距），网格 0.05 mm、半径 1.2 mm）：

| 球 | 八方向最大出线（mm） | 1.2 mm 内合法过孔位（个） | 最近的合法位 |
|---|---|---|---|
| `U1.B15` `/USB1_DP` | **0.82**（315°，即 SE） | **1** | `(22.9861, 33.627)`，距球心 **0.901** |
| `U1.A15` `/USB1_DN` | 0.54 | 43 | `(21.8861, 34.3891)`，**1.320** |
| `U1.A21` `/SARADC_IN2` | 0.54 | **0** | — |
| `U1.B21` `/SARADC_IN3` | 0.56 | 1 | `(25.2579, 33.077)`，**0.854** |
| `U1.B19` `/ACODEC_INN` | 0.70 | 1 | `(25.2840, 33.077)`，**0.461** |
| `U1.W22` `/DDR_A11` | 0.50 | 64 | `(26.8700, 23.473)`，**0.354** |
| `U1.Y21` `/DDR_A8` | **2.98**（270°，S） | 162 | `(25.8079, 22.5109)`，**0.292** |

两条必须一起读的口径：

1. **「有合法过孔位」不等于「能接过去」**。`U1.A15` 有 43 个合法过孔位，但它的八个扇区**全是堵的**
   （§2）⇒ 一个都够不着。表里"最近的合法位"距离是**直线距离**，不是可走的长度。
2. **`A15` 的 43 个合法位最近在 1.320 mm**，而它的最大出线只有 0.54 mm ⇒ 中间 0.78 mm 没有通道。
   这一条同时解释了为什么 `0.1.34` 删掉的那些过孔长在 0.40–0.57 mm 处：**它们是当时唯一放得下的位置，
   而放得下的位置刚好在球出不来之后**。

## 4. 结论（与 `docs/175` §4 第 3 条一致，但现在有数）

* 7 条网 × 2 焊盘 = 14 个端点，**零根铜**：问题在扇出，不在"接最后一根线"。
* 三个球八面全堵（`A15`/`A21`/`W22`），一个球连合法过孔位都没有（`A21`）⇒ **这 7 条不是手写坐标能补的**：
  要么改 BGA 球阵的扇出规则（更大间距/更细线/盘中孔——盘中孔用户明令禁止），要么动 U1 的位置/朝向
  （`docs/167` 量过：U1 转 270° 空气线只省 1.9%，而 43 条网落在错板边才是真账单）。
* 因此**本轮没有动板子**：在没有通道的地方硬画，就是把 `docs/168` 的"已验段"再变成一次
  "看起来连上了、DRC 掉下来、其实靠的是贴边走线"的假绿。
* 更正记录：`docs/168` §2 的可抄段**作废**（起点过孔已在 `0.1.34` 删除），`docs/168` §3.2 已就地加更正行。
