# 172 · 盘中孔的真数、几何判据与 52 个孔的搬迁

上一版把 `hole_in_pad` 报成 **8**，那是**弱判据造成的假绿**：旧判据只问「孔心在不在焊盘矩形里」，
孔心挪到焊盘边上一半、钻孔整个压在焊盘铜上的孔，一律漏判。用「**钻孔壁切进同网焊盘铜**」这条几何判据
重新盘点，同一块交付板 `examples/rk3506_som/rk3506_som.kicad_pcb` 上是 **61 个**（vias 606 / pads 682），
全是 SMD 焊盘里的通孔。这一版做三件事：把判据改成几何的、给判据配反向对照测试、把盘中孔里**能合法搬出去的 52 个搬出去**。

> 数字更正（0.1.36）：本节初版写 **62**，是把「钻孔壁**相切**焊盘铜」也算成命中。唯一差的那一个是 `U5.2`
> 的孔 `(40.650, 31.400)`，`hole_gap_mm == drill/2 == 0.05`。判据现在是 `gap < drill/2 - 1e-6`（严格小于），
> 相切不算，故真数为 **61**；两套独立实现各数一遍都是 61。`<=` 口径下的 62 作废。
剩下 10 个的结论在第五节，是负读数，不粉饰。

## 1. 判据：从「矩形探针」改成「孔壁 vs 焊盘铜多边形」

`src/pcb_agent_mcp/place_gate.py` 的 `hole_in_pad`（优先级 1，blocking）现在读一个数：

```
gap = 孔心到焊盘铜外轮廓多边形的距离        （在铜内则 0）
hit = gap < drill/2 - 1e-6
```

- 焊盘轮廓用 `adapters/canonical.pad_points()`，即矩形 / 圆形 / 椭圆 / 圆角矩形 / 自定义焊盘的真实多边形，
  不是包围盒。旧实现里的 `_rect_contains` 保留，但 docstring 写明它**不再是 `hole_in_pad` 的判据**，只作矩形探针用。
- 判据的物理含义：**钻孔（不是孔环）碰到同网焊盘铜**才算盘中孔。孔环压住焊盘铜是合法的 dogbone，
  因为焊盘本身就带 0.10 mm 的 `DRILL_PAD_GAP` 余量。
- 报告新增 `hole_gap_mm`，能读出「差多少」而不是只有一个布尔。
- verdict 文案一并改成描述工艺后果：`"%d via drill(s) stand inside a same-net pad - a process defect,
  not a clearance: the barrel wicks solder out of the joint"`。

`tests/test_place_gate_hole.py` 七条反向对照（全绿，0.3 s）：孔心在矩形外但钻孔切轮廓 ⇒ 1；孔心外且钻孔净空 ⇒ 0；
圆焊盘内孔 ⇒ 1；刚擦边 ⇒ 0；异网 ⇒ 0；THT 焊盘旁边的孔 ⇒ 0；规则必须是 priority 1 且 blocking。

## 2. 工具：`tools/off_pad_dogbone.py`

`tools/via_off_pad.py`（BFS stub）弃用，换成以**孔的实际接触面**为出发点的规划器：

- `contacts_of()` 找出端点在孔上的同网 track，带上「离开方向」`u`、长度、宽度、**接触端**与**远端**；
- 每个候选点位必须同时满足：`point_ok`（同网焊盘 0.10 gap / 异网铜 `r+CLR` / 孔到孔 `H2H` / 板边 0.50）、
  `stitch_ok`（旧位置→新位置的同层同网铜不穿异物）、`held ≥ 2`（孔必须真的服务两层以上）、
  以及**不把任何同网 track 端点落在孔外**（`pinned`：内层端点被孔环接住、搬走后必须被新孔铜覆盖、
  或被一条 45° pick-up stitch 接住、或沿自身轴线滑动）；
- 允许 **2 段 45° 狗腿**（`_dogleg_at`）：两条腿夹角 45° 或 90°（内角 135°/90° 合法），
  **135° 转永不生成**（内角 45° 是锐角）；
- 首选点位与已接受点位孔到孔冲突时，按 `alts` 顺序换备选；
- 只在「孔太胖进不了窄缝」时缩径，且**只缩孔体不缩钻**（`ANNULAR_MIN` 保证环宽）；
- `--apply` 每搬一个孔做一次连通性闸门：`GetUnconnectedCount(False)` 变大就整孔 revert。本轮 **52/52 零 revert**。

参数全部来自板子自己的规则，不是自造的更严规则：`OPD_CLR=0.11`（板 netclass clearance 是 0.10，留 0.01 浮点余量）、
`OPD_DPG=0.10`、`OPD_DMAX=3.0`、`OPD_HOPS`（狗腿第一腿长度表）、`OPD_EDGE=0.50`。

## 5. 负读数：用板子自己的 0.10 mm 规则重跑，只有 1 个能解

把 `OPD_CLR` 从 0.11 降到板规的 **0.10**、`OPD_DMAX` 放到 4.0、狗腿第一腿放到 6 档
（`0.25/0.35/0.45/0.60/0.80/1.00`）重跑这 10 个：**1 个成功（`FB1.1` → `(12.466,26.046)`，0.50 mm，lattice 方向），9 个仍然无解**。

机制是清楚的：**板子全部走 0.10 mm 间距、最小过孔 0.20/0.10**。一个 0.20 的孔要占
`0.20 + 2×0.10 = 0.40 mm` 宽，而这 9 个焊盘的正下方/正侧面挤着 0.10 mm 线宽的并行总线
（`/+0V9_LOGIC` 的 45° 斜线、`SPI1_MISO`/`SPI1_CSN0` 的两层平行线、`/SDMMC_CMD`、`/RMII0_*`…），
焊盘到最近异网铜的余量普遍只剩 0.07–0.25 mm。**这不是「再挪几个 0.05 台阶」能解决的**。

## 6. 这 9 个孔的合法出路只有两条

1. **VIPPO（树脂塞孔+盖帽）**——用户已明令禁止，不选用；
2. **改布局/布线**：把焊盘正下方那几条并行总线让出 0.40 mm 通道，或把对应的小器件/IC 移开≥0.5 mm，
   再让孔搬出去。属于布局层动作，不是 via 挪位；本仓库现有工具链（只滑端点、只加 45° 缝合）做不到，
   需要新增「按预算重排局部总线」的能力，且必须用 DRC + 未连接数双向验证。
