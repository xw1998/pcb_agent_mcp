# 61 · 电热的厚度方向：层间耦合、内部层没有空气、以及一次 8.5 K 的静默错答案

0.0.45 起 `board_electrothermal` 解的是**一块均质板**：你给 `k_w_mk`，它按这一个数在面内扩散。
真实板子不是均质的——热源在顶层铜上，底下 1.5 mm 层压板，再下面是地平面，热要走
**厚度方向**才能到另一面。0.0.47 用 `copper_pours` 补了"面内有铜"这一半，厚度方向仍是一块
均质板：顶层 4 W 和底层 4 W 在它眼里完全相同。

本版加 `layer_stack`（**默认关，关时体积与行为零变化**）：把板厚切成 N 层，每层一张面内场，
层与层之间**只有层压板的 `k_z` 传导**，对流与辐射**只发生在最上、最下两个表面层**——
内部那一层（一块内层平面）**看不到空气**。这正是这块板物理上最反直觉的一点：一块埋在
板里的平面，确实没有地方把热散到空气里，它只能把热往两边推。

> **一句话结论：层堆做出来了，闭式锚点 1e-6 一致，`k_z → ∞` 精确退化回单平面；同时必须
> 登记一处自己犯的错——第一版在 z 方向也用扫描，`k_z = 1e6`（层间短路，合法输入）时
> **第一次扫描就宣称收敛，返回的其实是初始猜测**，两层给出 26.2468 °C 而正确答案是
> 34.77 °C，8.5 K 的静默错答案。修法是 z 方向改成**逐列精确三对角解（Thomas）+ 整块松弛**。**

---

## 61.1 模型：层节点 + 中点法则

`layer_stack` 的形状：

```json
{"copper_layers": [{"z_mm": 0.0,  "thickness_um": 35},
                   {"z_mm": 1.6,  "thickness_um": 35, "zones": [...]}],
 "k_z_w_mk": 0.3}
```

- `z_mm`：**0 = 底面，`thickness_mm` = 顶面**。`copper_layers` 必须非空（要表达"无铜"就写
  `[{"z_mm": 0.0, "thickness_um": 0}]`）。
- 层节点 = `{0, th} ∪ {各 z_mm}` 去重排序。`nL` 个层，`nL − 1` 个间隙。
- `zones`（与 `copper_pours` 同形的矩形列表）= 该层的铜只铺在这几个矩形上，用
  `_rect_cover` 的**精确面积分数**，不是网格近似；不给就是整板整层。
- `k_z_w_mk` 缺省 = `k_w_mk`。

**中点法则**（这是"层堆能退化成单平面"的算术来源）：第 k 层的厚度是它到上下邻居的中点距离，
`Σ dz_k == th` **精确**；每层的面内片导

    S_k = k · dz_k(m) + k_cu · t_cu_k

于是 `Σ S_k = gp + k_cu·Σ t_cu`，**恰好等于**单平面把全部铜摊在一起的那个片导。所以
`k_z → ∞` 不是"大致接近"，而是**代数上恒等**。

层间只有层压板：

    gz_base[k] = k_z · ac / gap_k(m)

**只有 k = 0 与 k = nL−1 有对流/辐射**，每层一个面（`hc_face = h · ac`，不是单平面的两面）。
内部层的对角项里根本没有 `h`——它不跟空气说话。

过孔（`thermal_vias`）在分层模式是**跨每个间隙串联的均匀桶壁**：
`gz_via[k] += k_cu · annulus / gap_k`，并要求 `span_mm == thickness_mm`。它表达的是
"一根桶把相邻两层短起来"，**不是**"一条通往某个 sink 的路"——桶的两端本来就落在两个表面层上，
再加 sink 会把同一份热算两遍，所以分层模式下 `sink_c` 与 `barrel_profile` 直接拒答（`ARG_INVALID`）。

热源：`conductors` 在分层模式下**必须显式给 `z_mm`**（且必须是层节点之一）、`layers == 1`。
不给默认层，是因为"热源放错层"是一个看起来完全正常的错答案。
`uniform_power_w` 按 `dz_k/th` 的体积权重分摊到各层。

瞬态：每层 `C_k = rho·cp·ac·dz_k/dt`，合计 = `rho·cp·ac·thickness`（实测
`heat_capacity_j_per_k` = **44.1549 J/K**，与解析值逐位一致）。

**与 `copper_pours` 互斥**：同一块铜会被算两遍（一遍在面内、一遍挂到层上），所以两个都给
直接 `ARG_INVALID`。

## 61.2 z 方向：为什么不能扫描（本轮最值钱的教训）

第一版 `_sor_layers` 在 z 方向也用 Gauss-Seidel 扫，收敛判据是"单次扫描的最大改动 < `tol_k`"。
在面内问题上这是对的。在刚性耦合的 z 方向上是**错的**：

一次 z 扫描把一层拉到它的邻居温度，改动量是 `O(h·A / gz)` 量级；`k_z = 1e6`（合法的"层间短路"）
时 `gz` 极大，这个改动量**远小于 `tol_k`**，于是

> 第 1 次扫描 → `dmax = 0.0000x K < 1e-4` → **宣称收敛** → 返回初始猜测。

实测（100×80×1.6 mm、`cell 2 mm`、单条 3 A 走线、两层无铜、`k_z = 1e6`）：

| 量 | 修前 | 修后 | 单平面（正确答案） |
| --- | --- | --- | --- |
| `t_max_c` | **26.2468** | 34.771012（`tol 1e-4`）/ 34.771874（`tol 1e-6`）/ 34.771882（`tol 1e-8`） | **34.771887** |
| `sor_sweeps` | **1** | 90 / 142 / 197 | 95 |
| 静默误差 | −8.525 K | 1.3e-5 K | —— |

**这不是"精度差一点"，是一个平得像真答案的错数字**（26.25 °C 是一块完全均温的板，看上去
比 34.77 °C 那个有热点的场"更像"收敛结果）。与"宁可报错不给错答案"正面冲突，所以必须改结构，
不是调参数。

**修法**：面内保持 Gauss-Seidel SOR，**z 方向改成逐列精确解**。对每个 (i, j) 列，垂直方向是一个
三对角系统（层内是"到上下邻居的串联"，两端是 `hc_face`）：

    a_k · T_k − gz_{k−1} · T_{k−1} − gz_k · T_{k+1} = c_k

用 Thomas 前推 + 回代**精确**解它，然后整列作为**一块**做松弛（`omega = 1.0`；试过 1.85，
会崩成 0.001 °C 与负温）。于是"z 方向收敛"不再是判据的一部分——它每次都是精确的，收敛只由
面内问题决定，与 `k_z` 的大小无关。

第二件必须说清的事：`omega = 1.85` 在面内是加速，在"整列一块"上是**破坏性的**（块松弛的谱半径
不再是那个数），实测崩掉后直接降到 1.0。

## 61.3 两个门：把求解器自己的误差地板报出来，而不是静默放宽

分层的场比单平面更难解（刚度横跨几个数量级），所以两个健壮性门的阈值必须放宽一点点。
**放宽本身不是问题，"没有告诉调用者"才是问题**，所以两个门都带**自己算出来的允许量**，
并且只在分层路径启用（单平面的判定逐位不变，既有 196 例电热测试为证）。

**(1) 物理性门**（场低于环境 = 非物理）：

    slack = max(1e-6, 10·tol_k, 0.002 · (t_max − t_ambient))

最后那一项是本版新增的**相对**量：分层分辨的是"升幅"的相对精度，绝对 `tol_k` 在 1e12 这种刚度下
不够用。实测 `k_z = 1e12`：`t_min = 24.986143`（低于环境 0.0139 K = 升幅的 0.14 %），
靠 0.2 % 的相对 slack 过关——真正的非物理场差几个百分点到几度，能被分开。

**(2) 能量平衡门**：

    resid_allow = 0.005 · p_in               # 5 %，与单平面同一个口径
    floor_w     = tol_k · op_norm            # 求解器自己的噪声地板（仅分层）
    resid_allow = max(resid_allow, floor_w)  # 哪个大用哪个，并改 why 的文案

`op_norm` 是**算子对角质量**（每层每格的 `hc_face + Σ面内片导 + Σ上下层间导`，辐射在场的
就按当前场加 `h_rad`），不是矩阵范数——它是"场整体偏移 `tol_k` 会带来多少 W 的残差"的直接估计。
判据从"`|resid_pct| > 0.5`"改成"`|residual| > resid_allow`"，且

- 输出侧在 `energy_balance` 里**多报两个键**：`residual_allowance_w`、`residual_allowance`（一句
  人话解释这个数是怎么来的）；
- 被拒时 err 的 `extra` 里给 `residual_w` / `residual_allowance_w` / `residual_allowance`；
- **单平面不产生这两个键**（0.0.57 的输出逐位不变，实测无 `residual_allowance_w`）。

这条的取舍是明确的：分层的 `residual_pct` 会被求解器噪声主导（三层实测 0.75 %–2.11 %），
所以**百分比不是判据，W 才是**；而 W 的门必须>求解器自己的地板，否则它只是在测噪声。

## 61.4 算术锚点（不是自己对自己的回放）

**(a) 两层闭式。** 源均匀铺满顶面、`alpha_per_k = 0`（源强与温度无关）、每表面层一个对流面、
层间耦合 `G = k_z·A/th`，则

    u_top = q(hA + G) / (hA(hA + 2G))
    u_bot = q·G    / (hA(hA + 2G))

均匀源在面内无处可导，网格从式子里掉出去，于是数字是**精确**的（只受求解器容差影响）。
实测（cell 4 mm、50 A、`h = 10`）：

| 量 | 本工具 | 手算 |
| --- | --- | --- |
| 顶层 | 25.035534 | 25.035534 |
| 底层 | 25.033734 | 25.033734 |

1e-6 一致，500/500 cells，`residual` 3.2e-11。

**(b) 短路极限退化回单平面。** 见 61.2 的表：`k_z = 1e6` → 34.771874，单平面 34.771887。
这是整个模型的回归锚点——若层厚、片导或表面面积任何一处数错，这个极限会落到别处。

**(c) 单调性。** 两层无铜、源在顶面，`k_z` 从 0.3 → 5 → 1e6：

| `k_z` | `t_max_c` | 顶底升幅差 |
| --- | --- | --- |
| 0.3（层压板） | 35.467686 | 10.464 |
| 5 | 34.819157 | 9.815 |
| 1e6（短路） | 34.771874 | ~0 |

从上方逼近单平面，且**上层的热确实能到下层**（`rise_across_board_k` 随 `k_z` 单调减）。

**(d) 铜把热点摊平。** 上下各 35 µm：`t_max` 26.995254，底 26.582 / 顶 26.995，
`hot_level = 1`——铜的存在让整块板比无铜的 35.47 °C 低了 8.5 K。这是"面内片导加大"的
正确后果，不是 bug。

**(e) 三层：内部层最热、两表面对称。** 源在中层（z = 0.8），三层对称：

| `k_z` | 底 / 中 / 顶 | `residual_pct` | `allowance_w` |
| --- | --- | --- | --- |
| 0.05 | 27.068 / 27.445 / 27.068 | 2.11 % | 0.0115 |
| 0.3 | 27.188 / 27.257 / 27.188 | 1.14 % | 0.0125 |
| 5 | 27.217 / 27.221 / 27.217 | 0.75 % | 0.0313 |

两表面对称（对称性由几何保证，不是拟合），中层最热——内部层**没有**对流，只能把热往两边推。

**(f) 过孔跨层。** 117 个 `d = 0.3 mm` / 镀 25 µm 的通孔：`rise_across_board_k` 10.464 → 10.464
（几乎不变），`via_conductance_w_per_k` 0.6318、`through_vias_w` −0.0173、
`conductance_with_vias_w_per_k` 2.13175。过孔相对整板层压板耦合很小——**这是物理上正常的**
（1.6 mm 的板、铜桶只占极小面积），不是 bug；它说明的是"层压板本身比你以为的更会导热"。

## 61.7 边界（写进 `precision` / `assumptions` / `not_computed`，不是待办）

- **这不是 3-D 场解**：每层在**自己的 slab 内等温**（z 方向有限体积），面内是 2-D 场。层内的
  z 梯度、界面热阻、铜箔与层压板之间的接触热阻都不算。
- **层间只有层压板 `k_z`（+ 你列的过孔）**：没有介质各向异性（`k_x ≠ k_z` 必须你自己给两个数，
  而 `k_w_mk` 只有一个）、没有铜-树脂界面。
- **内部层没有对流也没有辐射**，这是模型的核心假设，不是简化——它对应的就是"一块埋在板里的平面"。
- **过孔仍是点载荷**：落在包含其圆心的那一格，`cell_mm` 会改变答案（报告里明说）。
- **只做传导 + 恒 `h`**：没有自然对流随姿态/高度变化、没有接触面、没有风扇流场。
- **DC**：没有趋肤、没有介质损耗、没有 AC 损耗（`gn` 那一路仍然不存在）。
