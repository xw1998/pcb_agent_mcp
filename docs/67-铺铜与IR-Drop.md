# 铺铜也是铜：把 zone 当成 2-D 薄片并进电阻网络

日期：2026-11-01　工具：`board_ir_drop(..., model_zones=True)`（`calc/zonefield.py` 新增，
`calc/power.py` 新增 CG 求解，纯 stdlib）

这篇解决的是一个**真机上必须先撞上才会承认**的问题：在一块大板上量 `+3V3` 的 IR drop，

```
board_ir_drop(net="+3V3", source="U71.14", sinks=["C93.2","C355.2"], current_a=2.0,
              plating_um=25)
→ error NOT_APPLICABLE: could not solve the copper network: singular: singular at 21
   (a node with no conductive path to ground?)
```

这不是 bug。`+3V3` 在这块板上有 315 段走线、149 个过孔、166 个焊盘、**7 块铺铜**，而那
7 块铺铜里有一块是 `In2.Cu` 上 **17832 mm² 的整层平面**。走线建图之后，网被这个平面
**分成两半**——两半之间唯一的连接就是平面本身。于是「只用走线」的模型给出的是
**两个互不相连的子图**，线性代数只能说它奇异。

0.0.63 的文档里把这件事写成一条限制：「铺铜在并联，所以这个 drop 是上界」。这条限制
在真机上直接变成「没有答案」。这一轮把它做成数。

---

## 1 判据

**把每块同网铺铜当成一层薄铜片：`R_sheet = rho(T) / t`［Ω/□］，栅格化成四连通电阻网，
与走线/过孔/焊盘同处一个节点空间，然后整网解一次。**

三条要判的事：

1. **铺铜的尺寸对不对** —— 用一个**能解析算出来**的几何锚死（§3，1.9 方块）；
2. **默认路径有没有被动过** —— 开关关掉时必须**逐字**还是 `singular at 21`（§5 负控制）；
3. **铺铜确实解开了「奇异」** —— 真机 `+3V3` 从一个错误变成一个数（§4）。

第 3 条单独说一句：**「算出来了」不等于「算对了」**。所以它排在第 1 条之后——先有解析
锚点，真机读数才有资格被引用。

---

## 2 模型

### 2.1 一个方块就是一个方块

```
R_sheet = rho(T) / t          [Ω per square]
```

栅格是四连通的，**格间电阻与栅距无关**：一格的边长是 `h`，长 `h` 宽 `h` 的一块铜就是
一个方块，`h` 取多少都是 1 个方块。这条性质是这个做法值得做的**唯一理由**——离散化不偏
置方块电阻，它只限制「电流在接触点附近能散多细」。

所以栅距不是精度旋钮，是**接触模型的分辨率**旋钮。§4 的真机读数验证了这一点：`h=0.5`
与 `h=2.0` 的答案差 1%（对数项），不是差一倍。

### 2.2 栅距按**填充面积**规划，不按 bbox

第一版按包围盒面积规划，在真机上直接翻车：`B.Cu` 上有 5 块 2×2 mm 的小铺铜散落在
112×79 mm 的范围里，bbox 面积规划给出 `h = 1.816 mm` —— **整层只落到 11 格**，每块小
铺铜两格，等于没建。

改成 shoelace **实际填充面积**（`_poly_area`）规划：`h = sqrt(area / max_cells)`，
钳位 `[0.2, 2.0] mm`。同一层立刻是 `h = 0.2 mm`、**1085 格**。

下限 0.2 mm 不是精度考虑：0.1 mm 对小铺铜只买墙钟，因为接触本来就是点（§2.3）。

填充本身用 `filled_polygons`（文件已经存了填充结果），没有才退回 `outline` 并计数
（`from_filled_polygons` / `from_outline_only` 都在 `zone_summary.sheets` 里）。

### 2.3 焊盘是**分布式接触**，不是点接触

一个焊盘接在平面上，电流是从整块焊盘进去的。只把焊盘锚点所在那一格连上去，会凭空造出
一段扩展电阻（点接触 = 一个针尖）。所以按焊盘尺寸（含旋转）算 AABB，落在焊盘内的**每一格**
各用一条 `LINK_OHM = 1e-6 Ω` 链到焊盘节点。

超过 2000 格的焊盘退回点接触，并单独计数 `wide_pads_left_point_linked` + 一条 warning
（这种时候接触扩展是被**高估**的，方向要说出来）。

合成锚点证明这条是对的：1×10 mm 的焊盘纵向铺满 10 mm 高的条带，接触是两列格，
有效长度 19 mm 而不是 20 mm ⇒ **1.9 方块 = 0.9359 mV**，实测 **0.935986 mV**，差 0.01%。
点接触会把它算成 2 方块（0.9851 mV，差 5%）。

### 2.4 桥接：一个方块，不是一根短路

节点不落在填充里、但离填充 ≤ `zone_link_mm`（默认 0.5 mm）时，连到最近一格，电阻取
**一个方块**。

- 物理上：这就是热焊盘辐条（或没填满的缝）的量级——一条长宽相当的辐条就是 1 个方块；
- 数值上：一开始用 1e-6 Ω 当桥，CG 迭代数被抬高 10 倍（见 §6）。

这条是**本条答案里最粗的一个数**，warning 里原话写着 `it is the single crudest number in
this answer`，并给出被桥接的节点数与最大跨距。

### 2.5 过孔按层拆分（只在开关打开时）

原来过孔只在 `layers[0] ↔ layers[-1]` 建两个节点。内层平面在**中间**，桶身物理上穿过它，
但图上没有那个节点 ⇒ 内层平面永远搭不上（实测只连到 `U71.15`，`In2.Cu` 平面孤立）。

`model_zones=True` 且过孔跨 >2 层时，每一层一个节点，桶身电阻按层数均分。这是层级开关的
一部分：关掉时过孔仍然只有两个端点，**历史答案逐位不变**。

## 3 解析锚点：1.9 方块

夹具（`tests/test_ir_drop_zones.py` 里的 `FULL`）：F.Cu/B.Cu 两层、35 µm、
`U1.1` 与 `U2.1` 是 **1×10 mm** 的 SMD 焊盘、相距 20 mm、**完全没有走线**，
一块 30×10 mm 的铺铜把两者连起来。

```
R_sheet = 1.724e-8 / 35e-6 = 4.92571e-4 Ω/□
```

| 口径 | 方块数 | 1 A 下的 drop | 与实测（0.935986 mV） |
|---|---|---|---|
| 手算，焊盘接触两列格（19 mm / 10 mm） | 1.9 | 0.935898 mV | **+0.01%** |
| 「长度 × 方块电阻」= 20 mm / 10 mm | 2.0 | 0.985142 mV | +5.3% |

- `model_zones=False` → `NOT_APPLICABLE: net 'VCC' has no tracks on this board`（默认路径不动）；
- `model_zones=True, zone_grid_mm=0.5` → **0.935986 mV**，1202 节点、1200 格、**52 次 CG
  迭代**、0.13–0.17 s。

而 2 方块那条是**上界**——它把焊盘当成一条横跨整个 10 mm 边缘的线接触。「长度×方块电阻」
这个估法在铺铜上的误差就在这里：它永远取上界那一侧。

## 4 真机：`+3V3`（jetson-agx-thor-baseboard.kicad_pcb）

src `U71.14`，sinks `["C93.2","C355.2"]`，`current_a=2.0`，`plating_um=25`：

| | 结果 |
|---|---|
| `model_zones=False` | `error NOT_APPLICABLE: … singular at 21`（与 0.0.63 **逐字相同**） |
| `model_zones=True` | **ok，13.4 s**，`max_drop_mv = 57.2440` |
| 节点 / 边 | 7052 / 11209 |
| 铺铜网格 | `F.Cu h=0.2 441格`、`B.Cu h=0.2 1085格`、`In2.Cu h=2.0 3425格` |
| 求解 | `ic0_preconditioned_cg`，**907 次迭代**，`residual_rel = 9.4e-10`，`tol = 1e-9` |
| 桥接 / 超宽焊盘 | 3 个节点跨 0.5 mm 桥接；0 个超宽焊盘 |
| 功耗 | `total_copper_loss_w = 0.112710`（2 A 下） |
| 并入 sink 读数 | `C93.2 = 57.2440`、`C355.2 = 55.4662` |
| 峰值电流密度 | 285.71 A/mm²（某段 `track`） |

两条 warning 都在（这是它该有的样子）：3 个节点是桥接的、25 个铺铜节点与源不连通被丢弃。

### 4.1 栅距收敛（探针实测）

同一块板、同一对 sink，只改栅距：

| `h` | 墙钟 | `max_drop_mv` | 节点 | 格数 | 迭代 |
|---|---|---|---|---|---|
| 2.0 mm | 3.5 s | 57.5795 | 5228 | 3442 | 269 |
| 1.0 mm | 15.8 s | 57.8807 | 15142 | 13392 | 458 |
| 0.5 mm | 108.2 s | 58.1658 | 55936 | 54171 | 878 |

增量 `Δ(2→1)=+0.301`、`Δ(1→0.5)=+0.285` —— **不是二次收敛**（2-D 扩展电阻带对数项），
外推极限 ≈ 58.45 mV。即 `h=2` 与极限差 ~1.5%，`h=1` 差 ~1%。

**这段读数的出处要说清楚**：这组是在「分布式焊盘接触 + 桥接一个方块」之前跑的**网格探针**，
当时只用来回答「栅距影响多大」。最终代码同条件读 57.2440 mV，比表里 `h=2` 的 57.5795 低
0.58%——方向正确（分布式接触比点接触少一段扩展电阻），量级也对得上 §1 说的「栅距是分辨率
旋钮」。表里三行没有被重跑，所以它们是**趋势证据**，不是最终代码的复现记录。

## 5 负控制（每条都能失败）

`tests/test_ir_drop_zones.py`，25 条：

| 若这项失败说明什么 | 判据 |
|---|---|
| 默认路径被悄悄改了 | `model_zones=False` 与签名默认都是 `False`；pour-only 网仍是 `NOT_APPLICABLE / no tracks` |
| 换了线性代数改动了历史答案 | 无铺铜时 `model_zones=True` 与 `False` **逐位相同**（单走线 19.702857 mV；跨层过孔 20.979986 mV） |
| 过孔被无条件拆层 | 2 层板上的贯通过孔**不拆**（同样逐位相同） |
| 铺铜尺寸算错 | 实测 0.935986 mV 落在 2 方块上界的 −5% 内，且与 1.9 方块差 <1% |
| 栅距被当成精度旋钮 | `h=1.0` 与 `h=0.5` 差 <2% |
| 铺铜没接上 sink 却给了个小 drop | 铺铜只盖住源那一侧 → `NOT_CONNECTED`，并点名 sink |
| 别人的铺铜被算进来 | zone 的 net 改成 `VCC2` → `NOT_APPLICABLE` |
| keepout 被当成铜 | 带 `(keepout …)` 的同网 zone → `NOT_APPLICABLE` |
| 预算被静默放过 | `max_zone_nodes=100` → `TOO_LARGE`（不是偷偷粗化） |
| 栅距 0 被静默钳到 0.2 | `zone_grid_mm=0` → `ARG_RANGE`；`"fine"` → `ARG_INVALID`；`zone_link_mm=-0.1` → `ARG_RANGE` |
| CG 与稠密解不一致 | 7×7 薄片 `max|dv| < 1e-9`；4 节点链逐位相等，IC(0) ≤4 次迭代 |
| 平行边被重复计入 | 两条 1 Ω 并联 = 0.5 Ω（不是 0.25） |
| 常量悄悄漂移 | `zonefield.LINK_OHM == oracle._ZF_LINK_OHM`；栅距窗口 0.2/2.0 两处一致 |

## 6 求解器：为什么必须是 CG，以及 IC(0) 是怎么来的

铺铜开起来以后未知数从几百升到 7052。`calc/power.py` 原来的 `resistive_network` 是**稠密
O(n³)** —— 这个规模根本跑不动。新增：

```
resistive_network_cg(nodes, edges, injections, ground, tol=1e-10, max_iter=20000)
```

地面节点消元 → SPD 系统 → **Jacobi / IC(0) 预条件共轭梯度**。返回形状与 `resistive_network`
兼容，并额外给 `iterations / residual_rel / converged / precond`。

- 7×7 电阻网：稠密 vs CG `max|dv| = 2.6e-12`，迭代 24 → **14**（IC(0)）；
- 4 节点链：逐位一致，IC(0) 下 **1 次迭代**；
- 真机 `+3V3`（7052 未知）：Jacobi **3113 迭代 / 39 s** → IC(0) **907 迭代 / 13.4 s**。

**一个真实的坑**：IC(0) 假设矩阵 pattern 里每对 `(i,j)` 只出现一次。而焊盘到铺铜是 40 条
平行边、合成板上同一对节点还会被多条边连——平行边在邻接表里被**重复计入**，后向代入就会
把同一格算两次，pattern 与矩阵不符。症状是「迭代 20000 次、残差卡在 0.09、跑 43 s」。
把邻接建好后**折叠成一条合成电导**（`1/Σ(1/R)`），同一块板 20000 → **52 次迭代**、
45 s → 0.17 s。

不收敛就直接 `NOT_CONVERGED` 报错，**不返回数字**——一个没收敛的解读数是噪声。

### 6.1 节点预算

`max_nodes`（默认 1200）守的是稠密解；`model_zones=True` 时放宽到
`max(max_nodes, 4096)`（CG 不是 O(n³)，而且过孔拆层会多出节点）。铺铜格另有
`max_zone_nodes`（默认 8000，墙钟换来的，不是精度换来的）。

## 7 本轮**没有**证明什么

1. **热焊盘辐条没有建模。** 焊盘落在填充里就按实心铜处理（1e-6 Ω）。真实连接常是辐条，
   那里这个 drop 是**下界**——这是本条答案唯一可能偏乐观的方向，写进了 `precision`。
2. **桥接是量级模型。** 跨 ≤0.5 mm 的缝按 1 个方块算，不是测出来的。
3. **zone priority / 最小宽度 / 与其他网的间隙都没有解。** 用的是文件里已经存好的填充结果，
   模型信任那份填充。所以「填充是过期的」这种情形（改完走线没有重新灌铜）会静默继承。
4. **孤岛被丢弃。** 从源点 BFS 不可达的铺铜节点直接删掉并报数——它们不带电流，但「被删了
   多少」必须看得见。
5. **超宽焊盘点接触。** >2000 格的焊盘只连锚点一格，接触扩展被高估，有 warning。
6. **DC 且只有 DC。** 没有 skin effect、没有平面自身的谐振（那是 `pdn_plane_impedance`）、
   没有频率相关铜。
7. **没有第三方实现可以对表。** 解析锚点只有 §3 那一条（1.9 方块）；真机读数没有第二个
   独立实现交叉验证过，所以它只有「自洽 + 与探针趋势一致」这一层证据。
8. **层数/XZ 方向。** 平面被当成同一层内的 2-D 薄片，层与层之间只有过孔与通孔焊盘的桶身
   相连；层间通过电介质电容的耦合不在 DC 模型里。

## 8 成本

| 场景 | 节点 | 格数 | 迭代 | 墙钟 |
|---|---|---|---|---|
| 合成锚点（1 层铺铜） | 1202 | 1200 | 52 | 0.13–0.17 s |
| 真机 `+3V3`（3 层铺铜） | 7052 | 4951 | 907 | 13.4 s |
| 真机 `h=0.5`（探针） | 55936 | 54171 | 878 | 108.2 s |
