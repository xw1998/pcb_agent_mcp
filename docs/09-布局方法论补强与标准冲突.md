# 布局方法论补强：两处标准冲突与可机判约束扩充

日期：2026-10-27
来源：Analog Devices《PCBs Layout Guidelines for RF & Mixed-Signal》《Successful PCB Grounding with Mixed-Signal Chips》、Henry W. Ott 混合信号分割地论述（Autodesk 转载）、IPC-2152 / IPC-2221 / IPC-7351 / IPC-6012 / IPC-A-600 / IPC-3406 标准体系。
前置：04 篇（布局表示与度量层）、08 篇（流程与映射）。

本文的作用不是"再列一堆经验"，而是把检索到的两处**方法论互斥**登记下来——因为它们决定了 AI 在这种场合最容易给出的错答案。

## 1. 争议一：地平面到底该不该分割

这不是细节，是**两派工程实践**，而且互相否定：

### 1.1 传统派：数模地分开，单点连接

教科书与多数国产资料的做法：数字地与模拟地分开铺，在一点（通常在 ADC 下方）用细颈或磁珠连起来。

### 1.2 Ott / ADI 派：分割地平面是误区

Henry Ott 的论断直接：**「混合信号 PCB 设计中最重要的误解之一，就是分割地平面的有效性」**。ADI 的对应文章标题更直白——**「Follow the Path of Least Impedance」**：接地应按**最小阻抗路径**处理，而不是按"数/模"这两个抽象标签处理。

其核心论据：

- 高频回流**永远走信号线正下方的参考平面**（最小回路电感），而不是"回到我那个符号上的地"；
- 一旦分割，跨越分割的信号被迫绕行 ⇒ **回路面积暴增 ⇒ 辐射与串扰**；
- 正确做法是**统一地平面 + 分区布局**（把模拟器件与数字器件物理分区），让回流自然各走各的路，而不是靠切断平面强制隔离。

### 1.3 我们的处置：**不裁决，要声明**

两派都有成立场景（高压隔离、精密测量确实可能要分）。**工具不许替用户选边。**

⇒ 设计必须显式声明 `ground_topology`：

```yaml
ground_topology:
  scheme: unified        # unified | split | split_with_bridge
  rationale: "..."       # 为什么
  stitch_points: [...]   # 分割时的桥接点
  crossing_signals: []   # 允许跨分割的信号（必须显式白名单）
```

对应 Oracle 查询 `ground_topology()` 返回：`{scheme, split_lines:[...], bridge_points:[...], signals_crossing_split:[...], loop_area_delta}`。

**AI 在这种场合的典型错误答案**：不声明方案，直接给出"模拟地和数字地要分开，单点连接"——如果这块板其实是 ADC 厂推荐统一地，这句话就是错的，而且 DRC 全绿。这正是 03 篇判据的又一次命中。

## 2. 争议二：载流计算用 IPC-2221 还是 IPC-2152

### 2.1 事实

- **IPC-2221** 的载流曲线源自 1955 年 NBS Report 4283，实验对象是**空气中悬浮的圆铜线**；而 PCB 上的扁平铜箔一面贴着导热极差的基材。这个先天缺陷让它长期被诟病。
- **IPC-2152**（《Standard for Determining Current Carrying Capacity in Printed Board Design》）是现行标准，基于更完整的实测数据，考虑了板厚、铜厚、内/外层、邻近导体、 airflow 等因素。
- 两者结论**差得很大**，而网上流传的"1 oz 铜厚、1 mm 线宽 ≈ 1 A（温升 10 ℃）"是第三种口径，与前两者都不同。

### 2.2 我们的实算对照（1 A / ΔT=10 ℃ / 1 oz 外层）

| 口径 | 结果 |
|---|---|
| IPC-2221 图表拟合（08 篇 §4.2 的公式） | **0.300 mm** |
| 网络流传"1A≈1mm" | 1.000 mm（**3.3 倍保守**） |
| 某技能实现（漏了 `^(1/0.725)`） | 0.139 mm（**低估 2.2 倍**） |
| IPC-2152 | **需标准数据表，不凭记忆给值** |

同一句话有三个数量级相近但不相容的答案 ⇒ **这正是「AI 瞎话」的高发区**，而且方向上有的偏保守（浪费空间）有的偏危险（烧线）。

### 2.3 处置：Calc 必须强制声明 standard

```python
width_for_current(..., standard="ipc2221")   # 可用
width_for_current(..., standard="ipc2152")   # 需加载数据表，否则 fail-closed 报错
width_for_current(...)                       # 不传 → 报错，不许默认
```

- `ipc2221` 用公式，返回 `model: "ipc2221_chart_fit"`, `precision: "±20%"`；
- `ipc2152` **必须从数据表插值**，表未加载则返回 `status: error`，理由写明「标准数据未加载」；
- 任何结果都必须带 `basis`（标准号+条款/图表号）。

⇒ 这条把 08 篇 §6.2 的「不返回 basis 一律无效」具体化为**可执行的 fail-closed 分支**。

## 3. 新增的可机判约束（补 04 篇）

| # | 约束 | 判据 | 来源 |
|---|---|---|---|
| 1 | **20H 规则** | 电源平面边缘相对地平面内缩 ≥ 20×层间距 | 通用 EMC 实践 |
| 2 | **跨分割缝合** | 必须跨分割的信号，在跨接点附近加缝合电容（典型 0.1 µF） | ADI / 通用 |
| 3 | **换层回流过孔** | 信号换层处，两侧加接地过孔 | ADI / 射频技能 |
| 4 | **层叠顺序** | 相邻信号层走线方向正交；4 层推荐 SIG/GND/PWR/SIG | 通用 |
| 5 | **去耦距离** | 同层、距引脚 < 3 mm（`kicad-free`）或 < 5 mm（网络资料）——**冲突，配置化** | 两源冲突 |
| 6 | **差分阻抗** | 通用 100 Ω、USB 90 Ω、公差 ±10 % | 通用 |
| 7 | **等长** | DDR ±5 mil；USB 差分对内 ±1 mil | 通用 |
| 8 | **板厚孔径比** | ≤ 8:1（1.6 mm 板 ⇒ 机械钻 ≥ 0.2 mm） | 板厂能力 |
| 9 | **焊盘到外形** | ≥ 8 mil；V-cut 处 ≥ 20 mil | 板厂能力 |
| 10 | **热过孔阵列** | 发热器件下方 φ0.3 mm / 间距 ≈1 mm | 通用 |
| 11 | **地平面完整性** | 无 slot、无长条沟槽；`ground_topology` 已声明 | §1 |
| 12 | **参考平面连续** | 关键信号下方参考平面连续（`cross_split()` 覆盖） | ADI |

### 3.1 冲突登记（不许静默取一个）

| 项 | 冲突 | 处置 |
|---|---|---|
| 载流标准 | IPC-2221 / IPC-2152 / 网传口径 | 强制 `standard` 参数 |
| 去耦距离 | 3 mm / 5 mm | 项目级配置项，默认取严（3 mm）并显示来源 |
| 地平面 | 分割 / 统一 | 强制 `ground_topology.scheme` 声明 |
| 爬电依据 | IEC 60664-1 / 62368-1 / 仪器类 | 强制 `safety_standard` 声明（08 §5.2） |

**这四项的共同点：都有"正确答案"，但正确答案取决于项目前提，而前提不在文件里。** 所以必须问、必须记、必须随设计一起落盘。

## 4. 标准体系速查（哪条管什么）

| 标准 | 管什么 | 我们用在哪 |
|---|---|---|
| IPC-2221 | PCB 设计通用要求（层叠/间距/布线基础） | 载流（legacy）、间距基线 |
| **IPC-2152** | 载流能力 | `current_capacity` 的现行依据 |
| IPC-7351 | 表面贴装焊盘图形（Land Pattern） | S2.5 封装核对 |
| IPC-6012 | 刚性板制造与验收（孔铜厚/阻抗） | DFM 能力表 |
| IPC-A-600 | 外观验收 | DFM |
| IPC-3406 | 高频材料选用 | 叠层/材料 |
| IPC-356 | 网表（Netlist） | Gerber 交付包 |
| IEC 60664-1 / 62368-1 | 绝缘配合（爬电/间隙） | `creepage_required` |

## 5. 对 04 篇约束清单的修订

04 篇原列 10 类可机判布局约束（group/flow、symmetry、pattern、thermal、proximity、parasitic、isolation/guard、ground 拓扑、orientation/fixed、side/shield）。

本文补充/修订：

- **`ground 拓扑` 从"一类"升为"一个必须声明的方案 + 一组可查询几何"**（§1）；
- **新增 `plane_rule` 类**：20H、缝合电容、换层过孔、层叠正交（#1~#4）；
- **`proximity` 类加去耦距离的冲突值与来源**（#5）；
- **`parasitic` 类加板厚孔径比、焊盘到外形**（#8、#9，属 DFM 而非电学，但同属"几何硬限"）；
- 所有约束条目必须带 `source`（标准号 / 厂商 app note / 项目约定），否则不可进 `layout_report`。

## 6. 补充检索：布局顺序、分区、叠层与分割决策树

第二轮检索（Ott 转载文、RF Cafe 隔离方法论、国内工程整理）补齐了几处更细的东西。

### 6.1 放置顺序被明确成五段（比"先放重要信号"更细）

```
① 固定件：连接器、开关、LED、指示灯、散热器、屏蔽罩、需要特定结构位置的器件
② 核心 IC：MCU / FPGA / 电源 IC / 高速器件 —— 通常置于板中央或其功能模块中心
③ 高频与敏感件：时钟、高速收发、模拟前端 —— 最短路径、远离干扰源
④ 支撑件：围绕核心件按逻辑顺序放外围（电阻、电容、晶振、电平转换）
          —— 优先放去耦/旁路电容（尽量贴电源引脚）
⑤ 其余低速、非关键件
```

与 08 篇 §4.2 的三层（硬约束 → 重要性 → 填充）一致，但把"硬约束"和"核心器件"分开了：**核心 IC 的位置由板级架构决定，不由信号类别决定。**

### 6.2 分区的第一原则是「按信号流向线性布局」

- 信号流向：输入 → 处理 → 输出，**不许回折**；
- 电源流向：入口 → 转换/稳压 → 分配；
- 热源分布：发热件集中成区，与热敏件分开。

⇒ 这是可机判的：`flow_order()` 可以检查每个 module 的 x 坐标是否随信号流向单调。

### 6.3 四层板的推荐叠层与器件分布

```
L1  信号 / 模拟       ← 模拟器件放这层，紧邻 L2
L2  完整地平面         ← 回流参考层
L3  电源平面
L4  数字信号          ← 数字器件放这层，以 L3（去耦后）为参考
```

**关键机制**：模拟信号的回流参考是 L2 的完整地；数字信号的回流参考是 L3 的电源平面（因为紧邻）。所以**"模拟器件放 L1、数字器件放 L4"不是风格，是回流路径的物理选择**。

⇒ 这一条把 04 篇的「回流路径场」变成了可判的：信号层的**相邻层是什么**，决定了它的回流面。

### 6.4 分割地的决策清单（从"该不该分"变成"什么条件下才分"）

只有三种情形可以考虑局部分割：

1. **单面板 / 双面板**——根本没有完整地平面可用，分割是无奈之举；
2. **大功率开关电源与微弱信号共存**（如电机驱动旁的 mV 级传感器）——在功率区与信号区之间设"桥梁"单点连接；
3. **射频前端与数字基带**——RF 模块通常要求**局部净空区（keep-out）**，而不是把地平面切开。

若决定分割，**必须**：

- 跨分割的信号线在跨接点附近加**桥接电容**（1 nF ~ 100 nF，不同资料给的典型值不同），提供高频回流捷径；
- 桥接点靠近信号跨域处（不是随便找一处连）。

### 6.5 一条很具体、很容易漏的可机判规则

> **ADC 的 AGND / DGND 引脚应在芯片下方或就近单点连接，且该连接点必须低阻抗（短而宽的走线或过孔直连地平面），而不是通过长走线绕到某处汇接。**

这条把"单点连接"从一句话变成了三个可测条件：**位置（芯片下方/就近）、连接方式（过孔直连）、阻抗（短而宽）**。

### 6.6 新增冲突登记（并入 §3.1）

| 项 | 冲突值 | 处置 |
|---|---|---|
| 器件间距（SMT 可制造性） | ≥0.2 mm（国内资料） vs >0.5 mm（射频技能） | 按工艺（回流/波峰）+ 器件类型分档，不取单值 |
| 等长容差 | ±5 mil（DDR 类） vs ±50 mil（泛化说法） | 按接口与速率定，**必须由项目声明** |
| 去耦距离 | <3 mm vs <5 mm | 项目配置，默认取严 |
| 桥接电容值 | 0.1 µF vs 1 nF~100 nF | 给区间 + 说明按噪声频段选 |
| 电源层分割间距 | 20 mil（不同电压域隔离） vs 20H（边缘内缩） | **两者不是同一件事**，分别建约束 |

### 6.7 其他可机判条目

- 电源分配优先**星型拓扑**（从电源芯片输出点分支），避免菊花链级联；
- **时钟线：包地、远离其他走线、禁止打过孔**（"禁止过孔"是硬约束，不是建议）；
- 板边每隔 **λ/20** 打屏蔽地过孔；
- 波峰焊器件方向平行于板边；
- 极性元件方向一致（电解电容、二极管）；
- 20H 规则：电源平面边缘相对地平面内缩 ≥ 20×层间距；
- 电源层不同电压域之间用 20 mil 间距隔离。
