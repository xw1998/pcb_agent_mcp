## 3 怎么把这 233 行从 PDF 里挖出来（方法，可复用）

1. **分组靠合并单元格，不靠 y 聚类**。`page.find_tables().tables[0].rows[i].cells[0]`
   里合并首列给出的就是材料名；按 y 聚类会在跨页处滞后一行（本轮实测过一次）。
2. **数值靠词级坐标，且列 x 从每页表头现场取**（含 `Perm` 且六个列名齐的那一行），
   最近列归属，`|best_x − x| > 40` 丢弃 —— 这样一页列序不同也不会把系数挪位。
3. **印刷稳定性表必须按字形原点重建**。`find_tables().extract()` 给出的是
   `'29%\n.'`（其实是 `2.9%`）这种小数点脱位的串；改用 `get_text("rawdict")` 的
   `chars` 取 `(origin_y, origin_x, c)`，落在单元格 bbox 内按
   `(round(y/1.5), x)` 排序拼串，才得到干净的 `'0.6%'` / `'+2.5%'` / `'20 MHz'`。
   判据：重建后 60µ 那九行必须与温度拟合的动态范围对上（≤ 0.05 pp），实测全对。
4. **变体页用七连 token 头扫描**：`['Perm','a','b','c','d','e','x']`，之后每 7 个
   token 一组。因为 High DC Bias Edge 那一页的 `DC Magnetization` 标题印在页面**最末尾**，
   系数表在标题**上方**，按「标题之后取表」会一行都取不到。
5. 一组数字的元数（7 列还是 5 列）不对**整页中止**，不猜列。
6. 抽样渲染复核：磁化表前四行 200 dpi 裁图逐位复现（14µ `3.918E-02 / 1.856E-02 /
   4.812E-04 / 1.390E-01 / 4.478E-04 / 1.875`），MPP 温度页六行重复行二次确认。

## 4 三条独立校验（全部先量、后写、且写进数据文件）

### 4.1 磁化拟合 ≡ DC 偏置拟合的积分

`B[T] = 1e-4 · ∫ µr,diff dH`，其中 `µr,diff = perm · %µ/100`，中点法 20000 步。
两条式子来自**不同页**（磁化 128–132，DC 偏置 63–65），拟合方法也不同，所以这是一条
真正独立的路径。

| H (Oe) | 全 125 行 中位 / p90 / max | 仅 61 个环型 中位 / p90 / max |
|---|---|---|
| 25 | 2.70 % / 8.32 % / 21.51 % | 1.54 % / 8.03 % / 19.23 % |
| 50 | 0.76 % / 3.95 % / 30.50 % | 0.79 % / 3.62 % / 30.50 % |
| 100 | 0.48 % / 2.21 % / 54.34 % | 0.49 % / 3.01 % / 54.34 % |
| 200 | 0.58 % / 4.95 % / 73.86 % | 1.05 % / 6.93 % / 73.86 % |

100 Oe 处 **>10 % 的只有三行**，且都落在磁导率标尺两端（厂商分段拟合的地方）：

| 行 | 磁化拟合 | 积分 | 差 |
|---|---|---|---|
| MPP Toroids 550µ | 0.2341 T | 0.5128 T | 54.3 % |
| Kool Mµ EQ&LP 75µ | 0.5101 T | 0.4394 T | 16.1 % |
| MPP Toroids 300µ | 0.996 T | 0.869 T | 14.6 % |

`fits_disagree` 的阈值就取 **10 %**：全表中位 0.5 %、最差 54 %，10 % 正好把两个
种群分开。它是**报告阈值**，不是「谁对」的裁决。

### 4.2 温度拟合的动态范围 ≡ 印刷 p.15 的那一列（60µ，九材料全对）

| 材料 | 拟合 Δµ(−50 °C) | 拟合 Δµ(+100 °C) | 拟合跨度 | 印刷 | 差 |
|---|---|---|---|---|---|
| Kool Mµ | −4.378 % | −1.433 % | 2.945 % | 2.90 % | **0.045 pp**（最差） |
| High Flux | −1.300 | +1.341 | 2.641 | 2.60 | 0.041 |
| XFlux Ultra | +0.074 | +0.734 | 0.660 | 0.70 | 0.040 |
| Edge | −0.565 | +0.675 | 1.240 | 1.20 | 0.040 |
| MPP | −0.411 | +0.622 | 1.032 | 1.00 | 0.032 |
| Kool Mµ Ultra | −2.686 | −2.262 | 0.424 | 0.40 | 0.024 |
| Kool Mµ Hƒ | −3.600 | −1.119 | 2.481 | 2.50 | 0.019 |
| XFlux | −2.165 | +0.817 | 2.981 | 3.00 | 0.019 |
| Kool Mµ MAX | −2.283 | −0.995 | 1.288 | 1.30 | 0.012 |

### 4.3 印刷例 3 单点

60µ Kool Mµ：`B(95 Oe) = 0.44126 T`（印 0.441，差 0.06 %）、
`B(15.8 Oe) = 0.09149 T`（印 0.092，差 0.6 %）。

### 4.4 被否决的方法（勿再试）

用 `µr = x·a^(x−1)·(b − a·d)/(µ0·79.5771)` 反推小信号磁导率，61 个环型上**中位误差
36.9 %** —— 因为 `B(0) = a^x ≠ 0`（60µ Kool Mµ 是 5.3 mT）。这条否决直接变成了
工具的一条拒绝分支：`H = 0` 或 `H < 0` 报 `ARG_INVALID`，并把 `B(0)` 的值一起给出，
同时在提示里指明要零偏置答案请用 `magnetics_dc_bias`。

## 6 印刷异常：登记，不改（5 条，全部 `kept_as_printed`）

1. MPP 温度 147/160/173µ 三行系数完全相同（`−2.308E-03 / 8.497E-05 / 2.943E-07 / 0 / 0`），
   200 dpi 渲染裁图 + 视觉复核二次确认，页上就是这样。
2. MPP 温度 200/300µ 两行相同（`−2.528E-03 / 9.211E-05 / 3.601E-07`）。
3. Edge 温度 90µ 的 `d = −2.000E-21`、`e = 1.000E-23`：在 −60…200 °C 上这两项最大
   1e-14 量级，是凑数位而不是成形项，**保留原样不清零**。
4. Edge 磁化 Toroids 40–125µ 五行退化成近线性（`a ≈ 1.000E-03`、`d ≈ 1.000E-03`、
   `x 0.833–1.021`），与全表其余行（`a 0.0123–0.1285`、`x 1.25–2.20`）形态不同；
   B(H) 仍正、有限，所以可用，但**不能当邻居行读**。
5. MPP 磁化 Toroids 550µ：`c = 1.118E-10`，是唯一峰值落在印刷 H 带内的行（23.8 Oe），
   且与同料号 DC 偏置拟合积分在 100 Oe 差 54.3 %。**两个数都是厂商印的，两个都报，一个都不选。**

## 7 印刷范围：读出来的是「图覆盖到哪」，不是「厂商承诺到哪」

- 磁化图 H 轴刻度：`1, 2, 3, 5, 7, 10, 20, 30, 50, 70, 100, 200, 300` Oe；B 轴 `0.0…0.8 T`。
  部分面板只画到 100 Oe，且页面**没有**印数值有效范围 ⇒ 这是「曲线覆盖的带」，
  超出就答但打 `inside_plotted_band = false`。
- 温度图 T 轴刻度：`−60, −40, …, 180, 200 °C`。**这一条只采信文本层**：把图渲成
  PNG 让视觉模型读，得到的是 −55…125，与文本层冲突；轴范围属于量测，不能来自
  「看图」。曲线路径本身是矢量、未做反读，已登记 `graphs_not_read_off_pixels`。
- 温度求值范围取 `[−50, 200] °C`：−50 是 p.15 印刷动态范围的下界（可查），200 是那列
  表头 `MATERIALS RATED TO 200 °C` 的评级。**不把 −60 当拒绝下界** —— 它是图的轴，
  属于「图画到哪」而不是「厂商承诺到哪」。100…200 °C 之间答、但打
  `inside_printed_dynamic_range = false`。

## 8 不携带的（5 条，逐条给理由，不是欠账）

1. **Bsat 没有温度曲线**：p.10 每个材料只印一个 Bsat，温度页印的是 µ 不是 Bsat。
2. **粉末芯没有 Steinmetz 系数**，也没有损耗曲线的 DC 偏置修正。
3. **没有单料号标称重量**：p.16 原句是 `See individual data sheets`，指回单料号数据表。
4. **µ-vs-B / µ-vs-f 两列是范围值不是曲线**。
5. High DC Bias 页后面那两张 `Perm/a/b/c` 表（XFlux `443.53 / 2.015 / 1.312`、
   Edge `83.23 / 2.106 / 1.520`）是**另一种拟合式而页面没印公式** ⇒ 不猜，登记不携带。

## 9 工具与拒绝分支

`magnetics_powder_curve(material, permeability, h_oe | turns+dc_current_a+le_mm,
temperature_c, shape_family, include_evidence)`

| 情形 | 结果 |
|---|---|
| `H ≤ 0` | `ARG_INVALID`，并给出 `b_at_zero_h_t`（本行 0.00529 T）与「这不是小信号模型」 |
| 没有 `h_oe` 也没有 `temperature_c` | `ARG_INVALID`（「这是两条不同的式子」） |
| 同时给 `h_oe` 与匝数三件 | `ARG_INVALID`（两条路只许走一条） |
| 匝数三件缺一件 | `ARG_INVALID`，点名缺哪个 |
| 材料印在多个形状下且没给 `shape_family` | `ARG_INVALID`，列出四个形状 |
| 未印的磁导率 / 形状 / 材料 | `NOT_FOUND` + 印刷清单 |
| 变体材料给了 `shape_family` | `ARG_INVALID`（变体块不印形状） |
| 温度越出 `[−50, 200]` | `OUT_OF_VALIDITY`，说明四次多项式外推没有测量背书 |
| 该材料没有温度拟合 | `NOT_FOUND` + 九材料清单 |
| 表缺失 / schema 不对 / 列错位 | `DATA_UNAVAILABLE`（整表拒绝，不照算） |

变体材料（`High DC Bias XFlux` / `High DC Bias Edge`）**不做**与标准牌号的 DC 偏置
交叉校验：那是**另一条曲线**，比了等于把两条曲线当成一条。答案里 `cross_check_note`
把这句话写出来，而不是把字段静默省掉。

`include_evidence = true` 时额外返回 `cross_check`（上面 4.1/4.2/4.3/4.4 全部数字）、
`printing_anomalies`（5 条）、`not_carried`（5 条），让「这个数凭什么信」在软件里
可以就地被问出来，而不是只能翻文档。

## 10 负控制

- **表结构**：把某行 `a` 改成 `−1e9`（分子在某 H 变负）、把温度 `a` 改成正、把某个
  系数改成 `"n/a"`、把 `schema` 改掉 —— 四种篡改各写一份到 `_scratch/`，**全部**
  被 `DATA_UNAVAILABLE` 拒掉（`tests/test_powder_curve.py` 的
  `TestTheLoaderRefusesAShiftedColumn`）。
- **转捩旗标不是装饰**：断言 `B(100) < B(23.8)` 且 `B(200) < B(100)`，即那条支路
  **确实在下降**；再断言在 10 Oe 处 `past_fit_turnover = false` 且 `mu_r_differential`
  有值，证明旗标来自这个 H 而不是行本身。
- **不一致清单来自实测**：遍历**全部** 125 行在 100 Oe 上求 `fits_disagree`，结果集
  必须与数据文件里存的那三条**完全相同**（不是子集、不多不少）。
- **温度跨度来自文件而非答案**：九材料动态范围在测试里用系数独立重算，与 p.15 比，
  最差 0.045 pp；把任意一行的系数改动都会让这条测试红。

## 11 与既有答案的关系

- `select_core` / `magnetics_dc_bias` / `magnetics_material_core_loss` / `magnetics_toroid_mlt`

- `calc_capabilities` 只动两处：`available` 加 `magnetics_powder_curve`，

  并把残留逐条点名（Bsat 无温度曲线、两式端点不一致且都报、七行转捩、`H = 0` 拒绝、
  变体无温度拟合）。
- 工具数棘轮 177 → 178；`available` 171 → 172。
- `--selftest` 288 → **295** 项；`tests/test_powder_curve.py` 新增 37 例。
- 全量回归 `Ran 3248 tests in 1236.909s` / `OK (skipped=5)`（0.0.79 是 3211 例 / 1401.993 s，`3211 + 37`）。
