# DC 偏置接进 `select_core`：匝数 → H → µ → 电感 这个回路，以及为什么它是区间搜索而不是不动点

日期：2026-11-01　工具：`magnetics_select_core`（加 3 个参数，**工具数仍是 176**）

`79` 篇末尾的 `not_implemented_yet` 里点着名的那一条，原话是：

> DC 偏置能算 `% µi` 跌落，但**没接进 `select_core`**：这里给的匝数仍是零偏置的
> 匝数，偏置下的匝数是一个 **0.0.77 不求解**的不动点。

这一篇把那个不动点做掉。做完之后同一个问题换一个答案，而不是加一段说明：

```
100 µH / 峰值 10 A / 60 µ 磁导率的粉末环，DC 偏置 8 A
  0.0.77（零偏置匝数）  0077141A7  Kool Mµ  54 匝   235.3 µH
  0.0.78（偏置下求解）  0074121A7  XFlux Ultra 82 匝  100.26 µH
                        H = 200.09 Oe，µ 剩 42.60 %，B = 0.6368 T（限 1.28 T）
```

零偏置的 54 匝在 8 A 下只剩 **约 42 %** 的电感（不是 100 µH，是 100.26 µH 的
42 %），也就是说 0.0.77 的答案在这个工作点上是**偏差 2.3 倍**的一个数，而且它
自己不会报警 —— 因为 0.0.77 根本没被问过偏置。

## 2 回路与三个式子

```
H(N)  = 0.4·π·N·I_dc / le[cm]            （目录的关系，le 由 mm 折成 cm）
µ(N)  = 1 / (a + b·H^c)                   （% of µi，厂商印的式子，第 79 篇）
L(N)  = AL₀ · N² · µ(N)/100               （AL₀ 是印刷 AL，单位 nH）
B(N)  = L(N) · I_pk / (N · Ae)            （峰值磁密，Ae 由 mm² 折成 m²）
```

三个式子里的常数不用猜：`(a, b, c)` 来自 `data/dc_bias_fit.json` 里**这一颗芯
材料 × 形状族 × 磁导率**的那一行；`AL₀`、`Ae`、`le` 来自粉末芯表（第 76 篇入库）。
答案里每次把 `fit`（含 `a`/`b`/`c`/`printed_page`/`printed_formula`）原样带出来，
所以读数可以手工复算，不需要相信这个实现。

---

## 3 `L(N)` 不单调：不是数值细节，是物理结论

把 `L(N)` 写成 `N² / (a + b·(k·N)^c)`（`k = 0.4π·I_dc/le_cm`，每匝的 Oe），
对 `N` 求导并令其为零：

```
dL/dN = 0  ⇔  N^c = 2a / ((c − 2)·b·k^c)
```

这个驻点**只当 `c > 2` 时存在**（分母符号）。`c > 2` 时它是**极大值**：
越过它以后 `µ` 的跌落快过 `N²` 的上涨，**更多匝数换来更少电感**。

实测：`data/dc_bias_fit.json` 的 **125 行里有 86 行 `c > 2`**（`c ≤ 2` 的 39 行
是单调的）。这不是边角情形，是**多数情形**。

同一个零件上直接读出来（XFlux Ultra 60µ，`c = 2.815`，8 A，`le = 41.2 mm`）：

| 匝数 | H (Oe) | µ (% µi) | L (µH) |
|---|---|---|---|
| 82 | 200.09 | 42.6005 | **100.256** ← 达到要求的 100 µH |
| 1000（上限） | 2440.07 | 0.064955 | 22.73 |

1000 匝只有 82 匝的 **22.7 %** 电感。所以"多绕几圈总能到"这句话在这个基质上
是错的，而**不动点迭代恰好会踩在这个错上**：从 54 匝出发迭代，`L(54) ≈ 42 µH
< 100 µH` ⇒ 加匝；加过峰值以后 `L` 掉下来 ⇒ 再加匝 ⇒ 停在 1000 匝上限，或者在
两个值之间来回。两种都是错的，而且**看上去像一个答案**。

这一条也写进了答案里：顶层的 `dc_bias.found_by` 明说这是区间搜索、并把
`N^c = 2a/((c−2)·b·k^c)` 和 **86 of the 125** 一起印出来；`unreachable` 的
`why` 会区分 `c > 2`（"过去 N 匝以后跌落快过 N²"）与 `c ≤ 2`（"一路涨到上限"）
两种原因 —— 因为这两种"达不到"的**补救方向不同**。

---

## 4 搜索算法（三步，都不迭代到不动点）

```
1) 定位 L 峰的匝数 n_peak
     c > 2  : n_peak = min(cap, max(1, floor((2a/((c−2)·b·k^c))^(1/c))))
     c <= 2 : n_peak = cap
   若 L(n_peak) < L_required  ⇒ 这个零件做不到，带 diag 返回（见 §7）
2) 在 [1, n_peak] 上二分找**第一个**达到 L 的匝数
   区间单调（峰左侧恒升），所以二分是对的；得到 n_lo
3) 从 n_lo 往上走，直到峰值磁密落进限值
   一旦某个 n 的 L 又掉到 L 以下就停（峰右侧没有可找的东西了）
```

`cap = dc_bias_turns_max`，默认 **1000**，是参数不是硬编码（自检里用
`dc_bias_turns_max=6` 做负控制：把上限压到 6 匝，必须报做不到而不是给一个
超过上限的匝数）。

第 3 步为什么往**上**走：同样 L 下匝数越多、`B = L·Ipk/(N·Ae)` 越小。所以
"电感够但磁密超"的修法只能是加匝（在峰左侧），而峰存在时这个修法有终点。

---

## 5 通量口径：用偏置后的 L

`B = L_biased · I_pk / (N · Ae)`，不是 `L_unbiased`。理由是这件事的物理本身：
偏置把 `µ` 压下去，**同样的电流在偏置后的芯里储更少的磁通**，所以偏置后峰值磁密
**更小**。用零偏置的 L 算会偏大约 `1/µ%`（本轮样例里 2.3 倍），于是报出不存在
的饱和。

每条候选的 `dc_bias.flux_basis` 把这句话原样写出来，同时
`dc_bias.inductance_without_bias_h` 与 `turns_without_bias` 一起给出，方便对照
"零偏置会怎么答"。

---

## 6 AL 余量口径：对偏置后的 AL 比

`select_core` 原本用一种"AL 够不够"的比值判定要不要开气隙，对粉末芯来说气隙是
分布式的、没有可切的东西。偏置之后必须换成**偏置后的 AL**：

```
AL_at_bias = AL₀ · µ(N)/100            （本轮样例：35 nH × 42.6005 % = 14.91018 nH）
al_ratio   = AL_required / AL_at_bias  （本例 14.8721 / 14.91018 = 0.997446）
```

如果仍对印刷 AL（35 nH）比，比值会变成 0.42 —— 一个**不存在的 58 % 缺口**，
还会把 `gap_required` 触发成"要切气隙"，而粉末芯没有可切的气隙。所以偏置路径下：

- `al_at_bias_nh` 与 `al_ratio` 都按偏置后算；
- `gap_required` 置 `None`，并在 `gap_because` 里说明判在哪里（`14.91018 nH =
  印刷 35.0 nH × 42.600515 %`）、以及为什么没有气隙可切。

## 7 门槛与"做不到"的三种形态

偏置路径下每颗芯落在四类之一，每一类都有自己的名字与解释：

| 形态 | 字段 | 含义 |
|---|---|---|
| 可行 | `verdict = "feasible"`，`dc_bias` 是设计 | 满足 L 与磁密两个约束 |
| 达不到 L | `verdict = "dc_bias_unreachable"` | `dc_bias` 是诊断：`turns_max_scanned` / `maximum_inductance_h` / `turns_at_maximum` / `percent_at_maximum` / `h_oe_at_maximum` / `why` |
| 电感够但磁密超 | `dc_bias_unreachable` | 诊断带 `turns_reaching_l` 与 `b_peak_at_that_turns_t`，`why` 说明"第一个够 L 的匝数就超磁密了" |
| 没有 fit | `dc_bias = None` + `dc_bias_because`，`missing` 加 `"dc_bias"` | 固体芯（铁氧体/铁粉）没有厂商 fit，不套粉末芯的曲线 |

顶层把第一种之外的三类点名：

```
dc_bias.listed_with_a_fit  = "232 of the 232 candidates listed"   （本例）
dc_bias.unreachable        = [零件号, ...]（只列号，诊断在 rejected 里）
dc_bias.outside_the_printed_band = [零件号, ...]
```

**注意 `unreachable` 只列零件号**。这是刻意的：诊断对象可能有一百多个，全塞进
顶层会淹没真正的读数；每一条的完整诊断都在它自己的 `rejected[i].dc_bias` 里。

## 8 带外（10–800 Oe）：标记，不 clamp

`79` 篇的 `DC_BIAS_PLOTTED_OE = (10.0, 800.0)` 是**从图页网格线量出来**的带，
不是厂商印的"有效范围"。偏置接进选型以后，一定会遇到 `H` 落在带外的设计
（大电流 + 大 `le` 组合），此时：

- **不 clamp**：夹到 800 Oe 会让答案看起来"在范围内"，而实际上是把跌落算浅了；
- **不拒绝**：大电流设计全是带外的，硬拒就把整个工况排除了；
- **标记**：`h_within_printed_band = false` + `h_band_note`（措辞里含
  `EXTRAPOLATION`）+ 顶层 `outside_the_printed_band` 点名。

实测（100 µH / 10 A / 60 µ / 8 A 偏置、全池 232 个候选）：**7 个零件带外**，
最小的那个在 **1743.51 Oe**（`µ` 只剩 0.451206 %，`B = 0.060 T`）。它是"能算但
只能当外推"的读数，不是错误 —— 所以列出来、标出来，让人自己决定要不要用。

## 9 未做（诚实清单）

这一版**没有**做的事，逐条写在这里，同样写进了答案的 `not_modelled`：

1. **温度**：厂商的 fit 页没有温度轴。100 ℃ 的曲线与 25 ℃ 不同，这一版按印刷值算，
   不编一个温度系数。
2. **饱和不是建模**：`B_peak` 只与限值比（限值本身是 `0.8 × Bsat`，Bsat 又是厂商
   一列一个的典型值），不做 `µ(B)` 的自洽迭代 —— 那是另一个回路，且需要 `Bsat`
   随温度的数据，目录没印。
3. **固体芯没有 DC 偏置曲线**：`dc_bias = None` 并说明原因，不套粉末芯的 fit。
4. **损耗拟合是无偏置的**：`material_core_loss` / `core_loss_steinmetz` 的系数是
   在无直流预磁化下测的，所以偏置设计的 `core_loss_w` 是**下界**。这一条写在顶层
   `dc_bias.loss_fit_is_unbiased` 与 `not_modelled` 里。
5. **环型没有平均匝长**：目录不印 MLT，所以这一版**不估**铜损（不报一个猜的
   `windowing_report`）。要做必须新增派生字段，不能改 `mlt_mm` 的原值（那里现在
   是 `null` + 说明）。
6. **不优化**：给的是"满足约束的最小匝数"，不替你在体积/损耗/成本之间选。
   多目标留给调用方。
