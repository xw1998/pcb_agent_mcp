# 143 · RK3506 核心板（SOM）设计输入与方案冻结

- 日期：2026-11-12
- 器件：Rockchip RK3506J（工业级 −40~85℃）/ RK3506B（−20~70℃），同封装可换
- 权威数据源：`RK3506J Datasheet Rev 1.3`，50 页，**2,724,252 B，文末 `%%EOF` 完整**
- 本阶段只写**能从手册逐字核到**的数；手册没给的标「手册未列」，不填猜测值。

## 0. 数据源修复记录（先记坑，否则下面的数没有意义）

上一轮解析用的 `RK3506J_datasheet_V1.3.pdf` 只有 **1,231,973 B**，是**下载了 45% 就断的残件**（`tail` 停在
`386 0 obj`，无 `%%EOF`；`pdftotext`/`pdfminer` 直接 `Unexpected EOF`）。PyMuPDF 能靠重建 xref 打开 50 页，
所以「页数看起来对」极具欺骗性，但它把被截断的文本流按缺字吐出，造成两类系统性错误：

1. 球号/引脚名**重复末位被吞一位**：`A11→A1`、`A22→A2`、`1A11→1A1`、`1F11→1F1`、`DDR3_A11→DDR3_A1`、
   `DDR_DQ11→DDR_DQ1`。上一轮用「重复末位补位」的启发式去补，产生了两处**真错数**（见 §3 的 DQ1/DQ11）。
2. 整行整表缺失：`1C`/`1E`/`1G` 三行当时判为「手册没有」，其实**是残件没了**；`LOGIC_DVDD` 的球位被读成
   `1F1 1H1 1J10`（正确是 `1F11 1G11 1H11`），`SYS_PLL_AVDD1V8` 被判成「手册未给球位」（正确是 `1H1`）。

本文件所有数字来自**重下的完整 PDF**（`J_v13_fresh.pdf` = `https://mail.rockchip.fr/RK3506J%20datasheet%20V1.3.pdf`，
curl 跟随 301 → `rockchip.fr`，最终 200 / 2,724,252 B）并用 `rawdict` 逐 span 几何重解析。
**结论：凡「因为文档残缺而得到的否定结论」都不能当事实；下载件先验 `%%EOF` 再解析。**

## 3. DDR3L 16bit 接口（Table 2-1，前缀 `DDR_`/`DDR3_`，共 55 信号 + 5 电源 = 60 球）

| 信号 | 球 | 信号 | 球 | 信号 | 球 |
|---|---|---|---|---|---|
| A0 | V23 | A8 | Y21 | DQ6 | W9 |

| A2 | V22 | A10 | W17 | DQ8 | Y7 |
| A3 | 1N13 | A11 | W22 | DQ9 | W7 |
| A4 | W18 | A12 | W23 | DQ10 | Y6 |
| A5 | 1N14 | A13 | T23 | **DQ11** | **Y3** |
| A6 | Y20 | A14 | Y22 | DQ12 | W6 |
| A7 | T22 | A15 | Y17 | DQ13 | Y2 |
| BA0 | 1N12 | BA1 | Y18 | DQ14 | 1N1 |
| BA2 | 1N9 | RASN | 1M8 | DQ15 | 1N2 |
| CASN | 1N8 | WEN | 1M9 | DM0 | 1N4 |
| CSN | 1M11 | CKE | W15 | DM1 | 1M4 |
| ODT | 1N10 | RESET | 1M13 | RZQ | 1L8 |
| CLKP | Y14 | CLKN | W14 | VREF_CA | 1L10 |
| DQS0P | Y10 | DQS0N | W10 | VREF_DQ | 1L11 |
| DQS1P | Y4 | DQS1N | W4 | **DQ1** | **Y12** |
| OPEN0 | 1L6 | OPEN1 | 1K5 | DDR_VDDQ | 1K6 1K7 1K8 1K9 1K10 |

- 自检：16 A + 3 BA + 5 命令（RASN/CASN/WEN/CSN/CKE）+ ODT + RESET + CLKP/N + 4 DQS + 16 DQ + 2 DM + RZQ +
  2 VREF + 2 OPEN = 55 信号，+5 VDDQ = **60**，与手册 DDR 前缀球数一致；A0–A15、DQ0–DQ15 无重号无缺项。
- **与上一轮的差异（唯一）**：`DQ1` 与 `DQ11` 两个球位写反了（旧表 DQ1=Y3、DQ11=Y12）。完整手册为
  `Y12 = DDR_DQ1`、`Y3 = DDR_DQ11`。其余 59 球逐字一致。
- DDR3L 电压 = **1.283 / 1.35 / 1.418 V**（Table 3-2，`DDR_VDDQ` DDR3L 行）；VREF = VDDQ/2 = 0.675 V。

## 5. 板级方案（冻结）

| 项 | 决定 | 依据 |
|---|---|---|
| 板框 | **45 × 45 mm**，四角 R2 | 333-BGA 11.3×13.3 + DDR3L + eMMC + 电源 + 140 邮票孔；单面贴片要留布线通道 |
| 层数 | **6 层**，1.6 mm，ENIG | 用户指定 4–6；DDR 需完整参考面 |
| 叠层 | L1 信号 / **L2 GND** / L3 信号 / L4 PWR 分区 / **L5 GND** / L6 GND | 背面无走线、单面贴片，L2/L5 两个完整地平面夹信号 |
| 贴片 | 全部器件在 **L1（Top）**；背面只有平面与邮票孔焊盘 | 用户要求单面贴片 |
| 邮票孔 | **140 pin @1.0 mm**，半孔 φ1.0 / 孔盘 φ1.6，四边 35 pin/边 | 与主流 RK3506 SOM（创龙 2×30 + 2×40 = 140 @1.0 mm）对齐 |
| 阻抗 | 单端 50Ω ±10%、差分 100Ω ±10% | DDR3L-1333/1600 |
| 电源输入 | 5V（4 pin 并联）+ 3.3V 备份 | 其余电压全部板内产生 |

## 6. 电源树（电压已核，器件选型待核）

```
5V in ──┬─ Buck 0.95V/2A (DVFS 可调 0.855–1.103) ── CPU_DVDD  (1C2 1C3 1C4)
        ├─ Buck 0.90V/2A ────────────────────────── LOGIC_DVDD (1E4..1J10) + PMU_LOGIC_DVDD0V9 (1K2)
        ├─ Buck 1.35V/2A ──┬─────────────────────── DDR_VDDQ (1K6..1K10)
        │                  └─ VTT 0.675V/1A ──────── DDR 地址/命令端接（灌/拉双向）
        ├─ Buck 3.3V/2A ───┬─────────────────────── PMUIO_VCC3V3 (1L1) / VCCIO* 3.3V 档 / USB AVDD3V3 (1B10)
        │                  └─ LDO 1.8V/1A ────────── SYS_PLL (1H1) / MIPI 1V8 (1B7) / USB 1V8 (1B9) /
        │                                            ACODEC 1V8 (1B13) / SARADC (1B14) / TSADC (1B6) / VCCIO* 1.8V 档
        └─ LDO 0.9V/0.3A ─────────────────────────── MIPI 0V9 (1C7) / USB 0V9 (1C8)
```
- 约束：CPU_DVDD 必须可调（DVFS 0.855–1.103），不许固定输出；DDR3L VREF = 0.675 V（0.1 µF 就近）；
  VTT 需能灌/拉；`VCM`(1B11)/`AVDD1V6`(1B12) 电压手册未给，**不接电源、只留测试点**。
