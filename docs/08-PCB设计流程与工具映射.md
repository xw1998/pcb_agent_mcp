# PCB 设计流程：六步、回流边、方法论补齐与内置计算层

日期：2026-10-27
来源：
1. **用户口述的实际设计流程**（§1、§3 的权威依据，逐字保留）。
2. 技能市场方法论核对：`kicad-free`（全流程+红线+载流公式实现）、`rf-circuit-design`（射频间距/接地过孔/检查清单）、`gmai-pcb-layout-review`、`gmai-pcb-manufacturing`（付费，仅取覆盖面）。

用途：把流程固定成工具必须服务的状态机，逐点标出「现有 MCP 缺什么」，并划出**必须由我们内置实现的计算**。

## 1. 六步流程（用户原述）

| 步 | 名称 | 用户给的规则 |
|---|---|---|
| 1 | **确定需求 → 定硬件方案** | 需求确定后，结合**是否有后续升级**决定方案：**有后续软件升级计划的要留够硬件余量；没有就选余量少一点的方案即可** |
| 2 | **绘制原理图** | **要分各个模块和图页，不能全部混合在一起** |
| 3 | **绘制板框** | 板框实际是 CAD，在还没开始布局时导入。**有 CAD/草图就按尺寸绘制；没有就输入一个方型的长高** |
| 4 | **布局** | **优先重要信号**（模拟信号、高速数字信号），这些走完后再走低速信号。注意：**某些低速信号因布局导致需要打太多过孔时，可以返回第 2 步改原理图**，以减少过孔和对地平面的切割 |
| 5 | **拉线** | 见 §3 的六条细则 + §4 的方法论补齐；**部分电源线和其他线路也可以用铺铜解决** |
| 6 | **铺地 + DRC + DFM** | 见 §4.4 的检查清单 |

**三个必须在建模阶段就承认的事实：**

1. **第 4 步能回流到第 2 步。** 流程不是流水线，是带回路的状态机。
2. **布局的排序键是「信号」不是「元件」。** 「优先重要信号」意味着放置顺序由 signal class 决定——这改写了 04 篇的前提。
3. **板框先于布局，且是布局的输入约束。**

## 2. 阶段状态机（含回流边）

```
S1 需求/方案 ─▶ S2 原理图 ─▶ S2.5 封装核对/ERC ─▶ S3 板框 ─▶ S4 布局 ─▶ S5 拉线 ─▶ S6 铺地/DRC/DFM
                   ▲                              │
                   └───── 回流 R1（过孔过多）─────┘
```

| 边 | 触发条件 | 用户给的理由 | 工具必须做的 |
|---|---|---|---|
| **S2.5** | 原理图完成 → 进板框之前 | 旧流程缺这一步（见 §4.1） | 封装与 datasheet 对照、ERC 清零 |
| **R1** | 布局导致低频信号**过孔过多** | 减少过孔、**减少对地平面的切割** | 必须能报「这条信号现在要打 N 个过孔」，N 超阈值时提示回流。核心量是**过孔数**与**被切割的参考平面区域** |
| **R2** | 布局超出板框 | 放不下 | 布局中途报「剩余自由区放不下剩余元件」 |

⚠️ **R1 是最容易漏的一条。** 它要求工具同时知道：拓扑、当前布局下的过孔代价、**每个过孔对地平面的切割后果**（04 篇「回流路径场」的直接用途）。

⇒ 03 篇判据的又一实例：**布局阶段打的孔多了，DRC 全绿。**

## 3. 第 5 步（拉线）的六条细则

| # | 用户规则 | 关键点 | 工具必须提供 |
|---|---|---|---|
| 5.1 | 模拟/高速信号**先做阻抗计算，再按结果定线宽** | 线宽是**结果**，不是输入 | **反解查询** `width_for_z0()`，见 §6 |
| 5.2 | **线宽不利于扇出时，可先细线扇出，再接阻抗线** | 阻抗段必须定宽，扇出段允许细 | 检查器**不许一刀切**"全段同宽"。区分 `impedance_段` vs `fanout_段`，扇出段限长 |
| 5.3 | 重要信号**需要包地的就包地** | 包地是可机判几何 | `guard_trace_check()`：间距、过孔间距、两端接地、包地自身是否成天线 |
| 5.4 | 电源类**先预估电流 → 算线宽 → 工作时不得有温升** | 「不得有温升」须落成 ΔT 预算，见 §4.5 | `current_capacity()` / `width_for_current()` |
| 5.5 | **电流巨大且低频**时，加大线宽后**阻焊层开窗镀锡** | 载流载体不止线宽，还有「开窗 + 镀锡」 | 载流模型须识别**阻焊开窗**并计入；⚠️ 与爬电冲突见 §5.3 |
| 5.6 | **部分电源线路和一些其他线路也可以铺铜解决** | 导体形态不止 segment | 见 §3.1 |

**5.5 是被严重低估的规则。** 载流模型不能只看 `width × thickness`，还要看「这段铜上面有没有开窗」。而**阻焊开窗在两端表达完全不同**（KiCad 用 `F.Mask`/`B.Mask` 图形或 pad mask margin；立创用对应层 + pad 字段）⇒ **两个方向都错**：只看线宽，会把开了窗的大电流线判不合格，也会把没开窗的判合格。

### 3.1 铺铜作为走线载体

> 用户原述：**「第五步布线时部分电源线路和一些其他线路也可以铺铜解决」**

这条推翻了一个隐含假设：**「布线的载体只有 segment + via」是错的。**

```
conductor = segment | arc | pour_region
```

`pour_region` 在两端都原生存在：立创 `POUR` 定义 + `POURED` 填充结果（`isPoly` 区分实心轮廓与热焊盘辐条）；KiCad `zone` + `filled_polygon`。**数据不缺，缺的是把它当导体对待的模型。**

#### 后果一：连通性判定从「点重合」变成「面相交」

- segment 之间：端点坐标相等即连通，O(1)；
- **铺铜参与后**：必须判多边形相交 —— 几何 overlay + 空间索引，还要判**热焊盘辐条这个"细颈"是否真的连通、辐条宽度够不够**。

⇒ Oracle 的连通图**不能再是"点—边"图，必须是"点 + 面"混合图**。这是全系统几何代价最大的单点跃增，直接决定 07 篇 R1 里「加载预算 vs 按需算」的边界。

#### 后果二：载流模型对铺铜失效

铺铜**没有「宽度」这个量**，它是一片面。`current_capacity(width, ...)` 无法套用，必须换成面传导模型：

- **先定瓶颈**：实际瓶颈常是**热焊盘辐条宽度**或铜皮收窄处，不是整片面积；
- **再算截面**：瓶颈有效导电截面 × 允许 ΔT；
- **网格铜必须单独处理**：KiCad `zone` 有 `fill_mode: solid|hatch`，立创铺铜也有网格选项。**网格铜载流远低于同尺寸实心铜，按实心算会给出危险的高估。** 按红线：识别到网格铜时返回 `precision: unusable` 或报不支持精确载流，**不许糊一个数**；
- **过孔是另一个瓶颈**：换层时载流由孔壁铜厚 × 孔数决定，与铜皮面积无关。

#### 后果三：铺铜既是「第 5 步的走线」也是「第 6 步的地」——步骤交错

同一块 `zone`，连电源就是走线，连 GND 就是地平面。所以：

- **第 5、6 步在实作上交织**，不能做成硬串行；
- 更要紧的是**冲突**：铺一段电源铜，就在**同层参考平面上挖掉一块**。第 4 步的「减少对地平面的切割」与第 5 步的「用铺铜解决电源」，是**同一块面积的争夺**。

⇒ 给出一块铺铜时，要**同时报出它对同层地平面的切割后果**（面积、被切断的回流路径、跨分割必经次数）。`plane_cut()` 必须能处理「过孔切割」与「铺铜占用」两种成因。

#### 后果四：铺铜的 DFM 项

- 最小铜宽 / 最小间隙（含不同电位铺铜间的爬电，见 §5.3）；
- **孤岛铜**必须去除（否则当天线）——KiCad 的 island removal 参数可佐证这是必查项；
- **热焊盘辐条数量与宽度不足 → 焊接不良**（散热太快、润湿不够），典型「DRC 全过、回板焊不上」；
- 大面积铜的散热会改回流焊曲线，属板厂会主动提的工艺项。

## 4. 方法论补齐（技能市场核对后）

用户说「我说的并不全」，核对后确实有 4 处缺口 + 若干量化规则。

### 4.1 缺口一：S2 与 S3 之间少了一步「封装核对 + ERC」

`kicad-free` 的红线写得很硬：**「不编造器件参数：封装尺寸、电气参数一律以厂商 datasheet 为准，缺失时写「待查手册」，禁止凭印象填。」**

⇒ 这要求一个独立的 gate：

| 检查 | 判据 |
|---|---|
| 每个器件有 datasheet 依据 | 缺 → 标「待查」并**阻断**，不许画封装 |
| 封装引脚数/间距/1 脚标识与 datasheet Land Pattern 一致 | 逐项核对 |
| 焊盘尺寸符合 Land Pattern | 允许 ±10% 校验，超出要人确认 |
| 丝印不压焊盘、有极性标识、本体不与邻件干涉 | 几何判定 |
| **ERC 清零** | 未连接引脚、重复网络名、电源引脚未驱动、输出短路 |

**ERC 是一个被我们前面漏掉的硬 gate。** 它属原理图域，但必须在进板框前完成——否则封装都错了，后面全白做。

### 4.2 缺口二：S4 布局的第一步不是「放重要信号」

用户说「优先重要信号」，但方法论指出**更前面还有一步硬约束**：

> **先定连接器与机械约束**——板框、安装孔、接口位置是硬约束。

⇒ **S4 的真实顺序是三层：**

```
① 硬约束层：板框已定（S3 产物）→ 放连接器、安装孔、定位孔、按键/显示窗口
② 重要性层：模拟信号 → 高速数字信号 → 关键功能块（按 signal class）
③ 填充层：低速信号、辅助器件、测试点
```

补的定量规则（来自方法论，需入库成为可机判约束）：

| 规则 | 数值 | 影响 |
|---|---|---|
| 去耦电容 | **同层、距电源引脚 < 3mm** | 违反 → 噪声/偶发复位 |
| 晶振 | 紧靠 MCU，**下方禁走线**，包地处理 | 违反 → 时钟抖动 |
| 分区 | 电源区 / 数字区 / 模拟区 / 射频区 / 功率区按信号流分 | 违反 → 串扰 |
| 发热器件 | 远离敏感器件，留散热路径 | 温度场（04 篇两场之一） |
| 模拟/数字地 | 单点连接 或 统一地平面 | 二选一必须显式声明 |
| 器件间距 | > 0.5mm（可制造性） | DFM |

### 4.3 缺口三：布线的顺序与布局**不同**，且规则远多于六条

**布局顺序**：硬约束 → 模拟 → 高速 → 低速。
**布线顺序**（方法论给的）：**电源 → 关键模拟/高速 → 差分 → 一般信号**。

⇒ **布局先重要信号，布线先电源。** 两者不是同一顺序，实现时不能合并成一个序列。
（为什么：电源树要先占定通道，否则后来被信号挡死；而布局时位置由信号可布性决定。）

补充的可机判规则：

| 规则 | 数值 |
|---|---|
| 3W 规则（串扰） | 相邻线中心距 ≥ 3×线宽 |
| 射频线-射频线 | > 3w |
| 射频线-数字线 | > 5w |
| 射频线-板边 | > 3mm |
| 天线-其他射频线 | > 10mm |
| 差分对内间距 | 恒定（不随转弯变化） |
| 差分对间 | > 10w |
| 等长匹配 | 偏差 < 5mil（约 0.127mm），按项目定 |
| 转角 | 避免直角，45° 或圆弧 |
| 换层 | 信号过孔**两侧加接地过孔**提供回流 |
| 接地过孔间距 | < λ/20，λ = c/(f·√εr)。2.4GHz→1.0mm，5.8GHz→0.5mm，10GHz→0.3mm |
| 射频走线 | 勿被铺铜覆盖，需净空区 |
| 回流 | 每条信号下方有连续回流面 |

### 4.4 缺口四：S6 的 DFM 清单要具体到项

**DRC 必须清零**（不是"尽量少"）。打样前清单：

- 板框闭合、无重复线、无自交；
- 所有网络已连接（**无鼠线残留**）；
- 丝印不压焊盘、方向一致、1 脚/极性标识正确；
- 安装孔与结构尺寸核对（**拿实物或结构图比对**）；
- 器件高度与外壳干涉；
- 关键电源/信号留**测试点**；
- 拼板/工艺边按板厂要求；
- 铜厚、板厚、阻焊颜色、表面工艺（沉金/喷锡）确认；
- 最小线宽/线距/孔径 ≥ 目标板厂能力（**DFM 能力表属 `home: external`**）。

Gerber 层清单：F/B_Cu、F/B_Mask、F/B_Silkscreen、F/B_Paste、Edge_Cuts、钻孔 `.drl`。

## 5. 爬电距离（用户本轮新增，单列）

> 用户原述：**「布线需要注意爬电距离」**

### 5.1 它与我们已有的「间距」不是一回事

| | 电气间隙 clearance | **爬电距离 creepage** |
|---|---|---|
| 定义 | 两导体间**空间最短距离** | 沿**绝缘表面**的最短路径 |
| 受什么影响 | 空气击穿 | 表面污染、湿度、CTI、涂层 |
| EDA 会不会算 | 会（DRC 的间距检查） | **不会。立创 `ruleType:1` 的间距矩阵是电气间距，不是爬电** |

⇒ **爬电距离没有任何 EDA 的 DRC 会算。** 它需要沿表面的路径搜索。这是本项目必须新建的能力。

### 5.2 依赖 6 个输入，一张表查不出来

查表前必须确定：

1. **工作电压**（RMS / 峰值 / 瞬态过电压，取最严）；
2. **污染等级** PD1~PD4；
3. **材料组别**（按 CTI：I ≥600 / II 400–599 / IIIa 175–399 / IIIb 100–174）；
4. **绝缘类型**（功能 / 基本 / 附加 / 双重 / 加强）；
5. **海拔**（>2000m 需修正）；
6. **涂层**（三防漆可降级，但只对**完全覆盖**的区域有效，且有 A 型/B 型涂层之分）。

依据标准随项目走：`IEC 60664-1`（=GB/T 16935.1）、`IEC 62368-1`（音视频/IT）、`IEC 60601-1`（医疗更严）。**不同标准取值不同，必须由项目选定标准族。**

⚠️ **铁律：绝不给记忆值。**
`kicad-free` 自身的红线就是「**不编造安全间距：安规间距必须按适用标准与电压等级查表，本技能不给确定值**」。这条红线其实是在说：**方法论技能能告诉 AI "要查什么"，但不能替它算准。** 所以标准表必须以结构化数据入库（表号 + 版本 + 条款），计算只做查表 + 插值 + 海拔修正。

### 5.3 三处与我们自己规则的硬冲突

**① 5.5 的「开窗镀锡」会破坏阻焊，而阻焊正是爬电的绝缘介质。**
开窗后，表面路径的判据从「沿阻焊表面」变成「穿空气」（退化为电气间隙）。**若某处原本靠阻焊保证爬电，开窗后必须按间隙重算。** 两条规则必须联合校验，不能各算各的。

**② 5.6 的铺铜之间以及铺铜到板边。**
不同电位铺铜要靠爬电约束；**板边铜距是独立要求**（按电压与板厂能力，与内部间距不同）。

**③ 我们的产品是户外水文仪器。**
凝露、潮湿、污染 ⇒ **污染等级应按 PD3 考虑**，爬电要求显著提高。三防漆可降级，但必须声明涂层类型与**覆盖完整性**（引脚根、板边、开窗处往往涂不到 → 这些位置不降级）。

### 5.4 一个能立刻落地的保守判据

真正的爬电距离是**表面寻路**，实现成本高。但有一个几何不等式：

```
表面路径 ≥ 空间直线距离   ⇒   clearance ≥ required ⟹ 必然满足爬电要求
```

⇒ **先用 clearance 做充分条件判定**：过则直接放行；不过再去做表面寻路（或按保守估计报不通过）。这能把绝大多数情形挡在廉价判定上，**只有"间隙不够但可能仍满足爬电"的情况才需要昂贵计算**——而那正是最需要精确值的少数点。

⚠️ 反向不成立：间隙不够**不代表**爬电不够（中间有阻挡物时表面路径可以大于直线距离，但这恰恰是危险情形）。所以只能说"间隙过 ⇒ 安全"，不能说"间隙不过 ⇒ 不安全"。

## 6. 内置计算层（Calc）——05 篇三件套之外必须加的第四件

用户原述：**「这些电流、爬电距离、阻抗等相关计算也需要我们 mcp 内置工具」**

### 6.1 为什么它不能挂在 Oracle 上

Oracle 的语义是「**查询这块板的测量值**」，输入是 handle。但这些问题**不需要板子**：

- 「1 A 要走多宽」——输入是电流、铜厚、ΔT；
- 「250 V 的爬电要多少」——输入是电压、污染等级、材料组别；
- 「90 Ω 差分要多少线宽」——输入是 Z0、叠层。

⇒ 这是**无状态纯函数层**：

```
Canonical（EDA 模型，唯一真值）
Discrete（只装本来就离散的事实）
Oracle（测量这块板）
Calc（无板子的工程计算）  ← 新增
```

**Calc 的输入是数值，输出是带依据的结果；它不接触任何 EDA 格式。**

### 6.2 每个 Calc 必须返回五元组

```yaml
value: 0.30
unit: mm
model: "IPC-2221 chart fit"        # 公式名/模型名
basis: "IPC-2221B §6.2 / Fig.6-4"  # 标准条款，可追溯
precision: "±20%"                  # 必填
assumptions:                       # 必填，用户反驳的唯一入口
  delta_t: 10
  copper_oz: 1
  layer: external
  mask_opening: false
```

**不返回 `basis` 的计算结果一律视为无效。** 理由和 05 篇一致：模型不许自己算，也不许给出无法追溯的数。

### 6.3 一个实证：为什么「内置」而不是「让 AI 按方法论算」

`kicad-free` 技能里给的 Python 实现：

```python
A = (current_ma / 1000) / (0.048 * temp_rise_c ** 0.44)   # ← 漏了 ^(1/0.725)
```

IPC-2221 的正确形式是 `A = (I / (k·ΔT^0.44))^(1/0.725)`。实算对照（1 A / ΔT=10 °C / 1oz 外层）：

| | 结果 |
|---|---|
| 该技能代码算出 | **0.139 mm** |
| 该技能注释自己写的 | ~0.28 mm |
| 按 IPC-2221 正确算 | **0.300 mm** |

⇒ **代码低估 2.16 倍，方向是危险的那一侧**（线做细 → 温升超标 → 烧线）。而注释里的 0.28 与代码的 0.139 互相矛盾，说明作者也没核对过。

**这就是「必须内置、必须可单测、必须带依据」的直接证据。** 也说明 05 篇那条「模型永不自己算连续量」需要升级为：**模型不许自己算，也不许复用未经核验的第三方实现。**

### 6.4 Calc 清单（首版）

| 工具 | 输入 | 输出 | 依据 |
|---|---|---|---|
| `width_for_current` | I, ΔT, 铜厚, 层 | width | IPC-2221 图表拟合 |
| `current_capacity` | width, 铜厚, 层, ΔT, 开窗 | I + assumptions | 同上 |
| `via_current` | 孔径, 孔壁铜厚, 孔数, ΔT | I | 孔壁截面 vs 线宽等效 |
| `pour_bottleneck` | 铺铜 handle, 源, 负载 | 瓶颈截面 + 位置 | 面传导，保守降额 |
| `width_for_z0` | Z0, 叠层, 线型(microstrip/stripline/diff) | width / 间距 | 反解求根；**须标模型精度** |
| `z0_of` | width, 叠层, 线型 | Z0 | 正解，用于校验 |
| `creepage_required` | 电压, PD, 材料组, 绝缘类型, 海拔, 涂层 | mm + 表号 | IEC 60664-1 / 62368-1 |
| `clearance_required` | 同上（+ 过电压类别） | mm + 表号 | 同上 |
| `creepage_actual` | netA, netB | mm | 表面寻路；先用间隙做充分条件 |
| `lambda_over_20` | f, εr | 过孔最大间距 | λ = c/(f·√εr) |
| `unit_convert` | value, from, to | value | mil↔mm↔inch（含 0.01in，立创内部单位） |

**`unit_convert` 看着琐碎，但它防的是最贵的一类静默错**：立创内部 0.01 英寸、KiCad mm。25.4 倍的错误不会让任何 DRC 报错。

### 6.5 实现顺序：Calc 应该最先做

理由：**Calc 是唯一可以做到"完全可验证"的一层。**

- 纯函数、无几何、无文件格式；
- 可以对一组输入直接比对标准表/厂商手册 → **golden 对照**；
- 单测可穷举边界（ΔT=0、I=0、负值、极大值）。

对比之下 Oracle 依赖几何、Adapter 依赖格式，两者都难做全覆盖验证。

⇒ 这修正了 07 篇的分期：**Calc 应当先于 Oracle**，因为它同时提供了 Oracle 和检查器要用的所有数值能力。

## 9. 被流程逼出来的真问题：预留余量 = 预留 DNP 位

S1 的「有升级计划就留够硬件余量」，落到 PCB 上就是**预留空位**。

- 这些位号的**焊盘、阻焊、钢网都在文件里**（要能焊），但**元件不装**；
- 当"已占用"→ **过度保守**，本可利用的空间被锁死；
- 完全忽略 → **低估**，走线穿过就废掉预留。

⇒ 需要第三状态 **`reserved`**：物理几何存在、电气不参与、**布局/布线必须绕开**。

这是 03 篇 E 类语义丢失的典型：文件里只有 `dnp:true` 或一个 `ATTR`，**「这是为了升级预留的」这层意图不在文件里**，不显式登记就必然被 AI 当成普通空焊盘。
