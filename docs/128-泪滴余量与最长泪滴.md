# 128 · 泪滴：这个焊盘角上还有没有位置，最长能长到多少

`board_teardrop_room`。

## 1. 为什么需要

参考工程（`examples/ProPrj_立创梁山派·天空星开发板_2026-11-05.epro2`）里数得出
**30 个 `PRIMITIVE/TEARDROP` 对象**，而照着它复刻的 `sky_star_routed.kicad_pcb`
里有 `(legacy_teardrops no)`、一个泪滴都没画。这是「照着画不像」里可以量的那一部分：
KiCad 永远画得出泪滴，难的是**那个角上到底有没有位置**——加出来的铜仍要离别网
`clearance`、离板边 `edge_clearance`，而 0.3 mm 的扇出区里经常没有。

工具集里原来没有任何东西能回答这个：`board_routability` 量通道，
`board_escape_width` 量扇出宽度，`board_trunk_plan` 量干线宽度，都是「铜往哪走」，
没有一个是「焊盘角上多出来的那块铜放不放得下」。

## 2. 怎么算

1. **什么是角**：走线的**一个端点落在同网焊盘上**（`point_in_polygon` 或
   `dist_point_polygon ≤ 0.01`，按桶格环查 0..2 环），且**另一个端点在焊盘之外**。
   两个端点都在焊盘里的是 stub，不是角。
2. **方向** `u` = 这条走线自己的方向（`q − p` 归一化），不是「焊盘质心 → 远端」。
3. **起点** `p0` = 走线中心线**离开焊盘**的那个点（线段与焊盘边界求交，取最外的交点；
   交不到就说明端点本来就压在边界上，直接用它）。
4. **包络**：从 `p0` 出发、沿 `u` 长 `length_mm` 的梯形，半宽从「`p0` 处焊盘的
   **弦**（垂直于走线）的一半」线性收到「走线半宽」，且任何位置都不窄于走线。
5. 两条斜边与端帽在 `grid_mm` 上采样，每点算两个数：到板边的 `de − edge_clearance`
   （点在板外时 `de` 取负）与到最近**异网**铜的 `d − clearance`，取最小即 `room_mm`，
   `limited_by` 记住是谁卡住的（`kind` / 网 / 位号 / 层 / 实测距离）。
   `room < 0` 同时是一个判词（放不下）和一个距离（超出多少）。
6. `max_length_mm`：从 `length_mm` 起按 0.1 mm 上探到 `max_length_mm`（起始就不行
   则下探到 0.1），整条包络仍然合法的最长长度；全不行是 0.0。

**同网铜不是障碍**：泪滴正是长在自己网的铜上的。所以障碍集按网过滤后缓存
（`_obstacles(for_net)`），不是「取最近一件、再判断是不是同网」。

**铺铜默认不是障碍**，与 `board_cut_capacity` / `board_via_sites` / `board_trunk_plan`
同一个理由：灌铜会绕开新增的铜重切。要严格口径就 `pours_block=true`。

## 3. 判据与对照

二十一条，在 `tests/test_teardrop_room.py`。每条主判据都配一个「只改一件事、
答案必须翻」的对照：

| 事实 | 对照（能反向失败的） |
|---|---|
| 空地上量到的是板边：`limited_by.kind == "board_edge"`，`room = 19.5 − 0.2 = 19.3`（60×40 板） | 同角把 `length_mm` 从 0.4 换到 1.5，`room` 逐位不变（余量是地面的属性，不是长度的属性） |
| 别网 0.4 焊盘贴进包络 ⇒ `room = −0.1`，`limited_by.ref` 指名到那个焊盘 | **把那个焊盘改成同网** ⇒ `room > 10`，`verdict` 翻成 `teardrops_fit`（一次改名，两个答案） |
| 本网的第二条走线横在角上不算障碍 | 同一条走线改成别网 ⇒ 立刻压进包络 |
| 1.9 mm 外的别网焊盘：`length_mm=0.5` 放得下、`2.0` 放不下 | `max_length_mm` 报到的是「再长 0.1 就翻」的那个点 |
| 包络起点在焊盘边缘：1.6 mm 焊盘 + 中心引出的走线 ⇒ `at ≈ 20.8`、`pad_width ≈ 1.6` | 0.3×1.6 焊盘 45° 引出 ⇒ `pad_width < 0.6`（不再按对角线读成 1.6） |
| 完全在焊盘里的 stub 不是角：两个这样的 stub ⇒ `junction_count == 1` / `NO_GEOMETRY` | 同一根走线引到焊盘外 ⇒ 变成角 |
| `layers=["B.Cu"]` 而走线在 F.Cu ⇒ `NO_GEOMETRY`；`region` 排除角 ⇒ 跳过不发明 | 未知层 ⇒ `ARG_INVALID`；`length_mm=0` ⇒ `ARG_RANGE` |
| 假铺铜压进包络：默认 `fits` | `pours_block=true` ⇒ `teardrops_blocked`，`assumptions.pours_counted` 同步翻 |
| 工具面自称「draws nothing」、`not_claimed` 里写不选曲线、`precision` 里写采样步长 | 调用前后文件逐字节相同 |

## 4. 真板读数

`examples/sky_star/sky_star_routed.kicad_pcb`，`length_mm=0.5`、`grid_mm=0.05`、
间距 **0.15**（Default 网类）、边距 **0.5**（板规则）：

```
verdict = teardrops_blocked   junction_count = 238   fits = 234   blocked = 4
skipped = {outside_region: 0, zero_length_track: 0}
```

**238 个角，只有 4 个放不下。** 余量分布：`room ≥ 0.5` 的 60 个，
`0 ≤ room < 0.05` 的 25 个（焊盘就摆在间距的边沿上，余量正好 0），
命中上限 `max_length = 2.0` 的 140 个，`max_length = 0.0` 的 3 个。
限住它的东西：焊盘 193、过孔 32、走线 13。238 个角里 **237 个在 F.Cu**、
1 个在 B.Cu —— 这块板基本是单面走线。

最紧的几条（`limit=12`）：

可执行的三件事：

- **`R19.1` 是唯一一处真的放不下**（`room = −0.1`）：`_SDIO_D3` 的焊盘与 `+3V3`
  的焊盘只隔 0.05，泪滴往这边长就要吃掉 0.1。这一处要么把泪滴长度收到 0，要么
  让 `R19` 挪 0.1。
- **`D2.4` 两个角 `room = −0.000`**：刚好压在间距线上，属于「放得下但一点余量都
  没有」——数值上判 blocked，实操是「可以画，别指望再宽一丝」。
- **`D3.1`…`D9.1` 一整排 `room = 0.000` 且 `max_length = 1.2~2.0`**：二极管两焊盘
  间距就是 0.15，泪滴贴着屏着画是对的。这排读数说明工具没有把「焊盘本身贴着
  间距」误报成「没有位置」—— 那是第一版的形态（见 §5）。

耗时：默认 `limit=40`（只对报告出来的角做长度搜索）**5.2 s**；`limit=100000`
（238 个角全搜）**98.4 s**。这就是长度搜索为什么要推迟到排序之后。

### 一处必须写明的精度

1. 采样步长 `grid_mm=0.05`：窄于一个采样的缝隙可能漏掉 ⇒ `room_mm` 是**上界**。
2. 三倍桶格（≈ 3·(2+clr+step) mm）之外的铜当通畅 ⇒ 空旷角上的 `room_mm` 也是
   **上界**，会顶到板边那一项。
3. `pad_width_mm` 是「走线离开焊盘处、垂直于走线的那条弦」的两倍（焊盘那里更窄
   时取走线宽），不是焊盘的外接尺寸。
4. `max_length_mm` 按 0.1 mm 步进 ⇒ 是真实上限的**下界**。
5. 只量铜：不算孔、不算丝印、不算阻焊，也不判「这个角该不该加泪滴」。

## 5. 四处被推翻的做法

1. **第一版把同网铜当障碍**：283 个角**全部** `room = −0.15`，`limited_by` 指向
   结点自己的走线和自己焊盘上的铜。根因是「取最近一件、再判断是不是同网」——
   最近的那一件正是泪滴长出来的那根线。改成按网过滤整个障碍集后变成
   283 个角里 251 个放得下。
2. **方向取自「焊盘质心 → 走线远端」**：一条停在离焊盘质心 0.0002 mm 处的走线，
   方向就是它自己的数值噪声（长度 0.0002，方向 (−1,0)），包络于是从焊盘**左边缘**
   长出去、横过隔壁焊盘。真板上最差 20 条里有 7 条是这种。改成走线自身方向。
3. **包络在焊盘那一端取「沿走线方向最远的点 + 焊盘在法向上的整个跨度」**：
   0.3×1.6 的焊盘 45° 引出时被读成 **1.6 mm 宽**（对角线），一整整排排针被判
   blocked。改成「中心线离开焊盘处的那条弦的一半」。
4. **两个端点都在焊盘里的 stub 被当成角**，而且「求不到交点」时回退到「沿走线
   方向最远点」：U1 的两个角因此把包络起点放到了自己焊盘**外面 0.4 mm**。
   现在远端必须在焊盘之外，回退用端点本身。修完这一处，blocked 从 24 降到 4。

四条都是「不崩、数字还很好看」那类：读数整整齐齐，全错。

## 6. 没有做的事

- **不画泪滴**、不选 curve、不给「该多长」的建议：`not_claimed` 明写这只是
  「这个角放得下这个形状、最长这么长」，不落到文件。
- 不判孔、丝印、阻焊；不算电气连接。
- 带外不算：只看这一个角的包络，不看整条线的观感。
- 只报告 `limit` 个角的 `max_length_mm`；其余角只给 `room_mm`（`limit` 是
  schema 里的参数，要全部就把它抬上去，代价是耗时线性上涨）。
