# RK3506 核心板：DDR 等长规则、优先级与实测余量

第 0.1.15 步。上一版把 `unconnected` 压到 10，但**从未按 DDR 的等长规则验过一次**——这一轮补上：规则写进代码（`edit/checks.py` 的 `track_lengths()` / `length_match()`，CLI 为 `tools/check_length.py`），并做了能做的加长（`tools/meander_som_length.py`）。结论先摆在这里：**三组差分对内已从 1.60/2.22/1.36 压到 1.60/1.95/0.94 mm，但没有一组进公差；能加的铜只有需求的 11%，原因是每条网被夹在 0.2 mm 节距的束里，蛇形没有落点——蛇形这条路在这块板上到此为止，要过公差必须整组重布。**

## 1. 规则与优先级（先满足高优先级）

| 优先 | 规则 | 组 | 判据（默认） | 为什么在这一级 |
|---|---|---|---|---|
| 1 | 差分对内 skew | DQS0P/N、DQS1P/N、CLKP/N | ≤ 0.25 mm | 同一 strobe 的 P/N 在接收端做差分判别，错位直接吃掉采样窗口，**任何情况下都不能牺牲** |
| 2 | 字节 lane 内 | DQ0-7+DM0 对 DQS0，DQ8-15+DM1 对 DQS1 | ≤ 0.50 mm | 同一 lane 的 DQ/DM 由同一 strobe 采样，lane 内错位就是建立/保持余量 |
| 3 | 地址/命令/控制 对 CLK | A0-14、BA0-2、CSN/RASN/CASN/WEN/CKE/ODT/RESET 对 CLKP | ≤ 1.00 mm | 命令与时钟在 DDR 内部同一拍锁存；这一组数量大、走得远，公差本来就宽一档 |
| 4 | 跨 lane | lane0 对 lane1 | 只报告，不设公差 | Byte lane 各自有 strobe，跨 lane 不需要等长；写在这里是为了防止有人拿「全局最长」当基准 |

三个公差都是 `length_match()` 的入参（`tol_pair` / `tol_lane` / `tol_cmd`），不是硬编码常量——换速率等级时改调用处，不用改算法。

**蛇形只能加长，不能缩短。** 所以每一组的基准都是**组内最长的那条网**：比基准长的网是「重布问题」，不是「蛇形问题」。这条写死在 `length_match()` 的 `note` 字段里，别读成实现细节。

## 2. 测量口径

`track_lengths()` 只累加 `(segment)` 的长度，**不把过孔算进去**。理由不是省事：镀铜孔壁的电气长度是板厚方向的过孔深度，把它当走线长度会让「多换层」这条捷径被算成「更长」，从而在等长里奖励最差的布线习惯。过孔单独计数（本板 DDR 网每条 2 个，ZQ 4 个、CKE/BA2/DQ10 3 个）。

同一口径下，`authoritative` 永远是 `false`：这是文件的测量，不是信号完整性判定。

## 4. 为什么加不进去：不是走廊被占满，是每条网被夹在 0.2 mm 的束里

先摆一条必须说清的实测，它废掉了「走廊太窄」这个直觉结论：

| 层 | DDR 走廊 `x 15..26 / y 16.5..22.6` 的铜覆盖率 |
|---|---|
| F.Cu | **7.4 %** |
| In2.Cu | 22.6 % |
| In4.Cu | 19.9 % |
| B.Cu | 22.7 % |

区域内 **77–93% 是空的**。所以「挤不下」不成立。真正卡住蛇形的是**局部**：现有走线在 0.1 mm 线宽 + 0.1 mm 间距下成束并行（节距 0.2 mm），贴着走线量垂直方向的可偏移量只剩 0.05–0.10 mm，而蛇形振幅至少要 0.12 mm 才有意义。换句话说：**空地在束外，蛇形必须把这条网先挪到空地上去——那是重布，不是加长。**

重布这一步现在的失败也是有数的：撕掉最长的 6 条网（CSN 33.0 / A3 31.9 / ZQ 31.8 / BA0 31.3 / A0 31.3 / WEN 31.2）重布 **6/6 REFUSED**，单条 DQ7 **1/1 REFUSED**，A8/A11 至今 **2/2 REFUSED**。`_mazeH.py` 是逐网贪心、无 rip-up、无长度目标的搜索：它一旦在某次顺序下占到一条通路就不再回头，所以「拒绝」只说明**这个搜索**找不到，不说明几何上无解（覆盖率已经证明有空地）。

结论要这么写：**当前板上等长未达成；成因是「每条网被夹在束里、蛇形没有落点」，解法是带长度目标、允许 rip-up 的整组重布，而不是继续在同一束里找齿位。** 那是一个新工具，不是这次能顺手补的。

## 5. 本轮落地的代码

- `src/pcb_agent_mcp/edit/checks.py`：`DDR_LANES` / `DDR_PAIRS` / `DDR_CMD` 常量，`track_lengths(doc, prefix="/DDR_")`，`length_match(doc, tol_pair, tol_lane, tol_cmd)` → 每组带 `status` ∈ ok/fail/unmeasurable 与 `needs_mm`。
- `tools/check_length.py`：把板文件喂进去，输出分组偏差表；`ok=false` 退出码 1。
- `tools/meander_som_length.py`：45° 梯形蛇形，只加不减；先找「净空回廊」（同一侧沿中心线 0.05 mm 步长采样，扣除 0.05 半宽 + 0.10 间距），再在回廊里铺齿，落笔前逐段对异网铜做 0.15 mm 间距校验；输出是 `delete_copper(net)` + 全部原段与蛇形段 `add_track` + 原过孔 `add_via`，一条网要么整条重写要么不动。
- `tools/copper_geo.py`：焊盘按真实形状建模（circle / oval / rect / roundrect），通孔按全 6 层算——`edit/checks.py` 的连通判断用的是同一套口径。
