# 145 · RK3506 核心板：从球表到网表（一球一网一主）

本批只做一件事：**把已经冻结的四张球/焊盘表合成唯一一张网表**，让"哪个脚在哪条网上"变成可审计的
数据，而不是画图时的记忆。零板改动、零封装改动、零布线。

```
tools/gen_netmap.py --examples examples/rk3506_som
balls 332, nets 174, terminals 593
classes ground 1, nc 11, power 9, signal 153
dropped: NX2012SA (32.768 kHz) - RK3506J has no dedicated 32 kHz pin: ...
```

> 口径：本工具 docstring 第一句是 `Nothing here is a route, a placement, or a copper decision.`
> 它不决定去耦电容、串联电阻、上下拉阻值、也不决定任何铜。它只回答"这个脚属于哪条网"。

## 2. 八条规则（每条都在生成时断言，任一不过 ⇒ 退出码 2 + 不写字节）

| 规则 | 内容 |
|---|---|
| **R1** | 每个 SoC 球恰好一条网，且每个球都被覆盖（球表 332 行 → 332 个 SoC 端，集合相等） |
| **R2** | DDR3L 是**同一个信号落在两侧**；两侧词表不同，靠**声明表**翻译，并审计"芯片信号脚必须全被表覆盖" |
| **R3** | 芯片侧：电源脚落轨、NC 脚各自成网、不许有剩下的脚 |
| **R4** | 邮票孔的网必须真有人提供；行上的球必须在球表里；**已被规则定死的球不许被邮票孔改名**；一个球不许出现在两个孔 |
| **R5** | 没有宿主脚的器件**丢弃并具名**，不许硬连到"看着像"的脚 |
| **R6** | 未被外引、也未被任何规则认领的信号球 ⇒ `NC_<球>`（具名声明），且若它被外引则拒绝 |
| **R7** | 每条轨都有产生端与负载端；`+5V_IN` 无产生端（来自邮票孔）；**`+0V675_REF` 必须正好是 `+1V35_DDR` 的一半** |
| **R8** | 一条网要两个端；`nc` / `internal` 网豁免，且**必须恰好只有自己那一个脚**（内部输出被芯片驱动，不许再挂驱动） |

R8 被抽成独立函数 `audit_net_ends(nets, terminals)`，正因为它要能被一小组玩具网表直接测（见 §6）。

### 2.1 为什么 R2 必须是声明表

同一根线两侧叫不同名字：

| SoC 侧（Table 2-1 的多功能名） | 芯片侧（MT41K256M16 的脚名） |
|---|---|
| `DDR3_A10` | `A10/AP` |
| `DDR3_A12` | `A12/BC#` |
| `DDR2_RASN/DDR3_A10` | `RAS#` / `CAS#` / `WE#` / `CS#` |
| `DDR3_CLKP` / `DDR3_CLKN` | `CK` / `CK#` |
| `DDR3_DQS0P` / `DQS0N` / `DQS1P` / `DQS1N` | `LDQS` / `LDQS#` / `UDQS` / `UDQS#` |
| `DDR3_DM0` / `DM1` | `LDM` / `UDM` |
| `DDR3_RZQ` | `ZQ` |
| `DDR_VREF_CA` / `VREF_DQ` | `VREFCA` / `VREFDQ` |

模糊匹配（去掉 `#`、大小写归一）在这张表上必然会**漏 `DQS1P→UDQS`、串 `LDQS↔UDQS`**；
而声明表 + "芯片信号脚未被表覆盖即报错" 这一条，才抓得住 0.1.1 修过的那处真错
（手册 `DQ1=Y12` / `DQ11=Y3` 写反过一次，重解析后是 `DQ1=F7` / `DQ11=C2`）。

## 3. 五处设计判断（都不是"顺手连上"）

### 3.1 32.768 kHz 晶振：没有宿主脚 ⇒ 丢弃并具名

手册 p8 写 "One internal low frequency RC clock"、"Support single-end 32.768KHz clock input/output from/to GPIO"；
p34 Interface 表里 `CLK_32K` 是 **I/O，走 GPIO 复用（`RM_IO14`）**。`RM_IO14` 落在球 **N3**
（`SAI1_SDO2/SPI1_CSN0/RM_IO14/GPIO0_B6_d`），而 N3 在 0.1.2 已被外引为 **SPI1_CSN0（邮票孔 123）**。

⇒ **RK3506J 没有专用 32 K 引脚**；为一个 RTC 精度放弃一条外引 SPI 片选不值，且核心板无 RTC 芯片。
器件与封装/符号留在 `lib/`，本设计**不画、不连**，`dropped_parts` 里具名并写清依据。

### 3.2 A15：4 Gb x16 颗粒没有这个焊盘

MT41K256M16 符号实测 96 个脚名里 **A0–A14、没有 A15**（`A0..A14` + `BA0..2` + `DQ0..15`
+ `LDQS/LDQS#/UDQS/UDQS#` + `LDM/UDM` + `CK/CK#` + `CS#/RAS#/CAS#/WE#/CKE/ODT/RESET#`
+ `VDD/VDDQ/VSS/VSSQ/VREFCA/VREFDQ/ZQ` + 5 个 `NC`）。SoC 侧 A15 球是 `Y17` ⇒ 落 **`NC_Y17`**。
声明表里也**删掉了 `A15`**，并用一条审计反向看住：`DDR_SOC_NO_CHIP_PIN` 声明的符号不许再出现在映射值里。

### 3.3 VREF 是轨，不是两条新网

docs/144 的 `+0V675_REF` 本来就记了 **2 个球**（`1L10`/`1L11`）与 1 %/1k 分压。若把
`DDR_VREF_CA`/`DDR_VREF_DQ` 当两条独立网，那条轨就没有负载端、与已冻结的轨表自相矛盾。
⇒ SoC 侧 VREF 球与芯片侧 `VREFCA/VREFDQ` **全部归到 `+0V675_REF`**（共 5 端：SoC 2 + DDR 2 + 分压 1），
并把"必须正好一半"从纸面变成本批的 R7 硬门禁（0.675 对 1.35/2 差 ≤ 5 mV）。

### 3.4 RZQ 是信号，不是电源

`DDR3_RZQ`（球 `L8`）↔ 芯片 `ZQ`（脚 `L8`）成一条 `DDR_ZQ`，两端各一。1 % 电阻**值未定**，
所以 note 写 "1 % resistor to GND, value later"——**不给数**。

### 3.5 芯片的 5 个 NC 脚各自成网

`NC_DDR_J1 / J9 / L1 / L9 / M7`，class `nc`，恰好各 1 端。它们不是"随便空着"，
而是把"这个焊盘不接"写进数据 —— 有人把它们连起来一次，R8 就会报 3 端以上。

## 4. 板材侧的两条口径

1. **`5V_IN`/`3V3_OUT`/`GND` 是 0.1.2 冻下来的邮票孔网名，早于轨名** ⇒ `RAIL_ALIASES` 是**唯一**做
   词表归一的地方；信号名**不做别名**（邮票孔上的名字就是板级契约，网表就用它）。
2. **邮票孔 140 个端落在 98 条网上**：GND 行球是空的（一个地孔不属于某一个 VSS 球），
   `+5V_IN`/`+3V3` 同理，所以 R4 对"空球"不做球校验，只做"这条网有人提供"。

## 5. SY8113BADC 的外部取证（只补了能的，缺的照旧留空）

上一批（docs/144 §6.4）记 "Vref / fsw / ILIM 不在本仓库 ⇒ 电感与分压留空"。本批从分销页三方
一致取到两条，仍缺一条：

| 参数 | 值 | 来源 |
|---|---|---|
| Vref | **0.6 V ±1.5 %** | zweiic / hqew / eeworld / manychip 四处一致 |
| fsw | **500 kHz** | 同上 |
| Iout | 3 A（Vin 4.5–18 V，TSOT23-6，同步整流 80/40 mΩ） | 同上 |
| **ILIM** | **仍未取到**（只核到"逐周期峰值限流"这一句） | `datasheet.eeworld.com.cn` 与 `hqew` 的 PDF 页 fetch 均失败 |

⇒ FB 分压与电感**现在可以算**，但"限流余量"这一项仍**留空并具名**，不拿 3 A 当 ILIM。

正向 11 条（规模、全球覆盖、无单端网、A15、DDR 逐对、VREF 归轨、ZQ、三条外引轨、十条轨存在、丢弃件、
接收侧三器件）；反向 **22 条**，每条都靠**改表**触发一个具体审计；另有 5 条工具自身的单元测试。

| # | 故意破坏 | 期望的拒绝 |

| 3 | 从映射表删掉 `A11` | `is not in DDR_SOC_TO_CHIP` |
| 4 | 映射表把两 token 映到同一值 | `maps two SoC tokens onto` |
| 5 | 把 `A15` 加回映射表 | `has no chip pin` |
| 6 | 把 DDR 球外引到邮票孔 | `the DDR bus stays on the board` |
| 7 | 给被规则定死的球改名 | `by rule` |
| 8 | 一个球出现在两个孔 | `one ball, one hole` |
| 9 | 邮票孔球不在球表里 | `pinmap_rk3506j.csv does not have` + `no SoC pin provides` |
| 10 | 晶振球被外引成别的名字 | `the pin name decides` |

| 19 | DDR 信号指到不存在的球 | `pinmap has no such ball` |

### 6.1 一条自纠错记录（写下来防复发）

初版把"邮票孔说网 X 但球在网 Y" 写成拿 `stamp_nets[ball]` 去比 `row["net"]` —— **两边同源，永远相等**，
是条永远为真的检查。改成"用**球/引脚名**规则先定出该球的网，再要求邮票孔行与它一致"之后，
这条才真的能拒绝（测试 7、10 就是拿它做反向对照的）。

## 7. 验证与不声称

**验证**：`python tools/gen_netmap.py` 退出码 0、两个 CSV 落盘（174 + 593 行）；
`python -m unittest discover -s tests -p "test_netmap.py"` **38/38 通过**（0.9 s）。
KiCad 未参与本批（本批不产生 KiCad 文件）。

**不声称**：

- 不声称网表**空间上可实现**（飞线/交叉/层分布一概没看）；
- 不声称手册解析出的**每个球名**都对——332 个球名是 0.1.1 重解析产物，本批只校验
  "规约之间自洽"，不重读 PDF；
- 不声称 `load_ma` 与 `+0V675_REF` 分压电阻**值**已定（前者 design value，后者只查定义）；
- 不声称 ILIM 已知（见 §5）。

## 9. 欠账

- `src/pcb_agent_mcp/parts.py` 的 `footprint_to_kicad()` 仍直接采信 CANVAS 声明单位（连续第四批）；
- 手册 32.768 kHz 走 `RM_IO14` 这条线是"没有专用引脚"的判断依据，**不是**"不能用 32 K"的证明；
- `+5V_IN` 与 `+3V3` 的孔位（42–45 / 107–110）里没有球，意味着"这几个孔并联"由铜负责，本批不画铜。
