# 51 · 重复脉冲降额：一阶 ODE 的精确解，不是一张 I²t 表

`fusing_current` 回答的是「一发」。可是板子上的电流几乎从来不是一发：MOSFET 的短路保护
动作前有几十微秒的大电流，继电器触点弹跳、电机启动、容性负载上电、LED 驱动、脉冲电镀——
它们都是**一列车**，每发之间还留了时间让铜散热。工程上问的是两件事：

1. 这列车能不能**一直**跑下去？（不能的话，跑到第几发就熔？）
2. 若某个电流已经跑不下去，**占空比降到多少**才跑得下去？

`repetitive_pulse_rating` 就是这两问。它不查表、不套 I²t 经验式，解的是一个一阶 ODE 的
**每段精确解**，参数只来自铜自己的物性和你给的 `h`。

## 51.1 模型：一行 ODE，四行推导

按单位长度写（`w` 宽、`t` 厚，`A = w·t`、`P = 2(w+t)`）：

```
C' dT/dt = I² ρ'(T) − h·P·(T − Ta)
ρ'(T)    = ρ20 (234 + T)/(234 + 20)      ← 与 Onderdonk 的 234 同一个数
C'       = ρ_m c_p A
```

因为 ρ 对 T 是**线性**的，令 ΔT = T − Ta 后方程也是线性的：

```
d(ΔT)/dt = A₀ + k·ΔT
A₀ = I² ρ'(Ta)/(A·C')        β = 1/(234 + Ta)
k  = A₀β − 1/τ               τ = C'/(h·P)
```

于是**每一段**（导通段、关断段）都有精确解，不是步进：

```
ΔT(t) = (ΔT₀ + A₀/k)·e^{k t} − A₀/k
```

关断段的 `A₀ = 0`，解就是 `ΔT₀·e^{−t/τ}`。铁律是「精度不靠小步长」：这个模型里没有
`dt`。

常数（同一份，散在 `calc/current.py` 里并逐条在测试中重写一遍）：
`ρ20 = 1.72e-8 Ω·m`、`ρ_m = 8960 kg/m³`、`c_p = 385 J/(kg·K)`、熔点 `1083 °C`、
参考 `234`。**没有一个是拟合出来的**。

## 51.2 失控判据是闭式的，而且不含热容

「每发结束都比上一发开始时更热」⟺ `k·t_on ≥ t_off/τ`，展开后

```
I² ≥ A·h·P / (D·β·ρ'(Ta))          D = t_on/(t_on + t_off)
```

注意左边**没有 C'**——这是两个**速率**的比较（加热速率 vs 散热速率），不是能量比较。
所以

```
max_repetitive_current_a = √( A·h·P / (D·β·ρ'(Ta)) )
```

就是工具返回的 `value`：**这列车能永远跑下去的最大电流**。反解同一个边界得到「给定电流下
的占空比上限」：

```
max_duty_cycle_at_current = 1/(1 + k·τ)          (k > 0 时)
```

1 mm / 1 oz / Ta=25 °C / h=10 时：`τ = 5.800448396 s`，`k = 0.23283506112263327`，
`kτ = 1.3505477567806592`，`1/(1+kτ) = 0.42543275162790695`。工具报 `0.425433`。

## 51.3 两段映射与几何级数：发数也是闭式

设 `e_on = e^{k t_on}`、`e_off = e^{−t_off/τ}`、`q = e_on·e_off`、`b = (A₀/k)(e_on − 1)·e_off`。
第 m 发的谷值（每发开始前的温度）

```
trough(m) = b (q^m − 1)/(q − 1)        （收敛/发散是同一个式子）
steady_trough = b/(1 − q)              （q < 1 时）
```

熔化发数：把熔点代进去反解 m：

```
u   = (ΔT_melt + A₀/k)/e_on − A₀/k
arg = 1 + u(q − 1)/b
arg ≤ 0        → 序列整体到不了熔点 ⇒ shots = None（"永远不熔"）
|q − 1|<1e-12  → 线性极限 m = u/b
否则           → m = ln(arg)/ln q ,  shots = ceil(m) + 1
```

`pulses_to_melt = None` 时输出 `survives_indefinitely: true`——**"永远"不是一个计数**，
所以不报一个大整数。

## 51.4 三条内建闸门（失败即 `INTERNAL_CHECK_FAILED`）

| 闸门 | 挡什么 | 实测 |
|---|---|---|
| 绝热极限必须复现 Onderdonk（差 >2 % 报错） | `ρ20 / ρ_m / c_p` 漂移，模型就成了沙上城堡 | **−0.6156 %** |
| 3 步逐圈映射 = 几何级数 | 级数符号错、`e^{kt}` 写反 | 相对 1e-9 |
| 熔化发数逐发回溯 | 发数 off-by-one | shots ≤ 2000 时逐发步进 |

第一条最值钱：它是**两条互不共享常数的路线**——我们的路线是 `ρ20, ρ_m, c_p`，Onderdonk 的
是那个 `33`。两条独立算出的熔断时间对上了，才说明「解的是同一件物理」。

`h = 0` 就是绝热极限本身，此时 `value = 0 A`（没有任何电流能永远跑下去），
`no_cooling` 说明为什么；只报发数有意义：5 A / 1 mm / 1 oz / 1 ms / D=0.1 → 4014 发，
总导通时间 **4.014 s**，与 `fusing_current(width=1, t_s=4.014) = 5.015 A` 互为验证
（差 0.3 %，来自 Onderdonk 的等面积矩形假设）。

## 51.5 基准算例（全部实测，先量后写）

`repetitive_pulse_rating(1.0 mm, 1 ms, duty=0.1, h=10, current=5 A)`：

| 键 | 值 |
|---|---|
| `max_repetitive_current_a` | 10.313011 |
| `single_pulse_fusing_current_a` | 317.727834 |
| `derating_vs_single_pulse` | 0.032459 |
| `thermal_time_constant_s` | 5.800448396 |
| `time_constant_over_period` | 580.04484 |
| `steady_peak_c / trough / ripple` | 104.648 / 104.525 / 0.123 |
| `steady_mean_rise_c` | 79.586 |
| `dc_equivalent_current_a` | 1.581139（= 5·√0.1） |
| `max_duty_cycle_at_current` | 0.425433 |
| `adiabatic_limit_reproduced_pct` | −0.6156 |

**降额倍数有多狠**：同一根线，单发熔断电流 318 A，而占空比 10 % 的列车只允许 10.3 A
（`derating_vs_single_pulse = 3.2 %`）。这个数不是耸人听闻——它只是说明「单发」从来不
是「列车」的近似。

| duty | 0.1 | 0.25 | 0.5 | 1.0 |
|---|---|---|---|---|
| `max_repetitive_current_a`（1 mm/1 oz/h=10） | 10.313 | 6.523 | 4.612 | 3.261 |
| `time_constant_over_period` | 580.0 | 1450.1 | 2900.2 | 5800.4 |

`I ∝ 1/√D` 在这四列上逐位成立（10.313/√2.5 = 6.523）。

**宽度扫描**（D=0.1）：0.2 mm → 2.197 A，`τ = 5.113 s`；0.5 mm → 5.242 A；2.0 mm → 20.452 A。
`τ` 几乎不随宽度变（5.11 → 5.90 s），因为 `C' ∝ A`、`hP ∝ 2(w+t)`，`τ = ρ_m c_p A/(2h(w+t))`
在 `w ≫ t` 时趋近 `ρ_m c_p t/(2h)`——**薄的线热得快也冷得快，而厚的线两头都慢**。

## 51.6 `dc_equivalent_current_a`：一条能失败的恒等式

同一份冷却、同一个**平均**温升下，直流要高多少？

```
能量平衡：I²ρ'(Ta)·D = I_eq²·ρ'(Ta)   ⇒   I_eq = I·√D
```

工具里它是用逐周期中点积分算出的平均温升反解的（不走 √D），实测
`1.581139` 对 `5·√0.1 = 1.5811388`——**1e-7 级对上**。这条恒等式会失败，只要平均温升的口径
（中点积分、`ρ'(Ta)(1+βΔT)` 的线性化）任何一处偏了。

它是这个工具**唯一**该跟 `current_capacity`（IPC-2152 的 ΔT=10 K 额定值）对照的数。工具
在给 `standard` 时会一并给出 `continuous_rating.repetitive_over_continuous`，并在 `note` 里
写死：**那不是安全余量，连判据都不同**——一个是「跑到熔点」，一个是「升 10 K」。

## 51.7 h 是你猜的那个数，所以把它摊开

`h` 不给默认值（与 0.0.46 拒绝 TIM 表同型：冷却本身就是答案，裸板静风 ~10 W/(m²·K) 到
铜皮锁在金属壳上的数百，差 20 倍，猜一个就是给错答案）。给了之后，工具**同时**报
`h/2` 和 `2h` 下的稳态峰值：

| h | 稳态峰值 |
|---|---|
| h/2 = 5 | 254.869 °C |
| h = 10 | 104.648 °C |
| 2h = 20 | 59.547 °C |

`h_sensitivity = "halving/doubling h moves the steady peak by 245 % of its own rise"`。
这不是精度声明，是**归因**：答案的不确定度几乎全在这一个数上，不在模型里。

## 51.8 「失控」是存在问题，不是温度问题

一个容易读错的地方：略低于阈值的电流**有**稳态解，但那解可能远高于熔点。10.30 A
（阈值 10.313011）的稳态峰值是 **102560 °C**——它当然会熔（`pulses_to_melt = 2386`），
但 `runs_away = false`，因为「每发都比上一发开始时更热」这件事还没发生。10.32 A 则
`runs_away = true`、**没有**稳态解（`steady_peak_c` 这个键根本不出现）。

所以：

- `survives_indefinitely` = 有稳态解 **且** 稳态峰值低于熔点；
- `runs_away` = `k·t_on ≥ t_off/τ`，一个纯代数的存在性判断。

这一条是自检里专门盯着的（见 `--selftest` 第 169 组），因为把「无解」报成「很热的解」是
最容易悄悄发生的一类错。

## 51.9 一条实测抓到的缺陷：q→1 时的相消

临界点附近 `q − 1 ~ 1e-10`，闸门 2 原来用

```
(q³ − 1)/(q − 1)
```

算三步级数，两个近乎相等的数相减，**有效数字掉了七八位**，于是「幂等的两条路线」报出
`1.33851 vs 1.33851` 这种「看起来一样却过不了 1e-9」的结果，把一次正确计算判成了
`INTERNAL_CHECK_FAILED`。修法是代数分解：

```
(q³ − 1)/(q − 1) = 1 + q + q²        ← 精确，无相消
```

这个坑值得记：**闸门本身也要在它要判的边界上被验证**。收敛区中部 `q = 0.9987` 时旧式子
毫无问题，是边界才把它逼出来。

## 51.11 独立真值：一个 RK4 积分器

测试里有一个**从头写的 RK4**（`tests/test_pulse_fusing.py::_rk4_train`），它：

- 直接积原始 ODE，`ρ(T)` 就写 `ρ20(234+T)/254`；
- 导通段与关断段是**两个不同的右端**（关断段没有 `I²`——这一条我把第一次写的 RK4 写错过，
  它让关断段继续加热，结果稳态温度错了 10 倍）；
- 完全不知道几何级数、不知道 `q`、不知道 `shots`。

在 12 A 上它给出 **1191 发**，闭式给 **1191 发**；在 5 A 上它给出稳态峰值 **104.5246 °C**，
闭式 **104.525 °C**。0.2 mm / 400 A 上两者都给 **1 发**。这是本文件最强的那条断言：它与
被测实现**不共享一行代数**。

## 51.12 与 `fusing_current` 的分工

| | `fusing_current` | `repetitive_pulse_rating` |
|---|---|---|
| 问的是 | 一发熔断 | 一列车能不能一直跑 / 跑到第几发 |
| 冷却 | 无（绝热） | `h·P`，`h` 由你给 |
| 判据 | 熔点 | 失控（速率平衡）+ 熔点 |
| 时间上限 | ~10 s 后无意义 | 任意（由 τ/period 定） |
| 互校 | — | `h = 0` 时两者给出同一个总导通时间 |
