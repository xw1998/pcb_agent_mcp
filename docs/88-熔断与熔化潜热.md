# 88 · 熔断电流与熔化潜热

`fusing_current` 自 0.0.x 起算的是 Onderdonk（1928）：

```
I = A_cmil · sqrt( log10( (1083 − Ta)/(234 + Ta) + 1 ) / (33·t) )
```

这个式子回答的问题是「**多长时间能把铜加热到 1083 °C**」。它不是一个熔断判据——
铜到了 1083 °C 还没熔，它要先**吸收熔化潜热**才换相。原来文档里对这件事只有一句话：

> Blowing apart takes a little more.

「a little more」不是工程数字，而且用在这里措辞也不对：本文第 3 节量出来的
是 **I²t +25.3 %、电流 +11.9 %**（25 °C 环境）。一个 12 % 的电流差在选保险丝、
选走线宽度时不是小数。本篇把它做成闭式、可手算、可被独立积分校验的一条修正，
默认**关**（`melting_model="sensible"`），让以前打印的熔断表逐位复现。

工具数**仍 180**（本版只加参数、不新增工具），`dependencies = []` 仍成立。

---

## 1. 模型

绝热、单一材料、一维热流。`c` 比热、`ρ_m` 密度、`L_f` 熔化潜热、`ρ(T)` 电阻率：

```
c·ρ_m·A·dT/dt = I²·ρ(T)          ρ(T) = ρ20·(234+T)/(234+Ta)
```

`(234+T)` 那一项就是 Onderdonk 里 234 的来源；把它积到熔点，得到

```
(I²t)_sensible = (c·ρ_m·A²/ρ20)·(234+Ta)·ln( (234+Tm)/(234+Ta) )
```

到了 `Tm` 温度不再上升，功率全部转成潜热吸收：

```
(I²t)_latent = ρ_m·L_f·A²/ρ(Tm)
```

两者相除，**几何、面积、`ρ20` 全部消掉**：

```
β ≡ latent/sensible = L_f / ( c·(234+Tm)·ln(ratio) )
ratio = (Tm − Ta)/(234 + Ta) + 1 = (234+Tm)/(234+Ta)
```

`I²t` 是被能量平衡钉死的量，所以电流按**平方根**动：

```
I_melt = I_onderdonk · sqrt(1 + β)
```

代码：`calc/current.py` 的 `latent_heat_share_of_i2t(t_ambient_c)` 与
`fusing_current(..., melting_model=...)`。

## 2. 为什么不是 `L_f/(c·ΔT)`（这是最容易错的一步）

教科书的「热质」写法是 `L_f/(c·ΔT) = 208700/(385·1058) = 0.512361`。它给出 `I²t +51 %`。
**这个答案是错的，而且错得可解释**：它假设潜热阶段和显热阶段付同样的功率。

实际上最后一段是在 `ρ(1083)/ρ(25) = (234+1083)/(234+25) = 5.0849` 倍冷态功率下走完的。
潜热阶段站在**最热的那个点**上，所以它**按时间便宜、按能量昂贵**。相除的结果是

```
β/naive = (234+Tm)·ln(ratio)/(Tm − Ta) = 2.0244
```

即 `β = 0.512361/2.0244 = 0.253093`。第 6 节的独立积分和第 7 节的负控制都在打这一条：
如果实现里漏了 `ρ(Tm)/ρ(Ta)`，0.253 会变成 0.512，比值会变成 1.0。

## 3. 冻结数字（Ta 五个点）

`c = 385 J/(kg·K)`、`L_f = 208700 J/kg`、`Tm = 1083 °C`、`REF = 234`：

| Ta (°C) | ratio | ln(ratio) | β | I²t 倍数 | 电流倍数 |
|---|---|---|---|---|---|
| 0 | 5.628205 | 1.727791 | 0.238224 | 1.238224 | 1.112755 |
| **25** | **5.084942** | **1.626284** | **0.253093** | **1.253093** | **1.119416** |
| 50 | 4.637324 | 1.534137 | 0.268294 | 1.268294 | 1.126186 |
| 85 | 4.128527 | 1.417921 | 0.290285 | 1.290285 | 1.135907 |
| 100 | 3.943114 | 1.371971 | 0.300007 | 1.300007 | 1.140178 |

环境越热，**潜热占比越大**（显热份额变小），这反直觉但是对的：`β ∝ 1/ln(ratio)`，
而 `ratio` 随 `Ta` 上升而下降。

加权的四个算例（宽 × 铜厚 × 时间 → 两个电流）：

| 算例 | `sensible` | `sensible_plus_latent` |
|---|---|---|
| 0.5 mm, 1 oz, 1 s | **5.024 A** | **5.624 A** |
| 1.0 mm, 1 oz, 1 s | 10.047 A | 11.247 A |
| 0.2 mm, 1 oz, 10 ms | 20.095 A | 22.495 A |
| 2.0 mm, 2 oz, 10 s | 12.709 A | 14.227 A |

`I²t` 比恰为 `1+β`、电流比恰为 `sqrt(1+β)`（测试里按未取整的键核到 1e-6 相对误差，
因为对外报的电流是 1e-6 A 取整的）。

## 4. 稳态那一半也跟着动，但只动一个数

带 `standard="ipc2152"` 时 `steady_rating.adiabatic_melt_time_at_capacity_s` 是
「在这个连续额定电流下、绝热地多久熔穿」。`I²t` 钉死 ⇒ 时间乘 `(1+β)`，电流不动：

| | `sensible` | `sensible_plus_latent` |
|---|---|---|
| `capacity_a` | 1.404 A | 1.404 A（不动） |
| `fuse_over_capacity` | 3.578 | 4.005 |
| 熔穿时间 | **12.803135 s** | **16.043515 s** |

`12.803135` 是 0.0.85 及以前打印的值——**默认路径必须一字不差**。

开发中这里抓到一个真 bug：第一版把 `(1+β)` 无条件写进 `melt_at_cap_s`，
于是两个模型都打印 `16.043515`。数字看着对、`status` 是 `ok`，但**它悄悄把
「按熔点判」的答案换成了「按熔穿判」的答案**。修法是让系数跟着 `melting_model` 走。
这条只能靠「默认路径逐位不变」这条检查发现，因为单看一个模型，两个数都自洽。

## 5. 另外两个熔断工具仍然只算到熔点（登记，不静默）

`repetitive_pulse_rating`（脉冲串，集总温度 + 闭式熔界）与 `fusing_current_taper`
（沿长度逐段等温节点、后向 Euler）都还在 1083 °C 收手。把它们改对**不是一个标量乘法**：
潜热阶段需要给每个节点加一个 `0..L_f` 的焓状态，光滑 ODE 就变成切换系统。
所以本版的处理是：

- 在 `calc_capabilities.not_implemented_yet` 里新增一条 **「Melting, by name」**，
  写明这两个模型打印的熔断时间是「到达 1083 °C 的时间」，比熔穿时间**短 20.2 %**
  （0 °C 短 19.2 %、100 °C 短 23.1 %），以及为什么改对需要焓状态；
- 把「把潜热折算成一个温度偏移」这条**拒绝掉**——那正是本文禁止的那种静默近似。

## 6. 独立校验：RK4 直接积分同一条 ODE

不用分离变量、不复用闭式。数值上按物理量纲积一遍：`dT/dt = k(234+T)`（RK4），
记下到达 `Tm` 的时间；潜热阶段 `dL/dt = k(234+Tm)`，`L` 到 `L_f/c` 收手
（均质化后单位是 K 当量，`k` 是任取的尺度，在比值里消掉）。每段 200000 步。

| Ta (°C) | β_RK4 | β_闭式 | 相对 | t_sens (s) | t_lat (s) |
|---|---|---|---|---|---|
| 0 | 0.238223631682 | 0.238223631682 | 1.8e-12 | 81086.3 | 19316.7 |
| 25 | 0.253092718970 | 0.253092718970 | 2.6e-15 | 84476.6 | 21380.4 |
| 50 | 0.268294437783 | 0.268294437784 | 1.5e-12 | 87382.2 | 23444.2 |
| 85 | 0.290284624241 | 0.290284624243 | 4.9e-12 | 90715.8 | 26333.4 |
| 100 | 0.300006804552 | 0.300006804551 | 2.6e-12 | 91903.4 | 27571.6 |

（绝对时间没有意义——`I = 1 A`、`A = 1 mm²` 是任取的；有意义的是比值。）
测试 `tests/test_fusing_latent.py::TestIndependentIntegration` 里跑的是缩水版
（60000 步，判据 `< 1e-8`），并配一条负控制：把潜热阶段的 `ρ(Tm)` 换成 `ρ(Ta)`
会让 β 大 5 倍以上，所以这条校验**能失败**。

## 7. 与 Onderdonk 常数 33 的一致性（这条决定了 `c` 取 385 而不是 400）

Onderdonk 是拟合式，它隐含地说「铜的 `c·ρ_m/ρ20` 是这个值」。把两侧在 **25 °C** 对齐：

```
c·ρ_m·(234+25)/ρ20  =?  1/(CMIL²·33·ln10)
```

- `c=385`、`ρ_m=8960`、`ρ20=1.72e-8` ⇒ 左 `5.194456e16`，右 `5.125730e16`，**差 +1.34 %**
- `ρ20=1.68e-8` ⇒ `5.318133e16`，差 **+3.75 %**
- 反解让等式精确的 `ρ20 = 1.7431e-8 Ω·m`

**这就是把 `c` 定在 385 而不是 400 的依据**：400 会把左式推到 `+5.3 %`，与 Onderdonk
自己的 33 打架。注意这个恒等式**只在 25 °C 定义**——在其它温度上它本来就不成立
（0 °C 差 −8.4 %、100 °C 差 +30.7 %），所以测试里专门有一条负控制：
「在 0/50/100 °C 上这个检查**必须不平**」，否则它就没有分辨力、会在常数写错时也通过。

## 9. 同轴圆盘（极化级数）这条路为什么作废

先做的是「圆板上放同轴圆盘源」，`z=t` 等温，用 `J0` 的 Dini 基：

```
R = 1/(k·π·R²·A_s²) · Σ_m I_m² φ_m / J0(β_m)² ,  I_m = 2π·R·a·J1(β_m·a/R)
β_m = J1 的零点
```

整板极限（`a = R`，只剩 `m=0` 项）**逐位精确**：`R = t/(kπR²) = 0.06366197723675814`，
手算相同。但部分和**对数发散**（5 mm 板、1 mm 厚、a = 2 mm、k = 200，
物理上界 `0.39788735773`）：

| terms | R (K/W) | 与上界之比 |
|---|---|---|
| 100 | 15.499606962319 | 39× |
| 400 | 19.875190673392 | 50× |
| 800 | 22.067574739857 | 55× |
| 1600 | 24.261116583130 | 61× |
| 2400 | 25.544548217302 | 64× |
| 3200 | 26.455238543509 | 66× |

逐项衰减实测是 **1/m**（m=200 → `6.486e-3`、m=400 → `3.253e-3`，恰好减半），
解析上也能对上：`I_m ~ β^(−1/2)`、源面平均 `⟨J0⟩ ~ β^(−3/2)`、`f ~ R/β`
⇒ 通项 `~4.09/β`，`Σ 1/β` 发散。

**结论：不入库，也不做发散级数的外推。** 一个"多取几项就收敛"的说法在这里是假的。
替代路线已经推导但**未实施**：矩形板上放**同心**圆形/环形源，用二维余弦基，
`I_mn = c_m·c_n·π·a·[J1(k1·a)/k1 + J1(k2·a)/k2]`（`c_m = cos(mπ/2)`，奇数 `m,n` 全零；
`k2` 为虚时换 `I1`），衰减 `~k^(−3)` 绝对收敛；只限同心（偏心要 cos/sin 混合，
不是初等闭式）。它要 3-D FVM 独立验证才能入库，登记为后续候选。

## 收尾：这一轮改了什么

- `calc/current.py`：常量 `COPPER_CP_J_PER_KGK = 385` / `COPPER_LATENT_HEAT_J_PER_KG = 208700` /
  `COPPER_DENSITY_KG_M3` / `COPPER_RHO20_OHM_M` / `M2_PER_CMIL`；新函数
  `latent_heat_share_of_i2t()`；`fusing_current(..., melting_model="sensible")`，
  两个模型的电流、`melt_at_cap_s` 的系数、`model` / `basis` / `precision` / `assumptions` 分支。
- `tools.py`：`fusing_current` 的 schema 加 `melting_model`（enum 两项 + 三档温度下的百分比），
  handler 透传；`fusing_current` 与覆盖范围两处「no latent heat」改成**量化**的
  `+25.3 % I²t / +11.9 % 电流`；`not_implemented_yet` 新增「Melting, by name」条。
- `server.py`：自检 `860/861/862` 三条（默认逐位不变 + `sqrt(1+β)`；稳态熔穿时间按系数走；
  β 五点 + 33 一致性 + 负控制 `naive/β = 2.0244`），**311 → 314**。
- `tests/test_fusing_latent.py`：**28 例**，含三条能失败的负控制（naive 热质 / 33 只在 25 °C
  / 积分器的初值猜错）与一条独立 RK4 积分。

**仍未做**：`repetitive_pulse_rating` 与 `fusing_current_taper` 的潜热阶段（要焓状态，
是切换系统）；同心圆/环源（第 9 节，收敛但未实施）；熔化后的体积变化与熔流；
焊点的合金化/金属间化合物。
