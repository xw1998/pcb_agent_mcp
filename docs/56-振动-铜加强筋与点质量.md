# 56 · 振动：铜加强筋与点质量

0.0.52 的 `calc_capabilities.not_implemented_yet` 第 19 条自己写着：

> no component mass or copper stiffening (so f1 reads high on a board with one heavy part)

这是剩下的条目里**唯一仍可纯闭式解决**的一条（其余 18 条要么要工艺数据、要么要硬件、要么要付费
标准、要么结构上不做）。所以 0.0.53 做掉它，做法是给 `vibration_plate_modes` 加三个参数：
`copper_um`（双面对称铜皮，µm/面）、`added_mass_g` 与 `added_mass_at_mm`（一个点质量，默认板心）。

一句话结论：**铜和点质量都能塞进同一个 Ritz 求解，不用换解法**——铜是"每层各带各的 E 和 ν 的
变换截面"，点质量是"质量矩阵上的一次秩一更新"，后者有闭式平方根所以不用迭代、也不用单模截断。
两件事都**默认关**，两个都不给时每个数字与 0.0.52 逐位相同。

## 56.1 模型

### 铜：变换截面（transformed section）

对称双面铜皮 ⇒ 中性轴仍在板中面，所以只需要一组 D，不需要膜-弯耦合项：

    D11 = Σ_i  E_i/(1−ν_i²)   · ∫ z² dz      （含层压板 + 两块铜皮）
    D12 = Σ_i  ν_i E_i/(1−ν_i²) · ∫ z² dz
    D66 = Σ_i  E_i/(2(1+ν_i))  · ∫ z² dz

铜皮的厚度积分用 `iz_cu = ((h/2+t)³ − (h/2)³)/3`（`∫_{h/2}^{h/2+t} z² dz`），单面，两面对称相乘 2。
质量面密度同时变大：`mpa = ρh + 2·ρ_cu·t`。

铜的常数取轧制/电解铜箔的手册值：`E_CU = 110 GPa`、`NU_CU = 0.34`、`RHO_CU = 8960 kg/m³`。
（板上的**电镀**铜更软，退火后 60~90 GPa，镀桶壁根本不是箔——这里是外层箔片，而加强量只按
`√E` 走，所以更软的铜改的是几个百分点，不是一个倍数。这条写在 `E_CU` 的注释里。）

刚度装配写成展开式，逐项对应上面三个 D：

    stiff += d11·T_xx + d22·T_yy + d12·T_mix + 2·d66·T_tw
    T_xx = I2x·M0y/a⁴      T_yy = M0x·I2y/b⁴
    T_mix = (ICx·I1y + I1x·ICy)/(a²b²)      T_tw = 2·D1x·D1y/(a²b²)

各向同性时（`d22 = d11`、`d12 = ν·d11`、`2·d66 = (1−ν)·d11`）它与旧式
`D·[T_xx + T_yy + ν·T_mix + (1−ν)·T_tw]` **逐项同值**，所以默认路径直接保留旧式那几行不换实现。

### 形状为什么不变

每一层各自满足 `E_i/(1−ν_i²) − 2·E_i/(2(1+ν_i)) = ν_i E_i/(1−ν_i²)`（代数恒等），加权求和也满足：

    d12/d11 = 1 − 2·d66/d11  ≡  ν_eff

于是三个 D 退化成一个有效 ν 乘 d11，**模态形状一点不动**，`f ∝ √(D11/mpa)` 是精确关系（不是近似）。
实测 1 oz：`800.849 / 677.290 = 1.18243`，而 `√(14.2/3.5872 ÷ 8.38056/2.96) = 1.18243`。
FR-4 100×80×1.6 mm 上 `ν_eff = 0.22787`，夹在层压板 0.15 与铜 0.34 之间——这正是"加权平均"应该长
的样子，而且它是 §56.2 第 1 道闸门。

### 点质量：秩一更新 + 闭式白化

质量矩阵变成 `M = I + β s sᵀ`，其中 `s` 是（已白化的）基函数在那一点取样、`β = m/(mpa·a·b)`。
记 `a = |s|²`、`u = s/|s|`，则 `M = I + βa·uuᵀ`，它的 Cholesky 因子是 `I + c·uuᵀ` 且
`(1+c)² = 1 + βa` ⇒ `c = √(1+βa) − 1`。于是白化矩阵（对称逆平方根）是

    A = I + d·uuᵀ,    d = −c/(1+c)

并且 **`Aᵀ M A = I`、`Aᵀ K A` 仍对称**——Jacobi 可以直接吃。`|s| = 0`（质量落在某个模的节点上、
或落在基函数的零点上）时 `c = 0`、`A = I`，**整条更新退化成 no-op**，这就是"点质量不是抹平"
的判据。

返回的 `added_mass` 块给出 `added_mass_g / at_mm / plate_mass_g / mass_ratio / mode_basis_at_point /
whitening_c`。`mode_basis_at_point` 是 `|s|²`——注意它是**整个基**在那一点的范数，**不是**模 1 的
振幅，所以它本身不按到中心的距离单调（实测板心 13.7777、四分点 (25,20) 14.881）。真正决定频率
降多少的是模 1 的投影 `(c₁ᵀs)²`，板心最大：所以 f1 在板心降到最低（316 Hz）、四分点 436 Hz。

## 56.2 三道闸门，都配了会失败的对照

1. **变换截面必须能被独立积分复现**：测试里自己按层写 Simpson 逐 z 积分
   `E(z)/(1−ν(z)²)z²`、`ν(z)E(z)/(1−ν(z)²)z²`、`E(z)/(2(1+ν(z)))z²`、`ρ(z)`，与返回值比到 1e-5
   （这是 6 位有效数字的报告精度，不是机器精度）。**并且**独立断言那条
   `d12/d11 = 1 − 2·d66/d11` 恒等式——它对每一层单独成立，所以任何一层把 ν 或 2 放错位置都会翻脸。
   - 顺带记一个真踩到的坑：Simpson 必须是**偶数**个区间。第一次写成 1001（奇数）时 D11 读到
     14.18974 而不是 14.20004（−0.07 %），看着像模型错，其实是求积错。测试里把这条写在
     `_simpson` 的 docstring 上。
2. **`f ∝ √(D11/mpa)` 精确** + **纯质量的负控制**：给铜只加质量、不加刚度会预测
   `677.290/√(3.5872/2.96) = 615.24 Hz`（**比裸板还低**），而真答案是 800.849 Hz。一个"只把
   `mpa` 变大"的实现绝不可能落在 800.849 上——这道门有牙。
3. **点质量 vs 抹平**：一个 0.001 g 质量放在 `(0, 40)`（一阶模的节线）上，**所有**模态频率必须与
   裸板逐位相同、`whitening_c == 0`。抹平式实现（把 m 摊进 ρ）会让每一个模态都动。另一侧用
   **单模锚点**（外部参照，不是代码自己的答案）：SSSS 板心的 `(c₁ᵀs)² = φ_max² = 4`，所以

       f ≈ f₀ / √(1 + 4m/M_plate) = 677.290/√(1+4×0.844595) = 323.682 Hz

   全秩一解给出 316.044 Hz，低 2.36 %——差的那一点就是锚点忽略掉的高阶模态，与"锚点必须有偏"
   的预期同向。

负控制实测幅度（证明闸门真能失败）：

| 故意犯的错 | 会被读成 | 真值 | 幅度 |
|---|---|---|---|
| 铜只进质量、不进刚度 | 615.24 Hz | 800.849 Hz | **−23.2 %**（且方向反了） |
| 点质量当抹平质量 | 每个模态都动 | 节点上逐位不动 | 判据从 `==` 变 `!=` |
| 单模锚点当答案而不是参照 | 323.68 Hz | 316.04 Hz | +2.4 %（记在容差内，不当作"错"） |

## 56.3 真值

FR-4（E 24 GPa / ν 0.15 / ρ 1850），100×80×1.6 mm，四边简支（`mount="custom"`, `bc_x=bc_y=["ss","ss"]`）：

| 工况 | f1 (Hz) | D11 (N·m) | mpa (kg/m²) | 备注 |
|---|---|---|---|---|
| 裸板 | **677.290** | 8.38056 | 2.96 | 与解析 SSSS 闭式一致 |
| 1 oz（35 µm/面） | **800.849** | 14.2 | 3.5872 | 铜占质量 17.48 %，`d12` 3.23571、`d66` 5.48217 |
| 2 oz（70 µm/面） | **888.369** | 20.5284 | 4.2144 | 铜占质量 29.76 %，`d12` 5.38735、`d66` 7.57053 |
| 20 g 点质量在板心 | **316.044** | 8.38056 | 2.96 | `mass_ratio` 0.844595（板 23.68 g）、`whitening_c` 2.5548 |
| 0.001 g 在 (0, 40) | **677.290** | — | — | 节线上 ⇒ `whitening_c` 0.0，逐位等于裸板 |

点质量的位置依赖（20 g）：板心 316.044 < 四分点 (25,20) 436.228 < 近边 (95,40) 645.209 < 节线 677.290。

有铜时应力取**最外层铜面**（`surface_material = "copper"`、`surface_z_mm = 0.835`），因为没有铜时
那个面已经不存在了。同一 amplitude 0.01 mm 下 1 oz 的 `sigma_max` 1.7544 MPa 对层压板 0.331804 MPa，
比值 5.288 = `(110·0.835/(1−0.34²)) / (24·0.8/(1−0.15²))`——而 von Mises 的比值是 4.396，**不是**这个
数：它把 σ 和 τ 混在一起，而 `τ/σ = (1+ν)/(1−ν)` 随 ν 变，所以"混起来的那一个"不跟着缩。测试里
把这条同时钉住（该缩的缩、不该缩的明说不缩）。

## 56.4 默认逐位不变自证

三道：

1. **代码双分支**：`cu_t > 0` 走新展开式，否则走 0.0.52 那几行原代码（不是"新式在 ν 下等价"，是
   根本不同一条语句），避免浮点结合律改最后几位。
2. **点质量用 `apply_mass = None` 直通**：不给 `added_mass_g` 时 `apply` 是 `None`，特征向量那一行
   `col = evecs[mi] if apply_mass is None else apply_mass(evecs[mi])` 直接取原值。
3. **旧测试全部照跑**：`tests/test_vibration.py`、`test_vibration_stress.py`、`test_vibration_polygon.py`
   共 99 例（全部是解析闭式与 Leissa 系数）在改后仍然 OK；selftest 里另有一条硬口径：
   `copper_um = 0` 与"不给参数"的次数逐位相同（677.290 Hz、`composite`/`added_mass` 都是 `None`），
   且两个新块**不给就是 `None` 而不是空 dict**——读者能分清"没问"和"问了、是零"。

`warnings` 是唯一**可见**的变化：原来那条恒定的
`"component mass, copper stiffening, mounting compliance and shear deformation are not modelled"`
被拆成条件式（有铜就不再抱怨铜、有质量就不再抱怨质量），并把"安装柔度与剪切变形"单独留一条
（只有两个都给了才不再出现）。这条在 `CHANGELOG` 里显式登记。

## 56.5 拒答与边界

拒答（都有测试）：

| 输入 | 结果 |
|---|---|
| `added_mass_g = 0` 或负数 | `ARG_RANGE`，"a mass of zero is not a mass; leave the argument out" |
| `added_mass_at_mm` 落在板外（如 `[120, 40]`、`[50, -1]`） | `ARG_RANGE`，"outside the plate" |
| `added_mass_at_mm` 不是两项 | `ARG_INVALID` |
| `copper_um < 0` 或非数字 | `ARG_RANGE` |
| `copper_um ≥ h/4`（1.6 mm 板上 420 µm/面） | `OUT_OF_VALIDITY`，hint 说"薄板假设已经没了" |

仍然**不建模**（并写在 `warnings` 里，工具的 `not_implemented_yet` 第 19 条同步改口）：

- 分布的元件质量（只有**一个**点）、元件自身的刚度；
- **不对称**叠层（外层 1 oz + 内层平面必然不对称，那就需要膜-弯耦合项，这层解法不背）；
- 多边形轮廓路径上的铜（那条路径是矩形化的另一套近似，铜没接进去）；
- 应力工具自己那次独立求解里的铜（`surface_material` 只在 `plate_modes` 的应力块里有意义）；
- 安装柔度、剪切变形与转动惯量（薄板极限）、装配级模态、焊点蠕变 / BGA 球疲劳。

Ritz 多项式基的固有误差仍在：一阶模态按多项式阶数收敛，报告的 ±10 % 不变。

## 56.7 0.0.57 追加：本篇的三条边界已收窄，另有一条口径被修正

`56.1` 写的两条边界（"只进双面对称的铜""只进一个点质量"）在 0.0.57 都松开了：

- **不对称叠层**：`copper_um_bottom` 打开膜-弯耦合。`B = ∫Qz dz ≠ 0` 时中面一弯就带拉伸，
  `ε⁰ = −A⁻¹Bκ`，面内自由板实际显示的刚度是**折减刚度** `D* = D − B A⁻¹B`；`D` 单独会偏硬。
  单面 35 µm / 100×80×1.6 实测 `d11` 11.2903 → 10.9913（软 2.65 %）、`z₀` 0.0815537 mm、
  f11 = 737.558 Hz（裸板 677.29 / 双面 800.849）。
- **分布质量**：`added_mass_regions=[{mass_g, center_mm, size_mm}]`，省略 `size_mm` = 整板。
  精确矩积分**再除以 patch 面积**；漏掉除法时 patch 越小质量越趋近 0（20 g 的 0.5 mm patch
  会读成裸板），这就是它的负控制。patch 0.5 mm 给 316.052 Hz、点质量独立路径 316.044 Hz。
- **多边形轮廓路径的铜**：`vibration_plate_outline` 收 `copper_um`/`copper_um_bottom`，
  单独给 `copper_um` = 两面相同（与矩形同义）。

**被修正的是本篇 `56.3` 的最后一条读数**：0.0.56 的 `σ_x = −E_CU z/(1−ν_CU²)(w_xx + ν_LAM w_yy)`
用铜的 E 配**层压板的 ν**。0.0.57 改成 `σ = Q(z)(ε⁰+zκ)`，用哪一层就取哪一层的 `(E, ν)`。
`56.3` 里"`sigma_max` 涨 5.288 倍"那个数是**旧配方的读数**，新配方下同一块板是 5.8741；
逐条前后值与归因证据见 [`docs/60`](60-不对称叠层与分布质量.md)。
无铜路径（`legacy=True`）逐位不变。
