# 44 · 非矩形板振动：外轮廓就是边界，不是包围盒

> 一句话：`board_vibration` 的矩形解**没变**，但它算的是「同样大小的矩形板」；
> 板框是 L 形、圆角、圆弧时那个答案不是这块板。这一篇给出的第二条路
> 直接拿**真实外轮廓多边形**当边界，一套 penalty-Ritz 覆盖任意边数、逐边混合边界、
> 自由板与点支撑，并且**每条限制都在返回值里带一个能读出来的证据**
> （`alpha_scan` / `alpha_spread_pct` / `boundary_rms_mm` / `penalty_share`）。

## 44.1 为什么包围盒会答错，错多少

用同一块 100×100 mm、1.6 mm、FR-4（E = 24 GPa、ν = 0.33、ρ = 1850）的方板当尺子，
把真实轮廓换成 L 形（100×100 的方板挖掉一个 50×50 的角，fill = 0.75）：

| 轮廓 | 边界 | 包围盒 f1 | 真实轮廓 f1 | 比值 |
|---|---|---|---|---|
| L 形 | 全简支 | 553.651 Hz | 1734.760 Hz | **3.13×** |
| L 形 | 全固支 | 1009.460 Hz | 3187.210 Hz | **3.16×** |

差三倍不是小数点问题：包围盒解的能量峰值就落在被挖掉的那块里（方板 SSSS 的
反节点在 (50, 50)，恰好是 L 的凹角）。所以这一篇不是"把 bbox 答案修一修"，
而是**另解一块板**。没有静默替换：`board_vibration` 的 bbox 结果逐位不变
（`tests/test_vibration_polygon.py::test_the_bbox_answer_itself_is_unchanged`），
多边形答案只出现在 `plate_on_outline` 字段里，`ratio_to_bbox` 明写比值。

## 44.2 先试过、被数据否掉的三条路

写代码之前先把三个候选实现到能出数，再拿精度/成本把其中两个否掉。**这一节是
这篇文档里最值得看的部分**：它解释了为什么最后是"全局多项式 + 罚"这种看起来
最不像 FEM 的方案。

### (1) Morley 三角（非协调板元）

- patch test 过，方板 SSSS 也能到 −5%；
- 但 ~150 DOF 仍只有 −5.1% ~ −22%，靠加密才能收敛；
- n = 6 的网格要 19.3 s。

纯 Python 里 FEM 的装配成本换不来精度：150 个自由度的罚-Ritz 已经是 −0.01%。

### (2) 10-DOF 三次三角 + Guyan 缩聚

比 Morley 更差（−12%）：Guyan 把内部自由度静力缩掉，而板的高阶模态恰恰
不是静力响应，缩聚把要算的东西先删掉了。

### (3) 距离包络基 ψ = E(x, y)·xⁱyʲ

`E` 是到边界的"距离函数"，用它乘单项式，边界上自动归零——**看起来最优雅**：

- 方板：0.000% / 0.003%（几乎精确）；
- 16 边形：**+88%**；64 边形：**+105%**；
- 换成 min / softmin 型包络：连方板都 +85%。

原因：`E` 在凸角附近是分片光滑的，用它当权函数会把这个不可导性灌进基里；
边一多，`E` 的梯度跳变就把整个基的曲率积分污染。这条直接被数据判死。

## 44.3 最终方案：Green 定理精确积分 + 质量度量白化 + 罚阶梯

内部积分用 **Green 定理化成环上的线积分**：

```
∫∫_Ω ξⁱ ηʲ dξ dη = ∮_∂Ω ξ^{i+1} ηʲ / (i+1) · dη
```

每条边一条 Gauss 规则即可精确积出（被积函数是多项式，8 点足够到 degree 15）。
于是刚度阵 K 和 Gram 阵里**没有内部剖分、没有内部积分误差**，装配成本从
"每对单项式扫网格"降到每对一次 88k 级别的线积分。

剩下的工作量全在"怎么把 w = 0 / ∂w/∂n = 0 这些本质边界条件塞进
一个不含它们的函数空间"。最终是罚：`A = K + α·C`。以下六条是**量出来的**，
没有一条是推导出来就信：

### (1) 必须先按质量度量白化，再加罚

直接加罚 α = 1e6：固支方板读 **+6600%**。白化（`A ← QᵀAQ`，`Q` 是质量正交基）后：−0.11%。
罚项的量纲不是刚度的量纲，不白化就是给高模态灌不可控的刚度。

### (2) 白化不能用 Cholesky，也不能用 M 的特征分解

- Cholesky：degree 8 的单项式 Gram 是 Vandermonde 型，α > 1e10 时直接报 not PD；
- M 的特征分解截断（`1/√λ` 放大）：把无刚度方向的 1/√λ 放大成巨大数，
  结果是**伪零频模**（0.006 Hz 对真实 1.2e7），频谱彻底坏掉。

正解是**质量内积改良 Gram-Schmidt（两遍重正交）**，保留数 `rank` 当诊断报出来
（`basis.independent_dof` / `basis.dof`）。两遍是必要的：单项式之间离正交极远，
一遍重正交在高 degree 下会丢掉本可以保留的方向。

### (3) 空间里必须真的存在满足约束的非零函数

矩形固支需要 degree ≥ 8（w = 0 与 ∂w/∂n = 0 两条边条件同时满足，至少 8 次）：

| poly_degree | 固支方板 f1 | 相对闭式解 |
|---|---|---|
| 6 | 2222.970 Hz | **+120.245%** |
| 8 | 1009.550 Hz | +0.023% |
| 10 | 1009.550 Hz | +0.023% |

degree 6 **不是"精度差一点"，是空间里根本没有一个合法的 w**；p = 8 与 p = 10
逐位相同，说明此时误差由罚项而不是多项式度数主导。所以 `poly_degree < 8`
且带固支/点支撑时，返回值里有一条告警明说"may contain no function that
satisfies a clamped edge at all"。

### (4) 白化后特征值就是 ω²，不要再除一次 ρh

质量阵已经含 ρh（`M = mpa·jac·I`），所以白化后的特征值 λ = ω²。
再除一次 mpa 会得到统一 **−41.88%**（= √(1/2.96)）——一个所有几何都一样的
系统性偏差，是"多算了一步"的指纹，不是物理。

### (5) α 不是越大越准，拐点才是答案

64 边形逼近圆板（真值 553.684 Hz）的 α 阶梯：

| α | 1e3 | 1e4 | 1e5 | 1e6 | 1e7 |
|---|---|---|---|---|---|
| f1 | 540.31 | 557.57 | **559.57** | 562.10 | 584.46 |

1e5 之后每放大 10 倍只加伪刚度。原因是 **basis 无法让边界位移在 64 条弦上同时归零**
（任何 degree 10 多项式都做不到），过拐点后罚项只是在给"违规"付越来越贵的罚款，
不是在逼近真解。所以 `reported_alpha` = 阶梯上**最平的一档**，
该档的步长就是误差棒（`alpha_spread_pct`），`alpha_converged` = (spread ≤ 1%)。

一个必须注意的细节：**拐点判据要盯"第一个非零频率"**。自由板前三个是刚体零模
（恒 0），盯 mode 0 会让判据永远认为"没变化"、于是选到最小的 α。

### (6) 每阶模态要能说出自己有多少是罚项

这是最后补上的一条，也是最能防"看起来合理的错答案"的一条。
对每个特征向量 v 单独算

```
penalty_share = α·vᵀC v / vᵀAv
```

（`C` 就是约束 Gram 的组合，装配时已经单独留了一份。）物理模态这个数接近 0
（弯曲能占绝大头），basis 撑不起来的模态这个数接近 1（频率全部来自伪刚度）。
固支方板实测：

| 阶 | f1 | penalty_share | physical |
|---|---|---|---|
| 1 | 1009.55 Hz | 0.000402 | True |
| 2 | 21435.1 Hz | 0.901 | **False** |
| 3 | 28170.4 Hz | 0.988 | **False** |
| 4 | 28170.4 Hz | 0.988 | **False** |

分界干净到三个数量级（< 1e-3 对 > 0.9），不需要挑阈值。第 2~4 阶的真实值分别是
约 3.0 kHz 量级，报出来的 21~28 kHz 是**一个 degree 8 的基在固支下只能装下一阶模态**
这件事的直接后果。既然它必然出现，就必须带标记，并被一条能失败的对照盯住
（`test_a_mode_the_basis_cannot_carry_is_flagged_not_printed_as_a_plate_mode`：
固支必须标出来，简支四阶全 True 且**不许**出现这条告警）。

## 44.4 实测精度表

尺子：E = 24 GPa、ν = 0.33、ρ = 1850、h = 1.6 mm、a = 100 mm；
`c = √(D/ρh) = 1.762325`。

### 退化到矩形（与 `plate_modes` 逐 mount 对比）

| mount | 矩形 f1 | 多边形 f1 | 相对 | 4 阶相对 |
|---|---|---|---|---|
| `ssss` | 553.651 | 553.599 | −0.009% | +0.55% |
| `clamped` | 1009.460 | 1009.550 | +0.009% | （见 §44.3(6)，非物理） |
| `corners` | 199.253 | 199.232 | −0.011% | −0.64% |
| `free` | 0（刚体） | 0 | — | 第 4 阶 370.147 对 370.144（+0.0008%） |
| `cantilever` | 97.183 | 96.773 | **−0.42%** | −0.31% |

`cantilever` 是唯一超过 0.1% 的：悬臂的固支边在基里是"一侧罚"，收敛比全固支慢，
而且它的 `alpha_spread_pct` = 1.25%（`alpha_converged=False`）——**它自己说了自己没收敛**。
这正是设计目标：不冒充精度。

旋转不变性：方板绕原点转 15° / 30° / 45°，f1 分别 −0.011% / −0.011% / −0.010%。

### 圆弧轮廓（内接正多边形 vs 圆板解析解）

圆板真值：简支 553.684 Hz（λ = 4.9351）、固支 1146.142 Hz（λ = 10.2158），r = 50 mm。

| 边数 | 简支 | 误差 | 固支 | 误差 |
|---|---|---|---|---|
| 8 | 699.070 | **+26.26%** | 1372.750 | **+19.77%** |
| 16 | 577.741 | +4.34% | 1260.160 | +9.95% |
| 32 | 566.182 | +2.26% | 1233.640 | +7.63% |
| 64 | 559.573 | **+1.06%** | 1159.250 | **+1.14%** |

64 边形的面积是圆的 99.92%，它自己的（内接多边形板的）真值比圆板略硬，
所以 +1% 里有相当一部分是**几何差**而不是数值误差。但报告里不这么辩：
`alpha_spread_pct` 在 64 边形简支上是 0.36%（`converged=True`）、固支上是 1.99%
（`False`）——固支那个数就按"没收敛"读。

8 边形的 +26% 里也有几何成分（内接八边形面积只有圆的 90%），这一格的作用
不是精度而是**趋势**：边数越少越硬，实测单调，可当一条负控制用。

### 凹轮廓

L 形（`ssss`）的 `alpha_spread_pct` = 14.70%、`alpha_converged=False`、
`boundary_rms_mm` = 0.387 mm；固支更差（52.40% / 14.2 mm）。凹角附近
位移场有奇性，全局多项式在角上表达不了——这时返回值同时给出三个读数
（spread、converged、boundary_rms）让用户自己判断，并触发告警说"只作指示"。
**不给一个看起来很准的数字。**

### 逐边混合边界与点支撑

- `["ss", "free", "ss", "free"]`：268.536 Hz（对全简支 553.599，少两条支撑 → 更软，方向正确）；
- `["cc", "free", "cc", "free"]`：621.443 Hz；
- 点支撑的刚体模态数由 `3 − rank{[1, x_k, y_k]}` 定：1 点 → 2 个、2 点 → 1 个、
  3 个非共线点 → 0 个。实测 1 点支撑 `[0, 0, 324.998, 370.147]`、2 点 `[0, 106.555, …]`、
  3 点无零模。这条不是理论洁癖：早先一律按"0 个刚体模态"要求，导致
  "单点支撑 + 全自由"**直接 NO_CONVERGENCE**——一个正确的板被判成算不出来。

## 44.5 成本

| 情形 | 用时 |
|---|---|
| p = 8，64 边形（45 DOF，5 档 α） | 1.59 s |
| p = 10，64 边形（66 DOF） | 5.64 s |

两次优化（数值逐位不变）：

- GMS 携带 `M·v` 走内积（`<q,v>_M = q·(M v)`，缓存 `M q`）→ O(nb²) 而不是 O(nb⁴)；
- `whiten(A)` 写成 `(AQ)` 再 `Qᵀ(AQ)` → O(nb²·rk)。

合计 p = 8 固支 3.45 s → **1.22 s**（2.8×），p = 10 20.9 s → 6.19 s。

## 44.6 怎么读返回值

```python
board_vibration(..., )            # bbox 主答案（不变）
  └ plate_on_outline              # fill < 0.99 时才出现
      f1_hz, ratio_to_bbox, modes, model
      alpha_spread_pct            # 罚阶梯最平一档的步长 = 误差棒
      alpha_converged             # spread <= 1%
      boundary_rms_mm             # 首阶在受约束边界上的 rms 位移（相对自身峰值）
      poly_degree, area_mm2, perimeter_mm, warnings
  └ hotspots_on_outline

vibration_plate_outline(ring_mm=[[x, y], ...], thickness_mm=1.6, mount="ssss")
```

读法三条：

1. `alpha_spread_pct` 先看。> 3% 就只当指示，别拿去和实测比；
2. `modes[i].physical` 为 False 的**不是模态**，是基撑不住的伪刚度；
3. `boundary_rms_mm` 是"边界条件被违反了多少"：矩形 < 0.05 mm（合规）、
   64 边形 > 0.01 mm（多边形本来就没法让位移在多条弦上同时归零）。

`ring_mm` 顶点顺序任意（顺时针/逆时针、起点随意都行，内部会按面积定向），
自交环（蝴蝶形）按 `OUTLINE_INVALID` 拒绝——不是"零面积"，因为它的面积确实不为零，
错的是拓扑。

## 44.7 这一层不做的事

- **不网格化孔 / 挖空**：只解外轮廓。板上有大挖空时这个解会偏硬，做了也不对；
- **不加元件质量与铜厚**：与 `plate_modes` 同一条边界（见 `19`）；
- **不算应力与疲劳**：多边形轮廓上没有可信的曲率极值，需要用矩形路径的
  `plate_stress` / `solder_fatigue`；
- **不做全波 / 3-D**：那属于 `20` 与 `calc/em.py` 的接缝，这里不越界；
- **不给"准确度 ±x%"**：给的是罚阶梯步长与边界残差，这是能测的东西。
