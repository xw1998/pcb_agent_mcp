# 131 · 走廊判据：`_runs` 判 free 不等于能走

天空星板在 `47 unconnected` 这个基线上再往前走时，连续三条网（`$1N4403` /
`$1N5560` / `AGND` 的西向支）都是「`_runs` 全 free、写下去却不降」。根因不是走线画歪，
是**判据用错了一层**：`_runs.py` / `_map.py` 只看见**走线与焊盘**，看不见**铺铜填充**；
而且它们只回答「这一点空不空」，不回答「这一点空出来的空间**和外界通不通**」。

这一篇把两条新判据钉死，并把本轮实测的封闭区域连同「墙是谁的」一起记下来。

## 1. 判据一：走线会按 clearance 清出凹槽，凹槽落在窄颈上就断铜

走线本身不是问题，问题是它把别的网络的铺铜切开。0.15 走线在 x=c 处会把
`[c-0.30, c+0.30]` 的 +3V3 铜抹掉（0.15/2 线宽 + 0.15 clearance，两侧各 0.225）。
**当这段 +3V3 只有 0.31 宽时，整条被抹掉**，它连着的两块大平面就从这个位置断开，
`+3V3` 岛数 7 → 8/9，`unconnected` 上去。

反过来，**过孔在铺铜里只留一个小孔，不会把铜带切断**。所以跨另一个网络的走线应当
**钻下去**（via → 另一层 → via 回来），而不是在同层「切过去」。

判一条走廊能不能走，必须在 `_runs` 之外再叠一层 `_zrows.py`（该行/列 +3V3、GND 的填充跨度）：

| 穿过的东西 | 后果 |
|---|---|
| 宽面（回路仍能绕通） | 安全 |
| 窄颈（0.3 级细条、3 mm 级竖带只有一端相连） | **致命**：直接多一块岛 |
| 过孔 | 无害 |

## 2. 判据二：free 是「点」的结论，可走性要「面连通」

`$1N5560`（`R9.2 (-11.5,-21.967)` ↔ `U1.70 (3.5,-7.55)`）是本轮最干净的反例：
两端各自的 free 区域都很大，但**两块区域之间没有缝**。

route 坐标下量到的事实（`_runs need=0.225`，即 0.15 线 + 0.15 clearance）：

| 走廊 | free 区间 | w |
|---|---|---|
| F.Cu col -11.5 | -22.300 .. -5.300 | 17.0 |
| F.Cu col -10.0 | -21.400 .. -5.300 | 16.1 |
| F.Cu col -13.0 | -26.000 .. -4.600 | 21.4 |
| F.Cu row -21.9 | -15.800 .. -10.500 | 5.3 |
| F.Cu row -5.4 | -15.800 .. -9.200 | 6.6 |
| F.Cu col 3.5（pad 侧） | -17.600 .. -11.700 / -10.300 .. -6.900 | 5.9 / 3.4 |
| F.Cu row -6.4 | -9.100 .. -8.000（东侧大空面） | — |

两侧都对，但**中间那堵墙是通的**：`x = -9.70 .. -9.20` 的 F.Cu 铜柱，从
`y = -21.70` 一直顶到 `y = -5.50`。它只在两头有口子：

- 下口：`y < -21.7`（`col -9.4` 从此向下 free），但下口外侧紧接着
  `x = -10.40 .. -9.60` 的**第二根**竖线（`y < -21.7` 才有），两堵墙在 `y ≈ -21.6` 处搭上，
  缝隙不成立。
- 上口：`col -9.4` 在 `y = -5.5 .. -5.4` free（w 0.1），可是 `y = -5.4` 往东只到 `x = -9.2`，
  再往东 `x = -9.1 .. -6.5` 是 U1 左侧扇出铜块；`y = -5.3 .. -4.8` 又是一整条横铜。
  **上口是个死角。**

B.Cu 同样过不去（`_map B` 实测）：西侧 `y -23.2..-20.3`（x -10.5..-9.0）与上侧
`y -19.7..-16.9`（x -10.1..-8.8）之间，被 `y -19.8 .. -20.2` 一条**实心横铜条**
（x -11.5 .. -8.0）隔开；横铜条东端只剩 `x -7.9..-7.5` 一条 0.5 宽竖缝，
往上在 `y = -19.4` 又被 `x -8.4..-7.9` 的铜堵死。

⇒ `$1N5560` 判**当前几何下不可布**：两端不在同一个 free 连通块里。

## 3. 那堵墙是谁的：`$1I8749/$2N1200`

板文件里查到（file 坐标，`file_x = route_x + 148.5`、`file_y = 105 - route_y`）：

```
(segment (start 139.1 111.3695) (end 139.1 126.2)  width 0.15  layer F.Cu  net "$1I8749/$2N1200")
```

`139.1 → route x = -9.40`，`file_y 111.37..126.20 → route y = -6.37 .. -21.20`。
就是 §2 里那根竖柱。它由 `examples/sky_star/_sky_route6.py` 第 72 行画出：

```
('$1I8749/$2N1200', 'F.Cu', [(-7.55, -5.50), (-9.40, -5.50), (-9.40, -21.20)]),
```

同网第 73 行的 `B.Cu (-9.40,-21.20) → (13.20,-21.20)` 也就是 §2 里那条
`y = -21.20` 的 B.Cu 实心横铜条。

**这条网是已经布通的**，不是欠账；它把西南角整个圈死了。

## 4. AGND 的西向支被同一堵墙拦住

AGND 的 4 条未连接里，`$1N4403` 之外的西向那条（报告里
`Track @(139.9000,125.7249) F.Cu` ↔ `Pad 37 [AGND] of P1 @(129.0300,126.5900)`）：

| 走廊 | free 区间 |
|---|---|
| F.Cu row -20.3 | **-21.000 .. -9.800**（11.2 长，直通 P1 一侧） |
| F.Cu row -20.3 东段 | -9.100 .. -7.700 |
| F.Cu row -20.8 / -21.3 | -20.5 .. -18.1，再 -15.8 .. -9.8 |

东段与西段之间差的正好是 `-9.8 .. -9.1`——**同一根 `$2N1200` 竖线**。
`x = -18.1 .. -15.8` 那 2.3 宽的墙在 `y = -20.3` 和 `y = -23.0` 两个高度上是通的
（`row -20.3` free `-20.5..-14.0`，`row -23.0` 同），所以西半段本身没有障碍。

⇒ AGND 这条也只差过墙这一步。

## 5. 结论

- `_runs`/`_map` 的 free 是**点判据**，可走性必须额外确认「两端在同一 free 连通块」，
  并且叠 `_zrows.py` 看铺铜窄颈。本轮三条网全部栽在这两条里。
- 已确认**不可布**：`$1N4403`（route x 2.31..2.62 的 +3V3 细颈）、`$1N5560`
  （`$2N1200` 的 x=-9.40 竖柱 + B.Cu 实心横条双重封闭）。
- 已确认**只差过墙**：AGND 西向支、`$1N5560` 若墙让开即可布。
- 唯一能让开这堵墙的动作是**改 `_sky_route6.py` 里 `$1I8749/$2N1200` 的那段折线**
  （把 `x=-9.40` 的 15.7 mm 竖段搬到别的列）。这条线是已布通的网，
  动它属于结构性改造，需要单独确认后再做；本轮不动。

## 6. 第三块封闭区域：AGND 东向支被 +3V3/GND 两堵墙夹在 0.21 mm 里

`AGND` 的 A 组（西片，B.Cu 尾巴在 route `(-1.882,-20.800)`）要接 B 组
（`C10.1/C11.1` 在 route `(6.000..7.200,-19.533)`），两端都在 `_runs` 里显式 free：

```
F row -20.550  free  -2.000..-0.500 / 0.500..0.700 / 6.400..7.000
B row -20.550  free  -2.000.. 4.700 / 4.900..7.000
B row -20.800  free  -2.000.. 8.000          ← B.Cu 有一条 10 mm 直廊
_vc (6.800,-20.350)  F 0.651 / B 0.725  -> VIA OK
```

按这条画了 route30（B.Cu 沿 `y=-20.800` 东行到 `x=6.650`，45° 斜切上抬，
过孔 `(6.800,-20.350)`，F.Cu 竖直 0.82 mm 落进 `C10.1..C11.1` 那段本网铜）。
DRC + 缝合后读数：

| 项 | 基线 | route30 |
|---|---|---|
| unconnected | 47 | **48** |
| violations | 123 | 124 |
| AGND 对 | 4 | **3**（本网确实接通了） |
| `+3V3` F.Cu 岛 | 7 | **8** |
| GND 岛 | 62 | **63** |
| 缝合孔 | 51 | 51（`(3.235,-20.511)` 被挤到 `(3.135,-20.311)`） |

即：AGND 自己通了，但两处铺铜各裂掉一块，净结果 +1。两处都量到了硬边界。

### 6.1 `+3V3` 的桥在 file y=125.2，下面 GND 留的缝只有 0.21 mm

（file 坐标，窗口 x 150..158；`gap` = GND 右沿到 `+3V3` 左沿）

```
y=124.80  +3V3 [153.77,154.03] [156.21,..]   GND [152.76,153.56]   gap 0.21
y=125.00  +3V3 [153.72,154.15] [154.85,155.35] [156.05,..]
          GND [152.57,153.51]                                       gap 0.21
y=125.20  +3V3 [153.71, …连续… ]             GND [152.56,153.50]   gap 0.21
y=125.40  +3V3 [153.73, …连续… ]             GND [153.05,153.43]   gap 0.30
```

`+3V3` 在 `y=125.2` 是一条**从头连到尾的桥**（153.71 一路到 161.42），
`y=125.6` 才退到 154.91 —— 也就是任何一条从南往北进 `C10/C11` 的 F.Cu 走线
都必须横切这条桥。而桥正下方的 GND 与桥之间只剩 **0.21 mm**，
按本板 0.15 线宽 + 0.15 间隙需要 **0.45 mm**，差一倍多。
`C10.1/C11.1` 这两个焊盘以北（file y ≤ 124.6）`+3V3` 是断开的（
`153.77..154.03` 与 `156.81+`），但 B.Cu 在北侧 `y=-19.9` 以上全堵
（列 x=5.6..8.4 全部止于 -19.9），过孔落不过去。

### 6.2 改走 B.Cu 绕也绕不开

B.Cu 一段是通的（`y=-20.800` 全自由），但 B.Cu 上方 `y -18.8..-19.5`
是一条从 `x=1.5` 横到 `x=18.5` 的实心墙；`y -16.6..-17.1` 还有第二条。
想从 `(8.5,-15.3)` 那侧的既有 AGND 过孔接过去，必须穿这两条墙，都不通。

⇒ **AGND 东向支判「当前几何下不可布」**，证据就是 0.21 mm 这一条；
与 §5 的 `$1N5560` 不同，这次不是「只差过墙」，而是墙与墙之间的缝本身就窄于线宽加间隙。

## 7. 顺带量掉的一条：GND 缝合不是 rim 卡住的

既然 `GND 5 对` 是「岛数 − 1」，先怀疑缝合脚本的 `RIM=0.50`（要求孔心离岛沿 0.5 mm）
太严。把 `RIM` 改成 **0.35** 重跑 `_stitch_gnd.py`：

```
RIM 0.50 -> islands 60  vias 47  skipped 13
RIM 0.35 -> islands 60  vias 47  skipped 13     逐条 skipped 原因不变
```

13 个岛的原因全部是 `no legal site touching the island`，不是 `rim too tight`：
即岛上**根本没有任何一点**能放下 0.45-0.25 的孔（被邻网铜和既有过孔间距吃掉），
与 rim 无关。板子的网表规则下限就是 via 0.45 / drill 0.25，更小的 0.30-0.15
早前试过被 DRC 判死（`via_diameter` / `drill_out_of_range` / `annular_width`）。
⇒ `GND 5 对` 在「一岛一孔」这个手段下确实是地板；再往下要靠人工接线把岛并起来，
不属于铺铜/缝合，也不在本轮范围。`RIM` 已还原为 0.50，`_stitch_gnd.py` 无改动。
