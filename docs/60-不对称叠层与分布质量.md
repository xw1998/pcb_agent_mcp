# 60 · 不对称叠层的膜-弯耦合 / 分布元件质量 / 多边形上的铜 / 应力用哪一层的 ν

0.0.56 的振动层能进铜、能进质量，但漏了四处。前三处是"能力清单上写着不做"，第四处是
**算错了**——而且错得很有道理，所以一直没被发现：

1. `copper_um` 只能表示**双面对称**的铜皮；一面有铜一面没有（或两面厚度不同）是真实板子
   最常见的形态，而这个解**根本没有那一项**（膜-弯耦合 `B`）。
2. `added_mass_g` 只能表示**一个点**的质量；一块灌封胶、一颗大电容、一个屏蔽罩压在
   一片面积上，用点质量会把频率算**低**（点质量只压住它所在的那一阶，其余阶几乎不动）。
3. 多边形轮廓（`vibration_plate_outline`）**不收铜**，于是"L 形的板"和"L 形的板带 1 oz"
   只能算前者。
4. 铜面上的弯曲应力用**铜的 E 配层压板的 ν**（`E_CU z/(1−ν²)` 里的 `ν` 是 0.15，
   而铜是 0.34）。1 oz 板上这是 **10 %** 量级的偏差，方向、量级都固定，因此看起来
   "像个答案"。

> **一句话结论：前三处补上了，第四处必须登记为修正——钢性(`D*`)与应力都改成"用哪一层
> 就取哪一层的 (E, ν)"；无铜的默认路径逐位不变，有铜的应力数字变了，前后值逐条列在本篇
> 第 60.5 节，并给出归因证据（20/20 读数用旧公式在自报曲率点回放，差 ≤ 4.3e-6）。**

## 60.1 截面：A / B / D 与折减弯曲刚度 D*

层序自下而上：**底铜 / 层压板 / 顶铜**，`z` 原点在**层压板中面**。每层各向同性，
平面应力刚度

    Q = E/(1−ν²) · [[1, ν, 0], [ν, 1, 0], [0, 0, (1−ν)/2]]

截面刚度就是沿厚度的三个矩：

    A = ∫ Q dz        （拉压，N/m）
    B = ∫ Q z dz      （膜-弯耦合，N）
    D = ∫ Q z² dz     （弯曲，N·m）

对称叠层 `B ≡ 0`，于是回到 0.0.53 起的闭式（`D11 = Σ E_i/(1−ν_i²) ∫z²dz`）。
**不对称时 `B ≠ 0`**，中面一弯就同时被拉伸：曲率 `κ` 会带出中面应变

    ε⁰ = −A⁻¹ B κ

而板子**面内自由**（板子只是搁在铜柱上，四周没有面内牵引）时，它实际显示的弯曲刚度是
**折减刚度**

    D* = D − B A⁻¹ B

`D` 本身比板子能给出的更硬——用 `D` 算频率会**偏高**。中性面位置 `z₀ = B11/A11`。

### 实测（100×80×1.6 mm FR-4，单面 35 µm）

| 量 | 值 | 说明 |
| --- | --- | --- |
| `a11` | 4.36371e7 N/m | 单层压板 + 单面铜 |
| `b11` | 3558.77 N | ≠ 0，这就是耦合项 |
| `b11/a11` = `z₀` | 0.0815537 mm | 中性面朝铜面挪 81.6 µm |
| `d11_before_reduction` | 11.2903 N·m | 直接用 `D` |
| `d11_reduced` (`D*`) | 10.9913 N·m | **软 2.65 %** |
| `f11` | **737.558 Hz** | 介于裸板 677.29 与双面 800.849 之间 |

镜像叠层（铜在底）给出 `z₀ = −0.0815537`、`d11` 完全相同——**判据之一就是这条对称性**。

### 适用条件写进输出，不藏在代码里

`composite.asymmetric.note` 明说这是**平态附近**的解：

> B ≠ 0 把弯曲和拉伸耦合起来。板子面内自由时它实际显示的刚度是折减刚度
> `D* = D − B A⁻¹B`，`D` 单独会更硬。同一耦合会让**平态弓起来**，所以这里的频率是
> **绕平态**的频率；一块真的会翘的板是另一个问题，本解不做。

不对称板在现实里确实会弓，这个解**不是**那个平衡态的解——不说清就是把"平态"偷渡成
"实际形状"。

### 对称情形仍走旧路径

对称铜（两面同样厚度）**不切换到通用截面**，仍走 0.0.53 起的闭式。两条路径代数等价，
但浮点上差 ~2.7 ppm；统一切换会**静默改变**既有答案，所以保留旧路径。
测试 `test_the_closed_form_path_agrees_with_the_section` 就是钉这条 1e-5 的等价性。

## 60.2 分布元件质量：`added_mass_regions`

```json
"added_mass_regions": [
  {"mass_g": 20.0},
  {"mass_g": 3.0, "center_mm": [30, 25], "size_mm": [10, 8]}
]
```

- **省略 `size_mm` = 整板**（灌封、三防漆、整面钢板）。
- 有 `size_mm` = 一块矩形 footprint，质量在该 footprint 上**均匀分布**。
  这不是"近似"，是"元件质量在它自己的 footprint 上"这个物理事实的写法。

数学上：模态形状写成单项式基 `φ = qᵀ s(x,y)`，一块 patch 上的精确矩就是两个方向
一维积分的**外积**

    R_IJ = (∫_{x_a}^{x_b} s_I s_J dx) · (∫_{y_a}^{y_b} s_I s_J dy) / (Δx·Δy)

除以 patch 面积这一步是**必须**的：`s` 是"归一化的坐标多项式"，patch 上的平均是
均值而不是积分。漏了它，patch 越小质量贡献越趋近 0——极端情况下 20 g 的 0.5 mm patch
会被读成**裸板**。

质量矩阵变成 `M = I + Σ β_m R_m + (点质量项)`，`β_m = m_m / m_plate`；
白化改用**带质量的 Cholesky + Jacobi**（不是"解一次广义特征值再白化"）。

### 实测：patch 收敛到点质量（这就是负控制）

20 g 压在 SSSS 板中心，patch 边长从 40 mm 缩到 0.5 mm，f1 单调收敛到**点质量**的 316.044 Hz：

| patch 边长 | f11 (Hz) |
| --- | --- |
| 40 mm | 363.713 |
| 20 mm | 328.618 |
| 10 mm | 319.238 |
| 4 mm | 316.558 |
| 1 mm | 316.077 |
| 0.5 mm | 316.052 |
| 点质量（独立代码路径） | **316.044** |

两条独立路径在 2.5e-5 上碰头。这就是 `test_a_patch_shrinks_to_the_point_mass` 的判据：
`|tiny − point| / point < 1e-4`，**并且** `|tiny − bare| > 20·|tiny − point|`
——后一条是负控制，把"漏掉 1/面积"这种错（会让两级都退化成裸板）直接翻脸。

### 整板：`1/√(1+β)` 解析因子

20 g 铺满整块板（板 23.68 g，`β = 0.844595`）：**498.682 Hz**，解析 `677.29/√1.844595
= 498.6825`。整板质量不改变模态形状，只改频率，所以这条有闭式可对。

### 拒绝清单（都是逐条报错，不静默）

| 输入 | `reason_code` |
| --- | --- |
| patch 挂在板外 | `ARG_RANGE` |
| `mass_g ≤ 0` | `ARG_RANGE` |
| `size_mm` 有 0 或负 | `ARG_RANGE` |
| 空列表 `[]` | `ARG_INVALID` |

`[]` 不是"没有质量"——不传才是；给了空列表说明调用方以为自己在给东西。

## 60.3 多边形轮廓上的铜

`vibration_plate_outline` 的装配本来是 `D·∇²∇²` 的罚变分，刚度只有一个标量 `D`。
有铜以后截面不再是单层，于是改成**广义刚度四元组**

    dmat = (d11, d22, d12, d66)

各向同性对称叠层仍满足 `d11 = d22 = D*`、`d12 = νD*`、`d66 = (1−ν)D*/2`，但装配里
逐项用 `dmat`，不再假设它可由一个标量还原。**罚项尺度也从 `D` 改成 `sect["d11"]`**
——用错尺度会让"最平一档"选错，而这一档就是误差棒。

面积质量 `mpa += ρ_Cu (t_top + t_bot)`。

### 语义必须与矩形工具一致

`copper_um` 单独给 = **两面相同**（矩形路径一直如此）。0.0.57 初版把 poly 的
`copper_um` 当成"仅顶面"，结果同一块板两个工具给出 `D11 = 10.99` 与 `14.2`——
**同一个词给两个答案比不支持铜更糟**。已统一为两面，`copper_um_bottom` 才表示不对称。

### 实测

| 检查 | 结果 |
| --- | --- |
| 正方形轮廓 vs 矩形板 f1 | 差 0.0118 %（SSSS）/ 0.056 %（clamped） |
| `D11`（35 µm 双面） | 14.2，与矩形逐位同值 |
| 单面 35 µm | 报 `d11 = 10.9913`（折减后的） |
| 锁定读数 | SSSS 40×30×1.6 `f1 = 4588.03`；clamped `8546.05` |
| 无铜分支 | 保留原式 `D·jac·st`，**逐位不变** |

铜过厚（进入"铜不是薄皮"的区间）返回 `OUT_OF_VALIDITY`，不是硬算。

## 60.4 应力：用哪一层的 (E, ν)

### 旧配方错在哪

0.0.56 的应力是

    σ_x = −E_CU z/(1−ν_CU²) · (w_xx + ν_LAM w_yy)

系数里用了**铜的 E 和铜的 ν**（`1−ν_CU²`），括号里却用**层压板的 ν = 0.15**。
铜的 ν 是 0.34，两者相差 2.27 倍——在 `w_xx = 0` 的点上（很多峰点就是），**整个偏差
恰好就是 `ν_CU/ν_LAM = 2.2667`**。

### 新公式

    σ = Q(z) (ε⁰ + z κ)

- `Q(z)` 用**那一面自己那一层**的 `(E, ν)`：铜面用铜的，层压板面用层压板的；
- 不对称叠层要带 `ε⁰ = −A⁻¹Bκ`（对称叠层精确为 0，这就是"对称板不需要 ε⁰ 项"的原因）；
- `κ_xy` 用**工程扭转 `2w_xy`**（张量扭转的一半），否则 `τ` 差 2 倍；
- 双面都有铜时解**两个面**并报**较坏的一面**（`surfaces_checked`、`surface_face`、
  `von_mises_by_surface_mpa`）。

### 归因（不是"改完看起来对了"）

用 0.0.56 的公式在 0.0.57 **自报的曲率点**上回放：4 阶 × 5 读数 = **20/20 全对，
相对差 ≤ 4.3e-6**。这说明

- 峰点**没有移动**（曲率完全相同），
- 幅度**没有变**，
- 差异**唯一来源**是 `Q12` 里那个 `ν` 的层归属。

### 登记的前后值（60×40×1.0 clamped，70 µm 双面，`stress_amplitude_mm=0.05`）

| 阶 | 读数 | 0.0.56 | 0.0.57 |
| --- | --- | --- | --- |
| 1 | `sigma_1_mpa` | −10.1128 | **−22.9224**（×2.2667 = ν 比） |
| 1 | `von_mises_mpa` | 62.9744 | **59.3745** |
| 1 | `surface_strain_ue` | 91.9347 | **208.385** |
| 2 | `sigma_2_mpa` | 13.6333 | **30.9021** |
| 2 | `von_mises_mpa` | 84.8968 | **80.0438** |
| 3 | `sigma_2_mpa` | 27.1399 | **61.5172** |
| 3 | `von_mises_mpa` | 169.005 | **159.344** |
| 4 | `sigma_1_mpa` | −38.9402 | **−88.2644** |
| 4 | `von_mises_mpa` | 242.488 | **228.626** |
| 4 | `surface_strain_ue` | 354.002 | **802.404** |

每阶只有**一个**主应力变，因为该阶的峰点落在 `w_xx = 0` 或 `w_yy = 0` 上，另一个
主应力项与 `ν` 无关。`von Mises` **不**等比变化——它把 `σ` 和 `τ` 混在一起，
`τ/σ = (1+ν)/(1−ν)` 本身也随 `ν` 动。

### 无铜路径逐位不变

`legacy=True` 分支保留旧公式，`surfaces_checked = 1`、`surface_face = "laminate"`。
0.0.56 → 0.0.57 的逐位对比里，**无铜用例的所有数字一个不动**，只有新增的键与新
`formula` 文本。既有的 145 个振动测试全部通过；其中 `tests/test_vibration_mass_copper.py`
里有一条断言**依赖了旧的混 ν 数值**（"应力比 = 纯材料因子 5.2874"），已改写为
"材料因子 × 曲率混合比"，并把 5.2874 → **5.8741** 登记在此处，测试注释里写明回退会失败。

## 60.7 仍然不做（说清差哪一步，不当待办列表）

- **真的弓起来以后的平衡形状与它上面的频率**：本解只给平态附近的线化结果。
- **元件的刚度**（焊点/引线自身加了一阶弹簧）——质量进了，刚度没进。
- **加强筋/开孔的精确截面**：加强筋仍走 `docs/56` 的等效梁路径，多边形仍只解外轮廓。
- **层压板的各向异性**（正交各向异性 `E1≠E2`）：现在是各向同性层，`Q` 用单一 `(E, ν)`。
