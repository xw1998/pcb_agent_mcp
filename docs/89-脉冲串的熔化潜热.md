# 89 · 脉冲串的熔化潜热，以及「可持续电流」这个问题原来一直答错了

> 0.0.86 把熔化潜热加进了**一个**脉冲：Onderdonk 只算到铜「到达 1083 °C」，可它还没熔，
> `I²t` 要再乘 `1+β`（25 °C 下 +25.3 %）、电流乘 `sqrt(1+β)`（+11.9 %）。
> 0.0.87 要做的是同一件事在**一串**脉冲上的版本。动手时发现的问题比潜热本身严重得多：
> 那个工具返回的「最大可持续电流」从来不是可持续电流。

## 1. 缺口：一串脉冲问的不是一个问题

`repetitive_pulse_rating` 原来只回一个数——`max_repetitive_current_a`。它的定义是

```text
I² = area · h · P / (D · beta · rho(Ta))
```

这是一条**速率平衡**：铜每秒吸进来的焦耳热等于散出去的热。它里面**没有热容、没有熔点、也没有单发长度**。
它的真实语义是「再往上就连稳态静差都不存在」（runaway bound），而不是「再往上就会熔」。
两者在占空比高时差不多，在占空比低时差一个数量级——而低占空比正是脉冲工具的主要用途。

实测五组几何（宽 / 铜厚 / h / `t_on` / 占空比）：

| 几何 | 参数 | 不熔电流（新 `value`） | runaway 上界（旧 `value`） | 熔穿门槛 | 熔穿/不熔 | 熔穿/runaway |
|---|---|---|---|---|---|---|
| A | 0.5 mm / 1 oz / h=200 / 1 ms / 5 % | **29.617434** | 33.156444 | 29.717885 | 1.003392 | 0.8963 |
| B | 2.0 mm / 2 oz / h=50 / 10 ms / 20 % | **41.302920** | 46.121186 | 41.338090 | 1.000852 | 0.8963 |
| C | 0.5 mm / 1 oz / h=20 / 1 s / 10 % | **5.079179** | 7.414006 | 5.581757 | 1.098949 | 0.7529 |
| D | 0.5 mm / 1 oz / h=20 / 1 s / **1 %** | **5.284344** | 23.445147 | 5.881642 | 1.113032 | **0.2509** |
| E | 0.25 mm / 0.5 oz / h=30 / 0.1 s / 50 % | **1.279918** | 1.435716 | 1.286822 | 1.005394 | 0.8963 |

D 组：同一个铜、同样的脉冲长度，只把占空比从 10 % 降到 1 %，旧答案就变成真实可承受电流的 **4.436718 倍**。
（A/B/C 那种「约 0.89 倍」的印象只在中等占空比成立——那是 `thru/runaway` 这一列，不是旧答案/新答案。）

所以 0.0.87 把它拆成三个电流，各有各的名字：

| 键 | 含义 | 判据 |
|---|---|---|
| `value` = `max_current_without_melting_a` | 稳态峰值**恰好落在** 1083 °C 的电流 | 同一个精确映射上二分 `steady_peak(I) = 1083`，200 次 |
| `max_repetitive_current_a` | 速率平衡上界，数值与 0.0.86 **逐位相同** | `I² = area·h·P/(D·beta·rho(Ta))`，附 `_note` 说明它是上界 |
| `max_current_without_melt_through_a`（仅潜热模型） | 峰值可以钉在 1083 °C，只要停歇期能把储层排空的电流 | 逐发映射的不动点二分 60 次 |

第三个与潜热有关，前两个**与潜热无关**——边界处的脉冲正好在熔点结束，储层从未进入过。
这条分开很重要，否则「加了潜热却没抬高可持续电流」会被读成模型没接上。

## 2. 储层是 542.08 K，不是 542 K 的温升

熔化的那部分能量按 `L_f/c_p` 记成储层：

```text
latent_rise = 208700 J/kg / 385 J/(kg·K) = 542.077922 K
```

它**不是**温升（温度在 1083 °C 处停住），而是「还要再吸收多少焦耳·每千克」的记账单位。
逐发闭式（`_train_latent`）：脉冲内先解温度

```text
tA = ln((a + k·dTm) / (a + k·trough)) / k
```

`tA < t_on` 时脉冲先到熔点、剩下的时间以 `(a + k·dTm)` 的速率往储层灌 `gain = (a+k·dTm)(t_on − tA)`；
`tA >= t_on` 则整发都在升温、储层不动。停歇期以 `freeze_rise = dTm/tau` 冻结储层：
`t_hold < t_off` 时储层排空、沟底继续按 `exp(−(t_off−t_hold)/tau)` 冷却；否则整段停歇都钉在熔点上。

## 3. 逐发判定在临界点不可用，所以改成不动点二分

临界点附近沟底按 **1/n** 爬向不动点：B 组在 41.338 A 需要 **1e5** 发才稳定，4e3 发不够，
而 41.30 A 只要 4e3 发。用它做二分就是拿一个 1/n 的序列去判收敛。

改成解 `F(x) = x`（单调增映射，`x ∈ [0, dTm]` 上必有根），二分 80 次，然后判两条**不同**的熔穿条件：

```text
gain(x*) >= latent_rise              # 一发就装不下
gain(x*) >  freeze_rise · t_off      # 停歇期排不空
```

`_latent_settles` 与逐发参考实现的关系是**被交叉验证过的，不是假定**：
`tests/test_pulse_latent.py` 里写了一份逐发暴力实现（不碰任何闭式），
A/C/D/E 各两档有限发数（8 个点，305 / 70 / 2 / 1 / 1 / 1 / 100 / 23）逐一相等；
另有 4 个「稳定」点（0.98×门槛）在 2e4 发内不发散，与解析判据同向。
开发期间的探针跑的是 20 个点（含 40 %–140 % 门槛四档），20/20 一致。

## 4. 潜热做了什么、没做什么

**它推迟死亡**：在 0.95 × runaway 上（A 31.498622 A、B 43.815127 A），
sensible 模型 81 / 274 发熔，储层模型 139 / 467 发熔 ⇒ **+71.605 % / +70.438 %**。

**它能把死刑改成长寿**：A 在 1.005 × `value` 上 sensible 218 发就熔，储层模型 2360 发；
C 在 1.02 × `value` 上 sensible 3 发熔，D 在 1.02 × `value` 上 1 发熔，而储层模型**永不熔**
（停歇期足够长，每发都排空）。

**它不改可持续电流**：一个周期里进等于出，循环稳态存不住潜热。
`max_current_without_melt_through_a` 抬高的是「峰值可以贴着 1083 °C 走」的许可
（C +9.9 %、D +11.3 %），那是**另一个判据**，不是安全余量。所以信封里多一个键：

```text
max_repetitive_current_unaffected_by_latent = true
```

## 5. 绝热极限：本轮被自己的测试纠正的一处

`h = 0`、占空比 1、`I = fusing_current(0.5 mm, t_s=1.0, 1 oz) = 5.024 A`：

| `t_on` | sensible 发数 | 储层 发数 |
|---|---|---|
| 1.0 s | 1 | 2 |
| 0.5 s | 2 | 3 |
| 0.2 s | 5 | **7** |
| 0.1 s | 10 | **13** |

第一版测试把它写成 `ceil((1+β)/t_on)`——`(1+0.003861)/0.2 = 5.019`，ceil 是 **6**，实测 **7**。
所以那条「四档全中」的说法是错的（它是把 `0.2` 那一档算错了）。

真实规律是：储层**按熔点处的吸热速率** `φ = a(1 + β·dTm) = 2155.32 K/s` 被灌满，
而不是按冷态速率 `a = 423.86 K/s`，也不是按平均速率。

```text
额外通电时间 = (L_f/c_p) / φ = 542.077922 / 2155.3238 = 0.251506 s
```

实测每档的「多发了几发 × `t_on`」全部落在 `0.25–0.30 s`：`t_on=0.05` 多发 5 发 = 0.25 s、
`0.01` 多发 25 发 = 0.25 s、`0.005` 多发 51 发 = 0.255 s、`0.2` 多发 2 发 = 0.4 s（分辨率只有一个脉冲）。
测试断言「与 0.251506 s 相差不超过一个脉冲」，同时断言**不是**冷态速率（那要 1.279 s，5 倍）。

## 6. 负控制：把潜热当温升，差 2 倍以上

如果 208.7 kJ/kg 只是「再多 542.08 K」的温升，熔化时间会乘 `1 + 542.08/1058 = 1.512`；
真值是 `1+β = 1.003861`。因为潜热阶段站在 `ρ(1083)/ρ(25) = 5.08` 倍功率上走完，
时间上便宜、能量上昂贵。测试里把这两个模型都写出来，要求实测的额外通电时间
**不等于**温升模型（`extra < 0.7 × naive_extra`，实测约 0.5 倍），也就是这条判据能失败。

## 7. 默认关，且逐位不变

`melting_model` 缺省 / `None` / `"sensible"` 三种写法给出**逐位相同**的信封（`==` 比整个 dict），
默认信封里没有 `melting_model`、没有 `max_current_without_melt_through_a`、没有任何 `latent*` 键。
`value` 的语义变了，这一点**显著登记**在 CHANGELOG、README 一页速查和 `max_repetitive_current_a_note` 里——
不是静默改数：旧值仍以原名打印，并带一句「它是上界，不是答案」。

## 8. 仍未做

- `fusing_current_taper`（沿长度的温度梯度）**仍按熔点判**，报的熔断时间比带潜热短 **20.2 %**
  （0 °C 19.2 %、100 °C 23.1 %）。改对要把每节点状态从温度换成焓（`0..L_f` 储层），
  `_taper_coeffs` 的源项按 `T(H)` 分段，后向 Euler + Picard 迭代，且必须保留
  「绝热极限复现 Onderdonk」这个锚。这是换状态量级的改动，`not_implemented_yet` 已点名。
- 熔化后的体积变化与熔流、焊点合金化、铜箔与基材的分层，都不在任何模型里。
- 储层模型假设「储层里的能量只会被停歇期的导热排走」，不含熔化前沿的移动（那是 Stefan 问题）。
