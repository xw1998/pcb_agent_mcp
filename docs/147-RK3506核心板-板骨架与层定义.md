## 1. 两个新 spec：`inner_kinds` 与 `corner_radius_mm`

`create_board`（`src/pcb_agent_mcp/edit/plan.py` → `_build_board_text`）原来把所有内层一律写成 `signal`，板框只能是直角矩形。本步补两处：

| spec | 取值 | 作用 |
|---|---|---|
| `inner_kinds` | `["signal","power","mixed","jumper","user"]` 之一，长度 = 内层数 | 每层真实材质；非法值报 `EditError(..., "ARG_INVALID")` |
| `corner_radius_mm` | 浮点，`0 < r < min(w,h)/2` | 圆角板框；`>= min/2` 直接报错，`<= 0` 走原 `rect_as_lines` |

本板用 `inner_kinds = ["power","signal","power","power"]`（In1/In4 为 GND 平面，In2 信号，In3 电源分轨目标）。

### 圆角为什么要用 `gr_arc`，而不违反"禁弧"

**"不要用圆弧线"约束的对象是铜层走线**（`arc` 走线 = 0）。板框圆角属于 `Edge.Cuts` 的**机械几何**，KiCad 自己的圆角板就是 4 直线 + 4 `gr_arc`。若改成直线倒角，铣出来的板角就不是 R2 而是 45° 斜切，与机械图纸不符。这一点已写进 `build.rounded_rect` 的 docstring，避免后来者把它当违规删掉。

实现要点（`src/pcb_agent_mcp/edit/build.py`）：

- 4 条 `gr_line` 贴住四边（端点退让 r）
- 4 条 `gr_arc`，`mid` 落在 45° 对角线上（`arc3` 构造器早已存在，不新增 op）
- 半径校验在 `_build_board_text`，不在 `rounded_rect`，保证 `create_board` 是唯一写板入口

## 4. `plane_outline()`：圆角矩形铺铜轮廓

内层 GND 平面不是矩形：它要跟着 R2 圆角板框走，且内缩 `ZONE_INSET = 0.5`、圆角半径 `ZONE_R = 1.5`、弧采样 `ZONE_ARC_STEP = 15°`。

- 采样 `range(0, n+1)`（**含两端切点**）；早期 `range(1, n)` + 事后补切点会跨接自交，面积 1964.738 > 外接盒 1936，是自交的直接暴露
- 实测 **28 点 / 面积 1933.988 mm²**；解析值 1934.069，差 0.081 mm²（弧的折线化，非错误）
- 面积必须与解析值同向且略小，这是该函数的自检口径

## 5. `fill.py` 三处修复（每处都有失败原文）

`add_zone` 之前只服务 F.Cu/B.Cu 的老板，遇到 6 层板与 KiCad 10 的新写出格式就连错三处。

### 5.1 内层被硬编码拒绝

- 原文：`_COPPER_LAYERS = ("F.Cu", "B.Cu")`
- 失败：6 层板上 `add_zone(..., "In1.Cu", ...)` 直接 `BAD_LAYER`
- 修法：`_COPPER_NAME = re.compile(r"^(F\.Cu|B\.Cu|In(\d{1,2})\.Cu)$")` + `is_copper_name(name, limit=30)` 做早检；**解析板后再做精确校验** `board_copper_layers(board)`，不在板上报 `LAYER_NOT_ON_BOARD`。两层校验分工：正则管形状，`board_copper_layers` 管"这文件真声明了这层"——只在板上声明 4 层时写 `In5.Cu` 会静默消失。

### 5.2 网名读错一个参数

- 原文：`S.arg_text(node, 1)`
- 失败：`NET_NOT_FOUND: this board has no net 'GND'; 98 nets exist, e.g. 1, 10, 11…`（读到的是净编号）
- 修法：`text = S.arg_text(node, 2) or S.arg_text(node, 1)`。KiCad 10 写 `(net <code> "<name>")`，arg1 是编号，arg2 才是名字；老文件/hand-written 只有裸名字，所以保留 arg1 兜底。

### 5.3 Y 方向：`y_flip(board)`

`add_zone` 的 `points` 按**板坐标（Y 向上，人读图的方向）**收；而 `create_board` 写出的文件是 KiCad 自己的 Y 向下（板几何 y 全为负）。写错方向**不会**在 KiCad 里报错，而是轮廓镜像到板外，然后：

- 失败原文：`pcbnew refused to fill the zones: … kimathLogOverflow(): Overflow converting value -2147493567.024006 to int.`
- 修法：`y_flip(board)` 读该板已有的 `Edge.Cuts` 的 `start/end/mid` 的 y 均值判符号，`-1.0` = 文件 Y 向下，`_pts_block` 写 `_fmt_mm(y * flip)`。
- **为什么不加参数**：同一个 `add_zone` 也要服务 Y 向上的老板（`sky_star` 的 zone 在 `+139.8`），强行翻转会打坏它。判定法可解释、可复查；判定错时溢出会立刻暴露，不会静默出错铜。
- 复验：修好后 In1.Cu 上的同一多边形**一次通过**（见 §6），溢出不再出现。

## 6. `--planes` 实测：四层同文件逐层试，只有 In1.Cu 铺得出来

判据只用 `ZONE_FILLER` 的真实输出，不用轮廓面积代替填充面积。四层跑的是**同一份文件、同一个多边形、同一个网（GND）**，每次都在副本上先把已有 zone 全部剥掉再试：

| 层 | 结果 |
|---|---|
| `In1.Cu` | **ok**：`poured_zones 1`、`fill_area_mm2 1922.987`（轮廓 1933.988）、`filled_polygons 1` |
| `In3.Cu` | `ENGINE_FAILED` / `kimathLogOverflow(): Overflow converting value -2147493567.024006 to int` |
| `In4.Cu` | `ENGINE_FAILED` / 同一个溢出值 |
| `F.Cu`（外层对照） | `TIMEOUT` / `the engine did not finish filling in 300s` |

判读（**每一条都排除了一个候选**）：

- "输入板已经带填充多边形" 被排除——剥干净 zone 后 In3/In4 照样溢出；`_without_previous_fill` 那套 stale 处理不是这里的解。
- "多边形形状/顶点数/6 层堆叠/模板缺字段" 被排除——In1 用同一串文本成功。
- **剩下的判别式就是层本身**：In1 通，In3/In4 溢出，外层不返回。且溢出值是 `-2147493567`（≈ -2^31），`y_flip` 修好之后它**一分没变**，说明这不是 Y 方向问题（Y 方向的症状是轮廓镜像到板外，In1 已经证明翻转是对的）。
- 因此 `GND_PLANE_LAYERS` 仍是设计目标 `["In1.Cu","In4.Cu","B.Cu"]`，但本轮只铺 `PLANE_LAYERS_NOW = ["In1.Cu"]`；**In4 与 B.Cu 是欠账，不是结论**。`planes()` 遇失败记 `{"error","message"}` 后 `continue`，不允许一层的失败掩盖另一层的读数。

### 铺完后的 DRC 读数（`drc_after_fill`，如实照抄）

## 8. 用户实机打开报错：圆角弧的 `mid` 算错 ⇒ `kimathLogOverflow`（已修）

用户在 KiCad GUI 打开本板时弹出：

```
wxWidgets Debug Alert
C:\jenkins\...\libs\kimath\src\math\util.cpp(61): assert "Assert failure"
failed in kimathLogOverflow(): Overflow converting value -2147493567.024006 to int.
```

这与 `--planes` 里 In3/In4 失败的是**同一句断言**，所以两者同源。判读过程（每一步都是一次对照）：

| 对照 | 结果 |
|---|---|
| `examples/demo_board/demo60x40.kicad_pcb` 用 pcbnew `LoadBoard` | **rc 0，瞬间加载**（环境正常） |
| 把 demo 压成**单行**再加载 | **rc 0** ⇒ 单行格式不是原因 |
| 本板（骨架 + J1 + In1 zone） | TIMEOUT 40 s |
| 本板**删掉 zone** | TIMEOUT 40 s ⇒ zone 不是原因 |
| `_noJ1`（只有板框，2604 B） | **assert kimathLogOverflow**，rc 2147483651 |
| `_noJ1` **删掉 4 个 `gr_arc`** | **rc 0，加载成功** ⇒ **圆角弧是原因** |

根因在 `build.rounded_rect` 第 1 个弧（右下角）：

```lisp
(gr_arc (start 43 0) (mid 44.414214 -1.414214) (end 45 -2) ...)   ; 错
```

该弧圆心是 `(43, -2)`、半径 2。`mid` 到圆心只有 `sqrt(1.414² + 0.586²) = 1.531 = 0.766 r`，
**三点不在同一个圆上**，pcbnew 算弧心/弧角时除出奇异值 ⇒ int 溢出断言。正确 `mid` 是圆心沿
45° 走满 r：`(44.414214, -0.585786)`。四个弧里只有这一个写错（`y0 + d` 应为 `y0 + r - d`），
另三个恰好用了 `y - r + d` 的正确形式。

修复后（代码 + 已写出的板文件同改）：

- `LoadBoard`：**rc 0 / zones 1 / footprints 1**（带 J1 与 In1 平面正常打开）
- `--check`：`zones 1 / footprints 1 / nets 98`，`drc_violations 641`（`copper_edge_clearance` 138 → 140）

**教训（写进 docstring）**：`gr_arc` 的 `mid` 必须落在**圆弧上**，与起点/终点到圆心等距；
写成"角点斜向偏移"会在数值上看起来对、在几何上不是同一个圆，而 `kicad-cli` 全程读得下去
（stats / DRC / SVG 全绿），只有 pcbnew/GUI 才断言 —— 所以"CLI 全绿"不能当"文件能打开"的证据，
`kicad_cli` 的每个结论都必须与一次 `pcbnew.LoadBoard` 配对。

## 9 邮票孔整圈重排（0.1.10）

### 9.1 0.1.9 的断环是怎么来的

封装焊盘位置由 `tools/gen_som_footprint.py` 的 `edge_axis()` 生成，原式是 `-HALF + off`（N 边）/ `HALF - off`（S 边），也就是**整段锚在起始角点**上排。实测量到的旧落点：

| 边 | 首盘 | 末盘 | 到下一个边的首盘 |
|---|---|---|---|
| N（40） | `x=-22.5`（**板角点**） | `x=16.5` | pad 41 在 `22.5` ⇒ **空档 6.00 mm** |
| E（30） | `y=-22.5`（**板角点**） | `y=6.5` | pad 71 在 `(-)22.5` ⇒ **空档 6.00 mm** |
| S / W | 同构 | | |

于是肉眼看到的是「一圈点，每边突然缺一大口」，而且首盘压进 R2 圆弧区（`corner_clear = 0.00`）。

审计没拦住它，是因为 F5 用的是 `HALF - span/2`——**算的是假设居中的模型，而不是实际写进文件的坐标**。这类「审计与被审对象不是同一个量」的假绿，比几何错本身更难发现。

### 9.2 修法

- `edge_axis()`：`half_span = (count-1)*PITCH/2`，N `(-half_span+off, -HALF)`、S `(half_span-off, HALF)`、E `(HALF, -half_span+off)`、W `(-HALF, half_span-off)`。
- F5：改为对已生成坐标实测 `HALF - max(|min|,|max|)`，报错文案 `... (pad sits in the R2 arc)`。

### 9.3 新几何（实测，pcbnew 读回）

| 边 | 盘数 | 跨度 | 首盘 | 末盘 | 角点余量 |
|---|---|---|---|---|---|
| N | 40 | 39.0 | `-19.5, -22.5` | `19.5, -22.5` | 3.00 |
| E | 30 | 29.0 | `22.5, -14.5` | `22.5, 14.5` | 8.00 |
| S | 40 | 39.0 | `19.5, 22.5` | `-19.5, 22.5` | 3.00 |
| W | 30 | 29.0 | `-22.5, 14.5` | `-22.5, -14.5` | 8.00 |

盘 0.85 / 孔 0.55 / 节距 1.000 不变（`docs/143 §5` 冻结）。四角 R2 内无盘。

### 9.4 出图口径（两条必须记住的读数）

1. **`--scale 1` 会裁板**：板在文件里落在负 Y 区（`y -45..0`），默认页面从原点向上排，实测墨迹只剩 4887 px 且 bbox 贴左/上边界。**`--scale 0`（autoscale）完整且保彩色**，这才是给人看的图。
2. **`PLOT_CONTROLLER.SetColorMode(True)` 对 PDF 无效**：pcbnew 逐层绘图实测整图只有灰阶（`0/68/87/88/117/192/221/255`），要彩色走 `kicad-cli pcb export pdf`（默认彩色，色值实测 `In1 Cu 127,200,127`、`B.Cu 77,127,196`）。
