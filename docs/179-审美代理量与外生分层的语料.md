# 179 - 审美代理量与外生分层的语料

上一版结尾登记了两件「没做到」的事，这一版把它们做掉：

1. **审美代理量**：`detour_ratio` 只能抓「某一条网绕了一大圈」，`shape_gate` 只会拒绝「这坨铜不许出厂」。
   两者在「两块板都合法、都干净，哪一块更好看」这个区间里**都是平的**——而这正是用户一直在问的问题。
2. **语料分层**：`judge_corpus` 只数失败率，把一块 2005 年的两层演示板和一块 2024 年的量产板当同一把尺子用。

这一版没有动任何既有的判据：八关、`shape_gate` 五条、`place_gate` 五条、DRC 是判官，全部原样。
新加的三件东西（`aesthetics.py`、`board_aesthetics` 工具、`plan_sequence` 里的分层）都是**读数与证据，不是裁决**。

## 1. 审美代理量：六条读数

全部从 canonical 几何算出来，可复现，每条都带方向。

| 读数 | 是什么 | 越高越好？ |
| --- | --- | --- |
| `chunk_median_mm` | 单段长度中位数 | 是（长直跑是眼睛读到「干净」的东西） |
| `bends_per_100mm` | 每 100 mm 铜的转向次数 | 否 |
| `bends_per_pad` | 每个焊盘的转向次数 | 否（密度归一化的孪生读数） |
| `bundle_share` | 与另一张网并行同行的铜占比 | 是 |
| `long_seg_share` | ≥ 5 mm 的段数占比 | 是 |
| `collinear_per_100mm` | 每 100 mm 铜的「拼接点」（一根直跑被存成两段） | 否（这是浪费，不是丑） |

另有两个**不排序**的读数：`via_per_100mm`（`better_when: no_direction` —— 密集 BGA 用过孔是为了布得更好，
低不是美德）、`offgrid_share`（这是 `shape_gate` 的辖区，这里只报数）。

### 转向怎么数

`_leave_heading` 给的是「从关节沿这一段离开」的朝向。所以：

- 两根共线的段，离开方向**相反**（夹角 d ≈ 180°）⇒ `change = 180 − d ≈ 0` ⇒ **拼接点**，不是弯；
- 真正的 90° 转弯：`change = 90`；45° 倒角：`change = 45`；135° 发夹：`change = 135`；其它进 `off-grid`。

这一版修掉了两个把读数算错的实现缺陷，两个都只在**反向对照**里才看得见：

1. **共线判定写反了**。原来判 `d <= 1°` ⇒ 把「共线」写成了「180° 原路折返」。症状：`(10,10)-(20,10)` 与
   `(20,10)-(30,10)` 两根共线段被读成 1 个弯、`collinear = 0`，`bends_per_100mm` 直接虚高。
2. **T 型支线完全看不见**。三根铜在一个点相遇会被数成 tee，但**支线端点落在干线中段**时（这是最常见的形态）
   两端都不是「端点对端点」，于是既不算弯也不算 tee，**从读数里消失**。现在用 `geometry.dist_point_segment`
   + 2 mm 网格分桶补上，并把它从 `dangling_ends` 里摘出来（它不悬空，它接在别人身上）。

### 一个被读数纠正的测试板

`tests/test_aesthetics.py` 里原来那块「阶梯」把每一段的末端正好叠在下一段的末端上，于是每个交点有**三根**铜
——读数是 `tees_or_stars` 而不是 bend，`compare` 判 `incomparable`。这不是读数错，是那块测试板本身画错了：
它在数据里就不是一条连通的路径。改成真正的链式阶梯后，15 个 90° 弯、读数与手算一致。

### 2.1 五条能分开手画与自画，第六条不能

| 读数 | 手画 | 自画 | 语料中位 | 语料区间 | 能分离？ |
| --- | --- | --- | --- | --- | --- |
| `chunk_median_mm` | 1.344 | 0.361 | 1.796 | 0.277–3.493 | 是 |
| `bends_per_100mm` | 33.24 | 77.40 | 21.49 | 9.15–136.53 | 是（2.3 倍） |
| `bends_per_pad` | 1.43 | 4.78 | 1.65 | 1.10–3.64 | 是（3.3 倍） |
| `bundle_share` | 0.245 | 0.160 | 0.118 | 0.000–0.351 | 是（最弱的一条） |
| `long_seg_share` | 0.109 | 0.053 | 0.188 | 0.009–0.393 | 是 |
| `collinear_per_100mm` | 0.553 | 0.119 | 1.659 | 0.823–8.426 | **否** |

`collinear_per_100mm` 就是那个诚实的坑：它被排进 `DIRECTED`（浪费就是浪费），但**手画板的拼接点比本项目自画板多 4.6 倍**
——它反映的是工具怎么存段，不是手艺。所以 `CALIBRATION` 给它 `separates: False` 并附一句「never a craft verdict」，
`report()` 把它一起吐出来。沉默会让读者以为六条都能分离。

同样要写清楚的两条：手画板的 `chunk_median_mm`（1.344）与 `bends_per_100mm`（33.24）**都比语料中位更差**
（1.796 / 21.49）。原因是它密（462 pad）：长短跑被扇出短桩切断。它分开的是手画 vs 自画，不是手画 vs 全世界。

### 2.2 密度混淆，不是「谁更好」

`bends_per_100mm` 与 `bends_per_pad` 是同一个量的两种归一化。**一块板在一条上赢、在另一条上输时，`compare`
判 `confounded`，并写明 `density`** —— 差异来自铜的密度，不是布线的水平。这与仓库里「比值判据能被整体增益骗过」
是同一条防御。

`tests/test_aesthetics.py` 的反向对照直接构造了这对：A = 1 mm 铜 / 1 弯 / 100 pad（每 100 mm 惨、每 pad 好），
B = 100 mm 铜 / 10 弯 / 1 pad（反过来）⇒ 必须报 `confounded`，不许出胜者。

## 3. 排序语义：不给权重，只给排序与分歧

`compare(boards)` 返回：

- `pairs[].verdict` ∈ `a_dominates` / `b_dominates` / `tie` / `incomparable`。**支配**=每条有方向的读数都不差、
  至少一条严格更好。`incomparable` 时**把互相分歧的读数点名**（`a_better_on` / `b_better_on`），不平均掉。
- `order_by_borda`：每条有方向读数的百分位的均值。它唯一的加权假设是**每条读数算一票**，这一点写在返回值里
  （`how_to_read`），不藏。
- `pareto_front`：没被任何板支配的那些板。
- `not_ranked`：所有板读数相同（`every board reads X - the reading cannot tell them apart`）或可判板不足两条的读数。
- `skipped`：**没有铜的板被点名并给出原因，不参与排序**，也不被打 0 分——「文件里没有铜」是关于文件的事实，
  不是关于铜的事实。少于两块**输入**板 ⇒ `NOT_ENOUGH_BOARDS`；一块能读都没有 ⇒ `NO_GEOMETRY`。

## 4. 语料分层：证据必须外生

`judge_corpus` 原来说的是「12 块好板子里有几块过了这条规则」。它有一个致命的循环：**规则自己**决定哪块算好板。
所以分层用的证据**不能是八关自己的判词**，只能是外部引擎：

- 证据来源：每块板旁边一个 `<board>.kicad_pcb.drc.json`，由 `kicad-cli pcb drc --format json` 生成；
- 计分：`error + unconnected`，**排除 `lib_footprint_issues`**（它说的是库，不是铜）；
- 没有报告 ⇒ `unverified`，**永远不落进任何一层**（不是「算好的」，也不是「算差的」）；
- 分桶：按排名三等分（`low/mid/high` 各 4 块）。不用绝对阈值——2005 年的演示板和 2024 年的板不共享尺度。

| 层 | 板 | 缺陷数 |
| --- | --- | --- |
| low | complex_hierarchy / ecc83 / interf_u / multichannel | 1 / 0 / 3 / 0 |
| mid | microwave / pic_programmer / tiny_tapeout / video | 8 / 8 / 248 / 27 |
| high | cm5_minima / openair-max / royalblue54L_feather / stickhub | 1367 / 439 / 1226 / 795 |

`judge_strata` 的判词（每条规则一个）：

| code | 什么时候 | 说什么 |
| --- | --- | --- |
| `no_strata` | 一块板都没有证据 | 分层无从谈起 |
| `house_rule_not_stratified` | 规则类型是 `house` | 「本项目方针」——语料不过不构成反证，分层也不行 |
| `layering_silent` | 最干净一层判得了的 < 3 而整体 ≥ 0.9 | 不追加证据，也不假装加了 |
| `low_stratum_thin` | 最干净一层判得了的 < 3 | 样本不足，不下结论 |
| `low_stratum_unmeasured` | 有样本但读数缺失 | 同上，原因不同 |
| `hold_across_strata` | 最干净一层也过 | 分层不改变判决（最强的支持） |
| `rule_flags_cleanest` | 最干净一层挂了 | **规则被语料定罪** |
| `refuted_on_cleanest` | 同上但整体也低 | 同上，措辞更硬 |

关键一条：**只有最干净的一层能定罪**。脏板上过不了任何规则都不说明问题——它本来就脏。

## 5. 反向对照（`tests/test_aesthetics.py`，25 例）

- 读数**该动**：阶梯比直跑差；40 mm 存成两段 = 同样的弯、多一个拼接点；45° 倒角与 90° 直角分得开；
  tee 不算弯；两根不同网并行 0.3 mm 是 bundle、12 mm 不是；蛇形自己不算 bundle；pad 数归一化。
- 读数**该不动**：把每根段反向写一遍、整板平移 50 mm，六条读数一格都不许变（依赖「哪端先写」的读数不是在量铜）；
  不同层不许形成关节。
- 排序**该拒绝**：一块板 ⇒ `NOT_ENOUGH_BOARDS`；两块空板 ⇒ `NO_GEOMETRY`；一块干净一块空 ⇒ `ok` 但空的进 `skipped`。
- 校准表**会自检**：每一条声称能分离的读数，都要把 `hand − machine` 按 `DIRECTED` 的符号读成正数——
  方向写反在表里看不出来，在 `compare` 里是致命的。

## 6. 没做到 / 欠账

- `chunk_median_mm` 与 `bends_per_100mm` 上手画板比语料中位差（见 2.1）。它们分开的是「手画 vs 自画」，
  不是「好 vs 坏」，引用时必须连语料中位一起写。
- `bundle_share` 需要网名：12 块语料里有 8 块 `bundle_share = 0.0`（两层演示板，没有并行网），
  中位被拉低。这个读数在 `nets_known=False` 时会标 `degraded`，但「0.0」和「测不出」看起来一样，引用时要看标志位。
- 语料 12 块里 `microwave` 一条铜都没有（纯教学工程），六条读数全空，只在分层里以 `defects=8` 存在。
- `floorplan` 与 `stackup` 的分层读数暂时没有分辨力（干净层样本 0–2 块）。要判它们得先扩语料中干净的两层板。
- 没有做**图像美学**（对齐、间距节奏、丝印层次），那是 `layout_quality` 与 `place_gate` 的辖区；
  也没有做**焊盘级扇出几何**：0.4 mm 间距 BGA 必须每球一条 dogleg，`bends_per_pad` 就是为这件事存在的孪生读数。
- 全量 `pytest tests/` 超过 33 分钟没跑完，本轮只跑了定向子集（结果见下），这一点如实记下。
