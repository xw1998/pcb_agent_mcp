# 开边辐射 Q、开边失谐与 Huray 结节

> 0.0.60。`cavity_plane_q` 的 docstring 一直列着三件**明说不做**的事：radiation Q、
> Huray 结节模型、以及「真实的开边会把共振往下拉几个百分点」。第 63 篇把这三件做成
> 三个新工具（`plane_radiation_q` / `plane_open_end` / `roughness_huray`），**并且
> `plane_q` 一行未改** —— 旧答案逐位不变，这是这一轮的硬约束，不是客气话。
>
> 三件事各有一个「能翻脸」的锚点：辐射 Q 的锚点是**闭式** `er·a/(6h)`（手算 ∫cos²，
> 不是自洽回读）；开边失谐的锚点是**引文里的电容式**（Yariv 2021 eq. 5.20），把
> 「一个边只算一半修正」这个因子 2 钉死在别人的公式上；Huray 的锚点是 `x = 1` 处
> **精确** `F = 1/√5` 与两条极限（δ→0 得 `RF`、δ→∞ 得 1）。

## 63.1 为什么不能给 `plane_q` 加参数

三个理由，都不是风格问题：

* **默认路径会变**。辐射 Q 一旦进 `plane_q`，`Q_total` 的默认答案就变了（50 mm /
  0.2 mm 上 `Q` 从 115.07 掉到 70.07，掉 39 %）。既有答案不许静默改变 ⇒ 新工具。
* **输入不是一类**。结节模型要的是「半径 + 表面比」（或密度），开边要的是「哪几条边
  开着」，两者与 `plane_q` 的 `(f, h, tanδ, sigma, Rq)` 没有交集。
* **物理不在一个层级**。`plane_q` 给的是**腔内的损耗**（铜 + 介质），辐射是**腔外**
  的能量流失，开边失谐甚至不改 Q 只改频率 —— 合成一个函数会把「模态位置」和
  「模态阻尼」这两类问题又糊在一起，而这正是 `cavity.py` 当初把 `plane_resonance`
  和 `plane_q` 拆开的原因。

工具数 165 → **168**。

## 63.2 辐射 Q：一次漏了 k² 的推导，和它自己带出来的闸门

第一版手推得到的结论是「单位宽度辐射电导 `G′ = 常数`，与 λ 无关」，于是
`h → 0` 时 `P = E₀²hl/(2η)` 不趋零 —— **物理上不可能**（缝越窄越该像全反射）。
错在**漏了 k²**：开边不是静电场问题，等效磁流 `M = −2 n̂ × E` 的辐射功率是

```
P = k²|K|²/(12πη₀),   K = M·A   （磁流矩，量纲 V·m）
```

`A = h·l` ⇒ `P ∝ h²`，`h→0` 时正确地趋零。第二条路径（2-D 磁线源对偶，
`E_z = −(ωμI/4)H₀⁽²⁾(kρ)`）给出**同一个值**：每单位宽度

```
G′ = ω·ε₀ = k₀/η₀
```

于是 `P = (1/2)·ω·ε₀·∫V²dl`（每条开边），`U = (1/2)·ε₀·εr·(1/h)·∫∫V²dA`，`ω` 在
`Q = ωU/P` 里**约掉**：

```
Q_rad = εr · ∫∫(V/V₀)²dA / ( h · Σ_open ∫(V/V₀)²dl )
```

方形、四边全开、`V = V₀cos(mπx/a)cos(nπy/b)` 时 `∫∫cos² = a·σm·b·σn`

```
(1,0):  Q_rad = εr·a/(6h)        (1,1):  Q_rad = εr·a/(8h)
```

这两条是**手积分**，测试直接对它们断言 —— 50 mm / 0.2 mm / εr 4.3 给
**179.167** 与 **134.375**。

**模型自带的闸门**（不是拍出来的阈值）：一条窄缝流失的入射 TEM 功率份额是
`G′·η₀·h = k₀h`，所以 `k₀h ≥ 1` 时「辐射的比进来的还多」，模型自相矛盾 ⇒
`MODEL_SCOPE` 拒绝；`k₀h > 0.1` 打 warning。50 mm / 0.2 mm 给 `k₀h = 0.00606`，
安全；`h = 100 mm` 给 3.03 ⇒ 拒绝（实测）。

**plausibility 证据**（没有拟合常数）：50 mm / 0.2 mm / εr 4.3 的 `Q_rad = 179`，
1.6 mm 上 `Q_rad = 22.4`，正好落在文献里平面腔辐射 Q 的「几十到几百」区间。

## 63.3 开边失谐：因子 2 是谁给的

开边把共振往下拉，因为边缘场让**等效**板长变大。闭式来源是

> E. Yariv, *Edge corrections for parallel-plate capacitors*,
> Euro. J. Appl. Math. **32** (2021) 226–241, Open Access,
> doi:10.1017/S0956792520000108，eq. (5.20) / (A5)。

原文（单位宽度，两板长 `2l`、间距 `2h`）：

```
C ≈ ε₀ [ l/h + (1/π)(ln(2π l/h) + 1) ]
```

这**一个**修正项属于**两个端**。把它写成「多出一段平行板长度」`2Δl`，并要求两边**恒等**：

```
ε₀ (a + 2Δl)/h  ==  ε₀ [ a/h + (1/π)(ln(2π a/h) + 1) ]     ⇒
Δl = (h / 2π) · ( ln(2π·a/h) + 1 )
```

`a` 是该边**垂直方向**的板尺寸（因为 `l/h = a/h`）。这就是「单条边只算一半」的来源 ——
不是约定，是别人的公式除以 2。测试 `test_extension_is_the_halved_yariv_correction`
做的就是这件事：**函数自己的 Δl 与引文式在 1e-5 内相等**，若有人把因子 2 写错，
这条立刻红。

数字：50 mm / 0.2 mm ⇒ `Δl = 0.266086 mm`（`Δl/h = 1.33043`），(1,0) 移
**−1.05313 %**；同板 1.6 mm FR4 ⇒ `Δl = 1.59916 mm`，移 **−6.01208 %**（几百 µm 的
板边对薄介质的位移远大于直觉）。

频率：

```
a_eff = a + nx·Δl(a),  b_eff = b + ny·Δl(b)
f_eff = c/(2√εr) · √((m/a_eff)² + (n/b_eff)²)
```

**二阶项是可预测的**，所以它不是容差而是判据：一维模 `f ∝ 1/a` ⇒ `f_eff/f0 = 1/(1+ε)`，
而一阶式恰是 `−ε`，两者相对差必然等于 `−ε/(1+ε)`（实测 −1.05313 % vs 一阶
−1.06434 %，`ε = 0.01064344`）。通用的 (m,n) 下界是 `|相对差| ≤ max(ε_a, ε_b)`
（50×30 的 (1,1)：−1.55124 % 对界 −1.66551 %）。

三条自带负控制：

* **(1,0) 模只开 y 边 ⇒ 位移精确 0**（模式看不见那个方向）。任何「两个方向一起拉伸」
  的实现能通过本节其余全部测试，只在这里翻脸。
* 单边 = 两边的一半（`Δl` 精确成半；位移按 `2(1+ε)/(1+2ε)` 而非 2，这条也是预测）。
* `a/h < 10` 拒绝（Yariv 是大长宽比渐近式），10.0 通过、9.9 拒绝 —— 边界精确。

## 63.4 Huray 雪球：统一式、knee、以及一个漏掉的 2π

来源：Yu. Shlepnev, *Unified approach to interconnect conductor surface roughness
modelling*, EPEPS 2017（免费 PDF：simberian.com），式 (1)/(4)/(5)。

```
K = 1 + (RF − 1)·F
F = 1/√(1 + 2x + 2x²),   x = 2δ_s / r
RF = 1 + 3·N·π·r²·(2/A_hex) = 1 + (3/2)·sr      （sr = 4πr²N/A_flat，Hall-Huray）
```

极限自检两条：`δ → 0`（x→0）⇒ `F → 1` ⇒ `K → RF`；`δ → ∞` ⇒ `F → 0` ⇒ `K → 1`。
knee 在 `x = 1`（即 `δ = r/2`），此处 `F = 1/√5 = 0.447214` **精确**，`K = 1 + 0.447(F−1)`。

**knee 频率的定义式是 `ω = 8/(μ₀σr²)`，要再除 `2π`。** 第一版漏了这个 `2π`，于是
报告的 knee 落在 `δ = r/2.5` 而不是 `r/2`（测试 `test_knee_frequency_is_where_x_is_one`
就是抓这个的：它不信 `knee_frequency_hz` 这个字段，而是拿**频率回代**算 δ 与 `r/2` 比）。
修正后 1 GHz 的表格里 knee = **69.8767 GHz**（`knee_skin_depth_um = 0.25` = r/2）。
登记：这是 0.0.60 尚未发布的代码里自查出来的，没有已发布答案被改。

1 GHz 实测（r = 0.5 µm）：`δ = 2.08981 µm`、`x = 8.35923`、`F = 0.079689`、
`RF = 2.5`、`K = 1.11953`（+11.9534 %）；同一个点 Hammerstad（Rq = 0.5 µm）
给 `1.05091`，比值 1.0653 —— 两个模型**不是同一个参数化**，所以工具只并排报，
**不做 Rq ↔ (r, sr) 换算**（这一点写进 `hammerstad_comparison.model` 原文）。

10 GHz / sr = 6：`x = 2.64342`、`F = 0.222155`、`RF = 10`、`K = 2.99940`。

拒绝：`r > λ₀/100`（准静态前提，1e20 Hz 必须**拒绝而不是钳住**）、`sr > 30`（半球
互相重叠之前的上限，出版参数只到 1/3/6）、`sr` 与 `nodule_density_per_mm2` 同时给
（同一块地毯的两个说法，冲突时不许静默挑一个）、`sr = 0` ⇒ `K` **精确** 1.0
（负控制：光滑面不可能变差）。

## 63.6 这一轮不建模什么（写进 `assumptions` / 精度栏）

* 辐射：air 侧按 ε₀/μ₀ 算，**介质板与铜同时截止**（缝不是半埋的）；模态用未扰动的
  `cos·cos`；「关」的边是 PMC 墙 —— 真实过孔栅会漏，那不是边缘辐射；**没有角点修正**
  （边按无限长处理）。对 3-D 求解器差**几十个百分点**，读数只能用来判「这里辐射到底
  算不算个事」。
* 开边：`a/h ≥ 10` 的渐近式；同样没有角点修正；只改**频率**，不改 Q（Q 的修正属于
  微扰后重新积分，本轮不做，且已登记）。
* Huray：`σ`、`μ` 是单个常数；粗糙度只乘铜的 `Rs`（介质渗入齿间、粗糙度改电场、
  `Rz ↔ Rq` 换算都没做）；`r` 与 `sr` 是**独立参数**，不许与 Rq 互推。
* 三处共有的那条老纪律：**有 Q 不等于有判决** —— 共振是否成问题要看激励与耦合，
  三个工具都不给 pass/fail。
