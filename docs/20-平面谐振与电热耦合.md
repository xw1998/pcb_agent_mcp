# 20 · 平面谐振与电热耦合

两个问题都是"板子自己把自己搞坏"：

- **平面谐振**：两块铜箔夹一层介质就是一个腔体。到某个频率它开始振，那一刻"地平面"不再是地，
  而是两层之间立着驻波电压的辐射体。本层只回答两件事——**模在哪**、**缝合过孔要多密**。
- **电热耦合**：电流把铜加热，热了的铜更电阻，于是更热。这个环只有两个诚实结局：收敛到一个温度，
  或者热失控。本层解这个环，并**报出是哪一个**。

两者的共同纪律与前面几层一致：能推的推，推不出来的（Q、边界失谐、Rth、λ_g/20 判据）明确交给调用方，
不给一个"看起来合理"的默认值。

---

## 20.1 平面谐振：为什么只给模频，不给"能不能用"

矩形腔体（上下铜箔 PEC、四周理想磁壁 PMC）的 TM_mn0 模：

```
f_mn = c / (2·√εr) · √( (m/a)² + (n/b)² )      m,n ≥ 0，不同时为 0
λ_g  = c / (f·√εr)
```

注意三件事，都是模型自带的：

1. **f 不含板间距 h。** 平行板腔体模的谐振频率与两层间距无关（只与平面尺寸和 εr 有关）。
   所以"把介质做厚一点"不能推开模频——想推只能改尺寸或 εr。
2. **侧壁是 PMC，不是 PEC。** 真实平面边缘是开放的，会让模频**偏低**几个百分点；过孔围栏只是
   让边界"像"磁壁。本项目不做任何修正，返回里写清"这是教科书值，实物会有几个百分点的失谐"。
3. **不算 Q。** 介质 tanδ、铜损、辐射 Q 一个都没有。所以本层**不判"这个谐振是不是问题"**——
   一个 3 GHz 的模可能被有损半固化片完全压死。判据需要激励、Q 和耦合路径，那是场求解器的活。

100 × 80 mm、εr = 4.3 的实测输出（`cavity_resonance`）：

| m,n | f | 检查 |
|---|---|---|
| (1,0) | 0.722864 GHz | = c/(2√4.3·0.1 m)，且 λ_g = 200 mm = 2a（半波的定义） |
| (0,1) | 0.903580 GHz | = f₁₀·a/b = 0.722864 × 1.25 |
| (1,1) | 1.15715 GHz | = √(f₁₀² + f₀₁²)（正交叠加） |
| (2,0) | 1.44573 GHz | = 2f₁₀ |

方板时 (1,0)/(0,1) 严格简并：返回里**分成两行**而不是合并，让人看得见重数。

## 20.2 过孔围栏：判据是调用方的，不是我的

`cavity_via_fence` 算的是事实：`pitch/λ_g`、每个间距的电长度（度）、`vias per λ_g`。

"多密才够"这件事不同来源差 2 倍：`λ_g/20` 与 `λ_g/10` 都在流传，**两者都不是推出来的**。
所以：

- 只给 `pitch_mm` → 回比例 + `verdict: indeterminate`，并在 `verdict_reason` 里点名
  "λ_g/20 和 λ_g/10 都在流传，本模块不替你挑"；
- 给了 `max_pitch_ratio` → 才判 `pass/fail`，并回 `max_pitch_mm` 与 `margin_mm`；
- 只给判据不给间距 → 回 `max_pitch_mm`（这是有用的那一半），判 `indeterminate`，**不反推一个间距**。

同一块板、同一个 15 mm 间距，`max_pitch_ratio=0.05` 判 `fail`、`0.10` 判 `pass`——测试里就是这么断言的，
因为**判据不能内置**这件事必须有一条用例守着。

不建模：过孔孔径/反焊盘（0.3 mm 与 1 mm 的围栏被当成同一堵墙）、行数、围栏自身的阻带、
以及平面被挖空处的缝隙泄漏（这才是混信号平面真正失效的方式）。

## 20.3 电热耦合：环 + 精确的失控判据

```
R(T) = ρ₂₀·(1 + α·(T − 20))·L/(w·t)
P    = I²·R(T)              （只算直流电阻损耗）
T    = T_amb + P·Rth        （Rth 由调用方给，一个集中量）
```

写成 ΔT 的定点迭代：

```
ΔT(n+1) = A + G·ΔT(n)
A = I²·R20·Rth·(1 + α·(T_amb − 20))
G = I²·R20·Rth·α          ← 就是 dP/dT·Rth，热失控增益
```

`G < 1` 才存在不动点 `ΔT = A/(1−G)`；`G ≥ 1` 时**不存在稳态**，返回
`THERMAL_RUNAWAY` 并给出 G，而不是把第 N 次迭代当答案。这是**精确判据**（用参数算出来的），
不是"迭代不收敛就报错"那种事后猜测。

`G` 很接近 1（如 0.98）时确实收敛，但残差衰减极慢，`iterations` 会如实变大、`stability_margin`
（= 1 − G）会很小——这两个数就是"这个设计离悬崖有多远"的读数。

### 手算金标（测试与自检都用这一组）

R20 = 0.01 Ω、I = 1 A、Rth = 50 K/W、α = 0.00393 /K、T_amb = 25 ℃：

```
A = 1·0.01·50·(1 + 0.00393·5) = 0.5098250
G = 1·0.01·50·0.00393         = 0.001965
ΔT = A/(1−G) = 0.510829 K  →  T = 25.5108 ℃
R_hot = 0.01·(1 + 0.00393·(25.5108 − 20)) = 10.2166 mΩ
校核：P·Rth = 0.0102166·50 = 0.510829 = ΔT ✓
```

失控侧：R20 = 1 Ω、I = 2 A、Rth = 300 K/W → `G = 4·1·300·0.00393 = 4.716 ≥ 1` ⇒ 拒答。

走线版（`electrothermal_trace`）只是把 R20 从几何算出来：
20 mm × 1 mm × 35 µm 的铜，R20 = ρ·0.02/(0.001·35e−6) = 9.85143 mΩ，Rth = 100 K/W →
ΔT = 1.00841 K、T = 26.0084 ℃。

### 为什么 Rth 必须由调用方给

本层完全不知道你的叠层、铜面积、过孔、风速。默认 Rth 会是整层里**唯一一个不是推导出来的数**，
和 `dfm` 不内置板厂表、`steinberg_fatigue` 必须给 `z_allow_mm` 是同一条纪律。
Rth 的来源是 `thermal_stack` / `thermal_via_array` / `thermal_plate`，或者实测。

替身口 `electrothermal_conductor` 让这个环可以套在**任何**已知 R20 的东西上：过孔桶壁
（`via_resistance`）、分段串联（`ir_drop_chain`）、分流器、连接器针脚。

## 20.4 不做的东西（逐条写在每次返回里）

- `cavity_resonance` 的**模频**没有 Q、没有损耷、没有开放边缘失谐 ⇒ 它只是频率轴上的一个位置，不是判决。
- **峰值**由另一个工具给（§20.8）：`pdn_plane_modes` 取 `Q=1/tanδ`，给每个带内模的 `|Z_peak|`；
  0.0.49 起整条曲线的模态和也有工具（`pdn_plane_impedance`，需要焊盘尺寸，见 §20.8.3 的修订
  与 `52-平面阻抗曲线.md`），但它算的是**平面自己**——没有电容、没有封装，因此仍不声称平面与
  电容之间的反谐振。
- 0.0.50 起**平面 + 你列出的电容**的整条曲线也有工具（`pdn_plane_with_caps`：腔体当
  (N+1) 端口 Z 矩阵，每颗电容是一条 R-L-C 支路，端口降阶，见 `53-平面电容反谐振.md`）。它算
  得出反谐振在哪里、加载峰相对平面峰是升是降，但**不选型、不优化、最多 8 颗**，`esr`/`esl`
  是你给的数，die/package 与过孔桶壁仍在外。
- 平面与电容组并联后的**集中参数**曲线仍只是 RLC（`pdn_impedance`，带 `plane=…` 时只做诊断，
  不改那条曲线）；封装电感、分割平面、过孔桶壁电感都在外面。
- 电热耦合的**集中 Rth 那一层**（`electrothermal_trace` / `electrothermal_conductor`）只有
  一个标量 Rth；板级的 2-D 那层见 §20.6，但它铺的是介质 k，不是真实铺铜。
  没有 3-D、没有辐射、没有热过孔、没有器件热容与接触热阻、没有交流损耗（趋肤/邻近效应）、
  `sim_spice` 里的器件不发热；`board_ir_drop` 也不把自己的 I²R 反馈进温度场。

## 20.6 板级 2-D 场：从"一坨 Rth"到一个温度分布

§20.1 的耦合是标量：`dP/dT * Rth < 1`，Rth 由调用方给。板级场景（一条走线、一片铺铜、一堆
功率器件撒在 50×50 上）没法用标量回答——热点在哪、角落多热，都是场问题。
`board_electrothermal` 把它变成一个均匀矩形网格上的**线性**问题：

    k*t*lap(T) - 2h*(T - Ta) + q(T) + C*dT/dt = 0

### 20.6.1 让稳态变成严格线性的一步

`q(T) = I²R(T)`，而 `rho(T)` 是线性的：

    q(T) = q_ref*(1 - alpha*20) + q_ref*alpha*T

`q_ref` 在 20 ℃ 上算一次，于是 `alpha*T` 那项**挪到矩阵对角线上**：

    den = hc + capdt - q_ref*alpha         # hc = 2h 的面散热，capdt = C/dt

对角化之后稳态问题是**严格线性**的（不是牛顿迭代、不是伪时间步），一次 SOR（ω=1.85）就收敛。
瞬态用**后向 Euler**：无条件稳定，`dt` 只影响精度不影响是否炸。

### 20.6.2 失控必须"求解之前"判

这条是被真事教出来的：第一版把失控判据放在解完之后，13 W 的均匀板让 SOR 一路跑到 NaN，
`int(f*9.999)` 抛 `ValueError`，白烧 60 s 才报错。而对角是**逐格常量**，不需要解就能判：

    diag = hc + capdt - q_ref*alpha
    任一格 diag <= 0  ->  THERMAL_RUNAWAY（并指名是哪一格）

均匀板上它精确退化成 1-D 的 `P*alpha < 2hA`（50×50、h=10 ⇒ 2hA = 0.05 W/K ⇒ 阈值 12.7226 W）。
解完之后还有第二道防线：`t_min < Ta - 1e-6` 判非物理，非有限值判 `NOT_CONVERGED`——
SOR 在病态矩阵上会给出"看起来收敛"的垃圾，这两条拦住它。

### 20.6.3 导体怎么上网格：功率精确，分布量化

`_seg_cover(...)` 取"格心到线段距离 <= width/2"的格子。每根走线的总 `I²R` **精确平分**到
被覆盖的格子上，所以**总功率与网格无关**、只有分布被量化。`layers` 当作两端缝合的并联铜
（`R = rho*L/(w*t*layers)`）。比网格还细的线不猜：直接拒答，并说 "thinner than the grid"。

### 20.6.4 唯一有闭式解的情形，就是锚点

均匀功耗的板子有手算答案（把 `q(T)` 代进平衡式解一次）：

    T = (hc_tot*Ta + q*(1 - 20*alpha)) / (hc_tot - q*alpha)

`uniform_power_w` 因此既是"整板总功耗"这个真实输入，又是唯一能把场解对住算术的锚点。
瞬态同理退化成单个 RC（`tau = C_tot/hc_tot`），于是后向 Euler 的**第一步阻尼因子**也能验：

    dT_1 = dT_inf * (dt/tau) / (1 + dt/tau)

实测金标（50×50×1.6、k=0.3、h=10、cell 2 mm）：

| 工况 | 实测 | 手算 |
|---|---|---|
| 均匀 2 W 稳态 `t_max_c` | 73.393487 | 73.39345 |
| 均匀 5 W 稳态 | 192.982 | 同式 |
| 均匀 13 W | `THERMAL_RUNAWAY` | 13*0.00393 > 0.05 |
| alpha=0、2 W | 65.0 | 25 + 2/0.05 |
| 单根 3 A、40×1 mm、35 µm、cell 1 mm | `r20=0.0197029 Ω`、`r_hot=0.0220269 Ω`、`t_max=50.013524`、`Rth_eff=126.97` | 条形公式 |

`history` 首条固定是 `t=0`，`points` 含 t=0 ⇒ 步数 = `points-1`，末步正好落在 `t_end`
（这条一开始写成 `steps=points`，末步落到 5200 s）。

## 20.8 平面模态与 PDN：峰值是闭式的，曲线要补一个参数

`pdn_impedance` 给的是集中参数曲线（每个电容一个 RLC、并联相加）。那套东西在
1.4 GHz 附近会说出一个数，可那块平面在那个频率上是**一个短**——不是"曲线偏低"，
而是"这条曲线描述的对象换了一个"。所以补了 `pdn_plane_modes`。

### 20.8.1 单模峰值是闭式的

PMC 边界矩形腔的转移阻抗

    Z(f) = j·w·μ0·t · Σ_mn  ψ_mn(r) ψ_mn(r') / (k_mn² − k²(1 − j/Q))

在谐振点上取单模项：

    |Z_peak| = w·μ0·t·ψ_mn(r)·ψ_mn(r')·Q / k_mn² ,  Q = 1/tanδ
    ψ_mn = c_m c_n/√(a b) · cos(mπx/a) cos(nπy/b),  c_i = 1 (i=0) 否则 √2

50×50、εr 4.4、t 1.6 mm、tanδ 0.02、端口 `[12.5,25]`：(1,0) 在 **1.4292 GHz 峰 91.4691 Ω**。
中心点激发奇模全为 0（`z_peak_ohm = 0.0` + `why_not` 说是 null，不是"很小"）。

### 20.8.2 两个自己踩出来的因子

| 症状 | 真因 | 检测手段 |
|---|---|---|
| 频率整体差 **2 倍** | 写成 `k_plane = c/(2√εr)`，应为 `c/√εr`（因为 `f = c·k_mn/(2π√εr)`） | 与 `cavity.plane_resonance` 逐模对拍，1e-9 一致 |
| 峰值整体低 **20 倍** | `ψ` 的归一化写成 `(c_m c_n)/√(a b)`，漏了"两个端点各一次"⇒ 实为 `(c_m c_n)²/(a b)` | **函数内嵌电容锚点**：`f = 首模/100` 处模态求和必须回到平板电容 `1/(ωC)` 的 1% 内，否则 `INTERNAL_CHECK_FAILED` |

第二条比任何人工核对都可靠：它不检查我写的公式，它检查公式给出的物理量。所以固化成运行时
校验，而不是测试里的一次性断言。

### 20.8.3 为什么不给曲线（0.0.49 修订：不收敛的是点源，不是物理）

当时真跑模态求和：1.45 GHz 处截断 10 阶得 5.6 Ω，40 阶得 9.4 Ω——随截断阶数单调漂移。那组
数字的参数没有记下来，**复现不出来**，所以现在改用自己能量出来的序列：50×50 mm、2 GHz，
order 8/16/32/64/128/256 得 5.7106 / 8.2956 / 10.9700 / 13.6975 / 16.4539 / 19.2255 Ω，
**单调上升、无极限**，与当时的结论一致。

但"无极限"是**点源**的性质：点源在二维薄片里的电抗对数发散。真实端口是一个焊盘，把特征
函数在焊盘上取面积平均（`S = sin(u)/u`，`u = iπs/(2a)`）之后级数收敛。于是 0.0.49 补的是
**一个物理量**（`port_size_mm`，必填），而不是"多算几阶"：0.5 mm 焊盘在 256→384 阶只动
0.14 %，而点端口同期还在三倍量级地爬。完整推导、阶数表、负控制与判据见
`52-平面阻抗曲线.md`；5 条 `not_computed` 里"模态求和"那一条改成指向新工具（电容/封装、
die-package 电感、分割平面、过孔桶壁、辐射与开放边缘失谐仍然点名）。

0.0.50 顺手把这条曲线的**收敛门**补严了，因为它能被骗过：单条件「最后一次翻倍 ≤ tolerance」
在增量不单调衰减时会提前放行（默认带 + 一颗 0.5 mm 焊盘电容，加载曲线 128 阶的增量 22.31 %
比 64 阶的 21.03 % 还大，然后 256 阶掉到 2.54 %）；`freqs_hz` 只给一个频点时门更是**无物可测**
（探针集为空 ⇒ 相对变化恒 0 ⇒ 在 64 阶放行，而那时还差 9.7 %）。现在改双条件（容差内 **且**
增量自身减半）并让空探针集退回调用者自己的频点。默认带的 0.49 答案逐位不变
（92.4503 Ω / 1.75989 Ω / 256 阶），推导与实测表在 `53-平面电容反谐振.md` §53.3。

0.0.51 补上铜损的**表面粗糙度**一阶修正：`cavity_plane_q` / `pdn_plane_impedance` /
`pdn_plane_with_caps` 都收可选 `roughness_um`（RMS 粗糙度 Rq），乘子用 Hammerstad–Jensen
`K = 1 + (2/π)atan(1.4(Rq/δs)²)`，作用于 Rs ⇒ `Qc = h/(δs·K)`。推导、锚点表（K(δs) =
1.60514、K→2 从下方）、`σ_eff = σ/K²` 的第二条验证路径、以及三条读法（Qc 除以 K 而不是 K²、
介质主导时 Q 上看不出、曲线的"峰"会换身份）见 `54-表面粗糙度与导体Q.md`。默认不给
`roughness_um` 时三项工具的输出**逐位不变**（旧树逐字段 diff 已证）。

### 20.8.4 并进 `pdn_impedance` 的方式

`plane={width_mm,height_mm,er,thickness_mm,tan_delta,port_mm,...}` 只**加诊断**：
`points` 与 `min_z_ohm` 一个数都不动，额外给 `plane_modes`（带内模式、`worst_mode_in_band`、
`worst_mode_any_band`、`z_min_lumped_ohm`、`verdict`）。带内有模式时 verdict 直说
"a plane mode inside this band peaks at X ohm, against a lumped minimum of Y ohm - the lumped
curve is NOT the PDN there"；带内无模式时才说 "…so the lumped curve stands over it"。

粗糙度（三条锚点、`σ/K²` 恒等、介质侧逐位不动）。`tests/test_pdn_plane.py` 27 例覆盖电容锚点（三处端口）、

大于 a/4 的 0.707，所以远端反而强 1.345 倍）、带内 worst 语义、6 种拒答、诊断不改曲线、

## 20.9 厚度方向：`layer_stack`（0.0.58，见 [docs/61](61-电热-层间三维与多平面耦合.md)）

20.6 的板级 2-D 场解的是一块**均质板**。真实板子的热源在顶层铜上、地板在另一面，热要走
厚度方向才能到另一面，而 20.6 里这块板在厚度方向没有结构。0.0.58 加 `layer_stack`：
N 个层节点（`z_mm = 0` 是底面、`= thickness_mm` 是顶面），中点法则的 slab、层间只走层压板
`k_z`，**对流与辐射只在最上、最下两个表面层**——埋进板里的平面确实没有空气。

两件必须记住的事：

1. **这不是 3-D 场解**，是 z 方向的有限体积（层内等温）+ 面内 2-D 场。真 3-D 场解、
   铜-树脂界面热阻、介质各向异性都不算。
2. **一次 8.5 K 的静默错答案**：第一版在 z 方向也用扫描，"改动量 < `tol_k`"这个判据在
   刚性耦合下第一次扫描就成立（`k_z = 1e6` 是合法的"层间短路"）⇒ 返回初始猜测
   26.2468 °C，而正确答案是单平面的 34.771887 °C。改成**逐列精确三对角解 + 整块松弛**
   之后收敛只由面内问题决定。细节与自证都在 `docs/61`。
