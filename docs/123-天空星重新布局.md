## 1. 布局取舍

- 板框 44×72，P1/P2 两个 2×20 排针贴两侧长边，M3 孔四角，U1（LQFP100）居中。
- **左侧 27 件搬离**：原设计在 U1 与 P1 之间塞了一排器件，把 8.6 mm 的逃逸通道
  挤死；全部搬到 U1 下方的空带，左右通道完全打开。
- 顶部：TF 卡座 CARD1 贴板边，下面依次 ESD 二极管行、上拉电阻行、串联排阻行。
- 底部：按键行 → 去抖/滤波行 → USB/保护/指示灯三排。
- 铺铜：B.Cu 整面 GND（八角倒角），F.Cu 为 +3V3 的**形状折带**（MCU 上下梳齿、
  左右窄轨、去耦行、上拉行 + 到卡座的立管）与 +5V 的**阶梯带**（沿输入保护行），
  其余由 F.Cu GND 填充。

### 2.0 拐角：45° 斜接是算出来的，不是"意思一下"

所有折线走同一个入口 `Route.poly()`，拐角不写字面坐标，而是由 `finalize()` 统一
定尺寸：

- 每个内部顶点先取 `c = min(cap, 腿长×0.47)`，`cap` 默认 1.20 mm（斜边 = c·√2
  ≈ 1.70 mm，约 8 个线宽）。
- 然后把整板当成一个待约束的问题：拿真实的 pad / track / via 规则去测，**任何
  会被挤到的拐角按 0.70 折减，反复迭代到全板零违规为止**。
- 顶点落在自己的焊盘或过孔上时不倒角（`dist < 0.05`）——那种拐角被铜盖住，
  看不见，倒角反而浪费长度。

实测（本版）：184 个可见拐角，斜边长度 p10 0.279 / p25 0.512 / **p50 1.336** /
p90 1.697 mm；短于 0.30 mm（视觉上读成直角）的只剩 19 个，且全部落在 0.5 mm
pitch 的 LQFP 扇出与晶振两处真正挤不开的地方。

早先那版看起来是直角，原因很具体：`chamfer()` 里 `c` 被写死成 0.35 mm（斜边
0.49），而且 route2/3/4/5 里有 74 处显式传了 `0.12` / `0.001` 的 cap，等于到处
都在画直角。这两处都已改掉，cap 一律交给 `finalize()` 自适应。

## 2. 手绘布线的关键几何

**左右两侧排针扇出**（P1 30 条 + P2 28 条）

- 左列 L 类：F.Cu 横出到走廊 lane（`XN=-9.70`，步距 0.55），再竖到排针行。
- 外/内列错开：同排内外两网必须错开 0.35 以上，外侧网的过孔放到 `sy-0.55`。
- 右列 R 类：整族留在 B.Cu，过孔落在 x=18.25 的焊盘缝里。
- 顶排 T2 六网 + 低下四网全下 B.Cu，走廊 y 降序 ↔ 过孔 x 升序（嵌套不交叉）。
- U1.6 的过孔在 0.5 pitch 下放不进焊盘，移到焊盘上方 (3.40, 9.35) 出。

**TF 卡组**（7 网）

- 二极管行**按卡座焊盘顺序重排**（D2, D3, CMD, N1161, D0, D1, CD）。原设计是反序，
  等于把一个 7 网通道反转问题丢给布线；排序对齐后每条网只是嵌套两个折点的逃逸。
- 每网的逃逸列 = 二极管信号点 +0.65（二极管 GND 焊盘正在点下方，不能直下）。
- 上拉电阻的信号脚落在这条列上（`y=19.0`），串联排阻行在 `y=17.05`，扇入用 45°。
- `$1N1161`（→R21.2）与 `SDIO_CLK`（→R21.1）是长跳，走 B.Cu，各一层。
- RN2 的第 4 脚是无网络焊盘，CD 的斜线要提前转向、竖直落进 7.55，否则与它 0.09。

**SPI flash 组**

- RN3 左移到 flash 左侧，四条串联电阻形成嵌套车道：CS(21.45)/MISO(22.45)/MOSI(22.95)。
- CLK 是 RN3 第 3 脚、伙伴 R23 在上方，唯一出口要跨 MISO 车道 ⇒ B.Cu 一对过孔。
- CS 的上拉 R22 挂在 U5 正下方同一列上，靠 T 接，不占额外铜。
- `$1N1206` 从 U5 第 6 脚出发，走 flash 与 P2 之间的 15.62 缝，再从顶上回来。

**按键/LED 组**

- 去抖/滤波行**按网络排序**（R24+C25 / R25+R27+C26 / R26+R28+C27 / R29+LED2 / R30），
  每簇落在 2.4 mm 窗口内，全部共用 y=-17.95 这一条唯一可用横道。
- 每个器件的**信号脚朝上、GND/3V3 朝下**（下半行交给铺铜），否则行内焊盘互相
  屏蔽，下半行焊盘从上方永远够不到。

## 3. USB / 5V 输入组（`_sky_route6.py`）

- U2 的焊盘把两个数据网**交错**排（8196 在 B6/A6，而 962 的 A7 正卡在中间），
  所以只可能有一次交叉；这次交叉用一个过孔对在连接器下方的空 B.Cu 上付掉。
- D2（ESD）两排焊盘之间留了 1.6 mm 隧道，两个数据网都从隧道里爬上去，位置正好
  落在 D2 的 GND / +5V 焊盘之间。
- `$1N957`/`$1N960` 走 y=-31/-31.8 这条空带；**R11 从 x=-8.5 移到 -4.5**，因为
  U2 焊盘行里唯一能竖穿的走廊只有 A4B9 与 A5 之间，留在 -8.5 会把立管塞进 A4B9。
- `PIN_IN_+5V` 要把两个 2×20 排针都接上。6.5 mm 的安装孔焊盘把板边在 |x|≈17.8 处
  封死，所以总线从孔之间（x=13.5）下来，走 y=-34.9，那里只有 U2 屏蔽脚和 H1 靠近。

### 未打通的 52 条信号网：底栏几何是硬约束

底部三排（去耦行 y=-11、去抖行 y=-19.1、滤波行 y=-20.7、CC 电阻行 y=-22.4）把
y=-10.7 到 -22.3 这一段切成"只有 0.63 mm 竖缝、没有横道"的结构：

- 每排焊盘 0.5 pitch、焊盘 0.566 宽，缝隙只有 0.634 ⇒ 只能过一条 0.2 线，
  且 0.45 过孔（需离焊盘 0.375）放不进去。
- 行与行之间的净空：去耦行—按键行 0.33、滤波行 pad2—pad1 0.326、
  滤波行—CC 行 0.277、CC 行 pad2—pad1 0.30 —— 都小于一条 0.2 线所需的
  0.5，所以这一整段**没有横向通道**。
- 去耦行 8 个电容把 y=-11 这一横线占满，能同时兼容"去耦行 + 滤波行 + 按键横道"
  三个约束的竖直通道实测只有 x=-5.4 与 7.86 两个。

结论：这 52 条要打通，必须动布局（把去耦电容搬去左右侧翼、或把滤波行/CC 行
拉开或旋转 90° 让焊盘只占一行），不是继续手工找缝能解决的。已打通的
`$2N1193`/`$2N1200` 正是靠"左翼 x=-9.4 + B.Cu y=-21.2 干线 + 右翼 x=13.2"
这条绕开底栏的通路做到的，这条通路容量有限（一次一条网）。
