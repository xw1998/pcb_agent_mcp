# 36 无损传输线 `T`：一条延迟从卡面走到三个分析

## 36.1 为什么这一版做 T，仍不做 O

`0.0.29` 让内置引擎能解行为源之后，`NOT_IMPLEMENTED_CARDS` 里剩下的是一张很杂的清单：
`F H J K S W O U A`。其中 **`T`（无损传输线）是唯一一个「不需要器件物理、只需要一条延迟」的**：

- 它没有模型卡，没有材料参数，只有 `Z0` 和 `TD` 两个数；
- 它在一个**理想**定义下三个分析都有闭式答案：DC 是导线，AC 是移相器，瞬态是延迟加反射；
- 它有反射，而反射正是「一条线不能当导线」的全部理由。

`O`（有损线）与 `U`（URC）不同：它们的答案取决于**你怎么分配损耗**（`R L G C` 还是
`Z0 + 频变损耗`），那是新物理不是新语法，跟 `B` 时把 `laplace()` 拒掉同一个道理。所以这一版
只做理想无损线，`O`/`U` 按名拒绝，同时把「你的 line 有损耗吗」这件事交给
`engine="ngspice"`（实测：1 Ω 串联电阻的 `O` 卡在 50/50 分压上读出 1.5149/1.4851 V，
而理想 `T` 读出 1.5000/1.5000 V —— 差的 15 mV 就是损耗，它不在本模块的模型里）。

> 后续（`0.0.31`）：`O`/`U` 已经接上，但接的方式**不是**给它们写分布解，而是解析期把它们
> 展开成 `lump` 段普通 R/L/C（DC 是精确的串联电阻，AC/瞬态随段数一阶收敛到分布答案）。
> 本节那 15 mV 的对照因此有了第二个身份：它是「梯形把损耗建对了没有」的第一个读数。口径见
> [`37`](37-有损线与URC.md)。

## 36.2 DC：无损线就是两根导线，而且只需要一个支路未知量

无损线在直流上没有电压降，所以 `v(n1) = v(n3)`、`v(n2) = v(n4)`，这就是模型本身，不是近似。

实测（ngspice-47 与内置逐位一致）：`V1 1 0 dc 3` / `R1 1 2 50` / `T1 2 0 3 0 Z0=50 TD=1n` /
`R2 3 0 50` 给 `v(2) = v(3) = 1.5 V`，ngspice 的 raw 里还直接印出了支路电流
`t1#i1 = 0.03`、`t1#i2 = -0.03`。

**一个约束，一个未知量。** 第一版设计按「两个端口各一个电流未知量」写，结果是
`T1 2 0 3 0`（两个端口共用同一个地——单端线最常见的画法）会退化成 `0 = 0`，矩阵奇异。
所以最终实现是：**一个**支路未知量 `i1`，一行约束
`A[row][n1] = 1, [n2] = -1, [n3] = -1, [n4] = +1`（即 `v1 - v2 - v3 + v4 = 0`，两端都单端接
地时就是 `v(n1) = v(n3)`），`i2 = -i1` 由构造给出，不另立未知量。这样既不奇异，也不丢信息：
理想线两端电流本来就大小相等方向相反。

负控制：把这张卡从 deck 里删掉，`node 3` 只剩 `R2` 到地，读数变成 **0 V**。也就是说
上面那个 1.5 V 只能由这条线产生。

## 36.3 AC：精确的 Y 参数，以及半波点为什么必须拒绝

无损线的二端口导纳矩阵是闭式：

```
theta = 2*pi*f*TD
Y11 = Y22 = -j*Y0*cot(theta)
Y12 = Y21 = +j*Y0*csc(theta),  Y0 = 1/Z0
```

代码里就是这四个数打进节点矩阵（`y12` 从 `n1` 到 `n3`，`y21` 从 `n3` 到 `n1`），两个端口的
地节点由 `_add` 自动跳过。为什么信它：拿定义对账——终端接 `Z0` 时输入阻抗必须**恰好**是 `Z0`、
输出必须是输入延迟 `theta`。实测 50 MHz 起每 50 MHz 一档，`|V(3)| = 0.5` 恒定（源 1 V、源阻
50 Ω、线 50 Ω、负载 50 Ω 的分压），相位 `-18 / -36 / -54 / -72 / -90°`，与 `-2*pi*f*TD`
逐档一致，`V(2)` 的相位恒为 0（近端只看到线的输入阻抗，移相发生在远端）。

**半波点（`theta = k*pi`）直接拒绝**（`reason_code = SINGULAR`）。那里 `cot` 发散，理想线是
一个短路的短截线，导纳无穷：矩阵仍会算出一个巨大的数，而「巨大的数」正是本模块存在的意义
所要消灭的东西——它看起来像一个答案。所以：

- `|sin(theta)| < 1e-9` → `SINGULAR`，消息里写出 `theta` 与「这是理想模型没有有限答案的点」，
  并指向 `O` 卡（真实线有损耗，正是损耗让这个频率有限）；
- `1e-9 <= |sin(theta)| < 1e-3` → **给答案**，但顶层 `warnings` 里加一条（每条线只加一次，
  500 个频点不会刷 500 条）：数字在共振附近病态，精度不可信。

## 36.4 `.tran`：特征线法，且延迟短于一步就拒绝

瞬态用特征线法（Bergeron）：每个端口是一个 `1/Z0` 的电导，再加上一个「一个延迟之前那一端
的值」构成的电流源：

```
i1(t) = g*v1(t) - (g*v2(t-TD) + i2(t-TD))
i2(t) = g*v2(t) - (g*v1(t-TD) + i1(t-TD))
```

对**理想**线这不是离散化，是解析解：唯一的误差来自 `t-TD` 落在两步之间时的线性插值
（`_tline_history` 二分 + 插值），唯一的假设是「这中间什么也没发生」——而这正是一条无损线
的物理。`t=0` 的历史用直流点播种（无损线在直流是导线，两端电压相等、电流相反，这是它在
运走任何东西之前唯一可能的初始状态）。

报告里回读的端口电流**不读支路行**，而是用同一个 companion 关系重算（`_tline_ports`）：
支路行在瞬态被钉成零（它在时间里没有对应量），读它会得到「报告的电流与解出的电压各说一套」。

**两条拒绝，都是「宁可报错」：**

- `TD < tstep` → `ARG_RANGE`。历史表按步索引，延迟比一步还短时远端要读一个**还没解出来的
  时刻**。第一版实现过「钳到一步」并给出告警，实测波形延迟约 2 步才到（`t=0` 的播种值本身是
  0，是额外一步），与告警文案「最多晚 h-td」不符 —— 一个合理外观的错误答案，改判为拒绝。
  提示里直接给出可用的 `tstep = TD/10`。
- `TD` 缺失或 `TD <= 0` → `NETLIST_INVALID`。ngspice **对缺失的 TD 静默默认 0**（实测：
  `T1 2 0 3 0 Z0=50` 在瞬态里从 t=0 起就 `v2 = v3`，线变成导线），而真实工程里这两个形态
  99% 是「少抄了一个数」。同理 `Z0` 必须给：ngspice-47 自己也报
  `Fatal error: t1: transmission line z0 must be given`，而默认 50 Ω 会静默改掉整份 deck 的
  每一个反射系数。

`IC=`（初始电压/电流）、`REL=`/`ABS=`（截断误差容限，固定步长解器无法履行）**按名拒绝**，
不是忽略。

## 36.5 `F=`/`NL=` 与 `TD=` 是同一个延迟

`TD = 1/(F*NL)`。实测 `Z0=50 F=1G NL=1` 与 `Z0=50 TD=1n` 的 raw 逐点全等，`F=1G NL=2` 给
`TD = 0.5 ns`（远端在 0.5 ns 跳变）。只多三行代码，但真实 deck 里两种写法都有，所以支持而不是
拒绝。`F` 与 `TD` 同时给、`NL` 单独给，都报错（两种写法互相矛盾 / 缺一半信息）。

## 36.6 顺手抓到的真缺陷：`PULSE` 的宽度缺省不是 0，是 `tstop`

写这一版的瞬态用例时用了教科书式的最小激励 `PULSE(0 3 0 1p)`（不给宽度），结果整条线全程
读 0。根因不在线，在 `_source_value`：`pw = a[5] if len(a) > 5 else 0.0` —— 缺省宽度 0 意味着
「瞬间回落到初值」，这是一个**静默错答案**，它会让任何「不给宽度的阶跃」变成零宽尖峰。

SPICE 的语义是**缺省宽度 = `tstop`**，所以改成 `a[5] if len(a) > 5 else el["_tstop"]`
（瞬态段给所有 `V`/`I` 元件写入 `_tstop`）。这不是**为了这一版**加的宽容，而是把这个参数还原成
它的定义：默认值有权威定义的时候，实现定义比拒绝更好。

## 36.7 负控制：每一条都能失败

单元测试 `tests/test_spice_tline.py`（37 例）。除了「改一个数答案就变」这类逐条对照，另外做了
**突变检验**（把机制拆掉，看测试是否叫）：把 `_stamp_tline` 在 DC 里改成只留支路行（卡被解析
但不贡献方程），只有「远端也读到 1.500 V」失败而「删掉卡读到 0 V」仍通过（后者是 deck 的对照，
不是 stamp 的对照）；把线在三个模式里都改成一根 `1e6 S` 的导线，5 条断言全红。基线 0 红。

| 断言 | 如果机制不在会怎样 |
|---|---|
| 匹配分压两端都是 1.500 V，卡报 `+0.030 / -0.030 A`、`power = 0` | 卡被解析但没打进方程 ⇒ 远端浮空读 0 V |
| 删掉 `T` 卡后 `node 3` 是 0 V | 「导线」结论其实是浮空节点凑出来的 |
| 端口互换（`T1 3 0 2 0`）同解、两线串联、`.subckt` 体内的 `T` | 节点按位置读错 / 层次没重映射 ⇒ 远端不连通 |
| 远端短路（`R2 = 1 mΩ`）时源侧抽满 `3 V / 50 Ω = 60 mA` | 线在直流不是导线 ⇒ 电流少一半 |
| 匹配阶跃：`v(2)` 从第一步就是 1.5 V，`v(3)` 在 `TD` 前 0、后 1.5 | 线被当导线 ⇒ 远端 t=0 就到 1.5 |
| 开路端：`v(3)` 在 `TD` 翻倍到 3.0，`v(2)` 在 `2*TD` 翻倍 | 没有反射模型 ⇒ 远端永远 1.5 |
| 短路端：远端 ≈0，`v(2)` 在 `2*TD` 塌到 ≈0 | 反射系数写反 ⇒ 远端翻倍 |

| `PULSE(0 3 0 1p)` 的末端仍是 1.5 V | 宽度缺省回到 0 ⇒ 阶跃变成尖峰 |
| `elements_final` 的端口电压与最后一个点一致、两电流和为零 | 报告的电流读的是被钉零的支路行 ⇒ 与电压不一致 |
| AC `|V(3)| = 0.5` 恒定、相位 `-2*pi*f*TD`、`v(2)` 相位 0 | 线被当导线 ⇒ 相位恒 0 |
| 开路端 AC：`|V(2)| = cos(theta)`（200 MHz 0.309 = cos 72°）、250 MHz 处 0、`|V(3)|` 恒为 1.0 | 反射的频域面写错 ⇒ 四条都不成立 |

| `TD < tstep` 是 `ARG_RANGE`；半波点 `SINGULAR`；`O1` 仍被按名拒绝 | 钳位 / 返回巨大数 / `O` 被顺手放开 ⇒ 错误答案 |
| 近共振（500.05 MHz）`status ok` 且只加一条 `warnings` | 不告警 ⇒ 病态数字被当可信；每频点一条 ⇒ 刷屏 |
| op / tran / ac 三档 `cross_check` 与 ngspice-47 的 `max_abs_diff_v = 0.0` | 任一档不一致 ⇒ 模型与 ngspice 不同（不是精度，是模型） |

## 36.8 仍然不做

- **有损线 `O`**、**URC `U`**：本版（`0.0.30`）按名拒绝。损耗的分配方式是模型选择，不是
  语法；`0.0.31` 用**集总梯形**接上（见 [`37`](37-有损线与URC.md)），那仍然是模型不是分布解。
- **`IC=` 初始电压/电流**：需要「线上存着一个波形」这个初始条件，固定步长 + 历史表表达不了。
- **`REL=`/`ABS=`**：本解器是固定步长，容限没有意义，收下就是骗人。
- **频变损耗、色散、多导体（耦合线）**：不在理想无损线模型里。
- 半波点的「有限答案」：需要损耗，见上。理想模型没有有限答案这件事被写进 `NOT_COMPUTED`。
  注意 `0.0.31` 的 `O` 卡（集总梯形）**不能**替它补上：梯形在那个频率当然有有限答案，但那是
  20 段集总模型的答案，不是理想线在那里「无穷」这件事的解——两者不可互相顶替。
