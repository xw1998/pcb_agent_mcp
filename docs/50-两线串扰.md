# 50 · 串扰不是「3W 规则」：两线之间的 NEXT 与 FEXT

这个服务器给出过 158 个答案，其中关于「高速线」的每一个都是**单条线**：`trace_impedance`
不知道旁边还有一条线，`diff_impedance_field` 把偶模奇模解出来只为取个平均、然后叫它
「一条线」。所以「我这 1 V 的边沿有多少落到隔壁」——PCB 上被问得最多的那个问题——在这里
一直没有答案，市面上给出的要么是经验法则（3W、20H），要么是一个把假设藏起来的闭式。

这一版把它拆成**三段流水线，每一段调用方都能自己复算**：

| 段 | 做什么 | 凭什么信 |
|---|---|---|
| 1 | 解截面（偶模/奇模电容，介质与真空各一组，共 4 个数） | 就是 `field2d`，不走闭式 |
| 2 | 4 个数 → 两模态线的 L、C、Z、v | 恒等式，逐条写在 `modal_from_caps` 里 |
| 3 | 耦合电报方程在**时域精确解** | 两条独立路线对账（模态解 vs 集总梯形） |

## 50.1 第一段：截面是解的，不是拟合的

`field2d._cap_modes(kind, w, s, h, t, er, fine)` 给四个**形状因子**（每条线在那种激励下的
电容）：`c_odd_d / c_even_d`（真实介质）与 `c_odd_a / c_even_a`（真空）。奇模 = 对称面上
电壁（两条线 ±V），偶模 = 磁壁（两条线同电位）。

铜厚不是闭式里的修正项，而是**网格里的一个矩形**（和 `diff_impedance_field` 用的是同一个
截面类），所以梯形蚀刻、铜厚、s/h 都是几何而不是系数。

## 50.2 第二段：模态代数，每条都是恒等式

```
Cg  = c_even·ε₀                    （两条线同电位时互电容不充电）
Cm  = (c_odd − c_even)·ε₀/2
C11 = Cg + Cm
L_odd  = μ₀ / c_odd_a              （非磁性介质不改磁场 ⇒ 用**真空**电容取倒数）
L_even = μ₀ / c_even_a
L11 = (L_odd + L_even)/2 ,  Lm = (L_even − L_odd)/2

奇模线  C = C11 + Cm ,  L = L11 − Lm ,  Z_odd  = √(L/C)
偶模线  C = C11 − Cm ,  L = L11 + Lm ,  Z_even = √(L/C)
Z_iso   = √(L11/C11)                （只有一条线时的阻抗）
k_c = Cm/C11 ,  k_l = Lm/L11 ,  Kb = ¼(k_l + k_c)
```

三条能当场验的恒等式（都是 `tests/test_crosstalk.py` 里的断言）：

- **奇/偶模电容就是解出来的那个数**：`C11 + Cm = c_odd·ε₀` 逐位相等（`C11 − Cm = c_even·ε₀`）；
- **ε_eff 是电容比**：`ε_eff,odd = c_odd_d/c_odd_a`（偶模同理），且 `(c₀/v)²` 与它相等；
- **`Z_odd < Z_iso < Z_even`**——奇模把电容抬上去、把电感压下来，所以阻抗最低。

这里踩过一个**只有均匀介质能暴露的错**：`ε_eff` 一度写成 `c₀/v`。它对每一条线都成立
（因为 `v = c₀/√ε_eff`），但**报出来的数是 √ε_eff**。微带上看不出来（2.7124 与 3.3706 都
像模像样的有效介电常数），**带状线一眼就看穿**：均匀介质里 ε_eff 必须**正好等于 εr = 4.3**，
而它报了 **2.0736 = √4.3**。所以现在 `ε_eff` 直接从两个电容取比值，不经过任何平方根。

## 50.3 第三段：时域解，不是把 Kb 套上去

两端阻抗相同时两个模态电路**解耦**，所以每个模态就是一条普通一维线（阻抗 `Z_m`、延时
`T_m`），源是梯形波，末端负载 `R_l`，答案就是这条线的**弹跳级数**：

```
gl   = (R_l − Z_m)/(R_l + Z_m)
A[n] = (Z_m·src[n] + (R_s − Z_m)·B[n−d]) / (R_s + Z_m)     近端出发波
B[n] = gl · A[n−d]                                         远端出发波
V_near = A[n] + B[n−d] ,  V_far = A[n−d] + B[n]
V1,2   = (V_even ± V_odd)/√2
```

`d = T_m/dt` 不是整数，所以延迟用**线性插值**。没有弱耦合近似、没有长线近似、没有饱和度
假设，也不需要——只有「两端同阻抗」这一个前提，不满足就**拒绝**（见 §50.8）。

### 运行多久不是口味

原来固定跑 8 个往返，那是按「端接阻抗 ≈ 模态阻抗」想的。**端接 10 Ω 时它是错的**：
反射系数每往返乘 0.71，8 个往返之后还剩 3.4 %，远端停在 **0.483 V** 而分压器说 0.500 V，
于是内建的 DC 闸门把整次调用判成 `INTERNAL_CHECK_FAILED`——一个正常问题（驱动器 10 Ω 打
10 Ω 接收端）被自己的截断误杀了。现在往返数由更差的那个模态反射系数**算出来**：

```
trips = ⌈ln(1e-10)/ln(max|gl_even, gl_odd|)⌉ ,  swell = max(8, 2·trips + 4)
```

端接 10 Ω 时 swell 140（13 374 步）→ 远端 **0.500000000000**；端接 1 Ω 也到 0.5；端接
0.1 Ω 需要 7 000+ 个往返、超过 `MAX_STEPS`，于是**明确拒绝**（`OUT_OF_VALIDITY`，报出步数），
而不是给一个被截断的数。匹配（`Z_iso`）时 `gl = 0`，运行长度与从前逐位相同。

## 50.4 近端：NEXT = Kb · **V_入射**

教材里 NEXT 的系数是 `Kb = ¼(Lm/L11 + Cm/C11)`，那个 ¼ 常被读成「乘源电压」。**不是**。
乘的是**到达线里的那个波**：

```
V_incident = amp · R_l/(R_s + R_l)        （匹配时 = amp/2）
NEXT       = Kb · V_incident
```

弱耦合实测（合成电容，`k_c = k_l = 0.1996 %`，`Kb = 0.000998`）：
`NEXT/(Kb·V_incident) = 1.0000010`，而且**与长度、上升时间无关**——50/200/400 mm × 0.1/0.2/0.5 ns
四个组合的值相同到第 7 位。

这条判据是靠**一条完全独立的路线**裁决的，不是靠推导：

`_ladder`（`tests/test_crosstalk.py`）把同一条线做成**集总梯形网络**（FDTD 式 leapfrog，
K=200 段，2×2 的 L、C 矩阵直接求逆），它不知道「模态」、不知道「Kb」、不共享被测代码的任何
一行。微带那组几何（w=s=h=0.2、t=0.035、εr=4.3、L=50 mm、tr=0.2 ns）上：

| | NEXT |
|---|---|
| 集总梯形 K=200 | **0.0424918** |
| 集总梯形 K=400 | 0.042460 |
| 模态弹跳级数（本模块） | **0.0424279** |

差 0.15 % / 0.08 %。逐时刻波形也对得上（梯形 vs 模态，单位 V）：

| t (ns) | 0.05 | 0.10 | 0.15 | 0.20 | 0.30 |
|---|---|---|---|---|---|
| 集总梯形 | 0.010639 | 0.021244 | 0.031849 | 0.042454 | 0.042428 |
| 模态解 | 0.010683 | 0.021366 | 0.032049 | 0.042428 | 0.042428 |

所以：**因子 2 是真的，不是 bug**。以后谁把 `Kb` 改成乘源电压，梯形那一侧不会动，测试会红。

同时注意到 Kb 只在弱耦合下成立。同一个模块在 w=s=h=0.2 的**强耦合**（k_c 11.53 %、
k_l 22.07 %）上：仿真 0.0424279 对 `Kb·V_incident = 0.0420049`，**偏 +1.007 %**。所以工具
把「仿真峰值」和「Kb 会给多少」并排报，**不拿 Kb 当答案**。

## 50.5 远端：均匀介质里它是**算术零**

`FEXT = (V_even,far − V_odd,far)/√2`。两个模态速度相等时，这两个波形**逐点相同**，差恒为
0——这不是假设，是抵消。带状线正是这种情形（介质均匀）：

| 量 | 值 |
|---|---|
| ε_eff（奇 / 偶） | 4.3 / 4.3 |
| 速度差 | **3.41168e-05 %** |
| NEXT | 0.0135137 V（**1.35137 %**） |
| FEXT | **−1.96505e-07 V（1.96505e-05 %）** |

近端响得很响、远端**一万分之二伏**。这是本模块最好的负控制：模态拆分写错一位，这个数立刻
变成百分数量级。

## 50.6 微带：速度差就是 FEXT 的全部来源

| 量 | mesh_div=12 | mesh_div=8 |
|---|---|---|
| Z_odd / Z_even / Z_iso (Ω) | 59.0587 / 82.9949 / 70.6543 | 59.0209 / 82.8358 / 70.5638 |
| ε_eff 奇 / 偶 | 2.7124 / 3.37062 | 2.70836 / 3.36814 |
| 延时 奇 / 偶 (ns) | 0.274679 / 0.306199 | 0.274475 / 0.306086 |
| 速度差 | 10.294 % | 10.3276 % |
| k_c / k_l | 11.5293 % / 22.0746 % | 11.4476 % / 22.0316 % |
| **NEXT** | **4.24279 %** @0.2014 ns | 4.22691 % |
| **FEXT** | **−3.90842 %** @0.3067 ns | −3.92 % |
| Kb | 0.0840098 | 0.0836981 |
| 仿真 − Kb·V_inc | +1.00698 % | +1.00365 % |
| 网格 / 节点 / 步数 | 12 / 11 858 / 800 | 8 / 5 796 / 800 |
| 耗时（本机） | **75.8 s** | **29.3 s** |

FEXT 是**负的**：奇模更快、感性耦合占优，远端先看到电感的那一半。`samples_per_delay`
默认 60，`mesh_div` 默认 12；12→8 快 2.6 倍，Z 动 0.06 %、NEXT 动 0.4 %——网格敏感性
**如实写在工具描述里**，不假装无关。

## 50.7 FEXT 的两个区间，与那个把两者分开的长度

「FEXT ∝ L」是个**有条件的**说法，条件不是口味：

```
L_coh = tr / |1/v_odd − 1/v_even|
```

微带那组几何（Δ(1/v) = 6.304e-10 s/m）：

| L (mm) | 10 | 25 | 50 | 100 | 200 | 400 | 800 |
|---|---|---|---|---|---|---|---|
| FEXT (V) | −0.007817 | −0.019542 | −0.039084 | −0.078168 | −0.156331 | **−0.248002** | **−0.248002** |
| 每 mm | 恒等 | 恒等 | 恒等 | 恒等 | 恒等（偏 3.8e-5） | — | — |

- 200 mm 以内**严格按长度线性**（`L/L_coh = 0.63` 处每 mm 值偏 3.8e-5）；
- 400 mm 与 800 mm **同一个数**：两个模态的到达时刻差已经超过上升时间，差值是「一个模态的
  整步」而不是「两条斜坡的错位」，于是**不再随长度增长**；
- 那个平台就是 **amp/4**（0.248002 = 99.2 % 的 0.2500）：`V2 = (V_even − V_odd)/√2`，
  每个模态载 `amp/2·√2`，取最大差正好落到 `amp/4`；
- `L_coh` 随 tr 缩放，实测 0.1/0.2/0.4 ns → 158.6 / 317.3 / 634.5 mm。

所以报告里给了 `fext.scales_with_length`（这个长度在哪个区间）、`fext.coherent_length_mm`、
`fext.saturation_limit_v`。**「串扰随线长增长」在长线上是错的**，这里不让人自己猜。

## 50.8 三条闸门 + 一条拒绝

三条闸门**跑在函数里**，任一失败就返回错误信封（和 `pdn_plane_modes` 的电容回代闸门同型）：

| 闸门 | 判据 | 实测 |
|---|---|---|
| 无耦合对照 | 把 `Cm=Lm=0` 重解一遍，受端必须 **0 V**，远端必须落在分压器 | 泄漏 `0.0`，远端 `0.5` |
| DC 沉降 | 有耦合时远端仍必须落在 `amp·R_l/(R_s+R_l)` | 误差 −5.5e-14 ~ −2.2e-16 V |
| 步数预算 | 先用**平面波速度**（`c₀/√εr`，两个模态速度的上界）估步数 | 1.1e8 步 → 0 秒拒绝 |

第一条尤其重要：它把「模态拆分写错」变成一次**必然失败**，而不是一个看起来合理的错数。

**拒绝**（不是近似）：两条线在同一端的端接阻抗**不同**时模态电路不解耦，所以
`termination_ohm` 是**四端同一个值**；给不出同阻抗就不是这个电路能答的问题。

参数校验**全部在场解之前**（一次 0 值的入参不该跑 90 秒才报错）：`kind`、数值可解析、
w/s/h > 0、t ≥ 0、εr ≥ 1、length > 0、tr > 0（提示里写清 `FEXT ∝ 1/tr` 会发散）、
amp > 0、`termination_ohm` 是正数、`s/h ≥ 0.05`（对称面比一个网格还近）、`mesh_div` 4..24、
`samples_per_delay` 10..400、`waveform_points` 11..501、步数预算。

## 50.9 边界（写进 `not_computed`，六条）

1. **第三条线**、两线之间的地铺铜、带自身过孔的屏蔽线——这是两导体问题，三个导体的耦合
   不能相加；
2. 色散、铜损、集肤、介质的频率依赖——截面**只在 DC 解一次**（每个阻抗答案都背着的准 TEM 假设）；
3. 阻焊、蚀刻梯形、真实端接的长度（端口在耦合段的两个端头上）；
4. 过孔、连接器、封装的不连续，以及连接器插针之间的串扰（那是 3-D 问题）；
5. 辐射与真实回流路径产生的地弹——这里的参考平面是完美的；
6. **端接不一致的受端**：拒绝，不近似（§50.8）。
