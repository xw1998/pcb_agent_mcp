# DC 偏置：厂商自己印的那条 `% µi = 1/(a + b·H^c)` —— 零电流算的电感，在真电流下还剩多少

日期：2026-11-01　工具：`magnetics_dc_bias`（**第 176 个工具**）+ `magnetics_data(kind="dc_bias_fit")`

`78` 篇的 §8 第 2 条写着「DC 偏置下的 AL 跌落曲线：只在 p.10 印了两个点（80 % / 50 % µi 对应的 Oe），
做曲线要另一份资料」。这一篇是那句话的后半句：**另一份资料就在同一个 PDF 里**，
只是不在上一轮找的那三页上。

上一轮找的是「DC Magnetization」页（PDF 130–134，`B = x(a+bH+cH²)/(1+dH+eH²)`），
拿它反算 p.10 的 18 个数差了 **2–3.5 倍**，于是判「厂商三处互不一致、不做」。
本轮在同一份目录里找到真正的那三页 —— **`Permeability versus DC Bias Curves — Fit Formula`**
（PDF 65–67 = 印刷 63–65）—— 式子是一行：

```
% initial permeability = 1 / (a + b * H^c)          H 单位 Oersteds
```

**`a` 在 125 行上全是 0.01** ⇒ `H = 0` 时答案正好 100，也就是说这个式子输出的是**百分数本身**，
不是 0–1 的比例。这一条搞错，18 个数字会**全部差 10 倍**（本轮先踩了，见 §3.1）。

改用它之后，厂商自己的**四个独立印刷来源**全部对上（§3）。所以这一版不是"多了一张表"，
而是**一个原本只能靠翻 PDF 曲线目测的问题，变成了能算的数**：

```
60 µ Kool Mµ / 20 匝 / 20 A / le 63.5 mm
  -> H = 79.16 Oe, % µi = 58.4 %, 电感剩 58.4 %, B = 0.391 T
     （厂商印刷算例原文：「from curve fit equation, % µi = 0.58」）
```

既有行为一位不变：`magnetics_select_core` / `magnetics_material_core_loss` / `magnetic_data`
的三个既有 `kind` 全部未动；新增的是一个工具、一个 `kind` 和一个数据文件。

## 2 厂商原文（印刷页 → PDF 页）

```
vendor : Magnetics, a Division of Spang & Company
doc    : Powder Core Catalog
url    : https://www.mag-inc.com/Media/Magnetics/File-Library/Product%20Literature/
         Powder%20Core%20Literature/Magnetics-Powder-Core-Catalog.pdf
bytes  : 12,415,449
pages  : 210（PDF），本轮用到 PDF 65–67 = 印刷 63–65
```

**这一段 `印刷页 = PDF 页 − 2`**，而**不是**粉末芯表那一整段的 `− 1`。
两段的偏移不同是实测的，不是推的：PDF 50 页脚印 48、PDF 54 印 52、PDF 65 印 63、PDF 66 印 64、PDF 67 印 65。
数据文件里 `source.printed_page_offset` 把这五个样本逐条写出来，**每行还各自带 `printed_page`**，
所以将来谁重新解析，页号对不上会当场露出来。

三页的结构：每页左边是材料 × 磁导率的**系数块**（`permeability / a / b / c` 四列），
右边是该组的曲线图。系数块按「材料 → 形状族」分段，一小段一组。

解析要点（`_scratch/x_dcbias2.py`）：

- 磁导率行头是**纯数字**（`60`），系数行是 `0.01 / 2.142E-06 / 1.855`；
- 材料名里的 `µ` 是 `U+00B5`、`ƒ` 是 `U+0192` —— **heredoc 里直接写这两个字符会被吞**，
  本轮普查（`_scratch/x_cp.py`）确认页面只有 `0xae ® / 0xb5 µ / 0x192 ƒ / 0x3bc μ` 四种非 ASCII，
  正则一律用 `\u00b5` 这类转义写；
- 取完再按**列 x 坐标**复核一遍，行高（arity）不对就中止入库，**不做列位移**。

结果：**29 个（材料 × 形状族）组、125 行**，`b` 归一化成 Python float（`4.498E-08 → 4.498e-08`）。

## 3 五条校验（每一条都能翻脸）

### 3.1 厂商 p.10 的 80 % / 50 % 汇总表：18/18

p.10 印着「每种材料在 60µ 时，µi 掉到 80 % 与 50 % 对应的 Oe」。把 `1/(a+bH^c)` 反解
（`H = ((1/pct − a)/b)^(1/c)`，注意 `pct` 是 80 / 50 而不是 0.8 / 0.5 —— **踩过这个坑**）：

| 材料 | 印 80% Oe | 算 | 差 | 印 50% Oe | 算 | 差 |
|---|---|---|---|---|---|---|
| Kool Mµ | 45 | 45.02 | 0.05% | 95 | 95.06 | 0.06% |
| Kool Mµ MAX | 65 | 65.00 | 0.00% | 130 | 130.00 | 0.00% |
| Kool Mµ Hƒ | 60 | 59.98 | 0.03% | 115 | 114.96 | 0.03% |
| Kool Mµ Ultra | 60 | 60.00 | 0.00% | 120 | 120.00 | 0.00% |
| XFlux | 100 | 99.92 | 0.08% | 170 | 169.84 | 0.09% |
| XFlux Ultra | 110 | 109.99 | 0.01% | 180 | 179.98 | 0.01% |
| Edge | 130 | 129.92 | 0.06% | 205 | 204.87 | 0.07% |
| High Flux | 100 | 100.90 | 0.90% | 185 | 184.79 | 0.12% |
| MPP | 60 | 60.00 | 0.00% | 105 | **106.00** | **0.96%** |

18 个数字**全部**在 1 % 内，最差是 MPP 的 50 %：算 106.00 对印 105（0.96 %）；
15 个在 0.1 % 内，第 16 个（High Flux 50 %）0.12 %。**这一栏不许向上取整说成「16 个在 0.1 % 内」**——
本轮就先把 0.12 % 那个算进了 0.1 % 档，被 §3.1 的数自己抓出来，已改成 15。

> 对照：同一个校验换成上一轮用的 `B = x(…)/(1+…)` 表，9 个材料 × 2 档里 **没有一个**在 1 % 内，
> 差得最少的一档高 2 倍、最多的 3.5 倍。两条式子不是"精度不同"，是**不同的函数族**。

### 3.2 印刷算例 Example 2（p.24）：58.4 % 对原文 0.58

原文：60µ Kool Mµ、20 匝、20 A、`le = 63.5 mm`，「from curve fit equation, `% µi = 0.58`」。

```
H = 0.4π·20·20 / 6.35 = 79.158 Oe
% µi = 1/(0.01 + 2.142e-6 · 79.158^1.855) = 58.408 %
```

数值答案：`magnetics_dc_bias(material="Kool Mu", permeability=60, shape_family="Toroids",
turns=20, dc_current_a=20, le_mm=63.5)` → `h_oe 79.15824`、`percent_initial_permeability 58.40843`、
`inductance_ratio 0.584084`。

这一条同时钉住了两件事：**`H[Oe] = 0.4π·N·I[A]/le[cm]` 是 CGS 口径**（`le` 进 mm、出 cm，
写成 mm 就整好差 10 倍），以及 `% µi` 是**百分数**。

### 3.3 印刷算例 Example 3（p.25）：B 必须积分

原文：`H = 15.8 Oe` → `B = 0.092 T`。

```
B[T] = 1e-4 · ∫₀^H µr,diff dH,   µr,diff = µ · %µi(H) / 100
```

用 60µ Kool Mµ 的拟合做梯形积分（4000 步）给 **0.0936 T**，印 0.092 T，**高 1.7 %**。

**这一条只钉住量级，钉不住"必须积分"** —— 15.8 Oe 时曲线才掉到 96.5 %，
弦式 `µr·H·1e-4` 在这里给 0.0939 T，与积分只差 0.3 %，两者都过得去。
把这两条式子分开的是 §3.3 之后的那个点：

| H (Oe) | 印刷 B | 积分 | 弦式 |
|---|---|---|---|
| 95 | 0.441 T | **0.4421 T**（+0.25 %）| 0.285 T（**−35 %**）|
| 63.3 | 0.331 T | **0.3306 T**（−0.1 %）| — |

所以 `% µi` 是**微商（增量）磁导率**，不是弦磁导率。厂商把 B 印在图上、把式子印在页脚，
两处只有积分能同时满足。`b_t_basis` 字段每次都把**弦式会是多少**一起打出来，
让调用方自己看见这个差。

### 3.4 矢量曲线像素读数（印刷 p.52 MPP Toroids 面板，PDF 54）

10 条曲线（14µ…160µ）读成像素：600 dpi 渲染 + **用印刷网格线最小二乘自标定坐标**
（`x = -173.480 + 245.789·log10(H)`，残差 −0.6…+0.59 pt；`y = 441.000 − 3.150·pct`，残差 0.00 pt），
再按曲线颜色在位图上扫。7 条曲线在各自的 5 个水平上平均误差 **0.11–1.08 %**，
次优磁导率的差是 **6–30 %** ⇒ 归属无歧义。

两条被踩过的坑，写在这里省下一次：

- **不能用贝塞尔求交读**：`get_drawings()` 里曲线是 `c` 段，子路径 bbox 重叠处求交会取到图边界，
  读数落在 100 / 50 / 30 三个"好看"的值上 —— 全是伪读数。像素法才稳。
- **不能用视觉模型"看图"定归属**：本轮 `view_image` 说「19µ 是青色、14µ 是深棕最平」，
  与像素吻合度结论不一致。图像类工具的一次输出**不能进证据链**，轴范围与刻度也必须量测。

## 4 被否掉的那张表（写清楚，免得下次再试）

PDF 130–134（印刷 128–132）的「DC Magnetization」页印的是另一个式子：

```
B = x·(a + b·H + c·H²) / (1 + d·H + e·H²)
```

它的 `x·c/e` 给出一条**超过材料饱和磁密**的渐近 B，既不重现它自己那页的曲线，
也不重现 p.10 的 80 % / 50 % 点。所以 `data/dc_bias_fit.json` 的 `not_carried` 第 1 条写着：

> the "DC Magnetization" B-vs-H fit printed on pdf 130-134 is a different function family
> and does not reproduce its own printed curves or worked examples; this table does not use
> it and B comes from integrating the mu_i fit instead

**这张表不采用，但不是"厂商印错了"** —— 它的语义是 B–H 曲线（大信号），
`% µi` 是小信号增量量，两者不是同一个对象的两种写法。要用它得另立一个工具语义，
而且得先解释它为什么不重现自己的曲线，所以本轮不动。

## 5 工具的行为

```
magnetics_dc_bias(material, permeability, shape_family=?, h_oe=?
                  | turns + dc_current_a + le_mm,
                  include_b=True, bias_data_path=?)
```

| 输入 | 行为 |
|---|---|
| `h_oe` 与 `turns/…` 同时给 | `ARG_INVALID`（两条路说同一件事，静默取一条会藏起另一条）|
| `h_oe ≤ 0` / 匝数电流或 `le ≤ 0` | `ARG_INVALID`（零偏置不是偏置）|
| 材料印了多个形状族却没点名 | `NOT_FOUND` + 列出候选族 |
| 磁导率没印（如 MPP 55µ）| `NOT_FOUND` + 顶层 `permeabilities_printed` 列出 14 个 |
| 该材料在该族没印（如 Kool Mµ Ultra + EQ & LP）| `NOT_FOUND` + 列出它印了的族 |
| `H` 在 10–800 Oe 之外 | `ok` + `warnings`（含「outside」与带宽），**不 clamp** |
| `% µi < 25` | 追加一条 warning（曲线图上没有这一段）|
| `B/Bsat > 0.7` | 追加一条 warning：`% µi` 是小信号量，不建模饱和 |

答案字段：`h_oe` / `h_source` / `percent_initial_permeability` / `inductance_ratio` /
`fit{a,b,c,printed_page,printed_formula}` / `b_t` / `b_t_basis`（内含弦式会是多少）/
`saturation_flux_density_t` / `b_saturation_ratio` / `warnings`。

`include_b=False` 只去掉 `b_t` 那三个字段，`% µi` 一位不动。

`magnetics_data(kind="dc_bias_fit" | "dc_bias" | "dcbias" | "bias_fit", material=,
permeability=, limit=)` 把转录读回来（**是转录，不是答案**）：`count` / `total_matching` /
逐行 `(material, shape_family, permeability, a, b, c, printed_page)` + 表级 `formula` /
`printed_caveat` / `table_retrieved`。

## 7 这一版仍然没做

| # | 没做 | 为什么 |
|---|---|---|
| 1 | 把 DC 偏置接进 `select_core` | 那是一个**不动点**问题：匝数 ↑ ⇒ H ↑ ⇒ µi ↓ ⇒ 电感 ↓ ⇒ 匝数 ↑。匝数不是自由变量，得迭代。本轮只给式子和 H，迭代留给调用方（工具描述里明写）|
| 2 | 温度 | 目录只印一条拟合，不按温度分。硬造一条温度修正就是发明数据 |
| 3 | 饱和 | `% µi` 是小信号量；`b_t` 与 `B/Bsat` 只作对照，不反向修正 |
| 4 | 磁导率之间插值 | 曲线不是邻档的缩放（§5 的拒绝）|
| 5 | 每组自己的有效范围 | 页面只印 "Fit valid only for range shown on graph" 不给数；10–800 Oe 是**从 p.52 面板的网格线量出来的样品**，不是每组的承诺，`warnings` 里这么写 |
| 6 | `B = x(…)` 那张家表 | §4 |
