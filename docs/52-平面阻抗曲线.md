# 52 · 平面阻抗曲线：不收敛的是点源，不是物理

`pdn_plane_modes` 从前只报每个腔模的**峰值**，明说「模态和不做，因为它不收敛」。
0.0.49 把那条曲线做出来了（`pdn_plane_impedance`），而做法不是「多算几阶」「换求和技术」，
是**找出被漏掉的那个物理量**：端口的尺寸。

一句话结论：**点源在二维薄片里的电抗对数发散，真实焊盘不会。** 所以 `port_size_mm`
在这里是必填参数——不是细节，是答案的一部分。

## 52.1 原来为什么不做，以及那个数字靠不靠得住

旧文档（`20-平面谐振与电热耦合.md` §20.8.3）写着：1.45 GHz 处截断 10 阶得 5.6 Ω、40 阶
得 9.4 Ω，随阶数单调漂移。**这条实测复现不出来**——旧实验的具体端口/探针/是否含铜损都没
记下来。所以本轮不拿它当依据，改用自己能量出来的序列（§52.5 的负控制表），结论相同：
**点端口下 |Z| 随阶数单调爬升，没有极限。**

## 52.2 为什么没有极限：二维薄片的点源

PMC 边界矩形腔的转移阻抗是

    Z(f) = j·w·μ0·t · Σ_mn  ψ_mn(r) ψ_mn(r') / (k_mn² − κ²),   κ² = k²(1 − j/Q)

点源时 `ψ_mn(r)ψ_mn(r')` 里每个方向的归一化只剩 `c_m²/(a)`（两端口同点），级数尾项按
`1/(m²+n²)` 衰减：**二维格点上这是对数发散的**。所以曲线在物理上就是"价无穷"，
任何"我取够多阶"都是自欺。

## 52.3 补上的物理量：焊盘孔径

真实端口是一个焊盘，不是一点。把特征函数在焊盘上做面积平均，一维因子就是

    S_i(u) = sin(u)/u,     u = i·π·s/(2a)      （s = 焊盘边长）

于是每一项多乘 `S_x(m)² S_y(n)²`，尾项多衰减一层 `(2a/(πsm))²`，
级数变成 `Σ 1/m⁴` —— **收敛**，而且收敛所需的阶数大约是 `m ~ 2a/(πs)`
（焊盘 0.5 mm、平面 50 mm ⇒ m ~ 64 够了）。

物理解释很直白：**焊盘接不上半波长短于自己的模**。

完整式子（与 `power.py` 里的实现一一对应）：

    Z = j·w·μ0·h · Σ_mn  A_mn / (k_mn² − κ²)
    A_mn = (c_m c_n)²/(a b) · cos(mπx1/a) cos(mπx2/a) cos(nπy1/b) cos(nπy2/b) · S_x(m)² S_y(n)²
    c_i = 1 (i=0) 否则 √2
    κ² = k²(1 − j/Q),  k² = w²μ0ε0εr

### 52.3.1 损耗放进介质，而不是每模查一次

Q 在**求值频率 f** 上取一次（不是每模在自己的 f_mn 上）：

    1/Q = 1/Qc + 1/Qd,   Qc = h/δ_s,  δ_s = √(1/(π f μ0 σ)),   Qd = 1/tanδ

这是经典"有损腔"的写法：损耗变成波数的一个复部，分母里只有**一个**复数量，内循环只剩
复除法。**在谐振点上两种约定完全等价**；离开谐振点时高模会比"用自己的频率"多一点点阻尼，
而那正是它不主导你要看的东西的地方。

`m=n=0` 是特例：两板间均匀场 `H = 0`，只有介质损耗，`Q = 1/tanδ`。这一项加起来正好是
`1/(jω·C_pp(1−j/Q))`，`C_pp = ε0 εr a b / h`——这构成 §52.6 的锚点。

## 52.4 收敛判据：不能用逐点相对误差

第一版拿"逐点相对变化 < 容差"当判据，`pad = 0.5 mm` 在 order 256 仍然报 `NOT_CONVERGED`，
最差点在 **238 MHz**——首模以下的那个相消点。

原因是物理的：首模以下平面是「平板电容 ∥ 扩散电感」两个**大电抗量相减**，相消点上 |Z| 是
两个大数之差，逐点相对误差永远达不到。**误差要按答案自身的尺度量**，所以判据改成

    max|ΔZ| / max|Z|  ≤ tolerance        （默认 0.01）

同时把逐点量作为副列报出（`truncation_max_pointwise_relative_change`），让读者自己看：

| 阶数 | maxΔ/峰值 | 逐点最大相对变化 | 最差点 |
|---|---|---|---|
| 16  | 6.29 %  | 105.8 % | 4.2876 GHz |
| 32  | 5.97 %  | 51.4 %  | 4.2876 GHz |
| 64  | 5.01 %  | 30.5 %  | 4.2876 GHz |
| 128 | 2.52 %  | 13.4 %  | 4.2876 GHz |
| 256 | **0.203 %** | 1.07 % | 4.2876 GHz |

（50×50 mm、εr 4.4、t 1.6 mm、tanδ 0.02、端口 `[12.5,25]`、焊盘 0.5 mm、默认带
28.58 MHz ~ 4.288 GHz。）逐点 1 % 不是没收敛，是相消点上的 |Z| 本身只在 1 % 量级上被
两个大电抗决定。

## 52.5 实测：焊盘尺寸、负控制、阶数

**2 GHz、含铜损、同一端口**，随阶数的 |Z|（Ω）：

| 焊盘 | o32 | o64 | o128 | o256 | o384 |
|---|---|---|---|---|---|
| 0.25 mm | 10.91257 | 13.48001 | 15.65713 | 16.76094 | 16.84394 |
| 0.50 mm | 10.74475 | 12.88796 | 13.97429 | 14.06190 | 14.08098 |
| 1.00 mm | 10.13321 | 11.18562 | 11.26916 | 11.29041 | 11.29209 |

**负控制：点端口（同几何、含铜损）**

| 阶数 | 8 | 16 | 32 | 64 | 128 | 256 |
|---|---|---|---|---|---|---|
| |Z| /Ω | 5.7106 | 8.2956 | 10.9700 | 13.6975 | 16.4539 | **19.2255** |

单调上升，无极限（`--selftest` 里断言 `|Z|(256) > 2×|Z|(8)`）。这条对照是会失败的：
哪天有人"顺手"让点端口也收敛了，它立刻挂——那时焊盘才是无关的，"有限孔径"
这个论断就废了。

焊盘越大峰越低越平：0.5 → 1.0 mm 把 2 GHz 的值从 14.06 压到 11.29（−20 %）。
所以 **`port_size_mm` 必填、无默认**：默认一个焊盘就是替调用者改答案。

## 52.6 两条独立真值（都不是这套级数）

1. **平板电容锚点**：`f = f10/1000` 处模态和必须回到 `1/(ω C_pp)`。实测偏差
   **0.14916 %**，超过 1 % 直接 `INTERNAL_CHECK_FAILED`。这是运行时校验，不是测试里的一次性
   断言（§20.8.2 的老规矩）。
   注意：**这个锚点查不出坐标单位错**——`m=n=0` 项不含 `x,y`。本轮真踩过这个坑
   （把毫米当米传，f10 处读出 350.99 Ω 而不是 87.36 Ω），是**与闭式单模峰值互校**才发现的。
2. **闭式单模峰值**（`pdn_plane_modes` 的另一条代码路径）：
   `|Z_peak| = w μ0 t ψ ψ' Q / k²`。f10 处闭式 `91.4691 Ω`（Q = 50），
   模态和 order 64 得 `86.72 Ω`，`86.72 × 50/47.41 = 91.5` ✓。

f10 处的逐项贡献（order 64）：`(1,0) = 86.7241`（**纯实部**，并联谐振就是纯阻性）、
`(0,0) = 1.8290`、`(0,2) = 1.2192`、`(1,2) = 0.9143`，其余 < 0.4。
order 256 时 `R = 86.7799`、`X = 10.0117`、`|Z| = 87.3555`、相位 **+6.58°**。

## 52.7 默认调用读出来什么

`pdn_plane_impedance(50, 50, 4.4, 1.6, 0.02, [12.5,25], port_size_mm=0.5)`
（约 **2.4 s**，106 个点，其中 **10 个是被插进去的模频**）：

| 字段 | 值 |
|---|---|
| `peak_z_ohm` / `peak_freq_hz` | **92.4503 Ω @ 2.85841 GHz**（(0,2) 模；(2,0) 在 x=12.5 处 cos=0，不耦合） |
| `dip_z_ohm` / `dip_freq_hz` | **1.75989 Ω @ 1.55812 GHz** |
| `first_resonance_hz` | 1.42920 GHz（精确 1 429 204 466.2 Hz） |
| `first_mode_q` / `_copper` / `_dielectric` | 47.4101 / 915.295 / 50 |
| `plane_capacitance_f` | 6.08725e-11 |
| `truncation_order` | 256（`maxΔ/峰值` 0.203 %） |
| `capacitance_anchor_error_pct` | 0.14916 |

**读法（必须说清的三件事）**：

* **峰比实测偏高偏窄。** 这是**平面自己**的曲线：没有电容、没有封装、没有过孔。真实板上
  电容组是主导阻尼，Q 在这里是**上界**。
* **谷比实测偏深。** 同理：没有电容阻尼，1.76 Ω 这个谷是"只有平面"的谷。
* **不报反谐振。** 平面与电容组之间的反谐振需要把两者放进同一个网络，这里没有。
* 一个细节：**有损模的 |Z| 峰不在 f_mn 上**，而在 `f_mn(1 − 1/(2Q²))`，Q = 47.41 时低
  **0.0222 %**（318 kHz）。所以采样曲线的最大值可能落在 f_mn 下面一格；f_mn 那一格的
  |Z| 与峰差 0.3 %。插入模频仍然必要（峰很窄），但"峰值频率 == f_mn"这个说法不精确。

## 52.8 拒答与闸门

| 情形 | 结果 |
|---|---|
| 缺 `port_size_mm` | `ARG_REQUIRED`，hint 里带点端口的实测爬升数（5.7 → 19.2 Ω） |
| 缺 `tan_delta` | `ARG_REQUIRED`——无损耗腔在谐振点没有有限阻抗 |
| 焊盘 ≥ 半个平面 | `ARG_RANGE`（"那不是端口，那是平面"） |
| 焊盘 0 / 负 | `ARG_RANGE` |
| 端口越界 | `ARG_RANGE` |
| `f_start ≥ f_stop` | `ARG_RANGE` |
| `tolerance`、`max_order` 越界（8..1024） | `ARG_RANGE` |
| `er < 1` | `ARG_RANGE` |
| 阶数扫描到 `max_order` 仍未达容差 | `NOT_CONVERGED` + `order_reached` / `order_scan` / `hint`（把 `port_size_mm` 调大或提高 `max_order`） |
| 电容锚点偏差 > 1 % | `INTERNAL_CHECK_FAILED` |

`conductivity_s_m = null` 表示理想铜（无导体损耗）——这不是装饰：它是复现
`pdn_plane_modes` 那条"只有介质损耗"口径的开关，负控制要靠它对齐。

## 52.9 与 `pdn_plane_modes` 的分工，以及自检

* `pdn_plane_modes`：**单模峰值**表，`Q = 1/tanδ`（只有介质），不需要焊盘，秒回。用来问
  "带内有哪几个模、各多高"。
* `pdn_plane_impedance`：**整条曲线**（含铜损），需要焊盘，带阶数闸门。用来问"我要的频段
  里 |Z| 到底多大、谷有多深"。
* 两者共同的 `not_computed` 仍然点名：电容/封装、die-package 电感、分割平面、过孔桶壁、
  辐射 Q、开放边缘失谐。

`--selftest` 新增 3 条（id 114–116，总 172 条）：

* `f10/1000` 处曲线 = 平板电容（1 % 内）；
* f10 处曲线 = 闭式单模峰值 × `Q_total·tanδ`（1 % 内）；
* **点端口仍发散**（19.226 / 5.711 = 3.37 倍）而 0.5 mm 焊盘在 256→384 阶只动 0.1 %。

`tests/test_plane_curve.py` 31 例：教科书级数独立重写（不折叠表、`√2` 单写、`sin(u)/u`
内联）对拍 1e-9、互易性精确相等、低频=平板电容（0.5 %）、低频与阶数无关、f10 峰对闭式
（1 %）、铜损按 Q 比例降峰、并联谐振 |φ| < 12° 且实部 > 0、点端口单调且末/首 > 2.5、
`NOT_CONVERGED` 闸门与 `order_scan` 字段、锚点 < 1 %、曲线 ok / 模频插入 / 峰与 dip 语义 /
`value == peak` / 调用者网格保留 / 默认带被标记、11 条拒答、3 条工具面（注册、
`call_tool`、`calc_capabilities` 不再声称曲线缺失）。
