# 86 · 热焊盘花的辐条电阻

`not_implemented_yet` 第 18 条从 0.0.82 起就写着：

> THERMAL-RELIEF SPOKES ARE NOT MODELLED … 这是本答案唯一可能**乐观**的地方。

一句自认的偏差，比二十条"暂不支持"更该先补：别的缺口是**没有答案**，这一条是**给了答案但偏小**。
本篇把它换成 `R = R_sheet · gap / (n · w)`，并把"补上了"和"补到什么程度"分开写清楚。

工具数仍 **179**（不加工具，`board_ir_drop` 多一个可选对象参数 `thermal_relief`），
`dependencies = []` 仍成立；**不传这个参数，答案逐位不变**（`0.935986 mV`，与 0.0.82 的金标一致）。

---

## 1. 一条辐条就是 gap/width 个方块

铜面上一个焊盘靠**辐条**跨过阻焊间隙接到铺铜。辐条沿电流方向的长度是 `gap`，宽度是 `w`，
所以它自己就是 `gap/w` 个方块，`n` 条并联再除 `n`：

```
R = R_sheet · gap / (n · w)
```

`R_sheet` 取**该层实际在用**的那个值（`rho/t`），所以带 `frequency_hz` 时它自动是**趋肤修正后的
厚度** `t_eff`——辐条和铺铜是同一片铜，没有理由给它另一种处理。

手工值（35 µm 铜、`rho=1.724e-8`、4 条 0.5 mm 辐条跨 0.5 mm 间隙）：

```
R_sheet = 1.724e-8 / 35e-6              = 4.9257142857e-4 Ω/□
R       = 4.9257142857e-4 · 0.5/(4·0.5) = 1.2314285714e-4 Ω = 123.14 µΩ
```

工具实测 `connection_ohm_by_layer["F.Cu"] = 1.23142857e-4`（报告层四舍五入到 12 位小数）。
这条不是"算出了一个数"，是**和手算对到 1e-6 相对误差**，且三方向缩放各自成立：

| 变化 | 解析预期 | 实测 `connection_ohm_by_layer` |
| --- | --- | --- |
| `n: 2 → 4` | 比值 2 | 2.000000（1e-6 内） |
| `w: 0.5 → 1.0` | 比值 2 | 2.000000 |
| `gap: 0.5 → 1.0` | 比值 2 | 2.000000 |

## 2. 默认是乐观的——这条要有能失败的对照

`0.0.82` 及以前，**落在填充里的**焊盘按 `1 µΩ` 接到铺铜（等于"实心"），**在填充外但在窗口内**的
按**一个方块**跨过去。前者在真有辐条的地方把压降算小了。同一块板（两个 1×10 mm 焊盘、20 mm 间距、
0.5 mm 栅格）：

| 情形 | `max_drop_mv` | 说明 |
| --- | --- | --- |
| 不传 `thermal_relief` | **0.935986** | 0.0.82 的金标，逐位不变 |
| 4 × 0.5 mm / gap 0.5 | **1.207938** | 两个焊盘各 123.14 µΩ 进入串联 |
| 4 × 0.25 mm | 1.454998 | 辐条窄一半 ⇒ 每个连接电阻翻倍 |
| 4 × 1.0 mm | 1.083380 | 宽一半 ⇒ 减半 |
| 1 × 0.5 mm | 1.947975 | 单条辐条 = 四条之和 |

抬升量 `1.207938 − 0.935986 = 0.271952 mV`，即 **271.95 µΩ**，而 `2R = 246.29 µΩ`。
多出来的 25.7 µΩ 不是误差：把两条 1 µΩ 的短接换成真电阻后，电流在铺铜里的分布也变了，铜本身再多吃一点。
所以判据写成 **`2R ≤ 抬升 < 1.5·2R`**——下界就是"每个焊盘只许算一次"，上界防"重复计了三四次"。

### 接触格要**均摊**，不能每格一条

焊盘不是点：0.5 mm 栅格下 1×10 mm 的焊盘压到 60 个填充格，`pad_boxes` 那一步本来会把每个格子都
按 `1 µΩ` 连一遍（实心时"多个短接并联还是短接"，无害）。换成真电阻就不一样了：60 条 123 µΩ 并联
是 **2.05 µΩ**，答案会小 60 倍。

所以每格给 `k·R`（`k` = 接触格数），`k` 条并联后**恰为 `R`**——一个焊盘的整体连接是**一个**辐条组，
不是每格一组。实测 `pads_split_over_cells = 2`（两个焊盘都被拆过），`connections[i]["cells"] = 60`。

### 锚点去重：一个真缺陷

焊盘的锚点本身是网络里的一个节点，所以它会在**节点循环**里被连一次，又在**焊盘循环**里连一次。
`1 µΩ` 时代这是无害的双重短接；有真电阻时并联会**减半**。因此开了 `thermal_relief` 时，
节点循环里对锚点 `continue`，把它留给焊盘循环统一处理。

这个"跳过"引入了第二个缺陷，是在探针里撞出来的：**当焊盘完全不落在填充里**（离铺铜 2 mm、
在 `zone_link_mm` 窗口内）时，锚点在节点循环里被跳过、焊盘循环里又因为"接触格为空"什么都不做
⇒ 这个焊盘**静默从网络里消失**，整条网报 `NOT_CONNECTED`。修法是焊盘循环在接触格为空时
自己走一次 `nearest_cell` + 辐条电阻；现在报两条连接（一条覆盖 60 格、一条跨 2.264 mm）。

这个"跳过"改完之后还有第二个坑，是全量回归抓出来的：新参数那个字典最初叫 `tr`，而函数后面
`for tr in tracks:` 也用它 ⇒ **不传参数**的调用跑到铺铜段时 `tr` 已变成最后一条走线，`KeyError: 'gap_mm'`。
改名 `tr_geo`。它正好说明"默认关时行为零变化"这条红线的用处：错的不是逻辑，是**新代码改了旧路径里一个名字的含义**，
而且只在铺满两种路径的板上现形。

顺带得到一条可读的对照：

| 同一块短铺铜板（U2 在填充外 2 mm） | `max_drop_mv` |
| --- | --- |
| 不传 `thermal_relief`（桥接按**一个方块** = 492.6 µΩ） | 1.654493 |
| 传 4 × 0.5 mm（辐条 = 123.1 µΩ） | **1.421040** |

这里**辐条的答案更小**，不是bug：一个方块比 4 条 0.5 mm 辐条更阻。也就是说旧的"一个方块"stand-in
在**覆铜远、辐条宽**时是**悲观**的，在填充里则是**乐观**的——两个方向都不该用 stand-in 代替几何。

## 3. 交流：辐条跟着 t_eff 走

`sheet_ohm_per_sq` 在 `frequency_hz` 下已经是 `rho / t_eff`，辐条直接用它，所以 1 MHz 时：

```
R(1 MHz) = 1.24001622e-4 Ω，R(DC) = 1.23142857e-4 Ω，比值 1.0069737
zone_summary.sheets[0].r_ac_over_rdc = 1.006973727
```

两个数对到 1e-6，说明辐条拿到的确实是**同一份**趋肤修正，不是另起一套。判据：
`connection_ohm_by_layer(AC) / (DC) == r_ac_over_rdc`，这条能失败（若辐条误用 DC 厚度，比值恒为 1）。

## 4. 文件里的值：报告，但**不采用**

KiCad 文件确实写着这件事，语法（在仓库内 22.8 万行的真实板上实证）：

* `(connect_pads (clearance 0.2))` ⇒ 实心
* `(connect_pads yes (clearance 0.1))` ⇒ 热焊盘花
* `(connect_pads thru_hole_only …)` / `(connect_pads no …)`
* `(fill yes (thermal_gap 0.5) (thermal_bridge_width 0.5))` —— **两个数在 `fill` 子节点里**，
  不在 `connect_pads` 里（这一点很容易记反）

所以 `_zone()` 现在把 `connect_pads`（`thermal` / `thru_hole_only` / `none` / `solid`）、
`thermal_gap_mm`、`thermal_bridge_width_mm` 读出来，写进 `zone_summary["board_file_states"]`：

```json
[{"layers": ["F.Cu"], "connect_pads": "thermal",
  "thermal_gap_mm": 0.5, "thermal_bridge_width_mm": 0.5}]
```

**但几何一律由调用方显式给。** 原因写在这里而不是藏起来：`connect_pads yes` 与 `zone_connect 2/3/0`
的数值语义，我**只有文件形态自洽 + 记忆，没有拿到一手文档**（`dev-docs.kicad.org` 抓取失败，
本机没装 KiCad）。凭记忆把文件值当默认，等于"记忆决定答案"——这条红线比多一个便利更重要。

因此行为是：**文件声称热焊盘花而调用方没传 `thermal_relief` 时，给一条 warning 说明"该处答案是乐观的"**，
并把文件里的三个数原样报在旁边，让人自己决定。判据（能失败）：`connect_pads yes` 的板子，
不传参数时 `max_drop_mv` 仍是 `0.935986` 而 warning 含 `OPTIMISTIC` / `Pass thermal_relief`。

## 5. 不在这个数里的东西（`not_in_it`，逐条报给调用方）

1. **焊盘自己的扩散电阻**——焊盘在这里（以及这个答案的其它所有地方）都是一个节点。
2. **辐条根部到焊盘角的电流集中**——这是焊盘边缘的三维效应。
3. **`n·w` 超过焊盘周长**——物理上不可能，工具**接受并报告**，不 clamp（钳到一个假值才是编答案）。

另外两条边界：

* 辐条**不加**传播（spreading）项、不加接触电阻。理由：辐条长度是 0.2–1 mm 的间隙量级、宽度是它的一部分，
  端到端电阻就是它自己的电阻；加一个没有几何依据的扩散项等于把两个不确定量乘起来。
* `thermal_relief` **只作用于焊盘**。走线端在填充里仍是 `1 µΩ`（同网同层同一片铜），
  桥接仍是一个方块——这两处没有辐条，改它们就是无依据地加电阻。

## 6. 拒绝而不是猜

三个数**全部必填**，一个都不默认：几何就是这个功能的全部内容。

| 输入 | `reason_code` | 说什么 |
| --- | --- | --- |
| 非对象（如 `[4,0.5,0.5]`） | `ARG_INVALID` | 必须是 `{spokes, spoke_width_mm, gap_mm}` |
| 未知键（如 `spokes_mm`） | `ARG_INVALID` | 静默忽略会让调用方以为辐条被建模了 |
| 缺任一键 | `ARG_REQUIRED` | `R_sheet·gap/(n·w)` 三个都要，**没有合理默认值** |
| `spokes` 0 / 17 / 负 | `ARG_RANGE` | 1..16；多于 16 条不是辐条，是实心 |
| `spoke_width_mm ≤ 0` | `ARG_RANGE` | — |
| `gap_mm = 0` | `ARG_RANGE` | hint：gap 0 **就是**实心连接，别传 `thermal_relief` |
| 值不是数 | `ARG_INVALID` | — |
| `model_zones` 没开 | `ARG_CONFLICT` | 没有铺铜就没有可跨的间隙 |

给了参数却一个焊盘都没用上时，另给一条 warning 而不是沉默（沉默会让人以为改对了）。

## 7. 判据清单（每条都能失败）

| # | 判据 | 失败的形态 |
| --- | --- | --- |
| 1 | `connection_ohm_by_layer` 对 `R_sheet·gap/(n·w)` 相对误差 < 1e-6 | 公式抄错、`w` 与 `gap` 互换 |
| 2 | `n`、`w`、`gap` 各翻一倍 ∓ 2 倍 | 参数没进公式 |
| 3 | 不传参数仍是 `0.935986` | 默认关被动过 |
| 4 | 传参数后 `1.207938`，且 `2R ≤ 抬升 < 3R` | 焊盘被算零次或算两次以上 |
| 5 | 每格 `k·R`、`k` 条并联 = `R` | 并联成 `R/k`（答案小 k 倍） |
| 6 | 填充外焊盘仍连接（`connections` 有 `gap_mm≠null` 那条） | 静默断网 ⇒ `NOT_CONNECTED` |
| 7 | `R(AC)/R(DC) == r_ac_over_rdc` | 辐条用了 DC 厚度 |
| 8 | `spokes` 1 > 2 > 4 > 8、`w` 0.25 > 0.5 > 1.0、`gap` 0.25 < 0.5 < 1.0 | 单调性反了 |
| 9 | 文件 `connect_pads yes` ⇒ `thermal` + warning，**答案不变** | 文件值偷偷当了默认 |
| 10 | 8 类坏参数各自的 `reason_code` | 谁被当成"算了" |

`tests/test_thermal_relief.py` **31 例**；`--selftest` 加 3 条（`305/305 → 308/308`）。

## 8. 一句话

以前这里是 `1 µΩ`，因为没有辐条的几何就没法算辐条的电阻；现在几何是入参，于是这处**唯一的乐观偏差**
变成了一个可以问、可以拒、可以手算对账的量——**而默认路径一位都没动**。
剩下的边界（扩散、根部集中、周长不可行）逐条写在 `not_in_it` 里，不装作不存在。
