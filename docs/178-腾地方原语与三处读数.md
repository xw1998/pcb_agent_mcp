# 178 - 缺口补齐：四个腾地方原语与三个读数

用户问「要让你这样一个模型画好板子还缺什么」，答复里点了五处缺口，这一版补的是其中最硬的两处：
**「看见要改的地方」与「真的能改」之间没有原语**，以及**改之前算不出还剩多少余量**。

底层的判据一条都没动：`shape_gate` 五条规则、`place_gate` 五条规则、八关的门槛、DRC 是判官这条口径，全部原样。
这一版只是让「知道错了」之后有可执行、可回退、可验证的下一步。

## 1. 为什么是这四个原语

RK3506 剩下的五条欠账里，四条是同一个形状：**某几个器件必须整体挪一点，或者某个网络的网名要互换，或者某条走廊要先占住**。
在这之前，这三件事在 MCP 里都没有工具，只能手工改文件——而手工改文件恰恰是静默断网的来源：
footprint 动了、track 没动，文件照样能解析，`board_drc` 的 `unconnected_total` 才会说话。

所以新增四个 `board_edit` op（不是工具，走 `board_edit` 的 plan/apply 三段式）：

| op | 做什么 | 拒绝什么 |
| --- | --- | --- |
| `move_cluster` | 一组成员整体平移/绕自身质心旋转；`with_copper` 把簇内铜一起搬 | 铜会留在原地而器件走了 ⇒ `ORPHAN_COPPER`（除非 `allow_orphan`） |
| `swap_pad_nets` | 一组焊盘的网名做**一环旋转** | 焊盘不存在 ⇒ 具名报错；只换一个 ⇒ `ARG_RANGE` |
| `reserve_region` | 用**命名的 rule area**（`reserve:<group>`）先占住一条带 | 同名已存在 ⇒ `RESERVE_EXISTS`；区内已有他网铜 ⇒ `RESERVE_OCCUPIED` |
| `release_region` | 撤掉同名命名区，所有图层一起撤 | 没有同名 ⇒ `RESERVE_NOT_FOUND`，消息里列出已有的命名 zone |

三条设计取舍，都是为了「不替用户做决定」：

- **`move_cluster` 只做一步，不做布局**。挪谁、挪多少、要不要转 90° 由调用方给。仓库不许自动布局，
  这条线不因为「多了一个好用的原语」而松动：它提供的是**一个可验证的移动**，不是一次布局搜索。
- **orphan 默认拒绝**。断网是这四件事里唯一不会当场报错的一种：板子还能打开、还能铺铜、还能出 Gerber。
  默认拒绝 = 把「静默断网」变成「必须显式承认」。`allow_orphan=true` 时仍然如实报
  `copper_orphaned` / `copper_orphaned_nets`，不因为「已经同意了」就不说。
- **reservation 用 KiCad 原生的命名 zone，不自造对象**。真实板文件里本来就有
  `(name "auto-placement-area-/CH4/")`，KiCad 自己写的；`(name ...)` 在 `(uuid ...)` 之后。
  round-trip 有官方保证，和「铜只能由官方 ZONE_FILLER 生成」是同一条道理。

## 2. 三个读数：把「还剩多少余量」变成数字

原语能改，但改之前得知道**还改不改得动**。三个新工具读的就是这个：

### `board_length_budget` - 这组网还能不能等长，卡在哪

用的是**等长工具自己的齿模型**（`route/tune.py`），不是另发明一套：一个振幅 A 的齿加长
`2*(sqrt(2)-1)*A ≈ 0.828*A`，吃掉 `2*A` 的直线段；于是

- 一条直线段能放 `floor((s - min_segment)/2A)` 个齿；
- 一条网的**天花板** `= 0.414 * 可用直线总长`——和振幅无关；
- 而 `route/tune.py` 的 `_serpentine` 拒绝单次超过 **400 个齿**，所以振幅窄到一定程度，
  长直线段会被这个上限截断，**可用的加长量真的会掉下来**（这是「窄带」唯一真正损失容量的地方，
  齿数公式本身对振幅是中性的）。

四种答案分开报，因为它们对应四种不同的处置：

| 判词 | 意思 | 该怎么办 |
| --- | --- | --- |
| `in_tolerance` | 差值已经落在公差里 | 不动 |
| `fits` | 在 permille 级现有的直线段里能弯出来 | 直接调 `board_tune_length` |
| `needs_wider_band` | 长度够，但这个振幅下放不下（齿数被 400 截断） | 放宽 `band_mm`，或把绕行分到别的段 |
| `route_too_short` | 再密的齿也到不了目标 | **这条线要重布，不是调** |

`nothing_to_match` 是第五种，专给只给了一条网又没给 `target_mm` 的情况：
目标从自己身上取，等于问「这条网和自己一样长吗」，答案恒真、零信息。
这一条不是防御性代码，是这一版实测出来的——第一轮探针就在这个坑里返回了 `budget_met`。

### `board_group_consistency` - 这一组看起来像不像一束

长度匹配的组，人眼看的三件事分开量、分开限、分开报，不做成一个分数：

1. `length_spread` - 组内长度极差，限 `tolerance_mm`；
2. `parallel` - 最差那一对里，段对中方向一致的**比例**，限 `parallel_min`；
3. `spacing_even` - 两两最小净空的**变异系数**，限 `spacing_cv_max`。

`spacing_even` 在只有两条网时是 `ok: None`（**跳过，不是失败**）：两条网只有一个净空值，
没有变异可言。把它判失败，会让每一对两网组因为算术原因变成 `inconsistent`——
这是实测踩到的，`failing` 只收 `is False`，不收 `None`。

同一条口径的另一面写在 `precision` 里：`parallel_fraction` 是**段对全配对**，
一条由很多短段、方向又杂的网，即使真的与同伴并行也会得低分。所以它是**该看的地方**，不是缺陷清单。

### `board_reservations` - 占住的带子还空着吗

把每个带名字的 zone 读回来：位置、图层、keepout 规则、区内有几条他网铜。
**只有当标签里每个词都是本板真有的网名时才判 `free`**；像 `buck cluster` 这样的名字会被
`nets_are_known=False` 认出「这是个名字不是网表」，于是不判外来铜——
猜哪个 token 是网名，就是 checker 开始编造拒绝的起点。

`kind` 区分 `reservation`（`reserve:` 前缀，本工具写的）与 `rule_area`（KiCad 自己写的
`auto-placement-area-*` 之类）：两种都读，但不混算。

## 3. 看图：`board_render` 加了 region 与 compare

- `region=[x0,y0,x1,y1]`：只画一个窗口。300 mm 的板上要看一个 20 mm 的簇，这是唯一可行的办法。
  帧是**视图帧（Y 向上）**，即文件 Y 取反；反向的矩形报 `ARG_INVALID`，不静默纠正。
- `compare=<另一块板>`：同一个窗口、同一个比例画两块板，出差分图——灰=两边都有铜、
  红=只在 `path`、蓝=只在 `compare`，外加 `pixels_shared / pixels_only_here / pixels_only_there /
  changed_fraction / changed_bbox_mm / identical`。改完之后「到底动了哪些铜」有了逐像素的答案。

两条实测修正：差分 PNG 的默认文件名必须带**被比较文件的尾部**（否则连续两次比较互相覆盖，
第一次的「全灰自比」会把第二次的真差分图盖掉，信封里的数字是对的、看到图是空的）；
`compare` 的判型不能用 `isinstance(other, dict)`——另一块板是 `adapters.canonical.Board`，
判错会直接吐 `PARSE_FAILED`。

## 4. 反向失败对照

每个判词都配了能让它翻面的对照，都在 `tests/test_length_budget.py`（18 例）与
`tests/test_see_and_judge.py`（19 例）里：

- `route_too_short` → 同一块板子只把目标从 45 降到 40 就变 `budget_met`；
- `fits` → 同一块板子把 `band_mm` 从 1.0 收到 0.02 就变 `needs_wider_band`（且 `teeth_capped=True`），
  而 `ceiling_mm` 一分不变（只改了带子宽，没改直线段）；
- `consistent` → 同一组网里一条网绕出去 20 mm 就变 `inconsistent`，且 `failing` 里点名 `length_spread`；
- `spacing_even` 失败 → 把第三条平行线从 8 mm 外挪到 2 mm 内侧就通过；
- `free=True` → 一条他网 track 的端点落进带子里就变 `free=False` + `foreign_nets=['SIG']`；
- `ORPHAN_COPPER` / `RESERVE_EXISTS` / `RESERVE_OCCUPIED` / `RESERVE_NOT_FOUND` / `NO_GEOMETRY` /
  `ARG_RANGE` / `ARG_MISSING` 各有一条具名断言。

## 5. 没做到的

- **审美代理量**（"这条线绕了一圈"之类）仍然只有 `detour_ratio` 与 `shape_gate` 的五条，
  没有一个能对「两个都合法、但一个好看」排序的量。这一版没动。
- **语料分层**（哪几块板算「完美板」、规则在它们上的通过率该怎么加权）没做。
  `judge_corpus` 的口径仍是「一条规则在语料上的失败率」，没有按板的品质分层。
- `board_reservations` 的占用判据是**端点入界**（射线法），一条横穿带子但两端都在外面的线不算占用。
  这是刻意选的宽口径并写在 `precision` 里：宁可漏报，不可把「穿过」当「占了」。
