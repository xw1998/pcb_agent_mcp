# 22 · 微带与腔体滤波器设计（ADS 那一路的合成器，不是仿真器）

> 目标不是"再做一个场求解器"，而是把 ADS 里最常被点的那几个**合成（synthesis）**按钮，
> 做成这套 MCP 里可以被 AI 调用、并且**答案自带对账**的工具：原型 g 值、集总带通、
> 耦合微带几何反解、耦合谐振器带通、矩形腔 TE101。

一句话口径：**这里给的是"要画成什么样"，不是"画出来会是什么样"。**
凡是需要场求解器才能回答的问题（交叉耦合、色散、有限 Q、iris 几何、EM 扫描），
全部列进 `not_computed`，一个都不假装。

---

## 22.1 为什么"合成"可以脱离 EM 求解器

滤波器的设计链是两段：

1. **综合（synthesis）**：给定响应（Chebyshev / Butterworth）、阶数、带宽、阻抗，
   算出原型 g 值 → 元件值 或 耦合系数/Qe → 几何尺寸。这一段是**闭式 + 反解**，
   不需要知道最终场分布，只需要一个能算截面阻抗的 2-D 求解器（本仓库已有 `calc/field2d.py`）。
2. **验证（analysis）**：把几何放进去跑 EM，看插损、驻波、带外抑制、调谐灵敏度。
   这一段**只有全波求解器能做**，本仓库明确不做。

ADS 的价值在第一段（迭代快、几何直接给），风险在第二段（用户容易把合成结果当成仿真结果）。
所以本模块的每条答案都带 `model` / `basis` / `precision` / `assumptions`，
并且**两路独立推导必须对上，否则拒答**。

## 22.2 原型 g 值：`prototype_gvalues`

Chebyshev 原型（0.5 dB）与 Butterworth 的 g 值就是教科书表，用来当金标：

| n | Chebyshev 0.5 dB g1..g(n+1) |
|---|---|
| 3 | 1.596331, 1.096681, 1.596331, 1.0 |
| 5 | 1.705821, 1.229610, 2.540881, 1.229610, 1.705821, 1.0 |

Butterworth n=3 必须给出 1, 2, 1, 1（那个"1-2-1 交替"是它最容易写错的地方）。

- `ripple_db` 默认 `None` ⇒ 按 response 取自然值（chebyshev 0.5、butterworth 0）；
- Butterworth 传非零 ripple ⇒ `ARG_CONFLICT`（不是悄悄忽略，因为"忘了清 ripple"和
  "想要 0.5 dB Butterworth"在数值上看起来一样，但后者不存在）；
- `order > 20` ⇒ `ARG_RANGE`（闭式在数值上开始不稳，且这种阶数的集总实现不可制造）。

## 22.3 集总带通：`lumped_bandpass`

LP→BP 变换：

```
Omega = (1/FBW) * (f/f0 - f0/f)
```

每个低通元件变成谐振在 f0 的 LC 分支（串联→串联 LC，并联→并联 LC），再做阻抗缩放。
输出 `elements[]`，每项带 `kind` / `L_nh` / `C_pf` / `f_self_res_hz`。

**对账是硬门槛**：同一条响应算两遍——

- 路 A：把这些 L/C 真的级联起来，乘 ABCD 矩阵，取 S21；
- 路 B：闭式 `1/(1 + eps^2 * Tn^2(Omega))`。

两条路逐点比，`max_abs_deviation_db` 超过 **0.02 dB** 就返回 `INTERNAL_CHECK_FAILED`，
**不把答案端出去**。实测（n=3, 2.4 GHz, FBW=0.1）：`f0` 处 0.0 dB、
两个带边 0.5 / 0.5001 dB、`max_abs_deviation_db = 0.000521`。

这条对账是这类工具唯一能自证的方式：它同时能抓住 ABCD 的符号错、转置错、
2 倍因子错——这三种错都会让 S21 曲线"看起来还挺像"，只有逐点比才抓得住。

带边频率用几何公式而不是 f0(1±FBW/2)：

```
f_lo, f_hi = f0 * (sqrt(1 + (FBW/2)^2) ∓ FBW/2)
```

两者差距很小，但几何式才是变换本身定义的带边，且满足 f_lo*f_hi = f0^2。

不做的：有限 Q 插损、元件寄生（ESR/ESL）、电容自谐振、容差与良率、版图。

## 22.4 耦合微带反解：`coupled_microstrip`

给定 `z0e / z0o`（偶模 / 奇模阻抗），求 `w / s`。

截面是**解出来的**，不是查表：`field2d._cap_modes` 在截面上解拉普拉斯方程，
偶模用磁壁、奇模用电壁，得到单位长度电容，再换成阻抗。

反解用**阻尼 Newton + Broyden 更新 + 回溯线搜索**，变量取 `log(w), log(s)`
（几何量跨两个数量级，对数和线性差一个迭代次数级别）。这里踩过一个值得记的坑：

> Newton 步长 `dw`, `ds` 是 **mm**，而变量是相对比例 `w`, `s`。
> 直接把 mm 步长当成相对比例，每次只挪 3%，10 次迭代后还差 4.6%——
> **看起来像"收敛慢"，其实是单位错**。改成 `dw/w`, `ds/s` 之后 3~5 s 内收敛到 0.24~0.29%。

实测（`fine_div=6`，即网格 `h/6`）：

| 目标 (z0e, z0o) | w (mm) | s (mm) | 达成 | 最差误差 | 迭代 |
|---|---|---|---|---|---|
| 70, 40 @ h=0.2 er=4.3 | 0.2855 | 0.0788 | 70.00 / 40.00 | 0.006 % | 4 |
| 55, 45 @ h=0.2 | 0.3807 | 0.2914 | 55.05 / 44.87 | 0.283 % | 5 |
| 120, 80 @ h=0.2 | 0.0812 | 0.1829 | 119.90 / 79.81 | 0.242 % | 4 |

### 网格：追基板高，不追 gap

`fine_div` 定义 `cell = h / fine_div`（默认 6）。为什么不按 gap 加密？

因为 **quasi-static 模型自身的误差大于网格误差**。把网格从 `h/6` 加密到 `h/12`，
同一几何（w=0.2948, s=0.096, h=0.2, er=4.3）的 Z0e 只从 69.57 走到 70.17（+0.9%），
Z0o 同向 +0.7%；而 `h/3` 是 64.52，明显欠网格。所以：

- `h/6` 是**标定过的工作点**（3 倍快的代价换来约 1% 的偏差）；
- 文档如实写这个漂移，而不是声称"网格无关"；
- 需要更高精度就把 `fine_div` 开到 12，并且知道这是**用 3 倍时间换 1%**。

### k 的分辨率：一个必须说出口的缺陷

`k = (z0e - z0o) / (z0e + z0o)` 是**两个相近数之差**。阻抗都解到 0.5% 时，
k 的误差可能是 13% 甚至 15%。这不是不收敛，是信息本身在这种情况下不足。

所以当 k 误差 > 3% 时，信封里会带 `k_resolution_note`，明确说
"把 k 当调谐起点，不要当测量值"。**这一条曾经是个真 bug**：
note 里引用了不存在的变量名（`z0e_target`），只有在 k 误差超过 3% 时才会执行到，
而当时的测试用例都收敛得很好，所以这个分支从来没被执行过——
一个永远不会被跑到、一跑就 `NameError` 的"说明文字"。

> 教训：任何"只在异常情况下才输出"的解释性代码，都要有一条测试**专门把它逼出来**。

`k < 0.02` 直接拒（`OUT_OF_VALIDITY`）：这么弱的耦合既解不准，也做不成谐振器耦合。

不做的：色散、T 结、有限地平面、邻近铜、表面粗糙度、阻焊层。

## 22.5 耦合谐振器带通：`coupled_resonator_bpf`

边缘耦合半波谐振器带通，把 g 值换成三个几何量：

| 量 | 公式 |
|---|---|
| 外部 Q（输入/输出） | `Qe_in = g1/FBW`，`Qe_out = gn*g(n+1)/FBW` |
| 相邻耦合系数 | `k_ij = FBW / sqrt(g_i * g_j)` |
| 谐振器长度 | `lambda_g/2 - 2*Δl`（两端开路端修正，Hammerstad） |

每个耦合段都回带完整判定链：`target_z0e/z0o` → 反解 `w/s` → `achieved_k` →
`k_error_pct` → `meets_target` + `k_note`。

实测（n=3, 2.4 GHz, FBW=5%, h=0.254, er=4.3，约 29 s）：

- Qe in/out = 31.9266（= 1.596331/0.05）
- `lambda_g` = 69.0951 mm，`Δl` = 0.0978 mm，谐振器长 = 34.352 mm
- 段 1（between 1-2）：目标 k = 0.037789，achieved 0.040682（`k_error` 7.7%，`meets_target: false`）

这 7.7% 就是上面说的**k 分辨率极限**：同一段的 z0e/z0o 只差 0.3% 就解对了，
但它们的差商（k）解不到 1% 以内。工具不掩盖这一点，`meets_target: false` 就是它的结论：
**这个耦合太弱，准静态解不出可信的 s，要去 EM 里调。**

不做的：交叉耦合（因此带外零点 / 阻带零点是模型里不存在的）、
非相邻谐振器耦合、馈线间隙几何（只给 Qe，不给 gap 尺寸）、
有限 Q、辐射 Q、版图生成。

## 22.6 矩形腔 TE101：`waveguide_cavity`

给定 f0、a、b（b 默认 a/2），给 TE101 的：

- **长度 d**：由 `k^2 = (π/a)^2 + (π/d)^2`，`k = 2πf/c`；
- **表面电阻 Rs** = `sqrt(π f μ0 / σ)`；
- **无载 Q**：**两路独立推导**
  - 闭式括号式（六面壁的经典表达式）；
  - 数值积分：在六个面上对 `|H_tan|^2` 做数值面积分，再除以壁损；
- **R/Q** = `4b / (ω ε0 a d)`。

实测 WR-90（a=22.86, b=10.16）@10 GHz，铜：

| 量 | 值 |
|---|---|
| d | 19.8536 mm（= 波导波长的一半） |
| Rs | 0.02609 Ω |
| Qc（闭式） | 7821.5 |
| Qc（数值积分） | 7821.5 |
| 两者差 | 0.0 %（>2% 拒答） |
| R/Q | 160.957 Ω |

这三个数都能手算核对：d 用 `π/sqrt(k²-(π/a)²)`；Rs 用 `sqrt(πfμ0/σ)`；
R/Q 用 `4b/(ωε0 a d)`。测试里就是这么算的——**不是拿代码跑一遍当期望值**。

低于 TE10 截止（WR-90 的 6.56 GHz）⇒ `OUT_OF_VALIDITY`，因为没有 TE101；
`mode="TE011"` ⇒ `NOT_IMPLEMENTED`（本题只做 TE101，别的模式不假装）。

不做的：高阶模与 mode chart、iris/探针耦合几何（**必须全波**）、
表面粗糙度修正、介质填充的损耗角、多腔级联。

## 22.7 耦合矩阵：交叉耦合零点与有限 Q —— `coupled_matrix_filter`

`filters.py` 里所有东西都是 **inline** 的：梯型，或者一排只跟左右邻居说话的
边耦合谐振器。inline 滤波器**没有有限传输零点**——阻带斜率只由阶数定；插损也
只有一个数，看不出哪些谐振器储的能量更多。

把滤波器写成耦合矩阵 M，这两件事都变：

    A     = Omega * U - j * R + M
    Omega = (1/FBW) * (f/f0 - f0/f)

M 是归一化耦合矩阵（带通下 `m_ij = k_ij / FBW`），R 带两端的**外部 Q** 和每个
有损谐振器上的 `1/Qu`（归一化）。inline 矩阵由原型 g 值给出：

    m(i,i+1) = 1 / sqrt(g_i * g_(i+1)),   Qe1 = g1,   Qen = g_n * g_(n+1)

### 引擎为什么是节点法 + Π 逆变器

唯一的硬约束是**交叉耦合必须能形成环路**（1→3 的耦合与 1→2→3 的串路相消，
零点就是这么来的）。ABCD 级联做不到这一点，因为它是"串联"结构，没有环路。

所以每个耦合被贴成一个**理想导纳逆变器的精确 Π 等效**：

    两端各一条并联 +jJ，两点之间串一条 j/J

它的 ABCD 恰好是 `[[0, j/J], [jJ, 0]]`（A=0、D=0、B=jK、C=j/K 四式都可代数验证）。
然后在节点矩阵上解 `V = Y^-1 e_s`，`S11 = 2V0 - 1`、`S21 = 2V_(n+1)`。

**这里踩过的两个坑，写下来给下一个人：**

1. **串联支路不能"插一个内部节点、两端各加 ya"**。那样两端各 `ya` 再加内部
   节点两次，等效成 `ya/2`，阻抗翻倍——实测整块变成阻带（|S21| 从 −5.8 dB 起），
   而且看着"很像一个滤波器"，只有拿原型多项式对账才能发现。正确做法是直接在
   两个节点之间 stamp `1/z`。
2. **矩阵公式 `A = ΩU − jR + M` 的 |S21| 永远是对的，|S11| 不对**（归一化写错
   会给出非物理的 |S11| > 1）。所以 S 参数一律走节点解，矩阵只用来取代数：
   M 本身，以及下面那个零点的余子式公式。

### 三条自检（答之前先过）

| 检查 | 容差 | 实测残差 |
|---|---|---|
| inline + 无损必须复现 `1/(1+eps_eff²·Tn(Ω)²)` | 1e-6 dB | ~1e-12 dB |
| 无损时 `\|S11\|²+\|S21\|² = 1` | 1e-9 | ~1e-16 |
| 三阶 trisection 零点落在余子式给出的位置 | 1e-6（Ω 上） | 0 |
| 网络实际给出的纹波 = 原型 g 值所对应的纹波 | 1e-3 dB | ~1e-5 dB |

第 1 条里的 `eps_eff` **不是** `filters._epsilon(ripple)`，而是在 |Ω|=1 处从网络
自己读出来的：`filters.py` 的 Chebyshev g 值来自 Matthaei 的
`log(1/tanh(R/17.37))` 递归，与精确 ε 差 ~5e-5（相对），在远阻带表现为
**4e-4 dB、与 FBW 无关**的偏差。拿精确 ε 去对账，会把这条本来就存在的近似
当成这个模块的缺陷。代价是：eps_eff 会把"所有耦合被同比例缩放"这一点吸收掉，
所以第 4 条单独盯住纹波幅度。两条一起才既验形状又验尺度。

### 零点：来自余子式，不是来自曲线寻峰

三阶 trisection（1-2、2-3、1-3 三条耦合）的 `A` 的 (3,1) 余子式是
`m12² − Ω·m13`，所以

    Omega_z = m12² / m13

然后**再**在 ±0.6 Ω 窗内用黄金分割数值找 |S21| 的谷，两者对账。实测：
2.6 GHz / FBW 5% / 零点 2.86 GHz 时 Ω_z = 3.818182，数值最小点也在这里，
误差 0.0%，`depth_db` = 342.6 dB（无损时是真零，|S21| ~ 1e-17）。

`m13` 的**符号**决定零点在带上还是带下：m13 > 0 → 带上，m13 < 0 → 带下。
 |Ω_z| < 1.2 的 `zero_hz` 直接拒（那是把陷波切在通带里，不是交叉耦合滤波器）。

自定义矩阵（`couplings` 参数）会扫整个 span 找最深的几个谷。如果某个零点落在
**通带内**（|Ω| < 1），答案会给它打 `inside_passband: true` 并明说"这是从带里
挖掉的陷波，不是你给的矩阵所描述的一个带通滤波器的阻带零点"。如果 span 内
找不到谷，`why_none` 会提示"要么没有零点，要么零点在 span 之外，加大 span"。

### 有限 Qu：归一化网络里必须是 Qu·FBW

网络的频率轴被 1/FBW 拉伸过，外部 Q 已经按同比例缩放（`qe = Qe·FBW`），
那么物理的 Qu 也必须同样进入：`qu_norm = Qu·FBW`。

**用原文 Qu 会让插损小 1/FBW 倍**。实测 n=3 / Qu=200 / FBW=0.1 / 纹波 0.5 dB：
用原文 Qu 得 0.093 dB，正确应为 0.920 dB，差 ~10 倍。这个错误被 Matthaei 的
中频耗散损耗 `4.343·Σg/(Qu·FBW)` 交叉检查抓出来（判 `INTERNAL_CHECK_FAILED`）。修后：

| 阶数 / Qu / FBW（纹波 0.5 dB，f0=1 GHz） | 网络 | Matthaei | 偏差 |
|---|---|---|---|
| n=3 / 200 / 0.1 | 0.9204 dB | 0.9314 dB | −1.18 % |
| n=5 / 500 / 0.1 | 0.7257 dB | 0.7306 dB | −0.68 % |
| n=3 / 400 / 0.1 @2.4 GHz | 0.4628 dB | 0.4657 dB | −0.62 % |
| n=2 / 100 / 0.1 | 1.3328 dB | 0.9164 dB | −9.12 %（偶数阶含 ripple 基线偏移，已减掉） |

有损时零点**不再无限深**：`depth_db` 从 342.6 dB 掉到有限值（上例加 Qu=150 后
只剩 59.57 dB），`depth_limited_by` 会写明"the unloaded Q"。这就是这条支路
真正交付的抑制量。

### 通带内纹波：走自己的密网格，并且如实报告

两件事：

1. **in-band 的 min/max 不能从显示扫描里读**。默认 `points=41` 铺在整个 span
   上，落在带内的点很少（span=3 时 7 个，span=6 时 4 个），纹波会被照样低估：
   同一个滤波器实测 0.52 dB（span=3）/ 0.35 dB（span=6），而密网格是 0.86 dB。
   现在 in-band 数字来自**独立的 401 点网格，只扫 `band_lo..band_hi`**，并给出
   `sampled_points_in_band`。测试里断言 `points=41` 与 `points=401` 给出
   **完全相同**的 `ripple_actual_db`。
2. **加了交叉耦合之后，纹波不再是你要的那个数**。本模块的 trisection 是
   **对 inline 矩阵的微扰**，不是 Cameron 相似变换全合成。实测 n=3 / 纹波
   0.1 dB / FBW 5% / 零点 2.86 GHz：实际纹波 **0.86 dB**，是你要的 8.6 倍。

   代价有多大？实测**只重调一条 m12**（0.9192 → 0.9224，其余不动）就能把纹波
   压回 **0.102 dB**。也就是说这条微扰路径本身是良态的，缺的正是"把平移吸收
   掉"的那一步章法。本模块不做那一步。

   决定：**不做全合成**（需要复根求解 + Givens 旋转，风险和验证代价都大），
   改为诚实报告——`ripple_actual_db` 是"你实际得到的"，`ripple_requested_db`
   是"你要求的"，`ripple_note` 与 `precision` 都写明这是微扰矩阵的结果，
   `not_computed` 里点名 "exact synthesis (Cameron rotations) 未做"，同时
   `couplings` 参数作逃生口：**你自己合成好的矩阵可以原样传进来精确评估**。

### 输出里值得先看的东西

- `matrix.m` / `q_external_in/out`（归一化）与 `*_absolute`（真实 Qe，= 归一化/FBW）；
- `transmission_zeros.zeros[*]`：`analytic_omega` / `measured_omega` / `omega_error_pct`
  / `depth_db` / `depth_limited_by` / `inside_passband`；
- `inband`：`ripple_actual_db` vs `ripple_requested_db`、`sampled_points_in_band`；
- `loss`：`insertion_loss_center_db`、`matthaei_estimate_db`、`matthaei_deviation_pct`；
- `self_check`：上面四条自检的实测残差与容差；
- `next_step`：**这是电设计**。inline 要画图交给 `filter_coupled_resonator`；
  trisection 需要折叠版图与 gap 尺寸，本仓库不生成，只能拿这里的矩阵去跑 EM。

`not_computed` 五条：交叉耦合的**物理实现**（折叠/正则版图与 EM）、任意掩模的
**精确 Cameron 合成**、波导膜片/探针耦合、色散与耦合的频率依赖、非同步调谐
（`m_ii ≠ 0`）与更丰富的损耗模型。

## 22.9 这一层明确不做的事（写给下一个人）

1. **不做全波**。任何需要 Maxwell 方程在 3-D 里解的问题都不在这里：交叉耦合的
   **物理实现**（折叠版图、iris 尺寸、EM 验证）、辐射 Q、腔体高阶模、封装寄生。
   注意这条边界的位置：`filter_coupling_matrix` 能给**电学上的**带外零点与抑制量，
   但那是矩阵层面的答案，不是"这块板子会给出这个零点"。
2. **不做版图**。输出是 `w/s/length`，是可以被 `board_*` 工具拿去画的数字，
   但不是已经路由好的 PCB。
3. **不做无损之外的损耗模型**。集总带通是理想 LC，耦合谐振器只有 k 与 Qe，
   没有插损曲线。
4. **不做良率**。容差分析需要蒙特卡洛 + 元件分布，这里没有。

这四条的边界在 `calc/filters.py` 的 `NOT_COMPUTED` 里逐条列出，
并且每一份答案都会把它带出去——**调用方不需要读这份文档也能知道边界。**
