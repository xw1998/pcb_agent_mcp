# 19 · 机械振动：薄板、单模态、线性，边界说清楚

> 一句话：这一层回答四个问题——**它多快开始振、振多狠、多久会裂、掉一下会怎样**
> ——但只用四种闭式或半闭式模型，每一种都在 `basis` 里写明它成立的前提，
> 并且**不做应力场求解**：主答案仍是位移，应力只在同一组 Ritz 曲率上取三个极值（§19.9）。

## 19.1 为什么不抄一张模态表

薄板模态有权威表（Leissa《Vibration of Plates》/ NASA SP-160）。抄表看起来很划算：
一行一个边界条件、一个 λ²。但表只覆盖**矩形**、**四种经典边界**（SSSS / CCCC / FFFF / CFCF）
和**有限几个泊松比**。真实 PCB 落在这张表外：

- 板框是圆角矩形 / L 形 / 带挖空，只能用一个等效矩形；
- 四角螺丝固定（`corners`）既不是简支也不是固支，表里没有；
- FR-4 的 E 在 18~30 GPa 之间飘（见 §19.6），ν 也不是 0.3；
- 用户想知道的是"第一阶多少 Hz"，而表格给的是 λ²，还要自己换算 D / ρh，
  换算是错误的来源，不是知识的来源。

所以这一层用**一套**数值方法覆盖所有情形：Rayleigh–Ritz + 单项式基 + 边界约束零空间
+ 质量度量白化 + Jacobi。一套代码，五个 `mount`，任意长宽比，任意 ν。
精度已经用表核对过（§19.2），所以"不用表"并没有换来不准。

## 19.2 数值方法：四步

Kirchhoff 薄板的应变能是

```
U = D/2 · ∫∫[ w_xx² + w_yy² + 2ν w_xx w_yy + 2(1−ν) w_xy² ]
D = E h³ / (12 (1−ν²)),      质量面密度 = ρh
```

1. **基**：ψ_k(ξ) = ξ^k，k = 0..K，ξ ∈ [0,1] 是归一化坐标。二维基是张量积 ψ_i(ξ)ψ_j(η)。
2. **边界约束做成行**（每轴独立）：
   - ξ=0 端 简支 → `a₀ = 0` 与 `2a₂ = 0`（即 w(0)=0、w''(0)=0）；
   - ξ=0 端 固支 → `a₀ = 0` 与 `a₁ = 0`；
   - ξ=1 端 简支 → `Σa_k = 0` 与 `Σk(k−1)a_k = 0`；
   - ξ=1 端 固支 → `Σa_k = 0` 与 `Σk a_k = 0`；
   - 自由端 → 不加约束（自然边界条件由弱形式自动满足）。
   对这些行做 MGS 正交化，再把单位阵投影掉，得到**零空间**的正交基。
3. **白化**：一维质量阵 `M₁ = Bᵀ M₀ B`，Cholesky 分解 `M₁ = L Lᵀ`，取 `W = B L⁻ᵀ`。
   于是 `Wᵀ M₀ W = I`，二维质量阵就是 `I ⊗ I = I`——
   **广义特征值问题退化成对称矩阵的普通特征值问题**，不需要 QZ。
4. **Jacobi**：循环 Jacobi 旋转（阈值 1e-13），升序返回。自由度上限 44，超过就降 K 并在
   `basis.auto_reduced` 里说出来。

### 实现时踩过、并且留下了测试的三个坑

| 坑 | 症状 | 现在 |
|---|---|---|
| 刚度写成 `D/2 · ∫[...]` | **所有频率都偏低恰好 √2 倍**，看起来像"材料偏软" | 注释写明二次型求导后 1/2 会抵消，测试核 SSSS 到 6 位 |
| 混合项用 `Icross_y[j,l]` | 自由边界出现 **−92000 量级的负特征值**；SSSS/CCCC 因为矩阵恰好对称看不出来 | 用 `∫ψ_j ψ''_l`（转置），并有 `test_no_negative_eigenvalue_in_any_mount` |
| Jacobi 返回 `v[r][c]` 当模态 | **特征值对、振型错**：反节点不在中心 | 返回按模态做行，测试用 `sin(π·0.05)=0.1564` 核探针值 |

第三个坑最危险：特征值精确到 6 位，只有看振型才发现错。

| FFFF 方板（ν=0.3）λ² | 13.4687 | Leissa 13.489 | 0.15 % |
| FFFF 前三阶 | 0, 0, 0 Hz | 3 个刚体模态 | 识别为 `rigid_body` |

## 19.4 随机振动：Miles，两种算法互证

单自由度、平坦 PSD、单模态：

```
g_rms = sqrt(π/2 · f_n · Q · W)          W 单位 g²/Hz
```

非平坦 PSD（实测谱）则按定义积分：

```
g_rms² = ∫ W(f) |H(f)|² df,   |H| = 1/sqrt((1−r²)² + (2ζr)²)
```

被积函数在 r=1 附近宽度只有 ~ζ，均匀网格要几十万点才够，所以分三段：
`[0, 1−δ]`、`[1−δ, 1+δ]`、`[1+δ, 3]`，`δ = max(12ζ, 0.02)`。
平坦 PSD 下两法相差 **0.045 %**（测试断言 < 1 %）。

位移由加速度换算：`Z_rms = g_rms·9.80665 / ω²`。峰值 = γ·rms，γ 默认 3。

**只说一件事**：这是单模态。第二阶常常只在 1.5 倍频率处，它会一起响应。
`warnings` 里如果 PSD 跨频段变化超过 2 倍就会提示去用完整模态求和。

## 19.5 疲劳：Steinberg 三带 + Miner

把 3σ 位移切成三带，各自是一个"等幅"工况：

| 带 | 位移幅 | 循环占比 |
|---|---|---|
| 1 | 3σ | 0.3333 |
| 2 | 2σ | 0.2713 |
| 3 | 1σ | 0.3954 |

```
N_i = N0 · (z_allow / Δ_i)^b
D   = f_n · Σ (fraction_i / N_i)      每秒钟的损伤
寿命 = 1 / D
```

`b = 6.4` 是 Steinberg 对**引线**给出的斜率。`N0 = 2e7` 是他引用的循环数。

**`z_allow_mm` 是必填项，这一层不提供它。** 理由和 §18 一样：「±1.5 mm @ 2e7 循环」
是"引线类元件"这个类别的数，不是你这颗器件的数。填进去就等于替你做了一次选型判断。
没给就 `ARG_REQUIRED`，并在 `hint` 里说清要么去查器件自己的认证报告。

同样，焊点蠕变、BGA 焊球疲劳用的是别的斜率、别的允许值——这一层只做你给了数的那一种机制。

## 19.6 冲击：单自由度 + Newmark

```
ü + 2ζω u̇ + ω² u = −a_base(t)
```

三种脉冲：`step`（永不结束）、`rect`、`half_sine`。Newmark β=1/4、γ=1/2
（平均加速度法，无条件稳定），`dt ≤ min(T_n/24, pulse/60)`。

输出两个量，因为它们是两件事：
- **相对位移峰值** —— 决定安装/引脚受的力；
- **绝对加速度峰值** —— 决定器件自己感受到多少 g。

验证基准是解析解：

| 情形 | 本实现 | 解析 | 误差 |
|---|---|---|---|
| step，ζ→0 | 1.99953 | 2 | 0.02 % |
| step，ζ=0.05 | 1.85577 | 1+exp(−ζπ/√(1−ζ²)) = 1.85447 | 0.07 % |
| step，ζ=0.1 | 1.73142 | 1.72925 | 0.13 % |
| step，ζ=0.2 | 1.52864 | 1.52662 | 0.13 % |

0.13 % 是 Newmark 在 ζ 较大时的数值耗散，方向是**偏保守**（算出的位移略大）。

## 19.7 隔振：先看起点在哪

```
|T| = sqrt((1+(2ζr)²) / ((1−r²)²+(2ζr)²))
```

**隔振从 r = √2 才开始**。低于它，减振器把振动放大——这就是为什么要单独返回
`isolation_onset_hz`，而不是只给一条曲线。r=1 处 |T| ≈ Q。

高频渐近：因为分子的 (2ζr)² 项，|T| ~ 2ζ/r，**按 1/r 掉，不是 1/r²**
（1/r² 是相对位移传递率，两者不是同一个量）。

## 19.8 板级入口：`board_vibration`

输入是这块板自己的东西：板框 bbox 当板、`thickness_mm` 或 stackup 总厚当厚度、
元件坐标当探针点。输出是 f₁..fₙ，加上**每个位号在第一阶振型上的归一化挠度**，
按大小排序，`near_antinode` 是 |挠度| ≥ 0.5。

两处近似会明显偏向一侧，都在 `warnings` 里点名：

- **板框当矩形**：非矩形轮廓被 bbox 取代，bbox 更大更柔 ⇒ **f₁ 偏低**。
  `outline_fill_fraction_of_bbox` 给出轮廓占 bbox 的比例，1.0 表示正好是矩形。
- **不算元件质量**：重器件会往下拉频率、并移动振型 ⇒ **f₁ 偏高**。

## 19.9 不做的东西（逐条）

这一层是**薄板、单模态、线性**：

- 不算剪切变形与转动惯量（薄板极限 h/a ≪ 1；厚板或短悬臂会读得偏硬）；
- 不算元件附加质量、铜箔刚度、装配体模态；
- 不算安装本身的柔度（螺丝、机壳、垫片一律视为理想约束）；
- 不算焊点蠕变、BGA 焊球疲劳（只有 Steinberg 引线形式，斜率与允许值由你给）；
- 不算随机 + 冲击叠加、不算跌落、不算非线性接触/碰撞；
- **应力不是一个场**：§19.9 起 `vibration_plate_stress` 给出三个分开定位的极值（板角 von Mises、
  跨中主应力、板边最大剪应力）与 `sigma_max` 点的张量分量，但没有应力云图、没有孔边或加强筋的
  应力集中、也没有把这三个数再套疲劳律（Steinberg 的斜率与允许值仍由你给）。需要这些就去做有限元。

另外 FR-4 的材料预设有意做成四个：`fr4`（E=24 GPa）、`fr4_low`（18）、`fr4_high`（30）、
以及 `polyimide` / `al6061` / `steel` / `alumina`。用 `fr4` 时
`warnings` 会提醒 f ∝ √E 意味着 ±13 % 的频率范围——想收敛就把两端都跑一遍。

## 19.10 自检

`--selftest` 里有五条指纹（id 81–85），都是闭式解，不是代码自己的输出：

1. SSSS 方板 f₁₁ = 330.385 Hz；
2. CCCC 方板 f₁₁ = 602.382 Hz，且反节点在中心；
3. step 冲击 ζ=0.1 的 DLF = 1.72925；
4. 平坦 PSD 的数值积分与 Miles 闭式差 < 1 %（实测 0.045 %）；
5. 缺 `z_allow_mm` 时疲劳计算拒答。

`tests/test_vibration.py` 有 52 个用例，期望值全部来自闭式解、公开系数
（Leissa 13.489）或对手算的 fixture 算术——没有一个是从运行结果抄回来的。

## 19.9 从振型到应力：两个峰值，不是一个

振型本身没有幅值，所以应力必须由调用方给幅值（`amplitude_mm`，通常取 `miles_response` 的
`z_3sigma_mm`）。给了之后 Kirchhoff 理论直接从曲率给出表面应力（`z = h/2`）：

    sigma_x = -E z/(1-nu^2) (w_xx + nu w_yy)
    sigma_y = -E z/(1-nu^2) (w_yy + nu w_xx)
    tau_xy  = -E z/(1+nu)   w_xy

### 19.9.1 这里踩过一个真的坑：把两个问题当成一个点

第一版只扫一个点、按 `|von Mises|` 取最大，然后把**该点**的主应力当成 `sigma_max`。
在 100×80×1.6 的 SSSS 板上它报出 `sigma_max = 4.1195 MPa @ [100, 80]`——**板角**。
但板角的曲率是 1.6e-31 ≈ 0：那个 4.1195 全是 `tau_xy`（扭转）。

正确的事实是**精确正弦模态**（`w = A sin(pi x/a) sin(pi y/b)`）本来就有两个不同的极值点：

| | 板角 | 中心 |
|---|---|---|
| `w_xx`、`w_yy` | 0 | 最大 |
| `w_xy` | 最大（角点扭矩） | 0 |
| σx、σy | 0 | 6.524 / 4.638 MPa |
| τxy | 4.192 MPa | 0 |
| von Mises | **7.261** | 5.816 |
| 最大主应力 | 4.192 | **6.525** |

所以"最大 von Mises 在角上"是对的（Kirchhoff 板的经典角点扭矩），错的是**拿角上的张量去回答
"最大主应力"**——那样会把真正的峰值低估 37%。

修法：一次扫描同时记三个极值，各带各的坐标：

- `von_mises_mpa` / `von_mises_at_mm` —— 在哪扭转曲率最大
- `sigma_max_mpa` / `sigma_max_at_mm` —— 在哪弯曲曲率最大（这一份决定设计）
- `tau_xy_max_mpa` / `tau_xy_max_at_mm`
- `sigma_1/2`、`sigma_x/y`、`tau_xy`、`curvature_per_m` —— 全部取在 `sigma_max` 那个点上

四角通过对称性共值，所以"报了其中一条"这件事写在 `peak_locations_note` 里，不假装是唯一解。

### 19.9.2 误差棒是量出来的，不是引用的

二阶导的收敛慢于函数本身，所以"频率收敛了"不代表"曲率收敛了"。做法是**同一阶模态在几个
多项式阶上各解一次**，报出相邻两档的相对差（`degree_sensitivity_pct`），> 1 % 判未收敛。
实测（SSSS，100×80×1.6，amp 0.2 mm）：

| 阶 | `f` | `sigma_max` | `vm` |
|---|---|---|---|
| 5 | 677.588 | 6.45827 | 7.40294 |
| 7 | 677.29 | 6.63608 | 7.13363 |
| 9 | 677.29 | 6.63961 | 7.13518 |

频率 5→9 只走 0.04 %，`sigma_max` 走 2.8 %，`vm` 走 3.6 %——这正是"频率对了不代表曲率对"的实证。
与闭式解对账：曲率 `-0.197391 / -0.308423` 对 `-0.197392 / -0.308425`；`sigma_max` 6.63961 对
6.63964（ν=0.15 的预设，0.0005 %）；`tau_xy_max` 4.1195 对 4.1924（−1.7 %，扫描 21×21 的量化）。

### 19.9.3 点支承下"没有误差棒"比"误差棒很小"诚实

`max_dof=44` 让 `corners` 只能到 K=5，阶梯塌成一档 ⇒ `degree_sensitivity_pct=None`、
`converged=None`，并显式警告这是本模块里最不可信的数。另外 `poly_degree` 是**上限**而不是
替换：若它把阶梯压成一级，就同样丢掉误差棒，所以降级后仍补齐中间档。

## 19.10 应力层自检

`--selftest` id 110/111：`sigma_max` 必落在跨中 `[50,40]` 且对上正弦闭式（容差 0.05 MPa）、
von Mises 必落在角上且 ≈ `sqrt(3)*tau_角`、点支承板必须给 `converged=None`。
`tests/test_vibration_stress.py` 21 例：频率对 Navier 特征值（1 %）、中心曲率/应力对正弦（0.5 %）、
角上 `vm/sqrt(3)/|tau|` 恒等、应力随幅值线性、`amplitude > h/2` 警告、阶梯收敛与
"曲率比频率慢至少 4 倍"、四种拒答、6 条 not_computed 内容、以及工具面回环。
