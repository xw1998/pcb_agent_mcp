# 55 · 波导腔：从一个模，到一个模谱

0.0.51 的 `filter_waveguide_cavity` 只会答**一个**模：TE101。它的 `not_implemented_yet` 第 20
条自己写着「TE101 only: no higher-order modes, no mode chart, no surface-roughness
correction」。这三项都不需要外部数据、不需要全波——全由闭式给出，所以 0.0.52 把它们全部做掉。

一句话结论：**任意 TE_mnp / TM_mnp 的腔长、Qc 都有闭式解，但"我要的那个模"和"它旁边还坐着
谁"是两个不同的问题**——前者还多一个陷阱：`TM_mn0` 根本不决定腔长（它在任何长度上都谐振在
横向截止频率上），给个 d 就是编造。

## 55.1 模型

谐振条件与反解腔长：

    f_mnp = (c/2)·sqrt( (m/a)² + (n/b)² + (p/d)² )        c = c0/sqrt(er·mu_r)
    k0 = 2π f0/c      kc² = (mπ/a)² + (nπ/b)²      kz = sqrt(k0² − kc²)
    d = pπ / kz

模式合法性不是"看着像就行"，两条硬边界：

| 族 | 条件 | 不合法的原因 |
|---|---|---|
| TE_mnp | `(m,n) ≠ (0,0)` 且 `p ≥ 1` | `(0,0)` ⇒ kc = 0，横向场均匀，TE 模不存在；`p = 0` ⇒ `Hz ∝ sin(0) = 0`，不是模 |
| TM_mnp | `m ≥ 1` 且 `n ≥ 1` | 任一个为 0 则 `Ez = sin(mπx/a)·sin(nπy/b)` 恒为 0；`p = 0` **合法**（但见 55.6） |

壁损 Q 用峰值相量：

    Qc = ω·μ·∫|H|²dV / ( Rs·∮|H_tan|²dS )
    U = ½μ∫|H|²      Pc = ½Rs∮|H_tan|²

面积分全是 `∫sin² = ∫cos² = L/2`（**索引为 0 时例外**：`∫sin² = 0`、`∫cos² = L`），所以每
个模的 Qc 都是几项乘加，没有积分、也没有一张"标准公式表"可以照抄错索引。场分量（沿 z 为腔长 d）：

    TE:  Hz = cos(kx x)cos(ky y)sin(kz z)
         Hx = −(kz kx/kc²)·sin·cos·cos    Hy = −(kz ky/kc²)·cos·sin·cos
         Ex = −(ωμ ky/kc²)·cos·sin·sin    Ey = +(ωμ kx/kc²)·sin·cos·sin
    TM:  Ez = sin(kx x)sin(ky y)cos(kz z)
         Ex = −(kz kx/kc²)·cos·sin·sin    Ey = −(kz ky/kc²)·sin·cos·sin
         Hx = +(ωε ky/kc²)·sin·cos·cos    Hy = −(ωε kx/kc²)·cos·sin·cos

R/Q 仍然只给 TE101（`4b/(ωε·a·d)`）：R/Q 是"沿耦合路径的 E 积分"，探针和环耦合的路径不同，
别的模给一个数就是编造。这条写进 `not_computed`，并且**按模式名点名**。

## 55.2 三道闸门，都配了会失败的对照

1. **闭式 vs 网格积分**：`_cavity_q_closed` 与 `_cavity_q_numeric` 共享零行代数（一个乘
   `∫sin²`，一个逐点写场分量再求和），两者差超过 2 % 就不给答案。实测每个模的差都是
   `0.000000 %`——不是"运气好"，而是中点法对 `sin²(kx·(i+½)Δ)` 这类和**恰好精确**，所以这个
   闸门真正能抓的是代数错，不是求积误差。
2. **能量平衡 `u_e/u_m = 1`**：这**就是**本轮差点漏过去的那道门。返回值必须是 `u_e/u_m`，
   **不能**是 `u_e/(u_e+u_m)`——后者对任何平衡的模都恒等于 0.5，而代码一开始拿它和 1.0 比，
   于是除 TE101 之外**每个模都被拒**（`U_e/U = 0.500000000`）。判据写错的样子，就是"工具很
   严格但永远说不行"。测试 `test_the_returned_ratio_cannot_be_ue_over_total` 把这件事算术
   钉住：`ratio/(1+ratio) = 0.5`。
3. **默认路径逐位不变**：不给 `mode` / `roughness_um` / `modes_upto_hz` 时，TE101 走 0.0.51
   原来的 bracket 公式 + 原数值积分（不换实现），并用旧树逐字段 diff 自证（§55.4）。

闸门各自的**负控制**（证明它们真能失败，实测幅度）：

| 故意犯的错 | Qc 变化 | 会不会被 2 % 闸门抓住 |
|---|---|---|
| 只数 z=0 一面墙，丢掉 z=d | 7848.4 → 9216.2（**+17.43 %**） | 会 |
| x 墙上把法向 `hx²` 当切向、丢掉 `hy²` | 10966.6 → 12076.4（**+10.12 %**） | 会 |
| E 场整体乘 1.2（能量比变成 1.44） | `u_e/u_m = 1.44` | 会（第 2 道门） |

顺带说明第二个控制为什么不能**用**「H·n = 0」去做：PEC 壁上法向磁场恒为 0，所以
`|H|² − (H·n)²` 精确等于 `|H|²`——这条式子并不能被那样破坏。它的价值在别处：它**从不点名
切向分量**，所以闭式里切向集写错时，两边会**不一致**而不是一起错。

## 55.3 真值

WR-90（a = 22.86 mm，b = 10.16 mm），铜 `5.8e7`：

| 量 | 值 | 来源 |
|---|---|---|
| TE101 @ 10 GHz 腔长 | **19.8536 mm** | `d = pπ/kz` |
| TE101 @ 10 GHz Qc | **7821.5** | bracket 公式（0.0.51 的答案，未变） |
| 通用闭式在同一模上 | **7821.5**（差 ≤ 0.11，即报告的圈整） | 模谱里的 `TE_1_0_1` 行 |
| TE101 @ 10 GHz R/Q | **160.9572 Ω** | `4b/(ωε·a·d)` |
| TE011 @ 16.573220 GHz 腔长 | **19.8536 mm** | 与 TE101 巧合相等（kx = 0 时 kc 一样） |
| TE011 @ 16.573220 GHz Qc | **8828.7** | 同频 TE101 是 6873.4 ⇒ **1.2845 倍** |
| 介质腔（er 2.2、mu_r 1.2、30×15 mm、12 GHz） | d = **7.9535 mm**，Qc = **5934.2**，两法差 **0.0 %** | 0.0.51 在这里**直接拒答**（见 55.7） |

TE011 比同频 TE101 高 28 % 不是巧合，是它被选作高 Q 腔的原因（壁电流分得更开）；测试只断言
"排序成立且 > 1.15 倍"，不去钉这个比值——它对 a、b 敏感。

模谱（`modes_upto_hz = 20 GHz`，上表那台 WR-90 腔，光滑铜）：**9 个模**

| 模 | f | f/f0 | Qc | 退化数 |
|---|---|---|---|---|
| **TE_1_0_1** | 10.0000 GHz | 1.0000 | 7821.5 | 1（工作模） |
| TE_2_0_1 | 15.1324 | 1.5132 | 9837.8 | 1 |
| TM_1_1_0 | 16.1451 | 1.6145 | 8389.5 | 1 |
| TE_1_0_2 | 16.4624 | 1.6462 | 9852.4 | 1 |
| TE_0_1_1 | 16.5732 | 1.6573 | 8828.7 | 1 |
| TE_1_1_1 | 17.8232 | 1.7823 | 7473.0 | 2 |
| TM_1_1_1 | 17.8232 | 1.7823 | 7226.5 | 2 |
| TM_2_1_0 | 19.7396 | 1.9740 | 10686.1 | 1 |
| TE_2_0_2 | 20.0000 | 2.0000 | 11061.2 | 1 |

`next_mode = TE_2_0_1`，即**离工作模最近的那个寄生模只高 51 %**。方腔（a = b = 20 mm）上
`TE_1_0_1` 与 `TE_0_1_1` 在 10.0000 GHz 同时出现、退化数都是 2——这是"退化"这个字段唯一
能自证的时刻，测试就断言它。

**模谱每行的 Rs 用该模自己的频率**（`Rs ∝ √f`）。这里踩过一次：第一版把 f0 的 `rs_used`
传进每一行，`ω` 却用该模的 f，于是 15.13 GHz 那行 `Qc` 比真值高 23 %（`√1.5132`）。抓它的
是"模谱里的某一模 vs 直接问那一模"这条一致性测试——同一个量从两个入口进来，必须同值。

## 55.4 默认路径逐位不变的自证

用 `git archive HEAD`（0.0.51 的树）与当前树各跑 4 组参数（含 `b_mm` 省略、`er/mu_r`、非铜
电导率），逐字段 diff。**所有数字都没有变**；变的只有文本，逐条登记：

1. `value.mode`：`"TE101"` → **`"TE_1_0_1"`**（唯一一处可见的值变化；理由是模式名要能说
   `TE_2_0_1` 这种索引 ≥ 10 的模，两种拼法见 55.6）；
2. `not_computed` 里两条措辞（"surface roughness correction to Qc" → "…(pass
   roughness_um)"；"higher-order modes and mode charts: TE101 only" → "the mode chart (pass
   modes_upto_hz)…"），条目数与顺序不变；
3. `model` / `basis` / `precision` / `assumptions` 的措辞（多提了 `mu_r`、把 "five wall
   pairs" 改成 "every wall"）；
4. 报错文案 `wall-integral Qc` → `field-integral Qc`（**错误码与两个数字都不变**）。

## 55.5 粗糙度接到腔上

`roughness_um` 直接复用 0.0.51 的 `roughness_factor`：`Rs *= K` ⇒ `Qc /= K`（**不是 K²**，
理由见 54 篇）。WR-90 TE101 @ 10 GHz 的实测：

| Rq (µm) | K | Qc |
|---|---|---|
| 0 | 1.000000 | 7821.5 |
| 0.5 | 1.430101 | 5469.2 |
| 2.0 | **1.950452** | **4010.1** |
| 5.0 | 1.992057 | 3926.3 |
| 20.0 | 1.999504 | 3911.7 |

两条自证：`q_conductor × K` 必须回到光滑值 7821.5；`roughness.q_conductor_smooth` 必须**等于**
不给粗糙度时那次调用的 `q_conductor`（不是"接近"）。后者是本轮抓到的一个真错——`q_closed`
已经是除过 K 的值，代码又除了一次 K，于是"平滑值"报成 2056.0（真实 7821.5）。**除以 K 两次
的读数在任何工艺下都不存在**，但看上去像个合理的低 Q。

模谱里的每一行也按它**自己的**频率算 δs 与 K（K 随 δs 变，δs 随 f 变），不是全表共用一个 K。

## 55.6 拒答，以及两种拼法

| 输入 | 结果 | 报什么 |
|---|---|---|
| `TM110`（p = 0） | `OUT_OF_VALIDITY` | 它在**任何**长度上都谐振在 1.61451e10 Hz，给 d 就是编造 |
| `TE100` | `ARG_INVALID` | `p ≥ 1`（`sin(0) = 0`） |
| `TE000` | `ARG_INVALID` | kc = 0，没有这个 TE 模 |
| `TM011` / `TM001` / `TM_1_0_1` | `ARG_INVALID` | `m ≥ 1 且 n ≥ 1` |
| 5 GHz（低于 TE10 截止） | `OUT_OF_VALIDITY` | 截止 6.55714e9 Hz，腔长会是虚数 |
| `TE_10_0_1` @ 60 GHz | `OUT_OF_VALIDITY` | 截止 6.55714e10 Hz（同一句，点名 `TE_10_0`） |
| `XYZ101` / `TE_1_1` / `TE_1_x_1` | `ARG_INVALID` | 拼法读不出来 |
| `roughness_um < 0` | `ARG_RANGE` | 粗糙度不能为负，且 **Rz 不换算** |
| `modes_upto_hz` 要求 11454 个模 | `ARG_RANGE` | 上限 200，报出实际个数 |
| `er < 1` | `ARG_RANGE` | 真空是下限 |

**为什么允许两种拼法**：三位单数字 `TE101` 是所有人写的方式，但对索引 ≥ 10 就有歧义
（`TE201` 是 (2,0,1) 还是 (20,1)？）。猜错会**静默答另一个模**——所以第三种情况一律要求下划
线整数 `TE_2_0_1`，而三位数字只按单数字解释。`TE_10_0_1` 只能靠下划线拼出来，测试里它必须
真的答出来（而不是被读成 `1001`）。

方腔上退化数怎么算：图表里任何两行的 `f` 相对差 ≤ 1e-9 就算同一频率，`degeneracy` 是那一组
的行数。这不是"物理上的退化判定"，是"在这个腔里谁和谁撞了"。

## 55.7 本版修掉的一处 0.0.51 缺陷（**会改变答案，明示**）

0.0.51 的 `filter_waveguide_cavity` 在 `er ≠ 1` 或 `mu_r ≠ 1` 时**直接拒答**
`INTERNAL_CHECK_FAILED`（"closed-form Qc 4267.9 与 wall-integral Qc 1347.2 差 −68.43 %"）。
原因不是公式错，而是**数值积分里用的是真空 ε、μ**，闭式用的是介质——两边本来就在算两件
事。现在数值积分按 `EPS0·er` / `MU0·mu_r` 走，同一个输入答 **d = 7.9535 mm、Qc = 5934.2、
两法差 0.0 %**。

这条**不改变任何既有答案**（默认 `er = mu_r = 1`，真空下两个 ε、μ 就是 `EPS0`、`MU0`，
逐位相同），但它把一类"本该能答"的输入从拒答变成回答，所以在 CHANGELOG 里单独列出。

## 55.8 边界：这里仍然没有的东西

- **虹膜 / 耦合窗 / 探针 / 环的几何**：这是全波问题，`not_computed` 第一条。腔滤波器 = 这个
  谐振腔 + N−1 个虹膜，**虹膜恰恰是不在的部分**。
- **辐射 Q、介质 Q**：只算壁损；`Q_unloaded` 就是 `Qc`，字段名不改口。
- **R/Q 只给 TE101**（理由见 55.1）。要做别的模的 R/Q，得先定义耦合路径（探针在轴上？在壁
  上？），那是接口问题不是场问题。
- **开边失谐、调谐螺钉、温度漂移**（后者要膨胀系数）、**表面不是单一 Rq 的表面模型**
  （Huray 结节、箔 profile、各向异性）。
- **模谱只做枚举**：每一行是闭式 Qc，网格交叉验证只跑"你要的那个模"，不是 200 个都跑一遍。

## 55.9 本版修掉的第三处（自述，不是物理）

`model` 那句话曾无条件写 "resonance, wall-loss Qc, R/Q"，而 `r_over_q_ohm` 只对 TE101 有值、
其余模是 `null`；`", mode chart"` 的后缀又挂反了条件（`r_over_q` 存在时才加，与模谱无关）。
结果是一个空字段旁边写着它的名字、而真的给了模谱的调用反而不说。现在两个后缀各有独立的
条件，测试 `TestTheSelfDescription` 两条分别钉住「报了才写」与「给了才写」。

## 55.10 这一段落的落点

- `calc/filters.py`：`waveguide_cavity(..., mode, roughness_um, modes_upto_hz)` +
  `_parse_cavity_mode` / `_cavity_mode_name` / `_cavity_mode_reason` / `_sin2` / `_cos2` /
  `_cavity_q_closed` / `_cavity_q_numeric` / `_cavity_mode_chart`；TE101 默认路径仍走原来的
  `_te101_fields` + `_te101_q_numeric`（后者加了 `eps`/`mu` 参数）。
- `tools.py`：一个工具、三个新参数（**工具数仍是 162**，加参数不加工具）；`_capabilities`
  第 20 条从"TE101 only"改写成现在的能力与仍缺的部分。
- `tests/test_waveguide_modes.py`：**29 例**，含独立实现的壁损积分（`|H|²−(H·n)²`）、两条
  "故意写错必须被抓住"的负控制、能量比那道门的算术自证，以及两条**自述一致性**（`model`
  只在真的报了 R/Q / 真的给了模谱时才那么写）。
- `server.py`：5 条自检（1609~1612），钉住「通用闭式复现 bracket」「每个模能量平衡」
  「模谱 9 模 + next + 退化 2」「粗糙度只除一次 K」「介质腔不再拒答」。`--selftest` 178 → **183**。
