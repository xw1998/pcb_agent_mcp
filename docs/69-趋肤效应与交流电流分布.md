# 铜不会一直是那个铜：趋肤效应的 1-D 精确解，和它明说的边界

日期：2026-11-01　工具：`ac_sheet_resistance(...)`（`calc/skin.py` 新增，纯 stdlib）；
`current_density_field` 新增 `frequency_hz` / `skin_faces`（默认关，逐位不变）

到 0.0.65 为止，这个仓库里所有关于铜的电阻答案都带着同一个隐含前提：**直流**。
`board_ir_drop` 的假设里明写 "no skin effect"，`copper_resistance` 只认 ρ、L、W、t，
`current_density_field` 解的是 1 S/单元 的实电导场。

1 oz 铜（35 µm）的 `R(f)` 偏离 DC **1 % 的频率是 1.198 MHz**。也就是说：一块再普通
不过的数字板，只要时钟边沿有 30 ns 量级的上冲，20 mm 的电源路径上就已经不是 DC 那个数了。
**DC 答案在 1 MHz 就开始错**，而且它不是"稍微错"，10 MHz 时是 54 %。

所以这轮补的不是一个"可选精度"，是这个模型族缺的一整条边。

---

## 1 判据

**一个闭式解，必须在三个极限上同时成立，并且在第 5 节里被一个完全独立的数值解复现。**

三个极限这样选，是因为它们各自能让一件事失败：

| 极限 | 期望 | 打错哪里会失败 |
|---|---|---|
| `s→0` | `R/Rdc → 1 + 4s⁴/45`，`X/Rdc → 2s²/3` | 小 s 的展开系数（本轮就是这里错了，见 §7） |
| `s→∞` | `R = X = s`（表面阻抗 45°） | 渐近分支、`√f` 的系数 |
| `s=1` | `R = 1.0856357047503276`，`X = 0.6503925810415222` | 整条曲线的中段，任何一项漏掉都过不了 |

第三个锚是本机实测后钉死的常数，没有"推导出来应该是多少"的余地。

`X` 不是附带报的。它有一个**完全独立的物理锚**：小 s 时板内感抗
`X → ωμ₀t/3`，这是薄板的经典内感，与电阻那一支的推导毫无关系
（测试 `test_the_reactance_is_the_dc_internal_inductance` 直接验 `X·Rdc == 2πf·μ₀t/3`）。

---

## 2 模型：只解厚度方向

薄板内（横向尺寸远大于 δ），场沿厚度 1-D 扩散，`e^{+jωt}`：

```
d²E/dz² = j·ω·μ·σ·E
```

两族边界条件，用同一个参数描述：

| `faces` | 边界 | 参数 | 阻抗 |
|---|---|---|---|
| `"one"` | 背面 H=0（微带、覆铜对着回流面） | `s = t/δ` | `Z/Rdc = (1+j)s·coth(s(1+j))` |
| `"two"` | 上下对称（带状线、夹在两回流之间的平面） | `s' = t/(2δ)` | `Z/Rdc = (1−j)s'·coth(s'(1+j))` |

统一成一个**实函数**（`s` 按 `faces` 折算后的有效值）：

```
R_ac/R_dc = s·(sinh 2s + sin 2s) / (cosh 2s − cos 2s)
X_ac/R_dc = s·(sinh 2s − sin 2s) / (cosh 2s − cos 2s)
```

`faces="two"` 与 `faces="one"` 在**半厚度**上是同一个问题——这一点不是"顺手对齐"，
是判据：自检里直接断言 `two@35 µm` 与 `one@17.5 µm` 的 `R/Rdc` 与 `X/Rdc`
逐位相等（差 < 1e-12）。如果差的因子被塞在结果里而不是几何里，这条立刻失败。

`faces` **不是外观选项，所以非法值直接拒**：静默默认成 `"one"` 会让一条
本该算对称的带状线凭空多一倍损耗。

## 3 数值稳定性：半角恒等式

第一版照抄公式：

```python
R = s * (cmath.sinh(2*s) + cmath.sin(2*s)).real / (cmath.cosh(2*s) - cmath.cos(2*s)).real
```

在 `s = 0.01` 时，`cosh(2s) − cos(2s) ≈ 4e-4`，而两项各自都是 1 量级：**丢 8 位有效数字**。
后果是把 `R − 1 = 1.3e-9` 算成 `3e-5`，相对误差 4 个数量级。

改成半角恒等式，相消被提前消掉：

```
sinh 2s + sin 2s  = 2 (sinh s cosh s + sin s cos s)
sinh 2s − sin 2s  = 2 (sinh s cosh s − sin s cos s)
cosh 2s − cos 2s  = 2 (sinh²s + sin²s)      ← 两个平方和，恒正，不会相消
```

于是

```
R = s (sh·ch + sn·cs) / (sh² + sn²)
X = s (sh·ch − sn·cs) / (sh² + sn²)
```

分母是平方和，`s→0` 时精确到机器精度。

大 s 走渐近分支：`s ≥ 20` 直接返回 `(s, s)`，残差 `2e^{-2s} < 1e-16`，同时避开
`sinh` 在 `s ≈ 354` 的溢出点。这个分支是必需的：400 µm 铜在 100 MHz 时 `s = 60.5`，
不分支就会抛 `OverflowError`。

> 顺带一个单位坑：`s = t/(k·δ)` 里 `t` 是 mm、`δ` 是 **m**。第一版漏了 `1e-3`，
> `s` 大 1000 倍，症状是上面那个溢出——但溢出只是症状，真错的是单位。

## 4 独立对表：有限差分

闭式解自己验自己是不算数的。所以另写一个**完全独立**的数值解：对同一个方程在
`n` 个节点上做复系数三对角差分（Thomas 算法，背面 Neumann ghost、正面 Dirichlet），
`Z = 1/mean(E)`。

实测（`_scratch/skin_fd.py`）：

| n | 与闭式的相对差 |
|---|---|
| 501 | 0.2004 % |
| 1001 | 0.1001 % |
| 2001 | 0.0500 % |
| 4001 | 0.0250 % |
| 8001 | 0.0125 % |

误差**精确减半**（`e2 ∈ (0.4, 0.6)` 的断言写进测试），即 O(dz²)；Richardson 外推
后正好落在闭式上。这证明闭式不是某个离散化的产物，也证明 FD 那边没有把边界条件
写反（写反的话误差不会按这个阶数收敛）。

FD 脚本第一版还栽了一次：`c[N-2] = 0` 但忘了把已知值搬进右端项，解全零，
`Z = n = 2001`——一个"看起来像数"的答案。这正是为什么"独立实现"也必须先有量纲/极限检查。

## 5 三个里程碑频率，以及一个反直觉

`f_at_r_1pct / 10pct / 2x` 用**对数二分**求，不解析反解：one/two 两族共用一条路径，
也不会把阈值公式抄错。1 oz 铜（ρ = 1.724e-5 Ω·mm）：

| 量 | 值 |
|---|---|
| `f_1%`（R 高出 DC 1 %） | 1 198 257 Hz |
| `f_10%` | 3 864 536 Hz |
| `f_2x`（R 翻倍） | 15 535 544 Hz |

1 oz 铜的完整剖面：

| f | δ | s | R/Rdc | X/Rdc |
|---|---|---|---|---|
| 1 kHz | 2089.72 µm | 0.0167 | 1.0000 | 0.0002 |
| 100 kHz | 208.97 µm | 0.1675 | 1.0001 | 0.0187 |
| 1 MHz | 66.08 µm | 0.5296 | **1.00697** | 0.1866 |
| 10 MHz | 20.90 µm | 1.6749 | **1.54080** | 1.5862 |
| 100 MHz | 6.61 µm | 5.2964 | 5.2960 | 5.2965 |
| 1 GHz | 2.09 µm | 16.7486 | 16.7486 | 16.7486 |

注意 10 MHz 那一行：`R` 和 `X` 已经几乎相等（1.5408 vs 1.5862），提示进入
表面阻抗区；但 `R/Rdc = 1.54` **不是** `√10 = 3.16`——因为 10 MHz 时 `s = 1.67`，
还在过渡区，`√f` 律要 `s ≳ 3` 才成立。

**反直觉的那一条**：`f_1%` 与 `f_2x` 随厚度 **∝ 1/t²**。2 oz（70 µm）铜的
`f_1%` 是 **299 564 Hz**——是 1 oz 的**四分之一**。"越厚越晚进入趋肤"是错的：
`δ` 与厚度无关，`s = t/δ`，厚一倍则 s 大一倍，更早到 `s=1`。

同时，**同一频率下越厚 `R_ac/R_dc` 越大**（70 µm @ 1 MHz = 1.1068 对 35 µm = 1.0070），
因为 `R_ac` 饱和在 `ρ/(wδ)` 而 `R_dc` 还在随 t 下降。

这两句看似矛盾，其实是两个不同的比较。**唯一"厚铜有利"的量是绝对 `R_ac`**，
不是比值。测试里把这两句分开断言，就是为了不让哪一句被读成另一句。

## 6 `t_eff`：AC 下 `J` 到底是什么

求解器的电导改用 `G = t_eff/ρ`，所以它输出的 `J` 是**有效层内的密度**，
即表面值——不是毛厚度的平均值。

`current_density_field` 因此多报两个键：

- `peak_j_surface_a_per_mm2`：峰值电流密度（表面值，= 原 `peak_j_a_per_mm2`）；
- `peak_j_gross_a_per_mm2`：毛厚度平均 = `peak_j_surface / (R_ac/R_dc)`。DC 时两者相等。

20 × 2 mm 带、h = 0.1：

| | DC | 10 MHz |
|---|---|---|
| `resistance_ohm` | 0.004901063207153133 | 0.007551558690619792（= ×1.5408001） |
| `peak_j_a_per_mm2` | 14.285717452599883 | 22.011434911397746（= ×1.5408001） |
| `peak_j_gross_a_per_mm2` | 14.2857 | 14.2857 |
| `crowding_factor` | 1.0000002217 | 1.0000002217（**不变**） |

`crowding_factor` 必须不变：它是纯几何量。实现上 `_narrowest_section` 改传 `t_eff`
而不是 `t`，使 `j_uniform = cur/(w·t_eff)` 与 peak 同口径；DC 路径 `t_eff == t`，
所以逐位不变。

## 7 那个被 check 抓出来的系数

`R − 1 = 4s⁴/45`。第一版 docstring、`checks`、测试注释里全都写的是 **2/15**。

用 60 位 `Decimal` 直接算 `(R−1)/s⁴` 的极限：

```
0.088888888855...
```

= **4/45**，不是 2/15 = 0.1333。来源是 `u coth u = 1 + u²/3 − u⁴/45 + …`。

这个错误值得单独写一节，因为它恰好说明"自检要能失败"是什么：`checks` 里那条
`series_r_abs_error`（对 `1+4s⁴/45` 的残差）在系数写错时**直接报错**，
而不是"看起来收敛得挺好的"。如果当初只报了 `R` 而不报"R 相对小 s 展开的残差"，
这个错会一直躺在 docstring 里，而且不会有任何数字显得奇怪——因为 `4s⁴/45` 在
`s = 0.1` 时才 8.9e-6，肉眼看不出来。

## 8 两个常被混淆的数：0.8589 与 0.632

"一个趋肤深度内占多少电流"，常见答案是 0.632。那是 **密度比** `|J(δ)|/|J(0)| = 1 − e⁻¹`。

真正的**电流**占比要对密度积分：

```
|1 − e^{-(1+j)}| = 0.8589
```

工具返回的是 **0.8589**（`one_skin_depth_current_fraction`），文档与 `profile_note`
里把两者写清。100 MHz / 400 µm 铜实测 `s = 60.53`、`frac_delta = 0.8589546`。

这不是"两个差不多"，差 36 %，足以让"δ 内有一半电流"这类结论错方向。

## 9 明说没做什么

`extra.limits.not_modelled` 里是六条，逐条都是"这一层的物理不在这个解里"：

1. **横向重分布**：真实薄片的电流会在平面内向边缘/窄处重新分布，这会改变损耗
   分布；1-D 解只给"每个面元都一样"的表面阻抗。
2. **边沿拥挤**：走线边缘的电流峰值（edge singularity）不在这里。
3. **邻近效应**：相邻导体（回流面、相邻走线）的涡流会改变等效电阻，1-D 单导体解
   看不见。这是 10 MHz 以上最主要的误差来源之一。
4. **涡流**：厚度方向的涡流包含在内（这就是 1-D 解），但平面内的涡流环路不在。
5. **过孔场**：孔壁的电流分布是另一个问题。
6. **位移电流**：介质的 `jωε` 项被忽略（铜的 `σ/ωε` 在 10 GHz 仍 >> 1，所以这条
   在铜里是安全假设，但不适用于极薄/高频极限）。

**粗糙度**只作 Hammerstad 乘子（复用 `calc/roughness.py` 的 `roughness_factor`），
默认**关**。不给 `Rq` 时，`δ < 3 µm` 的情形会明确 warning：这是**下界**。
实测锚：`Rq = 1 µm @ 10 MHz → K = 1.00204`；`Rq = δ @ 1 GHz → K = 1.60514`。

**升温**不在电阻的迭代里：100 °C 时 `dc_sheet` 从 `4.9257e-4` 涨到 `8.7122e-4`
（ρ 变大），而 `R/Rdc` 反而从 1.5408 变到 1.3456（ρ 变大则 δ 变大、s 变小）。
要算自热请把 `ac_sheet_resistance` 的输出喂给 `electrothermal_conductor`——
它接受冷阻而不从几何反推。

## 10 口径与成本

- **默认关时逐位不变**：`current_density_field` 不传 `frequency_hz` 时，只多两句
  `t_eff = t` 与 `G = t_eff/ρ`（浮点完全相同）。测试断言 DC 输出**逐位相等**，
  且信封里没有 `frequency_hz` 键。
- **给频率时改写的 assumptions**：`current_source` 变成"横向图案仍是 DC 的"，
  并追加一条 warning 说明 §9 第 1–3 条。
- **工具数棘轮 170 → 171**。这是新工具而不是给 `board_ir_drop` 加开关：
  1-D 表面阻抗需要 `faces` 与 `δ`，与"给定几何求压降"不是同一张输入表。
- 成本：单次 `ac_sheet_resistance` 实测 **0.264 ms**（50 次平均；含 3 次对数二分的
  里程碑频率，每次约 60 次闭式调用）。`current_density_field` 给频率只多一次闭式求值，
  求解本身 1.66 s @ levels=2 不变——缩放的是电导，不是网格。

---

## 11 结论

**`R_ac/R_dc` 是可以闭式算准的，`J(z)` 是可以 1-D 算准的，横向的电流重分布不算。**

这三句要一起说。只报第一句，就会有人在 10 MHz 上把 1.54 倍当成"整个平面的损耗倍数"，
而真实平面会把电流摊开、边沿会拥挤、邻近的平面会反推涡流——那些是复电导 2-D 场解
的事，本轮没做，`limits.not_modelled` 里写清了。

**DC 铜的答案在 1 MHz 就开始错 1 %，在 10 MHz 错 54 %。** 这句话是本轮唯一想让人记住的。
