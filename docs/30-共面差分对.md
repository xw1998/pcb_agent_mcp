# 30 共面差分对：没有闭式可比的时候，判据要换成什么

> 这一篇回答两个问题：**边耦合共面线（差分 CPW / GCPW）的阻抗和差分损耗能不能解出来**，
> 以及 **在完全没有闭式可以对照的情况下，凭什么相信它**。
>
> 它是 [29 共面波导场解](29-共面波导场解.md) 的延长线：29 里共面**单线**至少还能和
> `feedline._cpw` 的闭式对账（−1.19% … −3.39%），
> 这一篇的截面**一个能比的闭式都没有**——共面差分对的准静态解在文献里是级数/保角混合的形式，
> 本仓库没有可引用的实现，也不打算凭记忆抄一个。
>
> 所以 30 的全部内容其实是：**把「对账」换成「自洽 + 极限 + 精确不变量」三类判据，
> 并且每条判据都配一个能失败的对照。**

代码：`src/pcb_agent_mcp/calc/field2d.py`（`_CoplanarPair` / `coplanar_pair_solve` /
`coplanar_pair_mode_check` / `coplanar_pair_shape_factor` / `coplanar_pair_field`）
测试：`tests/test_coplanar_pair.py`（15 例，含两个「故意写错的子类」当负控制）
工具：`coplanar_pair_field`（新增，第 151 个）

## 30.1 为什么这一批没有闭式可比，以及为什么这不是偷懒

先把话说死：**这一批不提供 Zdiff 的「准确度 ±x%」这句话。**
原因不是没查，而是这类几何的独立参照物在这个仓库里不存在：

| 想用的参照 | 为什么用不了 |
|---|---|
| `feedline._cpw`（单线闭式） | 只有一根条、一对地。差分对是两根条、中间多一个槽口，槽口那一项它没有 |
| 微带边耦合对的闭式（Hammerstad 类） | 那是「上面两条条、下面整块地」，回流路径完全不同；共面线的回流在**同一层** |
| 文献里的 CPW 差分闭式 | 要么是零厚度 + 无限衬底 + 保角映射的特定参数区，要么是级数截断且没有公开实现；凭记忆转写＝编造 |

所以判据改成三类，且每一类都不依赖「有人给过一个数」：

1. **自洽（线性叠加恒等式）**——三个驱动必须满足一个代数关系，且误差只受 SOR 容差限制；
2. **极限**——间距 → 0 时必须落到一个**已经过闭式验证**的解上（2w 单线，见 29）；
3. **精确不变量**——网格关于 `x = 0` 镜像，所以奇模解必须严格反对称、左右回流份额必须逐位相等。

顺手说一下：**判据方向比误差大小重要**。下面 §30.4 会看到两个极限往**相反方向**拉，
所以任何一个「读数随参数单调」的判据在这里都是错的。

## 30.2 两个模式＝两个驱动，不是两个对称面

微带/带状线那一对（0.0.x 里的 `_SectionPair`）用**半个域**求解，在 `x = 0` 放奇模电壁 / 偶模磁壁。
共面**对**这一批没有这么做，理由和 29 §29.2① 是同一条，但更强：

- 半域的电壁/磁壁是**求解器的假设**，同时也是**所有极限校验的假设**
  （间距 → ∞ 时「对的半边」就是「单线」，这个等价关系本身就建立在「墙是电壁」上）；
- 一旦墙是假设，它就不能再被任何检查发现——而这一批恰恰没有外部参照物来发现它，
  只有内部不变量可以。**所以墙必须是从解里读出来的，不是放进去的。**

做法：网格**镜像穿过 `x = 0`**（`self.xs = [-v for v in reversed(half_x[1:])] + half_x`，
不是拼两段），然后

| 模式 | 驱动（右条 / 左条） | 应满足 |
|---|---|---|
| odd | +1 V / −1 V | 解严格反对称；`charge_balance = −1.000000000` |
| even | +1 V / +1 V | 解严格对称；`charge_balance = +1.000000000` |
| grounded（只在自检里） | +1 V / 0 V | 作为第三个驱动喂叠加恒等式，**不进工具** |

`charge()` 只对 `self.live`（右条）求和，所以左条被当成一类「电位为 −1 V 的固定节点」，
和地节点同一套机制——两条条永远不相邻，没有导体-导体面，通量就是电荷。

代价：节点数是半域的两倍。这一批的节点量级是 3.3k / 5.6k（两级网格），
一次 `levels=2` 的完整求解 **37.8 s**，不是毫秒级。工具默认 `levels=2`，也就是说
**这个工具一次调用就是近 40 秒**，`levels=1` 是 8 秒左右。

### 30.2.1 踩到的坑：左条被 SOR 悄悄「松弛掉」

第一版写完，`z_odd` 与 `z_even` **完全相同**（都是 108.944 Ω），`charge_balance` 恒 0。
原因是 `_Section.build` 只把 `self.live` 与 `self.ground` 当成固定节点，
`live_left` 落在 `_rows`（未知集）里，于是每一轮 SOR 都把它当**空介质**重算一遍：
实测左条节点电位停在 **0.272 V**，不是 −1 V，而且和驱动符号无关。

修法：`_Section.build` 之后手动把左条从未知集里摘出去

```python
left = set(self.live_left)
self._rows = [row for row in self._rows if row[0] not in left]
self._free = [n for n in self._free if n not in left]
self._fixed[n] = val          # odd: -1.0, even: +1.0, grounded: 0.0
```

修后 `z_odd 64.930 / z_even 146.202`、`charge_balance −1.000000000`。
这段注释留在代码里，因为**这个 bug 不会报错，只会给出一个看起来很正常的数**。

### 30.2.2 盒尺寸：从地外沿量，不跟间距走

29 里单线的盒是 `8·(w + 2g)`。差分对如果照「按整个 footprint 缩放」写（`s + w + 2g`），
**唯一可检的极限会被盒子破坏**：

```
s = 1.5 mm 时, 盒 ∝ footprint: z_odd = 104.0 Ω
同一根条单独解(同网格约束):        89.7 Ω
```

差的 14 Ω 是**边界距离**，不是物理。修法：截断距离只从**地的外沿**和两条条本身量起，
`s` 不参与：`span = w + 2g`，`far = max(8·span, 1.2·span)`。
这条实测依据写在 `__init__` 的注释里。

## 30.3 四条自检，逐条给数

### 30.3.1 叠加恒等式：`(C_odd + C_even)/2 == C_grounded`

驱动力是线性的，所以同一个截面的三个解必须满足上面这条恒等式，误差只受 SOR 容差限制
（1e-8）。这是**唯一**一条带「对账」性质的检查，而且它检查的是**驱动**，不是几何。

`cpw w=0.3 / s=0.2 / g=0.2 / h=0.2 / er=4.3`，`fine_div=10`，12.1 s：

| 驱动 | `c_dielectric`（C/ε₀） | `c_air` |
|---|---|---|
| odd（+1/−1） | 8.997022 | 3.741710 |
| grounded（+1/0） | 6.347287 | 2.768722 |
| even（+1/+1） | 3.697552 | 1.795734 |

- `mean_over_grounded`（介质）= **1.0000000192**，残差 **1.92e-08**
- `mean_over_grounded`（空气）= **1.0000000578**，残差 **5.78e-08**

残差不是机器精度，是三次独立 SOR 各自的 1e-8 容差叠出来的；写错驱动时残差是 O(1)。

### 30.3.2 奇模解必须严格反对称

网格镜像穿过 `x = 0`，所以 +1/−1 的驱动下左右两条的电荷必须**逐位相等、符号相反**：
`charge_balance_odd = −1.000000000`（9 位）、`charge_balance_even = +1.000000000`。

这条是**精确不变量**，不是「大致对」——它同时管住了两件事：网格没有偏、
求解器没有把某一条当成另一条。

### 30.3.3 形状因子的左右对称

`∫g²ds` 按**差分电流**归一化（`q_ref` = 正条总电荷）后，
左右两条的份额必须逐位相等（`places=12`），左右两块地的份额也必须逐位相等，
左右两翼以外的背面地为 0（cpw）/ 不为 0（gcpw）。

### 30.3.4 两个极限，方向相反（**最容易被写错的地方**）

间距 → 0，`s = w/6 = 0.05`：

| 量 | 实测 | 对照 | 差 |
|---|---|---|---|
| `z_common = 0.5·z_even` | **74.99 Ω** | 单线 `2w = 0.6` 的闭式 **75.658 Ω** | **−0.87%** |
| `z_odd` | **45.62 Ω** | — | **−39.70%**（相对自身 0.2 mm 时的 64.93） |

`s = 0.03` 时 `z_common = 75.03`（**−0.83%**）、`z_odd = 40.67`。
更廉价的网格（`fine_div=3`，7.7 s，3627 节点）给 `z_common` **−0.62%**，测试用这一档。

**正确的读法**（第一版写错过一次）：
- **共模** → 一根 2w 宽的单线。物理上两条同电位的条中间那点缝隙不承载场，合并成一条；
- **奇模** → **0**。两条 +V/−V 的条之间，缝的电容按 `1/s` **对数发散**，所以 `Z_odd → 0`。
  这是物理正确的发散，不是求解失败。

**反过来，间距 → 大，不是单线答案**（这条故意不断言，但要写下来防止后来者拿来当判据）：

| `s` (mm) | `z_odd` (Ω) | 同一根条单独解 |
|---|---|---|
| 0.6 | 86.588 | 89.674 |
| 1.5 | 104.059 | 89.674 |
| 4.0 | 116.458 | 89.674 |

奇模阻抗**升到单线之上**，并且不收敛到它：间距大时每条条只有**一侧**有地，回流被推远，
等效地变少——和「孤立单线有两翼对称回流」是两个不同的边界条件。

### 30.3.5 两个「故意写错」的负控制（都在测试里）

仓库纪律：**每条新判据都要有一个能失败的对照。** 这一批放了两个坏的子类：

| 负控制 | 造出的 bug | 抓它的是哪条 |
|---|---|---|
| `_FreeSecondStrip` | 左条不摘出未知集（= §30.2.1 的真 bug） | 两个模式的电容**塌成同一个数**（`places=9`）；且该数既不是诚实的 odd 也不是 even（<0.9×odd、>1.1×even） |
| `_SignFlipped` | 奇模驱动忘了负号（+1/+1） | 叠加恒等式残差 ≈ 0.42（>5%） |

**并且把「恒等式对浮动条是盲的」这条也写成断言**：浮动左条时恒等式残差只有 **1.47e-10**，
因为浮动电位是驱动的同一个线性函数，三次求解照样构成线性关系。
也就是说，**一条检查兜不住两种 bug**——这是这批唯一一条「元结论」。

（`_SignFlipped` 第一版忘了同时把左条摘出未知集，于是 `val` 根本没进解，
控制恒等式残差 1.4e-10、**静默失效**。这条也写进了它的 docstring。）

## 30.4 差分损耗：三件事同时成立

`frequency_ghz > 0` 时另跑一次 `coplanar_pair_shape_factor`（**奇模**表面电荷），
按 `α_c = Rs/(2·Z_odd)·∫g²ds` 给导体损耗。基准几何、@2.4 GHz、`tanδ = 0.02`：

| 项 | 差分对 | 单线（29 的同几何） |
|---|---|---|
| 形状因子 `∫g²ds` /mm | **5.044122** | 3.321224 |
| — 两条条 | 4.528725（左右各 2.264362，逐位相等） | 2.1244 |
| — 两翼地 | 0.515397（左右各 0.257699，背面 0） | 1.1968 |
| `Rs` @2.4 GHz | 0.01278 Ω/sq | 同 |
| 导体损耗 | **0.4312 dB/100mm** | 0.2081 |
| 介质损耗 | **0.5157 dB/100mm** | 0.4561 |
| 合计 | **0.9469 dB/100mm** | 0.6642 |

三件必须一起说的事：

1. **归一化只能选「差分电流」。** 两条条各自归一化会让左右不同（差模下左条电荷是负的），
   归一化到总和则在奇模下恒为 0（两端地电流和为零）——只能以正条电荷为 `q_ref`，
   再把所有导体的 `∫g²ds` 加起来。
2. **形状因子是零厚度值，实测网格漂移 8.79%**（`fine_div=8, refine=1.5` 对 4.6 的粗网格）。
   真实铜箔约再高 10%，而那 10% 在 29 §29.5 里已经测过「不收敛」。
   所以导体这项是**下界 + 一个不确定度**，工具在 `conductor_note` 里逐字这么说。
3. **墙上的电流不是免费的**：奇模下两条条之间的缝里场最强，形状因子从 3.32 涨到 5.04（+52%），
   而 `Z_odd` 只有单线的 0.72 倍，所以 `α_c ∝ S/Z` 涨了约 2.07 倍。
   这不是「多了根线所以翻倍」那么简单——`S` 的涨幅本身也是缝变窄的结果。

## 30.5 工具：`coplanar_pair_field`

参数：`width_mm`、`spacing_mm`（边对边）、`gap_mm`、`dielectric_mm`（必填）、
`copper_um`（默认 0）、`er`（4.3）、`kind`（`cpw`/`gcpw`）、`levels`（默认 2）、
`frequency_ghz`（默认 0＝不算损耗）、`tan_delta`、`max_nodes`（默认 60000）。

返回：`value` = **Zdiff**（= `2·z_odd`，两位小数），另有
`z_odd_ohm` / `z_even_ohm` / `z_common_ohm` / `eps_eff_odd` / `eps_eff_even` /
`mesh`（两级网格的节点、sweep、残差）/ `mesh_drift_ohm` / `charge_balance_odd` /
`mode_note` / `limit_note` / `validated_against`；
`frequency_ghz > 0` 时再加 `conductor_db_per_100mm` / `dielectric_db_per_100mm` /
`total_db_per_100mm` / `surface_resistance_ohm_sq` / `shape_factor_odd` / `conductor_note`。

基准几何实测（`levels=2`，37.8 s）：

| kind | `z_odd` | `z_even` | `z_diff` | `z_common` | `eps_eff_odd` | `eps_eff_even` |
|---|---|---|---|---|---|---|
| cpw | 64.930 | 146.202 | **129.860** | 73.101 | 2.4045 | 2.0591 |
| gcpw | 50.944 | 65.417 | **101.887** | 32.708 | 2.888 | 3.322 |

两级网格漂移：odd **+0.123 Ω**、even **−0.443 Ω**（`fine 0.0200 → 0.0130`，
节点 3293 → 5588）。工具照例声明：**这是自洽性，不是总误差**。

拒绝路径（都是 `OUT_OF_VALIDITY` / `ARG_INVALID`，不闷头跑）：
`kind` 不是共面；几何非正；`max_nodes` 不够（细步长跟着 `min(w, s, h)` 走，
所以 `spacing` 远小于 `width` 时节点会炸——`s = 0.005` 时到 47k 节点）。
另外两条 `validity_note` / `gap_note` 在 `s/w < 0.25`、`g/h < 0.2` 时出现，
说的是「这个参数点上奇模答案由缝电容主导」和「槽窄于衬底时按单线实测再降 3% 量级」。

## 30.6 这一批明确不做的事

| 不做 | 为什么 |
|---|---|
| 有限地平面宽度 | 现在的两翼地是「从槽口向外 8(w+2g)」，近似无限；真实版图里地是有限宽的，会抬高 Z0 并改变回流。29 里也留着这条 |
| 有限铜厚进 Z0 | 和 29 同一结论：厚度项不收敛，不给数 |
| 不等宽 / 不等间距（非对称对） | 网格镜像穿过 `x = 0` 是这一批全部精确不变量的前提；非对称对先把这批判据全部作废，再谈解 |
| 模态变换 / 混合模 S 参数 | 那是网络层的事，本仓库现在是截面层 + 器件级 SPICE |
| 接到 `feedline_impedance` 的 `kind="cpw_diff"` | 有意留给下一批：那条链要把介质损耗、导体损耗、宽度反解一起接上，是另一批工作量 |
| 色散、辐射、蚀刻梯形 | 二维准 TEM 之外不猜（与 16/27/29 同口径） |
