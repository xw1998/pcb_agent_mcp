# 113 画板方法论与 MCP 用法，各写成一份 skill

这一篇记「布局走线全是狗屎」之后的处置：**不再急着改线，先把画板的判断力写下来**，
分成两份可复用的技能文档放进仓库 `skills/`。

零功能改动：没动 `src/`，没加工具，工具数仍是 **190**，自检与测试的既有门槛一条未改。
所以本篇的验收方式是「能不能拿去核一块真板」，不是「有没有新读数」。

## 113.1 为什么是 skill，不是又一段说明

前面几轮的失败不是「不知道某条规则」，而是**顺序错**：

- 要求双层板，画成 4 层 ⇒ 约束表里没有「铜层数」这一行；
- 要求单面贴片，两面都放件 ⇒ 摆放阶段没按层过滤；
- 没有铺铜、没有缝合 ⇒ 把铺铜当收尾；
- 用自动布线 ⇒ 优化目标（连通）与验收目标（回流、环路、工艺余量）不是一回事；
- 最后 12 组网络布不通 ⇒ 因为先布线后规划，`W25_CLK` 的板底横干 + 竖井筑成一道 L 形死墙，
  把东侧与东南角在拓扑上分开；`U2`+`C2` 又占掉了东侧唯一南北走廊。

**每一条都是「顺序」问题，靠加一段话修不了。**所以落成流程 + 判据 + 失败清单，
让下一个 agent 在动手前先把顺序走一遍。

## 113.3 学到的几条硬规则（带出处）

| 规则 | 内容 | 出处 |
|---|---|---|
| 间距先选行 | 同一 50 V，IPC-2221B 的 B1=0.10 / B2=0.6 / B4=0.13 / A5=0.13 mm，差 6 倍；未涂覆外层怕的是**表面爬电**，不是空气击穿 | rftools.io 对 Table 6-1 的逐行引用（**二手转述，正式报告需回原表**） |
| 涂覆先定后布 | 涂层把间距改 4 倍以上；事后补一句「已涂覆」不改变几何 | 同上 |
| 两层板的地 | 一层信号+电源、一层完整地；两层都走线则两面铺铜 + 缝合孔，**不切地** | Sierra Circuits 十大惯例（两层场景） |
| 缝合间距 | λ/20 ~ λ/10；高速数字 2.5–5 mm、混合 5–12.7 mm，只能更密 | 同上 |
| 铺铜与信号 | 留 1.5–2 倍线宽；离板边 10–15 mil | 同上 |
| 晶振布局 | 晶体与两个负载电容**各自**有独立地「底板」（与其它地留可见分隔），装配层做地护墙 + 多个过孔，底板单独接最近 VSS | ST 社区文（指向 AN2867 §7 Figure 14/15） |
| 负载电容 | `Cs = CIO + CPCB ≈ 3 pF`；`CL1 = CL2 = 2(CL − Cs)` | 同上 |
| 扇出算术 | `g = pitch − pad_w`；过 n 条线需 `g ≥ n·w + (n+1)·c`。LQFP 0.5/0.3 时 g=0.2 ⇒ 一条都过不去 | 本项目实算（F412 右列焊盘带实测） |

**诚实标注**：AN4879（USB 硬件与 PCB 指南）与 AN2867 的 PDF 正文本次**没有取到**，
只核到条目，所以 USB 一节只写通行做法、不引它的数值。要写进报告的数值必须回原件。

## 113.4 直接后果：当前这块 F412 板的判决

按 `05-routing-and-failure-modes.md` 的 14 条逐条对，命中：

| # | 失败模式 | 本板是否命中 | 证据 |
|---|---|---|---|
| 1 | 层数选错 | 命中（已改回 2 层） | 早期交付为 4 层 |
| 2 | 贴装面搞错 | 待核 | 用 `board_components` 数两层器件 |
| 3 | 没有铺铜 | 命中 | `board_zones` 无 filled_polygon |
| 4 | 用自动布线 | 命中（已摘除工具） | `board_route` 已退休 |
| 5 | L 形死墙 | 命中 | `W25_CLK` 横干 y=−42.05 + 竖井 |
| 6 | 唯一走廊被电源件占满 | 命中 | `U2.1`/`C2` 压 x 60.45..62.45 / y −36.3..−40.1 |
| 7 | 过孔压焊盘 | 未命中（已避免） | — |
| 8 | 中间车道耗尽 | 命中 | B.Cu 只剩 −41.30/−41.70 两条，需 4 条 |
| 9 | 绕板三圈 | 命中 | `W25_IO3` 从腹地跨到东侧 |
| 10 | 0.5 mm 间距想平行走线 | 已避免 | 扇出算术 |
| 11 | 把「连不上」当「网络不可布」 | 命中 | `PC2` 判不可布，实为摆放所困 |
| 12 | DRC 全绿当验收 | 命中 | `issues: 0` 但 12 组未连通 |
| 13 | 只判几何不判电气 | 命中 | 无 `board_cross_split`/`board_loop_area`/IR drop 读数 |
| 14 | 大面积空白、右侧极稀 | 命中 | 渲图：密度左/中高、右侧极稀 |

⇒ **结论不是「再修几条线」，而是「这一版布局要重摆」。**按 `02-placement.md` 的七步重来：
先把 `U2`/`C2` 移出南北走廊、把 `W25_CLK` 的横干换成不开死墙的走法、留出 4 条中段车道，
再谈 `PB12..15`/`PC2`/USB 那几组。
